Mutation Operator: Change Function Signature Calling Convention

This mutation operator targets function definitions using specific calling conventions and alters them to use another convention. It specifically applies to functions that are defined with the "rust-call" calling convention, as seen in the example.

Example mutation of the code construct:
Original Code:
```rust
struct Example;
impl Example {
    extern "rust-call" fn method_name(param: i32) {}
}

fn main() {
    Example::method_name(5);
}
```

Mutated Code:
```rust
struct Example;
impl Example {
    extern "C" fn method_name(param: i32) {}
}

fn main() {
    Example::method_name(5);
}
```

In this mutation, the `extern "rust-call"` declaration is changed to `extern "C"`. This kind of change is likely to expose bugs related to the interaction between different calling conventions and their handling within the compiler, especially in relation to unboxed closures when calling methods with these modified signatures.
