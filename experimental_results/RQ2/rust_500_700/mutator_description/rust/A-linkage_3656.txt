Mutation Operator: Alter FFI Function Signature

Description: This mutation operator targets the signature of functions declared within an `extern` block, specifically those that involve Foreign Function Interface (FFI) bindings. The goal is to modify the parameter types or add new parameters to the function signature to test how the Rust compiler handles changes in FFI function signatures.

Where it applies: In the `extern` block where FFI functions are declared.

Mutation Steps:
1. Identify a function within an `extern` block that takes a complex struct as a parameter.
2. Modify the type of an existing parameter or add a new parameter with a simple type such as `int` or `float`.
3. Ensure that any new parameter has a clearly defined type and is appropriately declared in the context of the function signature.

Example Before Mutation:
```rust
extern {
    pub fn mhash_keygen_ext(data: KEYGEN);
}
```

Example After Mutation:
```rust
extern {
    pub fn mhash_keygen_ext(data: KEYGEN, extra_param: int);
}
```

In this example, we added an `extra_param` of type `int` to the function `mhash_keygen_ext`. Modifying FFI function signatures in this way can help reveal how the compiler handles linkage and interfacing with external code, particularly in the presence of complex types like structs.
