Mutation Operator: Change Const Parameter Default Value

Target: Const generic parameters with default values in type definitions.

Description: Modify the default value of a const generic parameter in a type definition to manipulate how the Rust compiler evaluates and checks these defaults. This mutation targets the evaluation of expressions used as default values for const generics, which can expose inconsistencies in the compiler's const evaluation logic and error handling. 

Changes: Identify a type definition with a const generic parameter that has a default value. Modify the default expression by applying a different arithmetic operation or changing its components to a different valid expression. Ensure the new expression remains within the bounds of the type system and does not introduce undeclared variables.

Example:

Original:
```
type ArrayWrapper<T, const SIZE: usize, const EXTRA: usize = {SIZE + 1}> = [T; EXTRA];
```

Mutation:
```
type ArrayWrapper<T, const SIZE: usize, const EXTRA: usize = {SIZE * 2}> = [T; EXTRA];
```

In this mutation, the default value for `EXTRA` changes from `{SIZE + 1}` to `{SIZE * 2}`, triggering different internal calculations within the compiler and potentially revealing hidden issues in handling const generics with default values.
