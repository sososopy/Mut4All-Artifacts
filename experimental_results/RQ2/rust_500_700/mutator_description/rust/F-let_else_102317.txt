Mutation Operator: Condition Inversion in `let_else` Statements

This mutation operator targets the specific code construct of `let_else` statements within Rust programs. The mutation involves altering the condition within a `let_else` statement to its inverse. This operator is applicable when a `let_else` statement is used to destructure a value and handle the case where the pattern does not match.

Mutation Process:
1. Identify a `let_else` statement in the code where a pattern destructuring is used.
2. Invert the condition in the `let_else` statement, effectively modifying the logic to handle the opposite case of the current pattern.

Example:
Original Code:
```
let Some(value) = optional_value else {
    handle_none_case();
    return;
};
```

Mutated Code:
```
let None = optional_value else {
    handle_some_case(value);
    return;
};
```

Explanation:
- The original code checks if `optional_value` is a `Some` variant and executes logic within `else` when it is not (`None`).
- The mutated code inverts the pattern to check for `None` directly, assuming that `optional_value` can instead be matched with `None`. The `else` block would now handle the `Some` case, requiring adjustment to ensure `value` is used appropriately.

This mutation operator is designed to test the robustness of the `let_else` handling by reversing the intended control flow and examining if the program logic remains consistent and error-free under this modification.
