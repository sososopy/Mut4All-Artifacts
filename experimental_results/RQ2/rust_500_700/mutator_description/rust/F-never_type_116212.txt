Mutation Operator: Introduce Unreachable Code in Functions

Description: This mutation operator targets function bodies and introduces unreachable code paths by adding control flow constructs such as `if false { }`, `loop { break; }`, or `match` statements with non-exhaustive patterns. This operator aims to expose issues related to unreachable code handling and optimization passes like MIR optimizations.

Application: The mutation applies within the body of any existing function in the seed program.

Example:

Before Mutation:
```
fn example_function() {
    let a = 5;
    let b = 10;
    let c = a + b;
    println!("Sum is: {}", c);
}
```

After Mutation:
```
fn example_function() {
    let a = 5;
    let b = 10;
    
    if false {
        // Unreachable block
        let unused = a * b;
    }

    let c = a + b;
    println!("Sum is: {}", c);

    loop {
        break; // Introduce early exit from loop, making anything after unreachable.
    }
    println!("This will never be printed");
}
```

This operator introduces code paths that are not executed under normal conditions, which can help identify issues with the Rust compiler's handling of unreachable code, optimization passes, and related constructs.
