Mutation Operator: Constant Parameter Value Swapping

Target Code Construct: This mutation operator targets generic structures or functions with constant parameters.

Description: The mutation involves swapping out constant expressions assigned to generic type parameters with other valid constant expressions within the same program. This can potentially trigger bugs related to constant parameter substitution or evaluation during compilation.

Where It Applies: This operator applies to Rust code where a struct or function utilizes constant generics. Constant parameters are usually defined with the `const` keyword, followed by a type and an initializer.

Mutated Content: Given a struct or a function with a constant generic parameter, replace its initialized constant expression with another constant expression from within the program. If no other constant expressions are available, introduce a simple constant expression like an integer or character.

Example of Mutation:
Original:
```rust
struct Container<const N: usize = 5>();
fn process<const M: usize = 10>() {}

```

Mutated:
```rust
struct Container<const N: usize = 10>();  // Swapped the constant value from `process`
fn process<const M: usize = 5>() {}       // Swapped the constant value from `Container`
```

Note: Ensure that the swapped constant expressions are type-compatible (e.g., both are of type `usize`). If a new constant expression is introduced, it should be simple (e.g., `0`, `1`, `b'a'`) and declared where the mutation takes place.
