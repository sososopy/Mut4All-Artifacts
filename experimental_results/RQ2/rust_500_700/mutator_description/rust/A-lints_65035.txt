Mutation Operator: Generic Type in FFI

Description:
This mutation operator targets the use of generic types in foreign function interface (FFI) declarations. Specifically, it applies to situations where a static variable or function in an FFI block is declared with a generic type parameter. The operator modifies the FFI declaration to use a concrete type instead of a generic type. This helps identify and expose bugs related to how the Rust compiler handles type generalization in the context of FFI.

Mutation Details:
1. Identify the FFI block containing declarations with generic types. This includes static variables or functions using generic type parameters.
2. Replace the generic type parameter with a concrete type that is already present in the seed program. If no concrete type is present, introduce a predefined simple type such as `i32` or `f64`.
3. Ensure that the rest of the program is consistent with this type change, such as adjusting variable declarations or function definitions that may interact with the FFI.

Example Before Mutation:
fn example<T>() {
    extern "C" {
        static ffi_static: *const T;
    }
    // Assume T is used elsewhere in the function
}

Example After Mutation:
fn example() {
    extern "C" {
        static ffi_static: *const i32;
    }
    // Adjust other uses of T to use i32 if necessary
}

This mutation operator is aimed at catching inconsistencies or issues in the Rust compiler's handling of generics within the FFI context, which may not be fully supported or expected to behave differently from regular Rust code.
