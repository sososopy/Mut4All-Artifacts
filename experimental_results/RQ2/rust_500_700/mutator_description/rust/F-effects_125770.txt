Mutation Operator: Invalid Const Generic Type Mutation

This mutation operator targets const generic parameters by replacing their types with unsupported or invalid types. It applies specifically to structs, enums, and functions that use const generics. The intention is to expose bugs related to the handling of const generic parameters with unsupported types, which are known to cause internal compiler errors (ICE) in the Rust compiler.

Mutation Description:
1. Identify any struct, enum, or function that declares a const generic parameter with a supported type (e.g., integer, bool, char).
2. Mutate the type of the const generic parameter to an unsupported type, such as a user-defined struct or enum that is not marked with the appropriate feature gate (e.g., `adt_const_params`).
3. Ensure that the unsupported type used for the const generic parameter is already declared in the existing program or declare a new simple struct or enum if not present.

Example of Mutated Content:

Original Code:
```rust
struct Container<T, const N: usize> {
    data: [T; N],
}
```

Mutated Code:
```rust
struct Dimension;

struct Container<T, const N: Dimension> {
    data: [T; 1], // Use a placeholder value for the array size
}
```

Note: In this mutation, the original supported type `usize` for the const generic parameter `N` is replaced with an unsupported type `Dimension`. The placeholder `data` array size is set to 1 to maintain valid syntax, but the focus is on the invalid const generic type. This mutation is designed to trigger compiler errors or ICEs related to unsupported const generic types, particularly in the context of the `adt_const_params` feature.
