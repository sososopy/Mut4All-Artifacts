Mutation Operator: Modify Yield Expressions in Generators

Target: This mutation operator targets Rust generator functions, specifically their yield expressions. Generators are structures that implement the `Generator` trait and are often used with the `yield` keyword to produce values.

Description: To expose bugs related to type inference and the handling of references in generator functions, alter the yield expressions in such a way that they yield different types or references, potentially leading to type inference challenges or mismatches.

Example:

Original generator:
```
fn example() -> impl Generator {
    || { yield &1 }
}
```

Mutated generator:
```
fn example() -> impl Generator {
    || { yield 1 }
}
```

Explanation:
1. Identify the generator function in the seed program.
2. Within the generator function, locate the yield expression (e.g., `yield &1`).
3. Modify the yield expression to yield a value of a different type (e.g., change `yield &1` to `yield 1`). In this case, the reference `&1` is changed to the value `1`, altering the type yielded by the generator from a reference to an integer.
4. Ensure that the rest of the function remains unchanged to maintain a valid generator syntax, focusing only on the type change introduced by the altered yield expression.

This mutation aims to trigger type inference and reference handling issues in the Rust compiler by providing different types in yield expressions, encouraging varied compiler paths and diagnostic messages.
