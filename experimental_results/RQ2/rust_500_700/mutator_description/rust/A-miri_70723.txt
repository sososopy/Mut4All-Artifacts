Mutation Operator: Infinite Loop in Static Item

This mutation operator targets infinite loops within static items in Rust programs. The goal is to introduce or modify existing loops to ensure they are evaluated at compile time, which can trigger bugs related to constant evaluation.

Where it Applies:
- The mutation operator applies to static items, specifically those that may contain infinite loops or need compile-time evaluation.

Mutation Details:
1. Identify a static item in the seed program.
2. Introduce an infinite loop within the static item's initialization, ensuring this loop is intended to execute at compile time.
3. Use existing variables and types where possible. If a static item does not already exist, introduce one with a basic type such as `()` or `i32`.
4. Ensure the loop does not contain any break or return statements to maintain its infinite nature.

Example of Mutated Content:
Original:
static VALUE: i32 = 42;

Mutated:
static VALUE: i32 = loop {};

By introducing an infinite loop in a static item, we test the compiler's handling of constant evaluation, which can expose issues related to the handling of loops during compile-time execution.
