Mutation Operator: Modify Higher-Ranked Trait Bounds (HRTBs)

This mutation operator targets functions that use Higher-Ranked Trait Bounds (HRTBs) in their type signatures, specifically those involving lifetime parameters. The goal is to modify the lifetimes used in HRTBs to test the robustness of the Rust compiler's lifetime inference system.

Application:
- Identify functions that utilize HRTBs with lifetime parameters in their type signatures.
- Modify the lifetime parameters in these type signatures, either by introducing new lifetimes or altering existing ones.

Description:
1. Locate a function with a type signature that includes a Higher-Ranked Trait Bound with lifetimes, such as `for<'a> fn(&'a T)`.
2. Alter the lifetime parameter in the HRTB to introduce variations in lifetime relationships. This could involve replacing the existing lifetime with a different one, introducing a new lifetime, or combining lifetimes.

Example:
Consider the following function signature using HRTBs:

Original:
fn example<'a>() where for<'b> fn(&'b T): Trait {}

Mutation:
Modify the HRTB lifetime to introduce a new variation:

Mutated:
fn example<'a>() where for<'c> fn(&'c T): Trait {}

In this mutation, the HRTB lifetime '`b`' is replaced with a new lifetime '`c`'. This tests how the compiler handles different lifetime scenarios within the HRTB construct, potentially uncovering bugs related to lifetime inference and soundness in the presence of HRTBs.
