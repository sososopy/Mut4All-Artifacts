Mutation Operator: Array Index Mutation

This mutation targets the usage of arrays and the indexing operation applied to them. Specifically, it applies to instances where an array is accessed by using a variable or an expression to determine the index.

Original Code:
```rust
array_name[index_expression]
```

Mutated Code:
```rust
array_name[safe_index]
```

Description:
Replace an index that is determined dynamically (using a variable or an expression) with a constant or 'safe' index to test the compiler's handling of static versus dynamic indexing. The 'safe_index' should be a valid constant integer literal that does not exceed the bounds of the array when it is declared. This mutation can help expose bugs related to how the Rust compiler optimizes or manages static versus dynamic accesses in arrays.

Example:
Suppose there is a code segment with an array access like:
```rust
let value = my_array[i + offset];
```

The mutation would transform it to:
```rust
let value = my_array[0]; // assuming '0' is a valid index
```

To apply this mutation:
1. Identify array access patterns in the seed program.
2. Replace dynamic index expressions with valid constant index values.
3. Ensure the chosen constant index is within the array's declared bounds.
