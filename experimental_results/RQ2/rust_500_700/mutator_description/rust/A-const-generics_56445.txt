Mutation Operator: Modify Const Generics in Parametric Implementations

This mutation operator targets constant generic parameters within implementations that are parameterized by lifetimes. The goal is to introduce variations in how constant expressions are defined and used, potentially triggering compiler issues related to const generics normalization.

Mutation Description:
1. Identify any `impl` block with a lifetime parameter and one or more associated constant items.
2. For each constant item within such `impl` blocks, perform one of the following mutations:
   a. Change the value of the constant to a different valid literal or another constant if available.
   b. Introduce a new constant in the `impl` block, ensuring it uses a different data type or expression based on existing constants or types.
   c. Utilize the const item in a new function or extend its usage in existing functions beyond its current usage scope.

Example:
Original Code:
```
impl<'a> OnDiskDirEntry<'a> {
    const LFN_FRAGMENT_LEN: usize = 2;
    fn lfn_contents(&self) -> [char; Self::LFN_FRAGMENT_LEN] { loop { } }
}
```

Mutated Code:
1. Changing the value of the constant:
```
impl<'a> OnDiskDirEntry<'a> {
    const LFN_FRAGMENT_LEN: usize = 4;
    fn lfn_contents(&self) -> [char; Self::LFN_FRAGMENT_LEN] { loop { } }
}
```

2. Introducing a new constant:
```
impl<'a> OnDiskDirEntry<'a> {
    const LFN_FRAGMENT_LEN: usize = 2;
    const MAX_ENTRIES: u32 = 100;
    fn lfn_contents(&self) -> [char; Self::LFN_FRAGMENT_LEN] { loop { } }
    fn max_entries(&self) -> u32 { Self::MAX_ENTRIES }
}
```

3. Extending the usage of the constant:
```
impl<'a> OnDiskDirEntry<'a> {
    const LFN_FRAGMENT_LEN: usize = 2;
    fn lfn_contents(&self) -> [char; Self::LFN_FRAGMENT_LEN] { loop { } }
    fn extended_contents(&self) -> usize { Self::LFN_FRAGMENT_LEN + 1 }
}
```
