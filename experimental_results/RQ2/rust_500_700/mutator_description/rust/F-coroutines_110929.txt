Mutation Operator: Nested Generator Mutation

Target: The mutation operator applies to nested generators within a function.

Description: This mutation operator targets functions containing nested generators and modifies the nesting structure or the yield points within the generator. It alters the nesting depth of the generators by either removing a layer of nesting or adding an additional layer. The operator may also change the order of yield points or introduce new yield points within the generator logic. This operator is designed to test the compiler's handling of complex generator structures and how they manage borrow and ownership rules.

Example of Mutated Content:
Original:
```
fn example_function() {
    let mut outer = || {
        let mut inner = || {
            // Existing logic
            yield;
        };
        // Existing logic
        yield;
    };
}
```

Mutated:
```
fn example_function() {
    let mut outer = || {
        // Existing logic
        yield;
        let mut inner = || {
            // Altered logic, adding yield before the existing one
            yield;
            yield;
        };
    };
}
```

Explanation: The mutation operator has altered the structure of the nested generator by adding an extra yield before the existing yield in the inner generator. This tests how the compiler deals with modified generator execution paths and the associated borrow-checking obligations.
