Mutation Operator: Modify References to Raw Pointers in Constants

Target: This mutation operator targets code constructs involving the use of raw pointers within constant expressions, particularly where references are taken to stack-allocated variables.

Description: To expose potential bugs related to dangling raw pointers in constant expressions, this mutation operator modifies constant definitions involving raw pointers by introducing scenarios where the reference might become invalid. The goal is to simulate conditions that may lead to undefined behavior or ICEs (Internal Compiler Errors).

Mutation Steps:
1. Identify constant definitions that involve taking a reference to a stack-allocated variable within a block.
2. Alter the block by introducing a dereference operation on the pointer, or by changing the lifetime of the reference to a temporary or out-of-scope variable.

Examples:
Original Code:
const BAR: *const i32 = {
    let y = 100;
    &y
};

Mutated Code:
const BAR: *const i32 = {
    let y = 100;
    let z = &y;
    z
};

Explanation:
In the original code, a reference to a stack-allocated variable 'y' is directly assigned to a raw pointer. In the mutated code, an intermediate reference 'z' is introduced, and 'z' is assigned to the raw pointer instead. This variation tests the compiler's handling of intermediate references and the potential for dangling pointers when the original variable goes out of scope.
