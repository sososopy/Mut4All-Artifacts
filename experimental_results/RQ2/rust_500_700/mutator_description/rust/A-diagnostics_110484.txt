Mutation Operator: Introduce Unresolved Macro Interpolation with Multi-byte Characters

This mutation operator targets macro invocations that use string interpolation with unresolved identifiers and multi-byte characters. The operator applies to any usage of macro invocation that interpolates identifiers into strings, such as `printdoc!`, `format!`, or similar macros that allow string interpolation.

Description:
Modify a macro invocation that interpolates an identifier into a string by introducing an unresolved identifier (i.e., a variable name not declared within the scope) and include multi-byte characters within the interpolated string. This forces the compiler to handle cases involving multi-byte characters and unresolved identifier references, which are prone to diagnostics-related bugs and internal compiler errors.

Example of Mutation:
Consider a macro invocation in the seed program like the following:

Original:
```
macro_name! {
    "
    This is a normal string with {existing_var}.
    "
}
```

Mutated:
```
macro_name! {
    "
    ああ{unresolved_var}
    "
}
```

In the mutated example, we replace the `existing_var` with `unresolved_var` (an identifier that is not declared or defined in the scope) and include a multi-byte character sequence such as "ああ" in the string. The purpose of this mutation is to simulate scenarios where unresolved variables and multi-byte characters could lead to internal compiler errors, as suggested by the bug report.
