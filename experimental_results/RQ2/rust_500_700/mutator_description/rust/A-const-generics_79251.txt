Mutation Operator: Alter Const Generics Expressions

Target: This mutation operator targets const generics expressions, specifically arithmetic operations within array types or generic implementations. It applies to Rust code that employs const generics to define array sizes or other compile-time constant parameters.

Description: Const generics can often include arithmetic operations that determine the size of structures or arrays. These operations can be modified to expose bugs in the way the compiler handles const generics. The mutation operator changes the arithmetic expressions within const generics to test the robustness of the compiler's evaluation of these expressions.

Implementation: Locate const arithmetic expressions within struct definitions or generic implementations. Modify these expressions by altering the arithmetic operations (e.g., addition, multiplication) or by changing constants involved in these operations. Ensure that the resulting expression is valid and does not introduce out-of-bounds values.

Example:
- Original Code:
  ```rust
  struct Node<K, const D: usize> {
      keys: SmallVec<K, { D * 2 }>,
  }
  ```

- Mutated Code:
  ```rust
  struct Node<K, const D: usize> {
      keys: SmallVec<K, { D + 3 }>,
  }
  ```

In this example, the multiplication operation in `D * 2` is replaced with an addition operation `D + 3`. By altering the arithmetic expression, this mutation tests if the compiler can correctly evaluate and handle the modified const generics, potentially exposing bugs related to the const generics feature.
