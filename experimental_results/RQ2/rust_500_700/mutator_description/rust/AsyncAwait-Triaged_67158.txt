Mutation Operator: Macro Call within Async Block

Target: This mutation operator targets the specific construct of macro calls within async blocks, particularly when combined with coroutine-related features such as `yield`. The goal is to test the interaction and potential issues that may arise when macros are invoked in such contexts.

Description: The mutation involves inserting a macro call within an async block, especially when combined with coroutine control flows such as `yield` or `await`. The macro should be a simple one that expands to a valid Rust expression or statement. This operator aims to expose issues related to the expansion and evaluation order of macros within async constructs.

Example Mutation:

Original Code:
```
async {
    yield some_expression;
}
```

Mutated Code:
```
macro_rules! my_macro {
    () => {
        some_expression
    };
}

async {
    yield my_macro!();
}
```

Explanation: The mutation introduces a macro definition `my_macro!`, which expands to an expression that already exists in the context of the async block. The macro is then invoked within the `yield` statement to test if the compiler can handle the macro expansion alongside the `yield` functionality within the async block. This mutation helps in identifying potential ICEs or other issues related to macro expansion in async contexts.
