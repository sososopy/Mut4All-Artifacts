Mutation Operator: Or-Pattern Expansion

This mutation operator targets or-pattern constructs within match or assignment patterns. The operator applies to places in the Rust code where an or-pattern (|) is used within an enum or a similar pattern matching context. The purpose is to expand or-patterns into separate match arms or distinct logical branches, which can reveal inconsistencies or overlooked cases in the compiler's handling of or-patterns.

Example of Mutation:

Original Code:
```
match value {
    MyEnum::FirstCase(_) | MyEnum::OtherCase(_) => {
        // original branch logic
    }
}
```

Mutated Code:
```
match value {
    MyEnum::FirstCase(_) => {
        // original branch logic
    }
    MyEnum::OtherCase(_) => {
        // original branch logic
    }
}
```

Explanation:
- Identify the or-pattern in a match statement or pattern binding.
- Replace the or-pattern with separate branches or arms, each handling one of the original pattern cases.
- Ensure that the logic inside the or-pattern is duplicated across the new branches, maintaining original behavior.
- Avoid introducing new expressions or logic outside of separating the or-pattern into individual parts.

By transforming or-patterns into distinct branches, this mutation operator can test whether the handling of such pattern transformations is consistent and correct in the compiler, potentially uncovering internal errors when or-patterns are expanded in this way.
