Mutation Operator: Type Annotation for Const Items in Macros

This mutation operator targets `const` items inside macro definitions. It applies when a `const` item is declared without an explicit type within a macro. The mutation aims to expose issues related to type inference and macro expansion by enforcing explicit type annotations for `const` items.

Changes to be Made:
Identify `const` items in macro expansions that are missing type annotations. Add an explicit type annotation to these `const` items. The type should correspond to the expected type of the expression assigned to the `const`. Common types include `i32` for integer literals, `f64` for floating-point literals, and `&str` for string literals.

Example:

Seed Program:
```
macro_rules! suite {
    ( $( $fn:ident; )* ) => {
        $(
            const A = "A".$fn();
        )*
    }
}

suite! {
    len;
    is_empty;
}
```

Mutated Content:
```
macro_rules! suite {
    ( $( $fn:ident; )* ) => {
        $(
            const A: &str = "A".$fn();
        )*
    }
}

suite! {
    len;
    is_empty;
}
```

In this example, the `const A` item within the macro is mutated to include an explicit type annotation `&str`, which corresponds to the string literal "A". This mutation forces the compiler to handle type-checking explicitly, revealing any potential issues with type inference during macro expansion.
