Mutation Operator: Arithmetic Overflow Injection

Description:
This mutation operator targets arithmetic operations involving integer types. Rust is known to handle integer overflow by panicking in debug mode, making it a potential source of bugs. By deliberately injecting changes that can lead to overflow, we can expose issues related to improper handling of arithmetic operations.

Application:
The operator applies to any arithmetic operation involving integer variables, constants, or expressions. It focuses on operations such as addition, subtraction, multiplication, and division.

Mutation Steps:
1. Identify an arithmetic operation in the seed program involving integer operands. This could be an addition, subtraction, multiplication, or division.
2. Modify the operation to increase the likelihood of overflow. This can be done by:
   a. Adding a large constant value to one of the operands.
   b. Substituting one of the operands with an expression that evaluates to a significantly larger or smaller integer.
   c. Multiplying an operand by a large constant or another variable that could result in a large product.
   d. Dividing an operand by a very small constant or another variable that approximates zero.

Example:
Original Code:
```
let result = a + b;
```

Mutated Code:
```
let result = a + b + 10_000_000_000; // Increase likelihood of overflow by adding a large constant
```

In this example, `a` and `b` are existing integer variables. The mutation introduces a large constant to the addition, increasing the possibility of overflow. The goal is to observe how the program handles such scenarios and whether the overflow is correctly managed, potentially exposing compiler bugs related to arithmetic overflow.
