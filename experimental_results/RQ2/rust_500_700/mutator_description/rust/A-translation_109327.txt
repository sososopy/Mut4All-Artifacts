Mutation Operator: Type Lifetime Variance Mutation

Target: This mutation operator targets structs with lifetime parameters and modifies their lifetime variance. It applies to structs where at least one field has a reference type with a specified lifetime.

Description: The mutation involves changing the covariance or contravariance of lifetime parameters in structs. In Rust, lifetime parameters are invariant by default. By explicitly specifying covariance or contravariance, we can explore edge cases in type-checking and lifetime resolution. 

Steps for Mutation:
1. Identify a struct with lifetime parameters in its fields. For example, a struct with a field of type `&'a T`.
2. Modify the struct definition to explicitly specify lifetime variance.
3. Convert the lifetime parameter to use the variance specifier: `+` for covariance or `-` for contravariance.
4. Ensure the mutated struct is used in a context where variance could affect type resolution or lifetime checking.

Example:
Original Code:
```rust
pub struct Animations<'a> {
    current_animation: &'a str,
}
```

Mutated Code:
```rust
pub struct Animations<'a: +> { // Specify covariance with `+`
    current_animation: &'a str,
}
```

This mutation operator aims to stress-test the Rust compiler's handling of lifetime variance, potentially triggering bugs related to lifetime resolution and variance in more complex codebases. By introducing explicit variance, the mutated code can expose subtle issues in the compiler's translation phase when resolving lifetimes.
