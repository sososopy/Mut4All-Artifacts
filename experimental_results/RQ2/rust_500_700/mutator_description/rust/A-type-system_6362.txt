Mutation Operator: Reorder Definitions

Description: This mutation operator targets the order of type definitions, specifically focusing on structs and enums. It applies when a struct contains a field of an enum type, and the enum has a variant that includes a struct type. The operator will reorder these definitions to place the struct definition before the enum definition, which may expose type system bugs related to the handling of forward declarations or type resolution.

Examples of Mutated Content:

Original Code:
```
enum Action {
    Check { code: bool },
}

struct Exe {
    action: Action,
}

fn main() {}
```

Mutated Code:
```
struct Exe {
    action: Action,
}

enum Action {
    Check { code: bool },
}

fn main() {}
```

Explanation: The mutation involves swapping the positions of the 'struct Exe' and 'enum Action' definitions. By placing the struct definition before the enum definition, the mutation tests the compiler's ability to handle cases where the order of type declarations does not follow the standard top-down approach. This can reveal inconsistencies or flaws in the type-checking mechanism of the compiler, especially in scenarios involving nested or complex types.
