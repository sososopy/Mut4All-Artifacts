Mutation Operator: Invalid Template Deduction Guide

Target Code Construct: Template Deduction Guide within a namespace

Mutation Rule: 
1. Identify a namespace declaration in the code.
2. Inside the namespace, locate a template struct or class definition.
3. Outside the namespace, create a template deduction guide that incorrectly references the template struct or class without qualifying it with the namespace.
4. Ensure the deduction guide attempts to deduce from an invalid or non-existent template within its scope.

Example:
Original Code:
```
namespace example {
    template <class T> struct Container;
}

void function() {
    example::Container<int> c;
}
```

Mutated Code:
```
namespace example {
    template <class T> struct Container;
}

template <class T> Container() -> Container<T>;

void function() {
    example::Container<int> c;
}
```

Explanation:
- The mutation targets a deduction guide defined outside the namespace where the template struct `Container` is declared.
- The deduction guide is incorrectly referencing `Container` without the namespace qualification, leading to an invalid context for template deduction, which can cause the compiler to crash or behave unexpectedly.
