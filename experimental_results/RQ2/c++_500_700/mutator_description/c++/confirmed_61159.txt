Mutation Operator:

Target: Template Function Return Type

Description: This mutation operator targets template functions that return a type involving template parameters, such as `std::array<int, ct>`. It aims to modify the return statement to potentially trigger compiler bugs related to template instantiation and integral template argument handling.

Mutation Rule:
1. Identify a template function that uses a return type involving template parameters. For example, `auto do_something() -> std::array<int, ct>`.
2. Modify the return statement to eliminate explicit initialization for the return type, relying on default initialization instead.
3. Specifically, change `return std::array<int, ct>{};` to `return {};`.

Example:
Original Code:
```cpp
template <int ct>
auto do_something() -> std::array<int, ct> {
    return std::array<int, ct>{}; // Original explicit initialization
}
```

Mutated Code:
```cpp
template <int ct>
auto do_something() -> std::array<int, ct> {
    return {}; // Mutated to use default initialization
}
```

Rationale: The mutation modifies the way the return value is constructed, potentially triggering issues in the compiler related to template argument evaluation and type deduction, especially when dealing with integral template arguments. This operator encourages exploration of edge cases in template instantiation, which have historically led to compiler crashes.
