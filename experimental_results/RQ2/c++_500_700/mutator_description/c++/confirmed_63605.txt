Mutation Operator: Reorder Bitfield Initializers

Target: Structs containing bitfields

Mutation Rule:
1. Identify a struct that contains bitfields.
2. In the initialization list of an instance of this struct, change the order of the bitfield initializers. For example, if the initializers are originally set as `.x = 1, .y = 2, .z = 3;`, reorder them to `.z = 3, .x = 1, .y = 2;`.
3. Ensure that the struct declaration remains unchanged. Only reorder the initializer list of the struct instance.

Example Before Mutation:
```
struct {
  unsigned : 2;
  unsigned a : 6;
  unsigned : 1;
  unsigned b : 6;
  unsigned : 2;
  unsigned c : 6;
  unsigned d : 1;
  unsigned e : 2;
} data = {
    .e = 1,
    .c = 1,
    .a = 1,
};
```

Example After Mutation:
```
struct {
  unsigned : 2;
  unsigned a : 6;
  unsigned : 1;
  unsigned b : 6;
  unsigned : 2;
  unsigned c : 6;
  unsigned d : 1;
  unsigned e : 2;
} data = {
    .c = 1,
    .e = 1,
    .a = 1,
};
```

This mutation operator targets the specific issue outlined in the bug report by changing the order in which bitfields are initialized, which is linked to the compiler crash.
