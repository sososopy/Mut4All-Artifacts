Mutation Operator:

Target: Template struct with consteval member functions

Mutation Rule:
1. Locate a template struct definition in the code.
2. Identify a member function within the struct that is marked with the `consteval` keyword.
3. Remove the `consteval` keyword from the function declaration.
4. Add a new, simple runtime logic to the function (for example, return a constant value or perform a basic arithmetic operation).
5. Ensure the function is called within a context that doesn't require constant evaluation.

Example:
Original Code:
```cpp
template <typename T>
struct MyTemplate {
    consteval int myFunction() {
        return 42;
    }
};
```

Mutated Code:
```cpp
template <typename T>
struct MyTemplate {
    int myFunction() {
        return 42 + 0; // Simple runtime operation added
    }
};

// Usage of the mutated function
int main() {
    MyTemplate<int> obj;
    int result = obj.myFunction();
    return result;
}
```

This mutation is designed to challenge the compiler's handling of consteval functions that are mistakenly used where runtime evaluation is expected, potentially triggering unexpected behaviors or crashes.
