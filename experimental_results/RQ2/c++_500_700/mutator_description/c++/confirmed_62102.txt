Mutation Operator: Incorrect Use of Defaulted Functions

Target Code Construct: Function definition, specifically functions that are defaulted.

Mutation Rule:
1. Identify a member function in a struct or class declaration that can be defaulted, such as a comparison operator (e.g., `operator==`) or a special member function (e.g., constructor, destructor, copy/move assignment operator).
2. Modify the function to use the `= default` specifier incorrectly, such as applying it to a function that cannot be defaulted due to mismatched types or invalid conditions.
3. Ensure the invalid defaulting involves existing member variables or types within the struct or class to maintain realistic context.

Example:
Original Code:
```cpp
struct A {
  int value;
  bool operator==(const A&) const;
};
```

Mutated Code:
```cpp
struct A {
  int value;
  bool operator==(const A&) const = default;
};
```

Explanation:
In this mutation, the `operator==` is incorrectly defaulted using the `= default;` specifier. This is intended to trigger issues in the compiler as the defaulted function is expected to be automatically generated by the compiler only under valid conditions, which are not met here due to contextual mismatches or unsupported operations.
