Mutation Operator:
Target: Enum declarations within a templated struct

Mutation Rule:
1. Identify an enum declaration that is nested within a templated struct.
2. Modify the base type of the enum by replacing the templated type `T` with a concrete type.
3. Ensure that the changed enum base type is compatible with the rest of the code, adjusting any necessary arithmetic or function calls.
4. Retain the structure of the enum declaration and its usage, but alter the base type to induce potential type mismatch issues.

Example:
Original Code:
```cpp
template <typename T>
struct B {
    enum E : T { e1, e2 };
    E getValue() { return e1; }
};

B<int> b;
auto val = b.getValue() + 1;
```

Mutation:
1. Change the base type of the enum from a templated type to a fixed type, e.g., `int`.
2. Ensure the rest of the code reflects this change in enum base type.

Mutated Code:
```cpp
template <typename T>
struct B {
    enum E : int { e1, e2 }; // Changed from T to int
    E getValue() { return e1; }
}

B<int> b;
auto val = b.getValue() + 1; // Ensure arithmetic is still valid
```

This mutation operator targets the enum declarations within templated structs, altering the base type to instigate potential compiler type handling or arithmetic conversion issues, which can often lead to crashes or unexpected behavior during compilation.
