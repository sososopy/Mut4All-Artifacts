Mutation Operator: Lambda Expression in Templates

Target Construct: Function Template with Lambda Expressions

Mutation Rule:
1. Identify a function template that uses lambda expressions as part of its operations or instantiation.
2. Within the lambda expression, change the captured variables or parameters to introduce a decltype usage around the lambda, and attempt to perform operations that involve member access (such as pointer-to-member operations).
3. Ensure this mutation is applied in a context where the lambda is passed as a template argument or used in a template-dependent expression.

Example Mutation:
Original Code:
```cpp
template <typename Fn>
static bool check_lambda() {
    return requires { Fn().operator()(); };
}

int main() {
    check_lambda<decltype([](auto x) { return x; })>();
}
```

Mutated Code:
```cpp
template <typename Fn>
static bool check_lambda() {
    return requires { decltype(Fn().*(&Fn::operator()))(); };
}

int main() {
    check_lambda<decltype([](auto x) { return x; })>();
}
```

Description:
- The mutation targets lambda expressions used within a template. Specifically, it adds an additional decltype around the lambda member access operation with member pointer usage (e.g., decltype used with &Fn::operator()).
- The mutated code attempts to access the lambda's call operator in a way that involves a pointer-to-member operation, which is more likely to expose issues in the compiler's handling of lambda types in templates.
