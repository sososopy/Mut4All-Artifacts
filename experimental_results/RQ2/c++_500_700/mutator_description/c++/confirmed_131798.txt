Mutation Operator: Modify Template Function with Type Constraints

Target Construct: Template Functions with Type Constraints

Mutation Rule:
1. Identify a template function with type constraints in the seed program.
2. Modify the template function to introduce a non-type template parameter (NTTP) pack in the type constraints of the function parameters.
3. Add a lambda function that attempts to use this non-type template parameter pack within its parameter list.
4. Ensure the lambda function is instantiated and called within the main function or another function scope.

Step-by-Step Instructions:
- Locate a template function definition in your seed program with an existing type constraint.
- Introduce a non-type template parameter pack (e.g., `int... Args`) in the template parameter list of the function.
- Modify the function parameter to include a type constraint that utilizes this non-type template parameter pack. For example, change a parameter `auto` to `C<Foo<Args>> auto`.
- Within the function body, include a lambda function that takes a parameter using the modified type constraint. For instance, `[] (C<Foo<Args>> auto) { /* lambda body */ };`.
- Ensure that the lambda function is correctly instantiated using the non-type template parameter pack values and is called inside the program (e.g., in the main function).

Example in Pseudo-Code:
```cpp
template <typename T>
concept MyConcept = true;

template <int... Args>
void myFunction() {
    auto lambdaFunc = [] (MyConcept<Foo<Args>> auto param) {
        // Lambda body using 'param'
    };
    lambdaFunc(); // Call the lambda function
}

int main() {
    myFunction<0>(); // Instantiate and call the function with specific Args
}
```

Note: This mutation operator exploits the complex interaction between NTTP packs and type constraints, which can lead to unexpected compiler behavior, especially during template argument deduction and constraint satisfaction.
