Mutation Operator: Mutate Auto Initialization in Structs

Target: Struct member variables with auto initialization.

Mutation Rule:
1. Identify a struct with member variables initialized using the `auto` keyword.
2. Check if there is at least one non-default initialized member variable of a concrete type (e.g., `int`, `double`).
3. Change the `auto` initialized variable to use a lambda function for initialization.

Example:

Original Code:
```
struct Example {
  int a{0};
  auto b = 42;
};
```

Mutated Code:
```
struct Example {
  int a{0};
  auto b = []() { return 42; }();
};
```

Explanation:
- This mutation targets the initialization of auto-typed struct member variables, which can trigger compiler inconsistencies when the auto type deduction interacts with default member initializers.
- By replacing direct initialization with a lambda function, we introduce complexity in type deduction and initialization order, potentially exposing compiler bugs.
