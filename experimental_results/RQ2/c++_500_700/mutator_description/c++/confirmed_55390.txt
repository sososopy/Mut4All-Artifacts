Mutation Operator: Function Division by Zero

Target Code Construct: Function with division operations

Mutation Rule:
1. Identify functions in the code that perform division operations.
2. Select a divisor in any division operation.
3. Modify the divisor to a constant zero value to simulate a division by zero scenario.
4. Ensure the divisor is a literal zero or a variable that is explicitly assigned zero before the division operation.
5. The mutation should not introduce new variables or types; use existing variables or literals in the code.

Example:
Original Code:
```
auto g() { 
    int a = 10;
    int b = 5;
    return a / b;
}
```

Mutated Code:
```
auto g() { 
    int a = 10;
    int b = 0; // Modifying divisor to zero
    return a / b; // Division by zero
}
```

This mutation specifically targets division operations within functions and alters the divisor to zero, which is a common cause of crashes and assertion failures in compilers due to divide-by-zero errors.
