Mutation Operator: Modify Union Initialization with Multiple Designators

Target: Union initialization within a function or global scope.

Mutation Rule:
1. Identify union declarations in the source code. A union is defined with the `union` keyword, containing multiple member elements.
2. Locate the initialization of the union using a designated initializer list within a function or at global scope.
3. Modify the initialization list by adding multiple designators. In the context of unions, this means attempting to initialize more than one member at a time, which is against the standard behavior for union initialization.

Example:
Original code snippet:
```cpp
union ExampleUnion {
    int a;
    double b;
};

void test() {
    new ExampleUnion{.a = 5}; // Correct initialization
}
```

Mutated code snippet:
```cpp
union ExampleUnion {
    int a;
    double b;
};

void test() {
    new ExampleUnion{.a = 5, .b = 3.14}; // Incorrect initialization with multiple designators
}
```

Explanation:
This mutation operator targets the initialization of union types by altering the designated initializer list to include multiple designators, which the C++ standard does not usually allow for unions. This is designed to trigger potential bugs related to union initialization in the C++ compiler, particularly those that do not correctly handle or report this invalid usage.
