Mutation Operator

Target: Alias Template with Default Arguments

Mutation Rule:
1. Locate an alias template defined with default template parameters.
2. Modify the alias template by removing the default parameter(s) and explicitly specifying them in a template alias instantiation.
3. If the alias template is used with Class Template Argument Deduction (CTAD), ensure explicit template arguments are provided in instantiations.
4. If the original alias template is `using AA = A<U>`, change the instantiation to `AA<int, int> a;`.

Example:
Original Code:
```
template <class>
struct A {};

template <class T = int, class U = T>
using AA = A<U>;

AA a{};
```

Mutated Code:
```
template <class>
struct A {};

template <class T = int, class U = T>
using AA = A<U>;

// Explicitly specify template arguments instead of using default arguments
AA<int, int> a;
```

This mutation operator aims to manipulate alias templates involving default arguments by explicitly specifying the parameters during instantiation, potentially triggering edge cases in compiler template deduction logic.
