Mutation Operator: Modify Template Specialization Constraint

Target: Function Template Specialization with Constraints

Mutation Rule:
1. Identify a function template specialization that uses constraints (e.g., `requires` clauses) within a templated struct or class.
2. Introduce a new specialization for the existing function template by adding a new `requires` clause that contradicts or conflicts with existing constraints.
3. Ensure that the new `requires` clause is syntactically correct but logically inconsistent with the existing constraints.

Example:
Given a struct template `A` with a function template `g` specialized with a constraint:

```
template<typename>
concept B = true;

template<typename T>
struct A {
    template<typename U> requires B<U>
    void g() {
    }
};
```

Mutate to introduce a conflicting specialization:

```
template<typename T>
struct A {
    template<typename U> requires B<U>
    void g() {
    }

    // New specialization with conflicting constraint
    template<typename U> requires (!B<U>)
    void g() {
    }
};
```

In this example, the mutation introduces a specialization of the `g` function within the `A` struct, where the condition `requires (!B<U>)` directly contradicts the existing `requires B<U>` constraint. This change can potentially trigger bugs related to constraint resolution and overload resolution in a compiler.
