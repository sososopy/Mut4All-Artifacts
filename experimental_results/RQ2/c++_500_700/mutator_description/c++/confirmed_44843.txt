Mutation Operator:
Target: Template Function Specialization

Mutation Rule:
1. Identify a template function in the seed program. Look for functions that are templated using the `template<typename T>` syntax.
2. Introduce a secondary specialization for the template function.
3. Modify the existing specialization to ensure it is nearly identical to the newly introduced one, but with slight differences to mimic overloaded specializations. This will challenge the compiler's ability to resolve the correct specialization and potentially trigger bugs.
4. Ensure that the new specialization introduces a subtle difference, such as modifying the template parameter's constraints, or using a different type substitution for a specific condition.

Example Pseudo-code:
Original Code:
```cpp
template<typename T>
void process(T value) {
    // Original processing logic
}
```

Mutated Code:
```cpp
template<typename T>
void process(T value) {
    // Original processing logic
}

template<>
void process<int>(int value) {
    // Special processing for int type
}

// Introduce another specialization with a subtle difference
template<>
void process<const int>(const int value) {
    // Slightly different logic for const int type
}
```

Explanation: This mutation operator specifically targets template function specializations by introducing subtle differences between specializations. These differences can potentially cause the compiler to struggle when resolving which specialization to use, thus increasing the likelihood of encountering assertion failures or similar issues related to specialization handling.
