Mutation Operator

Target Construct: Template Function with Lambda Expressions

Mutation Rule:
1. Locate a template function in the source code that accepts a variadic number of template parameters.
2. Inside this function, identify if a lambda expression is defined with a template parameter pack.
3. Modify the lambda expression to incorrectly reference an undeclared template parameter within its body.

Step-by-step Instructions:
- Identify a template function similar to the following structure:
  ```
  template <typename... Args>
  void myFunction() {
    auto lambda = []<typename T>(T arg) {
      // Placeholder for modification
    };
  }
  ```
- Within the lambda expression, introduce a reference to a template parameter not declared in the lambda's signature:
  ```
  auto lambda = []<typename T>(T arg) {
    U someVariable; // 'U' is not declared in the lambda's template parameters
  };
  ```
- Ensure that 'U' is a valid type within the context of the code, but is not intended to be used in the lambda's template parameter list.

Example:
Original Code:
```
template <typename... Args>
void exampleFunction() {
  auto lambda = []<typename T>(T arg) {
    // Original implementation
  };
}
```

Mutated Code:
```
template <typename... Args>
void exampleFunction() {
  auto lambda = []<typename T>(T arg) {
    Args someVariable; // Incorrectly uses 'Args' which is not declared in the lambda
  };
}
```

This operator targets errors during the instantiation of template types with incorrect references in lambda expressions, increasing the likelihood of triggering compiler errors related to template parameter instantiation.
