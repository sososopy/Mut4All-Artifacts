Mutation Operator: Modify Template Constraints

Target: Function templates with constraints (requires clauses).

Mutation Rule:
1. Identify a function template that uses a constraint with a `requires` clause.
2. Alter the `requires` clause to reference a type or condition that causes a dependent expression.

Step-by-Step Instructions:
- Locate a function template declaration that uses a `requires` clause to specify constraints.
- Change the condition inside the `requires` clause to make it dependent on a template parameter in a way that is unlikely to resolve to true. This can involve using a condition that introduces value or type dependency.
- A simple way to achieve this is by using a condition that is inherently dependent on a non-deduced context or a type trait that evaluates differently based on template parameters.

Example:
Original Code:
```cpp
template <typename T>
void myFunc(T value) requires(std::is_integral_v<T>) {
    // Function implementation
}
```

Mutated Code:
```cpp
template <typename T>
void myFunc(T value) requires(IsSame<T, Empty> && std::is_integral_v<T>) {
    // Function implementation
}
```

Explanation:
- In the original code, the `myFunc` function template has a `requires` clause that checks if `T` is an integral type.
- In the mutated code, the `requires` clause is modified to include a condition `IsSame<T, Empty>`, which is deliberately false for most types except when `T` is `Empty`.
- This transformation introduces a dependency on a template parameter in a way that can trigger issues if the compiler mishandles such constraints.
