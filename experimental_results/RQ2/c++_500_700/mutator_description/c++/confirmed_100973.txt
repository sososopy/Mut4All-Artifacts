Mutation Operator: Inline Namespace Class Declaration Mutation

Target Construct:
This mutation operator targets class declarations within inline namespaces.

Mutation Rule:
1. Identify an inline namespace used within a regular namespace. For example, consider:
   ```
   namespace Outer {
   inline namespace Inner {
   class MyClass;
   }
   }  // namespace Outer
   ```
2. Modify the class declaration inside the inline namespace as follows:
   - Change the incomplete class declaration to a complete definition. For instance, modify:
     ```
     class MyClass;
     ```
     to
     ```
     class MyClass {
       public:
         void sampleFunction();
     };
     ```
3. If `sampleFunction` is introduced, ensure its declaration is accompanied by a definition elsewhere in the seed program. Example:
   ```
   void Outer::Inner::MyClass::sampleFunction() {
     // Function implementation
   }
   ```

Rationale:
The mutation operator focuses on class declarations within inline namespaces, a structure previously observed to cause issues due to incomplete definitions potentially interacting with name resolution in the presence of `hasName` matchers. This mutation provides higher coverage by transforming incomplete to complete class definitions, introducing function declarations that require resolution, and maintaining the integrity of inline namespaces.
