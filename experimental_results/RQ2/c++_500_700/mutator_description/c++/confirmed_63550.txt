Mutation Operator: Modify Atomic Variable Operands in Shift Operations

Target Code Construct: Function Definitions and Arithmetic Operations, specifically shift operations involving atomic types.

Mutation Rule:
1. Identify functions in the program that perform arithmetic shift operations, such as the left shift (<<) or right shift (>>), involving atomic variables.
2. Locate the atomic variable being used in the shift operation. Ensure the variable is of an atomic type, such as `_Atomic(int)`, `_Atomic(unsigned int)`, etc.
3. Modify the shift operation to use a regular integer variable instead of an atomic type.
4. If no suitable integer variable exists, define a new integer variable with the same bit-width as the atomic type and use it in the shift operation.

Example:
Before Mutation:
```

void exampleFunction(int x) {
    a << x;  // Shift operation with atomic type
}
```

After Mutation:
```

void exampleFunction(int x) {
    regularVar << x;  // Shift operation with regular integer type

```

Note: Ensure that the mutation maintains syntactic correctness and that variable types are compatible with the operations being performed. This mutation specifically targets inconsistencies in handling atomic types during arithmetic operations that could lead to compiler assertions or crashes.
