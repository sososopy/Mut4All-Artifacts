Mutation Operator: Modify Usage of Lambdas in Immediate Function Calls

Target: Function calls involving lambdas, especially when passed to immediate functions.

Mutation Rule:
1. Identify a function call within the seed program where a lambda is being passed as an argument.
2. If the lambda is being passed to an immediate function (like a consteval function), change the lambda's syntax.
3. Modify the lambda by adding or removing capture list elements or changing its return type.
4. Ensure the lambda maintains syntactical correctness after modification.

Example:
Original Code:
```
auto func = []() -> int { return 42; };
callImmediateFunction(func);
```

Mutated Code:
```
auto func = [x = 0]() mutable -> int { return x + 42; };
callImmediateFunction(func);
```

By modifying the lambda, introducing capture lists, making it mutable or changing function return types, we can identify if such mutations reveal vulnerabilities or bugs in handling lambdas in immediate function contexts within the compiler.
