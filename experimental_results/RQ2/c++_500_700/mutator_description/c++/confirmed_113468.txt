Mutation Operator:
Target: If statements with comma operator usage
Mutation Rule: 
1. Identify an if statement that uses a comma operator or contains a block statement in its condition.
2. Replace the comma operator or block with a binary operator expression that utilizes both arithmetic and logical operators.
3. Ensure that the operands of this new binary expression are of integral or enumeration types.

Example:
Original:
```
if (({ int a; a = 0; if (a) break; }))  
  return 2;
```

Mutation:
```
int x = 0; // Reuse existing integer variable if available, otherwise introduce
if ((x + 1) && (x == 0))
  return 2;
```

Explanation:
The mutation operator targets if statements with complex conditions using comma operators or block expressions, which can lead to intricate evaluation logic. This adjustment intends to stress-test the compiler's ability to handle logical and arithmetic operations on integral types, potentially exposing inconsistencies or unsupported edge cases in the evaluation process.
