Mutation Operator: Misuse of `constexpr` with Non-Compile-Time Expressions

Applicable Code Construct: `constexpr` in functions

Mutation Rule:
1. Identify a function in the seed program where a `constexpr` is used.
2. Locate an expression in the function that is evaluated as `constexpr` but involves a pointer dereference or a reference to a structure or class member variable.
3. Replace the `constexpr` expression with a similar expression involving a pointer dereference or a class/struct member access that depends on a runtime value.

Example of Mutation:
Original Code:
```cpp
void exampleFunction() {
    constexpr int value = 10 + 20;
}
```

Mutated Code:
```cpp
struct MyStruct {
    int member;
};

void exampleFunction(struct MyStruct *ptr) {
    constexpr int value = ptr->member + 20; // Introduces misuse of constexpr
}
```

In this mutation, the expression within the `constexpr` involves a non-compile-time expression (`ptr->member`), which is not valid for `constexpr` and can lead to compiler errors or crashes, similar to the provided bug scenario.
