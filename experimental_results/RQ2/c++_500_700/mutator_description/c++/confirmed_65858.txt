Mutation Operator: Coroutine with Variable-Length Array (VLA)

Target Construct: Coroutine Function
Applicability: This mutation applies to coroutine functions that contain variable-length arrays (VLAs). The mutation is designed to trigger potential issues in the compiler's handling of VLAs within coroutine frames.

Mutation Rule:
1. Identify a coroutine function that includes a VLA declaration. This typically looks like:
   ```
   co_yield <expression>;
   int arr[size];
   ```
2. Change the VLA declaration to use a more dynamic size-related expression. Modify the size of the VLA by using an arithmetic operation or function call involving the coroutine's parameter or a local variable.
3. Ensure the size expression remains valid and does not produce a constant result to maintain the VLA property.

Example Before Mutation:
```
dd::generator<int> g(int i) {
    co_yield 1;
    int arr[i];
    use(arr);
}
```

Example After Mutation:
```
dd::generator<int> g(int i) {
    co_yield 1;
    int arr[i * 2 + 1];
    use(arr);
}
```

Details:
- This mutation operator is tailored to explore how the compiler handles VLAs in coroutine frames, particularly when the size is determined by more complex expressions.
- The focus is to introduce a realistic scenario where the VLA size depends on dynamic and non-trivial expressions, potentially exposing issues in coroutine state management.
