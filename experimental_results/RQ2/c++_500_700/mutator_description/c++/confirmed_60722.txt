Mutation Operator: Macro Function Argument Parenthesization

Target: Macro function invocation containing initializer lists.

Mutation Rule:
1. Identify the macro invocation in the code. This is a preprocessor directive used as a function with arguments (e.g., `EXPECT_EQ` in the provided example).
2. Locate any macro arguments that include an initializer list without parentheses. An initializer list is a set of values enclosed in curly braces `{}` (e.g., `SS{1, 2}`).
3. Wrap the entire argument containing the initializer list in parentheses to ensure proper parsing by the preprocessor.

Example Before Mutation:
```
#define MACRO_FUNC(val1, val2) \
    USE_MACRO(val1, val2)

struct MyStruct {
    MyStruct(std::initializer_list<int>);
};

void example() {
    MyStruct m1 = {1, 2};
    MACRO_FUNC(m1, MyStruct{3, 4});
}
```

Example After Mutation:
```
#define MACRO_FUNC(val1, val2) \
    USE_MACRO(val1, val2)

struct MyStruct {
    MyStruct(std::initializer_list<int>);
};

void example() {
    MyStruct m1 = {1, 2};
    MACRO_FUNC(m1, (MyStruct{3, 4}));
}
```

This mutation operator applies universally in codebases that use macros with arguments that could contain initializer lists, helping to catch and potentially trigger bugs related to unparenthesized macro arguments.
