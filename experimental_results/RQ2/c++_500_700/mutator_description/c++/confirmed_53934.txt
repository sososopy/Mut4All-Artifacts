Mutation Operator: Templated Lambda with Unused Template Parameter

Target: Lambda expressions within template functions or methods.

Mutation Rule:
1. Identify a lambda expression that is part of a template function or method. Ensure that this lambda uses a templated parameter list (e.g., `<int>()`).
2. Introduce an additional, unused template parameter to the lambda expression's template parameter list. For example, change from `<int>()` to `<int, typename Unused>()`.
3. Ensure that the newly introduced template parameter does not affect the existing logic or body of the lambda. It should not be used within the lambda's body.
4. If any part of the code references the lambda's template parameters, ensure they continue to use the previously existing parameters only, not the newly introduced one.

Example Pseudo-code:

Original Lambda:
```cpp
auto h = [&]<int>() { n = 0; };
```

Mutated Lambda:
```cpp
auto h = [&]<int, typename Unused>() { n = 0; };
```

Explanation:
In this mutation, we add an unused template parameter to the lambda expression. The objective is to introduce complexity in template instantiation that might not be anticipated by the compiler's template handling mechanisms, potentially triggering a compiler bug.
