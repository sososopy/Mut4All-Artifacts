Mutation Operator: Modify Template Instantiation

Target Code Construct: Template Function Instantiation

Mutation Rule:
1. Identify a template function instantiation within the seed program.
2. In the template argument list of the function call, replace a type argument with a class or struct that contains member specializations or additional nested types that are unique to the new type.
3. Ensure that the new type is compatible with the function's requirements and has the necessary members or methods used within the function.
4. Ensure that this new type is declared before the function call.

Example:
Original Code:
```
template <typename T>
void process(T obj) {
    obj.method();
}

struct A {
    void method() {}
};

int main() {
    A a;
    process(a);
}
```

Mutated Code:
```
template <typename T>
void process(T obj) {
    obj.method();
}

struct A {
    void method() {}
};

struct B {
    void method() {}
    int additionalData;
};

int main() {
    B b;
    process(b); // Change the instantiation from 'A' to 'B'
}
```

The mutation operator targets template function instantiations by replacing existing type arguments with alternative types that have different or additional characteristics. This specific change can reveal issues in template handling and instantiation processes within the compiler, potentially triggering bugs related to type compatibility and specialization.
