Mutation Operator

Target Code Construct: Function Declarations and Calls

Mutation Rule:
1. Identify a function declaration in the seed program. For example, if you have a function defined as `int calculateSize(int x)`.
2. Modify the function declaration to include nested sizeof operations. For instance, change `int calculateSize(int x)` to:
   `int calculateSize(int x) { return sizeof(sizeof(sizeof(x))); }`
3. Apply the same modification to function calls within the code, if required, such as `int size = calculateSize(value);`.

Example:
Original Code:
```
int calculateSize(int x) {
    return x * 2;
}

int main() {
    int value = 10;
    int size = calculateSize(value);
    return 0;
}
```

Mutated Code:
```
int calculateSize(int x) {
    return sizeof(sizeof(sizeof(x)));
}

int main() {
    int value = 10;
    int size = calculateSize(value);
    return 0;
}
```

This mutation introduces nested sizeof operators, which can potentially explore edge cases in compiler parsing and semantic analysis related to size operations.
