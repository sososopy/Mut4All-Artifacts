Mutation Operator: Modify Cast Alignment in Function Body

Target Code Construct: This mutation operator targets function bodies, specifically modifying the alignment of casts within expressions.

Mutation Rule:
1. Identify an existing function in the seed program with a function body containing a C-style cast or static_cast expression.
2. Modify the alignment of the type being cast by introducing an `alignas` specifier to the type being cast. Ensure the `alignas` value is unaligned or non-standard, which may lead to alignment-related warnings or errors.
3. Ensure that the modification employs existing types and variables from the seed program, only altering the alignment aspect of the cast.

Example:
Original Code:
```cpp
void process_data(double* ptr) {
    float* fptr = (float*)ptr;
    // Function logic
}
```

Mutated Code:
```cpp
void process_data(double* ptr) {
    alignas(64) float* fptr = (alignas(8) float*)ptr;
    // Function logic
}
``` 

Explanation: This mutation introduces an `alignas` specifier with an alignment value that is misaligned for a float type, aiming to trigger any potential issues in the compiler's handling of cast alignment, especially when specific compiler flags related to warnings on cast alignment are used.
