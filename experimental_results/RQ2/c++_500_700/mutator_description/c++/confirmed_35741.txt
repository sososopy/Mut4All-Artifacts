Mutation Operator:
Target: Function Definition

Step-by-step Mutation Rule:
1. Identify a function declaration or definition within the seed program.
2. Locate the parameter list of the function.
3. Select an existing parameter from the list to duplicate.
4. Duplicate the selected parameter within the parameter list, ensuring the parameter type and name are identical to the original.
5. Insert the duplicated parameter immediately following the original parameter in the list.

Example Pseudo-code Before Mutation:
```
int myFunction(int a, float b, double c) {
    // Function body
}
```

Example Pseudo-code After Mutation:
```
int myFunction(int a, float b, double c, int a) {
    // Function body
}
```

Explanation: By duplicating a parameter within a function's parameter list, this mutation can potentially trigger the bug related to the assertion "function has too many parameters" by increasing the number of parameters without altering their types or values.
