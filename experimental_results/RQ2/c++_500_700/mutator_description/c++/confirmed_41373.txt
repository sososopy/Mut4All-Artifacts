
Mutation Operator: Modify Union Usage in Structs

Target Code Construct:
This mutation operator targets structs containing unions, specifically focusing on the usage of unions within the struct.

Mutation Rule:
1. Identify a struct that contains a union with multiple members.
2. Add a new member to the union with a different type than existing members.
3. Ensure that the new union member is properly initialized and accessed within the struct's methods or functions.

Step-by-Step Instructions:
1. Locate a struct that includes a union with existing members.
2. Introduce a new member to the union. For example, if the union currently includes a struct or a fundamental data type, add a new member of type `int`, `float`, or a simple struct.
3. Adjust the main method or any function within the struct to initialize and manipulate the new union member.
4. Ensure that the usage of the new member is consistent with the surrounding code logic and does not introduce syntax errors.

Example Pseudo-Code Mutation:
Original Struct:
```
struct ExampleContext
{
    union
    {
        int a;
        float b;
    };
    
    int doSomething()
    {
        a = 10;
        return a;
    }
};
```

Mutated Struct:
```
struct ExampleContext
{
    union
    {
        int a;
        float b;
        double c;  // New member added to the union
    };
    
    int doSomething()
    {
        c = 20.0;  // Initialize the new member
        return static_cast<int>(c);  // Adjust logic to use the new member
    }
};
```

This mutation operator aims to increase the likelihood of triggering compiler bugs by manipulating union members within structs, which can introduce complexities in type handling and initialization logic.
