Mutation Operator: Modify Array Access in Constant Expressions

Target: Arrays and constexpr variables

Mutation Rule:
1. Identify a `constexpr` array variable with multiple elements.
2. Locate any `constexpr` variable that uses this array in its initialization through an index. 
3. Change the index used to access the array in the `constexpr` variable's initialization to a value that is out of bounds for the array.

Example:
Original Code:
```cpp
constexpr char arr[] = { 'x', 'y', 'z' };
constexpr char ch = arr[1];
```
Mutation:
Step-by-step mutation process:
- Step 1: Identify the array `arr` which is of type `constexpr char[]` and has 3 elements.
- Step 2: Identify the `constexpr` variable `ch` initialized with an element from `arr`.
- Step 3: Modify the index accessing `arr` in the initialization of `ch` to be out of bounds, e.g., change `arr[1]` to `arr[3]`.

Mutated Code:
```cpp
constexpr char arr[] = { 'x', 'y', 'z' };
constexpr char ch = arr[3]; // Index 3 is out of bounds
```

This mutation exploits potential weaknesses in handling out-of-bounds array accesses in constant expressions, which might lead to unexpected compiler crashes or bugs. This operator is applicable to any program using `constexpr` arrays and can be adapted to various types of arrays and indices.
