Mutation Operator: Introduce Lambda with Unexpanded Parameter Pack

Target Code Construct:
This mutation operator targets templated structures or functions that utilize parameter packs within their body.

Mutation Rule with Step-by-Step Instructions:
1. Identify a templated structure or function in the seed program that utilizes a parameter pack (e.g., `template<typename... Ts>`).
2. Within the body of the templated structure or function, introduce a lambda expression.
3. Inside this lambda, attempt to use the parameter pack in a way that it isn't expanded. This can involve placing the parameter pack in an expression or statement where expansion isn't logically deduced.
4. Ensure the lambda has a non-standard return type that would typically require compilation logic to evaluate (e.g., `consteval`).

Example Pseudo-code:
```cpp
template<typename... Ts>
struct ExampleStruct {
  void function() {
    // Original code logic
  }
};

// Mutated code with introduced lambda expression
template<typename... Ts>
struct ExampleStruct {
  void function() {
    auto lambda = [] consteval -> void {
      (^Ts); // Using the parameter pack in a lambda expression without expansion
    };
    lambda(); // Invoke the lambda
  }
};
```

By introducing this lambda expression with an unexpanded parameter pack, we aim to trigger potential issues related to parameter pack handling within lambdas. This mutation has a high chance to expose bugs related to template instantiation and lambda parsing in the compiler, potentially leading to assertion failures or crashes as indicated in the bug report.
