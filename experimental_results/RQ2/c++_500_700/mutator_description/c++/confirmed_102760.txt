Mutation Operator: Modify Template Function Parameter

Target Construct: Generic lambda template function

Mutation Rule:
1. Locate the template lambda function in the seed program with the signature similar to `auto lambda = []<class _Tag, class... _Captures>(_Tag, _Captures...) { ... };`.
2. Modify the parameter list of the lambda function to change the pattern of the captured parameters.
3. Specifically, add a redundant parameter that is not used within the lambda body. For example, add an extra generic type `class _U` and corresponding parameter `_U u`.
4. Ensure that this new parameter is declared in the lambda but not utilized, which tends to trigger unexpected compiler behavior due to parameter mismatch during instantiation.

Example:
Original:
```cpp
auto lambda = []<class _T, class... _Args>(_T, _Args...) {
    // Lambda body
};
```

Mutated:
```cpp
auto lambda = []<class _T, class... _Args, class _U>(_T, _Args..., _U u) {
    // Lambda body (Note: `_U u` is unused)
};
```

This mutation operator targets compiler bugs related to template parameter handling, potentially causing assertion failures when the number of parameters during instantiation does not match the expected count.
