Mutation Operator: Modify Pointer Type in Template Function

Target: Template Function with Pointer Type Parameters

Mutation Rule:
1. Identify a template function that takes a pointer type as a parameter.
2. Modify the pointer type to introduce a volatile qualifier in the template parameter list.
3. Ensure the modified pointer type is used throughout the template function consistently.

Example:
Original Code:
```cpp
template <typename T>
void processElement(T* element) {
    // Some operations on element
}
```

Mutated Code:
```cpp
template <typename T>
void processElement(volatile T* element) {
    // Some operations on element
}
```

Note: The mutation targets template functions that use pointer types. By introducing a volatile qualifier, you can potentially expose compiler weaknesses related to volatile type handling within templates, which can trigger bugs in compiler implementations.
