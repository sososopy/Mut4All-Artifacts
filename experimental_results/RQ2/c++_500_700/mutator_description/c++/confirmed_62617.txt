Mutation Operator

Target: Lambda Expressions within Template Parameters

Mutation Rule: Given a lambda expression used as a non-type template parameter, modify the capture list of the lambda to include variables that are not explicitly part of the template parameter list, particularly capturing variables that have not been declared before.

Step-by-Step Instructions:
1. Identify a lambda expression used as a non-type template parameter. In the provided code snippet, this is `auto ImplGen = [](auto&&... ts){};`.
2. Modify the lambda expression to include a capture list. For example, change `[](auto&&... ts){}` to `[&](auto&&... ts){}`.
3. Ensure that the variables being captured (e.g., `&`) are either undeclared or misused within the lambda.

Example:
Original: `template <class T, auto ImplGen = [](auto&&... ts){}> struct Tmp {};`
Mutated: `template <class T, auto ImplGen = [&](auto&&... ts){ /* Use undeclared variables here */ }> struct Tmp {};`

Rationale: This mutation operator targets the lambda expression capturing mechanism within template parameters, which could expose issues related to template instantiation and argument substitution. By modifying the capture list, the mutation aims to reveal potential weaknesses in handling captures within non-type templates, which may lead to compiler crashes or unexpected behavior.
