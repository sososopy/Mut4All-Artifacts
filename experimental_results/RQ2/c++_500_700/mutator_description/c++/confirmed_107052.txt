Mutation Operator: Modify Built-in Function Calls

Target: Built-in functions within function bodies, specifically those with multiple parameters that include a mix of constants and variable references.

Mutation Rule:
1. Identify a call to any built-in function within a function body that involves multiple parameters.
2. Select a parameter that is a variable or a constant.
3. Change this parameter to a complex arithmetic expression combining existing variables and constants from the program.
4. Ensure the new expression introduces mixed data types if applicable, such as combining integers and floating-point numbers.

Example:
Original Code:
```
int main() {
    double x = 1.0;
    __builtin_fpclassify(0, 1, 4, 3, 2, x);
}
```

Mutated Code:
```
int main() {
    double x = 1.0;
    int y = 2;
    __builtin_fpclassify(0, 1, 4, 3, 2, (x + y * 3 - 1.5));
}
```

Explanation:
This mutation operator modifies a built-in function call by replacing one of its parameters with a more complex expression that combines variables and constants. This can potentially expose issues in how the C++ compiler handles expression evaluation within built-ins, especially when it involves implicit type conversions or unexpected side-effects.
