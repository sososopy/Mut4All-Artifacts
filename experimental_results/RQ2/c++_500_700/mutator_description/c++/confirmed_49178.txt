Mutation Operator: Modify Default Template Argument

Target Code Construct: Template function definitions with default template arguments.

Mutation Rule:
1. Identify a template function that uses a default argument in any of its template parameters. The target area includes the template parameter declaration in the function signature.
2. Change the template parameter's default type to another built-in type that still allows the function to be compiled but can impact runtime behavior.
3. If the default type is `int`, change it to `double`, and ensure any dependent expressions or initializations are compatible with this new type while maintaining the program's syntactic correctness.
4. If the function body or any expressions within the function use the template parameter, ensure they correctly handle the new type or cast appropriately.
5. For example, in the following pseudo-code:

Original:
```cpp
template<typename T = int>
void exampleFunction(T value = 42) {
    // Function implementation
}
```

Mutated:
```cpp
template<typename T = double>
void exampleFunction(T value = 42.0) {
    // Adjust any arithmetic or logic to ensure compatibility with `double`
}
```

By changing the default type, this operator explores the impact of type mismatches and compatibility issues, potentially triggering new or existing compiler bugs related to type handling or conversions.
