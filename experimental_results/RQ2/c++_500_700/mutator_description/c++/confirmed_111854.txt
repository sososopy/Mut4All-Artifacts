Mutation Operator: Modify Conditional Operator with Ternary Expression

Target Construct: Conditional (Ternary) Operator within function bodies.

Mutation Rule:
1. Identify any usage of the conditional (ternary) operator in the function bodies of the seed program. This operator is typically in the format: `condition ? expr1 : expr2`.
2. Replace the `expr1` or `expr2` (or both) expressions with a 'throw' expression if it is not already a 'throw'. This can potentially lead to improper conditional evaluations causing the compiler to crash.
3. If introducing a 'throw', ensure it is valid for the context, replace either `expr1` or `expr2` with `throw value;` where `value` is an integer or a default value suitable for the `throw` expression. For example, `throw 1;` or `throw -1;`.

Example:
Original Code:
```cpp
int check() {
    return (condition ? value1 : value2) + 10;
}
```

Mutated Code:
```cpp
int check() {
    return (condition ? throw 1 : value2) + 10;
}
```

In this mutation, the ternary operator's first expression `value1` is replaced with `throw 1`. This operation can lead to improper evaluations and potential compiler crashes if the surrounding logic or types are not properly handled.
