Mutation Operator: Invalid Builtin Function Arguments in Function Definition

Target: Function Definitions using Builtin Functions

Mutation Rule:
1. Identify a function definition in the seed program that uses a builtin function, such as `__builtin_assume_aligned`.
2. Replace the first argument of the builtin function call with a different type that is incompatible with the expected argument type.
3. If the first argument is a pointer, replace it with an integer or vice versa.

Example:
Original Code:
```cpp
void exampleFunction(void* ptr) {
    unsigned char *alignedPtr = __builtin_assume_aligned(ptr, 16);
}
```

Mutation:
1. Locate the function `exampleFunction` which contains a call to `__builtin_assume_aligned`.
2. Identify that the first argument `ptr` is of type `void*`.
3. Replace `void* ptr` with an `int`.

Mutated Code:
```cpp
void exampleFunction(int value) {
    unsigned char *alignedPtr = __builtin_assume_aligned(value, 16);
}
```

Note: This mutation causes a type mismatch that potentially triggers a bug in the compiler when processing the incorrect argument type for the builtin function.
