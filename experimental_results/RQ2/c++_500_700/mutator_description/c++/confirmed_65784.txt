Mutation Operator: Modify Array Initialization with Casts

Target Code Construct: Struct definition and array initialization

Mutation Rule:
1. Identify struct definitions in the code, especially ones containing pointer members.
2. Locate array initializations where structs are initialized with casts, particularly from string literals or numeric literals to pointers.
3. Modify the cast type to a different valid pointer type. If the current cast is (int *), change it to (void *).
4. Ensure that the change maintains syntactic correctness by using existing variables or types in the program.

Example of Mutation:
Original Code:
```cpp
struct ty { int *ptr; };
const struct ty arr[] = {(int *)("")};
```

Mutated Code:
```cpp
struct ty { int *ptr; };
const struct ty arr[] = {(void *)("")};
```

This mutation leverages existing structures and replaces the cast type within the array initialization to a broader type, such as `void *`, which may lead to unexpected behavior or crashes in the compiler's handling of type conversions and initializations.
