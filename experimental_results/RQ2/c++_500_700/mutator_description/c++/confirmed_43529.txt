Mutation Operator: Modify Default Arguments in Lambda Expressions

Target Construction: Lambda expressions with default arguments.

Mutation Rule: 
1. Identify a lambda expression in the code that has a parameter with a default argument.
2. Replace the default argument with a statement expression that includes a control flow statement (e.g., return) and an additional expression. For example, replace `int x = 0` with `int x = ({ return 42; 0; })`.

Example:
Original Code:
```cpp
auto lambda = [](int x = 5) { return x + 1; };
int result = lambda();
```

Mutated Code:
```cpp
auto lambda = [](int x = ({ return 42; 0; })) { return x + 1; };
int result = lambda();
```

Note: This mutation operator leverages the specific bug condition identified in the report, where the compiler crash is triggered by statement expressions used as default arguments within lambda expressions. This mutation increases the likelihood of triggering similar bugs across various seed programs by modifying default arguments in this specific manner.
