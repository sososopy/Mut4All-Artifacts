Mutation Operator: Modify Template Partial Specialization

Target Code Construct: Template Partial Specialization

Mutation Rule:
1. Identify a variable template or struct with partial specialization using a template template parameter and variadic templates.
2. Modify the partial specialization by introducing a deliberate mismatch in the template parameters of the partial specialization.
3. Specifically, add an extra parameter or remove an existing parameter from the partial specialization to cause a mismatch.

Mutation Steps:
- Locate the partial specialization of a template, for instance, in a struct similar to `struct is_specified_instantiation_of`.
- Alter the partial specialization declaration to introduce a mismatch. For example:
  - Original: `template <template <param_types...> class container, param_types... params>`
  - Mutated: `template <template <param_types...> class container, param_types... params, typename Extra>`

Example:
Given the original partial specialization:
```cpp
template <template <typename...> class container, typename... params>
struct val<container<params...>, container> {
  static constexpr bool value = true;
};
```
Apply the mutation:
```cpp
template <template <typename...> class container, typename... params, typename Extra>
struct val<container<params...>, container> {
  static constexpr bool value = true;
};
```

Outcome:
The mutation intentionally introduces a mismatch in the specialization parameters, potentially causing the compiler to crash or exhibit unexpected behavior during template instantiation or specialization resolution. This mutation operator tests the compiler’s robustness in handling incorrect or mismatched template specializations.
