Mutation Operator: Template Argument Deduction with Array Specialization

Target Code Construct: Function Template with Non-Type Template Arguments

Mutation Rule:
1. Identify a function template that uses non-type template arguments, particularly those involving arrays or specializations. For instance, a template that deduces array sizes or types.
2. Modify the template argument deduction by:
   a. Introducing a new overload or specialization that uses a different type or size for deduction. This could be an integer, a smaller or larger array, etc.
   b. Use explicit casting within the template argument to challenge the deduction process. For example, change the array type within the argument.

Example:
Original Code:
template<long unsigned int N> str(const char (&)[N]) -> str<N>;

Mutation:
template<long unsigned int N> str(int, const char (&)[N]) -> str<N>;

Explanation:
- The mutation introduces a new parameter (int) to the constructor template, which changes the deduction path.
- This challenges the compiler's ability to correctly deduce the template arguments when called with different types of arguments or when the function is invoked with implicit conversions/casts.
- Such changes are more likely to expose issues in compilers that struggle with complex deduction scenarios, leading to potential crashes.
