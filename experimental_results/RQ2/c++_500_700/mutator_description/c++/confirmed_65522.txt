Mutation Operator: Incorrect Default Argument in Template

Target Code Construct: Template Class Constructor

Mutation Rule:
1. Locate a template class definition with a constructor that has a default argument.
2. Modify the default argument to use a template instantiation or expression that relies on the template parameter itself, potentially leading to a circular dependency.
3. Ensure the newly introduced default argument is syntactically valid but semantically ambiguous or incorrect.

Example:

Original Code:
```
template<typename T>
class Example {
public:
    Example(int value = 0);
};
```

Mutated Code:
```
template<typename T>
class Example {
public:
    Example(int value = sizeof(T) + Example<T>());
};
```

Explanation:
- The original constructor has a straightforward default argument of `0`.
- The mutation changes the default argument to an expression `sizeof(T) + Example<T>()` that involves a recursive instantiation of the template class itself.
- This mutation leverages the compiler's handling of template instantiations and default arguments, aiming to introduce a potential crash due to improper handling of the expression.
