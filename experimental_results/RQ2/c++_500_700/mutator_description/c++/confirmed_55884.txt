Mutation Operator:

Target: Template Specialization and Instantiation

Mutation Rule:
1. Identify a function template in the seed program.
2. Add an explicit specialization that uses a different set of template arguments compared to the existing declarations.
3. In this specialization, introduce a non-standard operation, such as a static assert or a constexpr function call that is expected to fail for certain inputs.

Example:
Original function template:
```cpp
template<typename T>
void process(T val) {
    // original processing logic
}
```

Mutation:
1. Add an explicit specialization:
```cpp
template<>
void process<int>(int val) {
    static_assert(sizeof(int) > 4, "Unexpected int size");
    // specialized logic for int
}
```

Explanation:
This mutation involves modifying the template specialization to include unusual constraints or operations that are prone to causing the compiler issues during instantiation or specialization. The focus is on introducing conditions that might be unexpected or edge cases for the compiler, thereby increasing the likelihood of triggering bugs related to template processing. This operator can be adapted to different contexts by adjusting the specialization type and the conditions or operations used.
