Mutation Operator: Default Argument Removal in Constructors

This mutation operator targets constructor definitions in C++ struct and class declarations. The goal is to test the compiler's handling of default arguments in constructors, which can often lead to edge cases that are not well-handled, resulting in bugs.

Mutation Rule:
1. Identify a constructor within a struct or class that has a default argument.
2. Remove the default argument from the constructor declaration.
3. Ensure that the constructor is still invoked without arguments to check the compiler's handling of the now invalid call.

Example Before Mutation:
```
struct Example {
    Example(int x = 5) {}
};

void test() {
    Example e;
}
```

Example After Mutation:
```
struct Example {
    Example(int x) {}
};

void test() {
    Example e; // This should now trigger a compiler error due to the missing argument
}
```

Clarifications:
- The operator specifically targets constructors with default arguments and removes those defaults to invalid the call sites.
- This example assumes the presence of a constructor with default arguments in the seed program and modifies it accordingly.
- The mutation should be performed without introducing new variables, types, or constructs beyond removing the default argument.
