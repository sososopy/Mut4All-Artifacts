Mutation Operator: Modify Friend Class and Overloaded Operator Context

Target Code Construct:
This mutation operator targets friend class declarations and overloaded operators in struct or class definitions.

Precise Mutation Rule:
1. Identify a struct or class that declares a friend operator function, especially if the operator is overloaded.
2. Remove the friend keyword from the operator function declaration within the struct or class.
3. Move the implementation (if any) of the operator function outside of the struct or class definition to form a separate function.
4. Ensure the external operator function has the same signature as declared but without the friend keyword, maintaining its logic if implemented.

Example Pseudo-Code:
Original Code:
```cpp
struct Example {
    friend bool operator==(const Example& a, const Example& b);
};

// Implementation (assuming outside the struct)
bool operator==(const Example& a, const Example& b) {
    // some comparison logic
}
```

Mutated Code:
```cpp
struct Example {
    // Removed the friend keyword from the operator declaration
};

// Implementation outside the struct (unchanged)
bool operator==(const Example& a, const Example& b) {
    // some comparison logic
}
```

This mutation aims to test the compiler's handling of friend functions and overloaded operators when their context within the code structure is altered, potentially exposing issues with access control and operator overloading in different scopes.
