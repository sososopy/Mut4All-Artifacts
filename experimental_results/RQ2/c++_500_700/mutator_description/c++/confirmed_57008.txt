Mutation Operator: Modify Template Instantiation with Empty Parameter Pack

Target Code Construct: Template Instantiation

Mutation Rule:
1. Identify a template variable or function that uses a template parameter pack as an argument, e.g., `template<class... Ts>`.
2. Locate the instantiation of this template where the parameter pack is provided, such as `b<>` or similar constructs.
3. Modify the instantiation to use an empty parameter pack explicitly. For instance, if the code is `bool x = b<>;`, ensure it uses the empty parameter pack in the expression.
4. If the seed program does not contain an applicable template instantiation, introduce a simple template definition and instantiate it with no arguments to create an empty parameter pack scenario.

Example:
Before Mutation:
```cpp
template<class... Ts> bool b = __is_constructible(Ts...);
bool x = b<int, char>;
```

After Mutation:
```cpp
template<class... Ts> bool b = __is_constructible(Ts...);
bool x = b<>;
```

This mutation exploits the specific scenario of using an empty parameter pack, which may lead to issues in template meta-programming or type traits when the compiler does not handle empty cases correctly.
