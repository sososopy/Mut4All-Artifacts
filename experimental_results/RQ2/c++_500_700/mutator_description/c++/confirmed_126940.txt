Mutation Operator: Embed Directive Parameter Mutation

Target Code Construct:
This mutation operator targets lines containing `#embed` directives in preprocessor commands.

Mutation Rule:
Step 1: Identify an `#embed` directive in the source code. This directive will contain parameters, some of which may be known or unknown to the compiler.

Step 2: If the directive contains a sequence where a known parameter precedes an unknown parameter, modify the sequence so that an unknown parameter precedes a known parameter.

For example, if the original directive is:
```
#embed __FILE__ known_param(2) unknown_param(3)
```

Modify it to:
```
#embed __FILE__ unknown_param(3) known_param(2)
```

Step 3: Ensure that the unknown parameter is not recognized by the compiler. You may create a placeholder name not defined elsewhere in the program.

Step 4: Apply the mutation to every occurrence of `#embed` directives in the seed program to cover wider cases.

Example:
Original:
```
int a[] = {
    #embed __FILE__ limit(2) unknown(3)
};
```

Mutated:
```
int a[] = {
    #embed __FILE__ unknown(3) limit(2)
};
```

This mutation exploits potential parsing and validation weaknesses in handling parameter ordering within `#embed` directives.
