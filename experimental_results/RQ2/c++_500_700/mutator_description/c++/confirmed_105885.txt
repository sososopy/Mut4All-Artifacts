Mutation Operator: Alter Function Template with Variadic Parameter Pack

Target Code Construct: Function template where a lambda function with a variadic parameter pack is instantiated.

Mutation Rule:
1. Identify a function template within the seed program that utilizes a lambda function featuring a variadic parameter pack, similar to `decltype([](auto...) {})`.
2. Modify the lambda function's signature to include a non-type template parameter (NTTP) alongside the variadic parameter pack. This introduces a new complexity that may trigger a unique handling path in the compiler.
3. Ensure that the NTTP is used within the lambda body to maintain validity.

Example Transformation:
Original:
```cpp
template<typename... Ts>
void example() {
    auto lambda = [](auto... args) { /* original implementation */ };
}
```

Mutated:
```cpp
template<typename T, typename... Ts>
void example() {
    auto lambda = [](T value, auto... args) { /* modified implementation using 'value' */ };
}
```

The mutation introduces an NTTP `T` to the lambda signature and passes it as `value`, which may lead to an unexpected compiler behavior during template instantiation, providing a broad testing scope across different compiler versions and configurations.
