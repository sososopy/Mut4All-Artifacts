Mutation Operator: Alias Template Modification in Function Argument

This mutation operator targets alias template usage specifically within function argument contexts. It aims to test the compiler's handling of alias templates when they are passed as arguments to templated functions or within template deduction contexts.

Mutation Rule:
1. Identify a function that accepts template arguments or makes use of template deduction.
2. Replace direct type usage with an alias template of a similar type.
3. Ensure the alias template involves a type transformation, such as wrapping the original type in a struct or using it within another template type, to introduce potential complexity in template argument deduction.

Example:
Consider a function template that takes a type and an object of that type:

Original Code:
```
template<typename T>
void process(T obj) {
    // Some operations on obj
}

int main() {
    int value = 42;
    process(value);
}
```

Mutated Code:
1. Declare an alias template at the appropriate scope:
```
template<typename T>
using TypeWrapper = std::tuple<T>;

template<typename T>
void process(TypeWrapper<T> obj) {
    // Some operations involving std::get<0>(obj)
}

int main() {
    int value = 42;
    process(TypeWrapper<int>(value));
}
```

Explanation:
- The original function `process` is modified to accept a `TypeWrapper` alias template instead of the direct type `T`.
- The `TypeWrapper` alias template is defined using `std::tuple<T>`, adding a layer of complexity in template deduction.
- In `main`, `process` is called with `TypeWrapper<int>` instead of directly passing an `int`, checking if the compiler can handle this transformation in the context of alias templates and template deduction.
