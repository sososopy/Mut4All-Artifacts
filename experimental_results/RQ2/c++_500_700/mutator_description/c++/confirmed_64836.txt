Mutation Operator
Target: Function Declaration

Mutation Rule:
1. Identify a class or struct with multiple member functions.
2. Select a function declaration that has parameters, but ensure to choose a function that is not overloaded.
3. Introduce a syntax error by partially removing one of the parameter types in the function declaration. For example, if a function is declared as `void func(int a, double b);`, modify it to `void func(int a, b);` by removing the type `double` for the second parameter.
4. Ensure the rest of the class or struct remains syntactically correct to isolate the mutation effect to the modified function declaration.

Example:
Before Mutation:
```
class Example {
public:
    void calculate(int a, double b);
};
```

After Mutation:
```
class Example {
public:
    void calculate(int a, b);
};
```

This mutation targets the function declaration within a class or struct, introducing a syntax error by removing a parameter type, which can reveal how robustly the compiler handles incomplete parameter type information.
