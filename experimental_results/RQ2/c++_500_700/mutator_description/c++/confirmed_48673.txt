Mutation Operator: Modify Template Parameter Type in Nested Template Class

Target: Template Classes and Their Nested Template Classes

Mutation Rule:
1. Identify any template class (e.g., `C`) with a nested template class (e.g., `Type`) within its definition.
2. Within the nested template class, identify the template parameter, which is an integral type (e.g., `int TT`).
3. Change the integral template parameter type in the nested template class to a non-integral type, such as a pointer or reference type.

Step-by-step Instructions:
- Locate the template class definition: `template <typename T> class C`.
- Within `C`, find the nested template class `template<int TT> class Type`.
- Modify the nested template class parameter from `int TT` to `int* TT` or `int& TT`.

Pseudo-code Example:
```cpp
template <typename T>
class C {
public:
  template<int* TT> // Changed from int TT
  class Type {
  };
};
```
Note: If modifying to a pointer (`int* TT`), ensure that an integer object is used when instantiating the template. If modifying to a reference (`int& TT`), ensure that an integer variable is bound to it during instantiation. This mutation is likely to introduce issues in template instantiation and constraint satisfaction, potentially triggering compiler bugs or crashes.
