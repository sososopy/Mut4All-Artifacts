Mutation Operator: Partial Specialization with Unused Template Parameters

Target Code Construct: Template Class Partial Specialization

Mutation Rule:
1. Identify a template class declaration in the seed program. Ensure the class has at least one template parameter.
2. Add a partial specialization for this class. In this specialization, deliberately avoid using one or more of the template parameters in the specialization's member definitions.
3. Ensure the specialization has a valid syntax and compiles without semantic errors, aside from the unused parameters.

Example:
Original Code:
```cpp
template<typename T, typename U>
class Example {
    // Some member declarations
};
```

Mutated Code:
```cpp
template<typename T, typename U>
class Example {
    // Original member declarations
};

// Partial specialization with unused template parameter U
template<typename T, typename U>
class Example<T, U*> {
    void someFunction() {
        // No reference to 'U' in this specialization
    }
};
```

Explanation:
This operator targets scenarios where the incorrect use or omission of template parameters in a partial specialization could expose latent bugs in the compiler, such as invalid memory access or segmentation faults. This mutation is designed to trigger compiler bugs related to template specialization handling and is likely to have broad applicability across different template constructs.
