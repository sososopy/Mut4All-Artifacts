Mutation Operator: Template Aliasing with Conflict

Target: The mutation operator targets the "using" declaration in template programming constructs, specifically the use of type aliases with `std::variant`.

Mutation Rule:
1. Identify the `using` declaration that introduces the template alias, particularly those using `std::variant` or similar constructs.
2. Select one of the types in the `std::variant` list. This can be any type like `AstProgram`, `AstDecl`, `AstExpr`, or `AstStmt`.
3. Introduce a conflicting alias for the selected type that has a different or incompatible definition.
4. Alter the code so that this conflicting alias is visible in the template alias context.

Example Pseudo-Code Transformation:
Before Mutation:
```cpp
template <typename T>
using AstNode = std::variant<AstProgram, AstDecl, AstExpr, AstStmt>;
```

After Mutation:
```cpp
template <typename T>
using ConflictType = int;  // Introduce a conflicting alias

template <typename T>
using AstNode = std::variant<ConflictType, AstDecl, AstExpr, AstStmt>;  // Use the conflicting alias
```

In this mutation, `ConflictType` is introduced as an alias to `int`, which conflicts with the expected functionality of `AstProgram` (assuming `AstProgram` is more complex than an integer type). This can cause issues in template argument deduction or type substitution, potentially triggering bugs in the compiler's handling of template aliasing and type resolution.
