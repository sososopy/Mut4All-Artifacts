Mutation Operator: Enum Initialization with Non-Integral Expression

Target: Enum Declarations

Mutation Rule:
1. Identify an existing enum declaration in the C++ code.
2. For each enumerator within the enum, replace its initializing expression with a non-integral expression. Specifically, use a string-literal multiplied by an integer, which is an invalid operation for enum initializer.
3. Ensure to retain the enum structure and enumerator names, but change only the initializer expressions.

Example:

Original Code:
```
enum Numbers {
  One = 1,
  Two = 2,
  Three = 3
};
```

Mutated Code:
```
enum Numbers {
  One = ("a" * 1),
  Two = ("b" * 2),
  Three = ("c" * 3)
};
```

Note: This mutation introduces an operator involving a string-literal and an integer in place of the expected integral constant expressions, aiming to trigger similar assertion failures during the compilation.
