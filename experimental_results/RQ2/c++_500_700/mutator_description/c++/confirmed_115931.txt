Mutation Operator: Modify Lambda Capture in Nested Contexts

Target Code Construct: Lambda functions, specifically nested within other lambdas or complex scope hierarchies

Mutation Rule:
1. Identify a lambda function within the source code that is capturing variables either explicitly or implicitly.
2. Check if this lambda is nested within another lambda or other complex scope (e.g., within a class method, another lambda, or a template function).
3. Modify the capture list of the inner lambda to include an additional variable not initially captured. This variable should be a local variable from the outer scope but not from the immediate enclosing scope. If such a variable does not exist, declare a non-captured local variable in the outer scope.
4. Ensure that the newly captured variable is referenced within the lambda body to validate the capture.

Example:

Before Mutation:
```cpp
void exampleFunction() {
    int outerVar = 10;
    auto outerLambda = [outerVar]() {
        int innerVar = 5;
        auto innerLambda = [innerVar]() {
            return innerVar * 2;
        };
        return innerLambda();
    };
}
```

After Mutation:
```cpp
void exampleFunction() {
    int outerVar = 10;
    auto outerLambda = [outerVar]() {
        int innerVar = 5;
        auto innerLambda = [innerVar, outerVar]() { // Capture 'outerVar' as well
            return innerVar * 2 + outerVar;         // Reference 'outerVar' in the body
        };
        return innerLambda();
    };
}
```

By modifying the capture list in nested lambda contexts, this mutation operator targets the complex interaction of lambda capture mechanisms, which are more likely to trigger edge cases in the compiler's lambda handling logic.
