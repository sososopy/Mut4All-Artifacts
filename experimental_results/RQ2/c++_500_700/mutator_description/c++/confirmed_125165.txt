Mutation Operator: Structured Binding with Non-Iterable Types

Target: This mutation operator targets structured bindings applied to non-iterable types within function templates.

Mutation Rule:
1. Identify a structured binding declaration in a function template, e.g., `const auto& [...pack] = t;`.
2. Ensure that the type `t` is intended to be a non-iterable type (such as a fundamental type like `int`, `char`, etc.).
3. Modify the function template to use a structured binding with a basic, non-iterable type and invoke the function with an argument of this type.

Example:
Original code:
```cpp
template <typename T>
void exampleFunction(T t) {
    const auto& [a, b] = t; // structured binding
    // ... use a and b ...
}

int main() {
    exampleFunction(std::make_pair(1, 2)); // passing a pair object
}
```

Mutated code:
```cpp
template <typename T>
void exampleFunction(T t) {
    const auto& [a, b] = t; // structured binding
    // ... use a and b ...
}

int main() {
    exampleFunction(42); // passing a non-iterable integer
}
```

Rationale: This mutation operator leverages the incorrect use of structured bindings with non-iterable types, which can lead to compiler errors and, potentially, crashes. Such situations force the compiler to handle unexpected code constructs, increasing the probability of uncovering hidden bugs related to template instantiation and structured binding handling. This operator focuses on using existing constructs in a program to maintain universality and high coverage.
