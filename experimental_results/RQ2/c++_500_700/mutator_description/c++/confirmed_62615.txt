Mutation Operator: Template Instantiation with Implicit Conversions

Target: Template Function

Mutation Rule:
1. Identify a template function that takes parameters of various types.
2. For any parameter type that is convertible using a user-defined conversion operator, replace its usage with an expression that results in an implicit conversion using this operator.
3. Ensure the conversion operator is used within a context that requires the conversion, such as assignment or passing as an argument to another function.
4. The conversion should be well-formed syntactically but may lead to complex instantiations that challenge the compiler.

Example:
Original:
```cpp
template <typename T>
void process(T param) {
  // Original processing logic
}

struct Convertible {
  operator int() { return 42; }
};

int main() {
  Convertible c;
  process(c); // Uses implicit conversion
}
```

Mutated:
```cpp
template <typename T>
void process(T param) {
  // Modified processing logic
}

struct Convertible {
  operator int() { return 42; }
};

int main() {
  Convertible c;
  int value = c; // Implicit conversion
  process(value); // Pass converted value
}
```

In this mutation, the template instantiation is forced to deal with the implicit conversion, increasing the complexity of valid type substitutions and potentially exposing template instantiation issues in the compiler.
