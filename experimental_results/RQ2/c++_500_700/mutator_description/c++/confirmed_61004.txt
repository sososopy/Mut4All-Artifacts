Mutation Operator: Modify Constexpr Function with Deleted Assignment

Target Code Construct:
This mutation operator targets the assignment operator of a class, specifically when it is marked as both `constexpr` and `= delete`.

Mutation Rule:
1. Locate a class definition that includes an assignment operator. This operator may or may not be explicitly defined within the class.
2. If the assignment operator is explicitly marked as `constexpr` and `= delete`, proceed to step 3. Otherwise, explicitly define the assignment operator within the class.
3. Remove the `constexpr` specifier from the assignment operator declaration while retaining the `= delete` specifier.
4. Ensure the rest of the class definition remains unchanged.

Example:
Original Code:
```cpp
class Example {
public:
    constexpr Example &operator=(const Example &) = delete;
};
```

Mutated Code:
```cpp
class Example {
public:
    Example &operator=(const Example &) = delete;
};
```

Explanation:
This mutation focuses on altering the use of `constexpr` in conjunction with the `= delete` specifier for assignment operators within a class. By removing `constexpr`, this operator tests how the compiler handles the removal of constant expression evaluations in deleted functions, potentially leading to unique scenarios that could expose compiler vulnerabilities or crashes.
