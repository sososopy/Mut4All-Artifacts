Mutation Operator: Scoped Static Variable in Template Argument

Target Construct:
This mutation operator targets a function with a static variable used as a template argument. 

Mutation Rule:
1. Identify any function `func` where a static variable `static_var` is declared within the function scope.
2. Create a template variable `template_var` that uses `static_var` as its template argument.
3. Modify the static variable's value after its use in the template argument to trigger potential compilation issues.

Step-by-Step Instructions:
1. Locate a function in the source code, for example:
   ```
   void exampleFunction() {
       static int staticValue = 10;
       // ...
   }
   ```

2. Define a template variable outside the function using the static variable as a template argument:
   ```
   template <const int& Reference>
   static auto templateVar = 0;
   ```

3. Use the template variable within the function:
   ```
   void exampleFunction() {
       static int staticValue = 10;
       auto useTemplate = templateVar<staticValue>;
       // ...
   }
   ```

4. Modify the static variable's value after its usage in the template:
   ```
   void exampleFunction() {
       static int staticValue = 10;
       auto useTemplate = templateVar<staticValue>;
       staticValue = 20;  // Modify the static variable
       // ...
   }
   ```

The mutation operator exploits the behavior of static variables in template arguments, potentially causing the compiler to mismanage memory or type resolution, leading to crashes. Ensure that the static variable is used in a way that requires it to be evaluated or instantiated by the compiler, as this increases the likelihood of encountering a bug.
