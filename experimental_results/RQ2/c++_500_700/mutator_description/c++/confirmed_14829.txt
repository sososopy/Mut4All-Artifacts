Mutation Operator: Vararg Operator in Friend Function

Target: Struct with Friend Functions

Mutation Rule:
1. Identify a struct with at least one friend function.
2. Locate a friend function that uses standard parameters.
3. Replace the parameter list of this friend function with a vararg parameter list (e.g., replacing `int` or `void*` with `...`).
4. Ensure there is another normal function call or struct that uses this friend function in its expression, to trigger potential issues with the vararg handling.

Example:
Original Code:
```
struct ExampleStruct {
  friend void exampleFunction(ExampleStruct, int);
};

ExampleStruct obj;
// Usage: exampleFunction(obj, 42);
```

Mutated Code:
```
struct ExampleStruct {
  friend void exampleFunction(ExampleStruct, ...);
};

ExampleStruct obj;
// Usage: exampleFunction(obj, 42, "extra");
```

Explanation:
The mutation introduces the use of a vararg (`...`) in a friend function, which can expose issues in the compiler's handling of such scenarios. The mutation is designed to apply to existing structures with friend functions, ensuring compatibility with a wide range of seed programs. The example illustrates replacing an integer parameter with a vararg and introducing an additional argument in the function usage to increase the chances of triggering a compiler crash.
