Mutation Operator: Nested Array Initialization

Target Code Construct:
This mutation targets nested array declarations and initializations using C++ structures.

Mutation Rule:
1. Identify a multi-dimensional array declaration that involves structures (e.g., `S s[2][2];`).
2. Modify the array initialization by introducing additional nested scopes or initializing elements using lambda expressions or other complex constructs.
3. Specifically, replace the direct initialization with a nested lambda expression that accesses different indices of the array, ensuring complex array access patterns.

Example Pseudo-code:

Original Code:
```
struct T {
  int j;
};

void testFunction() {
  T t[3][3];
  
  int result[5];
  result[0] = t[1][1].j;
}
```

Mutated Code:
```
struct T {
  int j;
};

void testFunction() {
  T t[3][3];

  int result[5];
  result[0] = [t] { return t[0][1].j + t[1][1].j; }();
}
```

Explanation:
The mutation operator introduces a lambda expression that accesses multiple elements of the nested array `t`. By using a lambda, it increases the complexity in the initialization process, potentially exposing issues with how the compiler handles nested array initializations and access patterns. This mutation is designed to trigger similar issues as observed with `ArrayInitLoopExpr`.
