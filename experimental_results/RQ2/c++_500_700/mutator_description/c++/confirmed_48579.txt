Mutation Operator: Struct Member Mutation

Target Code Construct: Struct or Union Declaration

Mutation Rule:
1. Identify a struct or union in the code.
2. Within the struct or union, identify one or more member declarations.
3. Introduce a new member in the struct or union with a type that is already defined or used in the program (e.g., int, float, etc.).
4. Assign a default value to the new member within the struct or union's body, using an initializer list.
5. Ensure that any new member added follows the same type constraints and conventions as existing members.

Example:
Original Code:
```cpp
struct Example {
    int x;
    double y;
};
```

Mutated Code:
```cpp
struct Example {
    int x;
    double y;
    float z = 3.14f; // Newly added member with default value
};
```

This mutation operator modifies an existing struct by adding a new member with a default value, which can potentially expose issues in how the compiler handles struct initialization and default values.
