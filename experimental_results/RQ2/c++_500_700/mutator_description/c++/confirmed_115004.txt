Mutation Operator: Template Class Specialization with Constraints

Target Code Construct: Class Template Partial Specialization

Mutation Rule:
1. Identify a class template that has a constraint-based concept applied to its template parameters.
2. Modify the template by introducing a partial specialization that adds additional constraints on one or more template parameters.
3. Ensure that the added constraints are logically dependent or overlapping with the existing constraints, to increase complexity and potential for compiler inconsistencies.

Step-by-step Instructions:
- Locate a class template with a constrained template parameter, e.g., `template <typename T> concept C = ...; template <C T> class MyClass;`.
- Introduce a partial specialization of this class template with an additional constraint that interacts with the existing constraint. Use a different definition or specialized logic.
- For example, if the original class is `template <C T> class MyClass { /*...*/ };`, create a specialization like:
  `template <C T> requires (T::value > 0) class MyClass<T> { /* specialized behavior */ };`.
- Ensure the new constraints form a logically complex relationship that may challenge the compiler's constraint normalization logic.

Example:
Existing code:
```cpp
template <typename T> concept C = sizeof(T) > 0;
template <C T> class MyClass {
    // Base implementation
};
```

Mutation:
```cpp
template <typename T> concept C = sizeof(T) > 0;
template <C T> class MyClass {
    // Base implementation
};

template <C T> requires (alignof(T) > 2) class MyClass<T> {
    // Specialized implementation for types with alignment greater than 2
};
```

This mutation exploits the compiler's handling of overlapping constraints during template specialization, potentially triggering inconsistencies or crashes in the constraint normalization process.
