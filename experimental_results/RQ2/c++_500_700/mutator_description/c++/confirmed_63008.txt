Mutation Operator: Modify New Expression with Parentheses and Braces

Target: New expressions involving a constructor with both parentheses and braces for initialization.

Mutation Rule:
1. Locate a new expression that initializes an object using both parentheses and braces in a mixed initializer list. This commonly appears in new object allocations where constructor parameters are supplied through both forms.
2. Convert the initialization by removing either the parentheses or the braces, leading to a purely parenthetical or brace-based initialization.

Example:
Original Code:
```
struct B {
    int x;
    int y;
};

void bar() {
    auto instance = new B(1, {2});
}
```

Mutated Code:
```
struct B {
    int x;
    int y;
};

void bar() {
    auto instance = new B{1, 2};
}
```

Explanation:
This mutation directly modifies the constructor's argument list in a new expression by converting the mixed initializer to a single form. This is aimed at exposing potential issues in handling different initialization formats within the compiler, leading to assertion failures or crashes. The approach ensures that the mutation is generic and applicable across various seed programs by utilizing existing structs and constructor syntax.
