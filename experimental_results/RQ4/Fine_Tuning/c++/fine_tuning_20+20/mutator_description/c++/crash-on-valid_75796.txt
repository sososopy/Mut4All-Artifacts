mutation Operator: Target Structure: Function Declaration or Call. Mutation Rule: Step 1: Choose an existing function declaration or call that has at least one argument of simple type (e.g., int, char, float). Step 2: Replace the argument's type with 'auto'. Step 3: If targeting a function call, ensure the called function is updated to accommodate 'auto' by modifying its corresponding parameter. For example, transform 'int funcX(int a)' to 'void funcX(auto a)' and its invocation 'funcX(1)' to 'funcX(1)'.
