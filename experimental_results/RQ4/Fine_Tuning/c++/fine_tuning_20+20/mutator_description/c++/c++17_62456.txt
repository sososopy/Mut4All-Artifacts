mutation Operator: Lambda Return Type Replacement Target: This mutation operator targets lambda expressions that have an explicit return statement. Rule: Replace the lambda's return statement with a different expression that includes a fold expression over a parameter pack. Steps: 1. Identify lambdas with explicit return statements. 2. Replace the return statement with a fold expression. If a parameter pack is being captured as a lambda parameter, ensure that the new return statement uses this pack in the fold. Example: Before: [](auto... a) { return ([a]{}, ..., 0); } After: [](auto... a) { return (([a]{}, 0) + ...); }
