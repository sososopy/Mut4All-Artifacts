mutation Operator: Template Class with Private Template Method Target: A class template with at least one template method. Mutation Rule: 1. Identify a class template (e.g., C) with a template method (e.g., T foo()). 2. Change the access specifier of the template method to private. 3. Ensure there is at least one instantiation of the class template that attempts to call this method. Example: Before: template <typename T> class C { public: template <typename U> U foo(); }; int main() { C<int> c; c.foo<double>(); } After: template <typename T> class C { public: private: template <typename U> U foo(); }; int main() { C<int> c; c.foo<double>(); }
