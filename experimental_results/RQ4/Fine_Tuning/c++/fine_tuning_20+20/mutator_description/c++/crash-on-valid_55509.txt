Mutation Operator: Add Template Specialization

Step 1: Identify a primary template declaration. This could be a class template or function template.

Step 2: For class templates, choose one or more template parameters that will be specialized. These could be type parameters, non-type parameters, or template template parameters.

Step 3: Write a template specialization that overrides the primary template for the chosen parameter values. For example:

If the primary template is a class template like this:

template <typename T, int N> struct MyClass { /* primary template implementation */ };

You could add a specialization like this: 

template <typename T> struct MyClass<T, 0> { /* specialized implementation for N=0 */ };

If the primary template is a function template like this:

template <typename T, typename U> void myFunction(T t, U u) { /* primary template implementation */ };

You could add a specialization like this:

template <typename T> void myFunction<T, int>(T t, int i) { /* specialized implementation for U=int */ };

Step 4: Ensure the specialization provides a complete implementation. If it's a class template specialization, define all necessary member functions, typedefs, and nested types. If it's a function template specialization, provide a complete function body.

Step 5: Verify that the specialization is used correctly in contexts where the specialized parameter values are used. Make sure that the compiler resolves the specialization as intended.
