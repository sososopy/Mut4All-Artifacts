Mutation Operator 1: Unevaluated Function Parameter Pack In Compound Statements
- This mutation is targeted at compound statements within function bodies. It involves the insertion of a function parameter pack expression in a context where it is unevaluated, leading to potential assertion failures.
- Identify any compound statement within a function. This could be detected by searching for curly braces ('{}') following a function signature.
- Within the identified compound statement, choose an existing function parameter that is a pack. If none exist, insert a new variadic parameter in the function declaration, ensuring it is of a compatible type such as 'int'.
- Use the selected parameter pack within an expression inside the compound statement. This expression could be as simple as a standalone reference to the parameter, or it might form part of a larger construct such as a loop or conditional.
- Ensure that the parameter pack is used in an unevaluated context. This might be achieved by placing it within a 'sizeof' expression or another context where the compiler is instructed not to generate code for the actual evaluation of the expression.
- Example: Given a function 'void f(int a) { a; }', mutate it to 'void f(int... a) { sizeof(a); }'.
