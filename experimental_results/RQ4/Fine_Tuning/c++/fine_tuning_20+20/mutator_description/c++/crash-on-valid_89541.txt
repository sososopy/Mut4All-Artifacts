Mutation Operator: Lambda Return Type to Decltype

Target Constructs: Lambdas in function definitions that use auto as the return type.

Mutation Rule: Locate and replace auto return types in lambda expressions with decltype(auto).

Step-by-Step Instructions: Identify lambda expressions within function definitions that have return type auto. Replace this return type with decltype(auto). If the return type is not explicitly stated (i.e., omitted), insert decltype(auto) before the lambda parameter list. If the return type is specified as trailing return type with auto, replace auto with decltype(auto).

Examples:

1. Original: auto lambda = [] { return expr; };
   Mutated: decltype(auto) lambda = [] { return expr; };

2. Original: auto lambda = []() -> auto { return expr; };
   Mutated: auto lambda = []() -> decltype(auto) { return expr; };

3. Original: auto lambda = [] { return expr; };
   Mutated: auto lambda = []() -> decltype(auto) { return expr; };

4. Original: auto lambda = [&] { return expr; };
   Mutated: auto lambda = [&]() -> decltype(auto) { return expr; };
