mutation Operator: “Insert Invalid Requires Expression Inside Concept”  
Target Code Construct: Concept Definition 
Mutation Steps:  
1. Locate a concept definition in the seed program.  
2. Identify a valid requires expression within the concept definition.  
3. Insert an invalid requires expression before, after, or within an existing valid requires expression, creating a malformed concept definition.  
Example:  
Before:  
concept C = requires (T a) { a+b; };  
After:  
concept C = requires requires (T a) { a+b; };
