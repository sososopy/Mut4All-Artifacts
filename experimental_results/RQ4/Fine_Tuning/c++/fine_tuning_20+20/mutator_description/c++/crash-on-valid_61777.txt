Mutation Operator: Add default template argument in class template Nested inside another class template
Target Location: Class template definition inside another class template
Mutation Rule: 1.Identify a class template nested inside another class template. 2.Add a default template argument to the nested class template by assigning a value to one of its template parameters. 3.If any nested template parameter is non-type and not at the end, suggest adding a default argument to it.
Example Before Mutation:
template <class> struct O { template <class, auto> struct A { static const int i = 0; }; };
static_assert(O<void>::A<int, 0>::i == 0);
Example After Mutation:
template <class> struct O { template <class, auto = 0> struct A { static const int i = 0; }; };
static_assert(O<void>::A<int>::i == 0);
