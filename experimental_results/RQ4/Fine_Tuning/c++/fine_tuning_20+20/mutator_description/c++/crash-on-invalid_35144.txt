Mutation Operator 1: Recursive Template Lambdas

Target: Template and lambda expressions

Description: This operator modifies a templated function to include a recursive call inside a lambda expression, potentially leading to compiler instability or crashes.

Steps:
1. Identify a templated function within the code.
2. Inside the templated function, replace an existing return statement or expression with a recursive call to the templated function itself but wrapped inside a lambda expression.
3. Ensure that the lambda is invoked immediately, either by direct invocation or through a construct like `std::invoke`.

Example
Original Code:
template <typename T> auto someFunction(T x) { return x + 1; }

Mutated Code:
template <typename T> auto someFunction(T x) { return [] { someFunction([] {}) } (); }
