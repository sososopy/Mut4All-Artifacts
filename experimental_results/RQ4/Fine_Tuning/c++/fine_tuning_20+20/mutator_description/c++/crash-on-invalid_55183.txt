Mutation Operator: Invalid Function Body Return Type This mutation operator targets the function definition. It specifically alters the return type of a function to an invalid or mismatched type. Operator: 1. Identify a function definition with a well-defined return type. 2. Change the return type of the function to a type that is incompatible or invalid for the function's body. Example: Original: int function_name() { return 42; } Mutated: void function_name() { return 42; }
