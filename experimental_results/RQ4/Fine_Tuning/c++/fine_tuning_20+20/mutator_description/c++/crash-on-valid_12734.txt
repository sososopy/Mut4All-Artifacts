Mutation Operator 1: Partial Specialization Default Argument Substitution

Target Code Construct: Partial Specialization of Class Templates

Mutation Rule: 1. Locate a class template with at least one template parameter and a corresponding default argument in a partial specialization. 2. Modify the default argument for the partial specialization to reference the primary template parameters. 3. An example modification would be changing template <typename T2 = T> struct D; to template <typename T2 = T> struct D<T2>;.
