Operator: Insert Invalid Template Instantiation

Target: Template Instantiation

Description: This mutation operator targets template instantiations in the code. It modifies them to introduce invalid or ambiguous template arguments, which the compiler may struggle to resolve correctly, especially in cases involving nested templates or complex deduction scenarios.

Mutation Rule: Identify a template instantiation in the code. Modify it by replacing the template arguments with invalid types or expressions. For example, if you have a template instantiation like `MyTemplate<int, double>`, mutate it to something like `MyTemplate<3 + 4, "abc">`. Ensure the mutated code compiles or triggers a known bug by testing it.
