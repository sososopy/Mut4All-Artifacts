
    Mutation Operator: Template Function Specialization
    Target Construct: Template Function with Variadic Parameters
    Mutation Rule: Locate a variadic template function in the seed program and attempt to specialize it with explicit template arguments that do not match any valid instantiation of the function. Identify the variadic template function definition by searching for the 'template' keyword followed by 'typename...' and the function name. In a function or statement that calls this variadic template function, explicitly specify template arguments within angle brackets that do not match any possible valid instantiation according to the parameters of the function. Retain the original format and structure of the function call while modifying only the template arguments to induce a mismatch.
    Example: Original code: template <typename... Args> void variadicFunc(Args&&... args) {} void example() { variadicFunc<int>(42); } Mutated code: template <typename... Args> void variadicFunc(Args&&... args) {} void example() { variadicFunc<int, int>(42); }
