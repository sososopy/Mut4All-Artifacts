Mutation Operator 1: Mutate Function Return Type with Decltype

    Target: This mutation operator targets functions that have an explicitly specified return type and utilizes type deduction with decltype.
    Mutation Rule: Alter the return type of the function to a deduced type using decltype.
    Step-by-step Instructions:
    1. Identify a function with a specified return type, such as int, float, or custom class/struct type.
    2. Replace the specified return type with a deduced type using decltype. Use an existing variable, expression, or function call within the function body or accessible in the current scope as the argument for decltype.
    3. Ensure that the new return type is consistent with the function's intended behavior and usage, maintaining semantic correctness.
    Example: 
    Original: int myFunc(int a, int b) { return a + b; }
    Mutated: auto myFunc(int a, int b) -> decltype(a + b) { return a + b; }
