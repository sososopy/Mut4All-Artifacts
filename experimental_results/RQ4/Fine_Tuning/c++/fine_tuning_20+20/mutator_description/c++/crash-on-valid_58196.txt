mutation Operator: Template Deduction Guide Removal
Target: Template Deduction Guide in a Template Class
Mutation Rule: Identify an existing template class with a deduction guide within a header or source file. Remove the deduction guide entirely. For example, given a template class `template <typename T> class C {}` and a deduction guide `C(int) -> C<int>;`, remove the deduction guide, resulting in the class declaration without any deduction guide.
