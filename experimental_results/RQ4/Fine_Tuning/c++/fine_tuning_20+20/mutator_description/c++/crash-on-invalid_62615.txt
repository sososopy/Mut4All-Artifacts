    Mutation Operator: Substitute Template Type Parameters in Concept Definitions Target: Template parameter of a concept definition Mutation Rule: 1. Identify a concept definition with a template parameter list, e.g., template <class Tp, class Up> concept Foo = /*...*/; 2. Within the concept definition, locate all occurrences of the template parameters. 3. Substitute a template type parameter with a type derived from decltype or a similar type trait to force type substitution logic. 4. For example, replace Foo<Tp, Up> with Foo<decltype(Tp), Up> or Foo<std::remove_cv_t<Tp>, Up>. Example Before: template <class Tp> concept _nothrow_decay_copyable = _nothrow_constructible_from<std::decay_t<Tp>, Tp>; After: template <class Tp> concept _nothrow_decay_copyable = _nothrow_constructible_from<std::decay_t<decltype(Tp)>, decltype(Tp)>;
