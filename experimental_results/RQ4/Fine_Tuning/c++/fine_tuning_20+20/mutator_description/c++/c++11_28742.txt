Mutation Operator 1: Variadic Template Instantiation

Target Construct: Variadic Template Class

Mutation Rule:1. Identify a variadic template class definition in the code, which contains multiple template parameters, including at least one template parameter pack. 2. Select a function within the variadic template class definition. If there are multiple functions, prioritize selecting a function without a parameter pack. 3. Modify the function by adding a template specialization that instantiates the class with specific types for the parameter pack. Use existing types from the seed program to ensure validity. If there are no suitable existing types, introduce one or more new types as needed. 4. Ensure that the added specialization is syntactically correct and consistent with the original class template parameters.

Example: Original Code: template<typename... Args> struct A { };Mutted Code: template<typename... Args> struct A { }; template<> struct A<int, int> { };
