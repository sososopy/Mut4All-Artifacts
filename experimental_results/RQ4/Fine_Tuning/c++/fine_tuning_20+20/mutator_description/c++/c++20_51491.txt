Mutation Operator: Template Specialization with Export in Non-Module Context

Target: Template specializations in non-module contexts

Mutation Steps: 
1. Identify a template definition within the source code.
2. Select a type that is already defined in the seed program to act as the template argument.
3. Access an existing member of the template and use it to define a specialization.
4. Prefix the specialization with the export keyword.
5. Ensure the specialization is placed outside any module-related constructs or ensure no module declarations are present in the seed program.

Example:
Original: 
template<typename T> struct A {}; using B = int;
Mutated: 
template<typename T> struct A { int member; }; using B = int; export template<> int A<B>::member = 42;
