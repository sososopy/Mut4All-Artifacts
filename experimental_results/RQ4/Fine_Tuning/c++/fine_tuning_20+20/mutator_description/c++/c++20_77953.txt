mutation Operator 1: Target Nested Templates in Classes: Locate a class definition that contains a nested template (a template within a class, often a member function template). Mutation: Add a requires clause to the nested template, introducing a constraint. Use existing types, variables, and concepts if available, or introduce a new concept if necessary. For example, if the class is struct name { template <typename T> void func(); };, transform it into struct name { template <typename T> requires(name) void func(); };.
