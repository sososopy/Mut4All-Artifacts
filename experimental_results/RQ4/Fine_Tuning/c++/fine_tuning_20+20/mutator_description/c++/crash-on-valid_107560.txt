mutation Operator Replacing a lambda expression with a custom struct application: locate a lambda expression, which typically appears within a function call as an argument and is denoted by the [ ] syntax mutation: remove the lambda expression and substitute it with a custom struct that simulates the lambda's functionality example: replace [ ] (auto a, auto b) { return a + b; } with struct lambda { template <class a, class b> auto operator()(a && x, b && y) const { return x + y; } }
