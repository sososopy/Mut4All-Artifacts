Mutation Operator: Template Parameter Pack Expansion in Return Type Description: The mutation operator targets function return types involving template parameter pack expansions. Specifically, it introduces a pack expansion in the return type of a function using a template parameter pack, which can lead to compiler crashes when the parameter pack is empty. Mutation Rule: 1. Identify a function with a non-dependent return type. This could be a regular function or a member function within any class or struct. 2. Modify the return type to be a pack expansion based on an existing template parameter pack. Use a syntax like `auto` followed by the parameter pack expansion, e.g., `T...`. 3. Ensure that the mutation is applied within a templated scope where a parameter pack is available. 4. If no suitable parameter pack is present, introduce a new template parameter pack at the appropriate level (e.g., class or function template) and use it in the return type. Example: Before Mutation: template <typename T> T func1() {} template <typename... Ts> struct S { int method1() {} static double method2() {} }; After Mutation: template <typename... T> T... func1() {} template <typename... Ts> struct S { Ts... method1() {} template <unsigned i> static auto method2() -> Ts...[i] {} };
