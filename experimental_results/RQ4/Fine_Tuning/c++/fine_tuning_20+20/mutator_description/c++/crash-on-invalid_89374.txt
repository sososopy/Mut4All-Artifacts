Mutation Operator: Specialization Template Without Use 1.Target: Specialization template 2.Applicable Locations: Locate lines defining the specialization template (lines with template<...> and struct/class/typename ... { }) 3.Mutation Rules: If the specialization template takes n arguments in the angle brackets, 3.1. If it takes n arguments in the angle brackets, remove all template arguments in the angle brackets. 3.2. If it takes less than n arguments, remove the specialization template in the angle brackets. 3.3. If there are no template arguments in the angle brackets, leave it unchanged. 4.Note: This mutation is applicable to specialization templates, including class templates, struct templates, typename templates, and requires that the template arguments be non-empty. 5.Example: Original： template <typename T> struct A {}; template <> struct A<int> : A<int> {}; Mutated: template <typename T> struct A {}; template <> struct A : A<int> {};
