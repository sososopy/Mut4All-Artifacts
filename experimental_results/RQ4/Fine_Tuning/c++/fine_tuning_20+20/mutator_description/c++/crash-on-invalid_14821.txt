C++ compiler bugs are often triggered by complex interactions between templates, inheritance, and type deduction. These areas involve intricate rules and dependencies that can easily lead to errors if not handled correctly. 

Mutation Operator 1: Modify Template Inheritance Mutation Target: Template class with inheritance. Mutation Rule: Replace a template class that inherits from another template class with a new template class that uses a different base class or none. If a base class is used, it should be one that is already defined in the seed program or is a standard library class. Example mutation: Before: template <class T> struct D : public A<T> {}; After: template <class T> struct D : public B<T> {}; or template <class T> struct D {};
