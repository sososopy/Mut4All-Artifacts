Mutation Operator: “Apply `clang::always_inline` to overload function calls” Target: Function Overloads Mutation Rule: - Identify function calls within a template function. - Verify that there exists an overloaded function with different parameters but the same function name. - Apply the `clang::always_inline` attribute to the call site of the overloaded function. Example: If the seed code includes: void foo(int x) {} void foo(double y) {} template <typename T> void bar(T t) { foo(t); } Mutate to: void foo(int x) {} void foo(double y) {} template <typename T> void bar(T t) { [[clang::always_inline]] foo(t); }
