Mutation Operator :Modify array size to a floating number Description: This mutation operator targets variable declarations, specifically those involving arrays. It modifies the size of the array to be a floating-point number. Mutation Rule :1. Identify all array declarations in the code. 2. Select the first identified array declaration for mutation. 3. Replace the size of the array with a floating-point number by adding a ".5" to the existing size. Example: Original Code: int arr[10]; Mutated Code: int arr[10.5];
