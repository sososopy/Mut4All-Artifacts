Mutation Operator: Array Size Omission in Type Traits
Target Construct: This operator targets type trait expressions like __array_extent, __is_array, __is_pointer, etc.
Mutation Rule: Identify type trait expressions that take type arguments and intentionally omit one or more required arguments. For example, in a trait like __array_extent(Type, Dimension), remove the second argument entirely, such as __array_extent(Type, ). Similarly, for other traits, adjust the argument list to create a malformed expression by omitting expected parameters or inserting placeholders like commas without actual arguments.
