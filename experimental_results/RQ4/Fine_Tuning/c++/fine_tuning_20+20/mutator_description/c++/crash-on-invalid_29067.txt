Mutation Operator: Function with Pointer to Member

Target Code Construct: This operator targets functions that deal with pointers to members.

Mutation Rule: Inside a function, identify a pointer-to-member variable (e.g., a pointer to a class member such as a member function or member variable). Replace the existing pointer-to-member expression with a malformed or invalid expression, such as calling the operator on incompatible types or using an undeclared variable as the pointer to member. For example, if there is a pointer to member named pm that points to a class member function or variable, replace it with an invalid expression. You might attempt to call the pointer-to-member syntax with something that is not actually a valid pointer to member, like an undeclared variable.

Example: Original: int (C::*pm)() = &C::f; (obj.*pm)(); Mutated: (obj.*undef)(); // 'undef' is undeclared
