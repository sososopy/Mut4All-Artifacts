mutation Operator: Extract function template call with rvalue reference to a separate statement and assign to a named variable Applies to: Function template calls with rvalue reference arguments within compound statements Mutation Rule: 1. Find a function template call with an rvalue reference argument within a compound statement (e.g., inside a function body). 2. Extract the function template call and assign it to a named variable, declared with auto and initialized with the call. 3. Replace the original function template call with the named variable in the compound statement. Example: Original: int sum = a(0); Mutated: auto temp = a(0); int sum = temp;
