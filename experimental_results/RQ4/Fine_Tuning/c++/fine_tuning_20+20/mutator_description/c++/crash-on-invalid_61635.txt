Mutation Operator Based on the bug information, we can see that the crash is triggered when applying certain attributes with invalid indices to functions. Here’s a mutation operator that targets this specific pattern: Target Construct: Function with attributes Mutation Rule: 1. Identify functions that have attributes applied to them. 2. Focus on attributes that accept indices as arguments, such as __attribute__((format)), __attribute__((format_arg)), etc. 3. If a function with such an attribute has a varargs parameter (...), then modify the index in the attribute to point to a parameter beyond the valid range. This involves checking the number of fixed parameters in the function and setting the attribute index to a value greater than this count. Example Mutation: Let's say we have a function like this: __attribute__ ((format (printf, 1, 2))) void myPrint(const char *fmt, int x, ...); The mutation would change it to something like: __attribute__ ((format (printf, 3, 4))) void myPrint(const char *fmt, int x, ...); This sets the attribute indices to values beyond the number of fixed parameters, aiming to trigger the crash described in the bug report.
