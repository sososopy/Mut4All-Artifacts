Mutation Operator: Constructor Overloading with Identifier Target: Apply to class definitions with constructors. Mutation Rule: Inside a class definition, locate any constructor. If the constructor is overloaded, add an identifier name or rename the identifier. Ensure that this constructor is used in a constant expression, such as _Static_assert, to evaluate its behavior in the context of the class. Example Pseudo-Code: Replace struct S { S(){} }; with struct S { int id S(){} }; _Static_assert(S().id, "");
