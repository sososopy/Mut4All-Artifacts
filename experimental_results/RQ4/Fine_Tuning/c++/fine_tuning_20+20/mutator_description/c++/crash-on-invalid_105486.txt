Mutation Operator: Insert Pointer Indirection to Integer Literal 

Code Construct: Integer literal (used in expression)

Mutation Rule: Identify an integer literal within an expression. Prepend the literal with the dereference operator '*'. Ensure that the resulting expression is syntactically correct but semantically invalid, such as attempting to dereference a non-pointer type. 

Example: Transform "int x = 5;" to "int x = *5;".
