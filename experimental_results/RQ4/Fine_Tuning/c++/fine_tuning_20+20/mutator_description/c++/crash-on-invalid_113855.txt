mutation Operator 1: Target: Apply to any union with multiple members, which contains at least one non-numeric type, such as a struct or class.
Mutation: Insert a designated initializer before an existing initializer within a new expression or variable declaration. If the union contains a struct or class member, ensure that only one member initializer is included, disregarding the others.
Example: new (U{A(), .b = 2}) → new (U{.b = 1,A()})
