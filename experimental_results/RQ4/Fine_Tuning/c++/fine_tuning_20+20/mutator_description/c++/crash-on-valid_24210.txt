mutation Operator: Array Initialization with Complex Type Application Scope: This mutation operator targets array declarations in the seed program that use complex types like classes or structs as their elements. Mutation Rule: Transform an array declaration with complex types into one that uses empty initialization. Steps: 1. Identify an array declaration in the seed program where the element type is a complex type, such as a class or a struct. 2. Replace any existing initialization of the array with an empty initialization using a pair of curly braces {}. Example: Before Mutation: std::array<std::unordered_map<int, int>, 5> v; After Mutation: std::array<std::unordered_map<int, int>, 5> v = {};
