Mutation Operator: Target a function definition of a template specialization. Modify the function's return type to auto, and if the function is a member function, retain the class qualifier. For instance, given a function definition template<> int foo(int) {...}, change it to template<> auto foo(int) {...}. If the function is a member function of a class named MyClass, ensure it becomes template<> auto MyClass::foo(int) {...}.
