mutation Operator: Lambda Capture Mutation Target: Lambda Expression Capture Specification: Replace a variable capture with a different existing variable from the surrounding scope. If the lambda has an explicit capture list, identify a variable from the surrounding scope that is not already captured. Add this variable to the capture list in place of one of the existing captures. If the lambda uses implicit capture, switch one of the implicitly captured variables with another variable from the surrounding scope that is not originally captured. Example: Original Lambda: `auto lambda = [&x, &y]() { cout << x + y; };` Mutated Lambda: `auto lambda = [&x, &z]() { cout << x + y; };`
