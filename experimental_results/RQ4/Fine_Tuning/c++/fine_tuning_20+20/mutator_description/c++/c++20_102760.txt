Mutation Operator: Target the requirement clause of a lambda expression, including requires expression and requires-clause. Remove the requirement clause, which consists of the keyword requires, zero or one template parameter list, and conjunctive expressions, along with its delimiters such as brackets or parentheses. The requirement clause should be removed entirely, not just modifying its contents. For example, the following lambda expression auto lambda = [](auto x) requires requires(x) { x.foo(); } { x.bar(); }; will be transformed into auto lambda = [](auto x) { x.bar(); };
