### Mutation Operator: Incomplete Structure for Constexpr Declaration

Target: Constexpr declarations using structures

Description: When the code contains a constexpr declaration with a structure type, and the structure type is incomplete, it may lead to compiler crashes. This mutation operator targets such constexpr declarations by creating incomplete structures.

Mutation Rule:
1. Identify all constexpr declarations in the seed program.
2. Check if the type of the constexpr variable is a structure type.
3. If it is a structure type, traverse up the AST to find the original structure declaration.
4. Delete the structure’s base specifier list and all its members while retaining its name and template parameters (if any).
