mutation Operator: Insert a lambda expression in a nested scope within a function

Target Structure: Function body, specifically inside nested control structures or compound statements.

Mutation Rule:
1. Identify a function with a compound statement (enclosed in {}).
2. Inside the compound statement, find a nested control structure such as if, for, while, or an inner compound block.
3. Insert a lambda expression inside this nested scope.
4. The lambda can be simple, such as auto lambda = [](){};, or it can capture local variables and perform operations.

Example:
Original: void foo() { if (x > 0) { do_something(); } }
Mutated: void foo() { if (x > 0) { auto lambda = [](){}; do_something(); } }
