Mutation Operator 1: Variadic Template with Inheritance

Target: Variadic Templates with Inheritance

Mutation Rule: 1. Identify a variadic template class inheriting from parameter pack elements. 2. Use a member from the parameter pack in the template class. 3. Apply the template class with arguments having a common base class and using virtual inheritance from this base.

Example: Original: template<typename...args> struct X : public args... { using args::k ...; }; Mutated: template<typename...args> struct X : public args... { using args::k ...; };
