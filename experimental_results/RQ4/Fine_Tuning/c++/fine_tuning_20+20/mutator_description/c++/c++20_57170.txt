mutation Operator: Target: lambda variables in a lambda expression. Mutation Rule: For each lambda variable declared in the lambda parameter list, remove the parameter declaration from the lambda parameter list and replace all uses of lambda variables in the lambda body with a structured binding declaration that extracts elements from any type that can be decomposed (such as auto[var1, var2, ...] = varName). Example: Given a lambda expression auto lam = [](int x, float y) { return x + y; };, transform it into auto lam = []() { auto [x, y] = std::make_pair(1, 2.0); return x + y; };
