Mutation Operator 1: Template Deduction and Instantiation Operator Target: Function templates, especially those with complex parameter types and multiple levels of template arguments. Mutation Rule: For each function template in the program: Select a function template with multiple template parameters. Add an additional template parameter of a different type, such as a reference or pointer type if the original is a value type. Modify an existing parameter in the function's parameter list to use the new template parameter. Use the function template in a context where it requires deduction and instantiation with non-trivial types, such as nested template arguments or dependent types. Example: Original function template: template <typename T> void f(T x); Mutated function template: template <typename T, T* U> void f(U x); Use the mutated function template in a context where the deduction can be complex: f<int>(nullptr);
