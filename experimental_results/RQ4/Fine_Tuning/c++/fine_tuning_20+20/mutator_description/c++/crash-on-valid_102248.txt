mutation Operator: 
Target: Compound Literals
Description: Replace a compound literal with an array initializer using an existing type. 
Step by Step: 
1. Identify a compound literal in the code with the syntax (TypeName){initializer}. 
2. Replace the compound literal with an array declaration using the same type and initializer. 
3. Declare an array using the syntax TypeName arrayName[] = {initializer}. 
Pseudo-Code Example: 
Original: int *p = (int[]){1, 2, 3}; 
Mutated: int arr[] = {1, 2, 3}; int *p = arr;
