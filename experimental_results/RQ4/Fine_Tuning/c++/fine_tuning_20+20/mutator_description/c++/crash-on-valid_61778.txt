Mutation Operator 1: Modify constrained member function - Target: template struct with a constrained member function - Mutation Rule: For a member function with constraints in a template struct, add an unconstrained overload of the same function. Ensure the unconstrained version is declared before the constrained version, and it should be a separate overload rather than using ‘requires’ keyword. If an unconstrained overload already exists, no mutation is needed. - Example: Original: void f() requires C<T> { } Mutated: void f() { } void f() requires C<T> { }
