
Mutation Operator: Conditional Operator Mutation Target: Auto variable initialization with conditional operator Context: When auto variables are initialized using a conditional operator, particularly with operands of different types, it can cause crashes, especially in the context of type deduction and AST representation. Mutation Rule: 1. Locate an auto variable initialized with the conditional operator in the seed program. For example, "auto var = (condition ? expr1 : expr2);" 2. If the types of expr1 and expr2 are explicitly specified or can be deduced, modify one of the operand expressions to a different but related type. For example, change an operand from an array type to a pointer type of the same base type or from a derived class type to a base class type. 3. Ensure the modified operand type is still valid in the context, either directly or through implicit conversion, but differs in a way that affects type deduction or overload resolution, such as switching between a pointer and array, or const and non-const variants. 4. If necessary, ensure supporting declarations or type definitions are present, such as including necessary headers for standard containers or defining related custom types. 5. Verify that the mutated expression is syntactically and semantically correct, focusing on triggering complex type deduction scenarios. Example: Original: auto var = (condition ? array_expr : pointer_expr); Mutated: auto var = (condition ? pointer_expr : array_expr); Ensure that the pointer_expr and array_expr are constructed or modified accordingly to represent the same underlying type in different forms, such as using array decaying, address-of operators, or explicit casts to maintain validity while altering the type representation.
