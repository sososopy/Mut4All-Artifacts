Mutation Operator: Nested Struct Export Mutation

1. Target: Nested Struct with Export
2. Mutation Rule: 
Step1: Identify a nested struct that is exported using the syntax "export struct A::B" or similar.
Step2: Remove the export keyword from the nested struct definition.
3. Examples:
Example1: If you have "export struct A::B {}", change it to "struct A::B {}". 
Example2: If you have "export struct Y::X {}", change it to "struct Y::X {}".
