    Mutation Operator:  use a constant variable as an array initializer Target: Array initialization with constant variables Mutation: 1. Identify a constant variable declaration, which can be any existing constant variable. 2. Locate an existing array initializer, or insert a new variable with an array initializer. 3. Replace one of the initializer elements with the constant variable. 4. All other elements should be chosen from existing variables or literals. Example: const b; c[] = {b = a}
