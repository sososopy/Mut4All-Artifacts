Mutation Operator: Apply noexcept with expression that uses declval on a function. 1. Identify functions that can be mutated. They can be any function defined in the seed program, including member functions and lambda expressions. 2. For a selected function, if it doesn’t have a noexcept specifier, add `noexcept(A)`  after its parameter list, where `A` is an expression using declval on `one` parameter such as `std::declval<Type>().function_name()` and `std::declval<Type>(args...)`. If using a lambda expression, use `[]() noexcept(A)`, such as `[]() noexcept(std::declval<Type>().function_name())` 3. If the function already has a noexcept specifier, replace the current one with a new expression using declval, such as `noexcept(std::declval<Type>().function_name())`, where `Type` is a type already used in the parameter list. 4. In case of functions using macros for exception specifications, expand the macros and apply the mutation to the expanded form. 5. If there are overloaded functions, apply the mutation to each overload separately. 6. If the seed program contains templates, ensure the mutation is applied consistently across all instantiations of the template.
