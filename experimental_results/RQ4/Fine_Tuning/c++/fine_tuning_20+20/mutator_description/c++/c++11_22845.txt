mutation Operator: "Invalid Reference Inside Constexpr Function" Description: This operator introduces a reference to a non-local variable inside a constexpr function, which can lead to compiler crashes when the reference is not constexpr compliant. Target Constructs: This mutation targets constexpr functions, especially those within struct, class, or inline namespaces. Mutation Rule: 1. Identify a struct, class, or inline namespace within the seed program. 2. Locate or introduce a constexpr function within the identified construct. 3. Find a non-local variable (e.g., a variable declared in main or a global variable). 4. Inside the constexpr function, introduce a reference to the non-local variable. Example: Consider the following seed code: int main() { int a = 10; struct A { constexpr int func() { return 0; } }; } After applying the mutation, it becomes: int main() { int a = 10; struct A { constexpr int func() { return a; } }; }
