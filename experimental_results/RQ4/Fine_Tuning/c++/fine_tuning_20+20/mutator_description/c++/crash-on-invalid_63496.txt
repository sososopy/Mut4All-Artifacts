Mutation Operator: Introduce Undefined Member in Derived Class Initialization Context: This operator focuses on class members within a derived class, particularly in the context of object initialization. It aims to introduce an undefined member usage that can trigger compiler crashes due to unresolved references. Mutation Rule: 1. Identify a class that inherits from another class or struct. 2. In the derived class, locate the constructor definition. 3. Within the constructor's initializer list, introduce a reference to a member variable that is not declared in the derived class. Example: Consider a derived class `Derived` inheriting from a base class `Base`. Original: ```cpp struct Derived : Base { Derived() : Base() {} }; ``` Mutation: ```cpp struct Derived : Base { Derived() : undefined_member() {} }; ``` In this example, `undefined_member` is not declared in `Derived`. This mutation leverages the initializer list to create an unresolved reference, which can lead to compiler crashes during semantic analysis.
