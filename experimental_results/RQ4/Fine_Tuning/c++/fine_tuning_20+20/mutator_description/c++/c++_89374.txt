mutation Operator: Target: Template Specialization
Steps: 1. Find a template class or struct with partial specialization.
2. If the number of template parameters is greater than 1, set the template parameter list of the specializations to be empty; otherwise, replace the template parameter in the specialization with an int type without introducing a new partial specialization.
Example: 
Before: template<typename T> struct S; template<typename T> struct S<int, T>{}; 
After: template<typename T> struct S; template<> struct S<int, int>{};
