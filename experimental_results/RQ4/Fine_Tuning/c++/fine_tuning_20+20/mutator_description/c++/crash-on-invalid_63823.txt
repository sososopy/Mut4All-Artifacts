Mutation Operator: Template Argument Type Mismatch Target: Template Argument List Mutation Rule: For a given template instantiation, replace a type template argument with a different kind of template argument, such as a non-type or template template argument. This involves identifying a location where a template is instantiated with type arguments and modifying one of those arguments to be a different kind, such as a non-type argument. Pseudo-Code Example: Original: template<class T> void func(); Mutated: template<1> void func();
