Mutation Operator: Modify destructor with constexpr and =default  
Target: Class destructor  
Mutation Rule:  
- Identify a class with a user-defined destructor.  
- Change the destructor to a defaulted destructor by replacing its body with '=default;'.  
- Precede the destructor definition with 'constexpr' to mark it as constexpr.  
- Ensure the destructor remains a class member and retains its access specifier.  
Example:  
Original code:  
class TYPE_NAME {  
public:  
~TYPE_NAME() {  
// Destructor body code  
}  
};  
Mutated code:  
class TYPE_NAME {  
public:  
constexpr ~TYPE_NAME() = default;  
};
