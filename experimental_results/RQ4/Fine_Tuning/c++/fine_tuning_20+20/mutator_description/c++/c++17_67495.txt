Mutation Operator: Invalid Capture in Lambda

Target: Applies to lambda expressions that capture variables.

Mutation Rule: 
1. Identify existing lambda expressions in the seed program that capture variables.
2. Extract existing variable names used in the seed program outside the lambda scope.
3. If there is at least one variable name to choose from, mutate the lambda capture list by randomly selecting a variable name that is not in the lambda scope and adding it to the capture list.

Example:
Original:
bool b = [x, y] { return true; }();
Mutated:
bool b = [x, y, z] { return true; }();
