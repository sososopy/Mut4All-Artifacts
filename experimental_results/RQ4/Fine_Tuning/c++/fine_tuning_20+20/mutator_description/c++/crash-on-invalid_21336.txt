Mutation Operator: Add default argument with uninstantiated inline call

Code Construct: Default argument in a function declaration

Mutation Rule:
1. Select a function that takes arguments.
2. If the function has a default argument, change the default argument to an inline call to a function with the same name as the argument variable and invoke it with parentheses.
3. If the function does not have a default argument, add a new default argument by selecting an argument variable, and construct an inline call to a function with the same name as the argument variable and invoke it with parentheses.

Example:
Before: void f(int k = 0);
After: void f(int k = k());
Before: void f(int k);
After: void f(int k = k());
