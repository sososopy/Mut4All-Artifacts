Mutation Operator: Friend Declaration in Template Class Apply to: Non-member friend in template class Mutation Rule: Add a friend function in a template class using the template parameter as an argument type. Step-by-step: 1. Identify a template class declaration with at least one template parameter. 2. Add a non-member friend function declaration inside the template class. 3. The friend function should accept the template parameter as an argument type. Example: Before: template <typename T> class Y { void f(); }; After: template <typename T> class Y { void f(); friend void fun(T&); };
