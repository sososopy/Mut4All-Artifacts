1. C++ compiler bugs are often triggered by structures involving template specialization, dependent types, and default template arguments. Mutation operators that modify these aspects, such as altering template parameters, changing default arguments, and modifying specialization rules, are more likely to cause compiler bugs. The easiest and widest coverage mutation involves modifying default template arguments and template specialization.

2. Mutation Operator: Modify Default Template Argument in Partial Specialization. Target: Template class or struct with partial specialization having default template arguments. Mutation Rule: Locate a template with a default argument and apply a partial specialization. Modify the default argument to a different type or a dependent type. Example: Given template <typename T1 = int, typename T2 = double> class A {}; Change a partial specialization: template <> class A<int> {}; to template <typename T2 = float> class A<int> {};
