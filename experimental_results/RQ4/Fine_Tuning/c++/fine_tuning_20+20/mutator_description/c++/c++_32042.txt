Mutation Operator: Static Const Template Member

Applicable Context: Inside class/struct with template parameters

Mutation Rule: Add a static const member to a template class/struct.

1. Identify template classes or structs in the code. 2. Within the template class/struct, introduce a static const member. 3. Use a basic type for the static const member, such as `int`. 4. If the static const member is initialized, use a constant expression, such as an integer literal. 5. Ensure that the static const member is defined outside the class/struct if the initialization is complex.

Example: Given a template class/struct `Example` replace it with: 

template <typename T> struct Example { static const int value = 0; };
