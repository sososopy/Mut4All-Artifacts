mutation Operator: Target a range-based for loop. Replace the range expression with a ternary operator construct that returns a non-range type. If the range expression is 'expr', replace it with 'cond ? val1 : val2', where 'val1' and 'val2' are expressions that do not form a valid range for the loop. Example: for (auto &x:a) { } is transformed to for (auto &x: n ? 1 : 2) { }
