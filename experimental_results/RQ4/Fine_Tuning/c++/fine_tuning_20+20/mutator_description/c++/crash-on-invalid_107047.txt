mutation Operator: Enum Function Call Mutation  
Applicable Context: Within any function or method body where a call to a function is made using an enum value.  
Mutation Steps:  
1.Identify a function call that uses an enum value as an argument, ensuring the enum is defined in the scope, the function has been declared or defined in the scope, and the enum value is valid for the function's parameter type or context.  
2.Replace the enum value in the function call with an invalid enumeration member that doesn't exist in the defined enum.  
3.Ensure the invalid enum value is syntactically correct but semantically incorrect within the context, leading to an error during compilation.  
Example:  
Original: auto result = my_function(MyEnum::Value1);  
Mutated: auto result = my_function(MyEnum::NonExistentValue);
