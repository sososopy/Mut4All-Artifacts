
Mutation Operator: Lambda Capture by Reference to Global Variable 1. Locate a global variable or type in the seed program; this can be a global variable, constant, namespace variable, or class static member variable, containing the return type of the lambda function. 2. Identify the nearest enclosing capture-ready lambda function within the current class, struct, or function. This lambda should have a non-void return type and preferably not contain return statements or capture clauses. 3. Add a capture clause [&capturedVariable] to capture the selected global variable by reference. If the lambda already contains a capture clause, append the reference capture to it. 4. Replace all current return statements in the lambda function with return capturedVariable;, using the captured variable as the return value. 5. If the lambda is defined within the context of a class, struct, or union, and the lambda is enclosed in a member function or member function template, ensure that the lambda captures any necessary class members by adding capture clauses for 'this' or specific class member variables. 6. Example: Given a lambda function []() { return 5; } defined within a class member function, transform it to [&globalVariable]() { return globalVariable; } where globalVariable is a compatible global or namespace variable.
