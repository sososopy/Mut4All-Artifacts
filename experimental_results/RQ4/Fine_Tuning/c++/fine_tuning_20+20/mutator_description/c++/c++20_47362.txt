Mutation Operator 1: Modify a template function's return type to 'auto' and omit the trailing return type specification Target: Template function definitions Mutation Rule: Identify a template function with an explicit return type. Change the return type to 'auto' and ensure that any trailing return type specifications are removed. If the function is non-inline and relies on a trailing return type for deduction, the mutation should result in a return type ambiguity. Example: Before mutation: template <typename T> inline T add(T a, T b) { return a + b; } After mutation: template <typename T> inline auto add(T a, T b) { return a + b; }
