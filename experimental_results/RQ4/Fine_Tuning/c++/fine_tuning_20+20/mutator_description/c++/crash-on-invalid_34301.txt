Mutation Operator 1: Target: Structs with variable templates and template template parameters Mutation Rule: 1. Identify a struct with a variable template that employs a template template parameter. 2. Inside the struct, find the variable template definition. 3. Convert the variable template into a class template definition. 4. If the variable template has partial specializations defined, turn these into class template specializations. 5. If there are members inside the variable template, such as static data members, move them inside the class template specializations. 6. Ensure any references to the original variable template adapt to the new class template structure. Example Pseudocode: Before: template<int param> struct some_struct { template <typename T, template <T> param> constexpr int value = 0; template <template <T> param, T> constexpr int value<some_template<T>, some_template> = 1; }; After: template<int param> struct some_struct { template <typename T, template <T> param> struct val { constexpr int value = 0; }; template <template <T> param, T> struct val<some_template<T>, some_template> { constexpr int value = 1; }; };
