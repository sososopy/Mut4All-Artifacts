If it is a member function, change its return type or parameter type to another type; if it is a member variable, change its type to another type. Ensure these types already exist or are appropriately declared in the seed program. Example: Given a template class: template <typename T> class MyClass { public: T memberFunction(T param); }; // explicit specialization template <> int MyClass<int>::memberFunction(int param) { return param; } After mutation: template <typename T> class MyClass { public: T memberFunction(T param); }; // explicit specialization template <> char MyClass<int>::memberFunction(char param) { return param; }
