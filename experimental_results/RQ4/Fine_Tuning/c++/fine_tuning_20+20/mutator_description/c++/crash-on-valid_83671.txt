Mutation Operator: Struct member variable type replacement  
Applicable to: struct definition with member variables  
Mutation Rule:  
1. Select a struct definition in the seed program.  
2. Identify one or more member variables within the selected struct.  
3. Replace the type of the selected member variable with an existing struct type in the seed program.  
4. Ensure the replacement type is compatible with the usage of the member variable.  
Example: Transform struct S1 { int a; }; into struct S1 { S2 a; }; using an existing struct S2 in the seed program.
