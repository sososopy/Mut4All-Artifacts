mutation Operator: Enclosing an assignment statement in a compound statement with an early return statement  Description: This mutation operator targets assignment statements by replacing them with compound statements that include an early return statement. This is particularly effective in triggering bugs when applied in contexts that involve `constexpr` evaluation.  Mutation Steps: 1. Identify an assignment statement, preferably with a simple variable and an integer value, within a function-like context. 2. Replace the assignment statement with a compound statement of the form `({ _replace_with_original_assignment; if (_replace_with_assigned_value) break/continue/return; })`. The choice of break/continue/return depends on the surrounding context, with `return` being most effective in `constexpr` functions. 3. Example: Transform ` x = 1; ` into `({ x = 1; if (x) return; })` when within a `constexpr` function body.
