mutation Operator: Replace the condition of if True if False statements to use the macro directly without parentheses. Apply to: Conditional statements that are using macros with or without parentheses in their conditions. Mutation Rule: Step 1. Locate an if statement with a macro condition. Step 2. If the macro is used with parentheses, remove them. Example: Original code: #define CONDITION true if (CONDITION) { // do something } Mutated code: #define CONDITION true if CONDITION { // do something }
