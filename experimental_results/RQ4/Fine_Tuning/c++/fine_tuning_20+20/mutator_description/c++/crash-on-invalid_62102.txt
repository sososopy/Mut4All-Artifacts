Mutation Operator 1: Invalid Defaulted Comparison in Class

Target: This mutation operator targets class definitions, specifically those with existing member variables and a custom user-defined comparison operator.

Mutation Rule: Select a class that has member variables and a user-defined comparison operator. Add a defaulted comparison operator, such as operator==, to the class definition. Ensure that the defaulted comparison operator does not have any body or custom logic. If there is a user-defined operator==, keep it unchanged.

Example: Original: struct E { bool operator==(const E&); int x; }; Mutated: struct E { bool operator==(const E&) = default; int x; };

Note: The example illustrates the transformation where a user-defined comparison operator is replaced with a defaulted one, while preserving the member variables.
