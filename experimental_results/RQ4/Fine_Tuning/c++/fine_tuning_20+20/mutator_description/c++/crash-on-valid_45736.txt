mutation Operator: Target: Function Definition for Mutating Function Body: Add Statement Mutation Rule: In the body of a function definition, after the opening brace, insert a call to the function itself with appropriate arguments (or empty if none). Handle potential recursion and infinite loop by ensuring the call is safe. Example: Original: ``` void func(int a) { int x = a + 1; } ``` Mutated: ``` void func(int a) { func(a); int x = a + 1; } ```
