Mutation Operator: Default Argument in Template Instantiation Target: This mutation operator specifically targets function declarations or definitions that have a parameter with a default argument. Mutation Rule: 1. Identify a function template in the code (e.g., template <typename T> void func(T var)). 2. Add a parameter to this function with a default argument (e.g., template <typename T> void func(T var, int num = 10)). 3. Ensure that the function is instantiated in the code by calling it (e.g., func(5)). Example: Original: template <typename T> void func(T var) { } func(5); Mutated: template <typename T> void func(T var, int num = 10) { } func(5);
