mutation Operator: Modify the linkage of inline namespaces Description: This mutation operator targets inline namespaces and modifies their linkage to trigger bugs related to linkage inconsistencies. Target: Inline Namespace and Linkage Specification Mutation Rule: 1. Locate an inline namespace in the code. If an inline namespace is not present, create one using the syntax 'inline namespace { }'. 2. Determine the desired linkage for the inline namespace. Choose one of the valid linkage types: 'internal', 'external', or 'inline'. 3. Modify the linkage of the inline namespace by specifying the chosen linkage type. Replace the inline namespace declaration with the modified linkage specification. Example: Before Mutation: inline namespace A { void func(); } After Mutation: inline namespace B { void func(); }
