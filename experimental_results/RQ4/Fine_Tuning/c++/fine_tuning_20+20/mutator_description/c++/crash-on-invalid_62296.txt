mutation Operator: Target: Access specifier in class or struct. Mutation Rule: 1.Identify a class or struct definition. 2. Convert any existing access specifier (public, private, protected) to an invalid specifier, such as “internal” or one that is empty. 3.If no access specifier is present, add an empty one at the top of the class or struct. Example: class X { public: void f(); }; Mutated: class X { internal: void f(); };
