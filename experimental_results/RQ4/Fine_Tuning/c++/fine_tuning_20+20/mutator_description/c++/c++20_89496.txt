mutation Operator: Target: Lambda function inside a function or class Method. Mutation Rule: 
1. Identify the lambda function inside a function or class method. 2. Replace the lambda function with an immediately invoked lambda expression. 3. Remove the lambda call after replacing it with an immediately invoked lambda. Example: Before mutation: auto lambda = [&](auto from, auto to) -> Foo { for (auto it = from; it != to; ++it) {} return Foo(); }; lambda(vec.rbegin(), vec.rend()); After mutation: [&](auto from, auto to) -> Foo { for (auto it = from; it != to; ++it) {} return Foo(); }(vec.rbegin(), vec.rend());
