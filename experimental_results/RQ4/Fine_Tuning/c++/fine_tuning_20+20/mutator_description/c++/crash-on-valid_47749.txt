mutation Operator: Enum Redefinition in Template Class Context
Applicable scenario: Target seeds have templated class definitions with nested enum declarations.
Mutation rule: Identify a class template with a nested enum declaration. Introduce a new class template with a distinct name. Within this new template class, declare an enum with the same name and enumerators as the original enum.
Example: Given a templated class with a nested enum, such as: template <typename T> class MyClass { enum class Color { Red, Green, Blue }; }; Transform it into: template <typename T> class MyClass { enum class Color { Red, Green, Blue }; }; template <typename U> class AnotherClass { enum class Color { Red, Green, Blue }; };
