mutation Operator: Target: This operator targets function definitions within a class or struct template. It specifically focuses on member functions to modify their body content. Mutation Rule: Identify a member function within a template class or struct. Replace the function body with a statement that performs an unqualified lookup for a dependent base class member. Use 'this->*' syntax to cast and call a member function of an undeclared dependent base class. Example: Original: ```cpp bool CheckValid() const { return true; } ``` Mutated: ```cpp bool CheckValid() const { return (this->*static_cast<bool (DependentBase::*)()const>(&DependentBase::CheckValid))(); } ```
