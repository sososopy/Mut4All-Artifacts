Mutation Operator: Replace forward declaration of an unscoped enum with a definition and a conversion function to a type other than the specified type  
Target: Forward enum declaration followed by static_assert with a trait expecting a complete type  
Mutation Description: Identify a forward declaration of an unscoped enum with a specified underlying type. Replace it with a complete definition of the enum, including at least one enumerator. Add a conversion function for the enum type to a type that is different from the specified underlying type.  
Example:  
Original: enum E : bool; static_assert(!std::is_function<E>::value, "" );  
Mutated: enum E : bool {Y=0,N=1}; operator int(E e){return (int)e;} static_assert(!std::is_function<E>::value, "" );
