Mutation Operator 1: Builtin Function Argument Invalidation Target Construct: Builtin Function Calls Mutation Rule: 1. Identify all builtin function calls in the code. These typically start with a double underscore followed by 'builtin', such as __builtin_fpclassify. 2. Randomly select a builtin function call. 3. Randomly select one of its arguments. 4. Replace the selected argument with an invalid argument. For example, if the argument is an integer, replace it with a known undefined or invalid expression. Example: Consider a function call __builtin_fpclassify(x1, x2, x3, x4, x5, x6); A mutated version could be __builtin_fpclassify(x1, x2, x3, x4, x5, x6 + x6 + x6);
