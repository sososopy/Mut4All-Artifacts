mutation Operator: Deduction Guide Misplacement This operator targets class templates and their deduction guides. It involves incorrectly placing the deduction guide that should normally appear within the class template to instead appear outside of it. This mutation is particularly applicable to C++17 and later versions, as it deals with class template argument deduction. To perform this mutation, follow these steps: Identify a class template in the code that uses C++17 deduction guides. Locate the deduction guide within the class template that specifies how template arguments should be deduced from constructor arguments. Remove the deduction guide from its original position inside the class template. Re-insert the deduction guide outside of the class template, at the global scope or in a different enclosing namespace or class. For example, given a class template definition like template <typename T> struct MyTemplate { MyTemplate(T) { } MyTemplate(int) -> MyTemplate<int>; // deduction guide }; remove the deduction guide MyTemplate(int) -> MyTemplate<int>; from inside the class template and re-insert it outside, like this: template <typename T> struct MyTemplate { MyTemplate(T) { } }; MyTemplate(int) -> MyTemplate<int>; This relocation of the deduction guide can trigger compiler errors or crashes, especially if the compiler does not correctly handle deduction guides defined outside their associated class templates.
