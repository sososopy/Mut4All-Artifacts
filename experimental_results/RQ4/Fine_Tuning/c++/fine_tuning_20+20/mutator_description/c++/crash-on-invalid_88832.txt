Mutation Operator: Template Instantiation with Non-Type Parameters
Target Structure: Template instantiation with non-type parameters
Mutation Rule:
1. Identify a class or struct template with a non-type parameter.
2. Instantiate the template using an expression or value that is not a valid non-type argument for the template.
3. Ensure the instantiated template is used in a context that requires full instantiation, such as a static member access or a typedef.
Example:
Original: 
template <typename T> struct S { 
  using X = T; 
};
struct A { using Y = S<int>; };
Mutated: 
template <typename T> struct S { 
  static const T w = 0; 
};
struct A { using Y =S<int>::w; };
