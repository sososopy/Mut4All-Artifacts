Summary: The bug is triggered by partial specialization in variable templates with template template parameters. A common pattern to target here is the use of nested templates, especially involving template template parameters and partial specializations.

Mutation Operator: Target instances of template template parameters within templates. Replace a simple template template parameter with a more complex nested template or partial specialization. Example: If a template template parameter is defined simply as 'template <typename T> class container', mutate it to a nested version like 'template <typename T> class container' where inside container you have another template or a partial specialization.
