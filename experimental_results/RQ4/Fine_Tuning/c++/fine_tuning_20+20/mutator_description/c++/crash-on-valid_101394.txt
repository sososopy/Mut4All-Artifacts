Mutation Operator: Trigger assertion on invalid template parameter by altering template definition

Target: Template instantiation

Mutation Rule: Identify the instantiation of a template parameterized with another template, and alter the inner template's parameter type to an incompatible type.

Example: Locate `template struct A<B>;` and mutate it into something like `template struct A<C>;` where `C` is an incompatible type, e.g., `template<int I> struct C;`
