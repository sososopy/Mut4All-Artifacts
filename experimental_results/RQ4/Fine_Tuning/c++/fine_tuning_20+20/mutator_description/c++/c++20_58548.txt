mutation Operator: Template Non-type Parameter Usage Replacement in Function Call. Target: function call statements with template non-type parameter arguments. Mutation Rule: Identify calls to a function template with a non-type template parameter, replace the parameter usage with a cast or literal matching the expected argument type. Example: Replace a call to a function template like 'func<ConstexprVar>()' with 'func<static_cast<int>(ConstexprVar)>()' or 'func<42>()', ensuring type consistency.
