Mutation Operator: Replace a variable in a constexpr function with an undeclared variable
Applicable Code Construct: constexpr function
Mutation Rule: Select a variable used in the function body, such as condition of statement or right value of assignment, and replace this variable with an undeclared new variable.
Example: constexpr T func(T x, T y) { if(x==1){return x;} return x+y; } After Mutation: constexpr T func(T x, T y) { if(z==1){return x;} return x+y; }
