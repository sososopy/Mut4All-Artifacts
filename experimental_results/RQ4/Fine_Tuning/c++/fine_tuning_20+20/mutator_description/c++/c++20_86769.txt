Mutation Operator: Concept Reverse Logic

Target: Concept definition

Rule: Identify a concept definition, which usually begins with the keyword `concept` followed by a name and a requirement. Reverse the boolean logic used in the requirement of the concept. If the requirement is `true`, change it to `false`, and vice versa.

Example: Original: `template<typename T> concept X = true;` Mutated: `template<typename T> concept X = false;`
