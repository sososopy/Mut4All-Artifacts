mutation Operator 1: Target construct: Template function (or member function of a class template) with trailing return type. Mutation rule: Locate a template function (or member function of a class template) with a trailing return type using the 'auto' keyword. Replace the trailing return type with 'decltype(auto)'. Example: Original: template <typename T> auto foo(T t) -> decltype(t) { return t; } Mutated: template <typename T> decltype(auto) foo(T t) { return t; }
