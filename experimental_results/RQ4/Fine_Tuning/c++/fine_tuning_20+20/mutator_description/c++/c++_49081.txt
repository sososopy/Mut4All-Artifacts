Template using declaration The mutation operator designed based on this bug report is: Mutation Operator 1 Type: Generic Lambda Argument Explanation: This mutation operator targets generic lambda expressions with integer template parameters and aims to replace the lambda's argument with a constant integer. Steps: 1. Identify a generic lambda expression within a function template that is instantiated with an integer parameter. Look for a lambda argument of type 'auto'. 2. Replace the lambda's auto parameter with an integer constant expression, such as directly using a template parameter. 3. Use a constexpr variable or any known integer constant within the lambda body to maintain valid C++ syntax. Example: Transform auto lambda = [](auto arg) -> bool { return arg == 0; }; into auto lambda = []() -> bool { return constexpr_int_variable == 0; };
