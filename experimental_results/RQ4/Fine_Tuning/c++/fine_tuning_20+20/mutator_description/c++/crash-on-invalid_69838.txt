Mutation Operator: Transform Constructor Self Parameter into Member Function

Target: Constructor in a class or struct definition.

Mutation Rule:
1. Identify the constructor declaration within a class or struct that uses an explicit object parameter, typically indicated by 'this' followed by the parameter type and name, such as 'this auto &self'.
2. Change the constructor's name to a valid identifier that matches the class or struct name to make it a member function.
3. Retain the self parameter as the first parameter of the transformed function.
4. Ensure the function body remains intact, adjusting any references to the self parameter as needed.

Example:
Before: struct S { S(this auto &self) {} };
After: struct S { void member(this auto &self) {} };
