Mutation Operator: Constexpr Function to Return Lambda

Target: Modify a constexpr function to return a lambda function. This targets functions that compile-time evaluate and return a fixed value or expression.

Mutation Rule: 
1. Locate a constexpr function in the seed program that returns a statically evaluatable expression or value.
2. Replace the return statement with a lambda function that captures necessary variables and performs the same computation.
3. Ensure that the lambda captures are consistent with the original function parameters and any local variables used in the computation.
4. Include any necessary headers, such as <utility>, for std::index_sequence if not already included.

Example: 
Original: consteval auto transform_array(const auto &arr, auto func) { return func(arr); } 
Mutation: consteval auto transform_array(const auto &arr, auto func) { return [&arr, func ]<std::size_t... Is>(std::index_sequence<Is...>) { return arr[Is]; } (std::make_index_sequence<arr.size()>()) }
