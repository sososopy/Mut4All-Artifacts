Mutation Operator: This mutation operator targets concept definitions and concept usages in template parameters. Apply it by selecting a concept definition and terminating its associated expression with a semicolon without specifying a constraint expression.

Step-by-Step Mutation Rule: a. Locate a concept definition in the code. b. If the concept has an associated constraint expression, replace the expression (including any trailing semicolon) with a single semicolon. c. Ensure that any use of the concept in template parameters remains unchanged. d. If multiple concepts are present, consider applying the mutation to more than one to increase the likelihood of triggering a compiler crash.

Example: Original: template <typename T> concept C = sizeof(T) == 8; template <C T> struct S; Mutated: template <typename T> concept C; template <C T> struct S;
