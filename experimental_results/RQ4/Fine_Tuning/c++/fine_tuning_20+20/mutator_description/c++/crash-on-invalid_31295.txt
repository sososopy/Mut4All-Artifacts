### Mutation Operator: Struct and Union Member Reordering

#### Target Construct:

Struct and Union Member Definitions

#### Mutation Rule:

1. Identify all struct and union member definitions within the source code.
2. Randomly reorder the member definitions within each struct and union, ensuring that all members are still present but in a different sequence.

#### Example:

Given a struct definition like the following:

```cpp
struct ExampleStruct {
    int firstMember;
    double secondMember;
    char thirdMember;
};
```

The mutated version might look like:

```cpp
struct ExampleStruct {
    char thirdMember;
    int firstMember;
    double secondMember;
};
```
