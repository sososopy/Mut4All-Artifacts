Mutation Operator: Template Parameter Type Removal
Description: This mutation operator focuses on modifying template declarations by removing the template parameter list.

Step-by-Step:
Identify any template declaration in the code, such as class templates, function templates, alias templates, or variable templates.
Remove the entire template parameter list, including the template keyword and angle brackets.
Example:
Before:
template <typename T> class MyClass {};
After:
class MyClass {};
