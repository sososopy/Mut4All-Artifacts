Mutation Operator 1: Add Fold Requires Expression to Variable or Return Type - Target: Variable or Function - Find a variable declaration or a function definition. Check the type of the variable or the return type of the function. - If the type is already a fold requires expression, skip this mutation. - For a variable, replace the type with a fold requires expression that evaluates a constraint on a parameter pack. - For a function, replace the return type with a fold requires expression that evaluates a constraint on a parameter pack. - Example: For a variable, transform ‘type name = expression;’ into ‘auto name = requires requires_expression;’. For a function, transform ‘type foo() { return expression; }’ into ‘auto foo() { return requires_expression; }’.
