mutation Operator: Extract Template Lambda with Attribute
Applies to: Lambda expressions with attributes inside function templates. Mutation Rule: 1. Identify a function template that contains a lambda expression with attributes, such as [[noreturn]], __attribute__((pcs("aapcs-vfp"))), etc. 2. Extract the lambda expression outside of the function template into a standalone, templated lambda function. 3. Replace the original lambda with a call to the new standalone, templated lambda function. 4. If the standalone lambda function requires template parameters, ensure they match the original function template’s parameters and use them accordingly. Example: Original code: template <typename T> void foo() { auto l = []() __attribute__((pcs("aapcs-vfp"))) {}; } Extracted code: template <typename T> auto l = []() __attribute__((pcs("aapcs-vfp"))) {}; template <typename T> void foo() { l<T>(); }
