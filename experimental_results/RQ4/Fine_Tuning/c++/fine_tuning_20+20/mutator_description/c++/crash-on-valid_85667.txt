Mutation Operator: Nested Lambda with Fold Expression
Target Construct: Lambda expression inside a templated context.
Mutation Rule: Identify any instance of a lambda function within a templated entity. Inside this lambda, introduce a fold expression that captures a parameter pack from the enclosing template. Ensure the lambda is called with a specific set of template arguments.
Example: Original: `template<typename... Args> void f() { auto lambda = [](){}; }` Mutated: `template<typename... Args> void f() { auto lambda = []<Args...>() { ([x = Args{}]..., ); }; lambda.template operator()<int, double>(); }`
