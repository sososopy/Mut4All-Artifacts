Mutation Operator: Replace a lambda with a block when a non-static local variable is captured by a lambda without an explicit 'mutable' keyword

Context: This mutation operator targets lambda expressions within a function body that capture non-static local variables without an explicit 'mutable' keyword.

Mutation Rule:
1. Identify lambda expressions within a function body that capture non-static local variables without specifying 'mutable'.
2. Replace the lambda expression with a block expression.
3. Ensure captured variables are accessible within the block.

Example: Consider a function with a lambda capturing a non-static local variable:

void exampleFunction() {
  int x = 42;
  auto lambda = [x]() { return x; };
  lambda();
}

After applying the mutation, the code becomes:

void exampleFunction() {
  int x = 42;
  auto block = ^{ return x; };
  block();
}
