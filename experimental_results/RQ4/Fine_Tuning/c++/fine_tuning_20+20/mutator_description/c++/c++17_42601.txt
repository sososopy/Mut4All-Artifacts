Mutation Operator 1 Target: Apply to any function in the code. Mutation Rule: Add a lambda function within the body of the existing function. The lambda function should be defined using the auto keyword and should capture all variables by reference. For example, if the original function has a simple statement like return a; you can mutate it to auto lambda = [&]() { return a; }; return lambda(); This transformation can be applied inside any function in the seed program.
