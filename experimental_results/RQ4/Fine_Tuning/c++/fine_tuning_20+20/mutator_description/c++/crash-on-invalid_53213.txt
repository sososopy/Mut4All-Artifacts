Mutation Operator: Purpose: to trigger crashes by manipulating concepts with requires expressions and invalid instantiations. Applicable Scope: applicable to concepts with requires expressions defined in the seed program. Mutation Rule: 1. Identify all concepts in the seed program that have requires expressions. 2. Select one of the identified concepts for mutation. 3. Replace one of the requirements in the requires expression with a call to an undeclared function 'f'. Ensure the function invocation passes the concept parameter to 'f'. 4. Retain the original declaration of the concept after mutation. 5. Construct a function template for a function named 'f' that accepts a concept parameter. Use auto to deduce the parameter type. 6. In the function body, return the concept parameter. 7. Ensure the mutated concept, undeclared function 'f', and function template 'f' are in the global scope. Pseudo-code Example: Before mutation: template<typename T> concept C = requires(T t) { t.m(); }; After mutation: template<typename T> concept C = requires(T t) { f(t); }; auto f(C auto);
