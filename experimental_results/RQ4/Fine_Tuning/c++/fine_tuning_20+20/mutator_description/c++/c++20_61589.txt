mutation Operator: Target the template function that accepts a generic lambda as a parameter. Rule: Replace the generic lambda parameter with a non-generic lambda. Specifically, in the template function that invokes a generic lambda, modify the parameter list of the lambda to explicitly specify the types of the arguments instead of using auto. Example: Replace a lambda parameter like [](auto&&... args) with [](Type1&& arg1, Type2&& arg2) where Type1 and Type2 are actual types deduced or specified in the context.
