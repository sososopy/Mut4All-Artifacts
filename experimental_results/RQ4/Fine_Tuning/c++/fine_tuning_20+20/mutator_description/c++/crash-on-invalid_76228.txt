Mutation Operator: Add Empty Member Access in Struct Method Body

Target: This mutation targets class or struct method bodies.

Mutation Rule: Select a class or struct method. Inside the method body, insert an empty member access (e.g., `object_name.{};`) using a valid object of an existing class or struct.

Example: Original Code: struct A { int x; }; struct B { void foo() {} }; Mutated: struct A { int x; }; struct B { void foo() { A().{}; } };
