mutation Operator: Template Instantiation with Invalid Using Directive Target: Template and Using Directive Mutation Rule: 1. Identify a using directive that defines an alias for a template instantiation. 2. Replace the target of the using directive with an invalid or undeclared type or template instantiation. 3. Ensure the replacement is syntactically valid but semantically incorrect to trigger invalid template instantiation. Example: Original: template <typename T> using MyType = std::vector<T>; Mutated: template <typename T> using MyType = std::vector<UnknownType>;
