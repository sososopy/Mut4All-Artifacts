mutation Operator: Template Scoped Static Argument Mutation Target: Apply this to any template instantiation in the code, particularly those using scoped static variables. Mutation Rule: Locate a template instantiation that uses a scoped static variable as a template argument. Change the static variable to a regular global or local variable. Example: Original: auto bar = join_v<scoped_static>; Mutated: auto bar = join_v<global_variable>;
