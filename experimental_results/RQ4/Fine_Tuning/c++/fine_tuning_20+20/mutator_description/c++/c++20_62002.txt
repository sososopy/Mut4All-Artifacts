mutation Operator: Change a consteval constructor to initialize a constinit object within the constructor.

Explanation: This mutation targets struct definitions with consteval constructors, specifically those involving constinit objects. It aims to provoke the constant expression interpreter by modifying initialization patterns.

Mutation Steps:

1. Locate a struct with a consteval constructor. Ensure it contains at least one constinit object declaration.
2. Inside the consteval constructor, instead of directly initializing the constinit object using inline initialization, perform the initialization within the constructor body.
3. If the object was initialized inline, remove the inline initialization expression and transfer it to the constructor body.
4. For example, a struct with consteval constructor and inline initialized constinit object should be transformed into a constructor-initialized form:

Example: Before mutation:
struct S {
  consteval S() {
    x = /* initialization expression */;
  }
  constinit int x;
};

After mutation:
struct S {
  consteval S() : x(0) {}
  constinit int x;
};
