Mutation Operator: Target a class template and replace its body with the definition of a union containing a non-trivial class. 

Change a class template's body to a union containing a non-trivial class, which can be a class with user defined constructors, destructors, or copy constructors, depending on the context. 

Example: template <typename T> class A {}; -> template <typename T> union A {class B {B(){} }; };
