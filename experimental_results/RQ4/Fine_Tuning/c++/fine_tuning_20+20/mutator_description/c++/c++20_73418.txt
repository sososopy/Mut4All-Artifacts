Mutation Operator: Nested Lambda with Requires Clause

Rule: Identify any nested lambda expression within the code. Within the innermost lambda, introduce a requires clause that checks a property or method of the argument using a pack expansion. 

Example: Given code with a nested lambda expression: return [](auto obj, auto... params) { return false; }(y); Transform it into a requires expression like: return [](auto obj, auto... params) requires requires { obj.size(params...); } { return false; }(y);
