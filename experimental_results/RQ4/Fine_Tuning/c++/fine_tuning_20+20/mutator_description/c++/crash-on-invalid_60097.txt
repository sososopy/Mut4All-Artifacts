mutation Operator: Target: Apply to function template definitions using concepts. Mutation rule: For each function template that uses a concept in its parameter list, replace the concept parameter with a type parameter that has the same name as the concept. Example: Original: template <typename T, typename U> concept C = true; template <typename T> auto foo(C<T> auto param) -> void; Mutated: template <typename T, typename U> concept C = true; template <typename T> auto foo(T param) -> void;
