Mutation Operator: Insert generic lambda in generic lambda  
Description: This mutation operator targets lambda expressions and focuses on inserting a generic lambda expression within another generic lambda.  
Mutation Rule: Locate a non-generic lambda expression within the code. Modify its parameter list to include a template parameter, converting it into a generic lambda expression. Inside this newly created generic lambda, introduce another generic lambda expression by specifying a template parameter within its parameter list.  
Example:  
Original code: auto l = []{};  
After applying the mutation: auto l1 = [](auto a) {auto l2 = [](auto b) {}};
