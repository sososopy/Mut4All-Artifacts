Mutation Operator: Partial Specialization Violation in Template Structures

Target: Template structures with partial specializations.

Description: For a given template structure with partial specialization, modify the partial specialization to not use any of its template parameters. This can trigger errors by violating the requirement that a partial specialization must depend on its template parameters.

Example:
Given a template structure.
```
template <typename T>
struct MyStruct;

template <typename U>
struct MyStruct<int> {};
```
Mutate the partial specialization to not use any of its template parameters.
```
template <typename U>
struct MyStruct<int> {}; // Partial specialization does not use its parameter 'U'
```
