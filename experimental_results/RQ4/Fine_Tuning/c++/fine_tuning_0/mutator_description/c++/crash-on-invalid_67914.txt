Mutation Operator: Partial Specialization with Template Parameters

Target: Struct partial specialization

Mutation Rule: 
1. Identify a partially specialized struct template in the code.
2. Modify the specialization to replace one of the template parameters with a concrete type, leaving the other parameters as-is.
3. Ensure the partially specialized struct uses some of its template parameters, but not all.

Example: Transform a struct partial specialization like ‘struct StaticArrayImpl< int, 16, 1, Mask< int, 16 > > {...};’ to ‘struct StaticArrayImpl< int, 16, 1, Mask< int, 16 > > : KMaskBase< Derived_ > {};’ by replacing a template parameter with a concrete type.
