Mutation Operator: Struct Template Specialization

Target: This mutation applies to template structures with at least one specialization.

Mutation Rule: 

1. Identify a template struct with at least one specialization in the seed code.
2. Locate one of the specializations of this template struct.
3. Duplicate the specialization and change its template argument(s) to form a new specialization.
4. Ensure that the new specialization argument(s) are valid types or values in the context of the seed program.

Example: Consider a template struct `template <typename T> struct MyStruct {};` with a specialization `template <> struct MyStruct<int> {};`. Duplicate this specialization and modify its argument to create a new specialization, e.g., `template <> struct MyStruct<double> {};` or use another existing type in the program to form the new specialization.
