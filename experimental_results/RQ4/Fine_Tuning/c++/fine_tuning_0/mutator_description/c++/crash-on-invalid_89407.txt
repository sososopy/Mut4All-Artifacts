Mutation Operator: Modify the return type of a constexpr function to a signed integer type and return a negative value within that function. Applicable Location: Inside a struct or class where a constexpr function is defined. Mutation Rule: 1. Identify a constexpr function with a return type of unsigned integer, such as size_t, uint32_t, etc. 2. Change the return type to a signed integer type of the same width, e.g., change size_t to ssize_t, uint32_t to int32_t, etc. 3. Modify the return statement in the function body to return a negative integer value, ensuring that it fits within the signed range of the new return type. Example: Original: constexpr __SIZE_TYPE__ size() const { return 10; } Mutated: constexpr ssize_t size() const { return -1; }
