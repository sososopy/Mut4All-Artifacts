Mutation Operator: Nested Template Class Instantiation  
- Target Construct: Nested classes within a template class.  
- Mutation Rule:  
  a. Identify a template class in the seed program.  
  b. Within the template class, define a nested class (let's call it NestedClass).  
  c. Inside NestedClass, add a static member function that returns an instance of NestedClass.  
  d. In the global scope or within another function, instantiate the outer template class and call the static member function of NestedClass.  
- Example:  
  Before Mutation:  
  ```cpp  
  template <typename T>  
  class OuterClass {  
  // Original content  
  };  
  ```  
  After Mutation:  
  ```cpp  
  template <typename T>  
  class OuterClass {  
    class NestedClass {  
      static NestedClass createInstance() {  
        return NestedClass();  
      }  
    };  
  };  
  OuterClass<int>::NestedClass::createInstance();  
  ```
