Mutation Operator: Target: Template instantiation within function bodies. Mutation Rule: Within a function definition, identify any instantiation of a templated type using a type alias, especially when the alias involves default template arguments. Modify the instantiation to utilize a concept constraint directly on the template parameter, similar to 'Constraint<T> auto'. If no such instantiation exists, create one by declaring a type alias with a default template argument for a templated type that has a constrained constructor, and then instantiate this alias with an argument that satisfies the constraint.
