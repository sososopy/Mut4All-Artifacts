Mutation Operator: Target: Struct Declarations within Functions. Rule: Within a function body, declare a struct without defining it by omitting the body, immediately followed by redefining the same struct with a new body. Instruction: Identify a function definition. Within the function body, declare a struct with just the name (e.g., struct A;). Follow this declaration by redefining the same struct with a new body (e.g., struct A { int x; };). Example: Original: void foo() { int x = 0; } Mutated: void foo() { int x = 0; struct A; struct A { int x; }; }
