Mutation Operator: Variadic Template Argument Duplication

Target Construct: This mutation targets variadic template classes or functions. It specifically modifies the template argument list passed to a variadic template instantiation.

Mutation Rule: Identify a variadic template instantiation in the code, either a class or a function. Duplicate one of the variadic arguments in the template argument list.

Example:

Original Code:
template<typename... Args>
struct A {};

A<int, double> a;

Explanation: The mutation operator duplicates the last template argument in the variadic argument list.
