Mutation Operator: Recursive Template Instantiation

Target: This mutation operator targets template structures, specifically those that can be recursively instantiated.

Mutation Rule: Identify a template that can be instantiated recursively. Introduce a higher level of nested instantiation by modifying the template arguments to include a more complex type that is defined using the same template. Ensure that the recursion depth is increased in a controlled manner to trigger compiler stress without causing infinite recursion.

Example: Suppose there is a template defined as template <int N, typename T> struct MyTemplate; and it is instantiated as MyTemplate<0, int>. Change the instantiation to MyTemplate<0, MyTemplate<0, int>> to increase the recursive depth. If the template is already instantiated recursively, increase the depth by one more level. Ensure that the base case for recursion remains reachable to avoid infinite recursion during compilation.
