mutation Operator: Insert a Lambda Expression within a Lambda
Target: Lambda expressions
Mutation Rule: Take an existing lambda expression and insert a new lambda expression within it.
Procedure:
1. Identify an existing lambda expression in the seed program.
2. Within the body of this lambda, insert a new lambda expression capturing the same variables as the enclosing lambda.
3. The inner lambda should perform a simple operation (e.g., return a constant or print a message).
4. Ensure the inner lambda is invoked immediately or stored in a variable for later use.
Example:
Before mutation:
auto outerLambda = [](int x) { return x * x; };
After mutation:
auto outerLambda = [](int x) { auto innerLambda = [=] { return 42; }; return innerLambda(); };
