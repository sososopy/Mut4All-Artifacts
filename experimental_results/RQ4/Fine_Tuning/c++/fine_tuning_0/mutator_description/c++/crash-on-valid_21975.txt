Mutation Operator:

Target: Function Parameters and Declarations

Step-by-step Mutation Rule: Identify any function declaration or definition in the seed program. Select a parameter within the function. Replace the selected parameter's type with a pointer to a forward-declared struct. If a forward-declared struct is not already present, introduce one at the global scope by declaring `struct StructName;`, where `StructName` is a unique identifier not currently used in the seed program. Example: Given a function `void foo(int a)` in the seed program, mutate it to `void foo(StructName* a)` and ensure `struct StructName;` is declared before this function. This mutation leverages the parser's sensitivity to forward declarations and pointer semantics to induce potential compiler crashes.
