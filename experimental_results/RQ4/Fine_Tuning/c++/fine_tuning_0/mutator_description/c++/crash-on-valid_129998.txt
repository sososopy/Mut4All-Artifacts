mutation Operator: Template Alias Instantiation Without Specifying All Template Parameters
Description: This mutation targets template alias declarations. It involves omitting some template parameters when instantiating a template alias, particularly when default template arguments are provided.
Mutation Rule: 1. Identify a template alias declaration that involves templates with multiple parameters. 2. Check if the template alias has default arguments for some of its parameters. 3. Instantiate the template alias without specifying all the template parameters, leaving out those with default arguments. 4. Ensure that the omitted parameters can be deduced from the context or have default values. Example: Given a template alias: template <typename T, typename U = int> using MyAlias = std::pair<T, U>; Apply the mutation by instantiating MyAlias with only one parameter: MyAlias<double> myVar; Here, the second parameter is omitted, relying on its default value.
