mutation Operator: Target: Union Initialization using Designated Initializers. Apply when there is a union with multiple members, especially if they are of different types. Mutation Rule: 1. Locate a union declaration with multiple members. 2. Identify if the union is initialized using designated initializers. 3. If the union is initialized, add an additional initializer using a different member than the one already initialized. 4. Ensure that the initializer type matches the member type. Example: Original Code: union U { int x; float y; }; U u = {.x = 1}; Mutated Code: union U { int x; float y; }; U u = {.x = 1, .y = 2.0};
