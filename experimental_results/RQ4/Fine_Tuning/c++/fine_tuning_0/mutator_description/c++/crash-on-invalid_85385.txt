mutation Operator: Template Aliases with Invalid CTAD
Target: Template type alias with template template parameters.
Mutation Rule: Identify a template type alias that uses a template template parameter. In the instantiation of this alias, use class template argument deduction (CTAD) with an invalid or incomplete set of arguments. Specifically, provide fewer arguments than the template expects or arguments that cannot be deduced from the context. For example, if the alias requires two template parameters, provide only one non-type argument. 
Example: Given a template alias 'template <typename C, template<typename> typename TTP> using Bar = Foo<C, K<TTP>>', instantiate it with 'Bar(1)' instead of 'Bar<int, SomeTemplate>', where 'SomeTemplate' is a valid template template argument.
