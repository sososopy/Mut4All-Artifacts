Mutation Operator: Target a lambda expression that captures a variable by reference. Modify it to capture the variable by value instead. If the variable being captured is of an incomplete or invalid type, this change can exploit the compiler's handling of type checking and size calculations, potentially exposing vulnerabilities related to invalid declarations and triggering crashes. Example: Given a lambda expression `[&x]() { ... }`, where `x` is a reference to an incomplete type, mutate it to `[x]() { ... }`. This change forces the compiler to evaluate the size and layout of `x`, which can lead to assertion failures if `x` is not fully defined or has an ill-formed type.
