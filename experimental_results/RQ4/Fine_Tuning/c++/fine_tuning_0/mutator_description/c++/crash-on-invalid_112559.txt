mutation Operator: Apply to the return statement within a function that returns an instance of a template-based struct. Mutation Rule: 1. Identify the return statement in a function that returns an instance of a struct templated on the same struct. 2. Replace the entire return statement with an expression that constructs the same templated struct using the function's receiver. 3. Ensure the expression is enclosed in braces. Example Before: constexpr operator Wrap<S> (this const S& self) { return { }; }; After: constexpr operator Wrap<S> (this const S& self) { return Wrap<S>{self}; };
