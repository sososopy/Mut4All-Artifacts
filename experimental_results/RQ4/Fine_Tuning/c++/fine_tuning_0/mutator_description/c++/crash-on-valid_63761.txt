Mutation Operator: Replace a constexpr function with a non-constexpr function Definition: Identify any function defined with the constexpr specifier in the source code. Mutation: Remove the constexpr specifier from the function definition, converting it to a regular non-constexpr function. Example: Original: constexpr int add(int a, int b) { return a + b; } Mutated: int add(int a, int b) { return a + b; }
