Mutation Operator 1: Target Function Templates with Constraints

Target: Function Templates with Constraints

Mutation Rule:
1. Identify a function template with constraints using concepts.
2. In the template parameter list, remove or modify the constraints by replacing the concept with a more general or unrelated concept.
3. Ensure the template instantiation in the code violates the original constraint but satisfies the mutated constraint, leading to unexpected behavior or compiler issues.

Example Mutation:
Original: template<typename T> requires std::integral<T> void func(T val) {}
Mutated: template<typename T> requires std::same_as<T, int> void func(T val) {}
