Mutation Operator: Struct Member Function Template Specialization

Target Code Construct: Struct with member function templates

Mutation Rule: 

1. Identify a struct with a member function template that has an explicit specialization.
2. Add a new member function template with a different parameter type or value.
3. Create an explicit specialization for the new member function template.
4. In this specialization, use a lambda function or another complex construct that is different from the original member function template specialization.

Example: 

Original Code:
template<class T> struct S {
  template<int> auto foo();
  template<> auto foo<1>() {
    return [](auto x) { return x; };
  }
};

Mutated Code:
template<class T> struct S {
  template<int> auto foo();
  template<> auto foo<1>() {
    return [](auto x) { return x; };
  }
  template<int> auto bar();
  template<> auto bar<2>() {
    return [](auto y) { return y + 1; };
  }
};
