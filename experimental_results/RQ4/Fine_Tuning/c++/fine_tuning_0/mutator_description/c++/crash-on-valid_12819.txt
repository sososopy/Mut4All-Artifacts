
Mutation Operator: Modify Function Return Type
Target: Functions in the seed program
Mutation Rule: 
1. Identify a function with a non-void return type.
2. Change the return type of the function to a different existing type (e.g., change int to float or any other existing type in the program).
3. Ensure that the return statement within the function is also modified to return a value of the new type. Use existing variables or literals of the new type if available. If not, declare a new variable of the new type within the function to be returned.
4. Ensure that all calls to the modified function are updated to handle the new return type appropriately, either by storing the return value in a variable of the correct type or by using it in a context that accepts the new type.

Example: If the original function is int foo() { return 42; }, and the return type is changed to float, the modified function should be float foo() { return 42.0; }.
