Mutation Operator: Target code construct is template instantiation involving class templates and static members. Applicable to C++ code with class templates containing static member variables. Mutation Rule: Step 1: Identify a class template with a static member variable. Ensure that the static member variable is of a primitive type (e.g., int, char). Step 2: In another struct or class, use a template alias to refer to the static member variable of the class template as if it were a type. Step 3: Create a member function template in another struct or class that attempts to return the static member variable alias using the template keyword. Step 4: Instantiate the member function template with a struct or class that contains the alias to the static member variable. Example: Before mutation: template <typename T> struct O { static const T v = 0; }; struct P { template <typename T> using I = typename O<T>::v; }; After mutation: struct Q { template <typename T> int foo() { return T::template I<int>; } }; int bar() { Q m; return m.foo<P>(); }
