Mutation Operator: Template Parameter Transformation Target: Template class declarations and usage. Mutation Rule: 1. Identify a template class with multiple template parameters, including type and non-type parameters. 2. Select one of the template parameters to transform. This can be a type or a non-type parameter. 3. If it's a non-type parameter, change its type to another compatible type (e.g., change an integer non-type parameter to a long or unsigned long). 4. If it's a type parameter, replace it with another existing type from the codebase. 5. Ensure that all usages of this template class in the code are also updated to reflect this transformation. Example: Original: template <class e, e as> using at = __make_integer_seq<q, e, as>; Mutated: template <class e, long as> using at = __make_integer_seq<q, e, as>;
