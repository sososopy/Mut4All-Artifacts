Mutation Operator: Incorporate Template Pack Expansion into a Fold Expression
Target: This mutation operator targets code constructs that use template parameter packs, specifically within fold expressions.
Mutation Rule: Locate a fold expression that involves a template parameter pack. Within the fold expression, replace the current operation with a different fold operation that still uses the pack expansion. For example, if the original fold expression is summing elements, change it to a logical AND or OR operation.
Example: Given a fold expression ((args + ...) + 0), mutate it to ((args && ...) && true) or ((args || ...) || false).
