### Mutation Operator
1. Target Code Construct: This mutation operator targets function declarations within a C++ seed program. 2. Mutation Rule: Identify the function declaration in the seed program. Modify the function declaration to a function template by adding a template parameter list before the function name. Specifically, add `template<typename T>` before the function declaration. Ensure that the program has appropriate template parameters or types to replace the original function parameters if needed. 3. Example: Given a function declaration like `void foo() { ... }`, modify it to `template<typename T> void foo() { ... }`.
