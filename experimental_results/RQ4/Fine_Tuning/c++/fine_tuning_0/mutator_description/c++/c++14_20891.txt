Mutation Operator: Replace decltype(auto) with auto in variable declaration

Description: This mutation operator targets variable declarations that use decltype(auto). The goal is to replace decltype(auto) with auto to test how the compiler handles the inferred type in different contexts.

Mutation Steps:
1. Identify variable declarations in the code that use decltype(auto).
2. Replace decltype(auto) with auto in those declarations.

Example:
Original Code: 
decltype(auto) g = &f<int>;
Mutated Code: 
auto g = &f<int>;
