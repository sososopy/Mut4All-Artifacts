Mutation Operator: Export Template Specialization in Non-Module Context

Target Structure: Non-module C++ code with template class declarations.

Mutation Rule: Identify the first template class declaration in the code. Immediately after the template class declaration, introduce an export template specialization by inserting the following code: “export template <class T> <template_class_name><T>::<undefined_member> =”, replacing <template_class_name> with the name of the declared template class and <undefined_member> with an arbitrary identifier that is not defined within the template class. This mutation exploits the invalid use of export specialization outside a module context, as demonstrated in the bug report.

Example: Given the seed program:
```
template <typename T>
class Example {
public:
  void show() {
    // Implementation
  }
};
```
Apply the mutation to get:
```
template <typename T>
class Example {
public:
  void show() {
    // Implementation
  }
};

export template <typename T> Example<T>::undefined_member = //...
```
