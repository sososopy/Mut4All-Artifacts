Mutation Operator: Insert Invalid Whitespace Highlighting

Target: Source Code with Whitespace Sensitivity

Mutation Rule: Identify areas in the code where whitespace is significant, such as alignment in structured bindings, indentation in macros, or spacing in template arguments.

Insert ambiguous or unusual whitespace characters like tab, multiple spaces, or non-breaking spaces around those areas.

Example: In a structured binding such as `auto [ var1 , var2 ] = expr;`, insert multiple spaces or tabs between the brackets and variable names, or between the equals sign and the expression, to create `auto [  var1  ,  var2  ] =  expr;`.
