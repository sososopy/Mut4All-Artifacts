Mutation Operator: Remove Namespace Wrappers

Target Construct: Enums within Structs or Classes

Mutation Rule: Identify any enum declaration that is wrapped within a struct or class. Temporarily remove the struct or class wrapper, effectively making the enum declaration free-standing. Ensure that any references to the previously nested enum constants are updated to match their new un-nested scope. This can help identify issues related to scope resolution and using enum, particularly in C++20 and later standards.

Example: Transform code from using a struct-wrapped enum like: struct Bar { enum Foo { A, B, C }; }; to a free-standing enum: enum Foo { A, B, C };. Adjust any code that uses the enum constants to reflect this change in scope, such as changing Bar::Foo::A to Foo::A or A if using enum is involved.
