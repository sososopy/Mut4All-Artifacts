Mutation Operator: Modify Template Specialization Rule

Target Code Construct: Template Specialization within struct or class definitions

Mutation Rule:

1. Identify a template class or struct in the seed code.

2. If it contains a partial specialization, modify the specialization to not use any of the template parameters. 

3. If there is no existing partial specialization, introduce one by creating a specialization that ignores the template parameters.

Example:

Original Code:

```cpp
template <typename T>
struct MyStruct {
    void foo();
};

template <>
struct MyStruct<int> {
    void foo();
};
```

Mutated Code:

```cpp
template <typename T>
struct MyStruct {
    void foo();
};

template <>
struct MyStruct {
    void foo();
};
```
