mutation Operator: Invalid Constructor Definition in Template Class: Target: Template class constructors. Mutation Rule: Identify a template class. If it does not have a constructor, add an invalid constructor definition without providing a constructor body. If it has a constructor, modify it by removing the constructor body and placing the constructor definition at an invalid location, such as after a function outside of the class scope. Example: Original: template <typename T> class MyClass { public: void someFunction() {} }; Mutated: template <typename T> class MyClass { public: void someFunction() {} } void anotherFunction() {} MyClass() {}
