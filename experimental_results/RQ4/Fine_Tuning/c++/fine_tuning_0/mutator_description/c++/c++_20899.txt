Mutation Operator: Template Specialization Mutation

Target: Templates with specialization

Description: This mutation targets template specializations within the code. Specifically, identify template structures with specializations and modify the condition or type in the specialization.

Steps: 
1. Locate a template definition that includes specialization, such as a `struct` or `class` template with specialized behavior based on conditions like `enable_if`.
2. Identify the specialized condition or type, for example, `template <bool B, typename T = void> struct enable_if;` and `template <typename T> struct enable_if<true, T>`.
3. Modify the specialization condition or type. For instance, change `enable_if<true, T>` to `enable_if<false, T>` or alter the typename used in the specialization.

Example: 
Original: template <bool B, typename T = void> struct enable_if;
          template <typename T> struct enable_if<true, T> { typedef T Type; };

Mutated:  template <bool B, typename T = void> struct enable_if;
          template <typename T> struct enable_if<false, T> { typedef T Type; };

This mutation operator forces the compiler to handle potentially invalid or unintended template specializations, which can trigger edge cases in template resolution and error handling, leading to compiler crashes or unexpected behavior.
