Mutation Operator: Target: Functions with a return statement inside a compound statement. Mutation Rule: 1. Identify a function with a body enclosed in curly braces. 2. Locate the return statement within the function's body. 3. Modify the return statement by changing it to return an expression that involves a ternary operator. The ternary operator should have a condition, true case, and false case. 4. Ensure the types in the ternary expression are compatible with the function's return type. Example: Original code: int foo() { return x; } Mutated code: int foo() { return (x > 0) ? x : -x; }
