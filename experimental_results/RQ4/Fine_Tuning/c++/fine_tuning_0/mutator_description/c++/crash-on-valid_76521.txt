Mutation Operator: Add an Attributed Lambda Inside a Templated Function

Target: Templated functions

Mutation Rule:
1. Identify a templated function in the code. It may look like `template <typename T> void foo() {}`.
2. Within the function body, declare an attributed lambda. Use an existing attribute that your compiler recognizes. An example pattern is `auto l = []() __attribute__((pcs("aapcs-vfp"))) {};`.
3. Ensure that the lambda captures or uses some existing variable or type if necessary, to make the attributed lambda semantically meaningful.
4. In the calling context of the templated function, instantiate the template with an existing type.
5. Verify that the lambda is evaluated or instantiated within the template instantiation process.

This mutation operator targets the template instantiation mechanism in combination with attributed lambdas, aiming to explore edge cases in how attributes are handled in templated contexts.
