Mutation Operator: This mutation operator targets the usage of extern functions within a struct constructor. Step-by-step mutation: 1. Identify any existing function declaration marked with 'extern'. 2. Within a struct, locate the constructor. 3. Inside the constructor, insert a call to the extern function. 4. Ensure the constructor is marked as consteval. Example of mutation in pseudo-code: Given 'extern return_type function_name();', and a struct 'struct StructName { consteval StructName() { } };', mutate the constructor to 'consteval StructName() { function_name(); }'.
