Mutation Operator: Template Default Argument Crash

Target: This mutation operator targets templated classes with templated methods.

Rule: Identify a templated class with a method that accepts a templated parameter with a default argument. Modify the call to this method by invoking it without providing the argument, thereby relying on the default.

Steps:
1. Locate a templated class with a method that takes a templated parameter with a default value.
2. Identify any function call to this method where an explicit argument is provided.
3. Remove the explicit argument from the function call, making it rely on the default argument.

Example:
Before Mutation:
```cpp
template <typename>
struct Impl {};

template <template <typename> class T1>
class A1 {
   public:
    template <typename T2>
    void b(T1<T2> = T1<T2>());
};

void bug1() {
    A1<Impl> a;
    a.b<int>(Impl<int>());
}
```

After Mutation:
```cpp
template <typename>
struct Impl {};

template <template <typename> class T1>
class A1 {
   public:
    template <typename T2>
    void b(T1<T2> = T1<T2>());
};

void bug1() {
    A1<Impl> a;
    a.b<int>();
}
```

Note: This mutation operator leverages the templated nature of C++ and the often complex interactions between template instantiations and default arguments to induce compiler crashes.
