Mutation Operator: Inner Class Template Constraint Target: Class or Struct with Inner Classes Description: This mutation operator targets classes or structs that contain inner classes, specifically those with template constraints. It manipulates the template constraint and structure to trigger compiler behavior related to template instantiation and constraint satisfaction. Mutation Steps: Identify a class or struct with an inner class template that uses constraints. If no such inner class exists, create a new inner class template with a simple constraint. Modify the constraint expression by either: Reversing the logic of the constraint (e.g., change `requires (Expr)` to `requires (!Expr)`). Replacing the constraint with a syntactically correct but semantically different constraint (e.g., change `requires (A)` to `requires (B)`). Add an additional layer of template indirection by wrapping the inner class template with another template. Ensure that the outer template forwards its parameters to the inner template. Example Illustration: Original Code: ```cpp struct S { template<typename T> requires (is_integral_v<T>) struct Inner {}; }; ``` Mutated Code: ```cpp struct S { template<typename T> requires (!is_integral_v<T>) struct Inner {}; template<typename U> struct Outer : Inner<U> {}; }; ```
