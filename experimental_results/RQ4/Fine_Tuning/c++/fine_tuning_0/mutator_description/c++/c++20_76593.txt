Mutation Operator: Target Structure: Lambda Expressions. 
Mutation Rule: 
1. Identify a lambda expression where the return type is explicitly specified. 
2. Change the lambda's explicit return type to a trailing return type using the '->' syntax.
3. Example of Change: 
Original Lambda: auto myLambda = [](auto a, auto b) { return a + b; };
Mutated Lambda: auto myLambda = [](auto a, auto b) -> decltype(a + b) { return a + b; };
