mutation Operator: Lambda with Parameter Pack in Decltype

Target: Lambda Expression inside decltype

Description: This mutation operator targets lambda expressions used within the decltype specifier. It introduces a lambda expression that immediately invokes itself with a parameter pack, which can create complex template deduction scenarios that are prone to causing compiler crashes.

Mutation Steps: 1. Identify a decltype expression in the code. 2. Insert a lambda expression within the decltype. The lambda should take a parameter pack as its argument. 3. Immediately invoke the lambda with a parameter pack. 4. Ensure that the parameter pack contains at least one template parameter that needs to be deduced by the compiler.

Example: Original code: int x = 5; auto val = decltype(x)(10);

Mutated code: int x = 5; auto val = decltype([]<typename... T>(T&&... args){ return (args + ...); }(5, 10))(10);

Explanation: The mutation replaces the simple decltype expression with a more complex one that involves a lambda expression taking a parameter pack. The lambda is immediately invoked with a set of arguments, creating a scenario that requires the compiler to deduce the types of the parameter pack. This can expose bugs related to template argument deduction and lambda expression handling within decltype.
