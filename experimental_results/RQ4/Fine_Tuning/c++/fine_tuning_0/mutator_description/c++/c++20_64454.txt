Mutation Operator: Parameter-Dependent Requires in Out-of-Line Definition

Target: This mutation operator targets a template class with a member function that has a requires clause. Specifically, it focuses on the scenario where the requires clause is dependent on a parameter and the function is defined out-of-line.

Mutation Rule: 
1. Identify a template class with a member function that has a requires clause. The requires clause should depend on a function parameter.
2. Ensure that the function is declared within the class but defined outside of the class using the out-of-line definition approach.
3. Modify the requires clause to make it parameter-dependent if it is not already.
4. If the function is defined in-line, move the definition out-of-line while preserving the parameter-dependent requires clause.

Example: 
Original Code: 
```cpp
template<class T> struct MyStruct {
  auto myFunction(auto x) requires (x > 0);
};
```

Mutated Code: 
```cpp
template<class T> struct MyStruct {
  auto myFunction(auto x) requires (x > 0);
};

template<class T>
  auto MyStruct<T>::myFunction(auto x) requires (x > 0) { }
```

In this mutation, the focus is on modifying or ensuring the presence of a parameter-dependent requires clause in a member function of a template class and using out-of-line definition for the function. This targets the specific bug scenario where a stack dump occurs due to parameter-dependent requires in out-of-line definitions.
