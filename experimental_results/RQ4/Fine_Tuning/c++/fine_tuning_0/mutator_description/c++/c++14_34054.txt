Mutation Operator: Modify Default Arguments in Lambdas

Target: This mutation operator targets default arguments in lambda expressions.

Mutation Rule:
1. Identify any lambda expression in the code, particularly looking for those that have default arguments.
2. If the lambda is a generic lambda, ensure that the default argument is a lambda itself.
3. Modify the default argument lambda to include at least one of the following features:
   a. Use of auto in parameter declaration.
   b. Capture by value or reference.
   c. Nested lambda expression.
4. Ensure that the modified lambda default argument is syntactically and semantically correct according to the C++14 standard.

Example:
Consider a seed code snippet with a generic lambda:
auto glambda = [](auto a, auto b) { return a < b; };

Mutation:
Change it to:
auto glambda = [](auto a, auto b = [](auto x){ return x*2; }) { return a < b(); };
