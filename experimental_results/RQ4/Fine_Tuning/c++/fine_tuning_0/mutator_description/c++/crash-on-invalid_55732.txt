Mutation Operator  
Target Construct: Struct Declaration  
Mutation Rule: Select an existing struct in the code. For each member variable in the struct, if it is a reference type (e.g., `type &variableName`), apply the `const` qualifier to it (i.e., change `type &variableName` to `const type &variableName`). If the reference is already `const` or if there are no reference members, add a new member variable of type reference to an existing type in the program and apply `const` to it.
