Mutation Operator: Target Function Instantiation with Multiple Base Classes

1. Target: Identify classes derived from multiple base classes. 2. Mutation Rule: Instantiate a member function of the target class that invokes a member function from each base class. 3. Steps: a. Identify a target class that inherits from more than one base class. b. Verify that each base class has at least one public member function. If not, introduce a simple public member function in the base class. c. In the target class, introduce a new member function. d. Within this new member function, invoke one member function from each base class. e. Ensure that the new member function is instantiated in the main function or any existing function to trigger code generation. 4. Example: Original: ``` class Base1 { public: void func1() {} }; class Base2 { public: void func2() {} }; class Derived : Base1, Base2 {}; ``` Mutated: ``` class Base1 { public: void func1() {} }; class Base2 { public: void func2() {} }; class Derived : Base1, Base2 { public: void newFunc() { func1(); func2(); } }; int main() { Derived d; d.newFunc(); } ```
