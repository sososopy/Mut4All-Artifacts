mutation Operator: Target requires-clause in class templates with partial specialization. This operator applies to class template declarations that have a partial specialization with a requires-clause. Mutation rule: 1. Identify a class template with a partial specialization that uses a requires-clause. 2. In the primary template definition, insert a requires-clause with a newly defined concept or an existing concept in the codebase. Ensure the concept is relevant to the template parameters. 3. Apply the same requires-clause to the partial specialization to preserve semantic meaning. Example: Given a primary class template without a requires-clause and a partial specialization with a requires-clause, add a relevant requires-clause to the primary template that constrains the template parameter(s) similarly to the partial specialization.
