Mutation Operator 1: Target Construct: Static Constexpr Member Function and Usage within Class. Mutation Rule: 1. Identify static constexpr member functions within a class. 2. Locate any usage of such functions within the same class, such as in data member initializations. 3. Modify the call by adding explicit template arguments to the function call where none are required or expected, e.g., change `func()` to `func<int>()`, assuming `func` takes no template parameters. Example: Original: ```cpp struct A { static constexpr auto as_tuple_helper() { return std::tuple_size<decltype(static_cast<Tuple&>(*this)._data)>; } static constexpr int data_size = as_tuple_helper(); }; ``` Mutated: ```cpp struct A { static constexpr auto as_tuple_helper() { return std::tuple_size<decltype(static_cast<Tuple&>(*this)._data)>; } static constexpr int data_size = as_tuple_helper<int>(); }; ```
