Mutation Operator 
Name: Invalid Decltype in Generic Lambda 

Target: Generic Lambda Expressions 

Mutation Rule: 

1. Identify a generic lambda within the code. This can be recognized by the presence of a lambda expression that uses template parameters or auto in its parameter list. 
2. Locate the capture list of the lambda. 
3. Insert an invalid decltype expression in the capture list. This can be done by writing decltype(), an empty decltype expression without any argument. 

Example: 
Original Lambda: 
auto lambda = [](auto a) { return a + 1; }; 

Mutated Lambda: 
auto lambda = [decltype()] (auto a) { return a + 1; };
