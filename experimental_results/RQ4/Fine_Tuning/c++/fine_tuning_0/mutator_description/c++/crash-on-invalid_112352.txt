Locate a function template instantiation. Replace a parameter with a fold expression that uses a variadic template argument but does not expand it. Example: Original: `template<typename T> void func(T arg) {}` Mutated: `template<typename... Ts> void func(Ts... args) { auto value = (args + ...); }`
