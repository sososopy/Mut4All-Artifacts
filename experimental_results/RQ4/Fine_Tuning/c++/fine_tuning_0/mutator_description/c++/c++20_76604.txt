mutation Operator: Template Parameter Reduction Target: Templates with multiple template parameters. Mutation Rule: 1. Identify a template declaration with multiple template parameters. 2. Remove one or more template parameters, ensuring that the removal does not affect the first template parameter. 3. Adjust the code to accommodate the removed template parameters by either replacing them with default values or removing dependent code constructs. Example: Original: template<typename T, std::size_t N, int M> struct S; Mutated: template<typename T, std::size_t N> struct S;
