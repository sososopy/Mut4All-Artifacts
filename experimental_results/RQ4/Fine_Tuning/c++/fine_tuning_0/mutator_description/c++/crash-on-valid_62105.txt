Mutation Operator: Struct Default Argument in Conditional Expression

Target Construct: This mutation targets structs with constructors that have default arguments and are used within conditional expressions.

Mutation Rule:
1. Identify a struct that has a constructor with at least one default argument.
2. Locate a conditional expression (ternary operator ?:) in the code.
3. Replace one of the potential results of the conditional expression with a constructor call to the identified struct, using an initializer list if necessary.
4. Ensure that the default argument of the struct constructor is utilized in the call.

Example:
Original:
```
struct X {
  X(int x, int y = 5);
};

int main() {
  int a = 0 ? 10 : 20;
}
```

Mutated:
```
struct X {
  X(int x, int y = 5);
};

int main() {
  int a = 0 ? X{10} : 20;
}
```

In this example, the struct X has a constructor with a default argument for the second parameter. The conditional expression uses a ternary operator to choose between two integers. The mutation replaces one of the integer results with a constructor call to X, utilizing the default argument. This mutation leverages default arguments in a conditional context, which can expose compiler edge cases related to code generation and overload resolution.
