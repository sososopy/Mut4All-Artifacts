Mutation Operator: Target: Switch statement

Mutation Rule: 1. Identify any switch statement in the code. 2. Remove the "switch" keyword and the corresponding condition in parentheses, leaving only the case clauses and the associated code blocks. 3. Ensure that at least one case clause remains, so the mutated code resembles a block of consecutive case labels and code blocks without a surrounding switch statement.

Example: Original: switch (0) { case 0: Zero zero; } Mutated: case 0: Zero zero;
