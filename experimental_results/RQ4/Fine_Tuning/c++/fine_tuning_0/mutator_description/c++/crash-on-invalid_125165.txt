Mutation Operator: Structured Binding in Template Function Context

Target: Template function definitions with return type deduction

Mutation Rule: Within a template function that utilizes structured bindings, change the bound variable type to a reference to auto. This exploits type deduction and structured binding behavior to increase the likelihood of encountering compiler bugs.

Step-by-Step:
1. Identify a template function definition that uses a structured binding.
2. Modify the bound variable type to be a reference to auto. For example, change `auto [x, y] = expr;` to `const auto& [x, y] = expr;`.

Example: Given a template function like:
```
template <typename T>
void func(T t) {
    auto [x, y] = t;
}
```
Mutate to:
```
template <typename T>
void func(T t) {
    const auto& [x, y] = t;
}
```
