mutation Operator: Target code construct: Template class with friend function. 

Mutation rule: 

Step 1: Identify a template class with a friend function that takes an instance of the template class as a parameter. 

Step 2: Modify the friend function declaration by adding a default argument to one of its parameters. Make sure this friend function is not defined within the template class itself, but outside. 

Step 3: Create an instance of the template class in a function and call the friend function without providing the default argument. 

Example: 

Change: template<typename = int> struct ct { friend void f(ct, int); }; void test() { f(ct<>{}, 0); } 

To: template<typename = int> struct ct { friend void f(ct, int = 0); }; void test() { f(ct<>{}); }
