Mutation Operator: Specialize Template Alias Targeting: Template alias declaration with complex template arguments. Mutation Rule: Identify a template alias and its associated template specialization. Change the specialization to an unrelated or malformed type or template, preferably one that doesn’t match the original alias pattern. Example: Transform template <typename T> using Alias = ComplexTemplate<T>; to template <typename U> using Alias = UnrelatedType<U>;
