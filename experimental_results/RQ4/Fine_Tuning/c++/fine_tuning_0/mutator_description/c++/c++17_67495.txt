Mutation Operator: Target the use of structured bindings with auto& on the left-hand side in conjunction with a function that returns a user-defined type. 1. Identify any function that returns a user-defined type. 2. Replace its return value with an auto& structured binding declaration involving the returned members. 3. Introduce the structured binding variables into a lambda capture. 4. Use the lambda in a boolean context or other evaluative context. Example: Given a function that returns a struct type, mutate it by declaring an auto& structured binding with the function call on the left side, then capture the structured binding variables in a lambda, and finally call the lambda in a boolean expression.
