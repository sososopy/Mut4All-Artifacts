Mutation Operator: Template Specialization Mutation

Target: Template Specialization with Const Qualifier

Description: Identify a function template that accepts a template-typed parameter with qualifiers (e.g., const, volatile). Modify the function to instantiate the template with a different qualified type in a function call.

Steps: 1. Locate a function template that takes a parameter with a qualified type, such as `B<const T>`. 2. Modify a function call that uses this template specialization by instantiating the template with a different type, preserving other qualifiers. For example, change `f(B<int>())` to `f(B<const int>())`. 3. Ensure that the template instantiation in the function call either removes or changes the qualifiers while maintaining the template parameter's base type.
