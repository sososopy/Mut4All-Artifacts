Mutation Operator: Default Template Argument Substitution

Target: Template specialization and default template arguments

Mutation Rule: 

1. Identify a template alias or class template with a template parameter that has a default argument dependent on another template parameter.
2. Modify the code to create a partial specialization that uses the alias or class where the dependent default template argument needs to be substituted.
3. Ensure that the partial specialization explicitly or implicitly relies on the default argument's substitution to trigger the bug.
4. Add a static or non-static member function to the partially specialized template to increase the likelihood of compiler crash during semantic analysis.

Example:
Given a template alias defined as:

template <typename T2 = T> using pt = point<3, T2>;

Create a partial specialization that uses this alias without explicitly specifying the dependent template argument:

static int test(const pt<>&) { return 0; }

This forces the compiler to substitute the default template argument T2 = T in the context of the partial specialization, which may lead to a crash due to incorrect handling of dependent types.
