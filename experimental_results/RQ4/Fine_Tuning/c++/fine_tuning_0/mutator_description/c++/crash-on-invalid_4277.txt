Mutation Operator: Target the Use of Inline Assembly in Function Bodies  
1. Identify a function body in the code. This is typically enclosed by curly braces {} following a function declaration.  
2. Within the identified function body, introduce an inline assembly statement using the asm keyword. This statement should be syntactically incorrect, such as asm("invalid_instruction").  
3. Ensure that the introduced assembly statement is placed at a valid position within the function body, such as before a return statement or at the beginning of the body.  
4. Verify that the mutation does not interfere with other code structures or introduce undeclared variables or types.

Example Before Mutation: void exampleFunction() { int a = 5; return a; } After Mutation: void exampleFunction() { asm("invalid_instruction"); int a = 5; return a; }
