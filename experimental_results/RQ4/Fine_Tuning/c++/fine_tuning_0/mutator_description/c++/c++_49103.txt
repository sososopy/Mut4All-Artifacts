Mutation Operator: Template Argument Expansion to Existing Structs or Classes

Target: Template instantiation within structs or classes.

Mutation Rule:
1. Identify all struct or class definitions in the seed program.
2. For each struct or class, check if it contains any template instantiation using the `__make_integer_seq` or similar constructs.
3. Modify the template instantiation by increasing the number of template arguments beyond the expected limit of the template being instantiated.
4. Ensure that the additional template arguments are of valid types already declared in the program, such as existing class or struct names.

Example: if the seed program has a struct like this: `template <class> struct B; struct T { __make_integer_seq<B, int, 10> n; };`. Mutate it to: `template <class> struct B; struct T { __make_integer_seq<B, int, 10, float> n; };`.
