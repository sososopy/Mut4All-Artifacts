Mutation Operator: Recursive Template and Lambda Mutation

Target: Template Functions Involving Lambdas

Mutation Rule:
1. Identify a function template that takes a parameter of any type. 
2. Inside the template, introduce a recursive call to the same function template using a lambda as the argument.
3. Ensure the lambda is an empty capture-less lambda, i.e., `[]{}`.
4. Invoke this template function with a predefined type or struct. 
5. Make sure the invoked type or struct is declared in the seed program. If not, introduce a simple struct or type declaration for this purpose.

Example:
Consider a template function: `template <typename T> auto func(T) {}`. Mutate it to: `template <typename T> auto func(T) { func([]{}); }`. Then invoke it with a type like `struct A {};`. Call `func(A{});`.
