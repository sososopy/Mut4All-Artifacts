Mutation Operator:
Target: Variadic Templates
Mutation Rule: 1. Locate a variadic template structure with a template parameter pack (e.g., template<typename... Args>). 2. Introduce another variadic friend function or operator within the template. 3. Use a fold expression within a requires clause of the friend function's template parameter, such that the fold expression involves more than one parameter pack of differing lengths. Example Before: template<typename... Ts> struct A {}; template<typename... Ts> struct A { template<typename... Us> requires(... and c<Ts, Us>) friend bool operator==(A, A<Us...>) { return true; } };
