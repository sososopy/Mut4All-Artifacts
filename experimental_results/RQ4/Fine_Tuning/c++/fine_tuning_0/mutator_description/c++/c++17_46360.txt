Mutation Operator: Target a lambda function definition with a capture list. Mutation Rule: Identify a lambda function definition with a capture list. Replace the lambda capture list with a move semantic capture by adding "std::move" around each captured variable. Apply this transformation to at least one variable in the capture list. Example: Original Lambda: auto lambda = [x, y](int z) { return x + y + z; }; Mutated Lambda: auto lambda = [x = std::move(x), y = std::move(y)](int z) { return x + y + z; };
