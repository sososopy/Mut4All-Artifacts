Mutation Operator: Template Function Mutation

Target Code Construct: Template function declaration and definition.

Mutation Rule:
1. Identify a template function that takes a forwarding reference as a parameter. The template function should be of the form: template<typename T> void a(T &&s) { }.

2. Replace the forwarding reference parameter with a normal parameter. For example, change void a(T &&s) { } to void a(T s) { }.

3. In the function body where this template function is called, attempt to assign its return value to a variable. For instance, if the function is called as a(0), modify it to int sum = a(0);.

Example:

Before Mutation:
template<typename T> 
void a(T &&s) { }

After Mutation:
template<typename T> 
void a(T s) { }

Before Mutation:
void b() { 
    a(0); 
}

After Mutation:
void b() { 
    int sum = a(0); 
}
