mutation Operator: Struct Initialization with Lambda. Target: This mutation operator targets structs with member variables that are initialized using lambdas. Rule: Identify any struct that has a member variable initialized directly within its declaration. If the initializer is a simple expression, replace the initializer with a lambda expression that captures all variables by value [=] and returns the original initializer expression. Example: Given a struct with a member variable like `int n = 42;`, transform it to `int n = [=]() { return 42; }();`. If the struct has a member `int d = 5;`, it should be morphed to `int d = [=]() { return 5; }();`, ensuring the lambda is immediately invoked.
