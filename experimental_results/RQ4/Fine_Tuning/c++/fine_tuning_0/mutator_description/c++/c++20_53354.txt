mutation Operator: Template Specialization with Requires Clause. Select a primary template and its corresponding partial specialization. For the partial specialization, add a requires clause that constrains the template parameter using a concept or a requires expression. Ensure that the constraint is non-trivial, involving a nested type or member access in the concept or requires expression. Example: Given a primary template template <typename T> struct S {}; and a partial specialization template <typename T> struct S<T*> {}; mutate the partial specialization to template <typename T> requires C<T> struct S<T*> {}; where C<T> is a concept that checks some property of T, such as the presence of a nested type or a member function.
