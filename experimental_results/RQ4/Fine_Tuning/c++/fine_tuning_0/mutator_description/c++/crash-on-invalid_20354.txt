mutation Operator: Target: Function Parameter Shadowing with External Declaration. Mutation Rule: 1. Identify functions with parameters. 2. For each parameter, create an external declaration with the same name as the parameter inside the function body. 3. Place the external declaration at the beginning of the function body. Example: Original Code: void f(int x) { // Function body } Mutated Code: void f(int x) { extern int x; // Function body }
