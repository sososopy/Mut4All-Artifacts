Mutation Operator: Template Argument Replacement
Description: This operator targets template declarations and usages. It specifically works on replacing template arguments with incomplete or forward-declared types. 
Mutation Rule: Locate any template usage with a complete type as an argument. Replace this argument with a type that is either forward-declared or not defined within the current translation unit. 
Example: Given the code snippet template<class T> struct Foo {}; struct S { static Foo<int> test(); }; apply the mutation to get template<class T> struct Foo {}; struct Incomplete; struct S { static Foo<Incomplete> test(); };
