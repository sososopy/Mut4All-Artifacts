Mutation Operator
Target: This mutation operator targets instances of base classes in an inheritance hierarchy, specifically when dealing with a base class pointer or reference.  
Mutation Rule:  
Identify all instances of base class pointers or references being used in the code. For each base class pointer or reference, replace it with a derived class pointer or reference if a derived class exists. Ensure that the derived class is accessible in the current scope. If necessary, include the required headers or forward declarations to make the derived class available.  
Example:  
Original Code:  
```
Base* obj = new Base();  
```
Mutated Code:  
```
Derived* obj = new Derived();  
```
