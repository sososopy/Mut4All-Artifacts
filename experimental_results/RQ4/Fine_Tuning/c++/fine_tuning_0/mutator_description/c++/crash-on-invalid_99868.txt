Mutation Operator 1: Replace Template with Incomplete Class

Target: Template declarations and usages

Rule:
1. Identify a template declaration in the code. For example, a declaration like `template <typename T> class X;`.
2. Replace the template with a forward declaration of an incomplete class. For instance, replace `template <typename T> class X;` with `class X;`.

Example:
Before:
```
template <typename T> class X;

class Y : X<int> {};
```

After:
```
class X;

class Y : X {};
```
