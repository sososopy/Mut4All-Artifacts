Mutation Operator: Target Enum Declaration

Step 1: Identify all enum type declarations in the seed program, such as any line with the keyword "enum".  
Step 2: For each enum declaration, introduce a duplicate enumerator to the enumeration list. Select an existing enumerator, copy it, and append it to the end of the enumeration list.  
Example:  
Original:   
enum Day { sunday, monday, tuesday };  
Mutated:   
enum Day { sunday, monday, tuesday, sunday };
