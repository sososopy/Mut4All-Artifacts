Mutation Operator: Target: Lambda Function within a Template Function. Mutation Rule: Locate any lambda function that is defined within a template function. Examine the lambda's return type and determine if it involves any variable declared within the template function. Alter the return type to use decltype with a variable that exists within the template function scope. Example: Original Lambda: [](auto a) -> void { return; } Mutated Lambda: [](auto a) -> decltype(c) { return; }
