mutation Operator 1: Nested Lambda Capture with Template Functions Target: Nested Lambdas within Template Functions Rule: Identify any lambda function within a template function. Mutate by adding a nested lambda inside the existing lambda. The inner lambda should attempt to capture a variable from the outer lambda scope. If no suitable variable exists, introduce a new variable in the outer lambda scope to be captured by the inner lambda. Example: Original Code: ```cpp template<typename T> void func(T val) { auto lambda = [val]() { return val; }; } ``` Mutated Code: ```cpp template<typename T> void func(T val) { auto lambda = [val]() { auto innerLambda = [&]() { return val; }; return innerLambda(); }; } ```
