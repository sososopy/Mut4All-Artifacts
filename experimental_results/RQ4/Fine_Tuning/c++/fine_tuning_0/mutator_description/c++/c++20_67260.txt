mutation Operator: Add a using-declaration for an injected-class-name

Where to Apply: Inside a class template or class template specialization that is already defined in the seed program.

Mutation Rule: 1. Identify a class template or class template specialization in the seed program. 2. Inside the class definition, add a using-declaration that refers to the injected-class-name of the template. This can be done by adding a line like 'using typename <class-name>::<class-name>;'.

Example: Before Mutation: template <typename T> struct MyTemplate {}; After Mutation: template <typename T> struct MyTemplate { using typename MyTemplate::MyTemplate; };
