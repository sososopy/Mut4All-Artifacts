Mutation Operator: Modify Constant Evaluation Context

Target: Constant expressions and constexpr constructs.

Mutation Rule:
1. Identify any constexpr variable or function in the code.
2. Add a non-trivial statement that breaks the constexpr evaluation, such as a runtime-dependent condition or operation.
3. For instance, if there's a constexpr function, introduce an if constexpr with a false condition that includes a non-constexpr operation (e.g., I/O operations, dynamic memory allocation).
4. Ensure the rest of the code remains valid, and the mutation does not introduce syntax errors or undeclared identifiers.

Example:
Original: constexpr int x = 5;
Mutated: constexpr int x = (5 > 0) ? 5 : (std::cout << "not constexpr", 0);
