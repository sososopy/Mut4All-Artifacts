Mutation Operator: Target Struct Member Access in Constant Expressions

Description: This mutation operator targets struct member access within constant expressions, particularly when using macros or other inline operations. 

Mutation Rule: Identify struct member accesses (e.g., `st->a` or `st.a`) in constant expressions (e.g., within `constexpr`) and replace the member access with a macro or inline operation that takes the struct member as an argument.

Example:
Original: 
```cpp
struct my_struct { int x; };
constexpr int val = my_struct().x;
```

Mutated: 
```cpp
#define my_macro(a) (a + 3)
struct my_struct { int x; };
constexpr int val = my_macro(my_struct().x);
```
