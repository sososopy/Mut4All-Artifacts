Mutation Operator: Insert Constrained Variable Template

Target: Variable Template Declarations

Rule: Identify a non-constrained variable template declaration in the seed program. Modify it by adding a requires clause that uses an existing or newly introduced concept. Ensure the concept is defined and applicable to the template parameter. If no suitable concept exists, define a new concept that evaluates to true for demonstration.

Example: 
Original: 
template <typename T>
constexpr T pi_v = 3.141592653589793238462643383279502884L;

Mutated: 
template <typename T>
concept AlwaysTrue = true;

template <typename T>
requires(AlwaysTrue<T>)
constexpr T pi_v = 3.141592653589793238462643383279502884L;
