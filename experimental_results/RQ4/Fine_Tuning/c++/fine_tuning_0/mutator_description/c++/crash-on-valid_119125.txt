mutation Operator: Annotate with Function or Method Declaration.
Target: Functions and methods within any class or struct.
Instruction: Identify any function or method within a class or struct definition. Add a `[[clang::annotate]]` attribute to the function. Within the attribute, include a string argument followed by a complex expression that utilizes existing types or variables. The complex expression can be a tuple or nested tuple, incorporating a cast to void of an object of the template parameter type or any type used within the class/struct.
Example: If a class `A` has a method `void foo()`, transform it to `[[clang::annotate("test", (9, (void)T{}))]] void foo() {}` within the class/struct.
