Mutation Operator: Enum to Using Enum Conversion
1. Target: `enum` declarations and their usage in the code.
2. Mutation Rule:
   a. Identify all `enum` declarations within the code.
   b. For each enum, introduce a `using enum` statement at the appropriate scope level, depending on the visibility needed.
   c. Replace all occurrences of the enum members with their unqualified names, facilitated by the `using enum` statement.
   d. Ensure that any bitwise operations or other expressions using the enum members are updated to use the unqualified names provided by the `using enum` statement.
3. Example:
   Before Mutation:
   ```cpp
   enum Color { Red, Green, Blue };
   int main() {
       int color = Color::Red | Color::Green;
   }
   ```
   After Mutation:
   ```cpp
   enum Color { Red, Green, Blue };
   using enum Color;
   int main() {
       int color = Red | Green;
   }
   ```
   This transformation leverages the C++20 `using enum` feature to simplify the usage of enum members and can expose issues in how the compiler handles scoping and name resolution for enums.
