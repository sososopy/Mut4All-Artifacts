Mutation Operator: Target Location: Identify a usage of a member function within any class or struct, especially within a namespace. Mutation Rule: Replace a direct call to a member function with a lambda expression that captures the context and calls the member function inside the lambda. Example: Original code: auto result = obj.member_function(args); Transformed code: auto lambda = [&]() { return obj.member_function(args); }; auto result = lambda();
