Mutation Operator: Focus on Doxygen Comments in Classes

- **Target Structure**: This mutation operator targets doxygen comments within class declarations.
- **Mutation Rule**: Identify doxygen comments within classes that utilize tags like `@param`, `@return`, etc. Mutate the comment so that it uses a tag not supported by Doxygen or misuses a tag that depends on the class context.
- **Mutation Steps**:
  1. Locate a class declaration within the C++ code.
  2. Identify any doxygen-style comments preceding member functions or within the class body.
  3. Replace a valid doxygen tag with an invalid one, such as using `@doc.self` outside of its intended context.
- **Example**: Original Code:
```cpp
/// Performs addition of two numbers.
/// @param a The first number.
/// @param b The second number.
/// @return The sum of a and b.
int add(int a, int b) { return a + b; }
```
Mutated Code:
```cpp
/// Performs addition of two numbers.
/// Satisfies the [`Add<@doc.self>`]($sus::num::Add) concept.
int add(int a, int b) { return a + b; }
```
This mutation leverages the misuse of doxygen tags, particularly those that expect a certain context such as within a class, which can trigger errors related to comment parsing in the compiler.
