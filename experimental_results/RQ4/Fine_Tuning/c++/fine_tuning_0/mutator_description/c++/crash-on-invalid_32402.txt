Mutation Operator: Target Compound Statements within Functions

1. Identify and target a function within the code. This could be any function with a defined body.

2. Inside the function's body, which is enclosed by curly braces ('{}'), locate a compound statement. A compound statement is any block of code within the curly braces of a function's body. It could be an if-statement, for-loop, while-loop, or just a block of code enclosed by its own pair of curly braces.

3. Modify the compound statement by introducing an incomplete or malformed statement. Specifically, add a statement that begins correctly but lacks necessary components to be syntactically valid. For example, insert an if-statement without a condition or a for-loop without all its required parts.

void exampleFunction() { int x = 0; if (x > 0) { x++; } }
