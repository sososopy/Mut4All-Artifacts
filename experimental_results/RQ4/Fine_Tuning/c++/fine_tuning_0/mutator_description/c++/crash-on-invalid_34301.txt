Mutation Operator: Template Template Parameter Mutation

Description: This mutation operator targets template classes or structs that have template template parameters. It specifically modifies the template template parameter by changing the template parameter's template arguments to increase the likelihood of causing a compiler crash. 

Mutation Rule: 
1. Identify a template class or struct that has at least one template template parameter.
2. Locate the template template parameter declaration. It should look like: `template <typename T, template <typename...> class container>`.
3. Change the template arguments of the template template parameter to another type or pattern that is valid but different from the original. For example, if the original template parameter is declared as `template <typename...> class container`, you can change it to `template <int N> class container`.

Example: 
Original Code: 
```cpp
template <typename T, template <typename...> class container>
struct Example {
  // Some code
};
```

Mutated Code: 
```cpp
template <typename T, template <int N> class container>
struct Example {
  // Some code
};
```

Note: Ensure that the mutated template template parameter can still be instantiated with at least one existing template in the seed program to maintain validity.
