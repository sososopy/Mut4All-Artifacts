mutation Operator: Modify Function Call Expressions  
Applicable Construct: Function Calls  
Mutation Rule:  
1. Identify all function call expressions within the code, including built-in or standard library functions.  
2. For each function call, randomly change the number of arguments to either exceed or fall short of what the function signature requires.  
3. If increasing the number of arguments, duplicate existing arguments or use existing variables in the code to fill additional slots.  
4. If decreasing, remove arguments while ensuring the function call remains syntactically valid (e.g., do not leave trailing commas).  
Example:  
Original: `foo(a, b);`  
Mutated: `foo(a, b, c);` or `foo(a);`
