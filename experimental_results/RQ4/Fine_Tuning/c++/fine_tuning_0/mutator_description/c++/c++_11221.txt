Mutation Operator: Alter Class Template Specialization

Target: Class Template Specialization

Mutation Rule: 
1. Identify a class template within the seed program.
2. Create a partial specialization for the identified class template.
3. Duplicate the partial specialization by creating another identical partial specialization for the same class template.
4. Ensure both specializations are within the same scope.

Example:
Before Mutation:
```cpp
template<typename T>
class MyClass {};

template<>
class MyClass<int> {};
```

After Mutation:
```cpp
template<typename T>
class MyClass {};

template<>
class MyClass<int> {};

template<>
class MyClass<int> {};
```
