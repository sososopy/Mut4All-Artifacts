Mutation Operator: Specialization Access with No Instantiation

Applicable Code Construct: Template Classes and Methods

Mutation Rule: Target a template class that contains a nested template class. Access a nested template class specialization without instantiating it or using it in a complete construct.

Step-by-Step Instructions: 
1. Identify a template class that has a nested template class.
2. Within a member function of another class or template, access the nested template class specialization using the base template class, without instantiating it.
3. Ensure that the accessed specialization is not used in any valid C++ construct like a variable declaration or function call.

Example:
Original Code:
```
template <typename T>
class Outer {
public:
  template<int N>
  class Inner {};
};

void test() {
  Outer<int>::Inner<5> obj; // Valid instantiation
}
```

Mutated Code:
```
template <typename T>
class Outer {
public:
  template<int N>
  class Inner {};
};

void test() {
  Outer<int>::Inner<5>; // Accessing specialization without instantiation
}
```

This mutation operator leverages the compiler’s handling of template specializations and incomplete constructs, which are common sources of crashes in compilers due to their complexity in name resolution and instantiation logic.
