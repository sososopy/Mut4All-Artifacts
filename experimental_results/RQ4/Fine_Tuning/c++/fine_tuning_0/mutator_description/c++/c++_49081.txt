Mutation Operator:
Target: Generic lambda expressions used inside templates.
Mutation Rule: Locate a generic lambda expression that is defined within a template function or class. Replace the generic lambda's parameter type with an explicit non-generic type that is defined outside the lambda. If the lambda is currently invoked with a generic type, ensure the call is updated to reflect the explicit type change.
Example: Given a lambda expression `auto lambda = [](auto x) { };` inside a templated construct, change it to `auto lambda = [](int x) { };` where `int` is a type available within the current scope.
