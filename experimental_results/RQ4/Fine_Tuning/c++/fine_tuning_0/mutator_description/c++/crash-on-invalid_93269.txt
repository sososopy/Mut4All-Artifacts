mutation Operator: Target: template functions with parameter packs. Mutation Rule: 1. Identify a template function that takes a parameter pack. 2. Within the template function, create a lambda function. 3. Apply a Clang-specific attribute such as __attribute__((diagnose_if)) to the lambda. 4. Use the parameter pack as the first argument to the attribute, ensuring it remains unexpanded. Example: Original: template <typename... Args> void f() { } Mutated: template <typename... Args> void f() { [] () __attribute__((diagnose_if(Args, "message", "error"))) {}(); }
