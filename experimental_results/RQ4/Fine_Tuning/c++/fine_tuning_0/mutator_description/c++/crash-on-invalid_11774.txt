Mutation Operator 1: Nested Namespace Mutation

Target Code Construct: This operator targets nested namespaces within a C++ source file.

Mutation Rule: 

Step 1: Identify nested namespaces within the seed program. Nested namespaces are those where one namespace is defined within another. For example, in `namespace A { namespace B { ... } }`, `B` is a nested namespace within `A`.

Step 2: Introduce a syntax error within the nested namespace. One way to achieve this is by adding a semicolon immediately after the namespace keyword of the nested namespace. For instance, if `namespace B` is nested within `namespace A`, change `namespace B` to `namespace B;`.

Example:

Original Code:
```cpp
namespace A {
    namespace B {
        int x = 0;
    }
}
```

Mutated Code:
```cpp
namespace A {
    namespace B; { // Syntax error introduced here
        int x = 0;
    }
}
```

This mutation leverages the nested namespace structure to introduce a syntax error, which can be effective in triggering compiler bugs related to namespace parsing and error recovery mechanisms.
