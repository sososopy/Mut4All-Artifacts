Mutation Operator: Target Default Member Initializer with Lambda in Class Template

Mutation Rule: Identify a class template with a default member initializer. If the default member initializer contains a lambda expression, replace it with a different, simple expression, such as a literal or a previously declared variable. For example, if a class template has a member `int x = []() { return 0; }();`, replace the lambda with a simple expression like `int x = 0;` or `int x = some_var;`, where `some_var` is a previously declared variable in the same scope.
