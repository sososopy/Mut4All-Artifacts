mutation Operator: Builtin Function Argument Mismatch. Target: Calls to builtin functions. Mutation Rule: Identify calls to builtin functions in the seed program. For each call, intentionally mismatch the expected argument types. For example, if a builtin function expects a pointer type, pass an integer or a different type instead. This triggers semantic analysis errors related to type checking and alignment assumptions, causing the compiler to crash.
