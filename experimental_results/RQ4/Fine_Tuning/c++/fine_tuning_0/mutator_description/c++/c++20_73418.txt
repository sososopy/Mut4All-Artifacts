Mutation Operator: Target Nested Lambda with Requires Clause

Mutation Rule: 
1. Identify a nested lambda function within another lambda. The outer lambda should capture a variable or parameter, and the inner lambda should have a `requires` clause.
2. Modify the inner lambda's `requires` clause to include a pack expansion. For example, if the original requires clause checks `obj.size(params...)`, mutate it to include a pack of parameters that are expanded within the requires clause.
3. Ensure that the pack expansion involves a member function or operation that takes the expanded parameters.

Example: Original code might be: 
```cpp
auto outer_lambda = [&v](auto x) { return std::ranges::any_of(v.front(), [](auto y) { return [](auto obj) requires requires { obj.size(); } { return false; }(y); }); };
```
Mutated code becomes: 
```cpp
auto outer_lambda = [&v](auto x) { return std::ranges::any_of(v.front(), [](auto y) { return [](auto obj, auto... params) requires requires { obj.size(params...); } { return false; }(y); }); };
```
