mutation Operator: Target a compound statement within a function. Locate a compound statement that contains multiple expressions or statements. Select a statement that modifies a variable or performs an assignment. Change the assigned variable to a const-qualified variable that is not modified within the original compound statement. If no such const-qualified variable exists, introduce a new const-qualified variable at the beginning of the function with an arbitrary initial value and use it as the assigned variable. Example transformation: Original: { v = a + b; y = 2; } Mutated: const int x = 10; { v = a + b; x = 2; }
