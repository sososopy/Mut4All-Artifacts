Mutation Operator: Apply CTAD to Template Aliased Type with CRTP

Target: This mutation operator targets template alias declarations that use CRTP (Curiously Recurring Template Pattern), especially when the aliased type is constructed in a context that supports class template argument deduction (CTAD).

Mutation Rule: 
1. Identify a template alias that uses CRTP. The alias should refer to a template class that takes at least one template parameter.
2. Ensure the aliased class supports class template argument deduction (CTAD).
3. In a function or a context where the aliased type is used, replace the explicit template alias construction with an implicit one by removing the template arguments.
4. Ensure the context allows CTAD to deduce the correct template arguments.

Example Before Mutation:
template <typename T>
using SpecialFoo = Foo<T, Derived<T>>;

SpecialFoo<int> Doit() { return SpecialFoo<int>(new Derived<int>); }

Example After Mutation:
SpecialFoo Doit() { return SpecialFoo(new Derived<int>); }
