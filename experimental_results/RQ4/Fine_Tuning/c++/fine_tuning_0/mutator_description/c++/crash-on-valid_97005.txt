mutation Operator: Conditional Operator Array Type Change  
Target: Conditional Operator Expression Using Arrays  
Mutation Rule:  
1. Identify a conditional (ternary) operator expression where both true and false branches are array expressions.  
2. If the true and false branches are arrays of different types or sizes, change one branch to match the type and size of the other.  
3. Specifically, replace one of the arrays with an equivalent array of different size or type, such that the common type deduction in the conditional operator becomes ambiguous or inconsistent.  
Example:  
Original: `bool a; constexpr const unsigned char c[] = { 5 }; constexpr const unsigned char d[1] = { 0 }; auto b = (a ? d : c);`  
Mutated: `bool a; constexpr const unsigned char c[] = { 5 }; constexpr const int d[1] = { 0 }; auto b = (a ? d : c);`
