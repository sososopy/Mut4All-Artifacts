Mutation Operator: Template Constraint Inversion

Target: Template declarations with `requires` constraints

Rule: Identify templates with a `requires` clause. Invert the condition within the `requires` clause to its logical opposite. For example, if the original condition is `requires (Condition)`, change it to `requires (!Condition)`.

Example:
Original: 
template <typename T> struct S { S() requires (sizeof(T) > 1); };

Mutated: 
template <typename T> struct S { S() requires (!(sizeof(T) > 1)); };
