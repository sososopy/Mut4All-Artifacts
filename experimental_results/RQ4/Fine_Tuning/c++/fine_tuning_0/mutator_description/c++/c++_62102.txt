Mutation Operator: Target the use of defaulted comparison operators in structures with friend declarations. Step 1: Identify a structure that declares a friend comparison operator (e.g., `operator==`). Step 2: Implement this comparison operator as a defaulted function using `= default;`. Step 3: Ensure that the operator relies on a template-based comparison within the structure. For instance, use a template operator that compares an integer with a member variable of a templated type. Step 4: Invoke the comparison operator within the structure to trigger instantiation. The mutation targets the coupling between defaulted operators and template instantiation, which can expose weaknesses in the compiler's handling of template substitutions and instantiation diagnostics.
