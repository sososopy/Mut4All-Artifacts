Mutation Operator: Enum Forward Declaration with Template Instantiation

Target Construct: Enum forward declaration combined with class/struct template instantiation

Mutation Rule: 
Step 1: Identify any usage of an enum forward declaration in the code. This is typically in the form `enum EnumName;` or `enum class EnumName;` without a corresponding definition within the current scope.

Step 2: Locate a template class or struct that is being instantiated elsewhere in the code. This could be a template like `template <typename T> struct SomeStruct { /*...*/ };`.

Step 3: Modify the code to instantiate the template using the forward-declared enum as the template argument. For instance, change `SomeStruct<int>` to `SomeStruct<EnumName>` where `EnumName` is the forward-declared enum.

Example: Given the seed program, if we have a forward declaration `enum struct EnumClass;` and a template instantiation `is_class<int>::value;`, mutate it to instantiate as `is_class<EnumClass>::value;` where `is_class` is the template and `EnumClass` is the forward-declared enum.
