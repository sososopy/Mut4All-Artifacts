Mutation Operator: Template Argument Modification in Partial Specialization. Target: Class or Struct Template Partial Specialization. Rule: 1. Identify a class or struct template with partial specialization. 2. Locate the partial specialization declaration. 3. Modify the template argument in the partial specialization to an unrelated or invalid type. Example: Original: template<typename T> struct MyStruct; template<> struct MyStruct<int> {}; Mutated: template<> struct MyStruct<double> {};
