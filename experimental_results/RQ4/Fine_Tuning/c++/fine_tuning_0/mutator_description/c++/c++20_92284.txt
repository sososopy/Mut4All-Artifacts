Mutation Operator: Target structure: typedef alias of array type Target location: variable definition with type of typedef alias Mutation rule: Select an existing type alias using a typedef keyword that represents an array type. In the code where a variable is declared using this type alias, replace the initializer from brace-init-list to parentheses. If the selected array type is a constant array, the number of elements in the initialization should be equal to the size of the array; if it is a variable array, the number of elements in the initialization should be arbitrary, the same as or different from the size of the array. Before mutating, ensure that the selected typedef type alias is used in variable initialization and that the initial value exists. For example, the original code: using T = int[1]; T a{42}; or using T = int[]; T a{42,43}; Mutated code: using T = int[1]; T a(42); or using T = int[]; T a(42,43);
