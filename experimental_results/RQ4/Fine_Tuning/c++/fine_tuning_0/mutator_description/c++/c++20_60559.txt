Mutation Operator: Add a lambda inside a lambda. Target: Any lambda function in the code. Mutation Rule: Locate a lambda function within the code. Inside this lambda, add another lambda that captures its surrounding scope and performs a simple operation, such as returning a fixed value or printing a fixed message. Ensure that the inner lambda is invoked within the outer lambda. If the outer lambda has parameters, pass appropriate values to the inner lambda to match its parameter requirements. Example: Original Code: auto outer = []() { return 0; }; Mutated Code: auto outer = []() { auto inner = []() { return 1; }; return inner(); };
