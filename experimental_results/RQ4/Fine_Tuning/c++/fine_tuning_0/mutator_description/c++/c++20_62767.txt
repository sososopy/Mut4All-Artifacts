mutation Operator: Target: Use of templated structs and deduction guides. Mutation Rule: 1. Identify any templated struct with a deduction guide. 2. If the struct template has a deduction guide that uses constexpr or variadic arguments in its constructor, modify the guide to use a more complex argument type or remove the deduction guide entirely. 3. In the main function or wherever the deduction guide is used, replace the struct instantiation with a direct use of the template, possibly with incorrect or unexpected arguments to break the deduction process. Example: Original: template<long unsigned int> struct str { constexpr str(...) {} }; template<long unsigned int N> str(const char (&)[N]) -> str<N>; Mutated: template<long unsigned int> struct str { constexpr str(...) {} }; // Removed deduction guide str<5> s = str<5>(); // Directly using template with explicit arguments
