Mutation Operator 1: Template Specialization with Non-matching Argument Type Target: Template specialization within a namespace. Rule: Locate a template specialization within a namespace. For each template specialization, identify the argument type being specialized. Change the argument type to a type that does not match any existing specialization. Example: Given template <class Tp> extern _cpc _cpcvr<const Tp>; transform it to template <class Tp> extern _cpc _cpcvr<volatile Tp>;
