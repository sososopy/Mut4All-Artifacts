Mutation Operator: Struct with Invalid Reference Capture

Target Construct: Struct and Function within a Struct

Mutation Rule:
1. Identify a struct within the code. If there is no struct, create a new struct declaration within the scope of the function.
2. Inside the struct, create or identify a constexpr member function.
3. Within the constexpr function, introduce a reference to a local variable or parameter that is defined outside the struct, ensuring that the reference is invalid or not captured properly.
4. If no suitable reference is present, declare a new variable within the function scope and attempt to capture it by reference inside the struct's constexpr function.
5. Ensure that the reference is used in a return statement or as part of an expression that requires evaluation, triggering potential invalid capture issues.

Example Mutation:
Original: int main() { int i = 1; struct A { constexpr int a() { return i; } }; }
Mutated: int main() { int&& i = 1; struct A { constexpr int a() { return i; } }; }
