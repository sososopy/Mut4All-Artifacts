mutation Operator 1: Replace Lambda Expression with Function Definition
- Target: Lambda expressions in the code
- Rule: Identify any lambda expression in the code. Convert the lambda into a regular function definition. Adjust parameter types and return type accordingly.
- Example: If the original code contains auto a = [](int x) { return x + 1; };
- Mutated Code: Replace it with int a(int x) { return x + 1; };
