mutation Operator: Target: Template and Lambda in Unevaluated Context. Rule: Identify any usage of template type alias that involves a lambda expression. Transform the lambda expression by adding a constraint, such as a concept, to the lambda's template parameter. Example: If you have `template<class T> using U = decltype([](){})`, mutate it to `template<class T> using U = decltype([]<ConceptName> {})`, where `ConceptName` is a concept declared elsewhere in the code or introduced in the mutation if no concept is present. This mutation exploits the compiler's handling of constrained lambdas in unevaluated contexts, which is prone to triggering bugs.
