Mutation Operator: Enum Scope Mutation within Struct Context

This mutation operator targets enum declarations within struct or class contexts and involves scope manipulation and using enumerator declarations. 

Mutation Rule:
1. Identify a struct or class that contains an enum declaration. If no such enum exists, create one with at least three enumerators, assigning integer values incrementally starting from 0. Example: enum ExampleEnum { X = 0, Y = 1, Z = 2 };.
2. Use a using alias to bring the struct or class into a shorter scope. Example: using S = StructName;.
3. Within a function or the main body, use the using enum statement to bring all enumerator names of the enum into the current scope. Example: using enum S::ExampleEnum;.
4. Construct a compound expression using at least two enumerators brought into scope, with bitwise or arithmetic operations. Example: int result = (X | Y);.
5. Compile and run the program to observe if the inclusion of enumerators within using enum statements, followed by their use in compound expressions, leads to compiler crashes or unexpected behavior.
