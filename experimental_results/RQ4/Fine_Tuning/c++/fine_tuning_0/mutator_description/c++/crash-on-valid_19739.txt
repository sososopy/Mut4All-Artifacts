Mutation Operator: Explicit Base Inherited Constructor Specialization Removal

1. Target: This operator targets classes that use inheritance and have at least one base class with inherited constructors.
2. Mutation Rule:
   - Identify a derived class that inherits from a base class with constructors marked for inheritance.
   - For each constructor inherited explicitly in the derived class, remove the explicit specialization from the derived class.
3. Example:
   - Given a base class `Base` with constructors and a derived class `Derived` that explicitly specializes an inherited constructor, remove the explicit specialization from `Derived`. If `Derived` has `using Base::Base;`, remove `using Base::Base;` from `Derived`.
