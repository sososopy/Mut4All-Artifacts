Mutation Operator 1: Struct Compound Statement Mutation

Target: Structs and Unions

Mutation Rule:

Identify a struct or union in the code. Within the body of the struct or union, replace an internal statement with a compound statement. If the internal statement is a simple declaration or expression, wrap it in a pair of curly braces `{}` to form a compound statement. If the internal statement is already a compound statement, introduce a nested compound statement by adding an additional pair of curly braces around it. Ensure that the resulting compound statement is syntactically valid but semantically unusual or unexpected to increase the likelihood of triggering a compiler bug. Use existing types, variables, and expressions to construct the compound statement, avoiding the introduction of new elements that are not declared in the seed program.

Example:

Original: struct { int a; };

Mutated: struct { { int a; } };
