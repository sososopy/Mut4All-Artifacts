Mutation Operator: Function Call with Missing Arguments

Target Code Construct: Function Call

Mutation Rule:
1. Identify a function call in the seed program. Ensure that the function being called requires one or more arguments.
2. Remove all the arguments from the function call, leaving only the function name followed by an empty pair of parentheses.
3. Do not modify the function definition or declaration; only the function call is altered.

Example:
Given Function: int add(int a, int b) { return a + b; }
Original Call: int sum = add(x, y);
Mutated Call: int sum = add();
