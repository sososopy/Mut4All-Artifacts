Mutation Operator:
Target Construct: Array Initialization and Structured Binding
Mutation Rule: 
1. Identify any multi-dimensional array initialization. 
2. Replace the nested initialization values with a sequence using a single dimension, filling the array in row-major order.
3. Follow the array initialization with a structured binding that deconstructs the array.
4. Ensure that the code is encapsulated within a constexpr function.
Example:
Original: int arr[2][2] = {{1, 2}, {3, 4}};
Mutated: int arr[2][2] = {1, 2, 3, 4}; auto [a, b] = arr;
