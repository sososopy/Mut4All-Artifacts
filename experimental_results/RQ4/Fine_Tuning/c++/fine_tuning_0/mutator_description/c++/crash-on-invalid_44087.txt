
Mutation Operator: Faulty Member Access on Invalid Types

Target Construct: Member Access Expressions (dot ‘.’ and arrow ‘->’ operators).

Mutation Rule:
1. Identify member access expressions in the form of `Base.Member` or `Base->Member`.
2. Confirm that the base (`Base`) is a valid expression. 
3. Mutate the base type to a type that doesn’t support member access, such as a non-struct, non-class type like `int`, `char`, `float`, or an undeclared type.
4. If the mutated base type is not inherently invalid (e.g., it's a primitive type), ensure that the mutation results in a semantically incorrect member access by selecting a member (`Member`) not accessible by the mutated base type.

Example:
Before Mutation: `struct MyStruct { int x; }; MyStruct obj; int y = obj.x;`
After Mutation: `int obj; int y = obj.x;`
