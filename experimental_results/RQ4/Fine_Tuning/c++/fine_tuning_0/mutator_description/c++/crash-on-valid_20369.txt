Mutation Operator: Target code construct: Inline namespaces and template specializations. 

Mutation Rule: 

1. Identify any `inline namespace` declaration in the seed program. 

2. Check if there are any template function declarations within the inline namespace. If not, skip this mutation. 

3. Select a template function declared within the inline namespace. 

4. Outside of the inline namespace, provide an explicit specialization for the selected template function. 

5. Ensure that the specialization uses a type that is already available in the seed program. If no such type exists, declare a basic type (e.g., `int`) and use it for the specialization. 

Example: Before Mutation: inline namespace { template <typename T> void bar(T); } After Mutation: inline namespace { template <typename T> void bar(T); } template <> void bar(int);
