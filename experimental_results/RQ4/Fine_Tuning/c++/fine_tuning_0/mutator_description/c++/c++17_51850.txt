Mutation Operator: Templated Lambda Mutation

Target: Templated Lambda Expression

Rule: Identify a templated lambda expression within the seed program. For each template argument used in the lambda, create a switch statement inside the lambda body. Within each switch case, invoke the lambda itself recursively using the template argument and case value as template parameters. The recursive call should also include a different parameter if the lambda takes parameters.

Example: Original Code: auto lambda = []<int N>(int x) { /* original body */ };

Mutated Code: auto lambda = []<int N>(int x) { switch(x) { case 0: lambda.operator()<N, 0>(); break; case 1: lambda.operator()<N, 1>(); break; /* other cases */ } };

This mutation operator leverages the recursive nature and template instantiation mechanism of lambdas to stress the compiler's ability to handle complex template meta-programming constructs.
