Mutation Operator: Transform Dependent Type to Non-dependent Type

Target: Template-dependent types in template functions

Mutation Rule: 

1. Identify a template function in the code.

2. Within the template function, locate any dependent type that uses template parameters (e.g., `bla<T>::template blo<T>`).

3. Transform the dependent type into a non-dependent type by replacing the template parameters with a concrete type.

Example:

Given Seed Code:
```cpp
template <class T>
constexpr bool pred() {
    return typename bla<T>::template blo<T>{};
}
```

Mutated Code:
```cpp
template <class T>
constexpr bool pred() {
    return typename bla<int>::template blo<int>{};
}
```

Rationale: By transforming a dependent type to a non-dependent type within a template function, we exploit the compiler's need to resolve type dependencies, which is a frequent source of compiler bugs, especially related to template instantiation and name lookup.
