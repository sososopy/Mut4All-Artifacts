
Mutation Operator: Address-of-Label with Arithmetic in Function

Target: Function Definitions

Rule: Within a function definition, use the address-of-label GNU extension, and perform arithmetic operations between address labels, then compare the result with a function name.

Steps:
1. Identify or introduce a function with any name, e.g., `foo`.
2. Within the function body, declare at least two labels, e.g., `label1`, `label2`.
3. Use the address-of-label operator (`&&`) followed by label names to obtain their addresses.
4. Perform an arithmetic operation (e.g., subtraction) between these label addresses.
5. Compare the result of this arithmetic operation with the function name using a comparison operator (e.g., `<` or `>`).
6. Ensure the above expression is part of a statement within the function body.

Example: 
```cpp
void foo() { &&label1 - &&label2 < foo; label1: ; label2: ; }
```
