Mutation Operator: Target a lambda expression with trailing return type. Replace the trailing return type with decltype(auto) and provide a nested lambda within the original lambda that returns a constant integer. Assign the outer lambda to a function pointer with the appropriate signature. For example, change a lambda like 'auto lambda = [](auto t) -> decltype([] { return 0; }() ){ return t; };' to 'int(*f)(int) = [](auto t) -> decltype([] { return 0; }() ){ return t; };'.
