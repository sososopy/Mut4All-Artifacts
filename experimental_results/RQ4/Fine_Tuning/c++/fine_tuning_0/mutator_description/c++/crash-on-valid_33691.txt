mutation Operator: Target: Template & Namespace Interaction. Mutation: Replace friend template function with a non-friend function and move it outside the class. Steps: 1. Identify a friend template function within a class. 2. Remove the 'friend' keyword and move the function definition outside the class. 3. Ensure that the function signature remains the same, and adjust any access to class members accordingly. Example: Original: template <typename> struct X { template <typename T> friend void func() { /* implementation */ } }; Mutated: template <typename> struct X { // friend keyword removed and function moved out }; template <typename T> void func() { /* implementation */ }
