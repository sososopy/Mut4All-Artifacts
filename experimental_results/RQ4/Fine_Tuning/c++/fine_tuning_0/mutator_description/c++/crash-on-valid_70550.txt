Mutation Operator:
Target: Binary Operator Overloading in Template Classes
Mutation Rule: 1. Identify a binary operator overload (e.g., operator+) defined within a template class. 2. Replace the existing implementation of the binary operator overload with a different binary operation (e.g., change addition to multiplication). 3. Ensure that the replacement operation uses existing member variables or member functions of the template class for operands. 4. Retain the original function signature to ensure that the mutation is focused on the operator's behavior rather than its interface.
Example:
Original: template <typename T> class MyClass { T data; public: MyClass(T val) : data(val) {} MyClass operator+(const MyClass& other) const { return MyClass(this->data + other.data); } };
Mutated: template <typename T> class MyClass { T data; public: MyClass(T val) : data(val) {} MyClass operator+(const MyClass& other) const { return MyClass(this->data * other.data); } };
