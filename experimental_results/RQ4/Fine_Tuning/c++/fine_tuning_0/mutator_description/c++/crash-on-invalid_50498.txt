mutation Operator: Target Construct: Struct and Variable Usage Mutation Rule: Identify a struct type in the code. Create a variable of that struct type. In a comma expression, use the struct variable with another variable of a different type. Try to access a member of the struct from the result of the comma expression. Example: Given a struct declaration like struct A { int m; }; and a variable declaration int n;, create a variable of type A. Use this variable in a comma expression with n, such as (var1, n), and attempt to access a member, var2 = (var1, n).m;.
