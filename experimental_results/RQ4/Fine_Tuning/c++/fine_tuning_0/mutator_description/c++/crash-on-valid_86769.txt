mutation Operator: Template Friend Class Constraint Generalization

Target Construct: Template Friend Class Declaration

Mutation Rule: Identify a friend class template declaration that uses a concept-based constraint. Replace the concept with its equivalent expression that uses traditional type traits or SFINAE (Substitution Failure Is Not An Error) techniques.

Example: Given a friend class template declaration like:
```cpp
template <X U>
friend class Y;
```
Replace it with:
```cpp
template <typename U, typename = std::enable_if_t<X<U>>>
friend class Y;
```
