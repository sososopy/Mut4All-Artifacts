Mutation Operator: Target the initialization of objects with aggregate types using `new` and brace-initialization.
1. Identify all aggregate types in the seed program. An aggregate type can be a struct, array, or class without private or protected non-static data members, user-provided or inherited constructors, virtual functions, or virtual base classes.
2. For each aggregate type, locate the expressions that create new objects using the `new` keyword and initialize them with parentheses.
3. If such an expression is found, replace the parenthesis-enclosed arguments with a single brace-enclosed argument. For example, if you have `new A(0, 1)`, mutate it to `new A({0, 1})`.
4. Ensure that the arguments within the braces match the types and number of the aggregate's members to avoid semantic errors. If the original expression used default initialization (i.e., no arguments), no mutation is applied.
