mutation Operator: Target: Function Templates with Multiple Parameters, including Parameter Packs. Mutation Rule: 1. Identify function templates with multiple parameters, particularly those including parameter packs. 2. If there is a parameter pack followed by regular parameters, swap their positions so that the parameter pack is the last parameter. Example: Original: template<typename T, typename... Args, typename U> void func(T t, Args... args, U u) {...} Mutated: template<typename T, typename U, typename... Args> void func(T t, U u, Args... args) {...}
