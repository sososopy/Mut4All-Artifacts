Mutation Operator

Target Code Construct: Function Template with Default Arguments
Applicable Context: Apply to function templates with default arguments in function parameters.

Mutation Rule: 
1. Identify a function template in the code. 
2. Locate any parameters that have default arguments. 
3. Replace the default argument with an expression that involves a cast. 
4. Ensure that the cast expression is valid according to the C++ standard.

Example:

Before Mutation:
```cpp
template <typename T>
void foo(T x = 42) {
  // function body
}
```

After Mutation:
```cpp
template <typename T>
void foo(T x = static_cast<T>(42)) {
  // function body
}
```
