Mutation Operator: Deduction Guide Misconfiguration

Target Code Construct: Class Template with Deduction Guides

Mutation Rule:
1. Identify a class template in the seed program. If none exists, introduce a simple class template, for example:
```cpp
template <typename T> class MyClass {};
```
2. Introduce a deduction guide for the class template that does not match any constructor signature within the class template. For example, if the class template is `MyClass`, a non-matching deduction guide would be:
```cpp
MyClass() -> MyClass<int>;
```
3. Ensure that the deduction guide uses an existing class template name and potentially existing types from the program to maintain relevance and integration with the seed code.

Example:
1. Given a seed class template:
```cpp
template <typename T> class MyClass {};

```
2. Apply the mutation:
```cpp
template <typename T> class MyClass {};
MyClass() -> MyClass<int>;
```
