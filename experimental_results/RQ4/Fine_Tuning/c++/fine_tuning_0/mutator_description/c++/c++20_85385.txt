Mutation Operator: CTAD with Alias Template

Mutation Description: This operator targets alias templates that are used with class template argument deduction (CTAD). The mutation involves modifying the alias template to use its intended template parameters incorrectly when deducing types, which can trigger compiler errors or crashes.

Mutation Steps:
1. Identify an alias template that uses template parameters to alias a class or struct.
2. Locate a function or method where the alias template is being used with CTAD (i.e., without explicitly providing template arguments).
3. Alter the alias template usage by providing an incorrect or unexpected argument that does not match the expected template parameter types. This can involve passing non-type arguments to type parameters or providing arguments that cannot be deduced correctly.

Example Mutation:
Given a code segment with an alias template using CTAD like this:

template <typename T> using Alias = SomeClass<T>; void func() { Alias obj; }

Modify the alias usage to:

void func() { Alias(1); }

This change attempts to use CTAD with an invalid argument, which can expose weaknesses in the compiler's template argument deduction and alias template handling logic.
