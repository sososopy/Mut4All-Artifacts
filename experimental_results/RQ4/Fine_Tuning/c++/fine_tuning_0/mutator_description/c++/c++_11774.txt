Mutation Operator: Namespace Insertion and Removal

Target: Namespace declarations in the C++ code.

Mutation Rule: 

1. Identify all the namespaces in the seed program. For example, if the namespaces are `A`, `B`, `C` in hierarchical form, note them down.

2. Choose a namespace at random. Let's say `B`.

3. Insert a new namespace within the chosen namespace. For instance, if `B` is chosen, transform it to `namespace B { namespace X { /* old content of B */ } }` where `X` is a new namespace name.

4. Optionally, remove the newly inserted namespace and flatten the structure back to increase the chance of invalid syntax.

Example:

Original code:
