Mutation Operator: CRTP Consteval Mutation

Target: Classes using CRTP (Curiously Recurring Template Pattern) with consteval functions

Mutation Rule:
Step 1: Identify a CRTP base class with a consteval function.
Step 2: Inside the consteval function, locate any conversion using static_cast or dynamic_cast.
Step 3: Modify the cast to use a different type from the CRTP hierarchy or introduce a cast to pointer/reference type.
Step 4: Ensure the return type is consistent with the modified cast.

Example:
Original Code:

template <typename Derived>
struct Base {
    consteval void foo() {
        return static_cast<Derived>(*this).bar();
    }
};

Mutated Code:

template <typename Derived>
struct Base {
    consteval void foo() {
        return static_cast<Derived *>(this)->bar();
    }
};
