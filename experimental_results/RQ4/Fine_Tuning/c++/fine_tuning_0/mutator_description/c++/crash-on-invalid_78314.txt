Mutation Operator: Target a class with overloaded operators. In the class definition, identify a deleted operator overload and a templated operator overload. Modify the seed by invoking the deleted operator within the templated operator overload. For example, if a class has `void operator++() = delete;` and a templated overload `template <class T> void operator++(int)`, within the templated overload, instantiate an object of the class and invoke the deleted operator, such as using `++object;`.
