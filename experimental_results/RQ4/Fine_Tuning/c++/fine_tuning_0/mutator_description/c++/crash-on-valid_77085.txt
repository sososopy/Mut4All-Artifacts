Mutation Operator:
Target Construct: Union with In-Class Initialization
Mutation Rule: 
1. Locate a union that contains multiple member types, such as primitive types and structs.
2. Ensure at least one struct has a flexible array member.
3. Initialize the union using an empty initializer list (e.g., `union foo = {}`).
4. Verify that the flexible array member is part of a struct within the union and that the union is initialized without specifying any member.
Example:
```cpp
struct MyStruct {
  int a;
  char b[];
};
union MyUnion {
  int x;
  MyStruct y;
} instance = {}; // Apply empty initializer
```
