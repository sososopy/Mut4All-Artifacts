Mutation Operator: Target enum Declarations in a Codebase
Locate the enum declarations within the codebase. If an enum is declared with a type (e.g., enum class or enum struct), replace its name with a reserved keyword such as 'class' or 'struct'. Ensure that the enum is used in a context where a semantic analysis or code generation phase of the compiler can be triggered after parsing. Example Before Mutation: enum class Colors { Red, Green, Blue }; After Mutation: enum class { Red, Green, Blue };
