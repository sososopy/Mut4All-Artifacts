mutation Operator: Target for-statement with a conditional in range declaration; Replace the initialization part of a range-based for-loop's declaration with a standalone conditional expression that does not yield a valid range type. For example, in the loop for (auto x = n ? 1 : 2 : a), transform it into a statement like for (auto x = (condition) ? (expression) : (expression)), where neither expression is a range, leading to the use of an invalid range.
