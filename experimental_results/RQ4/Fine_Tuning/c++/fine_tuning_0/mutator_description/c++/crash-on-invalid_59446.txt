mutation Operator: Invalid Access Specifier in Class Declaration

Target Construct: Class Declarations and Member Functions

Mutation Rule:
1. Target any existing class or struct declaration.
2. Within the class, select any member function or constructor.
3. Add an invalid access specifier (e.g., 'virtual' or 'static') before or after the function definition.
4. Ensure the access specifier is not valid in the current context (e.g., outside the class definition).

Example:
Original: struct MyClass { void myFunction(); }; Mutated: struct MyClass { virtual void myFunction(); };
