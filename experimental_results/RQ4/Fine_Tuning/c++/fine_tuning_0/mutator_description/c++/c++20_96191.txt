Mutation Operator: Target member operator methods (e.g., operator delete) within a class. Mutation Rule: 1. Identify a member operator method, such as operator delete, within a class definition. 2. Change the first parameter type to a class type that is declared but may not be intended for that operator method. 3. Ensure the class type used as the parameter is already declared in the seed program. 4. For example, if the original operator delete takes a non-class type as the first parameter, replace it with any existing class type. Example: Original code: struct S {}; struct T { void operator delete(S) {} }; Mutated code: struct S {}; struct T { void operator delete(T) {} };
