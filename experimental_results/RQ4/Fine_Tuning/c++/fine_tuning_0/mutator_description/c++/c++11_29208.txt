Mutation Operator: Initializer List R-Value with begin()

Target Construct: Initializer List in functions

Mutation Rule: 

1. Identify any initializer list within the seed program. For example, in a function that initializes a variable using an initializer list, locate this construct.

2. Modify the identified initializer list by appending `.begin()` to it. This turns the initializer list into a call to its `begin()` method, which can potentially trigger compiler issues when the list is used as an r-value.

3. Ensure that the modified code is still syntactically correct but semantically challenging for the compiler, thereby increasing the likelihood of exposing compiler bugs.

Example: Original code:
```
std::array<int, 3> arr = {1, 2, 3};
```
Mutated code:
```
auto it = std::array<int, 3>{1, 2, 3}.begin();
```
This mutation specifically targets the compiler's handling of r-value initializer lists when invoking member functions like `begin()`.
