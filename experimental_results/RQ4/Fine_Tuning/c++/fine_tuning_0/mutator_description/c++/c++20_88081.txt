Mutation Operator: Requires Clause Mutation in Structs

Mutation Target: Struct declarations using constructor requires clauses. 

Mutation Rule: 
1. Identify a struct that contains a constructor with a requires clause. 
2. Within the constructor, locate the requires clause. 
3. Modify the requires clause by encapsulating the current constraint expression within an additional ‘requires’ expression. 
4. Ensure that the original constraint logic is preserved while it is nested within the new requires expression. 

Example: 
Original: 
struct S { S(auto value) requires (requires () { [&] -> decltype(value) {}; }) {}; }; 

Mutated: 
struct S { S(auto value) requires (requires (requires () { [&] -> decltype(value) {}; })) {}; };
