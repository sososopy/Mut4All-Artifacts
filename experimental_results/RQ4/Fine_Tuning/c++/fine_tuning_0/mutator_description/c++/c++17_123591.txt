Mutation Operator: Target: Template Declarations, specifically template using declarations. Mutation Rule: Identify any template using declarations in the form template <typename T> using TypeAlias = Type;. Change the using declaration to a typedef by removing the 'using' keyword and replacing it with 'typedef', and also adjust the syntax to match typedef semantics. Example: Given code template <typename T> using TypeAlias = Type; mutate it to template <typename T> typedef typename TypeAlias Type;.
