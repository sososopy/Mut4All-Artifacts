Mutation Operator: Target: Function Calls within Lambda Expressions. Transformation Rule: Identify lambda expressions that invoke functions using the auto keyword for parameter type deduction. In the function call expression inside the lambda, modify the parameter type deduction by explicitly specifying the type using decltype(auto) for one or more parameters. Pseudo-code Example: Original: [lambda](auto param) { function_call(param); } Mutated: [lambda](auto param) { function_call(decltype(auto)(param)); }
