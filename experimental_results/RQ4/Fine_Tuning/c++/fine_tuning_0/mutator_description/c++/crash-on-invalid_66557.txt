mutation Operator: Target: Function and Variable Initialization. Mutation Rule: In a function's parameter list, replace a parameter of a compound type (struct, class, or union) with a parameter of a different compound type that is not implicitly convertible. If there is no compound type, replace a parameter of a built-in type (int, char, etc.) with a different built-in type that is not implicitly convertible. Example: Given a function definition `void foo(MyClass obj)`, replace it with `void foo(OtherClass obj)`. If the original parameter is of type `int`, replace it with `void foo(double obj)`.
