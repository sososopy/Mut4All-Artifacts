Mutation Operator: Remove Explicit Constructor Identifier

Description: This mutation targets class constructors with explicit identifier names preceding them, which can cause confusion and potential crashes when evaluated, especially in constant expressions or static assertions.

Mutation Steps: Identify a constructor definition in a class and check if there's an explicit identifier before the constructor name that matches the class name. Remove this explicit identifier to let the constructor be implicitly named by the class, ensuring it aligns with the standard constructor syntax.

Example: Given a class struct A { int A() { return 0; } };, identify the constructor int A() and remove the explicit identifier A before the constructor, resulting in struct A { int () { return 0; } };.
