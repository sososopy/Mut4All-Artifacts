mutation Operator: Apply to classes/structs with user-defined conversion functions. Rule: Locate a user-defined conversion function in a class/struct. If the function is marked with 'consteval', remove the 'consteval' keyword. If not, add the 'consteval' keyword before the function definition. Example: Given a struct with a conversion operator 'operator int() { return 1; }', if it’s marked with 'consteval', transform it to 'operator int() { return 1; }'. If it’s not marked, transform it to 'consteval operator int() { return 1; }'.
