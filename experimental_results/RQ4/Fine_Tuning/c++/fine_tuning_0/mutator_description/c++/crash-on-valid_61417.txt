Mutation Operator 1: Zero-Sized Bit Field in Structs and Classes

Target: Structs and Classes

Mutation Rule: 
1. Identify any struct or class definition in the code.
2. If none of the bit-fields have a size of zero, insert a new zero-sized bit-field.
3. If a zero-sized bit-field already exists, remove it or modify its size to be non-zero.

Example of Mutation:
Original Code:
```
struct Test {
    unsigned A_: 1;
    unsigned B_: 2;
};
```

Mutated Code:
```
struct Test {
    unsigned A_: 1;
    unsigned  : 0;
    unsigned B_: 2;
};
```
