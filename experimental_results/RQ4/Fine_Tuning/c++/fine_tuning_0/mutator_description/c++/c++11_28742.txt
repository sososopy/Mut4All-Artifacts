Mutation Operator: Variadic Template Instantiation  
Target: Variadic Template Class  
Mutation Rule:  
1. Select an existing variadic template class in the seed program.  
2. Inside the class, define another template member function or member class that uses variadic parameters to perform a type operation, like sizeof..., or a fold expression.  
3. Instantiate the variadic template class with a selection of types that vary in size or category, such as combining integral types with class types.  
4. Example Pseudo-code:
   - Seed Code:  
     ```cpp  
     template<typename... T> class A {};  
     ```  
   - Mutated Code:  
     ```cpp  
     template<typename... T> class A { void f() { int x = sizeof...(T); } };  
     A<int, char, double> a;  
     ```
