mutation Operator: Forward Declaration with Lambda Default Argument

Target: Functions with parameters having default values.

Mutation Rule: Identify a function parameter that has a default value. Replace the default value with a lambda expression that attempts to return a forward-declared type.

Steps:
1. Locate a function parameter with a default value.
2. Determine the type of the default value used.
3. If a forward-declared struct or class exists, replace the default value with a lambda expression that returns this forward-declared type.
4. Ensure that the lambda captures the default parameter if necessary, even though it might be invalid.

Example: Given a function `void foo(int x = 5)`, identify the default parameter `x`, and its default value `5`. Replace `5` with a lambda such as `[] { return fwd_declared_struct_or_class; }`, assuming `fwd_declared_struct_or_class` is a forward-declared type.
