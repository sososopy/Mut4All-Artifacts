Mutation Operator: Global Atomic Declaration Conversion
Target: Global variable declarations using _Atomic.
Mutation Rule: 
1. Identify global variable declarations that use the _Atomic qualifier.
2. Replace the _Atomic qualifier with the equivalent atomic type using the std::atomic template.
3. Ensure that the std::atomic template is properly included at the top of the file.
4. If using pointers, ensure the pointer is encapsulated within std::atomic.
Example: 
Before Mutation: _Atomic(unsigned int) a;
After Mutation: 
#include <atomic>
std::atomic<unsigned int> a;
