mutation Operator: Templated Lambda Usage

Target: Lambda functions with template parameters

Mutation Rule: Identify any lambda function that uses template parameters. Replace the template parameter with a concrete type that is used elsewhere in the program. If no such type exists, declare a new type or use a basic type like int or char. Ensure the lambda is still valid by checking its usage sites and adjusting them if necessary.

Example: Original Code: auto test_lambda = [&]<typename T>(T x) { /* ... */ };

Mutated Code: auto test_lambda = [&](int x) { /* ... */ };

Explanation: This mutation targets templated lambdas by concretizing their template parameters. It helps in checking the compiler's ability to handle templated lambdas and their instantiations.
