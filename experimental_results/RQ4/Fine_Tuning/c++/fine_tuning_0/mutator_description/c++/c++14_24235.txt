Mutation Operator: Add Constexpr to Function Return Type

Target Construct: Function Definition

Mutation Rule:

1. Identify a non-constexpr function in the seed program that has a simple return type and does not involve complex logic that would violate constexpr constraints.

2. Modify the function declaration by adding the `constexpr` specifier before the return type.

3. Ensure that the function body remains valid under constexpr constraints. If necessary, simplify the body to ensure it can be evaluated at compile time.

Example:

Original: int add(int a, int b) { return a + b; }

Mutated: constexpr int add(int a, int b) { return a + b; }
