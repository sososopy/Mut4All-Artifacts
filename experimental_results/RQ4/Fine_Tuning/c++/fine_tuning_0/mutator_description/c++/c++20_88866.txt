Mutation Operator: Target a function template with a template parameter pack. Add a concept constraint to one of the template parameters, and use this constrained parameter as a non-type template parameter (NTTP) in another template. Then, partially specialize this template using an unexpanded parameter pack in the NTTP's position. Finally, instantiate the partially specialized template. 

Explanation with Pseudo-code: 
1. Define a template class with a template parameter pack, e.g., `template <typename...Ts> struct index_by;`.
2. Define a concept that accepts one of the template parameters, e.g., `template <typename T> concept InitFunc = true;`.
3. Create a new template class with a constrained non-type template parameter (NTTP), e.g., `template <typename Indices, InitFunc<Indices> auto init> struct LazyLitMatrix;`.
4. Partially specialize the template class using an unexpanded parameter pack in the NTTP's position, e.g., `template <typename...Indices, InitFunc<index_by<Indices>> auto init> struct LazyLitMatrix<index_by<Indices...>, init> {};`.
5. Instantiate the partially specialized template with specific types and values, e.g., `LazyLitMatrix<index_by<int, char>, 42> inst;`.
