Mutation Operator 1: Transform Function to Lambda with Requires Clause Target: Function declarations with template parameters and a requires clause Mutation Rule:
Identify a function declaration that uses template parameters and has a requires clause.
Transform the function into a lambda expression by moving the function parameters and body into the lambda.
Remove the function keyword and replace it with auto.
Add the lambda capture list [] before the parameter list.
Ensure the requires clause is preserved in the lambda syntax.
Example:
Original code: template<typename T> requires SomeConstraint<T> void func(T x) { /*...*/ }
Transformed code: auto lambda = []<typename T>(T x) requires SomeConstraint<T> { /*...*/ };
