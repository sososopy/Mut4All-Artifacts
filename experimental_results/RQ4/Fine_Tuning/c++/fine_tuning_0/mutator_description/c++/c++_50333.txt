Mutation Operator 1: Template Static Assert Contradiction

Target Structure: Template class with friend function

Mutation Rule:  
1. Identify a template class with a friend function definition inside.  
2. Within the friend function, locate a static_assert statement.  
3. Duplicate the static_assert statement.  
4. Modify the condition of the duplicated static_assert to be the logical negation of the original condition.  
5. Ensure that both static_assert statements have the same error message.  

Example:  
Original: static_assert(std::is_same<T, fn_arg>::value, "Should be class_arg!");  
Mutated: 
static_assert(std::is_same<T, fn_arg>::value, "Should be class_arg!"); 
static_assert(!std::is_same<T, fn_arg>::value, "Should be class_arg!");
