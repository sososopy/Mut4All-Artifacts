Mutation Operator: Class Template Implicit Incomplete Prototype

Target: Template Classes

Mutation Rule: This operator specifically targets template declarations of classes. It transforms a fully defined template class into an incomplete one by removing its definition and leaving only its prototype. Here's how it works:

1. Identify a class template in the seed program.
2. Remove the definition part of the class, leaving only the template and class declaration with the template parameters. For example, if the seed program contains a class like: `template <typename T> class Foo { /* class definition */ };`, transform it to: `template <typename T> class Foo;`.
3. Ensure that no definition or body follows the class template declaration to make it incomplete.

This mutation leverages the incomplete class template declarations, which are often not handled gracefully by compilers, thereby potentially triggering crash-on-invalid bugs.
