Mutation Operator: Target: Template Instantiation with Overloaded Operators. Mutation Rule: 1. Identify any class template or function template in the seed program. 2. Inside the template, use a typename to define a type that is dependent on the template parameter(s). 3. Overload an operator (e.g., operator+, operator-, etc.) for this dependent type within the template definition. 4. Instantiate the template with a concrete type or value that triggers the operator overload. 5. For example, if the seed program contains a class template `template <typename T> class MyClass { ... }`, modify it to: ``` template <typename T> class MyClass { using DependentType = typename T::type; DependentType operator+(const DependentType &other) { return DependentType(); } }; MyClass<ConcreteType> obj; auto result = obj + obj; ``` Here, `ConcreteType` should be a type that has a nested type alias `type` to enable the instantiation.
