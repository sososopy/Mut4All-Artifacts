Mutation Operator: Apply this operator on C++ classes or structs that contain member access expressions.

Mutation Rule:
1. Identify member access expressions within a class or struct. For example, if there is an expression like `object.member`, locate it.
2. Modify the member access expression to access a non-existent member. For instance, if the original expression is `object.member`, change it to `object.nonExistentMember`.
3. Ensure that the rest of the code remains unchanged to preserve the structure and context.
4. If there's no member access in the class/struct, introduce one by creating an object of the class and attempting to access a non-existent member. For example, if the class is `class MyClass {};`, modify it to `class MyClass { void foo() { MyClass obj; obj.nonExistentMember; } };`.

Example Before Mutation:
```cpp
class A {
  void foo() {
    int x = 0;
    x++;
  }
};
```

  void foo() {

    x.nonExistentMember++;
