Mutation Operator  
Target: Variadic Templates in Combination with Lambdas  
Mutation Rule:  
Step 1: Identify a function template that uses variadic templates.  
Step 2: Within the fold expression of the variadic template, replace any existing function call with a lambda expression.  
Step 3: Ensure that the lambda captures a local variable declared in a different template.  
Step 4: The lambda's return type should be determined using decltype with the captured variable.  
Example:  
Original: ((Ts{}, f1(f)), ...);  
Mutated: char c; ((Ts{}, [](auto) -> decltype(c) {}(0)), ...);
