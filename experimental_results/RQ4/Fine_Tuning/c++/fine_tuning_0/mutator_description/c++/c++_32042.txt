Mutation Operator: Static Const Template Class Member

Target: Template class definitions.

Steps:
1. Identify a template class in the code.
2. Add a static const data member to the class.
3. Ensure the static const member is initialized within the class definition, if necessary.
4. Example: Transform a template class MyClass into:

template <typename T>
class MyClass {
  static const int value = 10;
};

This mutation targets the specific scenario where a static const member is used within a template class, which may trigger parsing issues or crashes in the compiler as described in the bug report.
