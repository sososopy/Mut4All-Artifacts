Mutation Operator 1: Template Argument Mutation Target: Function template with variadic template parameters Mutation Rule: 1. Identify the function template with variadic template parameters (e.g., template <typename... Ts> void foo(Ts&&... args) {}). 2. Find a call to this function template with template arguments specified (e.g., foo<int, int>(0, i)). 3. Modify the template arguments to create a mismatch between the number of template arguments and the number of function arguments. For example, if the original call is foo<int, int>(0, i), change it to foo<int>(0, i) or foo<int, int, int>(0, i). 4. Ensure that the modified call does not match any overload resolution for the function template.
