Target Code Construct: Concepts and Lambda Expressions
Mutation Rule:
1. Identify any concept definition in the code. Example: template<auto Q> concept C = requires { Q.template operator()<int>(); };
2. Locate a lambda expression that is utilized within a concept or static_assert and is part of a nested template or quoted constraint. Example: []<D>{}
3. Replace the inline lambda expression with a variable that holds the lambda expression. Ensure the lambda is defined using the `auto` keyword. Example: inline constexpr auto Q = []<D>{};
4. Update the concept or static_assert to use the newly created variable instead of the inline lambda definition. Example: template<class> concept E = C<Q>;
