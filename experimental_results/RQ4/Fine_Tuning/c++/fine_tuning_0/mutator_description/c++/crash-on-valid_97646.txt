Mutation Operator: Template Type Size Comparison to Bool Conversion. Target: Template functions with type-dependent expressions. Mutation Rule: Identify template functions that use `sizeof` on the template type parameter within an expression. Replace the `sizeof` expression with a boolean comparison that directly uses the type parameter, such as comparing the `sizeof` to a constant. Then, use `__typeof__` to deduce the type of the boolean expression and declare a variable of that type. Example: Original: `template <typename T> void func() { auto x = sizeof(T); }` Mutated: `template <typename T> void func() { __typeof__(sizeof(T) > 1) x; }`
