mutation Operator
Target: Template Class Instantiation within a Member Function
Where: Inside a member function of a template class.
Mutation Rule:
1. Identify a member function within a template class.
2. Within the function, locate any instantiation of a template class.
3. Replace the instantiation expression with only the template class name followed by "::template".
Example:
Original Code:
template <typename T>
class Container {
public:
  void func() {
    Holder<T>::template Inner<5>;
  }
};
Mutated Code:
template <typename T>
class Container {
public:
  void func() {
    Holder<T>::template Inner;
  }
}
