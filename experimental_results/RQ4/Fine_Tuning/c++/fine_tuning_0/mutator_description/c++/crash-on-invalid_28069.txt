Mutation Operator 1: Triggering Crash with Complex Template and Union

Target Code Construct: Class template instantiation within a union, specifically involving a non-trivial class in C++11.

Mutation Rule:
1. Identify a class template in the seed program. If none exists, introduce a new class template with at least one type parameter and a constructor or member function.
2. Identify a union in the seed program. If none exists, introduce a new union with at least one member.
3. Instantiate the identified class template (or the introduced one) as a member of the identified union (or the introduced one).
4. Ensure that the class template instantiation involves a non-trivial class by using a class with a constructor, destructor, or other special member functions.

Example:

Original Code:
```cpp
union MyUnion {
  int a;
};
```

```cpp

class MyClass {
  T value;
public:
  MyClass(T v) : value(v) {}

union MyUnion {
  MyClass<int> a;
};
```

Explanation: This mutation operator targets the instantiation of a class template within a union, specifically involving a non-trivial class in C++11, which is known to trigger crashes in certain compiler implementations, such as Clang.
