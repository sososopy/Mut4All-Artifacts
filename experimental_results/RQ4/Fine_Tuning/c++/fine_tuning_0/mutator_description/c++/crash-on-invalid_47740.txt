Mutation Operator 1: Nested Struct Export Mutation

Target: Nested structs with export keywords

Mutation Rule:
1. Identify a nested struct within the code.
2. If the nested struct is defined with an export keyword, remove the export keyword.
3. If the nested struct is not defined with an export keyword, add the export keyword before the struct definition.

Example:
Original: 
export module M; 
struct A { struct B; }; 
export struct A::B {};

Mutated: 
export module M; 
struct A { struct B; }; 
struct A::B {};
