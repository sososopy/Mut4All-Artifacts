Mutation Operator: Template Function Trailing Return Type Modifier

Target: This operator targets template functions with a trailing return type.

Mutation Rule: 
1. Identify a template function with a trailing return type.
2. Modify the trailing return type to include a more complex expression. This can involve using decltype with a function call.
3. Ensure the expression used in decltype is valid within the context, but does not affect the original logic of the function.

Example:
Original:
template<typename T> auto func(T t) -> decltype(t + 1) { return t + 1; }

Mutated:
template<typename T> auto func(T t) -> decltype(t + 1, void()) { return t + 1; }
