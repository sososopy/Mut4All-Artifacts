Mutation Operator 1: "Ref-to-RRef Conversion in Local Struct Method"
Target Code Construct: Struct method accessing local references/rvalue references.
Mutation Rule:
1. Identify a local struct within a function.
2. Check if the struct has a method that accesses any local references or rvalue references.
3. Convert the accessed reference to an rvalue reference using std::move.
4. Ensure the change is syntactically valid by including necessary headers if not present (e.g., #include <utility> for std::move).
Example: 
Original: struct A { constexpr int a() { return i; } };
Mutated: struct A { constexpr int a() { return std::move(i); } };
