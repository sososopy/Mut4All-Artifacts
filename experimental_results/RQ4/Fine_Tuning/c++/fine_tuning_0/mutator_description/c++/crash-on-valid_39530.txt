Mutation Operator: Target construct: Function calls with class template argument deduction and auto variables.

Mutation Rule: Identify function calls that utilize class template argument deduction (CTAD) with auto variables. Replace the auto keyword with explicit template argument specification. If a return type deduction is involved, replace it with an explicit return type.

Example: Original: auto obj = new MyClass(arg1, arg2); Mutated: MyClass<decltype(arg1), decltype(arg2)> obj = new MyClass(arg1, arg2);
