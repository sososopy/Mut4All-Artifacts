Mutation Operator: Misuse of Negative Literals in Function Arguments

Target Construct: Function Calls

Mutation Rule:
1. Identify function calls within the code. Ensure that at least one argument in the function is of integer type.
2. For the identified integer argument, replace it with a negative integer literal having a large magnitude (e.g., -1LL, -511LL, etc.).
3. Ensure that the replaced value is still contextually valid (e.g., type match) to avoid compile-time type errors unrelated to the mutation's intent.

Example:
Original Code: `int result = myFunction(0, 5, 10);`
Mutated Code: `int result = myFunction(0, -255LL, 10);`
