Mutation Operator: Modify Generic Constant Expressions in Struct Definitions

Target: This mutation operator targets struct definitions that use generic constant expressions, specifically those that define array sizes or other compile-time constants.

Description: In Rust, generic constant expressions can be used to define array sizes or other compile-time constants within struct definitions. This mutation operator modifies these expressions to introduce variations that might trigger bugs related to the handling of generic constant expressions by the compiler.

Application: Identify struct definitions that use generic constant expressions for array sizes or other constants. Modify the expression to introduce variations such as changing the constant value, using arithmetic operations, or introducing additional generic parameters.

Example:

Original Struct Definition:
```
struct EntriesBuffer(Box<[[u8; HashesEntryLEN]; 5]>);
```

Mutated Struct Definition:
1. Change the constant value:
   ```
   struct EntriesBuffer(Box<[[u8; HashesEntryLEN + 1]; 5]>);
   ```

2. Use arithmetic operations:
   ```
   struct EntriesBuffer(Box<[[u8; HashesEntryLEN * 2]; 5]>);
   ```

3. Introduce additional generic parameters:
   ```
   struct EntriesBuffer<const N: usize>(Box<[[u8; HashesEntryLEN + N]; 5]>);
   ```

These mutations aim to explore the compiler's handling of generic constant expressions by introducing variations that may expose inconsistencies or errors in the type-checking or borrow-checking phases.
