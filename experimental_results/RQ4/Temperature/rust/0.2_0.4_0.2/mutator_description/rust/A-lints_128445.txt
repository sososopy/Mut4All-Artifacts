Mutation Operator: Literal Range Mutation

Target: This mutation operator targets numeric literals within macro definitions in Rust code. It specifically applies to macros that return numeric literals, which may be subject to range limitations depending on their context of use.

Description: The mutation operator modifies numeric literals within macro definitions to values that are likely to exceed the typical range for common numeric types (e.g., i32, u32). This can help uncover issues related to range checks and error handling in the compiler's linting process.

Example:
Original Macro:
```rust
macro_rules! make { () => { 1000 } }
```

Mutated Macro:
```rust
macro_rules! make { () => { 2147483648 } } // This value exceeds the range of i32
```

Explanation: The original macro returns the literal `1000`, which is well within the range of common integer types. The mutated macro changes this to `2147483648`, a value that exceeds the maximum value for a 32-bit signed integer (`i32`). This mutation is designed to trigger potential issues in the compiler's handling of out-of-range literals, especially when the source code is not available for diagnostics, as indicated in the bug report.
