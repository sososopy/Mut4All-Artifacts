Mutation Operator: Duplicate Field Names in Nested Structures

This mutation operator targets nested structures within Rust code, specifically focusing on creating scenarios where field names are duplicated within nested anonymous and named structures. The goal is to expose bugs related to field uniqueness checks in the Rust compiler.

Where it applies:
- This mutation applies to any struct or union that contains nested anonymous or named structs or unions.

Mutation Description:
- Identify a nested structure (either a struct or a union) within a parent struct or union.
- Introduce a new field within this nested structure that duplicates an existing field name in the same scope.
- Ensure that the duplicated field name is already present in the same nested structure or in the parent structure.

Example of Mutated Content:
Consider the following seed program snippet:

```
struct Container {
    data: u8,
    nested: struct {
        value: u8,
    },
}
```

Apply the mutation operator:

```
struct Container {
    data: u8,
    nested: struct {
        value: u8,
        data: u8, // Duplicated field name
    },
}
```

In this example, the field `data` is duplicated within the nested struct, which should trigger the Rust compiler's field uniqueness checks. This mutation is designed to test the compiler's ability to handle and report errors related to duplicate field names in nested structures.
