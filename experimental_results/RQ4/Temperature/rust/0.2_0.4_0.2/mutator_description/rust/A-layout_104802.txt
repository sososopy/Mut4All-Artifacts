Mutation Operator: Modify Union Field Types

Target: This mutation operator targets union definitions in Rust code, specifically focusing on changing the types of fields within a union to expose potential layout and alignment issues.

Description: The mutation operator modifies the types of fields within a union to other types that may have different alignment requirements. This can help expose bugs related to alignment mismatches between ABI and layout, as seen in the provided bug report.

Application: This operator applies to any union definition in the seed program. It should be used when the union has fields that can be changed to types with different alignment characteristics.

Example:
Original Code:
```
union U {
    x: u32,
    y: f32,
}
```

Mutated Code:
```
union U {
    x: u16, // Changed from u32 to u16
    y: f64, // Changed from f32 to f64
}
```

Explanation: In this example, the field `x` is changed from `u32` to `u16`, and the field `y` is changed from `f32` to `f64`. These changes alter the alignment requirements of the union fields, which can potentially trigger alignment-related bugs in the Rust compiler. The mutation operator should ensure that the new types are valid and declared appropriately within the context of the seed program.
