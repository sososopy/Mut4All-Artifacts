Mutation Operator: Modify Struct Field Order

This mutation operator targets struct definitions in Rust programs, specifically focusing on the order of field declarations within the struct. The goal is to modify the order of fields in a struct to expose potential bugs related to field access, initialization, and type handling.

Where it applies: This operator applies to any struct definition in the seed program that contains two or more fields.

Mutation Description: For a given struct with multiple fields, reorder the fields. This involves swapping the positions of two or more fields within the struct definition. The rest of the program should be left unaltered, ensuring that the field order is the only change.

Example:
Original Struct Definition:
struct Example {
    field1: Type1,
    field2: Type2,
    field3: Type3,
}

Mutated Struct Definition:
struct Example {
    field3: Type3,
    field1: Type1,
    field2: Type2,
}

Considerations: 
- The mutation should maintain the original field types and names.
- It is crucial to test the program across various struct usages, including initialization, field access, and method calls that involve the struct.
- Observe how the change in order affects the behavior of the code, especially in interactions with other complex types and during constant evaluation.

This mutation operator can help identify bugs related to field order assumptions in the Rust compiler's handling of struct initialization and field access during constant evaluation.
