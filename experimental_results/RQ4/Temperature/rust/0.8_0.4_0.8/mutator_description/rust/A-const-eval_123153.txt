Mutation Operator: Mutable Static Mutation

Target: Mutable static variables in Rust programs.

Description: This mutation operator targets mutable static variables, which are shared across all threads and can be accessed and modified from anywhere in the program. These variables are prone to causing undefined behavior when improperly used, especially if not handled safely. The mutation involves changing the initialization or usage pattern of mutable static variables to expose potential bugs in constant evaluation or unsafe code handling.

Mutation Steps:
1. Identify all mutable static variables in the seed program.
2. For each mutable static variable, introduce a mutable reference to it within a function, and perform an operation that modifies its value.
3. Ensure that the operation is wrapped within an `unsafe` block since accessing mutable static variables requires unsafe code.
4. Use existing types and variables in the seed program to construct the modification operation.

Example:
Original Code:
```
pub static mut COUNTER: u32 = 0;

fn increment_counter() {
    unsafe {
        COUNTER += 1;
    }
}

fn main() {
    increment_counter();
}
```

Mutated Code:
```
pub static mut COUNTER: u32 = 0;

fn increment_counter() {
    unsafe {
        COUNTER += 1;
    }
}

fn decrement_counter() {
    unsafe {
        COUNTER -= 1; // Introduce a decrement operation to modify the static variable
    }
}

fn main() {
    increment_counter();
    decrement_counter(); // Call the function to trigger the mutation
}
```

Explanation: The mutation introduces a new function `decrement_counter` that modifies the mutable static variable `COUNTER` by decrementing its value. This change is intended to expose potential issues in the handling of mutable statics by the compiler during constant evaluation. By manipulating the value of a mutable static in different ways, bugs related to state management and concurrency can be uncovered.
