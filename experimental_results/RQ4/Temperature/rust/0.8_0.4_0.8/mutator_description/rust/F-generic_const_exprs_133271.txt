Mutation Operator: Modify Constant Expressions in Trait Implementations

This mutation operator targets trait implementations where generic constant expressions are used within constraints in the `where` clause or any part of the trait implementation. Specifically, it applies to structs implementing traits with generic constants in their method signatures or constraints.

Mutation Description:
1. Locate trait implementations where a struct implements a trait and uses a constant expression in the `where` clause, specifically within array length constraints or similar contexts.
2. Alter the constant expression in the `where` clause by changing its arithmetic operation or replacing it with another constant expression that uses the same underlying types and constants but alters the operation logic.

Example of Mutation:
Original:
```rust
impl<'a, const NUM: usize> std::ops::Add<&'a Foo> for Foo
where
    [(); 1 + 0]: Sized,
{
    fn unimplemented(self, _: &Foo) -> Self::Output {
        loop {}
    }
}
```

Mutated:
```rust
impl<'a, const NUM: usize> std::ops::Add<&'a Foo> for Foo
where
    [(); NUM - 1]: Sized, // Alter the constant expression logic
{
    fn unimplemented(self, _: &Foo) -> Self::Output {
        loop {}
    }
}
```

In this example, the mutation changes the constant expression `[(); 1 + 0]` to `[(); NUM - 1]` in the `where` clause. This modification tests whether the compiler correctly evaluates and handles the modified constant expression logic within generic contexts.
