Mutation Operator: Modify Iterator Usage with Const Generics

This mutation operator targets the usage of iterators in methods that return `impl Iterator`, specifically when the iterator involves operations on constant-sized arrays. The operator applies to methods that use iterators on arrays with sizes determined by generic constants in structs or other structures.

Mutation Description:
1. Identify methods that return `impl Iterator` and operate over arrays with constant sizes (e.g., `[[u8; HashesEntryLEN]; 5]`).
2. Modify the iterator operations to involve arithmetic or logical expressions using generic constants.
3. Ensure that the constants used are declared within the same struct or associated with the type in a way that they influence the iterator’s behavior.

Example of Mutation:
Original Method:
```
fn a(&self) -> impl Iterator {
    self.0.iter_mut()
}
```

Mutated Method:
```
fn a(&self) -> impl Iterator {
    let size = HashesEntryLEN * 2; // Introduce a calculation using the constant
    self.0.iter_mut().take(size) // Modify the iterator to take only `size` elements
}
```

In this mutation, the iterator operation is changed by incorporating a calculation (`HashesEntryLEN * 2`) which affects the iterator's behavior by limiting the elements iterated over. This mutation exposes potential issues in handling generic constants when they interact with iterator logic, potentially triggering bugs in the Rust compiler related to `generic_const_exprs`.
