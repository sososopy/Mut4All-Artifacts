Mutation Operator: Modify Trait Bounds with Const Generics

Target: Trait bounds involving const generics on associated types.

Where it applies: This mutation operator applies to Rust code involving trait declarations with associated types that have trait bounds using const generics. It is particularly relevant in the context of traits with complex generic requirements, as seen in the bug report.

Description: This mutation operator aims to modify the trait bounds by changing the constant value used in a const generic parameter or altering the type constraints on the associated type. The goal is to trigger potential bugs in the compiler's handling of const generics in trait bounds, similar to those noted in the bug report.

Example Mutation:

Original Code:
```
trait A {
    type T: B<U<1i32> = ()>;
}

trait B {
    type U<const C: i32>;
}
```

Mutated Code:
1. Change the constant value:
```
trait A {
    type T: B<U<2i32> = ()>; // Changed the constant from 1i32 to 2i32
}
```

2. Alter the type constraint:
```
trait A {
    type T: B<U<1i32> = bool>; // Changed the associated type's constraint from () to bool
}
```

These mutations introduce variations in the const generic parameter and the type constraints, which could potentially expose issues in the Rust compiler's handling of const-generics or trait bounds involving associated types.
