Mutation Operator: Enum Variant Addition

Target: This mutation operator applies to enum definitions in Rust code.

Description: In Rust, an enum can have multiple variants, each potentially carrying different types of data. The mutation operator introduces an additional variant to existing enums in the code. The added variant will contain standard types, such as an integer or a tuple, to explore how the Rust compiler handles transmutations involving enums with multiple variants and check if it triggers any ICEs when not expected.

Steps:
1. Identify existing enums in the seed program. For each enum, add a new variant.
2. The new variant should be named `NewVariant` followed by a sequential number to avoid naming conflicts (e.g., `NewVariant1`, `NewVariant2`, etc.).
3. The new variant can hold a predefined data type or structure, such as an integer (`i32`) or a tuple (e.g., `(i32, f64)`).
4. If the program includes functions or logic that perform operations on the enum, ensure that the new variant does not break existing functionality by default.

Example:
Original Code:
```rust
enum ExampleEnum {
    VariantOne,
    VariantTwo(i32),
}
```

Mutated Code:
```rust
enum ExampleEnum {
    VariantOne,
    VariantTwo(i32),
    NewVariant1(i32), // New variant added
}
```

This mutation operator can help test how the compiler deals with enums gaining additional variants, especially in contexts where transmutation operations or size assertions are involved.
