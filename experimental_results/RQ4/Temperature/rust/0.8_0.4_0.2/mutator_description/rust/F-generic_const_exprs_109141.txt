Mutation Operator: Alter Array Lengths in Structs

This mutation operator targets array lengths within struct definitions, particularly when used in conjunction with generic constant expressions, which can expose bugs in the Rust compiler's handling of such expressions.

Where It Applies: This operator should be applied to struct definitions that contain arrays with a length defined by a constant. The target here is to manipulate these lengths to introduce variations that can trigger bugs related to generic constant expressions.

Mutation Description: 

1. Identify struct definitions that include arrays with a constant length. For example, in `struct EntriesBuffer(Box<[[u8; HashesEntryLEN]; 5]>);`, the length `5` is defined as a constant.

2. Mutate the array length by replacing the fixed constant with a more complex expression utilizing const generics or dependent types. This can involve introducing a new constant expression or modifying existing ones that depend on other parameters or constants.

3. Example of Mutation in Pseudo-Code Form:
   - Original:
     ```
     struct EntriesBuffer(Box<[[u8; HashesEntryLEN]; 5]>);
     ```
   - Mutated:
     ```
     const NEW_LENGTH: usize = calculate_length();
     struct EntriesBuffer(Box<[[u8; HashesEntryLEN]; NEW_LENGTH]>);

     const fn calculate_length() -> usize {
         // Introduce a logic or computation to determine the length
         5 + 3 // For illustrative purposes, the expression can be more complex
     }
     ```

4. Ensure that any new constants or functions (`calculate_length` in this case) are clearly defined in the program, avoiding undeclared elements.

5. This mutation should help in exploring how the Rust compiler handles complex constant expressions in struct definitions, potentially revealing issues with the `generic_const_exprs` feature.

By modifying the array lengths in this manner, we aim to test the compiler's robustness and uncover edge cases related to the handling of generic constant expressions, potentially triggering bugs like those reported in the original issue.
