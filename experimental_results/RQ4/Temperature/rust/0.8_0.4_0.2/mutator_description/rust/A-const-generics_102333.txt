Mutation Operator: Modify Const Generic Parameters in Trait Bounds

This mutation operator targets trait bounds that involve const generics, particularly in associated types. The mutation involves altering the const generic parameters provided in the associated type constraints within trait bounds. This operator is applied to code where a trait is defined with associated types that have const generic parameters.

Example Mutation:

Original Code:
```
trait A {
    type T: B<U<1i32> = ()>;
}

trait B {
    type U<const C: i32>;
}
```

Mutated Code:
```
trait A {
    type T: B<U<2i32> = ()>;
}

trait B {
    type U<const C: i32>;
}
```

Description:
1. Identify trait definitions where an associated type uses a const generic parameter in its bounds.
2. Modify the const generic parameter value (e.g., change from `1i32` to `2i32`).
3. Ensure that the mutation does not introduce undeclared or ambiguous types, and only changes the values or types of existing const generic parameters.
4. This operator aims to expose issues related to handling different const generic parameters in trait bounds by the compiler, potentially uncovering inconsistencies or unexpected behaviors.
