Mutation Operator: Replace Async Closure with Async Block

Target: This mutation operator targets any instance of an async closure within the Rust program. It applies specifically where an async closure is used, such as in variable assignments or function arguments.

Description: When an async closure is found in the code, it should be replaced with an equivalent async block. Async closures are currently unstable in Rust and replacing them with async blocks can help identify issues related to async-await handling within the compiler. The mutation operator should modify the code such that the async closure is removed and replaced with an async block encapsulating the equivalent logic.

Example:
Original Code:
```rust
let async_closure = async move |arg| {
    // some async operations with arg
};
```

Mutated Code:
```rust
let async_block = async {
    // some async operations with arg
};
```

Explanation: In the mutated code, the async closure `async move |arg| { ... }` is replaced by an async block `async { ... }`. This transformation involves moving the logic inside the async closure to the async block. Any variables or arguments used in the async closure should be handled appropriately within the async block to maintain the intended functionality. This change forces the compiler to treat the construct differently and can trigger bugs or unexpected behaviors related to async-await handling in Rust.
