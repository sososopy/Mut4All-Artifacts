Mutation Operator: Nested Union within Struct Mutation

Target: This mutation applies to structures containing nested unions within structs.

Description: This mutation introduces a nested union inside an existing struct. The nested union will contain fields of basic types and potentially structs or unions already defined in the seed program. This mutation aims to expose issues related to handling nested anonymous data types (ADT) within other ADTs by the Rust compiler.

Mutation Steps:
1. Identify a struct in the seed program.
2. Introduce a new union within this struct. Ensure that the union contains at least one field that is a basic data type (e.g., `u8`, `i32`) and another field that uses an existing struct or union defined in the seed program.
3. Ensure that field names are unique within the context of the new union and struct to prevent name collisions.
4. Place the new union at a random position within the struct's field list.

Example:
Consider the following seed program snippet:

```
struct Parent {
    field1: u8,
    field2: i32,
}
```

Apply the mutation operator:

```
struct Parent {
    field1: u8,
    field2: i32,
    nested_union: union {
        field3: u8,
        nested_struct: ExistingStruct,
    },
}
```

Here, `ExistingStruct` represents a previously defined struct in the seed program. The mutation introduces a `nested_union` within the `Parent` struct, aimed at testing the compiler's ability to handle nested unions within structs.
