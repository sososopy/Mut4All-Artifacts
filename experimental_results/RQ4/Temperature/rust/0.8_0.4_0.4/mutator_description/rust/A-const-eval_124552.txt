Mutation Operator: Duplicate Field Names in Struct Definitions

This mutation operator targets struct definitions within Rust programs. When a struct is defined, it is required to have unique field names. This operator deliberately introduces duplicate field names within a single struct definition to test the compiler's ability to handle such cases. Based on the bug report, this structural anomaly can trigger bugs related to type mismatch and improper handling of static items.

Example of Mutation:
1. Identify a struct definition in the seed program. For instance:

   ```
   struct Example {
       alpha: i32,
       beta: f64,
   }
   ```

2. Introduce a duplicate field name within the struct. Duplicate one of the existing field names:

   ```
   struct Example {
       alpha: i32,
       alpha: f64, // Duplicate field name
   }
   ```

Mutation Application: 
- This mutation should be applied to struct definitions that have at least two fields, ensuring there is a field available to duplicate.
- The mutation is likely to cause a type mismatch error or other compilation issues related to field name conflicts, which may reveal bugs in the Rust compiler's handling of struct definitions and type checking.
- It is suitable for testing how the compiler deals with name resolution and struct field integrity, particularly during constant evaluation phases of compilation.
