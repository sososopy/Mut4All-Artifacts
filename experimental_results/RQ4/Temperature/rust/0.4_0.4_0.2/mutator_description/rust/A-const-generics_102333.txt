Mutation Operator: Modify Const Generic Parameters in Trait Bounds

Target: This mutation operator targets trait definitions with associated types that use const generic parameters in their trait bounds.

Where It Applies: This operator applies to any trait definition where an associated type is constrained by another trait that uses const generic parameters.

Description: The mutation involves altering the const generic parameter value used in the trait bound of an associated type. This change can expose bugs related to how the compiler handles const generics in trait bounds. The mutation can either increment, decrement, or replace the const value with another valid constant of the same type.

Example of Mutated Content:

Original Code:
```
trait A {
    type T: B<U<1i32> = ()>;
}

trait B {
    type U<const C: i32>;
}
```

Mutated Code:
```
trait A {
    type T: B<U<2i32> = ()>; // Changed the const generic parameter from 1i32 to 2i32
}

trait B {
    type U<const C: i32>;
}
```

In this example, the const generic parameter `1i32` in the trait bound is changed to `2i32`. This mutation can help identify issues in how the Rust compiler handles different const generic values in associated type constraints.
