Mutation Operator: Duplicate Field Declaration in Nested Structures

This mutation operator targets nested structures, specifically within `struct` and `union` types. It applies to any nested structure or union within a Rust program. The operator introduces a duplicate field declaration within a nested structure or union, which is likely to trigger errors related to field uniqueness checks in the Rust compiler.

Example of Mutation:

Original Code:
```rust
struct Container {
    data: u8,
    nested: struct {
        field1: u8,
        field2: u16,
    },
}
```

Mutated Code:
```rust
struct Container {
    data: u8,
    nested: struct {
        field1: u8,
        field1: u8, // Duplicate field declaration
        field2: u16,
    },
}
```

Description:
1. Identify a nested `struct` or `union` within a Rust program.
2. Within the identified nested structure, select an existing field.
3. Introduce a duplicate declaration of the selected field within the same nested structure.
4. Ensure that the duplicate field has the same type as the original to maintain syntactic validity while triggering semantic errors.

This mutation operator is designed to expose bugs related to field uniqueness checks within nested structures, as demonstrated in the given bug report. By duplicating field declarations, it aims to trigger the compiler's handling of such errors, potentially leading to internal compiler errors (ICE) or other unexpected behaviors.
