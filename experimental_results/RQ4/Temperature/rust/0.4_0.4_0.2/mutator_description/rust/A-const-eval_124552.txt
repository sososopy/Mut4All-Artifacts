Mutation Operator: Static Item Field Type Mismatch

This mutation operator targets struct definitions and their associated static instances in Rust programs. It specifically applies to situations where a struct has multiple fields, and a static instance of this struct is initialized. The goal is to introduce a type mismatch in the static instance initialization to expose bugs related to type checking and constant evaluation.

Description:
1. Identify a struct with multiple fields where at least one field is of a primitive type (e.g., u32, i32) and another field is of a user-defined type (e.g., struct B).
2. Locate a static instance of this struct that is initialized in the program.
3. Mutate the initialization of the static instance by swapping the values of the fields, specifically assigning a value of a user-defined type to a field that expects a primitive type, or vice versa.

Example of Mutated Content:
Original Struct and Static Instance:
```
struct B;

struct Foo {
    a: u32,
    b: B,
}

static BAR: Foo = Foo { a: 10, b: B };
```

Mutated Static Instance:
```
static BAR: Foo = Foo { a: B, b: 10 }; // Introduces a type mismatch
```

In this example, the mutation swaps the values assigned to fields `a` and `b` in the static instance `BAR`. The field `a` expects a `u32`, but is assigned `B`, and the field `b` expects a `B`, but is assigned `10`, a `u32`. This type mismatch is likely to trigger bugs related to type checking during constant evaluation.
