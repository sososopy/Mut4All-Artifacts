Mutation Operator: Modify Union Alignment

Target: This mutation operator targets union declarations with a specific representation attribute, particularly those using `#[repr(packed)]`.

Description: The mutation operator modifies the alignment specified in the `#[repr(packed)]` attribute of a union to a different value. This change can expose issues related to alignment mismatches between the ABI and layout, which are known to cause internal compiler errors (ICE) in the Rust compiler, as seen in the bug report.

Application: This operator applies to union declarations that have a `#[repr(packed)]` attribute. The attribute's alignment value should be changed to a different valid alignment value, which is typically a power of two.

Example:
Original Code:
```
#[repr(packed(1))]
union U {
    x: u32,
}
```

Mutated Code:
```
#[repr(packed(2))]
union U {
    x: u32,
}
```

In this example, the alignment value in the `#[repr(packed)]` attribute is changed from 1 to 2. This mutation can help uncover potential issues with how the Rust compiler handles alignment in packed unions, which may lead to internal compiler errors or unexpected behavior.
