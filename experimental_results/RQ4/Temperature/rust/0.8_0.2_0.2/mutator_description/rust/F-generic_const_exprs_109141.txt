Mutation Operator: Struct Field Access with Generic Const Expressions

Target: This mutation operator targets struct field access involving arrays with constant lengths determined by generic constant expressions. It applies to structs where one or more fields are arrays with lengths specified by const generic parameters.

Description: Modify the access of struct fields that involve arrays having their length specified by generic constant expressions. This operator changes how these fields are accessed, used, or manipulated, potentially exposing compiler bugs related to generic constant expressions. The modification can include altering the const expression, changing the way elements are accessed, or modifying the access pattern within the code.

Example of Mutated Content:

Original:
```pseudo
struct DataHolder<const N: usize> {
    data: [i32; N],
}

impl<const N: usize> DataHolder<N> {
    fn get_first(&self) -> Option<&i32> {
        self.data.get(0)
    }
}
```

Mutated:
```pseudo
// Introduce a new method that modifies the access pattern
impl<const N: usize> DataHolder<N> {
    fn get_element(&self, index: usize) -> Option<&i32> {
        if index < N {
            self.data.get(index)
        } else {
            None
        }
    }

    // Alter the constant expression in a use case
    fn get_last(&self) -> Option<&i32> {
        self.data.get(N - 1)
    }
}
```

In the mutated example, we add a method `get_element` to demonstrate accessing the array's elements by an index, which dynamically checks against the const parameter `N`. Additionally, `get_last` demonstrates using a const expression `N - 1` to get the last element, which might stress the compiler's handling of const expressions in generics. These changes expand the interaction with const generic expressions and increase the likelihood of triggering related compiler bugs.
