Mutation Operator: Modify Const Expressions in Trait Implementations

Target: This mutation operator targets const expressions within the `where` clause of trait implementations.

Description: In Rust, trait implementations can have const expressions as part of their `where` clause for additional constraints. This operator modifies these const expressions by replacing the numerical literals with simple arithmetic expressions. This can test the handling of generic const expressions by the compiler and may expose bugs related to the evaluation of such expressions. Given that the compiler bug is related to `generic_const_exprs`, altering these expressions could potentially trigger or uncover related issues.

Transformation:
- Locate the const expression within the `where` clause of a trait implementation.
- Replace any numerical literal with a simple arithmetic expression that evaluates to the same value.

Example:
Original Code:
```
impl<'a, const NUM: usize> std::ops::Add<&'a Foo> for Foo
where
    [(); 1 + 0]: Sized,
{
    fn unimplemented(self, _: &Foo) -> Self::Output {
        loop {}
    }
}
```

Mutated Code:
```
impl<'a, const NUM: usize> std::ops::Add<&'a Foo> for Foo
where
    [(); 2 - 1]: Sized,
{
    fn unimplemented(self, _: &Foo) -> Self::Output {
        loop {}
    }
}
```

This mutation operator preserves the semantical correctness of the const expression while potentially altering execution paths within the compiler, increasing the chance of exposing underlying issues with const expression handling.
