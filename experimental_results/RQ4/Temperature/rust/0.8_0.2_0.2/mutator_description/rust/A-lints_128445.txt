Mutation Operator: Literal Transformation in Macro Definitions

Target: This mutation operator targets macro definitions containing literal values in Rust programs.

Description: Macros in Rust can expand to arbitrary code, including literals. The bug report indicates an issue with handling literals when the source is not available. To expose bugs related to literal handling in macros, we can apply a transformation to modify literal values in macro definitions.

Mutation Details:
1. Identify macro definitions in the Rust source code that contain literal values, such as numbers, strings, or characters.
2. Modify these literals by changing their values or types. For instance, modify integer literals by:
   - Changing the numerical value (e.g., from 1000 to -1).
   - Changing the type of the literal (e.g., from an integer to a floating-point number).
   - Altering the sign of the literal (e.g., from positive to negative).

Example of Mutated Content:
Original Macro Definition:
```
macro_rules! make { () => { 1000 } }
```

Mutated Macro Definition:
```
macro_rules! make { () => { -1.0 } }
```

Rationale: By altering literals in macro definitions, we can test how the compiler handles edge cases involving literal transformation in macro expansions. This mutation operator may trigger bugs in linting or diagnostic code paths that process macro-expanded literals, potentially exposing issues similar to the "literal out of range" diagnostic crash reported in the bug.
