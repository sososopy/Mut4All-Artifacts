Mutation Operator: Alter Union Field Types

Description:
This mutation targets union definitions in Rust code, specifically focusing on altering the types of the fields within a union. It applies to any union declaration with at least one field.

The mutation involves changing the field type of a union member to another type that has a different alignment requirement. The goal is to potentially expose bugs related to layout and alignment constraints by creating a scenario where the union's alignment may conflict with the alignment requirements of its fields.

Example:

Original Code:
union ExampleUnion {
    field1: u32,
    field2: f64,
}

Mutated Code:
union ExampleUnion {
    field1: u8, // Changed from u32 to u8, which may affect alignment
    field2: f64,
}

Explanation:
In this example, the type of `field1` is changed from `u32` to `u8`. The alignment requirements for `u32` and `u8` differ, which could trigger layout or alignment-related issues within the Rust compiler, especially when the union or its instances are used in various contexts. This mutation is crafted to create discrepancies between the expected and actual memory layout, potentially exposing internal compiler errors or unexpected behavior during compilation.
