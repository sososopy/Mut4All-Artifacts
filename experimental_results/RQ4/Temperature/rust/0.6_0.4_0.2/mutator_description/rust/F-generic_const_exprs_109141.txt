Mutation Operator: Modify Const Generics in Array Types

Target: This mutation operator applies to array types in struct definitions and function signatures that use const generics.

Description: The goal of this mutation operator is to modify the const generic parameters in array types, which are often involved in complex type-checking scenarios. This can expose bugs related to the handling of const generic expressions, especially when combined with features like iterators and trait implementations.

Mutation Steps:
1. Identify any array types in the seed program that use const generics, such as `struct Example([T; N]);` where `N` is a const generic parameter.
2. Modify the const generic parameter to a different expression or value. This could involve:
   - Changing a simple constant to an expression involving other const generics or constants.
   - Increasing or decreasing the value of the constant.
   - Replacing the const generic parameter with another existing const generic parameter from the program, if applicable.
3. Ensure the modified value or expression is valid within the context of the program, maintaining type correctness.

Example of Mutated Content:
Original:
```rust
struct EntriesBuffer(Box<[[u8; HashesEntryLEN]; 5]>);
```

Mutated:
```rust
struct EntriesBuffer(Box<[[u8; HashesEntryLEN + 2]; 5]>);
```

or

```rust
struct EntriesBuffer(Box<[[u8; SomeOtherConst]; 5]>);
```

In this example, `HashesEntryLEN` is modified to `HashesEntryLEN + 2` or replaced with `SomeOtherConst`, which is assumed to be another const generic available in the program. This mutation tests the handling of arithmetic expressions in const generics and the interaction with other const parameters.
