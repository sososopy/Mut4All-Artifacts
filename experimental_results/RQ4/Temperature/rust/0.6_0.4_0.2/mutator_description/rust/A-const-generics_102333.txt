Mutation Operator: Modify Const Generics in Trait Bounds

This mutation operator targets trait definitions that use const generics in their associated types, specifically within trait bounds. The mutation modifies the const value used in the generic parameter to a different valid constant. This applies to any trait definition where an associated type is constrained by another trait that uses const generics.

Example of Mutation:

Consider a seed program with the following structure:

```rust
trait A {
    type T: B<U<1i32> = ()>;
}

trait B {
    type U<const C: i32>;
}
```

Mutation:

1. Locate the const generic usage within the trait bound. In this case, it is `U<1i32>`.
2. Change the const value `1i32` to another valid integer constant. For example, change it to `2i32`.

Mutated Code:

```rust
trait A {
    type T: B<U<2i32> = ()>;
}

trait B {
    type U<const C: i32>;
}
```

This mutation is designed to test the compiler's handling of const generics in trait bounds and can expose issues related to the evaluation of const expressions or incorrect handling of trait constraints with const generics. This operator ensures that the mutation remains valid within the language constraints and does not introduce syntax errors or undeclared variables.
