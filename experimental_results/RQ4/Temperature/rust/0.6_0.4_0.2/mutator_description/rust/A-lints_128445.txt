Mutation Operator: Alter Numeric Literal Boundaries

Target: This mutation applies to numeric literals within macro definitions or directly in the code. It is particularly relevant when these literals are used in contexts where their range might trigger lint checks or undefined behaviors.

Description: Modify numeric literals in the code by pushing them to their boundary limits. For example, if a literal is an integer, change it to the maximum or minimum value for its type (e.g., i32::MAX, i32::MIN). This is aimed at testing the compiler's handling of literals at their boundary values, which is a common source of bugs related to overflows and range checks.

Example of Mutated Content:

Original Code:
```
macro_rules! make { () => { 1000 } }
```

Mutated Code:
```
macro_rules! make { () => { i32::MAX } }
```

In cases where the literal is used in a context that expects a specific range, such as an index or a size, adjust it to the boundary values that are likely to cause overflows or underflows. This operator should be applied while considering the type of the literal and the context in which it is used to ensure realistic test scenarios.
