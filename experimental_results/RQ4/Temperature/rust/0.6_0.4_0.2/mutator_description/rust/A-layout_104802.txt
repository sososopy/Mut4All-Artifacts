Mutation Operator: Alter Union Definition with Varying Field Types

Target: This mutation operator targets union definitions, specifically altering the types of fields within a union to include various primitive and non-primitive types.

Description: The mutation operator modifies an existing union by adding fields of different types or changing the type of existing fields. This mutation is particularly useful for testing the Rust compiler's handling of unions with mixed types and varying alignment requirements.

Application: Apply this mutation to union definitions in the seed program. Ensure that the union has at least two fields of different types to expose potential alignment and layout issues.

Example:
Original Union:
```
union ExampleUnion {
    a: u32,
}
```

Mutated Union:
```
union ExampleUnion {
    a: u32,
    b: u16, // Added a new field of a different type
    c: f64, // Added another field of a different type
}
```

In this example, the original union `ExampleUnion` has a single field of type `u32`. The mutation introduces additional fields `b` of type `u16` and `c` of type `f64`. This alteration is designed to test the compiler's ability to handle unions with mixed type fields, potentially triggering issues related to alignment and layout, as seen in the bug report.
