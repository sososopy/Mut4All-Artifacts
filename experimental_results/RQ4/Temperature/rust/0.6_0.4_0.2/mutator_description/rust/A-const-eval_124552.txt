Mutation Operator: Duplicate Field Mutation

This mutation operator targets struct definitions, specifically where a struct has fields with the same name but different types. It applies to struct definitions that have multiple fields with identical names.

Description:
- Identify a struct with at least two fields having the same name but different types.
- Remove one of the duplicate fields to ensure fields have unique names. If both fields are necessary, rename one to maintain unique identifiers.

Example of Mutated Content:
Consider the following struct definition:

Original:
struct Sample {
    field1: i32,
    field1: f64,
}

Mutated:
struct Sample {
    field1: i32,
    field2: f64, // Renamed the second field1 to field2
}

Explanation:
In the original struct, there are two fields named `field1` with different types. The mutation operator identifies this duplication and renames the second `field1` to `field2` to ensure all field names are unique within the struct. This approach helps expose bugs related to field name duplication and type mismatches in the Rust compiler's handling of structs.
