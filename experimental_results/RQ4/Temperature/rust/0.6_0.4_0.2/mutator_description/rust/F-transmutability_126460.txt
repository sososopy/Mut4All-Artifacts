Mutation Operator: Enum Variant Structure Modification

Target: This mutation operator targets enum declarations, particularly those with uninhabited types like `Void` as variants. It applies to enums with multiple fields in a variant, especially when one of the fields is an uninhabited type.

Description: Modify the structure of an enum variant by adding, removing, or changing the order of fields. This can reveal issues in handling transmutability, especially when dealing with uninhabited types or specific layouts that the compiler might not handle correctly.

Example of Mutation:

Original Code:
```
enum ExampleEnum {
    VariantA(Void, u128),
}
```

Mutated Content:
1. Add a new field of a simple type (e.g., `bool`) to the variant:
   ```
   enum ExampleEnum {
       VariantA(Void, u128, bool),
   }
   ```
2. Remove an existing field from the variant:
   ```
   enum ExampleEnum {
       VariantA(Void),
   }
   ```
3. Change the order of fields in the variant:
   ```
   enum ExampleEnum {
       VariantA(u128, Void),
   }
   ```

In each case, ensure that the `Void` type is declared as:
```
enum Void {}
```

These mutations can expose potential issues in how the Rust compiler handles enum layouts and transmutability, especially concerning uninhabited types and their interaction with other data types in enum variants.
