Mutation Operator: Static Structure Field Reordering

This mutation operator targets static structures with multiple fields. It specifically applies to fields within static items that are initialized at compile time and are involved in constant evaluation.

Description:
The goal is to reorder the fields within a static structure declaration. This reordering can expose potential issues in the constant evaluation and initialization order, especially when certain fields have dependencies on the initialization of other fields.

Steps:
1. Identify a structure that is used in a static item. This structure should have two or more fields.
2. Reorder the fields in the structure definition, changing the order in which they are declared.
3. Ensure that the static item that utilizes this structure is updated to reflect the new order of fields during its initialization.

Example:
Original Code:
```
struct Foo {
    a: i32,
    b: u32,
}

static BAR: Foo = Foo { a: 10, b: 20 };
```

Mutated Code:
```
struct Foo {
    b: u32,
    a: i32,
}

static BAR: Foo = Foo { b: 20, a: 10 };
```

Here, the fields `a` and `b` in the `Foo` structure are reordered. Static item `BAR` is updated to match the new field order. The mutation operator can reveal potential issues if the compiler incorrectly assumes a specific order of field initialization during constant evaluation.
