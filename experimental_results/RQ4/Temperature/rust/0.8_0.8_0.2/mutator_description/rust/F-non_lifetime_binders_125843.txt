Mutation Operator: Impl Trait and Lifetime Specifier Mutation

This mutation operator targets function parameter definitions that use impl Trait with lifetime specifiers and applies to function signatures where impl Trait is used within generics, possibly with lifetimes. The goal is to introduce variations that can reveal issues related to generic bounds, lifetime handling, and type resolution.

1. Applicable Code Construct: Function signatures with impl Trait parameters, where lifetimes and generic bounds are involved.

2. Mutation Description: For any function parameter defined using impl Trait with a lifetime specifier, modify the lifetime specifier, or introduce an additional impl Trait parameter with a complex type bound that may include nested lifetimes. If the seed program has no lifetime specifier or only has '_ lifetime, introduce a named lifetime parameter and use it. If it has a named lifetime, replace it with '_ or another named lifetime.

3. Mutation Examples:

Original Function Signature:
```
fn example_fn(param: impl Trait<'a> + AnotherTrait) {}
```

- Mutation 1: Replace named lifetime with '_.
  ```
  fn example_fn(param: impl Trait<'_> + AnotherTrait) {}
  ```

- Mutation 2: Introduce an additional impl Trait parameter with nested lifetimes.
  ```
  fn example_fn(param: impl Trait<'a> + AnotherTrait, another_param: impl OtherTrait<'b, 'c> + '_) {}
  ```

- Mutation 3: Add a named lifetime parameter to a parameter that previously had '_ lifetime.
  ```
  fn example_fn<'b>(param: impl Trait<'b> + AnotherTrait) {}
  ```

- Mutation 4: Change lifetime specifier order in bounds.
  ```
  fn example_fn(param: impl Trait<'a> + AnotherTrait + impl for<'d> OtherTrait<'d>) {}
  ```

4. Coverage and Exposure: By manipulating the lifetime specifiers and introducing new impl Trait parameters with complex bounds, this mutation increases coverage of the generic and lifetime-handling capabilities in the Rust compiler, especially focusing on potential type resolution issues and handling of non-lifetime binders.
