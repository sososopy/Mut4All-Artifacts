Mutation Operator: Alter Trait Method Signatures

Target: Trait definitions in Rust code, specifically focusing on modifying associated types and methods' return types.

Description:
This mutation targets traits in Rust code, particularly those that define associated types or methods. By altering method signatures or associated types, this operator aims to expose potential inconsistencies or errors in trait implementation and usage. This operator can be applied to any trait within a Rust codebase.

Example Mutations:
1. If a trait has an associated type, change it to another primitive type or remove it altogether.
   Before Mutation:
   ```
   pub trait Indices<const N: usize> {
       type Output;
       const NUM_ELEMS: usize;
   }
   ```
   After Mutation:
   ```
   pub trait Indices<const N: usize> {
       // Remove associated type
       const NUM_ELEMS: usize;
   }
   ```

2. Modify the return type of a method within a trait.
   Before Mutation:
   ```
   pub trait Arithmetic<T> {
       fn add(self, other: T) -> T;
   }
   ```
   After Mutation:
   ```
   pub trait Arithmetic<T> {
       fn add(self, other: T) -> Self; // Change return type to Self
   }
   ```

3. Add an associated type in a trait that didn't have one originally.
   Before Mutation:
   ```
   pub trait Displayable {
       fn display(&self);
   }
   ```
   After Mutation:
   ```
   pub trait Displayable {
       type DisplayType; // Introduce a new associated type
       fn display(&self);
   }
   ```

These mutations are designed to stress-test the handling of trait definitions and implementations, particularly in the context of generic const expressions, where associated types and method return types play a significant role in type inference and resolution.
