Mutation Operator: Modify Macro Expressions with Out-of-Range Literals

Description:
This mutation operator targets macro expressions that generate integer literals, specifically focusing on scenarios that could lead to out-of-range values. The mutation applies to any macro definition that outputs a numeric literal, such as an integer. By altering the literal to exceed typical bounds (e.g., the maximum value for a given type), this mutation can help uncover potential issues in the compiler's handling of such cases, particularly with lints related to range checking and diagnostics.

Where it Applies:
The mutation applies to macro definitions that involve numeric literals.

Example Mutation:
Original Macro Definition:
```rust
macro_rules! generate_value {
    () => {
        1000
    }
}
```

Mutated Macro Definition:
```rust
macro_rules! generate_value {
    () => {
        9999999999999999999999999999999999999999 // A very large out-of-range literal
    }
}
```

In this example, the original macro that returned a numeric literal "1000" is mutated to return a very large numeric literal that is likely out of range for most integer types. This forces the compiler to handle the out-of-range value, potentially exposing bugs related to range checks and diagnostic generation.
