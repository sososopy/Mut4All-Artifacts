Mutation Operator: Nested Struct and Union Field Duplication

Target Code Construct: This mutation operator targets nested structs and unions within structs and unions in Rust code.

Description: Rust's type system can be sensitive to the duplication of fields within nested structs and unions, especially when anonymous fields are involved. This mutation operator introduces potential conflicts by duplicating field names within nested anonymous structs and unions. The aim is to explore the compiler's handling of field name conflicts in nested data structures, which can lead to internal compiler errors (ICE) or other unexpected behavior.

Mutation Steps:
1. Identify nested anonymous structs or unions within a struct or union.
2. Within these nested structures, introduce a new field with the same name as an existing field within the same scope.
3. Ensure the new field has the same type as the duplicated field to maximize the likelihood of triggering a type conflict.

Example:

Original Seed Program:

```rust
struct Example {
    data: u32,
    details: union {
        value: u8,
    },
}
```

Mutated Program:

```rust
struct Example {
    data: u32,
    details: union {
        value: u8, // original field
        value: u8, // duplicated field, intentionally causing conflict
    },
}
```

By duplicating the field `value` within the nested union in the `Example` struct, the mutation operator introduces a conflict that tests the compiler's ability to handle such scenarios, potentially exposing issues in the handling of nested data structures.
