Mutation Operator: Modify Alignment of Packed Unions

Objective: This mutation operator targets packed unions with the intention of altering their alignment attributes. It aims to expose bugs related to alignment mismatches between ABI and layout during the compilation process.

Where it Applies: This operator is applicable to unions declared with the `#[repr(packed)]` attribute, where specific alignment values are set. It is particularly relevant for union types with members of varying sizes.

Description: 
- Identify unions that are declared with the `#[repr(packed)]` attribute within the seed program.
- Modify the alignment value specified for the packed union, either incrementally or decrementally, to create a potential mismatch between the ABI alignment and the layout alignment.

Example in Pseudo-Code Form:

Original Code:

```
#[repr(packed(1))]
union U {
    field1: u32,
    field2: u16,
}
```

Mutation:

```
#[repr(packed(2))]
union U {
    field1: u32,
    field2: u16,
}
```

Explanation: The original union `U` is packed with an alignment requirement of 1 byte. The mutation operator modifies this alignment to 2 bytes. This alteration may trigger alignment-related issues during compilation, potentially exposing bugs like the one outlined in the bug report.

Note: When introducing new alignment values, ensure they are valid for the target platform and conform to the constraints of the Rust language. Avoid using ambiguous terms and specify exact numeric values for alignment changes.
