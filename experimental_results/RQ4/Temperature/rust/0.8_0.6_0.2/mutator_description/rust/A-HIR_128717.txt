Mutation Operator: Replace ASCII Parentheses with Fullwidth Parentheses

Target: This mutation operator targets function call expressions within Rust source code. Specifically, it focuses on replacing the standard ASCII parentheses used in function calls with fullwidth Unicode parentheses, which are visually similar but different characters.

Application: Apply this mutation to function calls within the code where arguments are enclosed in parentheses.

Description: In any function call expression of the form `function_name(arguments)`, replace the '(' and ')' characters with their Unicode fullwidth equivalents '（' and '）' (U+FF08 and U+FF09, respectively). This mutation aims to test the compiler's handling of Unicode characters that resemble standard ASCII characters, potentially triggering bugs related to token parsing or character recognition.

Example of Mutation:

Original Code:
```
fn example_function(arg1: i32, arg2: i32) {
    // function body
}

pub fn main() {
    example_function(10, 20);
}
```

Mutated Code:
```
fn example_function(arg1: i32, arg2: i32) {
    // function body
}

pub fn main() {
    example_function（10, 20）;
}
```

In the mutated code, the parentheses in the function call `example_function(10, 20)` are replaced with their fullwidth Unicode equivalents, resulting in `example_function（10, 20）`. This mutation helps uncover potential issues in the compiler related to parsing and handling such Unicode characters.
