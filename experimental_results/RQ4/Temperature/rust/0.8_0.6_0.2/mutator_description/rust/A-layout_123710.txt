Mutation Operator: Enum Variant Alignment

Target: This mutation operator targets enum declarations with a `#[repr(packed)]` or other representation attributes.

Description: Modify the representation attribute of enums that are marked as packed to a standard representation (e.g., `#[repr(C)]`), and vice versa, to test for issues related to alignment and layout discrepancies.

Example:

Seed Program:
```rust
#[repr(C)]
enum Color {
    Red,
    Green,
    Blue,
}

fn main() {
    let color = Color::Red;
}
```

Mutated Program:
```rust
#[repr(packed)]
enum Color {
    Red,
    Green,
    Blue,
}

fn main() {
    let color = Color::Red;
}
```

Explanation: The mutation operator changes the representation attribute of an enum from `#[repr(C)]` to `#[repr(packed)]`. This change can trigger alignment-related issues due to the packed representation, which might expose bugs such as incorrect layout assertions in the compiler. If the original enum already uses `#[repr(packed)]`, you would change it to a standard representation like `#[repr(C)]`. This ensures high coverage across different program structures by introducing potential misalignments that the compiler needs to handle correctly.
