Mutation Operator: Duplicate Field Declaration in Nested Structures

Description:
This mutation operator targets nested structures within Rust code, focusing on duplicating field declarations within these structures. The operator specifically applies to structs and unions where fields are nested within another struct or union. The goal is to introduce errors that check how the compiler handles situations where a field is declared multiple times within the same nesting level or hierarchy. This can help expose bugs related to field uniqueness checks and the handling of unnamed fields in the Rust compiler.

Application Context:
- The operator applies to structs and unions with nested structures.

Changes and Examples:
1. Identify a struct or union with nested fields.

Original Code Example:
```
struct Sample {
    field1: u8,
    nested: struct {
        field2: u8,
    },
}
```

2. Duplicate the field declaration within a nested structure.

Mutated Code Example:
```
struct Sample {
    field1: u8,
    nested: struct {
        field2: u8,
        field2: u8, // Duplicate declaration
    },
}
```

In this example, the `field2` within the nested struct is declared twice, which should trigger a field uniqueness check, exposing potential bugs in the handling of such situations by the compiler. This mutation should be applied to various levels of nesting and different combinations of structs and unions to achieve high coverage across different program structures and features.
