Mutation Operator: Swap Pattern Matching with Tuple Destructuring in Functions

This mutation operator targets functions in Rust code that use pattern matching on tuples. Specifically, it applies to functions where a tuple pattern is being matched or destructured in a let statement or as part of a destructuring assignment. By swapping the order of tuple elements in the pattern and the corresponding source tuple, we can potentially expose bugs related to unexpected type assignments or pattern mismatches.

Mutation Description:
1. Identify functions that use pattern matching on tuples in a let binding or assignment.
2. Swap the order of the elements in the pattern with the elements in the tuple being destructured.

Example:

Before Mutation:
```rust
fn example_function() {
    let (x, y) = (1, "hello");
}
```

After Mutation:
```rust
fn example_function() {
    let (y, x) = ("hello", 1);
}
```

In this mutated version, the order of the elements in the pattern `(x, y)` is swapped with the elements in the source tuple `(1, "hello")`. This can help identify issues in the compiler's handling of pattern matching, especially with regard to type inference and assignment. If `x` and `y` are used later in the function, this mutation could potentially lead to type mismatch errors or unexpected behavior.
