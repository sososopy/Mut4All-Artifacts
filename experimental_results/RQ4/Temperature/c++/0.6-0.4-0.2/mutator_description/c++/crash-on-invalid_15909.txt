Mutation Operator: Atomic and Integer Comparison Adjustment

Target Code Construct: Comparison operations within conditional statements involving atomic types and integer types.

Mutation Rule:
1. Identify conditional statements where an atomic type (e.g., `atomic<unsigned int>`) is compared to a non-atomic integer type (e.g., `int`).
2. Modify the comparison by introducing an explicit conversion of the atomic type to the integer type before the comparison.
3. Ensure that the atomic variable is accessed using the `.load()` method to safely retrieve its value for comparison.

Example Before Mutation:
```
#include <atomic>

std::atomic<unsigned int> atomicVar = 10;
int nonAtomicVar = 5;

void checkValues() {
    if (atomicVar > nonAtomicVar) {
        // Code block
    }
}
```

Example After Mutation:
```
#include <atomic>

std::atomic<unsigned int> atomicVar = 10;
int nonAtomicVar = 5;

void checkValues() {
    if (atomicVar.load() > nonAtomicVar) {
        // Code block
    }
}
```

This mutation operator targets potential issues in comparisons involving atomic types and non-atomic integer types, which can lead to mismatched type comparisons and compiler crashes. By explicitly converting and safely accessing the atomic value, the mutation addresses the root cause of the bug while maintaining the logical intent of the original code.
