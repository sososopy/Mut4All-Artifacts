Mutation Operator: Modify Lambda Return Type

Target Construct: Lambda expressions within function bodies.

Mutation Rule:
1. Identify lambda expressions in the code. These are typically defined using the syntax `[](...) -> return_type { ... }`.
2. Locate the return type specified after the `->` operator in the lambda expression.
3. Change the specified return type to a function type. For example, if the lambda originally returns `int`, modify it to return `int(int)`.
4. Ensure that the lambda body still attempts to return a value of the original type, not a function type, to maintain inconsistency and trigger errors.

Example:
Original code:
```cpp
auto myLambda = [](int x) -> int {
    return x + 1;
};
```

Mutated code:
```cpp
auto myLambda = [](int x) -> int(int) {
    return x + 1;
};
```

This mutation operator targets lambda functions and modifies their return types to function types. This is likely to cause a crash or error in the compiler when it tries to handle the invalid function return type, especially when the lambda is invoked or used in expressions that expect the original return type.
