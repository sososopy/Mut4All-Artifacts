Mutation Operator: Incomplete Struct with Constexpr

Target Code Construct: Struct and Constexpr Declaration

Mutation Rule:
1. Identify a struct definition in the seed program. If an incomplete struct is not present, declare a new struct without defining its body. For example, declare `struct Y;` without providing any member details.
2. Locate a `constexpr` variable declaration in the seed program. If not present, introduce a `constexpr` variable declaration using the incomplete struct type. For example, `constexpr struct Y y;`.
3. Ensure that the `constexpr` variable is initialized with a value, even though the struct is incomplete. This will highlight the improper use of `constexpr` with an incomplete type.
4. If a `constexpr` variable already exists, mutate its type to use the incomplete struct. For example, change `constexpr int z = 10;` to `constexpr struct Y y = {0};`.

Example:
Original Code:
```cpp
struct Z {
    int a;
};

constexpr struct Z z = {1};
```

Mutated Code:
```cpp
struct Z;
constexpr struct Z z = {1};
```

This mutation operator targets scenarios where the compiler's handling of `constexpr` variables with incomplete struct types can be tested, potentially leading to assertion failures or crashes as observed in the bug report.
