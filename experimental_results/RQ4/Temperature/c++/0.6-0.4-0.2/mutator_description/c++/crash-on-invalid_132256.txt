Mutation Operator: Default Template Argument in Function Templates

Target Construct: Function Templates

Mutation Rule:
1. Identify a function template declaration in the seed program.
2. Add a default template argument to one of the template parameters.
3. Ensure the default argument is a simple type (e.g., int, double) or a constant expression.
4. Ensure the function template is instantiated or used in the code.

Example:
Original Code:
```cpp
template<typename T>
void func(T arg) {
    // Function implementation
}

int main() {
    func(10);
}
```

Mutated Code:
```cpp
template<typename T = int>
void func(T arg) {
    // Function implementation
}

int main() {
    func(10);
}
```

In this mutation operator, the function template `func` has been modified to include a default template argument `T = int`. This mutation aims to explore how the compiler handles default template arguments in function templates, potentially triggering bugs similar to those described in the bug report.
