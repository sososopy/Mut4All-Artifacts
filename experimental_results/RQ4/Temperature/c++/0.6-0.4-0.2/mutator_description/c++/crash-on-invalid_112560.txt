Mutation Operator: Modify Union Member Initialization

Target: Union member initialization within a union definition.

Mutation Rule:
1. Identify the union definition in the source code. For example, locate the union keyword followed by a name and brace-enclosed member declarations.
2. Within the union definition, locate the member that is being initialized. Typically, this will appear as a member variable followed by an assignment operator and an initializer (e.g., `int f = 5;`).
3. Modify the initialization by removing the initializer completely. For instance, change `int f = 5;` to `int f;`.
4. Ensure that the union still compiles correctly by checking that the member declaration syntax is valid without the initializer.

Example:
Original Code:
```
union U {
  int f = 5;
};
```

Mutated Code:
```
union U {
  int f;
};
```
