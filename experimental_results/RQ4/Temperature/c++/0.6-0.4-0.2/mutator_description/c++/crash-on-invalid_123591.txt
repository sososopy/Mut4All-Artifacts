Mutation Operator: Template Argument Expansion in Variant

Target Code Construct: Template using declarations and std::variant

Mutation Rule:
1. Identify a `template` using declaration that leverages `std::variant` to define a type alias. For example:
   ```cpp
   template <typename T>
   using MyVariant = std::variant<int, double, char>;
   ```

2. Introduce a parameter pack expansion within the `std::variant` declaration. Ensure that one of the types within the `std::variant` is a template parameter pack. For instance, replace the above code with:
   ```cpp
   template <typename... Ts>
   using MyVariant = std::variant<Ts...>;
   ```

3. In the main function or any function where the type alias is used, instantiate the template with multiple types to test the expansion. For example:
   ```cpp
   int main() {
       MyVariant<int, double, char> var; // Usage of the expanded variant
       return 0;
   }
   ```

4. Ensure that the template parameter pack is utilized in a way that can trigger potential edge cases in the compiler's handling of parameter packs with `std::variant`.

This mutation operator exploits the compiler's handling of template parameter packs in conjunction with `std::variant`, which can be a complex area for compilers due to the varied and potentially large number of template arguments to handle.
