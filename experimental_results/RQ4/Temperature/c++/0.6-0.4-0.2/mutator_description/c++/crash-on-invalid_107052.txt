Mutation Operator: Modify Built-in Function Call Arguments

Target: Built-in Function Calls

Mutation Rule:
1. Identify a built-in function call in the seed program, such as `__builtin_fpclassify`.
2. Replace a valid argument with an inappropriate type or value that the built-in function is not designed to handle.
3. Specifically, for `__builtin_fpclassify`, change one of the integer arguments (e.g., replace an integer with a floating-point value).

Example:
Original Code:
```cpp
int main() {
    __builtin_fpclassify(0, 1, 4, 3, 2, (inf));
}
```

Mutated Code:
```cpp
int main() {
    __builtin_fpclassify(0, 1.5, 4, 3, 2, (inf)); // Changed the second argument from integer '1' to floating-point '1.5'
}
```

Note: This mutation exploits the strict argument type requirements of built-in functions, which can lead to unexpected behavior or crashes when violated.
