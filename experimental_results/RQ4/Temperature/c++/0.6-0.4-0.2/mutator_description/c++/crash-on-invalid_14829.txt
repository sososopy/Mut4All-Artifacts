Mutation Operator: Modify Use of Comma Operator in Struct Friend Function

Target Construct: Struct with Friend Function

Mutation Rule:
1. Identify a struct in the seed program that has a friend function using the comma operator.
2. Modify the friend function declaration to include a variadic parameter (`...`) in addition to an existing parameter. This change aims to explore how the compiler handles variadic arguments in the context of friend functions.
3. Ensure that the modified friend function is used in an expression where the comma operator is employed.

Step-by-Step Instructions:
a. Locate a struct with a friend function that uses the comma operator.
b. Change the friend function signature to include a variadic parameter. For example, if the original friend function is `friend void operator,(MyStruct, int);`, modify it to `friend void operator,(MyStruct, ...);`.
c. Use the modified friend function in an expression with the comma operator, ensuring it involves multiple operands, including a variadic argument.

Example:
Original Struct:
```

  friend void operator,(MyStruct, int);
};
```

```

// Usage in an expression
```
