Mutation Operator: Conflicting External Declarations

Target Construct: Variable Declarations within Functions

Mutation Rule:
1. Identify a function with a parameter or a local variable declaration.
2. Introduce an 'extern' declaration for the same variable name within the function scope, creating a conflicting declaration.
3. Ensure the 'extern' declaration does not have an initializer and matches the type of the parameter or local variable.

Example:
Original Code:
```
void exampleFunction(int x) {
    // Function logic here
}
```

Mutated Code:
```
void exampleFunction(int x) {
    extern int x;
    // Function logic here
}
```

In this mutation, the 'extern' keyword is used to declare 'x' within the function scope, conflicting with the parameter 'x'. This operator focuses on creating a clash between a function parameter and an 'extern' declaration, which can lead to compiler crashes or unexpected behavior.
