Mutation Operator: Invalid Template Deduction Guide in Nested Namespace

Target Code Construct: Template deduction guides within nested namespaces

Mutation Rule:
1. Identify a template struct or class declaration within a namespace. Example:
   ```
   namespace ns {
       template <typename T> struct MyStruct;
   }
   ```
2. Outside of the namespace, attempt to declare a template deduction guide that incorrectly references the template without the namespace qualification.
3. Specifically, create a deduction guide that:
   - Uses the template name without the namespace prefix.
   - Attempts to deduce the template argument using a constructor-like syntax.
   - Ensure the deduction guide is declared in a different scope than the original template.

Example:
Original Code:
```
namespace ns {
    template <typename T> struct MyStruct;
}
```

Mutated Code:
```
namespace ns {
    template <typename T> struct MyStruct;
}

// Incorrect deduction guide outside the namespace
template <typename U> MyStruct() -> MyStruct<U>;
```

This mutation operator targets the misplacement of deduction guides and incorrect namespace qualifications, which can lead to compiler assertion failures or crashes, especially in compilers that do not handle such errors gracefully.
