Mutation Operator: Modify Pointer Indirection

Target Code Construct: Pointer Indirection in Expressions

Mutation Rule:
1. Identify an expression that involves pointer indirection, such as dereferencing a pointer.
2. Ensure the expression uses a literal or variable that is not a pointer type, e.g., an integer or a non-pointer variable.
3. Modify the expression by replacing the pointer operand with a non-pointer type, such as an integer literal or a non-pointer variable, to simulate invalid pointer indirection.

Example:
Original Code:
```cpp
int value = 5;
int *ptr = &value;
int result = *ptr;  // Valid pointer indirection
```

Mutated Code:
```cpp
int value = 5;
int result = *value;  // Invalid pointer indirection, as 'value' is not a pointer
```

This mutation operator exploits invalid pointer dereferencing, which is likely to trigger a crash or error in the compiler when it attempts to evaluate the expression.
