Mutation Operator: Modify Default Argument in Constructor

Target Code Construct: Constructor with Default Arguments

Mutation Rule:
1. Identify a constructor in a class or struct that has a default argument specified.
2. Remove the default argument value completely, leaving the parameter declaration without a default value.
3. Ensure that this mutation is applied to constructors where the default argument is a fundamental type (e.g., `int`, `double`).

Example:
Original Code:
```
struct T {
  T(int a = 5) {}
};
```

Mutated Code:
```
struct T {
  T(int a = ) {}
};
```
