Mutation Operator: Modify Function Template Return Type

Target Construct: Function Template

Mutation Rule:
1. Identify a function template declaration with an unspecified or auto return type.
2. Modify the return type to a specific type that is already defined in the seed program. If no suitable type is available, declare a new simple type (e.g., `int`, `double`).
3. Ensure that any usage of this function template in the program is consistent with the specified return type.

Example:
Original Code:
```
template <typename T>
auto f(int);

int main(int argc, char* argv[])
{
    decltype(auto) g = &f<int>;

    return 0;
}
```

Mutated Code:
```
template <typename T>
int f(int);  // Changed return type from auto to int

int main(int argc, char* argv[])
{
    decltype(auto) g = &f<int>;

    return 0;
}
```

In this mutation, the return type of the function template `f` is explicitly set to `int`, which should be a type that is compatible with the existing code or easily adaptable. This mutation is designed to test the compiler's handling of specific return types as opposed to deduced ones, potentially triggering bugs related to type resolution or template instantiation.
