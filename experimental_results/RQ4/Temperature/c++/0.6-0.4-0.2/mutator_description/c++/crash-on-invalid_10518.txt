Mutation Operator: Template Function Argument Misuse

Target Code Construct: Function templates

Mutation Rule:
1. Identify a function template definition in the seed program. This typically starts with the keyword `template` followed by template parameters in angle brackets, and then a function definition.
2. Modify the function template by introducing an incorrect or incompatible template argument in a function call to this template. Specifically, use an argument type that does not satisfy the template parameter's expected type or constraints.
3. Ensure that the template function is called within the code with the incorrect argument type.
4. Do not modify any other part of the code, and ensure existing variables or types are used for the incorrect argument.

Example:
Before Mutation:
template<typename T>
void process(T value) {
    // Function implementation
}

int main() {
    int x = 10;
    process(x); // Correct usage
    return 0;
}

After Mutation:
template<typename T>
void process(T value) {
    // Function implementation
}

int main() {
    int x = 10;
    process("string_literal"); // Incorrect usage: passing a string literal instead of an int
    return 0;
}

Explanation: This mutation operator targets function templates and modifies the function call site to use an incorrect argument type that does not match the expected template parameter type. This can potentially lead to compilation errors or crashes due to template instantiation issues in the compiler.
