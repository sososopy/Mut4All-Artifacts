Mutation Operator: Invalid Structured Binding with Non-Class Type

Target: This mutation operator targets structured bindings, specifically within function templates that attempt to decompose non-class, non-array types using structured bindings.

Mutation Rule:
1. Identify a function template that uses structured bindings to unpack variables from an input parameter.
2. Ensure that the input parameter type is non-class and non-array, such as a basic scalar type (e.g., `int`, `char`, `float`).
3. Modify the structured binding to attempt unpacking the scalar type, which should not be decomposable.

Step-by-Step Instructions:
- Locate the function template with a parameter meant for structured binding decomposition.
- Change the type of the parameter to a scalar type if it is not already (e.g., `int`, `char`).
- Attempt to use structured binding on this scalar type by introducing a binding pattern that would typically be used for classes or arrays.

Example:
Original Code:
```cpp
template <typename T>
void process(T t) {
    const auto& [a, b] = t; // Assume 't' is decomposable
    // Further processing
}
```

Mutated Code:
```cpp
template <typename T>
void process(T t) {
    const auto& [a, b] = t; // 't' is now a scalar type, e.g., int or char
    // Further processing
}

void example() {
    process(42); // Passing an integer
}
```

Explanation:
In this example, `process` is a function template that attempts to decompose its parameter `t` using structured bindings. By passing a scalar type like `int` to `process`, the structured binding `[a, b]` becomes invalid, as scalar types cannot be decomposed in this manner. This mutation should trigger errors or potential crashes in the compiler when it attempts to handle the invalid structured binding.
