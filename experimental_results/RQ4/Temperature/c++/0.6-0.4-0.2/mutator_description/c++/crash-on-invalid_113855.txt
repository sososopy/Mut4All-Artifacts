Mutation Operator

Target Code Construct: Union Initialization

Mutation Rule: Modify the initializer list of a union to include multiple initializations, which is invalid and can lead to a crash in the compiler.

Step-by-Step Mutation Instructions:
1. Identify a union declaration in the seed program. For example:
   ```
   union U {
      int a;
      double b;
   };
   ```
2. Locate a point in the code where this union is being initialized using an initializer list.
3. Modify the initializer list to initialize more than one member of the union simultaneously. For example, change:
   ```
   U u = { .b = 2.5 };
   ```
   To the following invalid form:
   ```
   U u = { .a = 1, .b = 2.5 };
   ```
4. Ensure the modified initializer list includes at least two initializations for different members of the union.

The mutation operator can be applied in any context where a union is initialized, ensuring that it attempts to initialize multiple members simultaneously, which is against the rules for union initialization and can trigger compiler bugs.
