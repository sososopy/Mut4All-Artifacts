Mutation Operator: Invalid Preprocessor Directive Parameter Order

Target Code Construct: Preprocessor Directives

Mutation Rule:
1. Identify a preprocessor directive in the seed program that accepts parameters, such as `#embed`, `#define`, or any custom directive with parameters.
2. Ensure the directive has at least two parameters, one known (valid) and one unknown (invalid or nonsensical).
3. Modify the order of parameters so that a known parameter is placed after an unknown parameter.
4. Example transformation:
   - Original: `#embed __FILE__ valid_param(2) unknown_param(3)`
   - Mutated: `#embed __FILE__ unknown_param(3) valid_param(2)`

This mutation operator exploits the handling of parameter order in preprocessor directives, potentially triggering assertion failures or crashes in the compiler's handling logic.
