Mutation Operator: Empty Template Parameter Pack in Function Return Type

Target: Function Templates with Template Parameter Packs

Mutation Rule:
1. Identify a function template that uses a template parameter pack in its return type.
2. Modify the function template to instantiate the function with an empty template parameter pack, ensuring the pack is used in the return type.
3. Ensure the function is called in a context where the pack is expanded, but without any elements.

Step-by-Step Instructions:
- Locate a function template in the seed program. Example:
  ```
  template <typename... Ts>
  struct Example {
      template <int N>
      static auto func() -> Ts...[N];
  };
  ```

- Modify the function call by instantiating it with an empty template parameter pack and accessing a specific index in the return type:
  ```
  Example<>::func<0>();
  ```

Explanation:
This mutation operator targets scenarios where a function template is defined with a template parameter pack, but the function is called with the pack being empty. The crash is triggered when the compiler attempts to access an index in the empty pack, leading to issues similar to the bug report. This operator is designed to provoke the compiler's handling of template instantiation and pack expansions, likely exposing weaknesses in the template system.
