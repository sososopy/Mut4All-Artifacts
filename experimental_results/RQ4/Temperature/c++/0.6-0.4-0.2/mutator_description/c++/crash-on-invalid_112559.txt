Mutation Operator: Modify User-Defined Conversion Operator

Target: User-defined conversion operators within a class or struct.

Mutation Rule:
1. Identify a user-defined conversion operator within a class or struct. This is typically declared using the `operator` keyword followed by the target type.
2. Change the return type of the conversion operator to a different type that is unrelated to the original intended type.
3. Ensure that the new return type is a valid type within the context of the program, but it should not logically relate to the source type.

Example:
Original Code:
```cpp
struct S {
    constexpr operator int() const {
        return 42;
    }
};
```

Mutated Code:
```cpp
struct S {
    constexpr operator double() const {
        return 42.0;
    }
};
```

Explanation: This mutation changes the return type of the conversion operator from `int` to `double`. This can potentially trigger bugs in the compiler when the conversion is used in contexts that expect an `int`. The mutation is applicable to any user-defined conversion operator and aims to explore how the compiler handles unexpected return types in conversion contexts.
