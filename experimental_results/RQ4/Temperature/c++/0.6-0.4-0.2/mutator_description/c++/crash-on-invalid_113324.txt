Mutation Operator: Modify Default Arguments in Friend Function Declarations

Target Code Construct: Friend Function Declaration within a Template Structure

Mutation Rule:
1. Identify a friend function declaration inside a template struct or class. The function should have parameters with default values.
2. Modify the default argument of one of the parameters. If the parameter already has a default value, change it to a different valid value. If it does not have a default value, add one.
3. Ensure that the modified default argument is a valid expression based on the parameter type.

Example:
Original Code:
```
template<typename = int>
struct MyStruct {
  friend void myFunction(MyStruct, int = 0);
};
```

Mutated Code:
```
template<typename = int>
struct MyStruct {
  friend void myFunction(MyStruct, int = 10);
};
```

In this mutation, the default argument of the `int` parameter in the friend function `myFunction` is changed from `0` to `10`. This modification aims to explore how changes in default arguments within friend function declarations inside template structures affect the compiler's behavior.
