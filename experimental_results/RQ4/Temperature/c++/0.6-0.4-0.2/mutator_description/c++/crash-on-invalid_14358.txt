Mutation Operator: Modify Template Function Instantiation

Target Construct: Template Function Definition and Instantiation

Mutation Rule:
1. Identify a template function definition in the seed program. The function should have at least one template parameter, such as `<typename T>`.
2. Locate an instantiation of this template function within the code. The instantiation should explicitly specify a type for the template parameter(s).
3. Modify the instantiation to use a complex type that combines multiple existing types or involves multiple levels of indirection. For example, if existing types are `int` and `double`, create a new type such as `std::pair<int*, double>`.
4. Ensure that the new type respects C++ syntax and semantics, and declare it if necessary before the function instantiation. If the type is a user-defined type, ensure it is forward-declared or fully defined.
5. Replace the original template function instantiation with the modified type instantiation, ensuring that all necessary conversions or constructions are valid.

Example:
Original Code:
```cpp
template<typename T>
void process(T value) {
    // Function body
}

void example() {
    int x = 10;
    process<int>(x);
}
```

Mutated Code:
```cpp
template<typename T>
void process(T value) {
    // Function body
}

using NewType = std::pair<int*, double>;

void example() {
    int x = 10;
    double y = 20.0;
    NewType z = std::make_pair(&x, y);
    process<NewType>(z);
}
```

This mutation operator targets the instantiation of template functions with complex types, which can potentially expose compiler edge cases related to type deduction, conversion, and template specialization.
