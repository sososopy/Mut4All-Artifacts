Mutation Operator:
Target: Template Function Parameter Packs
This mutation operator is designed to manipulate template function parameter packs, which are often involved in complex template instantiation processes. The goal is to create scenarios where parameter packs are incorrectly expanded or not expanded at all, potentially triggering compiler assertions related to parameter packs.

Mutation Rule:
1. Identify a template function that uses parameter packs. For example:
   ```
   template<typename... Args>
   void func(Args... args) {
       // function body
   }
   ```

2. Modify the function call to intentionally omit the expansion of some parameter packs. This can be done by calling the function with arguments that do not match the parameter pack structure, causing a mismatch in expansion. For example, if the original call is:
   ```
   func(1, 2, 3);
   ```
   Change it to:
   ```
   func(1, );
   ```

3. Alternatively, introduce incorrect usage of parameter packs within the function body. For example, attempting to use an unexpanded parameter pack directly in a context that requires expansion:
   ```
   auto x = args; // Incorrect usage without expansion
   ```

4. Ensure that the seed program has sufficient context to demonstrate the mutation. If necessary, introduce minimal additional code to make the mutation applicable, such as declaring a template function if one does not exist.

5. The mutation should be applied in a manner that does not require introducing new types or variables unless absolutely necessary. If new elements are introduced, they should be simple and clearly defined.

Example:
Original Code:
```
template<typename... Args>
void process(Args... args) {
    (void)std::initializer_list<int>{(args, 0)...}; // Correct expansion
}

int main() {
    process(1, 2, 3);
    return 0;
}
```

Mutated Code:
```
template<typename... Args>
void process(Args... args) {
    (void)std::initializer_list<int>{(args, 0)...}; // Correct expansion
    auto x = args; // Incorrect usage without expansion
}

int main() {
    process(1, ); // Incorrect call with missing arguments
    return 0;
}
```

This mutation operator aims to create scenarios where parameter packs are not expanded or improperly used, potentially leading to assertion failures in the compiler similar to the one described in the bug report.
