Mutation Operator: Modify Function Call Argument Types

This mutation operator targets function calls, specifically those involving template functions or overloaded functions, to introduce type mismatches that could potentially trigger compiler crashes. The mutation alters the types of arguments passed to a function to create scenarios where the compiler's overload resolution or template instantiation mechanisms are stressed.

Mutation Rule:
1. Identify a function call in the code that uses template parameters or is overloaded.
2. Select one of the arguments in the function call.
3. Change the type of the selected argument to a different type that is incompatible with the expected parameter type. The new type should be one that is already used in the program or a simple type like `int`, `double`, or `std::string`.
4. Ensure that the change does not introduce undeclared variables or types by using existing types or declaring them if necessary.

Example:
Original Code:
```cpp
#include <tuple>

void g(int, double) { }

int main() {
    g(1, 2.0);
}
```

Mutated Code:
```cpp
#include <tuple>

void g(int, double) { }

int main() {
    g(1, "test"); // Changed the second argument from double to string
}
```

This mutation specifically targets the argument list of function calls to create type mismatches, which can lead to complex overload resolution scenarios or template instantiation issues, potentially exposing bugs in the compiler's type-checking and overload resolution systems.
