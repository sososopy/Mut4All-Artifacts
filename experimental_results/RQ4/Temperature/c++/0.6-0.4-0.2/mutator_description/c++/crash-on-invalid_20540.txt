Mutation Operator: Template Argument Type Mismatch

Target: Template Function or Class

Mutation Rule:
1. Identify a template function or class in the seed program with type parameters.
2. Locate a function or class instantiation using this template with specific type arguments.
3. Modify the type of one of the template arguments in the instantiation to a different type that is not implicitly convertible to the original type. Ensure that the new type is defined within the seed program.
4. If necessary, declare a new type within the program that will serve as the mismatched type. Ensure this type is distinct and unrelated to the original type used in the template instantiation.

Example:
Suppose you have a template function declared as follows:

template <typename T>
void process(T value);

And it is instantiated in the program with an integer type:

process<int>(5);

Apply the mutation by changing the instantiation to use a custom-defined type:

// Define a new type within the seed program
struct CustomType {};

// Apply the mutation
process<CustomType>(CustomType());

This mutation operator aims to create a scenario where the template argument type does not match the expected type, potentially causing the compiler to crash during type deduction or instantiation.
