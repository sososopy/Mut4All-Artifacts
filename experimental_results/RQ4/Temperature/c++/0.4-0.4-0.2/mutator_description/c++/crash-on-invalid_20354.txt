Mutation Operator: Modify Function Parameter and External Declaration

Target Code Construct: Function parameter and external variable declaration

Mutation Rule:
1. Identify a function with a parameter that has the same name as an externally declared variable within the function scope.
2. Change the external variable declaration to another name that does not conflict with the function parameter.

Step-by-Step Instructions:
- Locate a function definition with a parameter, e.g., `void f(int i)`.
- Within the function body, find the external variable declaration that uses the same name as the parameter, e.g., `extern int i;`.
- Modify the external declaration to use a different name, ensuring it does not conflict with any existing names within the function or the program. For example, change `extern int i;` to `extern int j;`.

Example:
Original Code:
```
void f(int i) {
  extern int i;
}
```

Mutated Code:
```
void f(int i) {
  extern int j;
}
```

This mutation operator targets the linkage and scope conflict between function parameters and external declarations, which can lead to compiler crashes when improperly handled.
