Mutation Operator: Modify Lambda Return Types

Target Code Construct: Lambda expressions

Mutation Rule:
1. Identify a lambda expression in the seed program. This can be found by locating the `[]` syntax followed by a parameter list and a function body enclosed in `{}`.
2. Check the return type specified after the `->` symbol in the lambda expression.
3. Change the return type to a function type, which is invalid in C++. For example, if the return type is `int`, change it to `int(int)`.

Example:
Original Lambda:
```cpp
[] (int x) -> int {
    return x + 1;
}
```

Mutated Lambda:
```cpp
[] (int x) -> int(int) {
    return x + 1;
}
```

Explanation: This mutation targets lambda expressions by altering their return types to function types, which are not allowed in C++. This can lead to compiler crashes or errors, as demonstrated in the bug report where the lambda return type was incorrectly specified as `int(int)`. This mutation is applicable to any lambda expression in a C++ program, making it widely adaptable and likely to expose similar issues in the compiler.
