Mutation Operator: Modify Function Template Return Type

Target Code Construct: Function Template Declaration

Mutation Rule:
1. Identify a function template declaration in the seed program. The function template should have an unspecified or complex return type that could lead to ambiguity or misinterpretation by the compiler.
2. Change the return type of the function template to a known type, such as `int`, `double`, or `void`, to ensure the return type is explicitly defined.
3. If the function template is used with `decltype(auto)` in the program, replace `decltype(auto)` with the explicit type used in the function template return type to ensure consistency.

Example:
Original Code:
```
template <typename T>
auto f(int);

int main(int argc, char* argv[])
{
    decltype(auto) g = &f<int>;
    return 0;
}
```

Mutated Code:
```
template <typename T>
int f(int);

int main(int argc, char* argv[])
{
    int (*g)(int) = &f<int>;
    return 0;
}
```

Explanation:
- The function template `f` originally had an unspecified return type `auto`. This was changed to `int` to provide an explicit return type.
- The `decltype(auto)` declaration for `g` was replaced with `int (*g)(int)` to match the explicit return type of the function template `f`. This ensures that the type deduction is consistent and avoids potential compiler crashes due to ambiguity.
