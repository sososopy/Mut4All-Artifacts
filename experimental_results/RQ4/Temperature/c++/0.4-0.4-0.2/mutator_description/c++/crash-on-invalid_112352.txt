Mutation Operator: Template Parameter Pack Mutation

Target: This mutation operator targets template function definitions that utilize parameter packs.

Mutation Rule:
1. Identify a template function with a parameter pack, for example:
   ```cpp
   template<typename... Args>
   void exampleFunction(Args... args) {
       // Function body
   }
   ```

2. Introduce an unused parameter pack in the function definition. For instance, add another parameter pack that is not expanded or used within the function:
   ```cpp
   template<typename... Args, typename... Unused>
   void exampleFunction(Args... args) {
       // Function body
   }
   ```

3. Ensure that the newly introduced parameter pack `Unused` is not utilized or expanded within the function body. The function should still compile without any changes to its logic.

4. Compile the modified code to check if the mutation triggers a compiler crash or assertion failure related to unexpanded parameter packs.

Example:
Original Code:
```cpp
template<typename... Args>
void process(Args... args) {
    // Some processing logic
}
```

Mutated Code:
```cpp
template<typename... Args, typename... Unused>
void process(Args... args) {
    // Some processing logic
}
```

This mutation operator exploits the handling of parameter packs in template functions, which can lead to assertion failures if the compiler's logic for managing these packs is flawed. The goal is to create scenarios where the compiler's handling of unexpanded parameter packs is tested, potentially revealing bugs in the compiler's template instantiation process.
