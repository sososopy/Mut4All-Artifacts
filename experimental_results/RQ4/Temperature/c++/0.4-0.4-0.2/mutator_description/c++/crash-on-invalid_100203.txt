Mutation Operator: Template Argument Mismatch

Target: Function template instantiation

Mutation Rule:
1. Identify a function template in the seed program. For example, `template <typename... Ts> void foo(Ts&&... args) {}`.
2. Locate a function call that attempts to instantiate this template. For example, `foo<int, int>(0, i);`.
3. Modify the template argument list to introduce a mismatch between the number of template arguments and the number of function call arguments. Ensure that the mismatch causes a failure in matching the function template.
4. Specifically, change the template arguments such that they do not match the expected types or number of arguments in the function call. For example, change `foo<int, int>(0, i);` to `foo<int>(0, i);`.

Example:
Original Code:
```
template <typename... Ts> void foo(Ts&&... args) {}
void bar(int i) { foo<int, int>(0, i); }
```

Mutated Code:
```
template <typename... Ts> void foo(Ts&&... args) {}
void bar(int i) { foo<int>(0, i); }
```

This mutation operator exploits the template argument deduction mechanism and can lead to a compiler crash if the compiler fails to handle the mismatch gracefully.
