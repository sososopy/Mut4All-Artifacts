Mutation Operator: Template Concept Misuse

Target: Template concepts in C++ code.

Mutation Rule:
1. Identify a template concept declaration in the code. A template concept typically starts with the `concept` keyword followed by a name and a parameter list.
2. Modify the concept declaration by omitting the parameter list entirely, leaving only the concept name followed by a semicolon. This creates an invalid concept declaration.
3. Ensure that the modified concept is used in a template or function declaration to trigger the compiler's concept checking mechanism.

Example:
Original Code:
```
template <typename T>
concept HasSize = requires(T t) {
    { t.size() } -> std::convertible_to<std::size_t>;
};

template <HasSize T>
void process(T t) {
    // Function implementation
}
```

Mutated Code:
```
concept HasSize; // Parameter list omitted

template <HasSize T>
void process(T t) {
    // Function implementation
}
```

In this mutation, the concept `HasSize` is declared without a parameter list, which is syntactically incorrect and is likely to cause the compiler to crash or produce an error during concept checking. This mutation targets the concept declaration and its usage in templates, aiming to exploit weaknesses in the compiler's handling of invalid concept syntax.
