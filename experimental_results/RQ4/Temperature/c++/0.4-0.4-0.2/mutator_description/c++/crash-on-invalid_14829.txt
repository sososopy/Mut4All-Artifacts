Mutation Operator: Overload Operator with Varargs

Target Code Construct: Operator Overloading in Struct

Mutation Rule:
1. Identify a struct that has overloaded operators.
2. Within the struct, locate an existing operator that has been overloaded with a specific parameter type.
3. Introduce a new overload of the same operator using a variadic argument (e.g., `...`) as the parameter.
4. Ensure that the new overload is declared as a friend function within the struct to maintain access to private members if necessary.
5. Use the overloaded operator in an expression that involves a comma operator to trigger potential issues.

Example:
Original Code:
```
struct ExampleStruct {
  friend void operator,(ExampleStruct, int);
};

ExampleStruct example;
int result = (example, 42);
```

Mutated Code:
```
struct ExampleStruct {
  friend void operator,(ExampleStruct, int);
private:
  friend void operator,(ExampleStruct, ...);
};

ExampleStruct example;
int result = (example, 42, "trigger");
```

This mutation operator targets the overloading of operators within a struct and introduces a variadic argument overload to test the compiler's handling of such constructs, potentially leading to a crash or unexpected behavior.
