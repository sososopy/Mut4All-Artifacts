Mutation Operator: Recursive Class Member

Target: Class declarations

Mutation Rule:
1. Identify a class declaration in the seed program.
2. Within the class, declare a member variable of the same class type, creating a recursive member declaration.
3. Ensure that the class does not have a complete definition at the point of the member declaration.

Example:
Original Code:
```
class MyClass {
  int value;
  virtual void doSomething();
};
```

Mutated Code:
```
class MyClass {
  MyClass instance; // Recursive member declaration
  int value;
  virtual void doSomething();
};
```

This mutation operator exploits the incomplete type error by introducing a recursive member declaration within a class. It is designed to trigger compiler issues related to incomplete type handling, similar to the bug report provided.
