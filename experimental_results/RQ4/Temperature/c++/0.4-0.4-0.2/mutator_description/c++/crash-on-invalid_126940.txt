Mutation Operator: Misordered Preprocessor Directive Parameters

Target Code Construct: Preprocessor Directives

Mutation Rule:
1. Identify a preprocessor directive in the seed program that accepts multiple parameters, such as `#embed`.
2. Within the directive, reorder the parameters such that a known parameter (e.g., `limit`) is placed after an unknown or invalid parameter (e.g., `unknown_param`).
3. Ensure the unknown parameter is syntactically correct but semantically invalid within the context of the directive.

Example:
Original Code:
```cpp
#embed __FILE__ limit(2) offset(3)
```

Mutated Code:
```cpp
#embed __FILE__ unknown_param(2) limit(2) offset(3)
```

Explanation:
This mutation operator targets preprocessor directives by altering the order of parameters, placing an unknown parameter before a known one. This can lead to assertion failures or crashes in the compiler if it does not handle unexpected parameter orders gracefully. The mutation is designed to be easily applicable to any preprocessor directive with multiple parameters, thus providing broad coverage across different seed programs.
