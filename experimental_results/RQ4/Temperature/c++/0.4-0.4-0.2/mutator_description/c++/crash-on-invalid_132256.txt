Mutation Operator: Modify Default Template Arguments in Function Templates

Target: Function Templates

Mutation Rule:
1. Identify a function template in the seed program. Ensure that the template has at least one template parameter with a default argument.
2. Modify the default argument of the template parameter to a type or value that is incompatible or unexpected in the current context. This could involve changing a type to a non-existent type or altering a value to one that does not match the expected type constraints.
3. Ensure that the function template is instantiated in the code, either directly or indirectly, to trigger the mutation effect.

Example:
Original Code:
```cpp
template <typename T = int>
void foo(T value) {
    // Function implementation
}

int main() {
    foo(10); // Instantiation with default argument
}
```

Mutated Code:
```cpp
template <typename T = NonExistentType>
void foo(T value) {
    // Function implementation
}

int main() {
    foo(10); // Instantiation with default argument
}
```

Note: The mutation involves changing the default template argument `int` to `NonExistentType`, which is not declared in the program. This can potentially lead to a crash or error during template instantiation, as the type is not defined.
