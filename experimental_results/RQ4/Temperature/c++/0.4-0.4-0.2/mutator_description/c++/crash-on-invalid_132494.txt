Mutation Operator: Enum Forward Declaration with Template Instantiation

Target: Enum types, specifically forward-declared enums used in template instantiations.

Mutation Rule:
1. Identify an enum type that is forward-declared but not defined within the code.
2. Use this forward-declared enum type as a template argument in a template instantiation.
3. Ensure the template requires the enum type to be complete, such as using it in a context where its definition is necessary (e.g., static_assert or type traits).
4. Do not provide a definition for the enum within the code.

Example:
Original Code:
```cpp
enum struct MyEnum;

template <typename T>
struct CheckType {
    static_assert(sizeof(T) > 0, "Type must be complete");
};

CheckType<MyEnum> checker;
```

Mutation Steps:
1. Forward declare an enum type without defining it: `enum struct MyEnum;`
2. Create a template that requires the type to be complete, such as using `sizeof(T)` in a `static_assert`.
3. Instantiate the template with the forward-declared enum type.
4. Ensure that no definition of `MyEnum` is provided in the code.
