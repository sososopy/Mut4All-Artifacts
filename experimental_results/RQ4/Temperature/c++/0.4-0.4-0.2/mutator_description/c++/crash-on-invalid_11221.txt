Mutation Operator: Modify Template Specialization

Target Construct: Class Template Partial Specialization

Mutation Rule:
1. Identify a class template in the seed program. For example, a template declaration like `template<typename T> class MyClass {};`.
2. Introduce a partial specialization for this class template. For instance, if the original template is `template<typename T> class MyClass {};`, add a partial specialization such as `template<typename T> class MyClass<T*> {};`.
3. Ensure that the partial specialization is syntactically correct but semantically conflicting or redundant with an existing specialization. For example, create another partial specialization that could be ambiguous with the existing one, like `template<typename T> class MyClass<T**> {};`.
4. Use existing types or template parameters from the program to ensure that the mutation is valid within the context of the seed program.
5. Verify that the mutation does not introduce undeclared types or variables by using only the types and template parameters already defined or by properly declaring new ones if necessary. For example, if introducing a new type, declare it before use: `using NewType = int;`.

Example:
Original:
template<typename T> class MyClass {};

Mutated:
template<typename T> class MyClass {};
template<typename T> class MyClass<T*> {};
template<typename T> class MyClass<T**> {};
