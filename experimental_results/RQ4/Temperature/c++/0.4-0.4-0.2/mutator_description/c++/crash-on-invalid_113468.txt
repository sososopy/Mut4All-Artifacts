Mutation Operator: Modify Conditional Statements with Comma Operator

Target Code Construct:
This mutation operator targets conditional statements within functions, specifically the `if` statement.

Mutation Rule:
1. Identify an `if` statement within a function.
2. Replace the condition of the `if` statement with a comma operator expression.
3. Ensure that the first operand of the comma operator is an assignment expression, and the second operand is a boolean expression.
4. Use existing variables and expressions from the seed program whenever possible.

Example:
Original Code:
```
int exampleFunction() {
    int x = 0;
    if (x > 0) {
        return 1;
    }
    return 0;
}
```

Mutated Code:
```
int exampleFunction() {
    int x = 0;
    if ((x = 1, x > 0)) {
        return 1;
    }
    return 0;
}
```

Explanation:
- The original condition `x > 0` in the `if` statement is replaced with a comma operator expression `(x = 1, x > 0)`.
- The first part of the comma operator assigns a value to `x`, and the second part evaluates the condition.
- This mutation can introduce unexpected behavior or edge cases in the evaluation of conditions, potentially triggering compiler bugs.
