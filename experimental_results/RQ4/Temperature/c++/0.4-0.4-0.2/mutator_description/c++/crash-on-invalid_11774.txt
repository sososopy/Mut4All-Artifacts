Mutation Operator: Namespace Reordering

Target: This mutation operator targets namespaces within a C++ source file.

Mutation Rule:
1. Identify a sequence of nested namespaces in the source code. For example, if the original code has:
   ```
   namespace A {
       namespace B {
           namespace C {
               // Code here
           }
       }
   }
   ```
2. Change the order of the nested namespaces. For instance, reorder them as:
   ```
   namespace C {
       namespace A {
           namespace B {
               // Code here
           }
       }
   }
   ```
3. Ensure that any references to types or functions within these namespaces are updated to reflect the new order. For example, if there was a reference to `A::B::C::someFunction()`, it should be updated to `C::A::B::someFunction()`.

4. If the namespaces contain any forward declarations or using directives, adjust them accordingly to maintain valid references.

5. Compile the modified code to observe if the reordering causes any unexpected behavior or crashes in the compiler.

This mutation operator is designed to test the compiler's ability to handle complex namespace structures and ensure that reordering does not lead to internal inconsistencies or crashes.
