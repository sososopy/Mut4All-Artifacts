Mutation Operator: Template Argument Type Mismatch

Target Code Construct: Template function or class instantiation

Mutation Rule:
1. Identify a template function or class in the seed program that takes one or more template parameters.
2. Locate a call or instantiation of this template function or class.
3. Modify the type of one of the template arguments in the instantiation to a different type that is incompatible with the expected type.
4. Ensure that the modified type does not match the expected template parameter type, leading to a type mismatch.

Example:
Original Template Function:
```cpp
template<typename T>
void process(T value) {
    // Processing logic
}

int main() {
    int number = 5;
    process(number); // Original instantiation
}
```

Mutated Content:
```cpp
template<typename T>
void process(T value) {
    // Processing logic
}

int main() {
    double number = 5.0;
    process(number); // Mutated instantiation with a different type
}
```

In this example, the original instantiation uses an `int`, while the mutated version uses a `double`, which may trigger a type mismatch issue if the template function expects a specific type, potentially leading to a compiler crash.
