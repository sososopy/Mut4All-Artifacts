Mutation Operator: Modify Default Arguments in Friend Functions

Target Code Construct:
This mutation operator targets friend function declarations within template structs or classes.

Mutation Rule:
1. Identify a friend function declaration within a template struct or class that has at least one parameter with a default argument.
2. Modify the default argument of one of the parameters to an expression that involves a template parameter or a non-trivial expression (e.g., a function call or arithmetic operation).

Step-by-Step Instructions:
- Locate the friend function declaration within the template struct or class.
- Select a parameter that has a default argument.
- Change the default argument to an expression involving a template parameter or a more complex expression. Ensure that the new expression is syntactically correct but semantically unusual or complex enough to potentially trigger compiler issues.

Example:
Original Code:
```
template<typename T = int>
struct MyStruct {
  friend void myFunction(MyStruct, int = 0);
};
```

Mutated Code:
```
template<typename T = int>
struct MyStruct {
  friend void myFunction(MyStruct, int = sizeof(T) + 1);
};
```

Explanation:
In the mutated code, the default argument `0` is replaced with `sizeof(T) + 1`, which introduces a dependency on the template parameter `T`. This change can potentially expose issues in the compiler's handling of default arguments in template contexts.
