Mutation Operator: Template Specialization with Invalid Type

Target Code Construct: Template Function Specialization

Mutation Rule:
1. Identify a function template that takes a template parameter (e.g., `template<class T> void func(T param);`).
2. Specialize the function template using a type that is not typically valid for the intended operation, such as a pointer to a void type or an incomplete type.
3. Ensure the specialized type is used in a context that typically requires a complete type, such as an instantiation or a function call.

Example:
Original Code:
```cpp
template<class T> void process(T param) {}

void example() {
    process(10);
}
```

Mutation:
1. Specialize the function template `process` with an invalid or incomplete type.
2. Use the specialized function in a context that requires a complete type.

Mutated Code:
```cpp
template<class T> void process(T param) {}

void example() {
    process<void*>(nullptr);  // Specialize with a pointer to void type
}
```

In this mutation, the function template `process` is specialized with a pointer to a void type, which is typically not valid for operations that require a complete type. This mutation can trigger potential compiler bugs related to template specialization and type checking.
