Mutation Operator: Invalid Structured Binding with Non-Class Type

Target: This mutation operator targets structured bindings in C++.

Mutation Rule:
1. Identify a structured binding declaration in the seed program. This is typically of the form `auto [a, b, ...] = expr;`.
2. Ensure that the expression on the right-hand side of the structured binding is a type that does not support decomposition, such as a fundamental type (e.g., `int`, `char`, `double`).
3. Replace the existing expression with a non-class, non-array type expression.

Example:
Original Code:
```
std::tuple<int, int> myTuple = std::make_tuple(1, 2);
auto [x, y] = myTuple;
```

Mutated Code:
```
char myChar = 'a';
auto [x, y] = myChar; // This will trigger a compiler error as 'char' cannot be decomposed
```

Note: The mutation involves changing the right-hand side of the structured binding to a type that does not support decomposition, such as a `char` or `int`. This mutation is likely to trigger errors related to invalid structured bindings.
