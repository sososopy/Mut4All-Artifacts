Mutation Operator: Union Designated Initializer Mutation

Target: Union initialization within functions.

Mutation Rule: Modify the initialization of union members using designated initializers to create scenarios where multiple initializers are used, which can lead to compiler crashes.

Step-by-step Instructions:
1. Identify a union type in the seed program. Ensure the union has at least two members of different types.
2. Locate a function where this union type is being used or can be introduced.
3. Within the function, create a new instance of the union using the `new` operator.
4. Initialize the union using designated initializers for more than one member. For example, if the union has members `int a` and `float b`, use an initializer like `new UnionType{.a = 1, .b = 2.0}`.
5. Ensure that the designated initializers are valid for the union members but include more than one initializer to trigger potential assertion failures in the compiler.

Example:
Suppose the seed program includes the following union:
```
union ExampleUnion {
    int a;
    double b;
};
```
Apply the mutation within a function:
```
void testFunction() {
    new ExampleUnion{.a = 10, .b = 20.5}; // This mutation uses multiple initializers
}
```
This mutation operator exploits the handling of union initializations by compilers and can trigger assertion failures if the compiler does not properly handle multiple initializers for unions.
