Mutation Operator: Modify Template Deduction Guide Scope

Target Code Construct: Template Deduction Guide

Mutation Rule:
1. Identify a template deduction guide in the code, which is a function-like declaration that specifies how to deduce template arguments from constructor arguments.
2. Ensure that the deduction guide is declared in the same scope as the template it is associated with.
3. If the deduction guide is declared outside the scope of the associated template, move it inside the correct scope.

Example:
Original Code:
```
namespace a {
template <class> struct pair;
}
template <class _T2> pair() -> pair<_T2>;
```

Mutated Code:
```
namespace a {
template <class> struct pair;
template <class _T2> pair() -> pair<_T2>; // Move deduction guide inside the namespace
}
```

Explanation:
In the original code, the template deduction guide for `pair` is declared outside the namespace `a`, which causes a scope mismatch and triggers a compiler crash. The mutation involves moving the deduction guide into the same namespace where the `pair` template is declared, ensuring the scope is consistent and preventing the crash. This mutation targets the scope resolution of templates and deduction guides, which is a common source of errors in template-heavy C++ code.
