Mutation Operator: Modify Function Overload Resolution with Ambiguous Types

Target Code Construct: Function Overloading

Mutation Rule:
1. Identify a function that is overloaded with different parameter types in the seed program.
2. Modify one of the function calls to use a type that could match multiple overloaded versions but is not explicitly defined in the overload set. This can be done by introducing a type conversion or using a type that can be implicitly converted to multiple types in the overload set.
3. Ensure the modified function call includes parameters that can be ambiguously resolved by the compiler, potentially leading to a crash or an error due to ambiguity.

Example:
Original Code:
```cpp
void process(int value);
void process(double value);

int main() {
    process(42); // Calls process(int)
}
```

Mutated Content:
```cpp
void process(int value);
void process(double value);

int main() {
    process(42.0f); // Ambiguous: float can be converted to both int and double
}
```

Explanation:
In this mutation, the function `process` is overloaded with `int` and `double` as parameter types. By changing the argument in the function call from an `int` to a `float`, the call becomes ambiguous because `float` can be converted to both `int` and `double`. This ambiguity can potentially lead to a compiler crash or an error in overload resolution, especially if the compiler's handling of such cases is flawed.
