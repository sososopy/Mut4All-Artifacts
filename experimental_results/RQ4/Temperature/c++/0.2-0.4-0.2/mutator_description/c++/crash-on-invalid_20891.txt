Mutation Operator: Modify Function Template Return Type

Target Code Construct: Function Template

Mutation Rule:
1. Identify a function template in the seed program. The function template should have an unspecified or unknown return type, typically indicated by `auto`.
2. Modify the return type of the function template to a specific type, such as `int`, `double`, or any other concrete type that is already used in the seed program.
3. Ensure that the function template's body, if present, is compatible with the new return type. If the body is not present, you can leave it as is or provide a simple return statement that matches the new type.

Example:
Original Code:
```cpp
template <typename T>
auto f(int);

int main() {
    decltype(auto) g = &f<int>;
    return 0;
}
```

Mutated Code:
```cpp
template <typename T>
int f(int) {
    return 0; // Ensure the return type matches the new type
}

int main() {
    decltype(auto) g = &f<int>;
    return 0;
}
```

Explanation:
This mutation operator targets function templates with unspecified return types. By changing the return type to a specific type, we can test the compiler's handling of type inference and template instantiation. This mutation is likely to trigger bugs related to type deduction and template specialization, especially in compilers that have incomplete support for C++14 features.
