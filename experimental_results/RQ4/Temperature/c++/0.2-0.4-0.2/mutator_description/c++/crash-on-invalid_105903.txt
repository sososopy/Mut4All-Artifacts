Mutation Operator: Modify Template Parameter Pack Usage

Target: Template function return type involving parameter packs

Mutation Rule:
1. Identify a template function that uses a parameter pack in its return type.
2. Modify the function to use an empty parameter pack in the return type, which is likely to trigger issues in the compiler's handling of pack expansions.
3. Ensure that the template function is instantiated with an empty parameter pack.

Example:
Original Code:
```cpp
template <typename... Ts>
struct Example {
    template <unsigned N>
    static auto func() -> Ts...[N] {}
};

void test() {
    Example<int, double>::func<0>();
}
```

Mutated Code:
```cpp
template <typename... Ts>
struct Example {
    template <unsigned N>
    static auto func() -> Ts...[N] {}
};

void test() {
    Example<>::func<0>(); // Instantiate with an empty parameter pack
}
```

Explanation:
The mutation involves changing the instantiation of the template struct `Example` to use an empty parameter pack. This modification targets the compiler's handling of pack expansions in return types, which can lead to crashes if not properly managed. This mutation is designed to exploit potential weaknesses in the compiler's template instantiation logic, particularly when dealing with empty packs.
