Mutation Operator: Modify Conditional Statements with Comma Operator

Target Code Construct: Conditional statements within functions.

Mutation Rule:
1. Identify a conditional statement (e.g., within an if, while, or for loop).
2. Replace the condition with a comma operator expression that includes an assignment and a condition check.
3. Ensure that the assignment and condition check involve existing variables or expressions from the seed program.

Example:
Original Code:
```
int foo(int a) {
  if (a > 0) {
    return 1;
  }
  return 0;
}
```

Mutated Code:
```
int foo(int a) {
  if ((a = 0, a > 0)) {
    return 1;
  }
  return 0;
}
```

Explanation:
- The mutation introduces a comma operator in the conditional statement, which first assigns a value to the variable and then evaluates the condition. This can lead to unexpected behavior and potentially trigger compiler bugs, especially if the compiler mishandles the evaluation order or type checks.
