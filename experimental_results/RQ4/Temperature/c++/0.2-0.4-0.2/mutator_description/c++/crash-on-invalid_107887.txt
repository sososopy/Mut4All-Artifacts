Mutation Operator: Modify Template Deduction Guide Scope

Target Code Construct: Template Deduction Guide

Mutation Rule:
1. Identify a template deduction guide in the code. This is typically a line that uses the syntax `template <class T> ClassName() -> ClassName<T>;`.
2. Ensure that the deduction guide is declared in the same namespace or scope as the template it refers to.
3. If the deduction guide is outside the scope of the template, move it inside the correct namespace or scope.
4. If the deduction guide is already in the correct scope, introduce an error by moving it outside the scope to trigger a potential compiler crash.

Example:
Original Code:
```
namespace a {
template <class> struct pair;
}
template <class T> pair() -> pair<T>;
```

Mutated Code:
```

template <class> struct pair;
template <class T> pair() -> pair<T>; // Move the deduction guide inside the namespace
}
```

Explanation:
This mutation operator targets the scope of template deduction guides. By ensuring that the deduction guide is declared within the same scope as the template, or by deliberately moving it outside to introduce an error, we can test the compiler's handling of scope-related issues with deduction guides. This mutation is designed to exploit the compiler's handling of template deduction guide scopes, which can lead to crashes if not managed correctly.
