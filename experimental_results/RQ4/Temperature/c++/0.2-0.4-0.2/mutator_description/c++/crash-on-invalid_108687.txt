Mutation Operator: Incomplete Static Assertion

Target Code Construct: Static Assertions

Mutation Rule:
1. Identify a static assertion in the code, which is typically in the form of `static_assert(condition, message)`.
2. Modify the static assertion by removing or truncating the message string, ensuring it is incomplete or improperly terminated.
3. Ensure that the condition part of the static assertion remains valid to isolate the mutation effect on the message string.

Example:
Original Code:
```
static_assert(sizeof(int) > 2, "Integer size is too small");
```

Mutated Code:
```
static_assert(sizeof(int) > 2, "Integer size is too small
```

Explanation:
The mutation operator targets static assertions by creating an incomplete or improperly terminated message string. This can lead to parsing issues or crashes in the compiler when it attempts to process the malformed string. The condition is left unchanged to focus the mutation effect on the message part of the static assertion.
