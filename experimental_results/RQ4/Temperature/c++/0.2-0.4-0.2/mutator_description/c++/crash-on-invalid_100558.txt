Mutation Operator: Modify Lambda Return Type

Target: Lambda expressions within function bodies.

Mutation Rule:
1. Identify a lambda expression in the code. This can be within any function, including main or other user-defined functions.
2. Check the return type of the lambda. If it is a valid type, proceed to modify it.
3. Change the return type of the lambda to a function type. For example, if the lambda currently returns an `int`, change it to `int(int)`.
4. Ensure that the lambda body attempts to return a value of the new function type, even though it is incorrect. This will likely involve returning a variable or expression that does not match the new return type.

Example:
Original Code:
```cpp
auto lambda = [](int x) -> int {
    return x + 1;
};
```

Mutated Code:
```cpp
auto lambda = [](int x) -> int(int) {
    return x + 1; // This line is intentionally incorrect for the mutation.
};
```

This mutation operator targets the lambda expression's return type, changing it to a function type, which is not a valid return type for a lambda. This is likely to trigger compiler errors or crashes, especially when the lambda is invoked, as it introduces a type mismatch that the compiler must handle.
