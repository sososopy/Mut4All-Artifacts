Mutation Operator: Modify Concept Definition

Target: Concept definition in template declarations.

Mutation Rule:
1. Identify a concept definition in the seed program. A concept is typically defined using the `concept` keyword followed by a name and a constraint expression.
2. Modify the constraint expression of the concept to be an expression that evaluates to a non-boolean type. This can be achieved by replacing the constraint expression with an integer or floating-point literal.
3. Ensure that the modified concept is used in a template declaration, such as a template class or function, to trigger the compiler's constraint checking mechanism.

Example:
Original Code:
```
template <typename T> concept MyConcept = sizeof(T) > 4;
template <MyConcept T> struct MyStruct {};
```

Mutated Code:
```
template <typename T> concept MyConcept = 42; // Constraint expression changed to an integer literal
template <MyConcept T> struct MyStruct {};
```

Explanation:
The mutation changes the constraint expression of the concept `MyConcept` from a boolean expression (`sizeof(T) > 4`) to an integer literal (`42`). This alteration is likely to trigger a compiler bug related to constraint normalization or checking, as concepts are expected to evaluate to boolean expressions. The mutation is applied to the concept definition and is used in a template declaration to ensure the compiler processes the modified concept.
