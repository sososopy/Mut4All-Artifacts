Mutation Operator: Template Specialization with Const Qualifier

Target Code Construct: Function Template Instantiation

Mutation Rule:
1. Identify a function template that takes a template class as a parameter.
2. Modify the template class parameter to include a const qualifier in its template argument.
3. Ensure that the function is called with an instantiation of the template class using a non-const type.

Example:
Original Code:
template<class T> struct C {};
template<class T> void h(C<T> p);
void i() { h(C<int>()); }

Mutated Code:
template<class T> struct C {};
template<class T> void h(C<const T> p);
void i() { h(C<int>()); }

Explanation:
This mutation operator targets function template instantiations where the template class parameter is modified to include a const qualifier. The function is then called with an instantiation of the template class using a non-const type. This can lead to inconsistencies in type expectations and potentially trigger compiler bugs related to type handling and template specialization.
