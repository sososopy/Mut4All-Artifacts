Mutation Operator: Modify Pointer Indirection

Target Code Construct: Pointer Indirection in Expressions

Mutation Rule:
1. Identify expressions in the seed program that involve pointer indirection, such as `*ptr`.
2. Replace the pointer operand with a non-pointer type, such as an integer or a floating-point number.
3. Ensure that the modified expression is syntactically valid but semantically incorrect, which can lead to compiler crashes during evaluation.

Example:
Original Code:
```cpp
int* ptr = nullptr;
int value = *ptr; // Pointer indirection with a valid pointer type
```

Mutated Code:
```cpp
int nonPointer = 42;
int value = *nonPointer; // Pointer indirection with a non-pointer type
```

Explanation:
This mutation operator targets pointer indirection expressions by replacing the pointer operand with a non-pointer type. This can lead to semantic errors that may trigger compiler crashes during the evaluation phase, as the compiler attempts to dereference a non-pointer type. This mutation is designed to exploit weaknesses in the compiler's handling of invalid pointer operations, potentially leading to assertion failures or crashes.
