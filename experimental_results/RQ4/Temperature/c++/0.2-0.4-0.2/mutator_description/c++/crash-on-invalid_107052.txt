Mutation Operator: Modify Built-in Function Call with Incorrect Argument Type

Target Code Construct: Function Call Expression

Mutation Rule:
1. Identify a function call expression in the seed program that uses a built-in function, such as `__builtin_fpclassify`.
2. Select one of the arguments in the function call that is expected to be of a specific type (e.g., an integer or a floating-point number).
3. Replace the selected argument with an expression of an incompatible type, such as a string literal or a character constant.
4. Ensure that the replacement maintains syntactic correctness, but introduces a semantic error due to type incompatibility.

Example:

```

    int result = __builtin_fpclassify(0, 1, 4, 3, 2, 1.0);

```

