Mutation Operator: Overloaded Function Call with Incorrect Argument Types

Target Code Construct: Function Calls

Mutation Rule:
1. Identify a function call in the seed program where the function is overloaded with multiple signatures.
2. Select one of the overloaded functions and note its parameter types.
3. Modify the function call by changing the argument types to ones that do not match any of the overloaded function signatures. Ensure that the new argument types are incompatible with all available overloads.
4. If necessary, introduce new variables or literals of the required types to use as arguments in the function call. Ensure these new elements are clearly declared and initialized before the function call.

Example:
Original Code:
```cpp
void process(int a) { /* ... */ }
void process(double a) { /* ... */ }

int main() {
    process(42); // Calls process(int)
}
```

Mutated Code:
```cpp
void process(int a) { /* ... */ }
void process(double a) { /* ... */ }

int main() {
    process("invalid"); // No matching function for call to 'process'
}
```

In this example, the mutation changes the argument from an integer to a string literal, which does not match any of the available overloaded function signatures, potentially triggering a compiler bug related to overload resolution.
