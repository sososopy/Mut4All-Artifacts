Mutation Operator: Modify Template Function Specialization

Target Construct: Template Function Specialization

Mutation Rule:
1. Identify a template function in the seed program. For example, a function template declared as `template<typename T> void func(T param)`.
2. Locate a specialization of this template function. For instance, `template<> void func<int>(int param)`.
3. Modify the specialization by introducing an additional, unused template parameter in the specialization. For example, change `template<> void func<int>(int param)` to `template<typename U> void func<int>(int param)`.
4. Ensure that the additional template parameter `U` is not used within the function body of the specialization.
5. Verify that the modified specialization is still syntactically correct and compiles without introducing new variables or types that are not already declared in the seed program.

Example:
Original Code:
```cpp
template<typename T>
void func(T param) {
    // Function implementation
}

template<>
void func<int>(int param) {
    // Specialized implementation for int
}
```

Mutated Code:
```cpp
template<typename T>
void func(T param) {
    // Function implementation
}

template<typename U>
void func<int>(int param) {
    // Specialized implementation for int with an unused template parameter U
}
```

This mutation operator targets the template function specialization construct and introduces an unused template parameter to potentially trigger compiler bugs related to template handling and specialization.
