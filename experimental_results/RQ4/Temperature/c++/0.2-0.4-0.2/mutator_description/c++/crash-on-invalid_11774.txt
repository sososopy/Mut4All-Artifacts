Mutation Operator: Namespace Nesting Disruption

Target Code Construct: Namespace declarations

Mutation Rule:
1. Identify a nested namespace declaration in the seed program. For example, if the seed program has:
   ```
   namespace A {
       namespace B {
           namespace C {
               // Code here
           }
       }
   }
   ```
2. Introduce a disruption in the nesting by closing one of the namespaces prematurely and then reopening it. This can be done by:
   a. Closing the innermost namespace with a `}`.
   b. Adding a semicolon `;` immediately after the closing brace.
   c. Reopening the namespace with the same name.
3. Ensure that the disruption is syntactically correct but semantically unusual, which might confuse the compiler's namespace resolution logic.

Example:
Original Code:
```
namespace A {
    namespace B {
        namespace C {
            int x;
        }
    }
}
```

Mutated Code:
```
namespace A {
    namespace B {
        namespace C {
            int x;
        }
        ; // Premature closure of namespace C
        namespace C {
            // Reopened namespace C
        }
    }
}
```

This mutation operator targets the compiler's handling of nested namespaces and aims to exploit potential weaknesses in the parsing and resolution of namespace scopes. By introducing a semantically unusual but syntactically valid construct, it increases the likelihood of triggering a compiler bug related to namespace handling.
