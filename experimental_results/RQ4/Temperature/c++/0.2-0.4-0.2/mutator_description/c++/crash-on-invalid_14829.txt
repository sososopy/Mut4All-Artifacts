Mutation Operator: Modify Friend Function with Varargs

Target Code Construct: Friend function declarations within a struct

Mutation Rule:
1. Identify a struct that contains a friend function declaration using varargs (e.g., `...`).
2. Modify the friend function declaration by changing the parameter list to include a mix of fixed and vararg parameters.
3. Ensure that the modified friend function is used in an expression within the program to trigger potential compiler behavior.

Example:
Original Code:
```
struct ExampleStruct {
  friend void operator,(ExampleStruct, ...);
};
```

Mutation Steps:
1. Locate the friend function declaration with varargs: `friend void operator,(ExampleStruct, ...);`
2. Modify the parameter list to include a fixed parameter followed by varargs: `friend void operator,(ExampleStruct, int, ...);`
3. Use the modified friend function in an expression:
   ```
   const char *result = (ExampleStruct(), 42, "test");
   ```

This mutation operator targets the handling of friend functions with mixed parameter types, which can expose issues in the compiler's handling of varargs in combination with other parameters.
