Mutation Operator: Modify Union Member Initialization

Target Code Construct: Union member initialization

Mutation Rule:
1. Identify a union declaration in the seed program.
2. Locate a member of the union that is initialized with a default value.
3. Remove the initializer for the union member, leaving it uninitialized.
4. Ensure that the union is used in a function or a block of code to trigger potential issues.

Example:
Original Code:
```
union MyUnion {
  int member = 42;
};

void exampleFunction() {
  MyUnion u;
}
```

Mutated Code:
```
union MyUnion {
  int member;
};

void exampleFunction() {
  MyUnion u;
}
```

Explanation:
This mutation operator targets union member initializations by removing the initializer, which can lead to undefined behavior or trigger compiler crashes when the union is used. The mutation is applied to existing union members, ensuring that the union is utilized in the code to maximize the chance of exposing compiler bugs.
