Mutation Operator: Modify Default Constructor Parameters in Structs

Target Code Construct: Structs with Constructors

Mutation Rule:
1. Identify a struct with a constructor that has default parameters.
2. Modify the default parameter list by removing the default value for one or more parameters.
3. Ensure that the constructor is still syntactically correct but semantically incomplete, such as missing a default value for a parameter.

Example:
Original Code:
```
struct MyStruct {
  constexpr MyStruct(int a = 10, int b = 20) {}
};
```

Mutated Code:
```
struct MyStruct {
  constexpr MyStruct(int a, int b = 20) {}
};
```

Explanation:
This mutation operator targets structs with constructors that have default parameters. By removing the default value for a parameter, the constructor becomes semantically incomplete, which can lead to unexpected behavior or crashes during compilation, especially when the constructor is used in contexts expecting default values. This operator leverages the compiler's handling of default parameters and initialization, which are common areas for bugs.
