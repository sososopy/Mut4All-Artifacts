Mutation Operator: Misplaced Preprocessor Directive Parameters

Target Code Construct: Preprocessor directives, specifically the `#embed` directive.

Mutation Rule:
1. Identify a preprocessor directive in the seed program, such as `#embed`.
2. Within the directive, locate the parameters or arguments that are passed to it.
3. Rearrange the parameters so that a known parameter (e.g., `__FILE__`, `limit`) is placed after an unknown or invalid parameter.
4. Ensure that the unknown parameter is syntactically similar to valid parameters but is not recognized by the compiler.

Example:
Original Code:
```
#embed __FILE__ limit(2)
```

Mutated Code:
```
#embed unknown_param(2) __FILE__ limit(2)
```

Explanation:
This mutation operator targets the handling of preprocessor directives by introducing an unknown parameter before a known one. This can trigger assertion failures or crashes in the compiler if it does not handle such cases gracefully. The mutation is designed to exploit potential weaknesses in the compiler's parameter parsing logic, particularly when dealing with unexpected or misplaced parameters.
