Mutation Operator: Modify Default Template Arguments in Function Templates

Target Construct: Function Templates

Mutation Rule:
1. Identify a function template in the seed program. This is typically defined using the `template` keyword followed by template parameters in angle brackets.
2. Locate a template parameter that has a default argument. This is usually specified in the form `template<typename T = DefaultType>`.
3. Change the default argument of the template parameter to a different type or value that is incompatible with the expected usage within the function. For instance, if the default type is an integer, change it to a pointer type or a user-defined type that is not directly convertible.
4. Ensure that the function template is instantiated without explicitly specifying the template argument, so the default argument is used.

Example:
Original Code:
```cpp
template<typename T = int>
void foo(T value) {
    // Function implementation
}

int main() {
    foo(10); // Uses default template argument 'int'
}
```

Mutated Code:
```cpp
template<typename T = double*>
void foo(T value) {
    // Function implementation
}

int main() {
    foo(10); // Uses default template argument 'double*', which may cause issues
}
```

This mutation operator targets the default template argument mechanism in function templates, which can lead to unexpected behavior or crashes if the default argument is incompatible with the function's implementation or usage.
