Mutation Operator: Modify Variable Linkage

Target Code Construct: Function with variable declarations

Mutation Rule:
1. Identify a function that contains a variable declaration within its scope.
2. Within the function, declare an external variable with the same name as the local variable but with a different linkage specification.
3. Ensure that the external variable declaration is placed after the local variable declaration within the function.

Example:
Original Code:
```
void exampleFunction() {
  int localVar = 10;
  // Other code
}
```

Mutated Code:
```
void exampleFunction() {
  int localVar = 10;
  extern int localVar; // Introduce an external variable with the same name
  // Other code
}
```

This mutation operator targets the linkage of variables within a function scope, which can lead to inconsistencies and potential compiler crashes when the same variable name is used with different linkage specifications.
