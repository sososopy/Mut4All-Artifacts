Mutation Operator: Modify Structured Bindings with Non-Class Types

Target Code Construct: Structured bindings in function templates

Mutation Rule:
1. Identify a structured binding declaration in a function template that attempts to decompose a variable.
2. Ensure the variable being decomposed is of a non-class, non-array type, such as a primitive type (e.g., `int`, `char`).
3. Replace the structured binding declaration with a direct assignment to a single variable, bypassing decomposition.

Example:
Original Code:
```cpp
template <typename T>
void exampleFunction(T t) {
    const auto& [a, b] = t; // Structured binding
}
```

Mutated Code:
```cpp
template <typename T>
void exampleFunction(T t) {
    const auto& a = t; // Direct assignment without decomposition
}
```

Explanation:
This mutation operator targets structured bindings in function templates, specifically when the variable being decomposed is of a non-class, non-array type. By replacing the structured binding with a direct assignment, we can trigger scenarios where the compiler's handling of structured bindings is tested, potentially exposing bugs related to type checking and template instantiation. This operator is applicable to any function template using structured bindings, providing broad coverage across different codebases.
