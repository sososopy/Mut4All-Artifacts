Mutation Operator: Atomic Type Comparison Mutation

Target Code Construct: Comparison operations involving atomic types

Mutation Rule:
1. Identify a comparison operation in the seed program where one operand is an atomic type and the other is a non-atomic type.
2. Modify the comparison operation to ensure both operands are of the same type. This can be done by either:
   a. Casting the non-atomic operand to the atomic type's underlying type.
   b. Casting the atomic operand to the non-atomic operand's type.
3. Ensure that the cast is explicitly defined in the code to avoid implicit type conversion issues.

Example:
Original Code:
```
std::atomic<unsigned int> atomicVar;
int regularVar;
if (atomicVar == regularVar) {
    // Some code
}
```

Mutated Code:
```
std::atomic<unsigned int> atomicVar;
int regularVar;
if (static_cast<unsigned int>(atomicVar) == regularVar) {
    // Some code
}
```

Explanation:
In this mutation, we explicitly cast the atomic variable to its underlying type before performing the comparison. This ensures type compatibility and can help identify potential issues in the compiler's handling of atomic types during comparison operations.
