Mutation Operator: Modify Template Specialization

Target Code Construct: Class Template Partial Specialization

Mutation Rule:
1. Identify a class template in the seed program. This is typically defined using the `template` keyword followed by template parameters in angle brackets.
2. Locate a partial specialization of this class template. Partial specializations are defined by specifying some, but not all, of the template parameters with specific types or values.
3. Modify the partial specialization by introducing a conflicting or redundant specialization. This can be done by:
   a. Creating another partial specialization with the same set of template parameters and constraints.
   b. Altering the existing partial specialization to have overlapping constraints with another specialization.
4. Ensure that the modified specialization is syntactically correct but semantically ambiguous or conflicting.

Example:
Original Code:
```cpp
template<typename T, typename U>
class MyClass {};

template<typename T>
class MyClass<T, int> {}; // Partial specialization

```

Mutated Code:
```cpp
template<typename T, typename U>
class MyClass {};

template<typename T>
class MyClass<T, int> {}; // Original partial specialization

template<typename T>
class MyClass<T, int> {}; // Conflicting partial specialization
```

In this mutation, the introduction of a conflicting partial specialization is intended to trigger the compiler's handling of template specialization ambiguities, potentially leading to a crash or assertion failure.
