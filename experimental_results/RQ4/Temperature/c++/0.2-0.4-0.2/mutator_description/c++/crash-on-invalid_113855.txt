Mutation Operator: Union Designated Initializer Mutation

Target Code Construct: Union initialization with designated initializers

Mutation Rule:
1. Identify a union declaration in the seed program. Ensure the union contains at least two members of different types.
2. Locate an instance where the union is being initialized using designated initializers.
3. Modify the initialization to include multiple designated initializers for different members of the union, which is typically invalid for unions as they can only have one active member at a time.
4. Ensure the designated initializers are syntactically correct but semantically invalid for union initialization.

Example:
Original Code:
```
union MyUnion {
    int a;
    double b;
};

void exampleFunction() {
    MyUnion u = {.a = 10};
}
```

Mutated Code:
```
union MyUnion {
    int a;
    double b;
};

void exampleFunction() {
    MyUnion u = {.a = 10, .b = 20.5}; // Mutated to include multiple initializers
}
```

This mutation operator targets the initialization of unions with designated initializers, which is a common source of errors in C++ compilers due to the constraints on union initialization. The mutation introduces multiple initializers, which should trigger a crash or assertion in compilers that do not handle this case correctly.
