Mutation Operator: Modify Default Arguments in Friend Functions

Target Code Construct: Friend Function Declarations within Template Structs

Mutation Rule:
1. Identify a friend function declaration within a template struct. The friend function should have a parameter with a default argument.
2. Remove the default argument from the friend function's parameter list.
3. Ensure that the friend function is called elsewhere in the code without providing the argument that previously had a default value.

Example:
Original Code:
```
template<typename T = int>
struct Example {
  friend void func(Example, int = 0);
};

void test() {
  func(Example<>{});
}
```

Mutated Code:
```
template<typename T = int>
struct Example {
  friend void func(Example, int);
};

void test() {
  func(Example<>{}); // Call without providing the second argument
}
```

Explanation:
This mutation operator targets friend function declarations within template structs, specifically focusing on parameters with default arguments. By removing the default argument, the mutation creates a scenario where the function call may lack necessary arguments, potentially leading to a compiler crash or error. This operator is designed to exploit the handling of default arguments in template contexts, which is a common source of bugs in C++ compilers.
