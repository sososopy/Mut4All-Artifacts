Mutation Operator: Modify Template Argument List in Alias Template

Target Code Construct: Alias Template Declaration

Mutation Rule:
1. Identify an alias template declaration in the seed program. This is typically in the form of `template <typename T> using AliasName = SomeType<T>;`.
2. Modify the template argument list of the alias template to include a pack expansion. This involves adding an ellipsis (`...`) to one of the template arguments.
3. Ensure that the modified alias template still references existing types or templates within the seed program.

Example:
Original Code:
```cpp
template <typename T>
using MyAlias = std::variant<int, double, T>;
```

Mutated Code:
```cpp
template <typename T>
using MyAlias = std::variant<int, double, T...>;
```

Explanation:
In this mutation, the template argument `T` is modified to `T...`, introducing a pack expansion. This change can potentially trigger issues in the compiler's handling of template argument packs, especially if the surrounding code does not expect a pack expansion in this context. The mutation leverages existing types and templates, ensuring it is applicable to a wide range of seed programs.
