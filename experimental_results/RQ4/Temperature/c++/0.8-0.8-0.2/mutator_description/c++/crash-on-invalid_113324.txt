Mutation Operator

Target: Function Declaration with Default Arguments

Description: This mutation operator targets function declarations with default arguments. Specifically, it manipulates the default arguments to create scenarios that are difficult for the compiler to handle correctly. It applies to functions that have parameters with default values.

Mutation Rule:
1. Identify a function with at least one parameter that has a default argument.
2. Replace the default argument with a template parameter that has a non-type default argument.
3. Ensure the function is used in a context where template instantiation is required, such as within a templated struct or class.

Example:
Original Code:
```
void exampleFunction(int x = 42);
```

Step-by-step Mutation:
1. Modify the function declaration to include a template parameter.
```
template<typename T = int>
void exampleFunction(int x = T());
```
2. Utilize the function within a templated structure to force template instantiation.
```
template<typename U = int>
struct TemplateStruct {
    friend void exampleFunction(int x = U());
};

// Usage
void testFunction() {
    TemplateStruct<> instance;
    exampleFunction();
}
```

This mutation creates a more complex instantiation scenario by involving template parameters, potentially exposing issues within the compiler's handling of default arguments during template instantiation.
