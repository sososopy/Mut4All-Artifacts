Mutation Operator:

Target Code Construct: Function Calls

Mutation Rule: Modify function call arguments to introduce type mismatches.

Step-by-Step Instructions:
- Identify a function call within the seed program that uses a standard library function or a user-defined function that accepts arguments. 
- Modify the arguments of the function call to create a type mismatch. Specifically, use a type that is incompatible with the expected parameter type of the function.
- Ensure that the modified argument list still corresponds to the number of parameters expected by the function, but with at least one argument having an incorrect type.

Example Pseudo-code:
Consider a function `void g(int, double)` in your seed program. There is a function call like `g(42, 3.14);`.

Mutation:
Change the function call to `g("string", 3.14);` to introduce a type mismatch with the first argument.

Note:
- Use existing variables or literals in the seed program for the argument modification.
- If using literals, ensure they are of a type that will clearly cause a mismatch with the expected parameter type.
- Aim to modify arguments in a manner that triggers type-checking mechanisms in the compiler, which are known to sometimes cause crashes with invalid code.
