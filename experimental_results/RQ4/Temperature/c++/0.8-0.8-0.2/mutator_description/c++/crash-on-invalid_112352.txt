Mutation Operator: Template Parameter Pack Misuse

Target: Function Template Declarations and Definitions

Mutation Rule:
1. Identify a function template that uses parameter packs within its template parameters.
2. Introduce a new function template specialization or instantiation that intentionally omits the expansion of one or more template parameter packs. 
3. Ensure that the transformation leaves certain parameter pack expressions unexpanded, which can lead to potential assertion failures in compilers.

Example:
Original:
```cpp
template<typename... Args>
void process(Args... args) {
    // Some operations on args
}

int main() {
    process(1, 2, 3);
}
```

Mutated:
```cpp
template<typename... Args>
void process(Args... args) {
    // Some operations on args
}

int main() {
    process<int>(); // Intentionally omitting parameter pack expansion
}
```

Explanation: 
This mutation involves creating a situation where the compiler is expected to handle parameter packs, but the packs are not properly expanded in some instantiations. This misuses the template parameter pack by omitting its necessary expansions, potentially triggering errors in template instantiation phases. This approach emphasizes the manipulation of template parameter packs in function templates to expose vulnerabilities in compiler handling of variadic templates.
