Mutation Operator: Union Designated Initializer with Multiple Fields

Target Code Construct: This mutation operator targets union type initializations, specifically when using designated initializers.

Mutation Rule:

1. Identify a union declaration within the seed program. Ensure the union has at least two fields of different types, e.g., a struct and a primitive type.
   
   Example:
   ```
   union ExampleUnion {
       int a;
       double b;
   };
   ```

2. Locate a place in the code where the union is being initialized. If there is no such initialization, introduce one.

3. Modify or create the initialization to use designated initializers for multiple fields within the union. Each field should be provided with a designated initializer, which typically would not be valid as a union can only have one active member.

   Example Mutation:
   Original:
   ```
   ExampleUnion e = { .a = 10 };
   ```
   
   Mutated:
   ```
   ExampleUnion e = { .a = 10, .b = 20.5 };
   ```

4. If no union member initialization is present, add a new function or modify an existing one to include the union initialization with multiple designated initializers.

5. Ensure that these changes adhere to the syntactic rules of the language, while purposefully introducing logical errors that might cause the compiler to crash or behave unexpectedly due to handling of invalid union initialization.

This mutation operator is designed to trigger potential issues within the compiler’s handling of unions with designated initializers, as seen in the provided bug report, by creating situations where multiple initializers are specified for a union, which is typically not allowed.
