Mutation Operator: Default Parameter Removal in Constructors

Target: This mutation operator targets class constructors that utilize default parameters.

Mutation Rule: 
1. Identify a constructor in the seed program that has one or more parameters with default values. 
2. Remove the default value from one of the parameters, ensuring that the parameter list remains syntactically correct (i.e., the parameter is declared, but no default value is provided).
3. Ensure that the constructor can still be called without specifying this parameter, potentially triggering default behavior issues.

Example:
Before Mutation:
```cpp
struct MyStruct {
    MyStruct(int x = 10, double y = 5.0) {}
};
```

After Mutation:
```cpp
struct MyStruct {
    MyStruct(int x, double y = 5.0) {}
};
```

Explanation: The mutation involves removing the default value for one of the constructor parameters. This change may lead to issues in parts of the program expecting the original default behavior, potentially exposing bugs related to default parameter handling within the compiler.
