Mutation Operator: Atomic vs. Non-Atomic Type Comparison

Target Code Construct:
This operator targets function bodies containing comparisons between atomic and non-atomic types.

Mutation Rule:
1. Identify a function within the seed program that includes a comparison operation, such as '==', '!=', '<', '>', '<=', or '>='.
2. Locate a variable of a non-atomic integral type (e.g., `int`) used in a comparison within the function.
3. Introduce a new variable with an atomic integral type (`std::atomic<int>` or `std::atomic<unsigned int>`).
4. Replace the non-atomic variable in the comparison with the atomic variable, ensuring that the variable names used are consistent with those already declared or introduce them following these precise steps:
   - If an atomic variable is not present, insert a declaration before the comparison operation as follows:
     ```cpp
     std::atomic<int> atomicVar = nonAtomicVar;
     ```
   - If a comparison involves a specific non-atomic variable, substitute it within the comparison using the atomic variable:
     ```cpp
     if (atomicVar > otherVar) { /* code */ }
     ```
5. Ensure that the rest of the function and program remains unaltered to avoid undeclared variables or types.

Example Pseudo-code:
Before Mutation:
```cpp
void checkComparison(int nonAtomicVar, int otherVar) {
    if (nonAtomicVar > otherVar) {
        // some code
    }
}
```

After Mutation:
```cpp
void checkComparison(int nonAtomicVar, int otherVar) {
    std::atomic<int> atomicVar = nonAtomicVar;
    if (atomicVar > otherVar) {
        // some code
    }
}
```

This mutation operator is designed to explore how comparisons between atomic and non-atomic types are handled, potentially leading to assertion failures or crashes in the compiler if not properly managed.
