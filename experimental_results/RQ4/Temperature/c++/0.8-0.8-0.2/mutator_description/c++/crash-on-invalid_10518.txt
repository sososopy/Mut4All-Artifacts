Mutation Operator: Template Parameter Removal in Function Template

Target Code Construct: Function Template

Mutation Rule:
1. Identify a function template declaration in the seed program. A function template typically starts with the keyword `template` followed by template parameters enclosed in angle brackets, e.g., `template<typename T>`.
2. Within the angle brackets, locate any template parameter, e.g., `typename T`.
3. Remove the identified template parameter from the list entirely while leaving the angle brackets intact. If multiple parameters exist, ensure that the syntax remains valid by correctly handling separators (commas).
4. Ensure that the function signature remains unchanged otherwise. If the removed template parameter is used in the function definition, replace its usage with a concrete type or an existing type from the program, ensuring the program remains syntactically valid.

Example:
Original Code:
```
template<typename T>
void foo(T value) {
    // function body
}
```

Mutated Code:
```
template<>
void foo(int value) {
    // function body
}
```
