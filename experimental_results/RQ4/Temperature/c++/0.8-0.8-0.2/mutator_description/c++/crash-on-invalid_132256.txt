Mutation Operator: Alter Default Template Arguments

Target: Function Template Declaration

Mutation Rule:
1. Identify a function template in the seed C++ program. Ensure it has at least one template parameter.
2. Add a default template argument to the template parameter that currently lacks one.
3. The default argument should be an expression or value that is inconsistent or logically incorrect given the context of the function template.

Example:
Original Code:
```cpp
template<typename T>
void exampleFunction(T param) {
    // Function implementation
}
```

Mutated Code:
```cpp
template<typename T = int>
void exampleFunction(T param) {
    // Function implementation
}
```

Notes:
- The addition of a default template argument can lead to unexpected behavior or crashes due to type mismatches or incorrect assumptions made in the function implementation.
- The mutation operator should ensure that the added default value is valid C++ but contextually incorrect or conflicting with the function's logic.
- This operator can potentially trigger bugs related to template instantiation and type deduction.
