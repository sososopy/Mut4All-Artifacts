Mutation Operator: Modify Class Destructor to Default Constexpr

Target Code Construct: This mutation targets class definitions in C++.

Mutation Rule:
1. Identify a class definition within the seed program. Focus on a destructor within the class.
2. If the class has a user-defined destructor, replace it with a default destructor and mark it as `constexpr`.
3. If the destructor is already defaulted and not marked as `constexpr`, add the `constexpr` keyword.
4. If the class does not define a destructor, explicitly declare a defaulted destructor and mark it as `constexpr`.

Example:
Before Mutation:
```cpp
class Example {
public:
    ~Example() {
        // Destructor logic
    }
};
```

After Mutation:
```cpp
class Example {
public:
    constexpr ~Example() = default;
};
```

This mutation is designed to expose issues in C++ compilers related to evaluation of defaulted destructors as `constexpr`. By modifying destructors in this way, it can potentially trigger bugs related to the evaluation of compiler-provided destructors, especially in conjunction with complex class hierarchies or templates.
