Mutation Operator: Struct Template Specialization

Target: This mutation operator targets template struct declarations and aims to introduce invalid specializations that can lead to compiler crashes.

Mutation Rule:
1. Identify a template struct declaration in the seed program. This can typically be found by looking for "template<typename T> struct StructName".

2. Create a partial specialization for the identified struct. Introduce a special template argument or condition that does not exist or is not valid according to C++ rules. For example, use an undeclared type or an unsupported specialization condition.

3. Insert the invalid partial specialization immediately after the original template struct declaration.

Example:
Original:
template<typename T>
struct MyStruct {
    T data;
};

Mutated:
template<>
struct MyStruct<UndefinedType> {
    int data;
};

Explanation:
- The mutation introduces a specialization of the template struct `MyStruct` that uses an undeclared type `UndefinedType`. This is intended to disrupt the normal template resolution process, thereby increasing the likelihood of triggering a compiler crash due to invalid template specialization rules.
