Mutation Operator: Modify Pointer Dereference

Target Code Construct:
This mutation operator targets expressions involving pointer dereferencing in the code.

Mutation Rule:
1. Identify any expression in the seed program where a pointer is being dereferenced, i.e., expressions using the '*' operator on a pointer variable.
2. Modify the expression to dereference a null pointer or an integer cast to a pointer type. This can introduce invalid pointer dereferencing, which is known to trigger compiler bugs.

Example Step-by-Step Mutation:
- Locate a statement in the seed code such as: `int value = *ptr;` where `ptr` is a pointer variable.
- Change the statement to: `int value = *(int*)0;` This effectively dereferences a null pointer, simulating the dereference of an invalid memory location.

This operator exploits incorrect handling of pointer dereferencing by the compiler, which can lead to crashes or undefined behavior during compilation. It's universal as it targets any code with pointer operations, and not limited to specific data types or structures. The mutation is straightforward to apply and can widely cover various scenarios leading to potential compiler crashes.
