Mutation Operator: Template Deduction Guide with Scope Change

Target Code Construct: Template deduction guides in namespace scopes

Mutation Rule:
1. Identify a template declaration within a namespace. For example:
   namespace N {
     template <typename T> struct MyStruct;
   }

2. Inside the same namespace, declare a deduction guide that refers to the template but deliberately omit the namespace qualifier. For instance, write:
   template <typename U> MyStruct() -> MyStruct<U>;

3. Modify the deduction guide to include the correct namespace qualifier explicitly, as follows:
   template <typename U> N::MyStruct() -> N::MyStruct<U>;

4. Test the compiler's handling of the deduction guide with and without the namespace specifier, ensuring to induce a scenario where the compiler might crash due to mismanaged scope resolution.

Example:
- Original Seed Code:
  ```
  namespace ExampleNamespace {
    template <typename T> struct ExampleStruct;
  }
  template <typename V> ExampleStruct() -> ExampleStruct<V>;
  ```

- Mutated Code:
  ```
  namespace ExampleNamespace {
    template <typename T> struct ExampleStruct;
  }
  template <typename V> ExampleNamespace::ExampleStruct() -> ExampleNamespace::ExampleStruct<V>;
  ```

Rationale: This mutation operator targets a known weak point in compiler implementations, where deduction guides are erroneously processed outside the scope of the associated template. By modifying the deduction guide to correctly or incorrectly reference the namespace, we can test the compiler's robustness in handling scope-qualified template deduction guides.
