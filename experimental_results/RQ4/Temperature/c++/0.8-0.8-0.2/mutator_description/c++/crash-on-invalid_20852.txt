Mutation Operator: Erroneous Template Instantiation

Target Construct: Template Usage in Return Type Declaration

Mutation Rule:
1. Identify a function declaration within a struct or class where the return type is a template specialization.
2. Alter the template argument to introduce an ill-formed construct. Specifically, use a non-existent member within a template specialization.
3. Ensure the structure of the code follows this pattern for mutation:

Original Code Example:
```
template<typename T>
struct Container {};

struct Example {
  static Container<ValidType>::type test();
};
```

Mutation Steps:
1. Replace `ValidType` with a reference to a non-existent member within a template, such as `NonExistentMember<int>::type`.
2. Ensure the mutation still maintains a valid C++ syntax structure, even though it refers to a non-existent member.

Mutated Code Example:
```
template<typename T>
struct Container {};

struct Example {
  static Container<NonExistentMember<int>::type> test();
};
```

Note: This mutation targets the template argument within the function return type to cause inconsistencies that are more likely to trigger compiler crashes.
