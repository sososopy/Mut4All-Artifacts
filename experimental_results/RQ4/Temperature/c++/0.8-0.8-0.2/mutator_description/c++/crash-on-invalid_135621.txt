Mutation Operator

Target Code Construct: Function Template Invocation within a Function

Mutation Rule:
1. Identify a function template or a function containing a template parameter in the seed program.
2. Within the function body, locate a template specialization or a member function invocation using a type-dependent expression.
3. Remove the 'template' keyword from the expression if it explicitly uses it to denote a dependent template name.
4. Ensure the resulting expression appears within a context where the dependent template name usage could lead to ambiguity or incorrect resolution.

Example Mutation:
Original Code:
```cpp
template <typename T> struct Example {
  template <typename T1>
  Example(T1) {}
};

template <typename T2>
auto function() {
  &Example<T2>::Example<int>;
}

int main() {
  function<int>();
}
```

Mutated Code:
1. Remove 'template' keyword from the expression `&Example<T2>::template Example<int>`.
2. Resulting in `&Example<T2>::Example<int>`.
