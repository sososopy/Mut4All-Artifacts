Mutation Operator: Modify Explicit Template Argument

Target: Function calls with explicit template arguments.

Mutation Rule:
1. Identify function calls that utilize explicit template arguments. These are typically visible as function calls with angle brackets specifying template parameters, such as `functionName<TemplateParam>()`.
2. Change the explicit template arguments in such a way that they become incompatible with the function's expected template parameters. This might involve substituting the expected type with a completely different type that is unlikely to be compatible.
3. Ensure the mutation maintains syntactic correctness to reach the semantic analysis phase, where the incompatibility is likely to cause a crash.

Example:
Original code:
```
template<typename T>
void process(T value) {
    // Some processing logic
}

int main() {
    process<int>(42);
}
```

Mutated code:
```
template<typename T>
void process(T value) {
    // Some processing logic
}

int main() {
    process<double>(42);  // Changing explicit template argument from int to double
}
```

Rationale:
By providing an incorrect template argument, the mutation operator specifically targets the compiler's type-checking mechanisms, potentially triggering a crash if there are weaknesses in handling unexpected template instantiations. This type of mutation is applicable to any template function in a C++ program, ensuring high coverage and universality.
