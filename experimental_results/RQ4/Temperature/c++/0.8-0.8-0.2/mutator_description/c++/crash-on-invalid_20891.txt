Mutation Operator: Modify Return Type in Template Function

Target Construct: Function Templates

Mutation Rule:
1. Identify a function template with an unknown or deduced return type in the seed program. The function should be defined with a template parameter but not fully defined in terms of its return type.
2. Change the return type of the function template to a type that includes decltype(auto). For instance, if the function was originally defined as `auto f(int);`, modify it to `decltype(auto) f(int);`.
3. Ensure that the function template is invoked or assigned to a variable in the main function. Modify the assignment to use decltype(auto) with an indirection or function pointer.
4. After making these changes, ensure that the program is still syntactically valid, even if the semantic meaning is undefined or ambiguous. The program should compile successfully to trigger the bug.

Example of Pseudo-Code Transformation:
Original:
```cpp
template <typename T>
auto myFunction(int);

int main() {
    auto variable = &myFunction<int>;
}
```

Mutated:
```cpp
template <typename T>
decltype(auto) myFunction(int);

int main() {
    decltype(auto) variable = &myFunction<int>;
}
```
