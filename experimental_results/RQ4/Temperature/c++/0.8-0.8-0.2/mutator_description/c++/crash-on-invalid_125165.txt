Mutation Operator: Invalid Structured Binding with Non-Class Type

Target Code Construct:
This mutation operator targets structured bindings in function templates, specifically when decomposing non-class, non-array types.

Mutation Rule:
1. Identify a function template that accepts a parameter of any type.
2. Locate a structured binding declaration within the function template.
3. Replace the structured binding declaration with an equivalent that attempts to decompose a non-class, non-array type (e.g., a fundamental type such as `int` or `char`).

Step-by-Step Instructions:
- Identify a function template with a parameter. For example: `template <typename T> void func(T t)`.
- Inside the function, identify the structured binding declaration, e.g., `const auto& [...pack] = t;`.
- Replace this declaration to bind a non-class, non-array type, such as:
  ```
  int nonClassType = 42;
  const auto& [a, b] = nonClassType;
  ```
- Ensure that the replacement is contextually similar to the original declaration location.

Example:
Original Seed Program:
```
template <typename T>
void process(T t) {
    const auto& [...pack] = t;
    (pack, ...);
}
```

Mutated Program:
```
template <typename T>
void process(T t) {
    int nonClassType = 10;
    const auto& [a, b] = nonClassType; // invalid structured binding
}
```
