Mutation Operator: Template Argument Type Mismatch

Target Code Construct: Class Template Specialization

Mutation Rule:
1. Identify a class template in the seed program, for example:
   ```cpp
   template <typename T>
   class MyClass {
       T member;
   };
   ```

2. Locate an instantiation of this class template with a specific type, such as:
   ```cpp
   MyClass<int> obj;
   ```

3. Modify the instantiation to use a template argument whose type is intentionally mismatched with the expected member function or variable type in the template. This can be done by changing the template parameter to a non-matching type, such as:
   ```cpp
   MyClass<void> obj;  // Change int to void which is non-instantiable
   ```

4. If the template contains function calls or operations that require a specific type, ensure they remain the same. For instance:
   ```cpp
   template <typename T>
   class MyClass {
       T member;
       void foo() {
           member + 5;  // This operation requires 'member' to be of a numeric type
       }
   };
   ```

5. Validate that the mismatch occurs in a way that the operation is incompatible with the new template parameter, such as:
   ```cpp
   MyClass<void> obj;  // This will cause issues during instantiation because 'void + 5' is invalid
   ```

Explanation:
This mutation operator intentionally causes a type mismatch during the template instantiation process by using a type that is incompatible with operations or member functions expected within the template. By doing so, it forces the compiler to handle invalid type operations, potentially leading to a crash if not managed correctly. This method targets the template argument deduction and instantiation logic where bugs are more frequently exposed.
