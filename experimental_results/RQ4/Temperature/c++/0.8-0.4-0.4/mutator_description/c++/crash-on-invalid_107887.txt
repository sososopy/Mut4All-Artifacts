Mutation Operator:
Target: Template Deduction Guide
Description: This mutation operator targets template deduction guides, specifically focusing on their scope relative to the associated template declaration. It aims to introduce a scope mismatch by altering the namespace in which the deduction guide is declared.

Step-by-Step Mutation Rule:
1. Identify a template declaration within a specific namespace. For example:
   ```
   namespace X {
       template <typename T>
       struct Example;
   }
   ```
2. Locate the corresponding deduction guide in the code. If it exists inside a different namespace or in the global scope, keep it there; otherwise, relocate it:
   ```
   template <typename T> Example() -> Example<T>;
   ```
3. Modify the deduction guide to appear in a different namespace than where the original template was declared:
   - If the original template is declared within a namespace (e.g., namespace X), move the deduction guide to the global scope or another namespace (e.g., namespace Y):
     ```
     namespace Y {
         template <typename T> Example() -> Example<T>; // Assuming Y is different from X
     }
     ```
4. Ensure the deduction guide refers to the correct qualified name for the template:
   - If the deduction guide is moved outside the original namespace, use a qualified name for the template:
     ```
     namespace Y {
         template <typename T> X::Example() -> X::Example<T>; 
     }
     ```

By applying this mutation, you create a scenario that can potentially trigger compiler issues regarding scope and name resolution for template deduction guides.
