Mutation Operator: Modify Structured Bindings with Non-Class Types

Target Code Construct: Structured Bindings in function templates

Mutation Rule:
1. Locate a structured binding declaration within a function template that attempts to decompose an argument.
2. Modify the declaration to use a non-class, non-array type that does not support structured binding. Typical candidates include primitive types like `int`, `char`, or `bool`.
3. Ensure the function template argument is instantiated with a literal or variable of the chosen non-class type to simulate the error condition.

Example:
Original Code:
```
template <typename T>
void example(T t) {
    const auto& [x, y] = t; // Structured binding expecting a class or tuple-like type
}
```

Mutation:
```
template <typename T>
void example(T t) {
    const auto& [x, y] = static_cast<int>(t); // Force the use of an 'int' which cannot be decomposed
}
``` 

In this mutation, structured bindings are intentionally misused with primitive types to trigger potential compiler crashes. This approach leverages the compiler's expectation of decomposable types in structured bindings, exposing bugs in handling invalid decompositions.
