
Mutation Operator: Default Template Argument in Function Template

Target: Function Templates

Mutation Rule:
1. Locate a function template definition in the seed program. This is typically identified by the `template` keyword followed by angle brackets enclosing template parameters.
2. If the function template does not already have a default template argument, add a default template argument to one of the template parameters. For example, if you have a template parameter `<typename T>`, modify it to `<typename T = int>`.
3. Ensure that the modified template parameter with a default argument is used within the function body to ensure its relevance to the function's operation.

Step-by-step Example:
Original Code:
```cpp
template <typename T>
void foo(T t) {
    // Function body using t
}
```

Mutated Code:
```cpp
template <typename T = int>
void foo(T t) {
    // Function body using t
}

// Example call that will use the default argument
foo(42);
```

By introducing a default template argument, the modification leverages template parameter deduction, potentially exposing issues in the compiler's handling of default arguments in templates. This can lead to a crash if the compiler struggles with parsing or deducing such constructs, especially in complex scenarios involving template specialization or overload resolution.
