Mutation Operator: Bitfield Size Overflow in Structs

Target Construct: This mutation operator targets bitfields within struct declarations in a C++ program.

Mutation Rule: The mutation focuses on altering the size of bitfields to exceed conventional limits, thereby potentially triggering assertion failures or crashes in the compiler.

Step-by-Step Instructions:
1. Identify a struct declaration within the seed program that contains a bitfield. If no bitfield is present, select a struct and introduce a new bitfield.
2. If modifying an existing bitfield:
   a. For a bitfield declared as `int : n`, replace `n` with an expression that evaluates to a number larger than 64. For example, `int : 1 + (unsigned long long)0xffffffffffffffff`.
3. If introducing a new bitfield:
   a. Choose a type for the bitfield, such as `int` or `unsigned int`.
   b. Declare a new anonymous bitfield within the struct using an expression that evaluates to a size larger than 64. Example: `int : 1 + (unsigned long long)0xffffffffffffffff`.
4. Ensure that the struct remains syntactically correct apart from the bitfield size, maintaining valid C++ syntax.

Example:
Original:
```cpp
struct Example {
    unsigned int field1 : 15;
};
```

Mutated:
```cpp
struct Example {
    unsigned int field1 : 1 + (unsigned long long)0xffffffffffffffff;
};
```

This mutation operator is designed to explore the compiler's handling of large bitfield sizes, specifically focusing on whether the compiler properly checks the limits of bitfield widths and handles them without crashing.
