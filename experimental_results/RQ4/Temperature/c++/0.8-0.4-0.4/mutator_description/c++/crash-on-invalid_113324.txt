Mutation Operator: Modify Friend Function Default Parameter

Target Code Construct: Friend function declarations within a template struct.

Mutation Rule:
1. Identify a friend function declaration within a template struct in the seed program.
2. If the friend function has any parameters with default arguments, remove the default arguments from these parameters.
3. Ensure that the function is called without arguments for the default parameters, simulating a call relying on default values.

Example:
Original Structure:
```cpp
template<typename T = int>
struct Example {
  friend void func(Example, int = 0);
};

void test() {
  Example<> obj;
  func(obj); // Calls func with default parameter 0
}
```

Mutated Structure:
```cpp
template<typename T = int>
struct Example {
  friend void func(Example, int); // Remove default argument
};

void test() {
  Example<> obj;
  func(obj); // Causes ambiguity or error due to missing argument
}
```

Note: This mutation targets structures where friend functions are used with default parameters, and the aim is to cause ambiguity or error in function calls that previously relied on default arguments.
