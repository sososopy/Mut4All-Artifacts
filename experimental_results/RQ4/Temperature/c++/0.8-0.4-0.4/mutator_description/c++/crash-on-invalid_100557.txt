Mutation Operator  
Target: Function template instantiation with incorrect types  
Mutation Rule:  
1. Identify any function calls in the seed program that use template functions or functions with template parameters.  
2. Replace one or more of the template arguments with a type that is incompatible with the expected type for one or more of the function parameters.  
3. Ensure the substituted type is unrelated to the expected type to increase the likelihood of triggering a type mismatch.  
4. For example, if a function template is invoked with `make_tuple<int, T>(...)`, replace `T` with a type such as `std::string` if an integral type is expected.  
5. Verify the function call still compiles by ensuring all required headers and declarations are present, and only the template arguments are changed.  

Example Pseudo-Code:  
Original:  
```cpp  
auto t = std::make_tuple<int, double>(1, 2.0);  
```  
Mutated:  
```cpp  
auto t = std::make_tuple<int, std::string>(1, "test");  
```  
This mutation operator should aim to substitute existing template function calls in a way that results in incompatible type arguments, thus potentially triggering compile-time errors or unintended behavior, increasing the diversity and coverage of testing scenarios.
