Mutation Operator: Function Template Return Type Inference

Target Construct: Function Template with Auto Return Type

Mutation Rule:
1. Identify a function template that has an `auto` return type.
2. Change the function template's return type from `auto` to `decltype(auto)`.
3. Ensure the template has a function prototype with an unspecified or inferred return type that depends on its template parameter.
4. Ensure the mutation applies to a function template used within a `decltype(auto)` variable declaration.

Example:
Original Code:
```cpp
template <typename T>
auto func(int);

int main() {
    auto ptr = &func<int>;
    return 0;
}
```

Mutated Code:
```cpp
template <typename T>
decltype(auto) func(int);

int main() {
    decltype(auto) ptr = &func<int>;
    return 0;
}
```

Explanation:
- Step 1: Locate a function template with `auto` as its return type.
- Step 2: Modify the return type of the template to `decltype(auto)`.
- Step 3: Ensure that the function template is used in a context where its return type is inferred, such as in a `decltype(auto)` variable assignment.
- This mutation targets the function template's return type and its usage, increasing the likelihood of triggering issues related to return type deduction in the compiler.
