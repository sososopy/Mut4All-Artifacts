Mutation Operator: Modify Template Instantiation Involving Unions

Target Code Construct: Class template instantiation within a union.

Mutation Rule:
1. Identify a class template instantiation within a union. This involves locating a union declaration that includes a member which is an instance of a class template.
2. Modify the instantiation of the class template by introducing a new member function within the template class that is not trivially destructible.
3. Ensure the new member function in the template class is complex enough so that its destructor requires explicit implementation (e.g., containing a non-static data member that is a type with a non-trivial destructor).

Example in Natural Language Description:
- Assume there is a union containing a member which is an instance of a class template.
- Within this class template, introduce a new private data member of a type that requires non-trivial destruction, such as a pointer to dynamically allocated memory.
- Additionally, provide an explicitly defined destructor for the template class that handles the cleanup of this new data member.

By forcing the template class within the union to have a non-trivial destructor, it increases the complexity and can potentially lead to edge cases that the compiler fails to handle properly, triggering crashes similar to the reported bug.
