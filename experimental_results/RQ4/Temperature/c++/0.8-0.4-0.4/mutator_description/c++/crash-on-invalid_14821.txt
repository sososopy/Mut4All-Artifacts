Mutation Operator: Template Instantiation with Const Qualifier

Target Code Construct: Template function or class instantiation

Mutation Rule:
1. Identify a template class or function where a type is being instantiated.
2. If the type being instantiated is a template parameter (e.g., `T` in `B<T>`), modify the instantiation by adding the `const` qualifier to the type.
3. Ensure that the modified type is passed to a function or used in a way that could affect template instantiation.

Example:
Original Code:
```
template <class T> struct C {};
template <class T> void func(C<T> obj);
void caller() { func(C<int>()); }
```

Mutated Code:
```
template <class T> struct C {};
template <class T> void func(C<const T> obj); // Add const qualifier to T
void caller() { func(C<int>()); } // Unchanged call, but affects instantiation
```

By applying the `const` qualifier to the template instantiation, the mutation explores compiler handling of const correctness in template resolution, which has the potential to trigger similar issues encountered in the provided bug report. The key aspect is maintaining the use of existing template parameters while introducing subtle changes in type qualifiers, which can stress the compiler's type management capabilities.
