Mutation Operator: Modify Nested Type Declarations

Target Construct:
This mutation operator targets nested type declarations within a class or struct.

Mutation Rule:
1. Identify a class or struct containing nested type declarations. For instance, find a class named `Container` that contains another type like `InnerType`.

2. Mutate the nested type by changing its scope or declaration context. Specifically, move the nested type outside the class declaration while maintaining its association with the outer class.

Step-by-Step Instructions:
- Locate a nested type within a class, for example:
  ```cpp
  class Container {
      class InnerType {
          // some members
      };
      // other members
  };
  ```
- Move the nested type declaration out of the class and use a forward declaration inside the class:
  ```cpp
  class Container; // Forward declaration of Container

  class InnerType {
      // some members
  };

  class Container {
      friend class InnerType; // Associate InnerType with Container
      // other members
  };
  ```

Explanation and Example:
- The original code defines `InnerType` within `Container`. By moving `InnerType` outside `Container`, we test the compiler's ability to handle scope and association changes without losing the logical connection between `InnerType` and `Container`.
- This approach can help uncover bugs related to type resolution and scoping rules, especially in compilers with intricate handling of nested and dependent types.
