Mutation Operator: Template Argument Mismatch in Class Template Specialization

Target Code Construct: Class Template and Template Specialization

Mutation Rule:
1. Identify a class template that is already declared in the seed program. This class template should have at least one template type parameter.

2. Locate a specialization of the identified class template. This could be either a full specialization or a partial specialization. Ensure that this specialization is using the template type parameters.

3. Modify the specialization so that one of the template arguments does not match the template parameter's expected type. If the template parameter expects a type, use a non-matching type as the argument. If it expects a non-type, provide an incompatible non-type argument.

4. For instance, if the template parameter is declared as template<typename T>, and an existing specialization uses int as the argument, change this to a non-matching type such as a pointer type (e.g., int*).

Example:

Before Mutation:
```cpp
template<typename T>
class SampleClass {
    // class definition
};

template<>
class SampleClass<int> {
    // specialization for int
};
```

After Mutation:
```cpp
template<typename T>
class SampleClass {
    // class definition
};

// Change the specialization to use an incompatible type
template<>
class SampleClass<int*> {
    // specialization now uses a non-matching type
};
```

This mutation operator is designed to test the compiler's handling of template argument deduction and type checking during the instantiation of class template specializations. It leverages existing structures in the seed program while introducing a type mismatch that can trigger type-related crashes in the compiler's template instantiation logic.
