Mutation Operator: Modify Lambda Expression with Invalid `decltype`

Target Construct: Lambda Expression

Mutation Rule:
1. Identify a lambda expression in the code where a `decltype` is used.
2. Within the lambda expression, find the return type specifier if it is using `decltype`.
3. Modify the `decltype` expression to refer to a non-existent or incorrectly scoped variable.
4. Ensure that the lambda contains a valid body, even if the `decltype` is invalid.

Example:
Original Code:
```
auto lambda = []() -> decltype(existingVar) {
    return existingVar;
};
```

Mutated Code:
```
auto lambda = []() -> decltype(nonExistentVar) {
    return existingVar; // Note: nonExistentVar is not declared
};
```

Explanation:
This mutation operator targets lambda expressions where `decltype` is used to specify the return type. By altering the `decltype` to reference a non-existent variable, it can expose potential compiler bugs related to handling invalid type specifiers in lambda expressions. This mutation is applicable to any lambda expression that utilizes `decltype` for its return type specification.
