Mutation Operator: Modify Lambda Return Type

Target Code Construct: Lambda expressions with a specified return type

Mutation Rule:
1. Locate a lambda function within a template function or a non-template function.
2. Identify the return type specified using `decltype` or any other C++ type specifier.
3. Change the return type to a more complex type or one that involves templates or type traits, such as `decltype(auto)` or `std::enable_if`.
4. Ensure the lambda body doesn't correspond to the new specified return type to confuse the type deduction.

    return x;

In this mutation, the lambda's return type has been modified to potentially create ambiguity and confusion for the compiler when deducing the return types, especially if the lambda's body does not produce a consistent return type. This can lead to crashes or incorrect behavior in the compiler's type inference engine.
