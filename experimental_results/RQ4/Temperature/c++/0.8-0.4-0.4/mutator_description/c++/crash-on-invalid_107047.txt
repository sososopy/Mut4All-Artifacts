Mutation Operator: Template Argument Misplacement in Function Calls

Target: Function calls involving template arguments

Mutation Rule:
1. Identify a function call within a C++ program that uses template arguments, typically seen in calls like `function<template_arg>(args)`.
2. Misplace or incorrectly specify the template argument in such a function call.
3. Specifically, provide an extra template argument or remove a necessary one.
4. Ensure the function being targeted is a part of the existing program and is known to accept template arguments.
5. The mutation should be applied in a context where the misuse of template arguments could confuse the overload resolution process.

Example:
Original code:
```
template<typename T>
void processData(T value) {
    // Function implementation
}

// Function call with correct template usage
processData<int>(42);
```

Mutated code:
```
template<typename T>
void processData(T value) {
    // Function implementation
}

// Function call with misplaced template argument
processData<int, double>(42);  // Incorrect number of template arguments
```

The mutation introduces an incorrect number of template arguments in a function call. This could lead to compiler confusion, especially in overload resolution, potentially triggering a bug or crash.
