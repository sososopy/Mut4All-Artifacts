Mutation Operator: Embed Directive Mutation

Target Code Construct: Preprocessor directives, specifically #embed directives.

Mutation Rule:
1. Identify an `#embed` directive in the source code.
2. Check for parameters following the `#embed` directive. If a known parameter (like `limit` or `offset`) is preceded by an unknown parameter, reorder them.
3. Specifically, place known parameters before any unknown parameters.
4. Example step-by-step mutation:
   a. Original: `#embed __FILE__ unknown_param(2) limit(2)`
   b. Mutated: `#embed __FILE__ limit(2) unknown_param(2)`

This mutation operator focuses on the order of parameters within the `#embed` directive, specifically placing known parameters before unknown ones to explore the handling of parameter sequences by the compiler.
