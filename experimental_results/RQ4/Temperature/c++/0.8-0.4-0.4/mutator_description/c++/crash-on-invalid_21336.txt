Mutation Operator: Faulty Default Argument in Template Function

Target Code Construct: Function within a Template Struct

Mutation Steps:
1. Identify a function definition within a template struct or class that includes a default argument.
2. Modify the default argument to be a function call where the function's parameters include an undeclared or previously defined variable within the same scope.
3. Ensure that the function call within the default argument includes a nested call to another function, further complicating the default argument expression.
4. To trigger the crash, ensure the function with the faulty default argument is called without specifying the parameter, allowing the default to be used.

Example Pseudo-Code:
- Original Code:
  ```
  template<typename T> struct Container {
      void process(int num = calculate(num));
  };
  void execute() { Container<int>().process(); }
  ```
- Mutated Code:
  ```
  template<typename T> struct Container {
      void process(int num = calculate(innerFunc(num)()));
  };
  void execute() { Container<int>().process(); }
  ```

This mutation operator exploits the compiler's handling of default arguments in function templates by introducing complex and potentially undefined behavior through nested function calls and variable dependencies.
