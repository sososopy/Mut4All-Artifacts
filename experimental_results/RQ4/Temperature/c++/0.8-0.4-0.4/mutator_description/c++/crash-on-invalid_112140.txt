Mutation Operator: Modify Default Initializers in Constructors

Target: This operator targets the constructor of a `struct` or `class`.

Mutation Rule:
1. Identify a constructor within a `struct` or `class` that has parameters with default initializers.
2. Remove the default initializer from one or more parameters.
3. Alternatively, replace the default initializer with an incorrectly formed expression to simulate a common error scenario.

Example:
Before Mutation:
```cpp
struct Example {
    Example(int x = 0, double y = 1.0) {}
};
```

After Mutation (Option 1 - Removal):
```cpp
struct Example {
    Example(int x, double y = 1.0) {}
};
```

After Mutation (Option 2 - Incorrect Expression):
```cpp
struct Example {
    Example(int x = , double y = 1.0) {}
};
```

Application: This mutation is applied to constructors of `struct` or `class` that include parameters with default initializers, where removal or erroneous alteration of the initializer can lead to parsing errors or unexpected compiler behavior, making it a promising candidate for triggering compiler bugs.
