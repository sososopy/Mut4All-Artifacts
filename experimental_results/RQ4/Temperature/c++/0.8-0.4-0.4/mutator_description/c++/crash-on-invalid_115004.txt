Mutation Operator: Modify Constraint Expressions in Concepts

Target: C++20 Concepts and Template Parameters

Mutation Rule:
1. Identify a concept definition within the seed program. A concept is a compile-time predicate that is used to specify template constraints.
   Example:
   ```
   template <typename T> concept MyConcept = expr;
   ```
2. Modify the constraint expression of the identified concept to introduce a null or trivially false condition.
   - For boolean expressions, replace with a constant `false`.
   - For non-boolean expressions, replace with an expression that cannot be evaluated properly, such as a division by zero or a condition that references an undeclared variable.

Step-by-Step Instructions:
a. Locate a concept definition:
   ```
   template <typename T> concept MyConcept = expr;
   ```
b. Change the constraint expression to a trivially false or erroneous condition:
   ```
   template <typename T> concept MyConcept = false; // Boolean expression change
   ```
   Or, for a non-boolean expression that would typically require evaluation:
   ```
   template <typename T> concept MyConcept = T::undeclaredMember != 0; // Erroneous condition
   ```
c. Ensure that the rest of the program makes use of this concept in template declarations or specializations to propagate the effect of the erroneous concept.

Example:
Original:
```
template <typename T> concept Check = sizeof(T) > 0;
template <Check T> struct Container {};
```

Mutated:
```
template <typename T> concept Check = 0; // Mutation introduces a trivially false condition
template <Check T> struct Container {}; // Usage propagates the mutation
```

This mutation operation alters the logic in concept definitions and targets the C++20 concept construct, making it highly likely to expose compiler bugs related to constraint normalization and evaluation.
