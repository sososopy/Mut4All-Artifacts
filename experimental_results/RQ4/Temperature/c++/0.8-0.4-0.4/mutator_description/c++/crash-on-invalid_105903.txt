Mutation Operator

Target Code Construct: Template Function Parameter Pack

Mutation Rule: Introduce an empty parameter pack and attempt to access an element from it using pack indexing in a different context.

Step-by-step Instructions:
1. Identify a template function that accepts a parameter pack, for example: `template <typename... Ts>`.
2. Ensure the parameter pack is instantiated with no arguments, making it empty.
3. Attempt to index into this empty parameter pack within a different context, such as a member function or another template function.
4. Use the pack index in a way that it is not suitably guarded by a condition that checks for the pack's non-emptiness.

Example Pseudo-code:
```cpp
template <typename... Args>
struct Container {
    // Ensure the pack is empty
    static void process() {
        anotherFunction<Args...[0]>();  // Attempting to index into an empty pack
    }
};

void caller() {
    Container<>::process();  // Instantiate with an empty pack
}
```

The above mutation attempts to access the first element of an empty parameter pack, which is likely to introduce a condition that may cause the compiler to crash if it does not handle such scenarios gracefully.
