Mutation Operator:

Target Code Construct: Function Parameters and External Declaration

Mutation Rule:
1. Identify a function with a parameter of any type (e.g., `void f(int x)`).
2. Inside the function body, declare an external variable that shadows the function parameter using the same name and type (e.g., `extern int x;`).
3. Ensure that the external declaration directly follows the function signature without any intervening statements.

Example Before Mutation:
```
void compute(double val) {
    // Function body
}
```

Example After Mutation:
```
void compute(double val) {
    extern double val;
    // Function body
}
```

This mutation operator targets the linkage and scoping rules by introducing an external declaration that conflicts with the function's parameter, which may trigger unexpected compiler behaviors or crashes during the compilation process.
