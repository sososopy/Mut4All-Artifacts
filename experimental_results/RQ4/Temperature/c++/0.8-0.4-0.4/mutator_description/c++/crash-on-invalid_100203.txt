Mutation Operator:

Target: Function Template Instantiation

Mutation Rule:
1. Identify a function template in the seed program. For instance, `template <typename... Ts> void foo(Ts&&... args) {}`.
2. Create a function call to this template with explicit template arguments that mismatch the expected types. For example, use `foo<int, int>(...)` when it's intended to accept perfect forwarding arguments.
3. Ensure that the function call uses arguments that will trigger a type mismatch or overload resolution failure. The example could be `foo<int, int>(0, existingVariable);` where `existingVariable` is an lvalue when an rvalue is expected.
4. Compile the program and observe if the compiler crashes or produces incorrect error diagnostics. 

Example Pseudo-code:
```cpp
template <typename T1, typename T2>
void exampleFunction(T1&& param1, T2&& param2) {}

void testFunction(double x) {
    exampleFunction<int, double>(42, x);
}
```
