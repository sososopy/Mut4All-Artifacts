Mutation Operator: Modify Macro Usage in Constant Expressions

Target: Function body where a macro is used within a constant expression.

Mutation Rule:
1. Identify a macro that is used within a constant expression in a function. The macro should involve an operation that includes variables or pointer dereferencing.
2. Modify the macro usage by replacing one of the macro arguments with an expression involving pointer dereferencing or member access, ensuring it is not a compile-time constant.
3. Verify that the macro invocation now includes a non-constant expression which conflicts with the constexpr context.

Example:
Original:
```cpp
#define max(x, y) ((x) > (y) ? (x) : (y))

struct data {
    int value;
};

void example_func(data *d) {
    constexpr int result = max(5, d->value);
}
```

Mutation:
1. Identify the macro `max(x, y)` used within the `constexpr int result`.
2. Replace one of the arguments with an expression involving `d->value`, which is not a compile-time constant.
3. The modified line in `example_func` is:
```cpp
constexpr int result = max(5, d->value);
```
This change should lead to a compile-time error or a crash in compilers with certain bugs when resolving constant expressions involving macros.
