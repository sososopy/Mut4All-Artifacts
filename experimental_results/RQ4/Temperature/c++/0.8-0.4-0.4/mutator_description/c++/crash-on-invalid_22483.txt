Mutation Operator: Lambda Expression with Template Argument Sizeof

Target Code Construct: Function Template

Mutation Rule:
1. Identify a function template that accepts a parameter of type X.
2. Inside the function body, declare a lambda expression that captures variables using a default capture mode (either by value or by reference).
3. Directly use the sizeof operator on the lambda expression or on a capture from the lambda expression.
4. Ensure the lambda captures a variable whose type is a template argument.

Example:

Original Code:
template <typename T>
void process(T t) {
  // Original function logic
}

Mutated Code:
template <typename T>
void process(T t) {
  // Declare a lambda capturing the parameter t
  auto lambda = [=]() { return t; };
  // Use sizeof on the lambda expression
  int size = sizeof(lambda);
}

Notes:
- This mutation operator targets scenarios where lambda expressions interact with template arguments, specifically using sizeof in potentially troublesome ways.
- The lambda captures the template argument to introduce a potential source of type complexity that can lead to compiler crashes when improperly handled.
- Using the sizeof operator on a lambda expression that involves a template argument attempts to mimic conditions that could lead to the assertion failure described in the bug report.
