Mutation Operator: Modify Class Destructors with Defaulted Specifiers

Target Construct: Destructor within a class (struct or class declaration).

Mutation Rule:
1. Locate a class declaration within the seed program.
2. Identify the destructor of the class. If a destructor does not exist, create one by using the `~ClassName()` syntax, where `ClassName` is the name of the class.
3. Modify the destructor by adding a defaulted specifier to it. This is done by appending `= default;` to the destructor declaration.
4. If the destructor is already defined outside the class definition, remove the external definition, keeping only the defaulted declaration inside the class.

Example:

Before Mutation:
```
class Sample {
public:
    ~Sample() {
        // Custom destructor logic
    }
};
```

After Mutation:
```
class Sample {
public:
    ~Sample() = default;
};
```

This mutation is designed to affect destructors which might have implications on constexpr evaluations, potentially exposing issues related to defaultedDestructorIsConstexpr.
