Mutation Operator: Modify noexcept Specifications in Function Declarations

Target: Function Declarations

Mutation Rule:
1. Identify a function declaration in the seed program that currently has a valid, constant noexcept specification.
2. Modify the noexcept clause to include a non-constexpr expression.
3. Ensure that the expression uses existing variables, types, or functions within the scope of the function declaration. If necessary, introduce a simple global or static variable initialized with a non-constexpr value to ensure the expression's evaluation is non-constant.

Example Pseudo-code:

- Original Function:
  ```cpp
  int exampleFunction() noexcept(true) {
    return 42;
  }
  ```

- Mutated Function:
  ```cpp
  int nonConstVar = 5; // Introduced global/static variable
  int exampleFunction() noexcept(nonConstVar > 0) {
    return 42;
  }
  ```

Explanation: The mutation replaces the constant expression `true` in the noexcept specification with a non-constexpr expression that involves a global/static variable (`nonConstVar > 0`). This change exploits the compiler's handling of noexcept expressions and targets the bug related to noexcept evaluation.
