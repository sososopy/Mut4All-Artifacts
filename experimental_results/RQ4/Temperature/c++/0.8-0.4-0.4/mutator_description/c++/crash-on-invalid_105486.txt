Mutation Operator: Invalid Pointer Dereference in Assignment

Target Code Construct: Variable Declaration and Initialization

Mutation Rule:
Step 1: Identify a variable that is being declared and initialized in a single statement.
Step 2: Replace the initial value with an indirection on a literal integer (e.g., replace `int x = 5;` with `int x = *5;`).
Step 3: Ensure that the indirection operator (*) is applied directly to a literal integer or another non-pointer type.
Step 4: The mutation must be applied to a location where the context allows such a replacement, maintaining syntactical correctness.

Example:
Original Code: 
  int number = 10;

Mutated Code:
  int number = *10;
