Mutation Operator: Incorrect Initialization of Union

Target Construct: Union initialization in function bodies.

Mutation Rule: This mutation operator targets union initializations where multiple initializers are incorrectly provided. The mutation involves modifying an existing union initialization to include multiple initializers, which is not valid C++ and is likely to cause a compiler crash.

Step-by-Step Instructions:
1. Identify union declarations in the seed program. Ensure these declarations have at least two data members of different types.
2. Locate a function definition where a union of this type is being initialized.
3. Modify the union initialization in such a way that you attempt to initialize more than one member at the same time.
4. Use the syntax that initializes one member by value and another by designated initializer.

Example Pseudo-Code:
Before Mutation:
```cpp
union MyUnion {
    int a;
    double b;
};

void myFunction() {
    MyUnion u = {.a = 10};  // Correct: initializing only one member
}
```

After Mutation:
```cpp
union MyUnion {
    int a;
    double b;
};

void myFunction() {
    MyUnion u = {20, .b = 3.14};  // Incorrect: initializing both members
}
```

Explanation: This mutation is designed to exploit the rule that a union should never have more than one initializer. By including multiple initializers (one by value and another by designated initializer), it aims to trigger potential assertion failures in the compiler's semantic analysis, similar to the provided bug report.
