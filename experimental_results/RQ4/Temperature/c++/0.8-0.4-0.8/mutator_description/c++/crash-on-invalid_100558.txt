Mutation Operator: Incorrect Return Type in Lambda Expression

Target Code Construct: Lambda Expressions

Mutation Rule:
1. Identify a lambda expression in the existing code.
2. Check if the return type of the lambda expression is explicitly specified.
3. If the return type is specified, change it to a function type that doesn't make sense for a return type.
4. If the return type is not specified, add an explicit return type that is a function type that cannot be used as a return type.
5. Ensure the parameters and body of the lambda remain unchanged to focus the mutation solely on the return type.

Example in Pseudo-code:
Original Code:
```
auto func = [](int x) -> int {
    return x + 1;
};
```

Mutated Code:
```
auto func = [](int x) -> int(int) {
    return x + 1;
};
```

This mutation targets lambda expressions by introducing an incorrect return type, which is a function type, into the lambda's signature, potentially leading to compiler crashes in improper handling scenarios.
