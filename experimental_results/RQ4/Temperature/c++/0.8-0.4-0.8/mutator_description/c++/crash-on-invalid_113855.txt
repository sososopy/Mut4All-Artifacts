Mutation Operator:
Target: Union Initialization

Mutation Rule:
1. Identify any union declaration in the code. For example:
   ```cpp
   union U {
      int x;
      float y;
   };
   ```
2. Locate an instance where the union is being initialized with a designated initializer. For instance:
   ```cpp
   U u = {.x = 5};
   ```
3. Modify the initializer list to include multiple initializers for different union members, like so:
   ```cpp
   U u = {0, .y = 1.0f};
   ```
4. Ensure that the modified code is semantically incorrect by initializing more than one member of the union simultaneously. For example, the initialization should look like:
   ```cpp
   U u = {.x = 10, .y = 2.5f};
   ```
5. Check for similar patterns in other union definitions and initialization instances to apply the mutation where unions are used in the code, ensuring the union has at least two members of different types.
