Target Code Construct: Constructor of a struct or class.

Mutation Rule:
1. Identify a constructor in a struct or class that has one or more parameters with default arguments.
2. Modify the default argument of a parameter to be incomplete or syntactically incorrect. For example, if the default argument is an expression, remove parts of the expression leaving it incomplete.

Original Code:
