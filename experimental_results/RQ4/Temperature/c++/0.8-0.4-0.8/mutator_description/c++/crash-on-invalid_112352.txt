Mutation Operator: Variadic Template Parameter Pack Manipulation

Target Code Construct: Variadic Templates

Mutation Rule:
1. Identify a variadic template function or class in the seed program. For example, a template with the syntax `template<typename... Args>`.
2. Modify the usage of the parameter pack within the function or class definition to intentionally omit the expansion where it is expected.
3. Specifically, if the parameter pack is used in a context where it should be expanded (e.g., in a function call or another template), alter the code to omit the ellipsis (`...`) that causes the expansion.
4. Ensure that the rest of the program attempts to use the unexpanded parameter pack, such as passing it to another function or using it in a context that requires an expanded pack.
5. Compile the program to observe potential compiler crashes due to handling of the unexpanded parameter pack.

    // Original: Use parameter pack expansion
