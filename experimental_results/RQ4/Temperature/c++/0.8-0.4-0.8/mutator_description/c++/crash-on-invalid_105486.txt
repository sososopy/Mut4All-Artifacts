Mutation Operator: Invalid Pointer Dereference in Function

Target Code Construct: Function Definition

Mutation Rule and Steps:
1. Identify a function in the seed program. If no function exists, introduce a simple function.
2. Within the function, declare an integer variable.
3. Create a pointer variable and set it to a null value (e.g., nullptr).
4. Attempt to dereference this null pointer and assign it to the integer variable.
5. Ensure the function is called in the program to trigger the mutation.

Example:
Before Mutation:
```
int main() {
    int x = 10;
    return 0;
}
```

After Mutation:
```
int main() {
    int x;
    int* ptr = nullptr;
    x = *ptr; // Invalid pointer dereference
    return 0;
}
```

This mutation operator attempts to introduce invalid pointer dereferences within a function, a common cause for evaluation errors and potential crashes in C++ compilers. By dereferencing a null pointer, the aim is to trigger assert failures or crashes during compilation, similar to the original bug report's invalid expression evaluation.
