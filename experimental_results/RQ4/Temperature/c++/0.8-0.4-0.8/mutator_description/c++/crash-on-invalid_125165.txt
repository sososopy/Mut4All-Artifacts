Mutation Operator: Invalid Structured Binding with Non-Class Type

Target Code Construct: Structured Binding Declaration

Mutation Rule:
1. Identify a structured binding declaration in the seed program. This is typically of the form `auto [var1, var2, ...] = expression;`.
2. Change the type of the expression being decomposed to a non-class and non-array type such as `char`, `int`, or `float`.
3. Ensure that the structured binding attempts to decompose this non-decomposable type.

Example Before Mutation:
```cpp
struct MyStruct {
    int a;
    double b;
};

MyStruct s = {1, 2.0};
auto [x, y] = s;
```

Example After Mutation:
```cpp
int s = 42; // Non-class, non-array type
auto [x, y] = s; // Attempt to decompose an int
```

This mutation operator exploits the use of structured bindings with types that are not decomposable, which is a scenario that can lead to compiler errors or crashes if not properly handled. The mutation is applicable to any structured binding in the code and should cause a crash or error when the binding tries to decompose a primitive type.
