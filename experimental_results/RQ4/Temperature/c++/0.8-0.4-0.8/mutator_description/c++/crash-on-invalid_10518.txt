Mutation Operator: Template Function Instantiation

Target Construct: Template Function

Mutation Rule:
1. Identify a template function within the seed program, which should have template parameters such as `template<typename T>`.
2. Declare a non-templated function with the same name as the template function, but with a different number and/or type of parameters. This non-templated function should not match any existing instantiations of the template function.
3. Attempt to instantiate the template function with mismatched arguments—arguments that do not match the intended types or number of the template parameters.
4. Ensure that the erroneous template instantiation is intended to trigger ambiguous calls between the non-templated function and template function.

Example in Pseudo-Code Form:
Assume a template function is defined in the seed program as follows:

```cpp
template<typename T>
void process(T value) {
    // some processing on value
}
```

Step-by-step Mutation:
1. Add a non-templated function that may conflict with the template name, but with different parameters:
```cpp
void process(int a, int b) {
    // some processing on a and b
}
```

2. Create a call to the template function with incorrect argument types or numbers:
```cpp
process(3, 4, 5); // Incorrect instantiation, as it doesn't match any function signature
```

Expected Outcome:
This mutation operator should create an ambiguous call or incorrect template instantiation, which can cause the compiler to behave unexpectedly, potentially leading to a crash similar to [crash-on-invalid] scenarios.
