Mutation Operator: In-Class Initializer Omission in Union

Target: Union declarations with in-class member initializers.

Mutation Rule:
1. Locate a union declaration within the C++ source code.
2. Identify any member variables within the union that have in-class initializers.
3. Remove the initializer from one of the member variables within the union. This means deleting the part of the code where the variable is assigned a value directly within the union declaration.
4. Ensure the variable is declared without any initial value, effectively converting it from a constant expression to a default-initialized member.

Example:
Original Code:
```
union MyUnion {
    int a = 10;
    double b;
};
```

Mutated Code:
```
union MyUnion {
    int a;
    double b;
};
```

This mutation operator targets union declarations specifically and modifies them by removing in-class initializers, which can potentially expose weaknesses in how compilers handle unions with member initializations.
