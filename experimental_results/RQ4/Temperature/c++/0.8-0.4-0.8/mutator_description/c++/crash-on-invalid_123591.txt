Mutation Operator: Alter Template Alias Definition

Target: Template alias (using declaration for templates)

Mutation Rule:
1. Locate a template alias declaration in the seed program. This is typically found in the format:
   `template <typename T> using AliasName = SomeTemplate<T>;`
   
2. Modify the template alias to introduce an additional, redundant type parameter, while keeping it unused. This can expose inconsistencies in the compiler's template handling.

   Step-by-step instructions:
   a. Identify the template alias declaration, for example:
      `template <typename T> using AliasName = std::variant<Type1, Type2, Type3>;`
   
   b. Introduce an additional type parameter to the template, for example:
      `template <typename T, typename U> using AliasName = std::variant<Type1, Type2, Type3>;`
      
   c. Ensure that the additional type parameter (`typename U` in this case) is not utilized within the alias definition.

Example before mutation:
```cpp
template <typename T>
using MyVariant = std::variant<int, double, T>;
```

Example after mutation:
```cpp
template <typename T, typename U>
using MyVariant = std::variant<int, double, T>;
```

In this mutation, `typename U` is declared but not used, which can lead to unexpected compiler behavior or crashes if not handled correctly by the compiler's template deduction mechanisms.
