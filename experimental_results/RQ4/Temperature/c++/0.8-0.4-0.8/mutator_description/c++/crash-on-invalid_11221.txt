Mutation Operator: Modify Template Specialization

Target: Class template and its partial specialization.

Mutation Rule:
1. Identify a class template in the seed program. For example:

   ```
   template<typename T>
   class MyClass {
       // Class members
   };
   ```

2. Locate an existing partial specialization of the class template. If no partial specialization exists, create one for demonstration purposes:

   ```
   template<typename T>
   class MyClass<T*> {
       // Specialized class members for pointer types
   };
   ```

3. Modify the partial specialization to introduce a conflict or redundancy. Specifically, attempt to create another partial specialization that conflicts with the existing one. Make sure to use existing data types available in the program to illustrate the mutation:

   ```
   template<typename T>
   class MyClass<T*> {
       // New conflicting partial specialization for pointer types
   };
   ```

4. The mutation illustrates a scenario where the compiler may crash due to a conflict in class template partial specializations, as it encounters ambiguity or redundancy in the specializations.

Note: Ensure the template class and specialization are appropriately defined, and avoid introducing syntactical errors unrelated to the specialization conflict.
