Mutation Operator: Modify Default Function Parameters in Friend Functions

Target Code Construct: Friend Functions with Default Parameters
Applicable Scope: Applies to friend function declarations within a class or struct, particularly those with default parameters.

Mutation Rule:
1. Identify a function declared as a friend within a class or struct.
2. Check if the friend function has default parameters. If it does, proceed with the mutation.
3. Remove the default argument value from one or more parameters of the friend function. This will result in a friend function declaration that does not specify all default values while retaining their use in calls.

Example Before Mutation:
```cpp
struct MyStruct {
  friend void myFunction(MyStruct, int = 10);
};

void test() {
  myFunction(MyStruct{});
}
```

Example After Mutation:
```cpp
struct MyStruct {
  friend void myFunction(MyStruct, int);
};

void test() {
  myFunction(MyStruct{}); // Default argument is not specified in the friend declaration
}
```

Explanation:
- The mutation operator targets friend function declarations with default parameters. By removing the default values from the friend function declaration while keeping the function calls unchanged, the compiler may encounter unexpected behavior, potentially leading to a crash. The mutation operator is designed to exploit potential gaps in handling friend functions and default arguments, which could result in edge cases not thoroughly tested during compiler development.
