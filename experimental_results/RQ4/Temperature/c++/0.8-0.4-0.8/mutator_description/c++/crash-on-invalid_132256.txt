Mutation Operator: Modify Function Template Default Argument

Target Code Construct:
Function templates with default template arguments.

Mutation Rule:
1. Identify a function template declaration that includes a template parameter with a specified default argument.
2. Change the default argument to a different type that does not match or cannot be implicitly converted to the expected type within the function body.
3. Ensure that the function is used within the code, invoking it without specifying the template argument explicitly to rely on the default argument.

Example:
Original Code Snippet:
```cpp
template <typename T = int>
void func(T value) {
    // Function body
}

int main() {
    func(42); // Calls func with T = int
}
```

Mutated Code Snippet:
```cpp
template <typename T = std::string>
void func(T value) {
    // Function body
}

int main() {
    func(42); // Calls func with T = std::string, potential type mismatch
}
```

Explanation:
- The mutation involves changing the default template argument type from `int` to `std::string`.
- The function `func` is called with an integer literal `42`, which will not match the expected type `std::string`, likely causing a type mismatch or compiler confusion during template argument deduction.
- This mutation is specific to function templates and targets the default argument feature, which is known to cause issues if the types do not align with usage patterns.
