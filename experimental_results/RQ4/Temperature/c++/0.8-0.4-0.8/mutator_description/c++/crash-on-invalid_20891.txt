Mutation Operator: Modify Function Template Parameter to Induce Ambiguity

Target: Function templates with auto return types and ambiguous return type specification.

Mutation Rule:
1. Identify function templates in the seed program that use `auto` as the return type.
2. Alter the function template by changing its parameter types to more generic or ambiguous types, such as changing specific types to pointers or references. This can increase the complexity of deducing the return type.
3. If the function template has parameters with specific type constraints, remove or modify these constraints to make the template more generic.
4. Ensure that the declaration of the function template remains valid but introduces sufficient complexity or ambiguity in type deduction to stress test the compiler's ability to infer types.

Example:
Original Function Template:
template <typename T>
auto myFunc(T input);

Mutation:
template <typename T>
auto myFunc(T* input); // Changed parameter to pointer type

Explanation:
This mutation operator focuses on altering the template parameter type to pointers, which can create ambiguity in type deduction, especially when combined with decltype(auto) in the calling context. By doing so, it aims to trigger areas of the compiler that handle complex type deduction and instantiation for function templates, potentially exposing bugs related to type inference and template instantiation logic.
