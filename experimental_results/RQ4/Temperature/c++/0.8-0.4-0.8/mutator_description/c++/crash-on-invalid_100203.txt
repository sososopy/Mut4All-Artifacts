Mutation Operator: Alter Template Argument List

Target: Template Function Call

Mutation Rule:
1. Identify any function call that involves a template function with explicit template arguments.
2. Select a template function call, ensuring that it has mismatched template arguments, such as more or fewer arguments than the function template parameters.
3. Alter the template argument list by removing one argument if the original has too many, or by adding a random type (e.g., `double`, `char`, etc.) if it has too few.
4. Ensure that the alteration leads to a mismatched number of function template arguments compared to the number of arguments expected by the template parameters.

Example:
Consider a template function `template <typename T, typename U> void foo(T &&, U &&);` and a call `foo<int>(1);`.
Mutation would result in altering the call to `foo<int, double>(1);` (adding a template argument) or, if it was `foo<int, double, char>(1, 2);`, altering it to `foo<int>(1, 2);` (removing template arguments).
