Mutation Operator  
Target: Member function operator overloading within a struct or class.  
Mutation Rule:  
1. Identify a member function operator overload declaration within a struct or class.  
2. If the operator overload is a unary or binary operator (e.g., operator+, operator-, operator<<), change its return type to a struct or class that is not directly related to the containing struct or class.  
3. Additionally, modify the function body to return an instance of this unrelated struct or class, ensuring that the returned instance is constructed with any parameters or member variables available within the function.  
Example:  
Original Code:  
```  
struct S {  
    int base = 20;  
    int operator <<(int i) {  
        return base + i;  
    }  
};  
```  
Mutated Code:  
```  
struct Unrelated {};  
  
struct S {  
    int base = 20;  
    Unrelated operator <<(int i) {  
        return Unrelated();  
    }  
};  
```  
This mutation can cause undefined behaviors or crashes as it introduces a scenario where the operator does not return a meaningful or expected value related to the operation being performed, potentially leading to compiler errors or crashes when the operator is used in expressions.
