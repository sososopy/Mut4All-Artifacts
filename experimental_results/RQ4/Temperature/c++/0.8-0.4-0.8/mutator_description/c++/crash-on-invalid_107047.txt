Mutation Operator: Incorrect Template Argument Usage in a Function

Target Code Construct: Function Template or Function Call

Mutation Rule:
1. Identify a function template or a function call that accepts template arguments.
2. In the invocation of the function, provide template arguments that are incorrect or incompatible.
3. Specifically, introduce a template argument that does not match the expected type or number of parameters.

Example:
Original Code:
```cpp
template<typename T>
T add(T a, T b) {
    return a + b;
}

int main() {
    add<int>(3, 5);
}
```

Mutated Code:
```cpp
template<typename T>
T add(T a, T b) {
    return a + b;
}

int main() {
    add<int, double>(3, 5); // Incorrect template argument usage
}
```

Explanation:
In the mutated code, the function `add` is invoked with an incorrect number of template arguments. The function `add` is defined to accept only one template argument, but in the mutated example, two template arguments are provided (`int, double`). This incorrect usage of template arguments can lead to a crash or unexpected behavior during compilation, especially when combined with complex expressions.
