Mutation Operator: Overloaded Function Call with Incorrect Argument Types

Target: Function overload resolution

Mutation Rule:
1. Identify function calls in the seed program where overloaded functions exist. Functions should have multiple versions differing in parameter types or counts.
2. Select a function call to mutate. Ensure the selected function call has multiple candidate overloads.
3. Modify the argument types in the function call to an incorrect type that does not match any of the available overloaded function signatures. Use constants or variables of types that already exist in the seed program.
4. Ensure that the mutated argument types are still valid C++ types to avoid compilation errors unrelated to overload resolution.

Example:
Original Code:
```
void process(int);
void process(double);
void process(int, double);

int main() {
    process(42);
}
```

Mutated Code:
```
void process(int);
void process(double);
void process(int, double);

int main() {
    process("string literal");  // Incorrect argument type, triggers overload resolution issue
}
```

Explanation:
The mutation operator targets overloaded function calls and modifies the argument types to create a situation where no valid overload can be resolved, which may trigger compiler issues related to function overload resolution. The mutation utilizes existing data types and ensures correctness in C++ syntax, focusing the mutation on the complexity of overload resolution rather than introducing new syntax errors.
