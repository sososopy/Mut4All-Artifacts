Mutation Operator: Embed Directive Mutation

Target Code Construct: Preprocessor directive with the #embed keyword.

Mutation Rule:
1. Locate any occurrence of the #embed directive in the existing code.
2. Within the directive, identify any parameters that are known and valid, such as __FILE__, limit, etc.
3. Introduce an unknown parameter after a known one in the #embed directive.
4. Ensure that the unknown parameter is formatted similarly to the known ones but uses an arbitrary name not recognized by the compiler.

Example Before Mutation:
```
int a[] = {
    #embed __FILE__ limit(2)
};
```

Example After Mutation:
```
int a[] = {
    #embed __FILE__ limit(2) unknownparam(3)
};
```

Explanation: This mutation operator intentionally places an unrecognized parameter after a valid one within the #embed directive. Such a configuration is likely to trigger assertion failures or other errors within the preprocessor handling, as evidenced by the bug report provided. This mutation leverages the compiler's behavior when encountering unknown terms in a structured preprocessor directive.
