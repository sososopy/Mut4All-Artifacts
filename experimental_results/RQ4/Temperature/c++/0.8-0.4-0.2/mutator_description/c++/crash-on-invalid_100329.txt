Mutation Operator

Target Construct: Struct and Function Definition

Mutation Rule:
1. Identify a struct in the given C++ code.
2. Within this struct, locate any function prototype or declaration, specifically an operator overload.
3. Modify the operator overload to incorporate the `default` keyword incorrectly by setting the function to default using a non-member function definition syntax, such as attempting to use `= default` outside of the struct's member function context.
4. Ensure to maintain the use of the `this` keyword in a non-static member function context to induce the crash.

Example:
Original Code:
```
struct B {
    bool isEqual(const int&, const B&);
};
```

Mutated Code:
```
struct B {
    bool isEqual(this const int&, const B&) = default;
};
```

This mutation will attempt to use the `= default` mechanism in an incorrect context, leveraging the `this` keyword with a non-static function, which is expected to create inconsistencies and potentially cause the compiler to crash.
