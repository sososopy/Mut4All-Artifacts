Mutation Operator: Template Constraint Mutation

Target Code Construct: Concept Templates

Mutation Rule:
1. Identify a concept template declaration within the seed program.
2. If the concept is defined with a constant expression, replace it with a tautological expression that is logically correct but vacuous in practice. 
3. Ensure that the expression in the concept is syntactically correct but semantically changes the constraint to be trivially true or false.

Example:
Original Code:
```cpp
template <typename T> concept C = sizeof(T) > 1;
template <C> struct S;
```

Mutated Code:
```cpp
template <typename T> concept C = true;  // or concept C = false;
template <C> struct S;
```

This change simplifies the constraint expression while retaining syntactic correctness, which can expose handling faults in the normalization of concept constraints during template instantiation. The mutation operator leverages existing templates in the seed program and modifies the constraint expression within the concept.
