Mutation Operator: Modify Return Type of Lambda Expressions

This mutation operator targets lambda expressions within a function body. It involves altering the return type of a lambda expression in a way that is syntactically valid but semantically incorrect, leading to potential compiler crashes or errors.

Step-by-step instructions:
1. Identify a lambda expression within the function. The lambda should be a part of a larger expression, such as a call to a standard library algorithm like `std::transform` or `std::for_each`.
2. Examine the current return type of the lambda expression.
3. Change the return type to a function type, which is syntactically valid but semantically incorrect. For example, if the current return type is `int`, change it to `int(int)`.
4. Ensure that the lambda body attempts to return a value that matches the original return type, not the modified one, to introduce inconsistency.

Example:
Before Mutation:
```cpp
std::for_each(vec.begin(), vec.end(), [] (int x) -> int {
    return x * 2;
});
```

After Mutation:
```cpp
std::for_each(vec.begin(), vec.end(), [] (int x) -> int(int) {
    return x * 2; // Note that the return statement remains unchanged
});
```

This mutation increases the likelihood of triggering a compiler crash or error due to the inconsistency between the declared return type and the actual return statement within the lambda. The mutated return type is both syntactically valid but semantically problematic.
