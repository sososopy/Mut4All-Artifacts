Mutation Operator: Add Invalid Template Argument

Target Structure: Function Template Call

Mutation Rule:

1. Identify a function template call in the seed program. It typically appears as a function name followed by angle brackets with template arguments, for example, `functionName<Args...>()`.

2. Modify the template argument list by introducing an invalid template argument. An invalid template argument could be a non-type argument used as a type, or an incomplete type.

3. Ensure that the mutation uses existing types or values from the seed program when possible. If no existing elements are suitable, introduce a new type or value explicitly.

Example:

Original Code:
```cpp
template<typename T>
void process() {
    // processing logic
}

int main() {
    process<int>();  // Valid template argument
    return 0;
}
```

Mutated Code:
```cpp
template<typename T>
void process() {
    // processing logic
}

int main() {
    process<int, 42>();  // Introduce invalid non-type template argument
    return 0;
}
```

Explanation:
- The original code calls the `process` function template with a valid type argument `int`.
- The mutated code introduces an invalid non-type template argument `42`, causing the template instantiation to fail and potentially triggering a compiler bug. This mutation specifically targets the template argument list of function template calls.
