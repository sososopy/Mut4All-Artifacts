Mutation Operator: External Redefinition in Function Scope

Target Code Construct:
This mutation operator targets the function scope where an external variable is declared. Specifically, it deals with declaring an external variable with the same name as a parameter in the function.

Mutation Rule:
1. Identify a function in the seed program that accepts at least one parameter.
2. Within the function body, declare an external variable with the same name as one of the function parameters.

Step-by-Step Instructions:
- Locate a function definition, e.g., `void exampleFunction(int param1, float param2)`.
- Inside the function body, e.g., after the opening `{` of the function, add a declaration for an external variable using the same name as one of the parameters. Consider the parameter type during this declaration:
  - If `param1` is an int, then declare `extern int param1;` within the function body after the opening brace `{`.

Example of Mutation:
Original Code:
```cpp
void exampleFunction(int param1, float param2) {
    // function body
}
```

Mutated Code:
```cpp
void exampleFunction(int param1, float param2) {
    extern int param1;
    // function body
}
```

This mutation leverages the redefinition of a parameter name as an external variable within the function scope, which is likely to trigger a crash in a C++ compiler due to scope and linkage conflicts.
