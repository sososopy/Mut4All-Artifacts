Mutation Operator: Nested Compound Statements in Conditional

Target Code Construct: Conditional statements (e.g., if, while) within a function body.

Mutation Rule:
1. Identify a conditional statement within a function, such as an `if` or `while`.
2. Within the conditional expression, introduce a compound statement (enclosed in braces `{}`).
3. Inside this compound statement, declare a local variable of an existing type from the program.
4. Assign a value to the local variable. This value should be of an existing variable type.
5. Use a break statement directly after the variable assignment if applicable, but not within a loop.
6. Ensure the conditional uses this compound statement as part of its condition.

Example:
Original Code:
```
int calculate() {
  if (x > 0) {
    return x;
  }
  return 0;
}
```

Mutated Code:
```
int calculate() {
  if (({ int tempVar; tempVar = x; if (tempVar) break; })) {
    return x;
  }
  return 0;
}
```

Explanation:
This mutation introduces a nested compound statement into the conditional expression of the `if` statement. A new local variable `tempVar` of an existing type is declared inside the compound statement, assigned a value using an existing variable `x`, and a break statement is introduced. This setup mimics patterns likely to trigger edge cases or bugs in compiler handling of complex conditional expressions and statement evaluations.
