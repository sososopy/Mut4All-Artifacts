Mutation Operator: Template Parameter Manipulation

Target Code Construct: Template function

Mutation Rule:
1. Identify a template function in the seed program.
2. Modify the template parameter list by:
   a. Adding a new template parameter type. Declare this parameter using an existing type from the seed program.
   b. Modify the function body to use this newly added template parameter in a way that changes the behavior of the function. If the function is currently not using any parameters in its operations, incorporate the new template parameter into an existing operation.
3. Ensure that the modified function is invoked at least once in the program, passing compatible types from the seed program for the template arguments.

Example:
Consider a seed program with the following template function:
```cpp
template<typename T>
void process(T value) {
    // Original function body
}
```

Apply the mutation:
1. Add a new template parameter `U`. Use an existing type `int` in the seed program for illustration.
2. Modify the function body to include a simple operation involving `U`.

Resulting mutation:
```cpp
template<typename T, typename U>
void process(T value, U extra) {
    // Modified function body using both T and U
    int result = value + extra; // Assuming T and U can be added
}

// Ensure this function is called with appropriate arguments
int main() {
    process<int, int>(5, 10); // Example of how it could be invoked, using existing types
}
```

This mutation operator targets the modification of template parameter lists and ensures the new parameter is functionally incorporated into the template function, uncovering possible crash scenarios due to template handling in compilers.
