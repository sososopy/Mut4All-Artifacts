Mutation Operator:

Mutation Operator: Modify Function Parameter Defaults
Applicable to: Function declarations with default parameters

Mutation Rule:
1. Identify a function within the code that has parameters with default values. For instance, locate a function with a signature similar to `void func(int a = 5, char b = 'x')`.
2. Modify the default parameters of this function by removing them entirely. For instance, change `void func(int a = 5, char b = 'x')` to `void func(int a, char b)`.
3. Ensure that the function is called somewhere in the codebase. If it's not called, insert a call to this function using appropriate arguments. For example, if previously a call exists like `func();`, modify it to `func(3, 'y');` or any valid arguments.
4. Verify that the function still compiles and that it is syntactically correct according to the language specification after the mutation.

Example Before Mutation:
```cpp
void exampleFunc(int num = 10, const char* message = "Hello") {
    // Function implementation
}

int main() {
    exampleFunc();
}
```

Example After Mutation:
```cpp
void exampleFunc(int num, const char* message) {
    // Function implementation
}

int main() {
    exampleFunc(10, "Hello");
}
```

Note: This mutation specifically targets the function parameter default values and aims to perturb the way compilers handle default arguments, which may expose potential mishandling or missed validation cases during compilation.
