Mutation Operator: Modify Template Function Argument Types

Target: Template Functions

Mutation Rule:
1. Identify a template function declaration in the seed program. The template function should have at least one type parameter (e.g., `template<typename T>`).
2. Locate a call to this template function where a specific type is passed as an argument to the template parameter (e.g., `func<int>()` where `func` is a template function).
3. Change the type of the template argument to a different, incompatible type that is unlikely to satisfy the constraints that the function implementation expects. For instance, if the original type is `int`, change it to a user-defined type or a pointer type.
4. Ensure that the new type does not have an implicit conversion to the original type that the template function expects.

Example:
Original Code:
```
template<typename T>
void process(const T& value) {
    // Function implementation
}

void example() {
    process<int>(42);
}
```

Mutated Code:
```
template<typename T>
void process(const T& value) {
    // Function implementation
}

struct CustomType {};

void example() {
    process<CustomType>(CustomType());
}
```

This mutation operator can cause the template instantiation process to hit unexpected conditions due to incompatible types, potentially triggering assertions or crashes in the compiler related to template argument deduction and type checking.
