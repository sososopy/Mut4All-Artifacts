Mutation Operator: Invalid Structured Binding Decomposition

Target Code Construct: Structured Binding Declarations

Applicability: This mutation operator applies to any structured binding declaration in a C++ program. The structured binding should decompose an existing variable or expression that resolves to a class or array type.

Mutation Rule:
1. Identify a structured binding declaration in the seed program. It will have the general form:
   `auto [a, b, ...] = expression;`
2. Change the `expression` on the right-hand side to a type that is not decomposable, such as a fundamental type (e.g., `int`, `char`, `double`) or a pointer type.
3. Ensure that the modified expression is a valid part of the program's context to avoid introducing syntax errors unrelated to the intended mutation.

Example:
Original Code:
```cpp
std::tuple<int, int> myTuple = std::make_tuple(1, 2);
auto [x, y] = myTuple;
```

Mutated Code:
```cpp
int myVar = 42;
auto [x, y] = myVar;  // Change myTuple to myVar, causing a crash due to invalid decomposition
```

In this example, the structured binding originally worked with a `std::tuple`, a valid decomposable type. The mutation changes it to an `int`, which cannot be decomposed, potentially triggering a compiler error or crash similar to the one described in the bug report.
