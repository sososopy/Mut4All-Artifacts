Mutation Operator: Modify Function Call with Invalid Arguments

Target Construct: Function Calls

Mutation Rule:
1. Identify a function call in the seed program. This could be a built-in function, user-defined function, or any library function.
2. Replace a valid argument with an expression that results in an invalid type or value for the expected argument type.
3. If the original argument is a variable or constant, replace it with a more complex expression that is likely invalid, such as operations involving undeclared variables or incompatible types.

Example:
Original Code:
```
int calculate(int x) {
    return x + 2;
}

int main() {
    int result = calculate(5);
}
```

Mutated Code:
```
int calculate(int x) {
    return x + 2;
}

int main() {
    int result = calculate(5 + undefined_variable);
}
```

Explanation:
In this mutation, the argument `5` in the function call `calculate(5)` is replaced with an expression `5 + undefined_variable`, where `undefined_variable` is not declared within the scope, thereby introducing an invalid argument. This mutation targets the function call construct by focusing on modifying its arguments, which potentially triggers compiler bugs when the function expects valid arguments for proper execution.
