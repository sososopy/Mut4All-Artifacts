Mutation Operator: Modify Union Initialization

Target: Union initialization in C++.

Mutation Rule:
1. Identify a union declaration in the source code. Ensure the union contains at least two members.
2. Locate an instance where the union is being initialized.
3. Modify the initialization to include multiple initializers instead of a single one, which typically triggers assertion errors in compilers when multiple initializers are not allowed in unions.
4. Ensure that the initialization uses both direct and designated initializers for different members, creating a conflict.

Example:
Original Code:
```cpp
union MyUnion {
    int a;
    double b;
};

void example() {
    MyUnion u = {1.0};
}
```

Mutated Code:
```cpp
union MyUnion {
    int a;
    double b;
};

void example() {
    MyUnion u = {1, .b = 2.0}; // Multiple initializers for different union members
}
```

Note: This mutation targets C++ unions, exploiting the language's restriction on initializing multiple members of a union simultaneously, which is likely to expose compiler handling issues or assertion failures.
