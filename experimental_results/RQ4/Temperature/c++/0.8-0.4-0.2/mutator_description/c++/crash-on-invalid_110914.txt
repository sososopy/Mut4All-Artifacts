Mutation Operator: Alter Function Parameter Types

Target Code Construct:
This mutation operator targets function declarations and their parameter types.

Mutation Rule:
1. Identify a function in the seed program. For this mutation, we'll focus on functions that take pointers as parameters.
2. Replace a pointer parameter type with an integer type. For example, replace `int*` with `int`.
3. Ensure that the function body remains unchanged, which may lead to type mismatches that can trigger compiler errors or crashes.

Example:
Original Function Declaration:
```
void processData(int* data) {
    // Function body using 'data'
}
```

Mutated Function Declaration:
```
void processData(int data) {
    // Function body remains the same
}
```

Detailed Steps:
- Locate a function with at least one pointer parameter.
- Change the type of the pointer parameter to an integer.
- Do not alter the function body to accommodate the change. Let the existing operations attempt to work with the new parameter type, potentially causing type mismatches.
