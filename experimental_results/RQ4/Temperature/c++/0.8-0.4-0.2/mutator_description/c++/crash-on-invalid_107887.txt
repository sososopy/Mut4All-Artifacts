Mutation Operator: Modify Template Deduction Guide's Scope

This mutation operator targets template deduction guides and aims to modify their declarations to trigger potential compiler bugs, especially crashes related to invalid scope declarations.

Mutation Rule:
1. Identify a template struct or class in a namespace. For instance, if you have a declaration such as `namespace a { template <class> struct pair; }`.
2. Locate an existing deduction guide associated with this template but declared outside its namespace. For example, `template <class T> pair() -> pair<T>;`.
3. Modify the deduction guide's declaration to operate within the namespace of the template. This involves:
   - Moving the deduction guide inside the namespace where the template is originally declared. 
   - Ensure the deduction guide references the template correctly using its fully qualified name if necessary.
   - For example, change `template <class T> pair() -> pair<T>;` to inside the namespace `a` as:
     ```cpp
     namespace a {
       template <class T> pair() -> pair<T>;
     }
     ```

By ensuring deduction guides are declared within their associated template's scope, this operator tests the compiler's handling of scope and template deduction guide resolution, potentially exposing hidden bugs.
