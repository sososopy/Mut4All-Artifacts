Mutation Operator: Alter Pointer Dereference

Target Code Construct:
This mutation operator targets expressions involving pointer dereferencing, specifically when the operand is not a valid pointer. This can occur in function bodies, variable initializations, or expressions within loops and conditionals.

Mutation Rule:
1. Identify expressions where a pointer dereference (*) is applied to a non-pointer operand.
2. Replace the non-pointer operand with a valid pointer type.
3. If no suitable pointer exists, declare a new pointer variable and initialize it with a valid address.

Step-by-step Instructions:
1. Locate an expression in the code of the form: `TypeX result = *Y;` where `Y` is not a pointer.
2. Modify `Y` to a pointer type if possible. If `Y` is of type `int`, change the expression to: `int* ptrY = &existingIntVar; TypeX result = *ptrY;`
3. If no existing variables of a suitable type are available, introduce a new pointer: 
   - Declare a new variable, e.g., `int newVar = 1;`
   - Declare a pointer and assign the address of the new variable: `int* newPtr = &newVar;`
   - Replace the original expression with: `TypeX result = *newPtr;`

Example:
Original:
```cpp
const long long t0 = *0;
```

Mutated:
```cpp
long someVar = 10;
long* ptrVar = &someVar;
const long long t0 = *ptrVar;
```

This mutation operator ensures that no invalid pointer dereferencing occurs, potentially triggering bugs related to unexpected pointer behavior and coverage of pointer handling code paths.
