Mutation Operator: Template Pack Usage in Function Return Type

Target Code Construct: Template functions with parameter packs, specifically focusing on the return type.

Mutation Rule:
1. Identify a template function that utilizes a parameter pack in its return type.
2. Ensure the parameter pack is intentionally left empty in at least one instantiation (i.e., the pack contains no elements).
3. Change the usage of the parameter pack in the return type to intentionally cause a compiler check failure or assertion by attempting to access an index of the pack.
4. If the seed program does not have an empty parameter pack instantiation, introduce one by calling the function template with no template arguments.

Example in Pseudo-Code:
Original Code:
```
template <typename... Args>
struct Example {
    template <unsigned Index>
    static auto getValue() -> Args...[Index];
};

void test() {
    Example<int, double>::getValue<0>();  // Valid usage with non-empty pack
}
```

Mutated Code:
```
template <typename... Args>
struct Example {
    template <unsigned Index>
    static auto getValue() -> Args...[Index];
};

void test() {
    Example<>::getValue<0>();  // Invalid usage with empty pack
}
```

Explanation:
The mutation involves calling `getValue` with an empty template parameter pack (`Example<>`). Attempting to access any index of a non-existent pack should result in a compiler crash or assertion failure, showcasing vulnerabilities in handling pack expansions without elements.
