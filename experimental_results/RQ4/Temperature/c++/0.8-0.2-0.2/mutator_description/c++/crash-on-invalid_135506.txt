Mutation Operator: Template Instantiation with Incomplete Type

Target Code Construct: Template class instantiation

Mutation Rule:
1. Identify a template class definition within the seed program.
2. Create a new variable or function that attempts to instantiate this template class using an incomplete type (e.g., a forward-declared struct or class).
3. Ensure the incomplete type is declared before the instantiation attempt to simulate a valid scope, but do not provide any definition.

Example:
Given a seed program with a template class:
```
template <typename T>
class Container {
public:
    T value;
    Container(T val) : value(val) {}
};
```

Apply the mutation:
1. Forward declare an incomplete type:
```
class IncompleteType;
```

2. Attempt to instantiate the template class with this incomplete type:
```
void testFunction() {
    Container<IncompleteType> testInstance; // This should trigger the mutation
}
```

3. Ensure that `IncompleteType` is not defined anywhere in the code to maintain its incomplete status. The mutation operator relies on the compiler's handling of incomplete types to potentially expose issues like the one described in the bug report.
