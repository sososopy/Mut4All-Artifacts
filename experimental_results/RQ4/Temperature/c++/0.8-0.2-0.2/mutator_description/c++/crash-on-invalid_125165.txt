Mutation Operator: Invalid Structured Binding with Non-class Types

Target Code Construct: Applies to structured bindings, specifically when attempting to decompose a non-class, non-array type, such as a primitive type (int, char, etc.) using structured bindings.

Precise Mutation Rule:
1. Identify a function or code section in the seed program where structured bindings are used.
2. Locate the declaration statement involving structured bindings, for example: `const auto& [a, b] = expression;`
3. Modify the right-hand side of the structured binding statement to use a non-class, non-array type, such as a fundamental type (e.g., int, char) or a pointer type.
4. Ensure the expression on the right-hand side evaluates to a non-class type by changing it to a primitive value or reference to a primitive type.

Example:
Before mutation:
```cpp
struct MyStruct {
    int x;
    int y;
};

void foo() {
    MyStruct s = {1, 2};
    const auto& [a, b] = s; // Proper structured binding
}
```

After mutation:
```cpp
void foo() {
    char c = 'x';
    const auto& [a, b] = c; // Mutated to use a char type instead of a struct
}
```

In this example, the mutation replaces the structured binding of a struct instance with a character type, which is not decomposable, leading to a scenario that could trigger a compiler crash similar to the one described in the bug report.
