Mutation Operator: Modify Extern Variable Declaration Conflict

Target Code Construct:
This mutation operator targets variable declarations within functions, specifically focusing on conflicts caused by redeclaration of extern variables.

Mutation Rule:
1. Identify a function that contains a parameter declaration, e.g., `void function_name(type parameter_name)`.
2. Within the function body, add an extern declaration for a variable with the same name as the parameter.
3. Ensure the parameter and the extern variable have the same type to mimic the conflict scenario.

Example:
Original Code:
```
void exampleFunction(int parameterA) {
  // Function implementation
}
```

Mutated Code:
```
void exampleFunction(int parameterA) {
  extern int parameterA; // Mutated line
  // Function implementation
}
```

Explanation:
This mutation introduces a conflict by attempting to redeclare an existing parameter as an extern variable within the same scope. This can potentially trigger bugs related to name and linkage resolution in the compiler, specifically testing its robustness in handling redeclaration within a function. The mutation operator does not introduce new types or variables outside of what is already present, ensuring compatibility with a wide range of seed programs.
