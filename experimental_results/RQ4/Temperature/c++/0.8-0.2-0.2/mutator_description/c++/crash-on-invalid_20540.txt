Mutation Operator: Template Argument Type Mismatch

Target Code Construct: Template Class Specialization

Mutation Rule:
1. Identify a template class with at least one type parameter in the seed program. For example:
   ```cpp
   template<typename T>
   class TemplateClass {
       T member;
   };
   ```

2. Locate a specialization or instantiation of this template class in the code. For example:
   ```cpp
   TemplateClass<int> instance;
   ```

3. Mutate the specialization by changing the type argument to a type that is incompatible with the operations defined within the template class. For instance, if the template expects a numeric type for arithmetic operations, change it to a class type without such operations.

4. Example mutation:
   - Original code:
     ```cpp
     TemplateClass<int> instance;
     ```
   - Mutated code:
     ```cpp
     class IncompatibleType {}; // New class added that does not support operations expected by the template
     TemplateClass<IncompatibleType> instance;
     ```

5. Ensure that the new type `IncompatibleType` is declared properly in the code, and modify the instantiation of the template class to use this new type. This mismatch should cause the compiler to face issues in template argument deduction, potentially leading to crashes.

This mutation operator is designed to exploit the sensitivity of template argument deduction and type checks within template specializations, which are common sources of compiler crashes due to invalid or unexpected type substitutions.
