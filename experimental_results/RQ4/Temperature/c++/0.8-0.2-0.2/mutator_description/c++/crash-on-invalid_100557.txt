Mutation Operator 1: Overloaded Function Argument Mismatch

Target Code Construct:
This mutation operator targets overloaded functions.

Mutation Rule:
1. Identify overloaded functions in the seed program. These are functions that have the same name but differ in their parameter types or counts.
2. Select one overloaded function and change one of its parameter types to a type that is incompatible with the types used in function calls in the seed program.
3. Ensure the modified function call still tries to call the original function using the same arguments, leading to a mismatch error.

Example Pseudo-code:
Seed Program:
```
void process(const std::vector<int>& vec) { /* ... */ }
void process(const std::map<int, std::string>& map) { /* ... */ }

int main() {
    std::vector<int> myVector;
    process(myVector);  // Correct call
}
```

Mutation:
1. Change the parameter type of one of the overloaded functions:
```
void process(const std::set<int>& vec) { /* ... */ }
```
2. Keep the function call the same:
```
int main() {
    std::vector<int> myVector;
    process(myVector);  // Now leads to a mismatch error
}
```

This mutation exploits the C++ function overloading mechanism and can potentially lead to compilation errors or crashes when the compiler attempts to resolve overloaded function calls.
