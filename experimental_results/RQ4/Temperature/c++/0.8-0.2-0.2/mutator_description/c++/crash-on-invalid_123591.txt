Mutation Operator: Template Argument Mutation

Target Code Construct: Template declarations and instantiations

Mutation Rule:
1. Identify a template declaration or instantiation in the code. This involves constructs utilizing templates, such as `template <typename T>`, `std::variant`, or any template-based constructs.
2. Modify the template argument list by introducing a non-existent type or an incomplete type in the list.
3. If the template is instantiated, replace one of the valid types in the template argument list with an undefined type name.

Example:
Original Code:
```cpp
template <typename T>
using AstNode = std::variant<int, double, char>;

AstNode<float> node;
```

Mutated Code:
```cpp
template <typename T>
using AstNode = std::variant<int, UndefinedType, char>;

AstNode<float> node;
```

Explanation:
In this mutation, `UndefinedType` is inserted into the template argument list of the `std::variant`. The compiler will attempt to resolve `UndefinedType` which could lead to scenarios where the type cannot be instantiated, potentially causing issues with template argument deduction or type resolution, thereby exposing weaknesses in the compiler's handling of templates.
