Mutation Operator: Target Union Initialization with Multiple Initializers

This mutation operator targets union initializations in C++ programs, specifically aiming to introduce multiple initializers for any union type, which can lead to compiler crashes.

Mutation Rule:
1. Identify any union type definition in the seed program. Ensure that the union has at least two fields, either of built-in types or user-defined types.
2. Locate any initialization of the union, especially in the form of a initializer list or a placement new expression.
3. Modify the existing initialization by adding an additional initializer for another member of the union that was not initially provided an initializer.
4. Ensure that the initializer added is compatible with the type of the union member field.

Example Pseudo-Code Before Mutation:
```cpp
union ExampleUnion {
    int a;
    double b;
};

// Existing initialization
ExampleUnion e = {3};
```

Example Pseudo-Code After Mutation:
```cpp
union ExampleUnion {
    int a;
    double b;
};

// Mutated initialization with multiple initializers
ExampleUnion e = {3, .b = 4.5}; // Intentionally adding multiple initializers
```

Note:
1. This mutation should only be applied to unions since they are designed to have only one active member at any time, and adding multiple initializers violates this.
2. The added initializer should be selected from the union's fields, ensuring no new fields or types are introduced unless necessary for demonstration.
3. This operator can be applied to any part of the program where a union initialization occurs, either in global scope, inside functions, or within class/struct members.
