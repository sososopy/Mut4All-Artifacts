Mutation Operator: Pointer Dereferencing with Literal

Target Code Construct:
This mutation operator targets expressions involving pointer dereferencing. It applies to any expression where a pointer is expected but a non-pointer value is provided.

Mutation Rule:
1. Identify an expression in the seed program where a pointer dereference is performed.
2. Replace the pointer variable with a literal integer value, e.g., `0`, which is not a valid pointer.
3. Ensure the expression still appears to perform a dereference operation on this non-pointer value.

Example in Natural Language:
Consider a seed program where there is a pointer variable `ptr` that is dereferenced as `*ptr`. The mutation involves replacing `ptr` with an integer, say `0`, so the expression becomes `*0`.

Explanation:
The mutation operator exploits the compiler's handling of pointer dereferences where the operand is not a valid pointer type. The intention is to trigger expressions where the compiler needs to evaluate an indirection operation without a valid pointer, which can lead to a crash if the compiler does not handle this edge case properly.
