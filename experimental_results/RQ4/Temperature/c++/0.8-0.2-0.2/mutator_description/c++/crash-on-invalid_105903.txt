Mutation Operator 

Target: Template Function Specialization with Empty Type Packs

Mutation Rule:
1. Identify a template struct or class with a variadic template parameter (e.g., `template <typename... Args>`).
2. Inside the struct or class, find a member function template that uses the variadic template parameter, especially where the parameter pack is explicitly expanded.
3. Modify the function to attempt to access an element of the parameter pack using an index, but ensure the pack is empty at the point of instantiation.
4. Ensure the function is called or instantiated with an empty parameter pack in a context where the indexed access would be evaluated.

Example:
Original:
```
template <typename... Ts>
struct Example {
    template <unsigned N>
    static auto get() -> Ts...[N] {}
};

void test() {
    Example<>::get<0>(); // Original code that causes crash
}
```

Mutation:
1. Locate the template struct `Example` with variadic template parameter `Ts`.
2. Within `Example`, find the member function template `get` that accesses `Ts...[N]`.
3. Ensure no type is provided for `Ts` when instantiating or calling `Example` (i.e., `Example<>`).
4. Attempt to access an element of the empty parameter pack within `get` by keeping the function call `Example<>::get<0>();`.

Note: The mutation operator is designed to exploit the behavior observed in the provided bug report, where accessing an element of an empty parameter pack leads to a compiler crash due to an assertion failure.
