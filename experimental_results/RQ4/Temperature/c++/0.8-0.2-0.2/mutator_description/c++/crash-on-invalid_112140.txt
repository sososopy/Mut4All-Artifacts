Mutation Operator: Modify Default Constructor Argument in Structs

Target: Structs with constructors that have default arguments.

Mutation Rule:
1. Identify a struct with a constructor that has a default argument.
2. Change the type of the default argument to a type that does not match the constructor's parameter type but is implicitly convertible.
3. If the constructor parameter is a reference type, use a temporary variable with a non-const type initializer.

Example Mutation:

Original Code:
struct MyStruct {
    constexpr MyStruct(const int &a = 5) {}
};

Mutated Code:
struct MyStruct {
    constexpr MyStruct(const int &a = 5.0f) {} // Change `5` to `5.0f`, a float value.
};

Explanation: The mutation involves modifying the default argument from an integer to a float. This change exploits the implicit conversion between types that may not be expected in certain compiler implementations, potentially triggering assertion failures or other unexpected behavior during compilation. This mutation has strong universality and high coverage as it can apply to numerous struct definitions across different codebases.
