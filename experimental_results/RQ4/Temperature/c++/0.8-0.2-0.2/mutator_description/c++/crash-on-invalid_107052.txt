Mutation Operator: Modify Built-in Function Call

Targeted Code Construct: Built-in function calls (e.g., `__builtin_xyz`)

Mutation Rule:
1. Locate a call to a built-in function, such as `__builtin_fpclassify`.
2. Modify the number of arguments passed to the function. If the built-in function expects a specific number of arguments, either increase or decrease the number of arguments.
3. When increasing the number of arguments, use variables or constants already present in the program or introduce simple constants like `0`, `1`, or `-1`.
4. When decreasing the number of arguments, ensure at least one required argument remains, if applicable.

Example:
Before Mutation:
```cpp
int main() {
    int x = 5;
    __builtin_fpclassify(0, 1, 4, 3, 2, x);
}
```

After Mutation:
```cpp
int main() {
    int x = 5;
    __builtin_fpclassify(0, 1, 4, 3, 2, x, -1); // Added an extra argument
}
```

The mutation aims to test the compiler's handling of deviations from expected argument counts in built-in functions, potentially triggering crashes or unexpected behavior.
