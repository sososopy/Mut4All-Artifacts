Mutation Operator: Modify Default Template Argument in Function Templates

Target Construct: Function Template

Mutation Rule:
1. Identify a function template in the seed program. A function template is generally declared as follows:
   ```cpp
   template<typename T = DefaultType>
   void functionName(T parameter) {
       // function body
   }
   ```
   
2. Introduce a new type used as a default template argument that is not defined within the scope. You can achieve this by changing the `DefaultType` in the function template declaration to a type that does not exist, leading to a potential crash in the compiler during parsing or semantic analysis.

3. Modify the function template as follows:
   - Locate the template parameter list, specifically the default argument, and change it to an undefined type. 
   - Ensure that the new type name does not exist anywhere in the program to ensure it is truly undefined.

Example Before Mutation:
```cpp
template<typename T = int>
void process(T value) {
    // Processing logic
}
```

Example After Mutation:
```cpp
template<typename T = UndefinedType>
void process(T value) {
    // Processing logic
}
```

Explanation:
- By changing the default template argument to `UndefinedType`, which is not declared anywhere in the program, this mutation induces a scenario where the compiler's ability to handle default template arguments is tested.
- This mutation can expose issues in the parsing and semantic analysis stages related to template deduction and type resolution, potentially leading to a crash if there is a latent bug in handling missing type definitions in default arguments.
