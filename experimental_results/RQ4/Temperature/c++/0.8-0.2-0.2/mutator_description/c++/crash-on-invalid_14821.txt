Mutation Operator: Template Specialization with Invalid Type

Target: Template Structures and Template Functions

Mutation Rule:
1. Identify a template structure, say `template<class T> struct X {};`.
2. Extend this structure with another template structure, for example, `template<class T> struct Y : public X<T> {};`.
3. Identify a template function that takes a parameter of the specialized template structure type, for example, `template<class T> void func(Y<const T> param);`.
4. In a function call, pass a parameter to this template function that does not comply with the expected template specialization, for example, call `func(Y<int>());` where the template function expects `Y<const T>`.

This mutation exploits the differentiation between a type and its const variant, which can lead to invalid type retrieval in a template instantiation context, potentially causing the compiler to crash. 

Example:
1. Start with a template structure `template<class T> struct X {};`.
2. Derive another template structure `template<class T> struct Y : public X<T> {};`.
3. Write a template function `template<class T> void func(Y<const T> param);`.
4. In a function, call `func(Y<int>());` even though `func` expects `Y<const T>`, leading to a mismatch that might trigger a bug in the compiler.

This mutation focuses on the subtle differences in template specialization expectations and their improper use, which can uncover bugs related to type handling in the compiler.
