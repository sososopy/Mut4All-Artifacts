Mutation Operator: Add Default Argument to a Friend Function

Target Construct: Friend Function within a Template Struct

Mutation Rule:
1. Locate a template struct definition in the code. Ensure the struct has a friend function declared within it.
2. If the friend function does not have a default argument, add one. If it already has a default argument, modify the existing default argument to a different, valid value.
3. Ensure the default argument type matches the parameter type of the friend function.
4. Reuse existing types and variables within the code for the default argument value, or declare a new constant or variable if necessary. Avoid using complex expressions or operations.

Example:
Original Code:
```
template<typename T>
struct Example {
  friend void func(Example, int);
};
```

Mutated Code:
```
template<typename T>
struct Example {
  friend void func(Example, int = 42); // Added default argument to the friend function
};
```

In this example, the default argument `42` is introduced in the friend function declaration within the template struct `Example`. This mutation can potentially cause the compiler to crash if it mishandles the instantiation of templates with default arguments.
