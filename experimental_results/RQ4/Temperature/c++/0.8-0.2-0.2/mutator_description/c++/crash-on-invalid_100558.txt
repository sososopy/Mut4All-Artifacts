Mutation Operator: Modify Lambda Return Type

Target Code Construct: Lambda Functions

Mutation Rule:
1. Identify a lambda function within the source code that specifies a return type using the '->' syntax.
2. Change the specified return type to an incomplete type or a non-sensical type. For example, if the lambda currently returns a specific type, change it to a function type, which is not allowed.

Step-by-step Instructions:
- Locate a lambda expression. For instance, in the code example, consider the lambda expression within the `std::for_each` function call.
- Identify the return type of the lambda. In the bug report example, the lambda incorrectly attempts to return `-> int (int y)`.
- Change this return type to an invalid type. For example, you could mutate it to `-> int(int)` (a function type), which is not a valid return type for a lambda.

Example before mutation:
```cpp
std::for_each(vec.begin(), vec.end(), [](int x) -> int (int y) {
    std::cout << "Value: " << x << y << std::endl;
    return x * y;
});
```

Example after mutation:
```cpp
std::for_each(vec.begin(), vec.end(), [](int x) -> int(int) {
    std::cout << "Value: " << x << std::endl;
    return x; // Ensure the lambda body is consistent with the mutation
});
```

Application:
- This mutation operator can be applied wherever lambda expressions are found, providing coverage across various parts of a program, as lambda expressions are commonly used in modern C++ codebases.
- It specifically targets the lambda return type specification, a feature introduced and evolving in C++11 and later standards, ensuring relevance across multiple C++ versions.
