Mutation Operator: Embed Directive Mutation

Target Code Construct: Preprocessor directives, specifically the `#embed` directive.

Mutation Rule:
1. Identify a `#embed` directive with known parameters in the source code. These known parameters typically include standard preprocessor macros like `__FILE__`, `__LINE__`, etc.
2. Introduce an unknown or unsupported parameter immediately after a known parameter. This unknown parameter should be a string or a token that is likely to be unrecognized by the compiler.
3. Example: If the original directive is `#embed __FILE__ limit(2)`, change it to `#embed __FILE__ unknownParam limit(2)`.
4. Ensure that the unknown parameter is syntactically correct but semantically invalid, which means it should look like a regular parameter (e.g., `param(3)`) but not recognized by the compiler.
5. Apply this mutation to various locations in the source, especially where `#embed` directives are used in the context of arrays or other structured initializations, to explore different crash scenarios.
