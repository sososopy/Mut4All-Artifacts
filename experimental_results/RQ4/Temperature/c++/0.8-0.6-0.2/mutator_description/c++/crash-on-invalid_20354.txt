Mutation Operator: Introduce Conflicting Linkage

- Target Code Construct: Function with a parameter
- Application Context: Applies to functions that have at least one parameter declared in their signature.
- Mutation Rule:
  1. Identify a function in the seed program that has at least one parameter, say `param`.
  2. Within the function body, declare an `extern` variable with the same name and type as `param`.
  3. Ensure that the `extern` variable declaration is placed in a manner that conflicts with the linkage of the function parameter.
  
Example before mutation:
```cpp
void exampleFunction(int param) {
  // Function implementation
}
```

Example after mutation:
```cpp
void exampleFunction(int param) {
  extern int param; // Conflicting linkage declaration
  // Function implementation
}
```

This mutation operator exploits the linkage conflict between a function parameter and an `extern` declaration within the same function scope, which can lead to compiler crashes or unexpected behavior due to linkage resolution issues.
