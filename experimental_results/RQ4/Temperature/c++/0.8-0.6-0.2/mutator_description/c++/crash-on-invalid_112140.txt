Mutation Operator: Modify Default Parameters in Constructors

Target Construct: Constructor in a struct or class.

Mutation Rule:
1. Identify a constructor within a struct or class in the seed program that takes parameters.
2. If the constructor has parameters with default values, alter the default value expression to an incomplete expression.
3. Specifically, remove a part of the expression that provides the default value, making it syntactically invalid.
4. Ensure the rest of the code, outside the constructor definition, remains unchanged to isolate the mutation impact.

Example:
Original Code:
```cpp
struct S {
  S(int x = 5) {}
};
```

Mutated Code:
```cpp
struct S {
  S(int x = ) {}
};
```

Explanation:
- In the original code, the constructor `S` has an integer parameter `x` with a default value of `5`.
- The mutated code removes the default value `5`, resulting in an incomplete expression `int x =` as the default parameter value.
- This mutation targets the expression that specifies the default value for a parameter in a constructor, potentially triggering issues with how the compiler handles default values and expressions.
