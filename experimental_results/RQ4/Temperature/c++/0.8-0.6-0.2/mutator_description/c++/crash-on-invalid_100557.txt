Mutation Operator: Template Argument Type Mismatch

Target Code Construct: Function Templates

Mutation Rule:
1. Identify a function template in the seed program that is instantiated with specific template arguments. For example, consider a function like `std::make_tuple<>()`.
2. Replace one of the existing template argument types with a type that is incompatible or unexpected. This could involve changing a type to a different category (e.g., from `int` to `std::string`) or to a type not supported by the function's intended usage.
3. Ensure that the mutated code is syntactically correct but semantically incorrect to trigger potential type resolution errors in the compiler.

Example (Pseudo-code form):
Original Code:
```cpp
auto t = std::make_tuple<int, double>(1, 2.0);
```

Mutated Code:
```cpp
auto t = std::make_tuple<int, std::string>(1, "test");
```

In this example, the second template argument `double` is replaced by `std::string`, causing a type mismatch.
