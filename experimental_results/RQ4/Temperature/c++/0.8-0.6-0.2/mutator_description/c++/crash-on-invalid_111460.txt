Mutation Operator: Modify Template Usage in Pseudo-Destructor Expressions

Target Code Construct: Function member in a template struct or class.

Mutation Rule:
1. Identify a function within a template class or struct that utilizes a pseudo-destructor expression.
2. Locate the pseudo-destructor expression within the function. It has the form `(*ptr).~Type()`, where `ptr` is a pointer and `Type` is a placeholder for either a specific type or a template parameter.
3. Replace the template parameter or type name in the pseudo-destructor expression with a variadic template argument expansion. For example, change `(*ptr).~T();` to `(*ptr).~T...();` where `T` is a template parameter and the pseudo-destructor is incorrectly using a pack expansion.

Example Before Mutation:
```cpp
template <typename T>
struct Example {
    void func() {
        int* ptr = nullptr;
        (*ptr).~T();
    }
};
```

Example After Mutation:
```cpp
template <typename T>
struct Example {
    void func() {
        int* ptr = nullptr;
        (*ptr).~T...();
    }
};
```

Explanation:
The mutation involves introducing a variadic template argument expansion (`...`) in place of a singular template parameter in a pseudo-destructor expression. This incorrect usage is known to potentially trigger compiler bugs, particularly in expressions where template parameter packs are not semantically valid. This mutation can disrupt the expected parsing of pseudo-desstructor expressions, which may lead to compiler errors or crashes.
