Mutation Operator: Modify Template Declarations

Target Code Construct: Template declarations in function or class templates.

Mutation Rule:
1. Identify a template declaration in the code, such as a function template or class template.
2. Modify the template parameters by introducing a recursive dependency or an ambiguity that would confuse the template instantiation logic.
3. Ensure the modified template is still syntactically correct but semantically invalid to trigger edge cases in the compiler's template handling logic.

Example:
Original template code:
```cpp
template <typename T>
class Sample {
public:
    void function() {}
};
```

Mutation Steps:
1. Change the template parameter to create a recursive dependency.
2. Modify the class to reference the template parameter in a way that depends on itself, but is not valid.

Mutated template code:
```cpp
template <typename T>
class Sample {
    typedef typename T::type NestedType;  // Introduces a recursive dependency
public:
    void function(NestedType) {}          // Function uses the dependent type
};
```

Explanation:
- The mutation targets template declarations and aims to introduce semantic errors that can cause compilers, especially ones like clang, to crash when they incorrectly handle the complexities of templates. By creating a recursive dependency on a non-existent member `type` of the template parameter `T`, the compiler may enter an unexpected state, revealing bugs in template parsing or instantiation logic.
