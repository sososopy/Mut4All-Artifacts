Mutation Operator: Modify Template Partial Specialization

Target Code Construct: Class Template Partial Specialization

Mutation Rule:
1. Identify a class template that has a partial specialization in the seed program.
2. Introduce a new partial specialization for the same class template that conflicts with the existing specializations.
3. Ensure the new partial specialization has a condition that overlaps with an existing one but differs subtly, such as using a different type that is interchangeable in certain contexts.
4. Insert the newly defined partial specialization into the code.

Example:
Assume a seed program has a class template with an existing partial specialization:
```cpp
template <typename T>
class MyClass {};

template <>
class MyClass<int> {};
```

Mutation Steps:
- Modify the code by introducing a conflicting partial specialization:

```cpp
template <>
class MyClass<short> {};
```

Note: Ensure that both specializations `MyClass<int>` and `MyClass<short>` can be seen as conflicting in some compiler contexts if type conversion or overloading is involved in the seed program.
