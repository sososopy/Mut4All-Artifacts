Mutation Operator: Template Argument Mismatch in Variadic Templates

Targeted Code Construct: Function Template with Variadic Templates

Mutation Rule:
1. Identify a function template with variadic template parameters, such as `template <typename... Ts>`.
2. In a function call to this template, deliberately provide mismatched or incorrect template arguments.
3. Ensure that the number of template arguments specified does not correspond correctly with the expected arguments or their types.

Step-by-Step Instructions:
- Locate a function template declaration using variadic templates.
  Example: `template <typename... Ts> void foo(Ts&&... args) {}`
- Find a call site where this template is invoked.
  Example: `foo<int, int>(0, i);`
- Modify the invocation by providing an incorrect or mismatched set of template arguments.
  - Example Mutation: Replace `foo<int, int>(0, i);` with `foo<int>(0, i);`
  - Here, the mutation reduces the number of template arguments from two to one, potentially causing a mismatch with the number of actual function call arguments.

Purpose:
This mutation operator induces a mismatch between the number of provided template arguments and the expected number in a variadic template function call, which can trigger bugs or crashes in compilers that fail to handle such cases gracefully. By altering the template argument count or types, it stresses the compiler's ability to manage variadic template argument deductions appropriately.
