Mutation Operator: Union Initialization Mutation

Target: Union initializations in function bodies, particularly where designated initializers are used.

Mutation Rule:
1. Identify a union with more than one member type, especially one of which is a struct or class type.
2. Within a function, locate a new expression or direct initialization that initializes an instance of the union.
3. Modify the initializer list by adding multiple initializations for the union's members (more than one initializer). 
4. Ensure that the initializers target different types or fields within the union.

Example:
Original:
```
union ExampleUnion {
    int a;
    double b;
};

void exampleFunction() {
    ExampleUnion u = { .a = 5 };
}
```
Mutated:
```
union ExampleUnion {
    int a;
    double b;
};

void exampleFunction() {
    ExampleUnion u = { .a = 5, .b = 3.14 };  // Multiple initializers for union
}
```

This mutation is designed to exploit the fact that unions should only have one active member at a time, potentially causing initialization issues or compiler crashes when multiple initializations are specified.
