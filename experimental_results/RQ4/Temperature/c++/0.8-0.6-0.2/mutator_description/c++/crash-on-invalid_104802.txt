Mutation Operator: Recursive Field Declaration in Class Structure

Target: Class declarations in C++.

Mutation Rule:
1. Identify a class declaration in the seed program. For example, consider a class named `MyClass`.
2. Within the class `MyClass`, declare a member variable of the same type `MyClass`, leading to a recursive declaration.
3. Ensure there is no explicit constructor or method in the class that handles or resolves this recursive declaration.

Example:
Original Code:
```
class MyClass {
  int value;
  void doSomething();
};
```

Mutated Code:
```
class MyClass {
  MyClass selfReference; // Recursive field declaration
  int value;
  void doSomething();
};
```

Explanation:
This mutation operator aims to create a scenario where the class attempts to contain an instance of itself, causing the compiler to potentially enter a state where it cannot resolve the size or layout of the class, as it becomes an incomplete type until class definition is complete. It is a direct trigger for testing how the compiler handles recursive type definitions, which can lead to infinite recursion or crashing during compilation. This mutation has wide applicability across various class declarations and can often lead directly to crashes due to incomplete types.
