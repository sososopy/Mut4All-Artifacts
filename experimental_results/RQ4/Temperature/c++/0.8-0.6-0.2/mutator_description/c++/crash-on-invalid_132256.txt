Mutation Operator: Default Template Argument Manipulation

Target: Template functions with default template arguments.

Mutation Rule: Modify the default template argument in a function template to a type or value that is mismatched or incompatible with its intended use within the function. 

Steps:
1. Identify a template function with a default template argument. For example:
   ```cpp
   template<typename T = int>
   void exampleFunction(T value) {
       // Function implementation
   }
   ```

2. Change the default template argument `int` to a type that is logically incompatible with the operations performed inside the function. For example, change `int` to `std::string`.

3. Ensure the template function attempts to perform operations that are incompatible with the new default type. For example:
   ```cpp
   template<typename T = std::string>
   void exampleFunction(T value) {
       // Original operation: supposed to work with int
       int result = value + 5; // This will cause a type mismatch
   }
   ```

4. Ensure the main function or any caller does not explicitly specify a type parameter, allowing the default to be used. For example:
   ```cpp
   int main() {
       exampleFunction(); // Uses default template argument std::string
       return 0;
   }
   ```

This mutation leverages the compiler's handling of default template arguments and can trigger issues when incompatible types are used in operations, leading to potential crashes or unintended behavior in the compiler.
