Mutation Operator: Modify Default Arguments in Friend Functions

Target Code Construct: Friend function declarations within a template struct.

Mutation Rule:
1. Identify a template struct, such as "template<typename T> struct S {}".
2. Locate a friend function declaration inside this struct. For example: "friend void func(S, int = 0);"
3. Change the default argument in the friend function to a non-trivial expression involving the template parameter. For example, replace "int = 0" with "int = sizeof(T)" or "int = T()".
4. Ensure that the function call to the friend function uses a non-template instance of the struct, such as "func(S<>{});".

Example in Pseudo-Code:
Original:
```
template<typename T>
struct S {
  friend void func(S, int = 0);
};

void callFunc() {
  func(S<>{});
}
```

Mutated:
```
template<typename T>
struct S {
  friend void func(S, int = sizeof(T));
};

void callFunc() {
  func(S<>{});
}
```

This mutation exploits the handling of default arguments in the context of template instantiation and friend functions, which has a history of causing issues in some compilers.
