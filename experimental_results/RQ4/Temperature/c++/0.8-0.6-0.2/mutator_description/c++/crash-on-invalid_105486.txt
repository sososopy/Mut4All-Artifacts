Mutation Operator: Invalid Pointer Dereference in Initialization

Target Code Construct: This mutation operator targets variable initialization within a function or global context.

Mutation Rule:
1. Identify a numeric literal or constant being assigned to a variable during its initialization.
2. Replace the numeric literal or constant with a dereference operation of an invalid pointer (e.g., dereferencing a null pointer or an out-of-bounds pointer).
3. Ensure the modified pointer expression is syntactically correct but semantically incorrect, causing the compiler to attempt evaluating an invalid memory access.

Example:
Original Code:
```
int myVar = 42;
```

Mutated Code:
```
int myVar = *reinterpret_cast<int*>(nullptr);
```

Explanation:
- Locate the initialization of `myVar` with the numeric value `42`.
- Replace `42` with a dereference operation of a null pointer cast to the appropriate type.
- In this example, we use `reinterpret_cast<int*>(nullptr)` to create a null pointer and then dereference it with `*`. This creates an invalid memory access during initialization, which is likely to trigger a compiler bug or crash.
