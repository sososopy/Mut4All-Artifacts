Mutation Operator: Modify Function Template Instantiation

Target Code Construct: Function template.

Mutation Rule:
1. Identify a function template definition within the seed program.
2. Locate an instantiation of this function template.
3. Modify the template arguments used in the instantiation:
   a. Change a type argument to an incompatible type that is not expected by any specialization.
   b. Introduce a non-type argument that exceeds the expected limits (e.g., using a large non-type template argument where a smaller range is expected).
4. Ensure that the modification causes conflict with an existing specialization or results in an invalid instantiation.

Example:
Consider a seed program with the following function template:

```
template <typename T>
void process(T arg) {
    // Implementation
}

int main() {
    process<int>(5); // Template instantiation
}
```

Mutation:
Change the template instantiation to use an incompatible type, such as `process<void*>(nullptr);`, assuming `void*` is not a compatible or expected type in the context of the template's implementation.

This mutation targets the parsing and semantic analysis stages during template instantiation, potentially leading to the assertion failure observed in the bug report.
