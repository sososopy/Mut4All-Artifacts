Mutation Operator: Invalid Use of Structured Binding with Non-Class Types

Target Code Construct: Structured Bindings in Function Parameters and Local Declarations

Mutation Rule:
1. Identify structured bindings in the seed program that decompose a variable.
2. Check if the variable being decomposed is of a class type, array, or tuple. If it is, continue with the mutation; if not, this operator does not apply.
3. Modify the type of the decomposed variable to a non-class, non-array type such as `int`, `char`, or `double`.
4. Ensure that the structured binding leads to a mismatch between the expected decomposable type and the actual type used.

Example:
Original Code:
```cpp
struct Point { int x, y; };
Point p;
auto [a, b] = p;
```

Mutated Code:
```cpp
int p = 42; // Changed from `Point` to `int`
auto [a, b] = p; // Structured binding now targets a non-class type
```

Explanation:
This mutation operator forces the structured binding to operate on a type that cannot be decomposed, such as a primitive type like `int` or `char`. This mismatch is likely to cause the compiler to encounter an error during semantic analysis, especially in scenarios involving template instantiation or function overloading where the expected type structure is violated.
