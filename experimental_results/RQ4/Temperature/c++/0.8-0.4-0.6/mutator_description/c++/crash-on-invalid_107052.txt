Mutation Operator: Modify Built-in Function Call with Incorrect Argument Types

Target: Function Calls, specifically built-in functions taking multiple arguments.

Mutation Rule:
1. Identify a function call to a built-in function, such as `__builtin_fpclassify`.
2. Replace one or more of the arguments with an expression of an incorrect type not expected by the function. For example, if the function expects an integer argument, replace it with a floating-point expression.
3. Ensure that the replacement does not introduce undeclared variables by using literal values or predefined variables from the program.

Example:
Original code:
```
int main() {
    int a = 3;
    __builtin_fpclassify(0, 1, 4, 3, 2, a);
}
```

Mutated code:
```
int main() {
    int a = 3;
    __builtin_fpclassify(0, 1, 4, 3, 2, 3.14);  // Replaced 'a' with a floating-point literal
}
```

This mutation operator is designed to introduce type mismatches in function arguments, which can test the robustness of type checking in compilers, potentially leading to crashes when handling unexpected input types. The operator is applicable to any built-in function calls requiring specific argument types, thus having broad applicability in triggering type-checking bugs.
