Mutation Operator: Default Argument Misplacement in Constructor

Target Code Construct: Constructor of a class or struct

Mutation Rule:
1. Identify the constructor declaration within a class or struct in the seed program.
2. Locate any constructor that has default arguments. If no default arguments exist, this mutation is not applicable.
3. Modify the constructor to remove the value for one of the default arguments by deleting the portion after the equals sign ('='), making it an incomplete default argument. For example, change from `int a = 10` to `int a =`.
4. Ensure that the constructor's closing parenthesis remains intact, and the overall syntax of the constructor is otherwise preserved.

Example Before Mutation:
```cpp
struct Example {
  Example(int x, int y = 5, int z = 10) {}
};
```

Example After Mutation:
```cpp
struct Example {
  Example(int x, int y = 5, int z =) {}
};
```

This mutation operator targets the constructor syntax with default arguments, intentionally creating an incomplete initializer to simulate erroneous code that could trigger potential compiler assertion failures.
