Mutation Operator:
Target Code Construct: Friend Function with Default Argument in Template Struct

Mutation Rule:
1. Identify a template struct that declares a friend function with a default argument.
2. Modify the friend function declaration by removing the default argument.
3. Ensure that the friend function is called from a separate function where the template struct is instantiated.
4. If a call to this friend function exists, remove the argument that corresponds to the default argument that was removed in the mutation.

Example before mutation:
```cpp
template<typename T = int>
struct Container {
  friend void exampleFunction(Container, int = 42);
};

void testFunction() {
  Container<> c;
  exampleFunction(c); // Calls with default argument 42
}
```

Example after mutation:
```cpp
template<typename T = int>
struct Container {
  friend void exampleFunction(Container); // Default argument removed
}

void testFunction() {
  Container<> c;
  exampleFunction(c); // No argument for previously defaulted parameter
}
```

Explanation:
This mutation operator targets the declaration of a friend function within a template struct that uses default arguments. By removing the default argument, it alters the function signature and affects function calls, potentially exposing bugs related to parameter handling in the compiler. This approach leverages existing components such as structs and functions in the seed program, ensuring broad applicability.
