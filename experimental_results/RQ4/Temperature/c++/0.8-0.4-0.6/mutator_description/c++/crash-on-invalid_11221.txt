Mutation Operator: Modify Template Specialization

Target Code Construct:
Template class partial specialization

Mutation Rule:
1. Identify a template class declaration with an existing partial specialization. For example:
   ```cpp
   template <typename T>
   class MyClass;
   
   template <typename T>
   class MyClass<T*> {
       // Partial specialization implementation
   };
   ```
   
2. Introduce a modification to the partial specialization that could confuse the compiler's specialization logic. In this case, alter the existing specialization by adding an additional specialization that contradicts or overlaps with the existing one:
   ```cpp
   template <typename T>
   class MyClass<T* const> {
       // Conflicting partial specialization implementation
   };
   ```
   
3. Ensure the new specialization is syntactically correct but semantically confusing, causing the compiler to assert due to conflicting specializations.

Rationale:
This mutation operator targets the area of template specialization where incorrect or overlapping specializations are more likely to cause issues such as compiler crashes. By introducing a specialization that conflicts with an existing one, it stresses the compiler's ability to handle complex template resolution scenarios.
