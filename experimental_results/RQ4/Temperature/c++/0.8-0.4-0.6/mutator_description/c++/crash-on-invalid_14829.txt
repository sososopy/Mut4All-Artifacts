Mutation Operator: Alter Variadic Operator Overloading in Struct

Target Code Construct: Struct with overloaded operators

Mutation Rule:
1. Identify a struct that includes overloaded operator functions, particularly those involving variadic templates or variadic operators.
2. Locate an overloaded operator function that uses the variadic operator, typically denoted by '...'.
3. Modify the function signature of the variadic operator overload by changing its visibility or by changing the parameter list.
4. Ensure that the variadic overload is used in an expression or assignment within the code to enforce evaluation.

Step-by-step Instructions:
- Identify a struct definition that includes friend functions for operator overloading.
- Within the struct, locate a friend function declaration for a variadic operator, such as `friend void operator,(StructName, ...);`.
- Modify the visibility of the variadic overload function from private to public (if applicable) or change the parameter list by adding a non-variadic parameter before variadic parameters.
- Use this overloaded operator in an expression involving the struct, ensuring the expression can be executed.

Example:
Consider a struct defined as follows:
```
struct ExampleStruct {
  friend void operator,(ExampleStruct, int);
private:
  friend void operator,(ExampleStruct, ...);
};
```

Mutation:
- Modify the variadic operator function declaration from:
  `friend void operator,(ExampleStruct, ...);`
  to:
  `public: friend void operator,(ExampleStruct, int, ...);`

- Apply the operator in an expression:
  `ExampleStruct example;`
  `int result = (example, 42, "string");`

By making these changes, the modified code increases the likelihood of triggering a crash in the compiler's handling of overloaded variadic operators, particularly due to visibility or parameter list inconsistencies.
