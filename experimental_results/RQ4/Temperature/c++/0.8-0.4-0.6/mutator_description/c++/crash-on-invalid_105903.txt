Mutation Operator: Empty Template Parameter Pack Access

Target Code Construct: Function template specialization in a class or struct template.

Mutation Rule:
1. Identify a function template defined within a class or struct template that uses a template parameter pack.
2. Attempt to access an element of the parameter pack using an index in the return type of the function.
3. Ensure that the template parameter pack is empty when the function is instantiated.

Step-by-Step Instructions:
- Locate a class or struct template definition that includes a function template. The function template should have a return type derived from a template parameter pack.
- Modify the function template to include an expression in its return type that indexes into the template parameter pack. For instance, if the parameter pack is named `Params`, the function might have a return type like `Params...[index]`.
- Ensure that when the class or struct template is instantiated, the template argument list for the parameter pack is empty.
- Instantiate the function template with an index, such as zero, to access the non-existent element of the empty parameter pack.

Example:
Consider the following pseudo-code to illustrate the mutation:

```cpp
template <typename... Params>
struct Container {
    template <unsigned Index>
    static auto get() -> Params...[Index] { return {}; } // Attempt to index into parameter pack
};

void example() {
    Container<>::get<0>(); // Instantiate with empty parameter pack
}
```

In this example, the `Container` struct template includes a function template `get` that attempts to access an indexed element of the template parameter pack `Params`. The function is instantiated with an empty parameter pack and accesses the zeroth index, triggering the compiler bug.
