
Mutation Operator: Template Instantiation with Incorrect Nested Types

Target Code Construct: Template declaration and usage, specifically involving the nested type references in templates.

Mutation Rule:
1. Identify a template class or struct that is defined in the seed program.
2. Locate an instance of the template where a nested type is being used as a template parameter. For example, `TemplateClass<NestedType<int>::type>`.
3. Modify the nested type usage to include an unmatched angle bracket, making it syntactically incorrect. For example, transform `TemplateClass<NestedType<int>::type>` to `TemplateClass<NestedType<int>::type>>`.
4. Ensure that the altered template instance is within a valid context where it could otherwise compile, such as within a function return type or a function parameter list.

Example Before Mutation:
```

struct Wrapper {};

struct Example {
  static Wrapper<Nested<int>::type> createInstance();

```

Explanation:
This mutation targets the use of templates with nested types. By introducing an extra angle bracket, it creates a syntactical error that might expose compiler vulnerabilities in handling malformed template syntax. This kind of mutation leverages the compiler's parsing and type-checking mechanisms, which are often complex and prone to edge case failures, thus increasing the likelihood of triggering a bug.
