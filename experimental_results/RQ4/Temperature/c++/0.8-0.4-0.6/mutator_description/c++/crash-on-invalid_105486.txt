Mutation Operator: Modify Usage of Indirection Operator

Target Code Construct: Indirection operation applied to literals or non-pointer expressions.

Mutation Rule:
1. Identify any occurrence where the indirection operator (*) is applied directly to a literal value or non-pointer expression. For example, *0 or *42.
2. Change the indirection operation to apply to a valid pointer instead. If no pointer is available in the context, declare a new pointer variable and initialize it with an address of an existing variable.
3. Replace the original expression with the dereferencing of this newly declared or existing pointer.

Example:
Original Code:
```
int n = *0;
```

Mutated Code:
```
int validVar = 10;
int* ptr = &validVar;
int n = *ptr;
```

Description: This mutation operator targets the misuse of the indirection operator on non-pointer values, which commonly causes compiler crashes due to invalid dereferences. The mutation ensures the operator is applied to a valid memory address, thus increasing the robustness of the code and potentially exposing other issues related to pointer handling. The mutation also involves using existing variables when possible, and only introduces new elements when necessary, following clear and unambiguous declarations.
