Mutation Operator: Template Specialization with Incomplete Type

Target Code Construct: Template function involving template specialization

Mutation Rule:
1. Identify a template function in the seed program that takes a template parameter. For example:
   ```cpp
   template<class T> void func(TemplateClass<T> param);
   ```

2. Modify the function call to specialize the template with an incomplete type, such as a forward-declared class or structure. Forward declaration means declaring a type without defining it. For example:
   ```cpp
   class IncompleteType; // Forward declaration

   void test() {
       func(TemplateClass<IncompleteType>()); // Specialization with an incomplete type
   }
   ```

3. Ensure the incomplete type remains incomplete in the scope of the function call. Do not provide a definition elsewhere in the code.

Explanation:
Specializing template functions or classes with incomplete types can lead to undefined behavior or compiler crashes, as the compiler may attempt to instantiate templates with insufficient information. This operator targets the handling of incomplete types during template instantiation, a common area where compilers can exhibit bugs or crashes.
