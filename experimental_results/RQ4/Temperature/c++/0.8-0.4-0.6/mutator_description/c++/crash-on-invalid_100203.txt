Mutation Operator: Template Argument-Arity Mismatch

Target Code Construct:
This mutation operator targets function templates with variadic template parameters. It applies to any function template instantiation that involves variadic template arguments.

Mutation Rule:
1. Identify a function template that uses variadic template arguments, e.g., `template <typename... Ts>`.
2. Locate a function call that invokes this template with specific template arguments.
3. Modify the number of template arguments provided in the function call to create an arity mismatch, ensuring the number of arguments does not match the number of template parameters expected. Specifically, remove or add template arguments while keeping the call itself syntactically valid.

Example:
Original Code:
```cpp
template <typename... Ts> void func(Ts&&... args) {}
void caller(int x) { func<int, double>(x); }
```

Mutated Code:
```cpp
template <typename... Ts> void func(Ts&&... args) {}
void caller(int x) { func<int, int, double>(x); }
```

In this example, the mutation adds an extra template argument to `func<int, int, double>(x);`, disrupting the expected arity for the template arguments.
