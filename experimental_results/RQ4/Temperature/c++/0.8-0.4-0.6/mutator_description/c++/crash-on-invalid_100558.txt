Mutation Operator: Modify Lambda Return Type

Target Code Construct: Lambda Expressions within Function Bodies

Mutation Rule:
1. Identify a lambda expression in the seed program.
2. Check the return type of the lambda function. If it is a specific type (e.g., `int`, `float`), modify the return type to a function type that takes parameters (e.g., `int(int)`).
3. Ensure that lambda's return statement or logic is compatible with the modified return type by introducing a function pointer or a temporary function definition within the lambda.
4. If necessary, update any use of the lambda to handle the new return type appropriately.

Example:
Original Lambda:
```cpp
[] (int x) -> int {
    return x * 2;
}
```

Mutated Lambda:
```cpp
[] (int x) -> int(int) { // Change return type to function type
    auto tempFunc = [](int y) { return x * y; }; // Temporary function
    return tempFunc; // Return the temporary function
}
```

This mutation operator targets the return type of lambda expressions by changing them to function types, which can lead to scenarios where compilers may not handle the mutation gracefully, potentially triggering a crash or producing unexpected behavior. The lambda logic is then adapted to accommodate the new return type, providing a comprehensive test for compiler robustness.
