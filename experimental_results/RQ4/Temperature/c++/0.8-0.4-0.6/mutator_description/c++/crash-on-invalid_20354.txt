Mutation Operator: Variable Shadowing within Function Scope

Targeted Code Construct: Function and variable declarations within the function scope.

Mutation Rule:
- Identify a function with parameters and an internal variable declaration.
- Inside the function, introduce a shadowing variable by declaring a local variable with the same name as an existing parameter.
- Ensure the shadowing variable is declared as an extern variable.

Step-by-Step Instructions:
1. Locate a function definition that accepts parameters.
   Example: 
   ```
   void exampleFunction(int a) {
       // existing code
   }
   ```

2. Within the body of this function, declare a local variable with the same name as one of the function's parameters using the `extern` keyword.
   Example:
   ```
   void exampleFunction(int a) {
       extern int a; // This declares a shadowing variable
       // existing code
   }
   ```

3. Ensure there is no initialization for the extern variable declaration to introduce a valid but potentially problematic shadowing scenario.

Explanation:
This mutation leverages variable shadowing within a function, especially using the `extern` keyword, which can confuse the linker or cause undefined behavior in certain compilers. The mutation targets the function scope where parameter names are reused, potentially leading to internal compiler errors during the linkage or name resolution phase.
