Mutation Operator: Default Template Argument in Function Templates

Target: Function Templates with Default Template Arguments

Mutation Rule:
1. Identify a function template in the seed program that has template parameters.
2. If no default template argument is specified for any of the template parameters, select one template parameter to modify.
3. Introduce a default template argument for the selected template parameter.
4. Ensure that the default argument is of a type or value that exists or can be derived from existing elements in the seed program.

Example:
Before Mutation:
```cpp
template<typename T>
void foo(T param) {
    // function body
}
```

After Mutation:
```cpp
template<typename T = int>
void foo(T param) {
    // function body
}
```

Explanation:
- The mutation specifically targets function templates, focusing on adding default template arguments.
- By introducing a default template argument, the mutation may reveal parsing issues or mismanagement of template defaults by the compiler.
- The mutation uses an existing simple type, `int`, as a default argument, ensuring that it is universally applicable across various seed programs without requiring additional declarations.
