Mutation Operator: Incomplete Initializer in Struct or Union

Target: This mutation operator targets unions or structs with member initializations in their declarations.

Mutation Rule:
1. Identify a union or struct declaration in the seed program.
2. Within this union or struct, locate a member that is initialized directly in its declaration.
3. Modify the initializer by removing its value, leaving only the assignment operator.
4. Ensure that only existing members of the union/struct are manipulated and that no new members are introduced.

Example:
Original Code:
```
struct S {
  int x = 10;
};
```

Mutated Code:
```
struct S {
  int x = ;
};
```

This mutation introduces an incomplete initializer, which can trigger compiler crashes or diagnostic errors related to incomplete initializations.
