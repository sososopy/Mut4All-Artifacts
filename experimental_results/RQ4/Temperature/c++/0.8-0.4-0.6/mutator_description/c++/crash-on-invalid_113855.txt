Mutation Operator: Union Initialization Overload

Target Construct: Union

Applicable Context: This mutation applies to any union type in a seed program.

Mutation Rule: The mutation aims to trigger potential compiler bugs by initializing a union with more than one member using both unnamed and named initializers. Here’s how to perform the mutation:

1. Identify a union declaration in the seed program. Ensure the union has at least two member variables of different types (e.g., an integer and a float).

2. Locate any instance in the code where the union is being initialized or used, or create a new instance if none exists.

3. Modify the initialization statement to include multiple initializers within the braces. Use both unnamed and named initializers.

4. Example Transformation:
   - Original Code:
     ```
     union U {
         int a;
         float b;
     };

     void function() {
         U u_instance = {1}; // Proper initialization with one member
     }
     ```

   - Mutated Code:
     ```
     union U {
         int a;
         float b;
     };

     void function() {
         U u_instance = {1, .b = 2.0}; // Mutated initialization with more than one member
     }
     ```

Explanation: This mutation operator exploits the fact that unions should only be initialized with one member at a time. By providing multiple initializers, especially mixing unnamed and named initializers, it increases the likelihood of triggering assertion failures or other compiler-handling bugs related to initialization list interpretation in union types.
