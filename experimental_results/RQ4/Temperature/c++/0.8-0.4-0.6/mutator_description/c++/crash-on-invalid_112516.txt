Mutation Operator: Template Instantiation with Non-Type Template Parameter

Targeted Code Construct: Template function

Mutation Rule:
1. Identify a non-template function in the existing code, for example, a function that takes one or more parameters and returns a value.
2. Transform the function into a template function by introducing a non-type template parameter. This parameter should be of a type that matches an existing variable or literal used within the function.
3. Replace a literal or variable within the function body with the non-type template parameter.

Example:
Original Function:
```
int calculateSum(int x, int y) {
    return x + y;
}
```

Mutation Steps:
1. Introduce a non-type template parameter of the same type as an existing parameter:
   ```
   template<int N>
   int calculateSum(int x, int y) {
       return x + y;
   }
   ```
2. Replace a literal used in the function with the template parameter:
   ```
   template<int N>
   int calculateSum(int x) {
       return x + N;
   }
   ```
3. Use the template function with a specific literal value for the template parameter:
   ```
   int result = calculateSum<5>(10);
   ```
This mutation targets potential errors related to template specialization and incorrect handling of non-type template parameters, increasing the likelihood of compiler crashes.
