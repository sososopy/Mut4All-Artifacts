Mutation Operator: Modify Function Argument Types

Target Code Construct:
This mutation operator targets function call expressions, specifically those involving `std::make_tuple`.

Mutation Rule:
1. Identify a function call expression using `std::make_tuple` or similar where template arguments are provided. In the bug report, this is `std::make_tuple<int, double>(0, "test")`.
2. Modify one or more template argument types to be intentionally incorrect or mismatched with the provided arguments within the tuple creation. This is to simulate a common error where the expected types do not match the actual types of the arguments supplied.
3. Ensure that the modified types are logically inconsistent with the provided arguments, such as changing to an incompatible or incorrect type.

Example in Pseudo-code:
Original:
```
f(std::make_tuple<int, double>(0, "test"));
```
Mutated:
```
f(std::make_tuple<int, std::string>(0, "test"));
```

Explanation of Mutated Content:
In this mutation, the second template argument `double` was changed to `std::string`. This creates a mismatch, as the provided argument `"test"` is a `const char*` type, leading to a potential issue in the system's type resolution and overload resolution logic. By doing this, we can trigger a compiler's robustness test for handling such invalid template instantiations, which may lead to crashes if not properly handled.
