Mutation Operator: Misordered Embed Directive Parameters

Target: Preprocessor Embed Directives

Mutation Rule:
1. Identify the #embed directive in the source code. This directive is followed by parameters enclosed with specific known keywords (such as __FILE__, limit) and unknown parameters.
2. Intentionally reorder the parameters so that a known parameter (e.g., __FILE__) comes after an unknown or incorrectly formatted parameter.
3. Ensure the directive still follows the #embed keyword.

Example:
Original:
```
#embed __FILE__ limit(2) unknownParam(3)
```

Mutation:
```
#embed unknownParam(3) __FILE__ limit(2)
```

In this mutation, the known parameter "__FILE__" is placed after an unknown parameter "unknownParam(3)".
