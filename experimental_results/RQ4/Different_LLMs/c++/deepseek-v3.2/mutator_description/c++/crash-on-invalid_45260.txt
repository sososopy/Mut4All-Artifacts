Mutation Operator: Corrupt Template Deduction Guide Syntax

Target: Template deduction guide declarations in C++17 or later.

Description: This mutation corrupts the syntax of a template deduction guide by altering the declaration pattern. It applies when a template class (with at least one template parameter) is present in the program and a deduction guide for it could plausibly exist. The mutation modifies an existing deduction guide or inserts a malformed one if no guide exists. The corruption involves omitting or scrambling key syntactic elements.

Procedure:
1. Identify a template class declaration in the seed program (e.g., `template<typename T> class Container;`).
2. Locate or create a context after this declaration where a deduction guide could be placed (e.g., near the class definition or in the same scope).
3. Generate a corrupted deduction guide string. For the template class named `Container`, a valid guide might be `Container(T) -> Container<T>`. The mutation will produce a malformed variant such as:
   - `Container() Container c;` (omitting the parameter list arrow and result type, adding a nonsensical declarator).
   - `Container Container -> ;` (repeating the name, missing parameter list and result type).
   - `Container(T) ->` (missing result type).
   - Use the exact template class name from the seed; do not introduce new names like 'b'. The corruption should use elements from the seed: the template class name and, if available, a template parameter name (e.g., `T`). Do not introduce undeclared variables or types.
4. Insert this corrupted declaration into the code at an appropriate point (e.g., immediately after the template class declaration or before any use of the class).

Example (Seed Program):
template<typename T> class Box {
public:
    Box(T elem) : content(elem) {}
private:
    T content;
};
Box(T) -> Box<T>; // Existing valid deduction guide.

Mutated Program:
template<typename T> class Box {
public:
    Box(T elem) : content(elem) {}
private:
    T content;
};
Box() Box c; // Corrupted deduction guide inserted, using the existing class name 'Box'.

Note: The mutation introduces a malformed syntax pattern that resembles the bug report's pattern (`b() b c;`). It uses only names and types present in the seed (e.g., `Box`). No new variables, types, or functions are declared; the corruption is purely syntactic, creating an invalid C++ construct likely to trigger parser crashes in compilers with deduction guide handling bugs.
