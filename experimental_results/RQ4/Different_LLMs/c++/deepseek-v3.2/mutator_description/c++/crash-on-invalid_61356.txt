Mutation Operator: Incomplete Template Class Forward Declaration Mutation

This mutation operator targets incomplete forward declarations of template classes, specifically those missing a required template argument list or having mismatched template parameters. It applies when a template class is forward-declared before its full definition.

The mutation modifies the forward declaration by altering the template parameter specification to be incomplete or mismatched relative to the actual class template definition. For example, if the original code contains a forward declaration like `template <typename T> class ClassName;`, the mutation may change it to `template <typename T> class ClassName<T, true>;` where `ClassName` is actually defined with only one template parameter later. Alternatively, it may change `template <typename T, bool B> class ClassName;` to `template <typename T> class ClassName<T>;` omitting the second parameter.

To implement this mutation, identify any forward declaration of a template class in the seed program. Examine the full definition of that template class later in the code to determine its correct template parameter list. Then, modify the forward declaration by either adding extra template arguments not present in the definition, removing required arguments, or changing the number or types of parameters. Use only the class name and template parameter names that already exist in the seed program. Do not introduce new type names or variable names.

For example, if the seed program has:
```
template <typename U> class MyClass;
template <typename U>
class MyClass {
    U member;
};
```
The mutation could produce:
```
template <typename U> class MyClass<U, false>;
template <typename U>
class MyClass {
    U member;
};
```
Here, the forward declaration incorrectly adds a second template argument `false` which does not match the actual definition. This creates an inconsistency that may trigger compiler crashes during parsing or instantiation. Ensure the mutated forward declaration uses only `MyClass` and `U` from the original code, and the additional argument `false` is a boolean literal permissible in the context.
