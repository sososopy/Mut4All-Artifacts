Mutation Operator: Replace a trivial class type within a union member with a non-trivial class type in a template context.

This mutation applies when a union contains a member of a trivial class type (e.g., a struct/class with only trivial members or an empty class) and this union is used inside a class template instantiation. The operator changes that member's type to a non-trivial class type, such as one with a user-defined constructor, destructor, copy/move operations, or virtual functions.

Where it applies: It targets unions declared within the scope of a class template (or a template member). The seed program must contain a union definition with at least one member of a trivial class type. The mutation modifies that specific member's type declaration.

Changes: Identify a union `U` within a class template `T`. Within `U`, locate a member declaration of type `C`, where `C` is a trivial class (e.g., defined as `struct C {};`). Mutate by replacing `C` with a non-trivial class type `N`. To create `N`, if a non-trivial class already exists in the seed program, use that type. If not, introduce a new class `N` with a user-provided default constructor (e.g., `N() {}`) and ensure it is declared before the union. The mutation changes only the member type in the union; the rest of the union and template remains unchanged.

Example: Original template snippet:
template<typename X>
class MyTemplate {
    union Inner {
        int i;
        struct TrivialStruct {} ts;
    } u;
};
Mutated version (if no non-trivial class exists, add declaration):
struct NonTrivial { NonTrivial() {} }; // introduced if needed
template<typename X>
class MyTemplate {
    union Inner {
        int i;
        NonTrivial nt; // replaced from TrivialStruct ts
    } u;
};
