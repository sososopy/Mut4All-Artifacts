mutation operator: replace initializer_list begin() call with raw array begin() call.
targets initializer_list objects used in contexts where begin() is called, specifically when the initializer_list is an r-value.
applies to code where std::initializer_list<T>::begin() is invoked on a temporary initializer_list object.
change: for an expression of the form std::initializer_list<T>{...}.begin(), replace it with (T*)(std::initializer_list<T>{...}).begin(). this casts the initializer_list's internal array pointer type directly.
example: if seed code contains auto it = std::initializer_list<int>{1,2,3}.begin(); mutate to auto it = (int*)(std::initializer_list<int>{1,2,3}).begin();.
note: uses existing std::initializer_list type and values from seed. introduces a cast to pointer type T* which should be valid as initializer_list stores a contiguous array. this mutation exposes potential compiler bugs in handling r-value initializer_list iterator access.
