Mutation operator: Template friend injection with contradictory static assertions.
This mutation applies when a class template contains a templated friend function definition inside its body. It modifies the friend function to include two contradictory static_assert statements based on the same condition, and uses a template parameter from the friend function in a context that may cause an internal compiler error. Specifically, it targets the friend function definition within the class template.

For a seed program containing a class template with a templated friend function, locate such a structure. Within the friend function body, insert two static_assert statements: one asserting that a condition is true, and another immediately after asserting the same condition is false. The condition should involve a template parameter from the friend function's template parameter list, such as checking the size of a parameter pack. Additionally, use a template parameter value in a potentially problematic context, like passing it as a non-type template argument to an existing function call. Ensure the static_assert messages are generic and do not reference specific names from the bug report.

Example: If the seed has a class template 'C' with a friend function 'helper' taking a parameter pack 'Ts', change it to:
    template<class... Ts>
    friend void helper() {
        static_assert(sizeof...(Ts) > 0, "condition true");
        static_assert(sizeof...(Ts) == 0, "condition false");
        existing_function<sizeof...(Ts)>();
    }
Use existing function names and types from the seed. If no suitable function exists for the call, declare a simple template function like 'template<int N> void dummy() {}' and use 'dummy<sizeof...(Ts)>();'. The mutation should be applied only once per eligible class template.
