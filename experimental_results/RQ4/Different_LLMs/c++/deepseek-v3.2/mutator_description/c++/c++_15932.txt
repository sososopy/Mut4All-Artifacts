mutation operator: Expand Template Recursion Depth Beyond Compiler Limits

This mutation operator targets function template instantiations that involve recursion or deep nesting. It applies when a function template is defined with a non-type template parameter that controls recursion depth, such as through integer template arguments or constexpr values. The operator increases the recursion depth by incrementing the parameter value used during instantiation, pushing it beyond typical compiler thresholds for recursion optimization or stack management during compilation.

Specifically, locate any template function invocation where a non-type template argument is an integer literal or a constexpr integer variable. Replace that argument with a larger value, typically by adding a fixed offset (e.g., +1, +5, or +10) or doubling it, ensuring the new value remains within the domain of the template's logic (e.g., positive if required). Prefer to use existing constant expressions from the seed program to determine the increment; if none exist, introduce a small literal like 1.

Example: In a seed program with `template<int N> int factorial() { return N * factorial<N-1>(); }` and an instantiation `factorial<5>()`, mutate to `factorial<6>()` or `factorial<10>()`. For a constexpr variable `constexpr int depth = 8;` used as `factorial<depth>()`, mutate to `factorial<depth+1>()`.
