mutation operator
Target: Partial specialization of a class template where the specialization does not use any of the primary template's template parameters. This applies when a class template has at least one template parameter and a partial specialization is defined. The mutation changes the partial specialization to remove all references to the primary template's parameters in the specialization's template argument list and potentially in its member definitions, creating a scenario where the specialization is independent of the primary template's parameters. The mutation should only be applied if the seed program contains a class template with a partial specialization that currently uses at least one template parameter from the primary template. The goal is to transform it into a partial specialization that does not use any, mimicking the bug-triggering condition.

Change: For a given partial specialization of a class template, modify its template argument list to be a fixed type or value that does not depend on the primary template's parameters. Specifically, if the partial specialization originally had a template parameter list like template<typename T> class Primary<T, int>, and it uses T in the specialization, change it to something like template<> class Primary<ExistingType, int>, where ExistingType is a concrete type already present in the seed program (e.g., int, float, or a user-defined type from the program). If no suitable existing type is available, introduce a new type alias (e.g., using DummyType = int;) at an appropriate scope before the specialization. Ensure the specialization's body remains unchanged or adjust any member references that originally depended on the removed parameter to use the fixed type instead, avoiding undeclared identifiers.

Example: Suppose the seed program has: template<typename U, typename V> class Widget { }; template<typename U> class Widget<U, double> { U member; };. After mutation, it could become: template<typename U, typename V> class Widget { }; template<> class Widget<int, double> { int member; };, where int is chosen because it exists in the program. Alternatively, if the program has a type alias like using MyType = char;, use MyType instead. The mutation operator must select an existing type from the seed program to replace the template parameter, ensuring compilation can proceed up to the point of triggering the bug.
