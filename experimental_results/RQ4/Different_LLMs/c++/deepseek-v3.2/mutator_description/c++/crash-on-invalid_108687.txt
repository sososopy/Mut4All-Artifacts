Mutation operator: Replace static_assert expression with empty string literal.

This mutation operator applies to static_assert declarations in C++ code. It targets the second argument, the message string, within any static_assert statement found in the seed program. The operator replaces the existing message string literal, regardless of its original content, with an empty string literal (""). The first argument, the constant expression, remains unchanged. This mutation should be applied to every static_assert declaration encountered.

Example: If the seed program contains `static_assert(sizeof(int) == 4, "int size mismatch");`, after mutation it becomes `static_assert(sizeof(int) == 4, "");`. Only the message part is altered; the condition and the structure of the static_assert declaration are preserved. This operator uses existing elements from the seed program, specifically the static_assert declaration itself, and modifies only its string literal argument to an empty one, which is a valid but potentially problematic construct as indicated by the bug report.
