Mutation operator: Replace parentheses initializer list with brace initializer list in class member initialization within nested class templates.

This mutation operator applies to C++ class member initialization expressions that use parentheses list initialization (CXXParenListInitExpr) within nested class templates or dependent contexts. Specifically, when a member variable inside a nested class (e.g., a struct or class within another class) is initialized using parentheses, we replace it with brace initialization.

The operator should be applied to any instance where a member variable is initialized using parentheses in a class definition, especially when the class is nested within another class or template. For example, if the seed program contains a nested struct with a member initialized via parentheses, such as:

struct Outer {
    struct Inner {
        int member = (value);
    };
};

We mutate the parentheses initialization to brace initialization:

struct Outer {
    struct Inner {
        int member = {value};
    };
};

If the parentheses list contains multiple values, like (value1, value2), we change it to {value1, value2}. The operator should only apply when the initialization is inside a class member declaration and uses parentheses directly. If the seed program does not contain such a construct, the operator does nothing. We use existing variables and types from the seed program; no new elements are introduced. This mutation targets scenarios that trigger CXXParenListInitExpr handling during template instantiation, as seen in the bug report.
