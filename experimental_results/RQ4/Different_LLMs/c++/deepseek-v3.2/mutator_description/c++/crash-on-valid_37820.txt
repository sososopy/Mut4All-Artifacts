mutation operator: replace switch condition with a user-defined conversion to enum type

This mutation applies when a switch statement uses a variable of class type that has a user-defined conversion operator to an enum type. The mutation replaces the switch condition with an explicit static_cast to the target enum type, invoking the user-defined conversion.

For a given switch statement of the form:
switch (condition_variable) { ... }

If condition_variable is of a class type CLS that has a conversion operator to an enum type ENUM, the mutation changes it to:
switch (static_cast<ENUM>(condition_variable)) { ... }

The types CLS and ENUM must already be present in the seed program. The mutation only applies when the original condition_variable is not already of an integral or enum type and when such a conversion operator exists. This targets compiler bugs related to constant expression evaluation in switch cases after user-defined conversions.
