Mutation Operator:  
Replace a static data member template instantiation with a dependent deduced type by substituting the deduced type with an explicit type that is dependent on the same template parameter but using a different form of type deduction or substitution pattern.  

Target:  
This applies when a static data member template is declared with a deduced type (e.g., using auto or decltype) that depends on a class template template parameter. The mutation changes the deduced type to an explicitly specified dependent type that preserves the dependency but alters the deduction context.  

Changes:  
1. Locate a static data member template definition or declaration within a class template where the member's type is deduced (e.g., via auto or decltype) and depends on a template parameter of the enclosing class.  
2. Replace the deduced type with an explicit type that is derived from the same template parameter but uses a different type transformation, such as:  
   - If the original uses decltype(expression involving template parameter), change it to a type alias or a nested type that is defined in terms of the template parameter.  
   - If the original uses auto, replace it with a dependent type like typename enclosing_class::template nested_type if available, or otherwise with a type that is directly the template parameter itself or a pointer/reference to it.  
3. Ensure the new type is still dependent on the template parameter to maintain similar parsing complexity.  

Example:  
Original pseudo-code in seed program:  
template<typename T>  
struct S {  
    static auto value = expression_dependent_on_T;  
};  

Mutated version:  
template<typename T>  
struct S {  
    static decltype(expression_dependent_on_T) value = expression_dependent_on_T;  
};  
Or, if a nested type exists:  
template<typename T>  
struct S {  
    static typename S<T>::nested_type value = expression_dependent_on_T;  
};  

Note: Use existing types or declarations from the seed program; if introducing a new nested_type, it must be previously defined within the class template or its bases. Avoid ambiguous or invalid constructs.
