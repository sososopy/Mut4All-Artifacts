Mutation Operator: Recursive Template Instantiation with Lambda in Return Type Deduction Context

This operator targets code constructs involving recursive template instantiation where a lambda expression is used in a context that triggers return type deduction (e.g., as a default argument, initializer, or within a return statement), specifically within a function template body. It applies to function templates that are called recursively, either directly or indirectly via their own definition.

The mutation introduces a recursive call to the same template function, where the argument is a lambda expression with an empty body. This call is placed in a context that requires the compiler to deduce a type involving the lambda, such as using `auto` return type deduction for a variable initialized with the recursive call, or as part of a return statement in a function that itself uses type deduction.

For adaptation to seed programs, identify a function template (call it `curry` for illustration) that takes at least one parameter. Within its body, add a new statement: `auto recursive_var = curry([]{});`. This creates a recursive instantiation with a lambda argument. Ensure the template is already declared; if not, declare a simple template `template<typename T> void curry(T t) {}` as a base. The lambda `[]{}` is a new element, but it uses the standard lambda syntax which does not require additional declarations. The variable `recursive_var` should be of deduced type `auto` to force the compiler to handle the lambda's type in the recursive context.

Example mutation in pseudo-code: In a seed program containing `template<typename A> void f(A a) { /* existing code */ }`, insert inside the function body: `auto recursive_call = f([]{});`. This creates a recursive template instantiation `f<lambda>` within `f`, where the lambda type is used in `auto` deduction.
