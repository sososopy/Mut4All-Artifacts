Mutation operator: Replace nested template argument with erroneous double closing angle bracket sequence.

This mutation applies to template arguments that involve nested template instantiations or dependent types. It targets situations where a template argument itself contains a template specialization, such as `SomeTemplate<Inner<Type>::member>`.

When such a structure is present, the mutation changes the closing part of the outer template argument list by appending an extra closing angle bracket (`>`), creating a sequence like `>>` where the compiler must parse it as either two separate closing brackets or a single shift operator. Specifically, it modifies the end of the template argument list from `>` to `>>`.

For example, if the seed program contains:
```
template<typename T>
struct Outer {};
struct Container {
    static Outer<Inner<int>::value> func();
};
```
The mutation would produce:
```
template<typename T>
struct Outer {};
struct Container {
    static Outer<Inner<int>::value>> func();
};
```
Here, `Inner<int>::value>` is the original template argument for `Outer`. The mutation adds an extra `>` after the existing one, resulting in `Inner<int>::value>>`. This creates an ill-formed construct because the `>>` appears where a single `>` is expected to close the `Outer` template argument list, potentially leading to parsing confusion.

The operator only uses existing template names (`Outer`, `Inner`) and types (`int`) from the seed. No new elements are introduced. The change is solely the insertion of one additional `>` character at the designated position in the source code.
