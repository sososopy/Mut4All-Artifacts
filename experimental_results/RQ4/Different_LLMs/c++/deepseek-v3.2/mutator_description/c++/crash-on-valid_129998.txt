mutation operator: Replace template argument deduction context with alias template substitution in variable declarations using class template argument deduction (CTAD). This operator targets variable declarations where CTAD is used and the deduced type involves a template alias that maps to a complex template specialization. It applies when a variable is declared using CTAD (type name omitted, using constructor arguments) and the deduced type is an alias template that itself refers to a class template with non-type template arguments derived from the initializer expressions. The mutation changes the variable declaration to explicitly use the alias template with placeholder arguments that force substitution through the alias during deduction. Specifically, for a variable declaration of the form 'identifier { initializer-list };' or 'identifier ( initializer-list );' where the type is deduced via CTAD to some type T, if T is an alias template (template alias) that resolves to a class template specialization, replace the declaration with 'alias-template-name<auto...> identifier { initializer-list };' where 'auto...' is a pack of placeholder types matching the number of template parameters expected by the alias template. This forces the compiler to perform deduction through the alias template, which may trigger bugs in template argument deduction for non-type template arguments. Use existing alias templates from the seed program; if none exist, introduce a simple alias template such as 'template<auto X> using alias = integral_constant<decltype(X), X>;' but only if the seed program includes std::integral_constant or similar. Ensure the mutation does not introduce undeclared identifiers; if the alias template is not present, skip mutation. Example: Original code has 'extents t2{constant<1>{},2};' where extents is an alias template. Mutated code becomes 'extents<auto, auto> t2{constant<1>{},2};' (since extents expects two template arguments). This changes the deduction path to go through the alias template directly.
