mutation operator: Replace a default-constructed object with a zero-initialized object in contexts involving template type deduction and constructor overload resolution. This mutation targets code constructs where a type is used in a context that expects a constructor call, particularly within templates where the type's constructors are not fully resolved until instantiation. It applies when a variable or temporary object is default-constructed using empty braces '{}' in a template-dependent context. The mutation changes the default construction to a zero-initialization using '0' or a null pointer constant appropriate for the type, aiming to trigger different constructor resolution paths and potentially expose bugs in the initialization sequence during template instantiation. For example, if the seed program contains a line like 'T var{};' within a template, mutate it to 'T var = 0;' if T is an arithmetic or pointer type, or introduce a cast if necessary. If T is a class type, mutate to 'T var = T(0);' assuming a constructor exists that can take a single integer argument, otherwise introduce a suitable zero-initialization based on existing constructors. The mutation should only use types and functions already present in the seed program; do not introduce new declarations. The change should be applied to all default-constructed objects in template-dependent code where the type is not fully known at mutation time.
