Mutation Operator: Replace `constexpr` with `const` in deleted member function declarations.

Target: This mutation applies specifically to member function declarations that are explicitly marked as `constexpr` and also have the `= delete` specifier. It only modifies the `constexpr` keyword, replacing it with `const`. The mutation should be applied when a class or struct member function (including operators) is declared with both `constexpr` and `= delete`. The function’s signature (return type, name, parameters) remains unchanged.

Description: In the seed program, locate any member function declaration within a class or struct definition where the function is declared as `constexpr` and is also explicitly deleted using `= delete`. Replace the keyword `constexpr` with `const`. This mutation changes the function’s qualifier from a constexpr function to a const member function while retaining its deleted status.

Example: If the seed program contains:
class Example {
public:
    constexpr Example& operator=(const Example&) = delete;
};
After mutation, it becomes:
class Example {
public:
    const Example& operator=(const Example&) = delete;
};

Implementation Steps:
1. Parse the program to identify class or struct definitions.
2. Within each definition, scan member function declarations.
3. For each declaration, check if it contains the keyword `constexpr` and the specifier `= delete`.
4. If both conditions are met, replace `constexpr` with `const`.
5. Ensure no other parts of the declaration are altered; the function name, return type, parameter list, and `= delete` remain exactly as in the original seed.

Note: The mutation uses existing elements from the seed program (the class name, function name, types). No new variables, types, or functions are introduced. The change is limited to swapping one keyword for another within the existing declaration structure.
