Mutation Operator: Misplaced Deduction Guide Insertion
This mutation operator targets class templates that have constructors. It applies when a seed program contains at least one class template with at least one constructor. The operator introduces a deduction guide-like declaration inside a different template class, mimicking the bug scenario. Specifically, it takes a constructor from a template class A and replicates it as a member declaration inside another template class B, without a trailing return type and with a function definition, while keeping the same template parameter names. The operator modifies the body of template class B by adding a line that looks like a constructor of template class A. If the constructor parameters involve types or references, those are preserved as in the original constructor. The mutation uses existing template parameter names and types from the seed program. For example, if the seed has template<typename T> struct Foo { Foo(T& x); } and template<typename U> struct Bar { }; then mutate Bar to have a member declaration: Foo(const U& x) : x(x) {} inside its struct body. This can cause the compiler to misinterpret it as a deduction guide for Foo, potentially triggering parsing errors or crashes similar to the reported bug. The mutation does not introduce new variables or types beyond those already present; it reuses existing template parameters and constructor patterns. The change is made directly in the class definition of the second template.
