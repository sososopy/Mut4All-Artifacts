mutation operator: introduce nullability qualifiers in alias templates

This mutation operator applies to alias template declarations within the seed program. It modifies existing alias templates by inserting nullability qualifiers (such as _Nullable, _Nonnull) into the alias definition. The operator targets alias templates that currently define a simple type mapping without such qualifiers.

The mutation changes the alias template definition from `template <typename T> using Alias = T;` to `template <typename T> using Alias = T _Nullable;`. The qualifier is appended directly to the type parameter in the alias. This transformation should only be applied when the alias template uses a single type parameter as its direct mapped type, and no such qualifier already exists. The qualifier chosen should be one that is supported by the compiler's syntax for pointer or object type annotations, typically found in Objective-C or C++ extensions for nullability. If the seed program does not contain any alias templates, this operator does not apply.

For example, if the seed has `template<typename X> using RefType = X&;`, it could be mutated to `template<typename X> using RefType = X& _Nullable;`. The operator prefers to use _Nullable as the inserted qualifier because it is commonly associated with crash triggers in bug reports. The mutation does not introduce new types or variables; it only adds an existing compiler-specific qualifier to an existing alias template structure. The change is made directly in the alias template definition line.
