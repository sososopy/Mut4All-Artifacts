Mutation Operator: Mutate template argument const qualification in template specialization contexts. This operator applies when a template specialization or partial specialization is used as a function argument type or variable type. The mutation changes a template specialization by adding or removing a top-level const qualifier from one of the template arguments provided to the template. Specifically, for a template specialization `TemplateName<Args...>` appearing in a function parameter declaration, variable declaration, or explicit type instantiation, select one template argument `Arg` that is a non-reference, non-pointer type. If `Arg` does not have a top-level const, add const to create `const Arg`. If `Arg` already has a top-level const, remove it to create the decayed type (e.g., `const int` becomes `int`). This mutation should be applied to existing template specializations in the seed program, using only types and templates already declared. For example, given a function call `f(B<int>())` where `B` is a template and `int` is the template argument, mutate to `f(B<const int>())`. Conversely, given `f(B<const int>())`, mutate to `f(B<int>())`. The change is made at the call site or declaration site, not in the template definition. Ensure the mutated type is used consistently in the immediate context; if the call is part of an initialization, adjust the receiving parameter or variable type accordingly if it is declared locally.
