mutation operator: introduce variable template instantiation with a member of a template class as a template argument. this operator applies when a template class contains a static constexpr member, and a variable template exists that can accept that member as a template argument. the mutation modifies a variable template specialization to replace an existing template argument with a static constexpr member from a template class, or adds such a specialization if none exists. preference is given to using existing variable templates and template classes from the seed program. if no suitable variable template exists, a new variable template is introduced: declare a template with a non-type template parameter pack of reference type, and a constexpr variable template that uses it. the mutation changes the instantiation of the variable template to include a static constexpr member from a template class as one of its arguments. for example, if the seed program contains a template class with a static constexpr member, and a variable template that accepts references, mutate a line that uses the variable template to include that member. as pseudo-code: original code may have a variable template instantiation like `VariableTemplate<Argument1, Argument2>`. mutated code changes to `VariableTemplate<TemplateClassMember, Argument1, Argument2>` or replaces an argument with `TemplateClassMember`, where `TemplateClassMember` is a static constexpr member of a template class like `TemplateClass<...>::member`. ensure the template class is instantiated with a template argument, and the member is accessible. the mutation should be applied in a context where the variable template is being used, such as in a static member initialization or a variable declaration.
