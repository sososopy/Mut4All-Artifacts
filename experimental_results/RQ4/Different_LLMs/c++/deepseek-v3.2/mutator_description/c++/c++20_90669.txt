Mutation operator: Replace a lambda capture by reference in a nested lambda within a template instantiation context with a capture by value, targeting lambda captures that appear in a requires clause or a constraint expression within a template.

This operator applies when a lambda inside a template (e.g., within a generic function or class template) captures a variable by reference, and that lambda is used in a context where template instantiation occurs, such as within a requires expression or a concept constraint. The mutation changes the capture from by-reference to by-value. For example, if the seed program contains a lambda like [&var] within a template's requires clause, mutate it to [var]. This change can alter the variable capture semantics during template instantiation and may expose bugs in the compiler's tryCaptureVariable logic, especially when dealing with nested lambdas and template constraints.
