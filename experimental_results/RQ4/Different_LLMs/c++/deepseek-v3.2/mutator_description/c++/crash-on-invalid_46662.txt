Mutation Operator: Destructor Declaration Removal in Class with Virtual Base

This mutation operator targets class definitions that include a destructor, specifically when the class inherits from a virtual base class. It applies to any class declaration within the seed program that contains a user-defined destructor (either virtual or non-virtual) and has at least one virtual base class.

The operator removes the explicit destructor declaration from the class body. This includes the destructor's definition if it is provided inline within the class. The operator does not introduce any new elements; it only removes existing code. The change must be made directly to the class definition in the source code.

For example, consider a seed program containing:
class Base { public: virtual ~Base() {} };
class Derived : public virtual Base {
public:
    ~Derived() override { /* some code */ }
    // other members...
};

After mutation, the class 'Derived' would become:
class Derived : public virtual Base {
public:
    // ~Derived() removed
    // other members remain...
};

The operator specifically looks for destructors in classes with virtual inheritance. It removes the destructor declaration line entirely, including any associated compound statement if defined inline. If the destructor is declared but defined outside the class (e.g., `~Derived();`), only that declaration line is removed. The goal is to create a class with virtual base inheritance but without an explicitly declared destructor, potentially triggering issues in compiler stages that compute special member functions.
