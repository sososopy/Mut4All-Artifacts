Based on the bug report, the compiler crashes when a lambda is passed to an immediate function (consteval). The bug occurs during template instantiation and constant evaluation. C++ compiler bugs are more likely to trigger with constructs involving: 1. consteval functions (immediate functions). 2. Lambdas within consteval contexts. 3. Template instantiation with non-trivial constant expressions. 4. Interactions between lambda captures and constant evaluation.

Mutation operator: Replace a lambda expression passed to a consteval function with a lambda that captures a variable from the surrounding scope. This applies when a consteval function call accepts a lambda argument. The mutation changes the lambda from having no captures to capturing a local variable by reference. If no suitable local variable exists in the scope, introduce a new variable of a simple type (like int) initialized with a literal (like 0) before the call, and capture it.

Example: Original code: consteval auto f(auto func) { return func(); } int main() { auto result = f([](){ return 42; }); } Mutated code: consteval auto f(auto func) { return func(); } int main() { int x = 0; auto result = f([&x](){ return 42; }); } The mutation adds a capture [&x] to the lambda. The variable x is introduced if not present.
