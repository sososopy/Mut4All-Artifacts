Mutation operator: Replace a template parameter pack with an empty pack in a pack indexing expression. This mutation targets template definitions where a pack indexing operation (using the syntax pack...[index]) is applied to a template parameter pack. The operator applies when the seed program contains a template with a parameter pack and a pack indexing expression referencing that pack. It replaces the pack with an empty pack (i.e., the template is instantiated with zero template arguments) while preserving the pack indexing expression. The mutation is performed by modifying the instantiation of the template to use an empty argument list. For example, if the seed program contains a template like: template<typename... Ts> struct S { using type = Ts...[0]; }; and an instantiation like S<int, char>::type, the mutation changes the instantiation to S<>::type. The pack indexing expression Ts...[0] remains unchanged. The operator should only apply when the template is instantiated with at least one argument in the seed; it replaces that instantiation with an empty instantiation. If the template is used in multiple places, one instantiation is selected and mutated. No new types or variables are introduced; only the template arguments are changed to an empty list. This mutation aims to trigger crashes similar to the reported bug where the compiler fails to handle pack indexing on an empty pack, particularly in contexts like return types or alias declarations.
