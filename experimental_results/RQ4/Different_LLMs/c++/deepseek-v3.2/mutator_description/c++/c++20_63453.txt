Mutation Operator: Replace switch statement condition with an undeclared identifier.

This mutation targets switch statements within constexpr or consteval functions. The operator applies when a switch statement is present inside a function declared with constexpr or consteval. The mutation replaces the condition expression (the expression inside the parentheses of the switch) with a new identifier that is not declared in the current scope. This identifier should be a simple name not used elsewhere in the function. For example, if the seed contains `switch (x) { ... }` where `x` is a declared variable, the mutation changes it to `switch (undeclared_ident) { ... }`, where `undeclared_ident` is a name that does not correspond to any variable, parameter, or function in the local or visible scope. The goal is to create a situation where the compiler must handle an undeclared identifier during constant expression evaluation, potentially triggering internal assertion failures or crashes related to type comparison or constant folding, as seen in the bug report. This mutation should be applied only to switch statements in functions that are contextually evaluated as constant expressions (e.g., functions called in static_assert or constexpr variable initializers).
