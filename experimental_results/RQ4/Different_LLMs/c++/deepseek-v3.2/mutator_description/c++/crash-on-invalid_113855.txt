Mutation operator: Introduce union designated initializer with multiple field initializers.

Target code construct: Union initialization using designated initializers in a new expression.

Where it applies: When a union type is being initialized in a new expression with an initializer list.

Description: Replace a union initializer that initializes a single field with an initializer that attempts to initialize multiple fields using designated initializers. The initializer list should contain designators for more than one member of the union.

Example transformation: If the seed program contains a union type U with members a and b, and an initialization like new U{some_value}, mutate it to new U{.a=value1, .b=value2}. Ensure value1 and value2 are expressions that are valid for the respective member types, using existing variables or literals from the context.

Specific changes: Locate a new expression where the allocated type is a union. Change the initializer list to include designators for at least two different union members. Use existing expressions or literals compatible with the member types. If no suitable expressions exist, use appropriate default literals like 0 for integral types or nullptr for pointer types. Do not introduce new identifiers.
