mutation operator: default argument mutation with invalid forward reference

This mutation operator targets default arguments in function and template member function declarations. It applies when a default argument expression is syntactically valid but semantically invalid due to forward referencing or self-referential evaluation.

For any function or member function declaration containing a default argument expression that uses variables or functions, replace one variable or function call within the default argument with a forward reference to a parameter from the same function's parameter list. If the function has at least one parameter, select the first parameter by name. If the default argument already contains such a reference, create a self-referential call where the default argument invokes itself recursively through a function call or evaluates the same parameter in an invalid context.

Example transformation:
Original: void f(int a, int b = func(a));
Mutated: void f(int a, int b = func(b));

Original: void f(int a = value + 1);
Mutated: void f(int a = a + 1);

Original: template<typename T> void f(T p = T::create());
Mutated: template<typename T> void f(T p = p.create());

The mutation uses only existing parameter names and does not introduce new identifiers. For member functions, the parameter name takes precedence over member names. This creates ill-formed code that may trigger compiler crashes during default argument instantiation or checking, especially in templates.
