Mutation Operator:
Replace a compound literal initializer with an #embed directive that references an existing file.

This operator applies when a compound literal is used to initialize a variable, typically of array or pointer type. The mutation modifies the initializer list within the compound literal by replacing it with an #embed preprocessor directive. The directive must point to a valid, existing file within the context of the seed program's build environment. The goal is to test compiler handling of the C23 #embed feature within a compound literal context, a structure that may expose frontend crashes.

Specifically, locate a compound literal of the form (type){ initializers }. Replace the entire initializer content (the part inside the braces) with #embed "file_path", where file_path should be a path to an existing file. Prefer using a file known to exist in a standard location, such as a header file already included by the seed program or a common system file. If no such file is obviously present, a small dummy file (like an empty file or a file containing a few bytes) should be created in the current directory, and its name used. The mutation changes only the initializer; the compound literal syntax and the variable declaration remain.

Example:
Original: int *arr = (int[]){1, 2, 3};
Mutated: int *arr = (int[]){
#embed "existing_file.bin"
};
Here, existing_file.bin must be a file that exists at the time of compilation. The mutation introduces the #embed directive, which should embed the file's raw contents as the initializer for the array.
