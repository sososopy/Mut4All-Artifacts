mutation operator: Replace a consteval constructor or consteval function call within a constinit variable's initializer with a call to an extern constexpr function that is not defined in the current translation unit. This applies to code where a constinit variable is initialized by a consteval constructor or function. The mutation operator changes the consteval call to an extern constexpr call, ensuring the extern constexpr function is declared but not defined in the seed program. Specifically, for a constinit variable of a class type with a consteval constructor, replace the constructor invocation by inserting an extern constexpr function call inside the constructor body, or if the variable's initializer directly calls a consteval function, replace that call with an extern constexpr function call. In the seed program, if an extern constexpr function is not already declared, add a declaration at global scope: extern constexpr void func();. Then modify the consteval constructor or function to call func(). Example: Original code: struct S { consteval S() {} }; constinit S s; Mutated code: extern constexpr void func(); struct S { consteval S() { func(); } }; constinit S s; This mutation targets the interaction between consteval, constinit, and extern constexpr, which can trigger bugs in the constant expression interpreter.
