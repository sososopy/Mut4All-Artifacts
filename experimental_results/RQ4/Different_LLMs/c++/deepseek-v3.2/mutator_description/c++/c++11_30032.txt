mutation operator: Replace lambda in default member initializer with explicit function object instantiation. This operator applies when a class template member variable is initialized in its default member initializer using a lambda expression. The mutation changes the lambda to a named function object class defined locally, and instantiates it explicitly in the initializer. Specifically, locate a default member initializer within a class template that contains a lambda. Create a new class inside the same scope (e.g., a local struct) with a public operator() matching the lambda signature and body. Then replace the lambda in the initializer with an explicit instantiation of that class (e.g., using curly braces). For example, if the seed program has: class TemplateClass { int member = [](){ return 42; }(); }; mutate to: class TemplateClass { struct LocalFunctor { int operator()() { return 42; } }; int member = LocalFunctor{}(); }; Ensure the new struct uses existing types from the seed; if the lambda captures variables, replicate the captures as constructor arguments and member variables in the struct. This mutation targets the intersection of class template instantiation, default member initializers, and lambda expressions, which triggered the bug.
