mutation operator: Replace reference initialization with value initialization for method call results. This operator applies when a reference variable is declared and directly initialized with the result of a method or function call. The mutation changes the reference declaration to a non-reference declaration, converting the binding into a copy initialization. Specifically, for a statement of the form "Type& var = expr();" where expr() is a call expression, mutate it to "Type var = expr();". This targets compiler bugs in reference binding logic, especially when the call returns a temporary or prvalue, as the original reference may attempt to bind to a temporary that is incorrectly managed. Use only existing types and variable names from the seed. Example: Original code "Foo& f = getFoo();" becomes "Foo f = getFoo();". Ensure the mutated statement replaces the original declaration entirely.
