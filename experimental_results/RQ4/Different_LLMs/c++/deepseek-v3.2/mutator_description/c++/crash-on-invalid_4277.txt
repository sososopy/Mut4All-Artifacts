Mutation operator: Insert malformed asm statements within function bodies.

This operator applies when a seed program contains at least one function definition. It targets the internal representation generation phase of the compiler by injecting invalid assembly statements. The mutation involves adding a new `asm` statement inside an existing function body, positioned before any return statement or at the end of the block if no return is present. The inserted statement must be syntactically valid C++ `asm` syntax but contain content that is intentionally malformed to trigger parsing or IR generation errors.

Specifically, for a selected function in the seed program, locate its body (the compound statement). Inside this body, insert a line: `asm("");` This empty string assembly instruction is deliberately incomplete, lacking any meaningful assembly code, which can cause the compiler's internal mechanisms to fail during processing.

For example, given a seed function:
```
int foo() {
    int x = 5;
    return x;
}
```
After mutation, it becomes:
```
int foo() {
    int x = 5;
    asm("");
    return x;
}
```
The operator uses the existing function context and introduces only the `asm` statement with an empty string literal. No new variables, types, or functions are declared beyond this statement. The change is minimal and focused on exploiting the compiler's handling of inline assembly directives.
