Mutation Operator: Inject malformed using-declarations within inheritance contexts.

Target a specific code construct: This mutation operator applies to any using-declaration that is already present within a derived class. The mutation modifies the using-declaration to become syntactically incomplete or malformed.

The mutation operator identifies a using-declaration that is correctly formed (e.g., `using Base::Member;`). It then mutates this declaration by removing the member name, resulting in a malformed using-declaration such as `using Base::;`. This mutation should be applied only in contexts where a using-declaration is valid, specifically within a derived class (struct or class) that inherits from a base class. The mutation leverages existing class names (Base and Derived) from the seed program.

To apply the mutation, select a using-declaration within a derived class. Replace the identifier after the `::` with nothing, leaving only the `using Base::;` construct. Ensure that the base class name (Base) is taken from the existing using-declaration or the inheritance relationship in the seed program. No new variables, types, or functions are introduced; the mutation solely alters the syntax of an existing declaration.

Example in pseudo-code: If the seed program contains `struct Derived : Base { using Base::func; };`, mutate it to `struct Derived : Base { using Base::; };`. This creates a syntax error identical to the bug report, targeting the parser's handling of incomplete using-declarations during access checking and delayed diagnostic processing.
