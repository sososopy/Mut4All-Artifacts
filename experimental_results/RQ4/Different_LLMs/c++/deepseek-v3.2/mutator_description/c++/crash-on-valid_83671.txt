Mutation Operator: Null Base or Member Record Type Introduction

This mutation operator targets code where a class or structure has base classes or member fields, specifically focusing on the possibility that a base class type or member field type may resolve to a NULL record declaration. It applies to any class definition that contains at least one base class specification or one member field of a type that could be a class, struct, or union.

The operator modifies the seed program by introducing a base class or a member field whose type, after certain type transformations (like stripping typedefs, pointers, references, or arrays), does not refer to a valid C++ record (class/struct/union) type. This simulates a scenario where `getAsCXXRecordDecl()` or `getAs<RecordType>()` returns a null pointer.

For base classes: In a class definition that inherits from one or more bases, replace one base class type specifier with a type that is not a class type. Preference is given to using an existing type alias (typedef or using) in the seed program that resolves to a fundamental type (e.g., int, float) or a non-record type. If no such alias exists, introduce a new typedef before the class definition that aliases a fundamental type, and use that typedef as the base class. Example: If the seed has `class Derived : public Base {};`, and there exists `using MyInt = int;`, mutate to `class Derived : public MyInt {};`. If no suitable alias exists, add `typedef int NonClassType;` before the class and mutate to `class Derived : public NonClassType {};`.

For member fields: In a class definition containing member fields, replace the type of one field with a type that is not a record type after stripping pointers/references/arrays. Use an existing type alias for a fundamental type if available. Otherwise, introduce a typedef for a fundamental type and use it. Example: If the seed has `class C { SomeClass member; };`, and `using Float = float;` exists, mutate to `class C { Float member; };`. If no alias exists, add `typedef char NonRecord;` and mutate to `class C { NonRecord member; };`.

The change must be made only in the class definition. The operator should not modify other parts of the program, such as object instantiations or method definitions, to keep the mutation compilable in other contexts. The goal is to create a situation where the compiler's internal logic for computing empty subobject sizes may receive a null record declaration.
