Mutation operator: Introduce a recursive default argument expression in a template member function.

Target: Default arguments in member functions of template classes/structs.

Procedure:
1. Identify a member function within a template class/struct that currently has no default argument or a simple default argument.
2. Replace the default argument with an expression that recursively references the function's own parameter name, using a function call syntax that is invalid due to the parameter being uninitialized at the point of default argument evaluation. Specifically, if the function has a parameter named `param`, change the default argument to `func(param)()` where `func` is a function that exists in the context (e.g., a member function of the class, a global function, or a static member function). If no suitable `func` exists, introduce a declaration for a simple function `int func(int);` at an appropriate scope (global or within the template if possible) before the template definition.
3. Ensure the recursive reference uses the parameter's name directly (like `g(k)` in the bug example) without introducing new variables.

If seed contains: `template<class U> struct Box { void set(int value) {} };`
Mutate to: `template<class U> struct Box { void set(int k = helper(k)()) {} };` and add `int helper(int);` before the template if not present.

Changes: Add a default argument `= helper(k)()` to the member function `set`. Declare `int helper(int);` globally if needed. No new types or complex data names are introduced; only the existing function name `helper` is used or declared.
