mutation operator: Replace an annotation token in the preprocessor cache with a token sequence that alters its end location.

This mutation targets annotation tokens generated by the preprocessor, such as those from _Pragma or Microsoft __pragma, within any C++ source file that uses such directives. It applies when the compiler's preprocessor caching mechanism is active and has stored annotation tokens.

The operator modifies the seed program by inserting an additional preprocessing token immediately after the annotation token's content but before its formal end, within the same logical line. Specifically, after a _Pragma("...") directive, a single space followed by a comment token /* */ is inserted. This changes the physical end location of the annotation token sequence without altering its semantic content, potentially breaking the assertion that the cached token's end location matches the annotation's end location.

For example, if the seed contains:
_Pragma("message(\"test\")")
It is mutated to:
_Pragma("message(\"test\")") /* */

The change must use only elements present in the seed: the _Pragma directive and standard comment syntax. No new variables, types, or functions are introduced. The mutation is applied to every _Pragma or __pragma directive encountered in the source code, one directive per mutation instance.
