mutation operator
This mutation operator targets the interplay between explicitly deleted overloaded operators and other overloaded operators within the same class. It applies when a class contains at least one overloaded operator (prefix or postfix increment/decrement, unary plus/minus, logical negation, etc.) that is explicitly deleted using = delete, and also contains another overloaded operator (of any kind, including templated versions) that is not deleted. The mutation modifies the body of a non-deleted overloaded operator function to invoke a deleted overloaded operator on an object of the same class type. Specifically, within the function body of a non-deleted overloaded operator, create a local variable of the class type, then apply the deleted operator to that variable. For example, if a class has a deleted prefix increment operator and a non-deleted postfix increment operator, the mutation would change the postfix increment operator's body to include a statement that attempts to use the prefix increment on a local instance. The local variable should be declared using the class name already present in the seed program. The mutation should only be applied if the required operators exist; no new declarations are introduced beyond the local variable within the function body. This creates a situation where overload resolution must consider a deleted operator, potentially triggering assertion failures or crashes in the compiler's overload handling logic, especially when combined with templated operators.
