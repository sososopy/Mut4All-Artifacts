Mutation operator: Replace the first parameter type of a member operator delete function with a class type that is already defined within the same translation unit.

This mutation targets member operator delete functions within a class definition. It applies when a class contains a declaration of operator delete (any form, such as void operator delete(void*) or void operator delete(void*, std::size_t)). The operator must be defined as a member function of the class. The mutation changes the type of the first parameter from its original type (typically void*) to a different class type that is already present in the program. The chosen class type must be a complete, non-dependent class type defined earlier in the same source file or included header, ensuring it is accessible. For example, if the program defines struct Widget {}, and a class MyClass has void operator delete(void* p);, mutate it to void operator delete(Widget p);. The function signature is altered accordingly. The mutation does not introduce new variables, types, or functions; it uses an existing class type from the program. The rest of the function body, if any, remains unchanged. This mutation is designed to produce invalid code where the first parameter of operator delete is not void*, which can trigger compiler crashes during parsing or semantic analysis, especially when combined with delete expressions.
