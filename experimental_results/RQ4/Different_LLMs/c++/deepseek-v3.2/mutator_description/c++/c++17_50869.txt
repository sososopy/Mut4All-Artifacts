Mutation operator: Replace inline variable template with non-inline variable template in struct/class scope. Apply when an inline variable template declaration is found within a struct, class, or union body in C++17 mode. The mutation changes the 'inline' specifier to be removed or placed outside the class definition if the variable template is a static member. For a non-static member variable template, move the declaration outside the class body and add an explicit specialization for the class type. Use existing variable names and template parameters from the seed program. Example: Original: struct S { inline static constexpr T var = value; }; Mutated: struct S { static constexpr T var = value; }; Or if var is non-static: Original: struct S { inline T var = value; }; Mutated: struct S { T var; }; template<> inline T S::var = value; This targets parser crashes related to inline variable parsing in class scope.
