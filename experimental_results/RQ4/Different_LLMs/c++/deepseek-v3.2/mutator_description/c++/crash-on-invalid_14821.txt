Mutation operator: Inconsistent template specialization inheritance mismatch

This mutation operator targets template class inheritance hierarchies where a derived template class inherits from a base template class. It applies specifically when a template class D inherits from template class B, and functions or methods use parameters of type D with different template arguments than those used in instantiation.

The operator modifies function declarations that accept parameters of the derived template type by changing the template argument in the parameter to be inconsistent with the inheritance relationship. Specifically, when a function F accepts parameter of type D<X>, and D inherits from B<Y>, the operator changes the function parameter to D<const X> or D<volatile X> while the base class remains B<X> without corresponding const/volatile qualification.

Changes to make:
1. Identify template class inheritance: Find template class D that publicly inherits from template class B
2. Identify function declarations: Find function F that has parameter of type D<T> where T is some type
3. Modify parameter: Change the function parameter type from D<T> to D<const T> or D<volatile T>
4. Ensure base class template argument remains unchanged: The base class B should still use B<T> without const/volatile

Example in pseudo-code:
Original:
template<class U> struct Base {};
template<class U> struct Derived : public Base<U> {};
void func(Derived<int> param);

Mutated:
template<class U> struct Base {};
template<class U> struct Derived : public Base<U> {};
void func(Derived<const int> param);

Note: Use existing types from the seed program. The const/volatile qualification is added only to the derived class template argument in the function parameter, not to the base class template argument in the inheritance specification. This creates an inconsistency where Derived<const T> inherits from Base<T> (not Base<const T>).
