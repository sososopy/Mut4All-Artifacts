mutation operator: replace union member with a non-trivial class type in template instantiation context

Applies to: union declarations within class template definitions where union members are currently trivial types or POD types

Changes: when a union inside a class template contains only trivial members (e.g., fundamental types, trivial structs), replace one member with a non-trivial class type that exists in the seed program. specifically, locate a union declaration within a template class, identify a member with trivial type, and change its type to a non-trivial class type already defined in the program (e.g., a class with user-defined constructor, destructor, virtual functions, or non-static data member initializers). if no suitable non-trivial class exists, introduce a simple non-trivial class by adding a declaration before the template: class nontrivial { nontrivial() {} }; then use this type as the union member.

example transformation:
original: template<typename T> struct wrapper { union { int x; char y; }; };
mutated: template<typename T> struct wrapper { union { nontrivial x; char y; }; };
where nontrivial is a previously defined class with user-provided constructor.
