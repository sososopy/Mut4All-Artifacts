mutation operator
Target a specific code construct: ambiguous or malformed array subscript syntax inside a function body, particularly involving nested brackets or missing expressions.
Where it applies: inside compound statements (function bodies, blocks) where array subscript operations are used.
Changes to make: replace a valid array subscript expression (e.g., arr[index]) with a malformed subscript that contains an extra bracket or an empty subscript, such as arr[] or arr[][]. Use existing array variables from the seed program. If no array variable exists, introduce a local array declaration (e.g., int localArr[5];) and then apply the mutation to it.
Example mutation: within a function body, change a statement like int x = arr[i]; to int x = arr[]; or int x = arr[][i];. Ensure the mutated code is syntactically questionable but not trivially invalid like using undeclared identifiers.
