mutation operator: Complex Number Built-in Operator Mutation.

This mutation operator targets expressions involving GNU C built-in operators for complex numbers, specifically __real__ and __imag__. It applies when a seed program contains a variable of a complex type (e.g., _Complex float, _Complex double, _Complex int) and the operator is used in a context that yields a pointer or address. The operator mutates the expression by swapping the use of the built-in operator or changing the context in which it is used, focusing on scenarios where the result is compared, assigned, or used in a potentially invalid type context.

Specifically, for a seed program that contains a complex variable 'var' and uses __real__ var or __imag__ var, the mutation will change the expression to take the address of the built-in operator result, forming &__real__ var or &__imag__ var, and then use this address in a comparison or another operation that may trigger internal compiler assumptions about type categories. For example, if the seed has an expression like f(__real__ var), mutate it to f(0 < &__real__ var). This places the address-of operator on the result of __real__, which yields a pointer to the real part, and embeds it in a comparison that may be evaluated during constant expression handling.

The mutation must use existing complex variables and functions from the seed program. If no complex variable exists, the operator does not apply. The change is made by locating any use of __real__ or __imag__ on a complex variable and replacing the entire expression where it appears with a new expression that takes its address and uses it in a relational operation (e.g., <, >, <=, >=) with an integer constant like 0, and then passes that as an argument to an existing function or uses it in a statement. This can expose bugs in the compiler's handling of pointers to complex components during constant evaluation or type canonicalization.

Example pseudo-code: Seed contains: _Complex float x; void foo(int); foo(__real__ x); Mutated to: _Complex float x; void foo(int); foo(0 < &__real__ x); Here, the argument to foo becomes a boolean expression comparing zero to the address of the real part of x.
