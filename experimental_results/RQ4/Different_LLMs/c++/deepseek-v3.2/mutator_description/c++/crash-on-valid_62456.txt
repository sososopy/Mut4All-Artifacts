mutation operator: fold-expression-within-lambda-capture-replacement

This mutation operator targets fold expressions that appear inside a lambda capture list. It applies to any fold expression that uses a pack expansion within the capture list of a lambda expression, especially when the lambda is generic (auto parameters) or within a template context. The operator replaces the original fold expression pattern with an alternative fold pattern that uses a different operator or changes the placement of the pack expansion relative to the fold, while keeping the same semantic intent of folding over the parameter pack. This aims to stress the compiler's handling of pack expansions in nested lambda captures during instantiation.

Specifically, when a seed program contains a lambda with a capture list that includes a fold expression over a parameter pack, the operator modifies the fold expression. For example, if the original code has a unary right fold using the comma operator like `([a]{}, ..., 0)`, it could be mutated to a binary left fold using the plus operator like `(0 + ... + [a]{})`, or vice versa, ensuring the fold remains valid C++ (e.g., the operators must be suitable for the expressions). The mutation must use only variables, types, and functions already declared in the seed program; no new elements are introduced. The change is made directly to the fold expression syntax within the lambda capture.

Example transformation in pseudo-code: Original seed snippet: `[](auto... a) { return ([a]{}, ..., 0); }` is mutated to `[](auto... a) { return (0 + ... + [a]{}); }`. This changes the fold from a unary right fold with comma operator to a binary left fold with plus operator, but note that the plus operator may not be valid for lambda expressions; thus, the operator should choose a mutation that results in syntactically correct code, such as swapping between different supported fold operators (e.g., changing `...,` to `... +` with appropriate operands). The mutation should preserve the pack `a` and the lambda body structure, only altering the fold expression itself.
