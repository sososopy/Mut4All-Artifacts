Mutation operator: Replace template specialization with dependent base class in a friend function declaration within a class template. This operator applies when a class template contains a friend function declaration that uses a template specialization of the same class template. The mutation changes the friend function's parameter type from a specialization of the same class template to a dependent base class type derived from that specialization, potentially altering type canonicalization during substitution. Specifically, for a class template 'Templ' with a friend function taking 'Templ<Args...>', introduce a new dependent base class 'Base' that inherits from 'Templ<Args...>' and change the friend function parameter to 'Base'. This must be done using existing types or introducing a simple struct if necessary. If no suitable base exists, declare a new struct within the same namespace that inherits publicly from the specialization, ensuring it is trivial and default-constructible. Example: Original code: template<typename... Args> class Templ { template<typename... Params> friend void func(const Templ<Params...>&); }; Mutated code: template<typename... Args> class Templ { template<typename... Params> friend void func(const Base<Params...>&); }; Where Base is defined as: template<typename... Params> struct Base : Templ<Params...> {}; The mutation should be applied only when the friend function is declared inside the class template and references the same class template specialization. Avoid introducing complex or invalid types; ensure Base is declared before use if not already present. This targets compiler bugs in canonical type handling during template instantiation, especially in friend declarations with dependent types.
