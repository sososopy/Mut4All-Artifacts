mutation operator
target: template instantiation with missing template arguments
applies to: any template class or function instantiation where the template arguments are partially or fully omitted in a context where the compiler attempts to complete the template argument list, particularly within a nested name specifier or when parsing a subsequent token like '<'.
change: when encountering a template-id (e.g., type<arg>) that is valid according to the seed program, mutate it by removing one or more template arguments from the argument list, creating an incomplete template instantiation. prioritize removing all arguments if possible, leaving just the template name followed by empty angle brackets (<>). if the template has default arguments, ensure the mutation still results in an argument count below the minimum required.
example: given `std::vector<int> v;`, mutate to `std::vector<> v;`. given `foo<X, Y, Z> obj;`, mutate to `foo<X, , Z> obj;` or `foo<> obj;`. use existing template names and types from the seed. do not introduce new identifiers.
