mutation operator: Replace requires expression inside lambda in concept constraint with a requires expression that uses a placeholder variable name derived from existing lambda parameter or template parameter, and modify the constraint to use a different concept from the seed program if available, otherwise substitute with std::same_as<T> using a placeholder type from the seed program. This mutation applies when a concept definition contains a lambda that returns a requires expression, targeting the lambda body. The mutation changes the requires expression's parameter list and constraint. For example, if the original requires expression is requires(T t) { { t } -> some_concept; }, mutate to requires(T t, auto... args) { { t } -> another_concept; } where another_concept is a concept already present in the seed program, or if not, use std::same_as<T> with T being the template parameter. Introduce auto... args as additional parameters using existing lambda parameters if the lambda has parameters, otherwise add them as new parameters. Ensure the placeholder variable t remains unchanged if it exists in the original, or introduce a new variable name using the template parameter name. The changes must not introduce undeclared types or concepts; use only elements from the seed program. For instance, if the seed program contains std::convertible_to, use that concept in the mutated constraint.
