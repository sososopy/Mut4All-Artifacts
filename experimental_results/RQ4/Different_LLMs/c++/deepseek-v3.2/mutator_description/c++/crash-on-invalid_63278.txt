mutation operator: Replace a non-static struct member initialization with an explicit type specifier for auto members that have a non-complex initializer.

This mutation applies to struct or class definitions containing non-static members declared with auto and initialized with a simple literal or constant expression. The operator changes the auto declaration to an explicit type deduced from the initializer, using the type that would normally be deduced by the compiler. For example, if a member is declared as auto x = 1;, it is mutated to int x = 1;. This mutation should only be applied when the initializer is a literal (like integer, floating-point, or string literals) or a simple constant expression that clearly deduces a fundamental type, and the member is non-static. The operator avoids introducing new types or variables; it uses the deduced type directly. Changes are made directly in the struct or class definition, modifying only the member declaration line. This targets compiler bugs related to auto type deduction in non-static member contexts, especially where initialization interacts with other members.
