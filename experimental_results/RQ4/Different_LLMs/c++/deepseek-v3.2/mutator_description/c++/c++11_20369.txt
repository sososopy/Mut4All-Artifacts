Mutation Operator: Inline Namespace Template Specialization Duplication

Target Construct: This mutation operator targets template specializations declared within inline namespaces. It specifically applies when a program contains an inline namespace (either named or unnamed) that declares a function template, and there exists a subsequent explicit specialization for that template.

Mutation Action: For each explicit template specialization that corresponds to a template declared inside an inline namespace, duplicate the specialization statement. The duplicate should be placed immediately after the original specialization, forming two consecutive, identical specialization declarations.

Application Rule: Apply this mutation only if the seed code contains an inline namespace definition that declares at least one function template, and there is at least one explicit specialization for that template declared outside the namespace (in the same or enclosing namespace scope). The mutation duplicates the entire specialization declaration.

Example (Pseudo-code):
Original seed code snippet:
inline namespace N { template <typename T> void func(T param); }
template <> void func(int param); // Explicit specialization

Mutated code:
inline namespace N { template <typename T> void func(T param); }
template <> void func(int param); // Original specialization
template <> void func(int param); // Duplicated specialization

Rationale: This mutation is designed to stress the compiler's handling of linkage and symbol caching for template specializations associated with inline namespaces. The bug report indicates a crash due to an assertion failure related to cached linkage when a template specialization is parsed. By creating a duplicate specialization, the compiler may be forced to process the same specialization twice, potentially exposing bugs in the mechanism that checks for redefinitions, merges declarations, or caches linkage information for entities in inline namespaces. The duplication uses only existing template names and types from the seed program, ensuring applicability.
