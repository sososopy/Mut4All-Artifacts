mutation operator: Replace a function call expression within a function body with a reference to a parameter pack expression, specifically within a compound statement where the call occurs, focusing on contexts where unevaluated operands like sizeof or decltype might be applied to a parameter pack. This mutation applies when a function has at least one parameter and a function call is present inside its compound statement body. The mutation changes the call to a decltype expression referencing a parameter pack of the function's parameters, ensuring the parameter pack is used in an unevaluated context. For example, if the seed contains a function like `void f(int x) { g(x); }`, mutate to `void f(int x) { decltype(x)...; }`. Use existing function parameters to form the parameter pack reference; do not introduce new types or variables. The change is made by replacing the entire function call expression with `decltype(parameter)...`, where `parameter` is an existing parameter name from the function's parameter list, selected arbitrarily if multiple exist. This targets compiler handling of parameter packs in unevaluated expressions within function bodies.
