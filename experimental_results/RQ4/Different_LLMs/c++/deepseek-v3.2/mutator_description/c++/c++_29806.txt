mutation operator: Replace an empty struct/union/class body with a single semicolon for code parsed under Microsoft extensions mode.

This mutation applies when a struct, union, or class definition in the seed program has an empty body (i.e., `{}`). The operator changes the empty braces to a single semicolon, resulting in `;`. This specifically targets compiler frontend parsing of incomplete type definitions, which is valid under Microsoft extensions (`-fms-extensions`). The mutation should only be applied if the seed program already contains at least one struct, union, or class type definition. No new variables or types are introduced; the change modifies only the existing type definition's body.

Example: If the seed code contains `struct X {};`, mutate it to `struct X ;`. If the seed code contains `class Y {};`, mutate it to `class Y ;`. This mutation is intended to expose crashes or assertion failures in the compiler when handling invalid code that may be accepted under certain language extensions.
