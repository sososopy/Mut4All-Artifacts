mutation operator
This mutation operator targets generic lambda expressions within template functions. It applies when a generic lambda captures a variable that is used in its return type specification, specifically when that return type depends on a template parameter or a captured constexpr value. The operator changes the captured variable's usage from being directly referenced in the lambda's return type to being used via a decltype expression, which may alter the instantiation context and trigger type compatibility assertions during template substitution. For example, if the seed program contains a generic lambda like auto lambda = [](auto) -> type<index> {}; where index is a captured constexpr variable, mutate it to auto lambda = [](auto) -> decltype(type<index>) {};. This mutation should be applied only when the lambda's return type explicitly uses a captured variable or template parameter in a type alias or template argument. The operator must use existing variable names and types from the seed program; no new declarations are introduced. The change is limited to modifying the return type clause of the lambda expression, replacing the original type with decltype(original_type). This can expose bugs related to the compiler's handling of captured variables in generic lambdas during template instantiation.
