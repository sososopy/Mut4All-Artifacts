mutation operator: Implicit Member Self-Reference in Dependent Context Initializer

This operator targets the initialization of non-static data members within a class or struct definition, specifically when the initializer expression refers to the member itself, creating a self-reference. It applies when a member is initialized using a direct identifier that matches the member's own name, particularly in template or dependent type contexts where such an initialization might be ill-formed but not immediately diagnosed.

The mutation modifies a member initializer that uses a non-member expression (like a literal, function call, or other variable) to instead use a self-referential identifier. If the seed program contains a member declaration with an initializer, the initializer expression is replaced with the name of the member being declared. This should be applied only to non-static data members, and care is taken to use the exact member name as it appears in the declaration.

Example seed code:
struct Example {
    int value = 42;
    double data = compute();
};

After mutation:
struct Example {
    int value = value;
    double data = data;
};

The operator introduces a direct self-reference, which can trigger issues in template instantiation or during the semantic analysis of default member initializers, especially in dependent contexts. It uses only existing member names, ensuring no new variables or types are introduced. The change is localized to the member initializer clause.
