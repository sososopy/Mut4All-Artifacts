Mutation Operator: Replace member pointer operand with null pointer constant in member pointer comparison expressions.

This mutation targets C++ code containing binary comparison operators (==, !=, <, >, <=, >=) where one operand is a pointer to member (either pointer to data member or pointer to member function). The operator applies when the compiler encounters a comparison expression between two pointers to members, or between a pointer to member and another pointer-like expression.

The mutation replaces one operand in the comparison with a null pointer constant (0 or nullptr). Specifically, if the comparison expression is of the form `lhs op rhs`, where at least one operand is a pointer to member type (e.g., `&ClassName::memberName`), the mutation modifies it to `0 op rhs` or `lhs op 0`. The choice of which operand to replace is based on which operand is the pointer to member; if both are pointers to members, either can be replaced. The null constant must be compatible with the pointer to member type, requiring no additional type declarations, as 0 or nullptr is a valid null pointer constant for any pointer type, including pointers to members.

Example: Original code snippet: `if (&MyClass::data == &MyClass::otherData) {...}`. Mutated version: `if (0 == &MyClass::otherData) {...}`. Alternatively: `if (&MyClass::data == 0) {...}`.

This mutation aims to expose bugs in compiler handling of invalid comparisons involving member pointers and null constants, potentially triggering assertion failures or crashes during type checking or placeholder resolution, as seen in the bug report where invalid member pointer usage led to a crash. It leverages existing variables and types from the seed program, introducing only the null constant which is universally defined. The change is minimal, altering only the comparison expression's operand to a null pointer constant, without adding new declarations or ambiguous constructs.
