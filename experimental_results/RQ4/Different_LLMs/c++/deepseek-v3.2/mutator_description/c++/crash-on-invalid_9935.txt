Mutation operator: Replace member template function call with missing parentheses by a call to a non-template member function with missing parentheses.

Apply this mutation when a member template function call expression includes explicit template arguments but lacks parentheses for the function call. Specifically, target expressions of the form `object.template_name<template_args>` where `template_name` is a member template function, but the parentheses and arguments for the function call are absent. The mutation changes this to an expression `object.non_template_name` where `non_template_name` is a non-template member function (i.e., a member function without template parameters) that already exists in the same class, also without parentheses. This tests compiler diagnostics and handling of incomplete calls across different function types.

For example, if the seed program contains a class with both template and non-template member functions:
struct Class {
    template<typename T> void template_func(T);
    void non_template_func();
};
And an invalid usage: `obj.template_func<int>`
Mutate to: `obj.non_template_func`
The non-template function must be selected from existing member functions of the same class in the seed program. If no such non-template member function exists, do not apply this mutation. The change involves only replacing the function name and removing template arguments, keeping the object expression unchanged. This exposes bugs in the compiler's overload resolution and diagnostic generation for malformed member function references.
