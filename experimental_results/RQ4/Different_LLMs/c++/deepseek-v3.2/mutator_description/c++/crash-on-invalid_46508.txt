Mutation operator: Duplicate incomplete nested struct definition before a valid struct definition.

This operator targets code constructs where a struct is defined inside another struct's body but is incomplete (only declares its own type) and then followed by a separate valid struct definition of the same name. Specifically, it applies when a seed program contains at least one struct definition. The mutation duplicates the incomplete nested struct declaration line immediately before a subsequent valid struct definition of the same name within the same scope.

Changes to make: Locate a struct definition in the seed program. Inside its body, add a nested struct declaration that only names the struct itself (incomplete). Then, after the outer struct's closing brace, insert a valid struct definition with the same name as the nested one, containing at least one member (using existing types and variable names from the seed). Finally, duplicate the incomplete nested struct declaration line, placing it directly before the valid struct definition.

Example in pseudo-code: If the seed has `struct Outer { int a; };`, mutate to:
struct Outer {
    struct Inner;
    int a;
};
struct Inner;
struct Inner { int b; };

Note: The new struct name `Inner` should be derived by modifying an existing struct name from the seed (e.g., appending "_dup") if no conflict, or use a new name like `MutatedStruct` declared as above. The member `b` uses an existing type (e.g., `int`) and variable name from the seed. This ensures the mutation introduces no undeclared elements.
