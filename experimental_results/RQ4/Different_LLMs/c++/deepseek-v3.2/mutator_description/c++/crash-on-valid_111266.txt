mutation operator: change explicit specialization syntax for member function template within class definition to out-of-line specialization syntax.

This mutation applies to explicit specializations of member function templates that are defined directly within the class definition. The operator transforms the in-class explicit specialization into a separate out-of-line specialization declaration and definition.

For a class template with a member function template, if an explicit specialization of that member function template appears inside the class body, the mutation relocates it. First, remove the explicit specialization definition from the class body. Then, add a declaration for the explicit specialization outside the class, using the appropriate template argument list for the enclosing class and the member function template. Finally, provide the definition of the explicit specialization outside the class, matching the removed body.

For example, given a seed program containing:
template<class T> struct S {
  template<int> auto foo();
  template<> auto foo<1>() {
    return [](auto x) { return x; };
  }
};

The mutation changes it to:
template<class T> struct S {
  template<int> auto foo();
};
template<class T>
template<> auto S<T>::foo<1>() {
  return [](auto x) { return x; };
}

The operator must use existing class names, function names, and template parameters from the seed program. If the class is instantiated, such as with 'template struct S<void>;', that line remains unchanged. The mutation ensures all variable and type references in the moved definition remain valid by preserving the original context. This operator targets the specific construct of in-class member function template explicit specializations, which are a known area of compiler divergence and potential crashes.
