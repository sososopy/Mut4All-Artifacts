Mutation operator: Replace template alias with a non-type dependent value.

This mutation operator applies when a template alias is defined within a class or struct, and that alias uses typename to refer to a dependent name that is intended to be a type. The mutation changes the alias to refer to a non-type member (like a static constant or value) instead, while keeping the typename keyword, potentially causing a mismatch during instantiation. Specifically, target template aliases of the form: template <typename T> using AliasName = typename SomeTemplate<T>::member; where SomeTemplate<T>::member is originally a type. Change it to refer to a member that is a non-type (e.g., a static constant integral value), if such a member exists in the seed program's context. If no such non-type member exists, introduce a static constant member in the referenced template (SomeTemplate) by adding a static constexpr integral member (like static constexpr int v = 0;) to provide a non-type target.

If it does, mutate the alias to refer to that non-type member instead of the original type member. Ensure the mutation maintains the typename keyword, which incorrectly suggests the member is a type, leading to potential compiler confusion during template instantiation when the alias is used in contexts expecting a type.
