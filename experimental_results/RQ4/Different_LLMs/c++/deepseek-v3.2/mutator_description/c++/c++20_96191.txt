Mutation Operator: Replace first parameter type of member operator delete with class type of enclosing class.

This mutation applies to member operator delete functions defined within a class or struct. Specifically, it targets the first parameter of such operator delete functions, which is typically void* or another pointer type. The operator mutates this first parameter type to the type of the enclosing class itself (i.e., the class where the operator delete is defined), making it a non-pointer class type.

Where it applies: This mutation is applied only when a member operator delete function is present within a class or struct definition in the seed program. It modifies the first parameter's type declaration within that operator delete function.

Changes to make: Locate any class or struct definition containing a member operator delete function. Identify the type of the first parameter in that operator delete declaration. Replace that type with the name of the enclosing class (the class or struct where the operator delete is defined). If the operator delete has multiple parameters, only the first parameter type is changed. No other parts of the function signature (like other parameters, function name, or return type) are altered.

Example illustration: Suppose the seed program contains a class definition: class MyClass { void operator delete(void* ptr, std::size_t size) {} }; After mutation, it becomes: class MyClass { void operator delete(MyClass ptr, std::size_t size) {} }; The first parameter type void* is replaced by MyClass. The mutation uses the existing class name MyClass, which is already declared in the program. No new types or variables are introduced; only the existing class name is used as a type.
