Mutation Operator: Replace Default Argument with Temporary Object of Same Type

This mutation operator targets default arguments in function and constructor parameter lists. It applies when a function or constructor declaration contains a default argument that is a literal constant (such as 0, nullptr, true, false, or a literal of integer, floating-point, or pointer type). The operator replaces this literal with a temporary object constructed from the literal, matching the parameter's type. This change specifically stresses the compiler's handling of temporary materialization and lifetime extension in constant evaluation contexts, particularly for references bound to default arguments.

The change must be made directly in the function or constructor declaration. The new default argument will be a functional-style cast or constructor call that creates a prvalue of the parameter's type, initialized by the original literal. If the parameter type is a reference, the temporary will bind to it. The mutation should only be applied if the original default argument is a simple literal, not a complex expression.

For example, given a seed program containing:
void func(const int& p = 0);
The mutation changes it to:
void func(const int& p = int(0));
Another example, given:
bool bar(const float& f = 0.0f);
The mutation changes it to:
bool bar(const float& f = float(0.0f));
This mutation should use types already present in the seed program. No new types, variables, or functions are introduced; only the default argument expression is altered. The change is made in the declaration, not at call sites. This mutation is designed to expose bugs related to the constant expression evaluator's handling of temporary creation and destruction, especially in arrays, aggregate initialization, and logical operator contexts, as hinted by the bug reports involving constexpr constructors and reference parameters.
