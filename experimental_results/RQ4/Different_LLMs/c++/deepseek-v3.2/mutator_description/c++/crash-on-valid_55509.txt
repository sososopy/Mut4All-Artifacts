mutation operator

Target construct: This mutation operator targets friend function declarations within class or class template specializations, specifically when the friend function returns an auto type that depends on template parameters or expressions involving template arguments. It applies when a class template has a friend function with auto return type, and the friend function's definition or declaration references template parameters from the enclosing class.

Mutation action: Replace the auto return type of the friend function with a deduced return type that introduces a new dependency on a template parameter from the enclosing class, by modifying the expression used in the return statement or the trailing return type if present. If the friend function already uses auto without a trailing return type, change it to use a trailing return type that incorporates a template parameter in a more complex expression, such as applying arithmetic or conditional operations to the template parameter. Ensure that the mutation uses only types, variables, and template parameters already in scope within the class or its template arguments.

Example in pseudo-code: Original code might have:
template<int N>
struct S {
    friend auto func(const S<N-1>&) { return N-1; }
};
Mutated code could be:
template<int N>
struct S {
    friend auto func(const S<N-1>&) -> decltype(N-1) { return N-1; }
};
Or, if already with trailing return type, modify it to something like:
template<int N>
struct S {
    friend auto func(const S<N-1>&) -> decltype(N-1 + sizeof(N)) { return N-1; }
};
The mutation should avoid introducing new variables or types not already present; it should only rearrange or extend existing expressions using template parameters.
