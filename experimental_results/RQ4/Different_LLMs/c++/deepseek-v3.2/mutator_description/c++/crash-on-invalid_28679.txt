Mutation operator: Introduce lambda expression with decltype referencing a function without parentheses in template context.

This mutation operator applies when a template function is present in the seed program. It modifies the template function by inserting a lambda expression inside its body. The lambda's return type is specified using decltype, but the decltype argument is a function name without parentheses, referencing the function as a type rather than a call. This construct is invalid but may trigger compiler crashes.

Specifically, locate a template function definition in the seed program. Within its body, add a lambda expression that has a parameter list and uses decltype with a function identifier that exists in the program. The function used in decltype must be declared elsewhere, such as a standard library function or user-defined function already present. If no suitable function exists, introduce a simple void function declaration like "void abort();" at global scope before the template. The lambda should not be called or used further.

Changes to make: Inside the template function body, insert "[](int)->decltype(function_name){};" where function_name is an existing function identifier. Ensure the function is declared; if not, add a declaration like "void abort();" at the top of the file. The lambda remains unused.

Example: Given a seed template function "template<class T> void g(T) {}", mutate to:
void abort(); // Add if not present
template<class T> void g(T) {
  [](int)->decltype(abort){};
}
This targets template and lambda interactions with decltype misuse.
