mutation operator template argument deduction in constructor calls for templated classes with callable parameters

This mutation operator targets constructor calls of templated classes where the template parameters can be deduced from constructor arguments, particularly when one argument is a callable object (function pointer, lambda, functor). It applies when a class template has template parameters that could be deduced from the types of arguments passed to its constructor, and at least one argument is a callable type. The mutation changes how the constructor is called to potentially trigger bugs in template argument deduction logic.

The operator modifies the constructor call by altering the argument list or the call syntax. Specifically, it changes a direct constructor call with arguments that include a callable to a form where the callable is wrapped or its type is altered through a cast or intermediate variable, while preserving the semantics where possible. For example, if the seed program has a templated class 'TClass' and a constructor call like 'new TClass(arg1, callable)', the mutation could introduce a temporary variable of the callable's type or use a static_cast on the callable argument.

The mutation must use existing types and variables from the seed program. If a new variable is introduced, it should be declared with the same type as the callable argument in the original constructor call. For instance, if the callable is a lambda, the new variable should be declared with the exact lambda type (using auto or the deduced type). The change involves replacing the constructor call with a modified version that uses this new variable or a cast.

Example in pseudo-code: Original code has 'auto obj = new TemplateClass(normal_arg, lambda_expr);'. Mutated code becomes 'auto temp_callable = lambda_expr; auto obj = new TemplateClass(normal_arg, temp_callable);' or 'auto obj = new TemplateClass(normal_arg, static_cast<decltype(lambda_expr)>(lambda_expr));'. This alteration can expose bugs in compiler handling of template deduction when callables are passed directly versus through intermediates.

The operator focuses on scenarios where the callable's type might affect template parameter deduction, and changes the context in which the callable is presented to the constructor. It avoids introducing new types or ambiguous terms; all modifications use existing elements from the seed program or straightforward declarations based on them. This mutation aims to test compiler robustness in C++17 template deduction rules, especially for classes with callable template parameters.
