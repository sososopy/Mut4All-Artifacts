Mutation operator: Replace a non-class type argument in a pointer-to-member template parameter with a forward-declared incomplete type.

This mutation operator applies to template instantiation contexts where a template parameter is used in a pointer-to-member type (e.g., `int T::*`). It targets scenarios where the template expects a class type but is given an incomplete non-class type. The operator modifies the template argument by replacing a concrete class type argument with a forward-declared incomplete type that is not a class, such as an enum or a union declared but not defined. Specifically, when a template parameter `T` is used in a pointer-to-member expression like `int T::*`, the operator changes the instantiation argument from a valid class type to an incomplete non-class type that is already declared in the seed program. If no such incomplete non-class type exists, introduce a new forward declaration of an enum or union without its definition. For example, if the seed program contains a class type `C` used as `is_class<C>`, mutate it to `is_class<EnumClass>` where `EnumClass` is a forward-declared enum (like `enum struct EnumClass;`). Ensure the mutated type is not a class and remains incomplete at the point of instantiation. The mutation should be applied to template arguments in static_assert, variable declarations, or function calls that rely on the template. This replicates the bug scenario where the compiler fails to handle incomplete non-class types in pointer-to-member contexts during template instantiation, triggering assertions like `Decl && "Passed null for Decl param"` in `ASTContext::getTypeDeclType`.
