Mutation operator: Replace bitwise OR expressions involving enum values with parentheses around the entire expression to force different parsing contexts.

This mutation applies to any expression where two enum values (or variables of enum type) are combined using the bitwise OR operator (`|`). It targets code where enum types are used, particularly in contexts where `using enum` declarations might be present or where enum values are directly referenced.

The operator changes the expression `a | b` to `( a | b )`, where `a` and `b` are enum values or variables of an enum type that exist in the seed program. This introduces parentheses that alter the parsing hierarchy, which can expose bugs in compiler handling of enum operations under different grouping, especially with C++20 `using enum` features.

Example transformation:
- Original: `int x = EnumVal1 | EnumVal2;`
- Mutated: `int x = ( EnumVal1 | EnumVal2 );`

The mutation uses only existing enum values, types, and variables from the seed program. No new elements are introduced. The change is solely the addition of parentheses around the entire bitwise OR expression involving enums.
