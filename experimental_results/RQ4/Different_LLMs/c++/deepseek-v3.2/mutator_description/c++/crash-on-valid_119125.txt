mutation operator
Target code construct: This mutation operator targets attribute argument expressions within templated constructs, specifically when an attribute applied to a member function of a class template contains an expression that may become invalid or non-constant after template instantiation. The operator applies to any attribute argument expression that includes a template parameter or a type dependent on a template parameter.

Description: Replace an attribute argument expression that uses a template parameter with a more complex expression that involves constructing or casting the template parameter type in a way that may not be a valid constant expression after instantiation. The mutation changes the argument expression to a compound expression that includes a cast or constructor call using the template parameter type, which can expose bugs in constant expression evaluation during template instantiation and attribute processing.

Changes: For a class template with a template parameter T, and a member function with an attribute that has an argument expression, if the argument expression is a simple constant or uses T, mutate it to a cast expression like (void)T{} or a similar compound expression that constructs or casts T. Specifically, if the attribute argument is a constant expression, replace it with (void)T{}. If the argument already uses T, wrap it in a cast or constructor expression, e.g., change T to (void)T{} or (9, (void)T{}). Use existing types and variables from the seed program; do not introduce new names. The mutation should only apply when T is a template parameter in scope.

Example: In the seed code, the attribute argument is (9, (void)T{}). If the original code had a simpler argument like 5, mutate it to (void)T{}. If the original had T, mutate it to (9, (void)T{}). Ensure the mutated expression is syntactically valid but may trigger assertion failures during constant folding in the compiler.
