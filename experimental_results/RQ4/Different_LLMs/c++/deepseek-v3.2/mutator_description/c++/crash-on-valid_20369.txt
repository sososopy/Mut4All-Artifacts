mutation operator: Inline Namespace Template Specialization Swap

This mutation operator targets explicit specializations of function templates declared within inline namespaces. It applies when the seed program contains a function template declared inside an inline namespace (either named or unnamed), followed by an explicit specialization of that template.

The mutation swaps the location of the explicit specialization relative to the inline namespace declaration. Specifically, it moves the explicit specialization to be nested within the same inline namespace as the primary template declaration. This changes the point of declaration and the associated lookup context for the specialization.

For a seed code structure of the form:

inline namespace N { template <typename T> ReturnType FunctionName(T parameter); }
template <> ReturnType FunctionName(SpecType parameter);

The mutation transforms it to:

inline namespace N {
    template <typename T> ReturnType FunctionName(T parameter);
    template <> ReturnType FunctionName(SpecType parameter);
}

All identifiers (namespace name N, ReturnType, FunctionName, T, SpecType, parameter) must be taken directly from the existing seed program. No new identifiers are introduced. The mutation only reorganizes existing code by moving the explicit specialization inside the namespace braces. The mutation should only be applied if the original explicit specialization is outside the inline namespace block. If the specialization is already inside the namespace, this operator does not apply. This tests compiler handling of linkage and declaration merging for specializations in inline namespaces.
