Mutation Operator: Insert Invalid Namespace Declaration Inside Class Scope
This mutation operator targets the structure of class definitions in C++ and applies when a seed program contains at least one class declaration (struct or class). It modifies the class by inserting an invalid namespace directive within the class body. Specifically, it adds a line that attempts to declare a namespace using an existing member name from the class or a common function name, but places it incorrectly inside the class scope, mimicking the invalid code pattern from the bug report. The operator selects a name from the set of existing member names (variables or functions) within the class, or if none exist, uses a common standard library function name like 'memmove' as a fallback. The change is: inside the class body, after an existing member declaration or at a valid insertion point, add a statement of the form "namespace using ::[selected_name];". This creates a syntactically invalid construct because a namespace declaration using the 'using' directive is not allowed inside a class. The operator ensures the inserted name is either an existing class member or a predeclared standard function, avoiding introduction of new undeclared variables or types. For example, if the seed class contains a member 'foo', the mutation adds "namespace using ::foo;" inside the class. This targets compiler crashes related to parsing invalid namespace usage within class scopes, as seen in the bug report.
