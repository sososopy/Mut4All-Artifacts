Mutation Operator: Incomplete Using Declaration in Class Scope

This mutation operator targets 'using' declarations within class definitions (including structs and classes). It applies when a seed program contains a valid 'using' declaration that brings a base class member or namespace member into the current class scope. The operator mutates this declaration by removing the identifier following the '::', creating an incomplete declaration similar to the bug-triggering pattern.

Where it applies: Inside a class or struct definition, where a 'using' declaration exists. The declaration must be of the form 'using NamespaceOrClass::Identifier;' or 'using typename Class::Identifier;'. The operator modifies only declarations that are already present.

Changes: For each 'using' declaration found in a class scope, replace it with a version where the identifier is omitted. Specifically, change 'using X::Y;' to 'using X::;'. If the original declaration uses 'typename' (e.g., 'using typename X::Y;'), mutate to 'using typename X::;'. Ensure the mutation is applied directly to the existing declaration; do not introduce new 'using' declarations or alter other parts of the code.
