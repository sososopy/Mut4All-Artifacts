mutation operator: Replace a template alias instantiation with an explicit template class instantiation using the same template arguments.

This operator targets code where a template alias is used to instantiate a template class. It applies when a template alias (using alias) is invoked directly as a constructor call (CTAD context) or in a deduction context. The mutation replaces the alias usage with the underlying template class name, explicitly specifying all template parameters as derived from the alias definition and the provided arguments.

For example, given a seed program containing:
template<typename A, typename B> class OriginalTemplate {};
template<typename X> using Alias = OriginalTemplate<X, int>;
void f() { Alias(5.0); }

The mutation changes the call from `Alias(5.0);` to `OriginalTemplate<double, int>(5.0);`. Here, `double` is deduced from the argument `5.0`, and `int` is taken from the alias definition. The operator analyzes the alias definition to extract the mapping of template parameters. It uses existing types and deduction results from the seed program. If the alias involves template template parameters or nested templates, the operator recursively resolves to concrete template classes available in the seed, avoiding introduction of new types. The change is applied only if the alias and the underlying template class are both present in the seed.
