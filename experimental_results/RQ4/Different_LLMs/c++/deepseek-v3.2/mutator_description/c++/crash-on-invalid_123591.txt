Mutation Operator: Variadic Template Argument Expansion Mutation in Alias Declarations

This mutation operator targets `using` alias declarations (type aliases) that involve template arguments, especially those that could be variadic or involve complex template types like `std::variant`. It applies when the seed program contains a `using` declaration that defines an alias for a template type. The operator modifies the alias by introducing a pack expansion pattern within the template argument list, which can stress the compiler's template argument handling and substitution logic, potentially exposing bugs like those seen in the report.

To apply the mutation, identify a `using` alias declaration in the seed program that aliases a template type, such as `std::variant`, `std::tuple`, or any other template class. The alias must already have a list of template arguments. The mutation changes this list by replacing one of the arguments with a pack expansion pattern that expands a template parameter pack. This requires that the alias is templated itself (i.e., it has a template parameter list). If the alias is not templated, this mutation does not apply. The operator uses existing template parameters from the alias or introduces a new template parameter pack if necessary, but prefers to reuse existing parameters to avoid introducing new undeclared elements.

Steps for mutation:
1. Locate a `using` alias declaration with a template parameter list and a template type on the right-hand side. For example: `template <typename T> using Alias = ExistingTemplate<T, int, char>;`.
2. Ensure the right-hand side template type has multiple template arguments. If it has fewer than two arguments, consider other mutations.
3. Select one of the template arguments on the right-hand side (preferably not the first, to vary patterns).
4. Replace the selected argument with a pack expansion pattern. If the alias already has a variadic template parameter (e.g., `template <typename... Ts>`), use that pack. For example, change `ExistingTemplate<T, int, char>` to `ExistingTemplate<T, Ts..., char>` where `Ts` is the existing parameter pack.
5. If the alias does not have a variadic template parameter, introduce a new template parameter pack in the alias's template parameter list. Add `typename... Pack` to the template parameter list (before or after existing parameters). Then, in the right-hand side, replace the selected argument with `Pack...`. For example, change `template <typename T> using Alias = ExistingTemplate<T, int, char>;` to `template <typename T, typename... Pack> using Alias = ExistingTemplate<T, Pack..., char>;`.
6. Ensure the mutation does not use specific type names like `int` or `char` in the description; the examples use generic names like `T` and `Pack` to illustrate.
