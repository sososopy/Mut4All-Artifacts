Mutation operator: Replace template name in deduction guide with a qualified name from a different namespace. This mutation applies when a template deduction guide is present in the code. The operator modifies the deduction guide by changing the unqualified template name to a qualified name that refers to a template from a different namespace, but where a template with the same unqualified name exists in the current scope. Specifically, if a deduction guide uses an unqualified name 'X', and there is a namespace 'N' that contains a template 'X', the mutation changes the deduction guide to use 'N::X' instead. This creates a mismatch between the deduction guide and the template it is intended for, as deduction guides must be in the same scope as their template. The change is applied to both the name in the guide declaration and the name in the trailing return type part if present. For example, given seed code with namespace N { template<class> struct X; } and a deduction guide template<class T> X() -> X<T>;, mutate to template<class T> N::X() -> N::X<T>;. The mutation uses existing namespaces and templates from the seed; no new elements are introduced.
