Mutation Operator: Replace struct/union/class member declaration with a member function declaration of identical name and void return type, using an empty parameter list.

This mutation targets the declaration of a non-function member (such as a variable or type alias) within a struct, union, or class body. It applies when the seed program contains a declaration like `int member;` inside such a compound type definition. The operator changes this declaration to `void member();`. This transformation invalidates the member lookup by introducing a function member where a non-function member was originally declared, potentially triggering assertions related to member lookup categorization during subsequent parsing or semantic analysis. The operator uses only names already present in the seed program; no new elements are introduced. For example, given a seed code snippet `struct S { int x; };`, the mutation produces `struct S { void x(); };`. The change is precisely the replacement of the declarator and type specifier to form a simple member function prototype.
