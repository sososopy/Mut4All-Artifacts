Mutation Operator: ConceptRequiresExpressionMissingCurlyBrace

Target: A concept definition that uses a requires-expression without a closing curly brace in its requirement body.

Description: Replace the closing curly brace in a concept's requires-expression requirement body with a semicolon or omit it entirely, leaving the requires-expression malformed.

Example: Given a concept definition like:
template<typename T>
concept C = requires(T a) { a.f(); };

Mutate to:
template<typename T>
concept C = requires(T a) { a.f(); ;

Or:
template<typename T>
concept C = requires(T a) { a.f(); }

Note: The mutation must preserve existing variable names and types from the seed program. The requires-expression body must contain at least one requirement (like a call or operation) but lack the proper closing brace. This targets the parser's handling of malformed concept definitions, particularly when the requires-expression is incomplete. The mutation should be applied to any concept definition in the seed program that includes a requires-expression.
