mutation operator
This mutation targets preprocessor conditional directives that contain line continuations within macro or feature-test expressions. Specifically, it applies when a preprocessor conditional (such as #if, #elif, #ifdef, #ifndef) includes a line continuation character (backslash followed by newline) inside the condition expression or its arguments. The operator modifies the placement of the line continuation relative to parentheses and tokens in the expression. For a seed program containing any preprocessor conditional, the mutation alters the condition by inserting or moving a backslash-newline sequence between tokens, ensuring the sequence does not split a token (like an identifier or number) but can split after an operator, before an opening parenthesis, after a closing parenthesis, or between a macro name and its opening parenthesis. The change must produce a valid preprocessor expression according to the C++ standard, as line continuation is allowed in such contexts. The operator prefers to use existing condition expressions from the seed; if no suitable conditional exists, it does not apply. Example: Original #if defined(SOME_MACRO) && SOME_MACRO > 0 could become #if defined(SOME_MACRO) \ && SOME_MACRO > 0. Another example: Original #if __has_embed("file") could become #if __has_embed(\ "file"). The mutation ensures the backslash is placed at the end of a line with no trailing whitespace except the newline.
