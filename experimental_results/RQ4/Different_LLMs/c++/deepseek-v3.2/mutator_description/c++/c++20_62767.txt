mutation operator: Replace a string literal template argument with a char array variable of matching size. This applies when a non-type template parameter is of a type deduced from a string literal via class template argument deduction (CTAD) and is used as a template argument directly. In the seed program, locate a template instantiation using a string literal as a template argument, where the template parameter type is a class type deduced from string literals. Replace the string literal with a named character array variable declared as const char array_name[literal_size] = "same_literal"; and change the template argument from the literal to array_name. Ensure the array variable is declared in the same scope as the template instantiation, before the call. Use the exact size of the original literal for the array dimension. For example, if the original code contains foo<"test">();, mutate to const char arr[5] = "test"; foo<arr>();. This mutation changes the deduction context from a literal to an array variable, potentially exposing bugs in template argument deduction for CTAD-enabled types.
