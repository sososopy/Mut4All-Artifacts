Mutation operator: Replace template argument constraint with unconstrained placeholder

This mutation operator applies when a template parameter uses a concept constraint involving non-type template parameters (NTTPs). Specifically, it targets template definitions where a concept is applied to auto... or similar NTTP patterns within template template parameters. The operator modifies the constraint by removing the concept requirement, leaving only the unconstrained NTTP placeholder.

Where it applies: In template declarations where a template template parameter has a constraint like "template<C auto...> typename Templ", where C is a concept name found in the seed program.

Changes: Remove the concept identifier before "auto..." in the template parameter list. The constraint "C auto..." becomes just "auto...". All other parts of the template remain unchanged.

Example from seed context (using existing concept name 'C'):
Original: template<template<C auto...> typename Templ> struct template_ {};
Mutated: template<template<auto...> typename Templ> struct template_ {};

If the concept name is different (e.g., 'Constraint'), use that existing name:
Original: template<template<Constraint auto...> typename Templ> struct X {};
Mutated: template<template<auto...> typename Templ> struct X {};

Note: This operator only applies when the concept is already defined in the seed program. It does not introduce new concepts or types. The mutation removes the binding constraint while preserving the NTTP pattern, which may lead to invalid bindings or internal compiler errors during template argument deduction.
