mutation operator: replace decltype member access with decltype static member access. target: decltype expressions that access a non-static member of a class or struct via ::. apply when a decltype specifier contains a nested name specifier using :: to reference a member that is not static. replace the member name with a static member of the same type if one exists in the seed program; if no static member exists, introduce a static member declaration in the class. example: for a class S with a non-static member Func, change decltype(S::Func()) to decltype(S::StaticFunc()). if S does not have a static member, add static void StaticFunc() {} to the definition of S before mutation. ensure the static member is accessible and has a compatible type. this mutation modifies the decltype context to trigger compiler checks on static member access via ::, which may expose internal compiler errors in type trait evaluations like is_invocable_v.
