mutation operator targeting defaulted template arguments involving concepts and lambda expressions in C++20. This operator applies to template parameter lists where a default argument is provided and uses a concept constraint. The mutation changes the default argument to a lambda expression that is syntactically valid but may have different capture semantics or body complexity, aiming to trigger parser or semantic analysis issues. Specifically, it replaces the default lambda with a lambda that captures a variable from the surrounding context if one exists, or introduces a simple capture if no suitable variable is present. For example, if the seed program has a variable 'x' of a suitable type, the mutation changes the default lambda from something like '[](auto arg) { return true; }' to '[x](auto arg) { return x(arg); }' ensuring 'x' is used inside the lambda body. If no such variable exists, a new variable 'dummy' of a suitable type is introduced by adding a declaration before the template, such as 'auto dummy = false;' and the lambda captures 'dummy' like '[dummy](auto arg) { return dummy; }'. The mutation modifies only the default argument part of the template parameter, keeping the concept constraint unchanged. This operator is designed to expose bugs in handling defaulted template arguments with concepts and lambdas, especially when the lambda involves captures or references to external variables, which can complicate parsing and instantiation.
