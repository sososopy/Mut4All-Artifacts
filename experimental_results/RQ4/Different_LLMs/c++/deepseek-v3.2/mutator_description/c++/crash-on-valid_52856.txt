Mutation operator: UsingEnumInCompoundExpressionMutation

This mutation operator targets the use of 'using enum' declarations within compound expressions. It applies when a seed program contains a struct or class with an enum definition, and that enum is brought into scope via a 'using enum' statement.

The operator modifies the code by taking an existing enum type defined within a struct/class and inserting a 'using enum' declaration for it inside a function scope (typically main or another relevant function). It then modifies an existing expression or creates a new one to use the enum constants directly (without qualification) within a compound expression, such as one enclosed in parentheses or involving bitwise operations.

Specifically, the changes are:
1. Identify an enum type E defined within a struct or class S in the seed program.
2. Inside a function body (preferring main if it exists, otherwise a suitable function context), insert the statement: using enum S::E;
3. Locate or create an expression that uses constants of enum E. If such an expression exists, mutate it to use the constants without qualification and ensure it is part of a compound expression (e.g., wrap it in parentheses or combine it with another constant using an operator like '|'). If no such expression exists, introduce a new variable declaration that uses the constants in a compound expression (e.g., int x = (C1|C2);), where C1 and C2 are constants from E, preferring constants that are already referenced elsewhere in the seed program.

Example based on the bug report: Given a seed with a struct Bar containing enum Foo { A, B, C };, the operator would insert 'using enum Bar::Foo;' inside main and change an existing expression like int f = Bar::Foo::A; to int f = (A|B); or similar.

Note: The operator uses only existing enum types and constants from the seed program. If the seed lacks a suitable enum within a struct/class, this operator does not apply. The goal is to trigger compiler crashes related to scope resolution and expression parsing when using enum constants in compound contexts after a using enum declaration.
