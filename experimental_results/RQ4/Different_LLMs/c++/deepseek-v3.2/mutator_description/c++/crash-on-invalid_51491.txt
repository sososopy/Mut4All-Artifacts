Mutation operator: Insert an export keyword before a template specialization that is not within a module interface unit. This operator applies to any template specialization (including class template, function template, or variable template) that appears outside a module context. Specifically, target a template specialization declaration that is already present in the seed program. If the seed program contains a template specialization like "template <typename T> void someFunction(T arg) { }" or "template <typename T> class SomeClass { };", then mutate it by prepending the export keyword to the specialization line. For example, if the seed has "template <> void someFunction(int arg) { }", change it to "export template <> void someFunction(int arg) { }". Ensure that the mutation is applied only to template specializations that are defined outside any module declaration (i.e., not preceded by "module;" or within a module interface unit). The change involves adding the export keyword immediately before the template keyword in the specialization declaration. If the seed program does not contain any template specialization, this operator does not apply. The operator aims to trigger crashes related to improper export usage in non-module contexts, as seen in the bug report where the compiler crashes when encountering export on a template specialization outside a module.
