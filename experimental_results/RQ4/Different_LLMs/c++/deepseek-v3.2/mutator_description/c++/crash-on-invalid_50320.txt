Mutation operator: Replace constant initializer with erroneous dependent assignment.

Target: Constant initialization expressions in variable declarations (including static and global variables). Applies when a variable is declared with 'const' or has a static storage duration and uses an initializer list or assignment expression.

Changes: For a declared constant or static variable with an initializer, replace the initializer with an assignment expression that attempts to assign a value from a variable of incompatible type or from a variable that is not constant, placed inside an initializer list. Specifically, take an existing variable 'X' (non-const) and an existing constant variable 'Y', then form an initializer like: { Y = X }. This creates a dependent assignment inside the initializer list that violates constant initialization rules.

Example: Original code has `const int var1 = 5; static int var2[] = {1, 2};`. Mutated code introduces erroneous dependent assignment: `const int var1 = 5; static int var2[] = { var1 = var2 }`. Here, var2 is non-const array and var1 is const, attempting assignment in constant initializer context.

Note: Use existing variables from the seed program. Ensure the assignment uses a const variable as the left operand and a non-const variable as the right operand within the initializer list. If no suitable const and non-const variables exist, introduce a new const variable with a simple literal initializer (e.g., `const int new_const = 0;`) and use an existing non-const variable for the assignment. The introduced const variable must be declared before use. Avoid introducing new types or functions.
