mutation operator: replace requires clause in class template partial specialization with a conjunction of constraints using a requires expression that accesses nested template member types.

target: class template partial specialization that has a requires clause. applies when a class template has at least one partial specialization with a requires clause. the mutation modifies the requires clause of the partial specialization.

procedure: locate a class template partial specialization that includes a requires clause. replace the entire requires clause with a new requires expression that forms a conjunction of constraints. the new requires expression should include a nested template member type access similar to T::template value_types as in the bug report, but using types and names already present in the seed program. if the seed program does not have such a nested template member, introduce a dummy template class inside a struct that is already defined or can be added without causing undeclared identifier errors. for example, if the seed program has a struct S, add inside it a template template member type alias using a placeholder. the mutation should not use specific names from the bug report like void_t or C1. instead, use generic constructs. example seed code: template<class T> struct Base {}; template<class T> requires sizeof(T) == 1 struct Base<T> {}; mutated code: template<class T> requires requires { typename T::template inner_template; } && sizeof(T) == 1 struct Base<T> {}; here, inner_template should be a template template member that exists or is added. to add it, ensure there is a struct that contains a template template alias, e.g., struct Holder { template<template<class> class> using inner_template = int; }; this should be declared before the partial specialization. the mutation should ensure the requires clause becomes more complex with nested template type accesses to trigger similar compiler crashes.
