mutation operator

This mutation targets alias templates that define a std::variant with multiple alternative types. It applies specifically to alias declarations of the form "using Identifier = std::variant<TypeList>;" where TypeList is a comma-separated list of two or more types. The mutation operator replaces the std::variant with a std::tuple containing the same list of alternative types. This change stresses template argument handling and type substitution during alias instantiation, which are areas implicated in the crash.

The operator should be applied only when the alias template's right-hand side is a std::variant specialization. It should preserve the left-hand side alias name and the list of types inside the angle brackets. The change is: replace "std::variant" with "std::tuple". For example, if the seed program contains "using NodeType = std::variant<int, float, char>;", mutate it to "using NodeType = std::tuple<int, float, char>;". If the alias is templated, like "template<typename T> using Alias = std::variant<T, double>;", mutate to "template<typename T> using Alias = std::tuple<T, double>;". This mutation uses existing types from the seed; no new types or variables are introduced. The operator is designed to expose bugs in template argument deduction and substitution, particularly when the alias is used later in variable declarations or function calls that rely on variant-specific behavior.
