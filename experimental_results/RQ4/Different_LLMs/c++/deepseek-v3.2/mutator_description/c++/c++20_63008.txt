mutation operator: replace a parenthesized initializer list in a new expression constructor argument with an empty braced initializer list.

This mutation applies to any new expression where one of the constructor arguments is a parenthesized initializer list (i.e., parentheses containing a braced-init-list). The mutation changes that parenthesized initializer list to an empty braced initializer list.

For example, if the seed program contains a line like `new SomeType( value, {subvalues} );`, mutate it to `new SomeType( value, {} );`. The mutation must target a specific argument in the new expression that originally uses parentheses around a braced list. The empty braces `{}` are inserted directly, without any surrounding parentheses. This change should use the existing types and variable names from the seed program. Only the form of that one argument is altered; the rest of the new expression remains unchanged. This operator is designed to expose potential compiler bugs in handling mixed initialization styles within new expressions, particularly where empty initialization lists interact with constructor overload resolution or aggregate initialization.
