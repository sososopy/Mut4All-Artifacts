mutation operator: Replace `constexpr` with `inline` in deleted member function declarations.

This mutation applies to any member function declaration that uses `constexpr` followed by `= delete`. It changes the `constexpr` specifier to `inline`. This targets a specific compiler handling of `constexpr` combined with deleted functions, which may expose parsing or semantic analysis bugs similar to the crash reported.

The operator only modifies existing declarations. It does not introduce new variables, types, or functions. It directly alters the specifier keyword in the source code. For example, if a seed program contains: `constexpr void someFunction() = delete;`, it would be mutated to: `inline void someFunction() = delete;`. The change is limited to the keyword replacement; all other parts of the declaration remain unchanged, including the function name, parameters, and the `= delete` suffix. This mutation is designed to test compiler reactions to different specifiers on deleted functions, potentially triggering frontend crashes or invalid code diagnostics.
