mutation operator: Introduce a constexpr variable declaration with an incomplete struct type and an initializer. This mutation targets variable declarations at global or namespace scope, or within function bodies, where a struct type is forward-declared but not defined. The operator modifies a seed program by adding a new declaration. For any existing struct type S that is declared but not defined in the current translation unit (e.g., via 'struct S;'), insert a constexpr variable declaration of that type. If no such incomplete struct exists, first add a forward declaration of a new struct type (e.g., 'struct MutOpStruct;') to the seed program. Then, insert a constexpr variable declaration using that incomplete struct type, with an initializer list containing a single integer zero. The new declaration should be placed at the same scope as the forward declaration, typically at global scope. For example, if the seed program has no incomplete struct, the mutation adds 'struct MutOpStruct;' followed by 'constexpr struct MutOpStruct mut_op_var = { 0 };'. If the seed program already contains 'struct Incomplete;', then the mutation adds 'constexpr struct Incomplete mut_op_var = { 0 };' without adding a new struct forward declaration. The variable name 'mut_op_var' should be unique and not conflict with existing identifiers in the seed program. This mutation is designed to trigger compiler crashes related to constexpr checking with incomplete non-literal types, as seen in the bug report.
