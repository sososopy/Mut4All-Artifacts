Mutation Operator: Incomplete Type Enum Mutation

This mutation operator targets enum declarations that reference incomplete types. It applies specifically to enum definitions where the underlying type is explicitly specified. The operator mutates the underlying type of an enum to an incomplete forward-declared type, which should trigger compiler diagnostics but may expose crashes in type resolution logic.

Applicable when:
- The seed program contains at least one complete struct/class declaration
- The seed program contains at least one enum declaration with an explicit underlying type
- The seed program contains at least one forward declaration of a struct/class

Mutation procedure:
1. Identify all enum declarations with explicit underlying types (e.g., "enum E : T" where T is a complete type)
2. For each such enum, identify all forward-declared but incomplete types in scope (e.g., "struct S;" without definition)
3. Replace the complete underlying type T with an incomplete type I from step 2
4. If no incomplete types exist, create a forward declaration "struct MutatedIncompleteType;" before the enum and use this as the underlying type

Example transformation:
Original: struct CompleteType { int x; }; enum MyEnum : CompleteType { VALUE1, VALUE2 };
Mutated: struct CompleteType { int x; }; struct IncompleteType; enum MyEnum : IncompleteType { VALUE1, VALUE2 };

Constraints:
- Only use types already declared in the program or explicitly created forward declarations
- Never introduce undefined variables or values
- Preserve all other aspects of the enum definition (enumerators, scoping, etc.)
- Apply mutation only when the resulting code would be syntactically valid C++
