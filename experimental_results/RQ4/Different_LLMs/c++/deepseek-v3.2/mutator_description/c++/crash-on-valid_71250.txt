mutation operator: InsertNoUniqueAddressAttribute

This mutation operator targets C++ structure or class definitions that contain fields. It applies when a seed program contains at least one non-static data member within a struct or class definition that does not already have the [[no_unique_address]] attribute. The operator modifies the source code by adding the [[no_unique_address]] attribute to one eligible field declaration. The selection of the target field should prioritize fields whose type is an empty class or struct (a class/struct with no non-static data members and no virtual functions), if such a type exists in the program. If no empty type exists, the operator can target any non-static data member of a non-empty type. The attribute is inserted immediately before the declarator of the field. If the program uses Objective-C++ (as indicated by .mm file extension or Objective-C constructs), this mutation becomes especially relevant, but it is not limited to Objective-C++ contexts.

Example application in pseudo-code:
Original seed code snippet:
struct S {
    int x;
    double y;
};
Mutated code snippet:
struct S {
    [[no_unique_address]] int x;
    double y;
};
If an empty type E exists:
struct E {};
struct S {
    E e;
    int x;
};
Mutated code snippet:
struct S {
    [[no_unique_address]] E e;
    int x;
};
The operator must ensure that any types or variables referenced are already defined in the seed program. No new declarations are introduced by this operator; it only adds the attribute to existing field declarations. The change is made to a single field per mutation application.
