Based on the bug report, crashes often occur when C++ specific constructs are used within C source files, triggering parser assertions that expect C++ language options. The mutation operator targets inserting C++-only tokens into C code.

Mutation operator: Insert C++ scope operator in C source file.
This mutation applies to any C source file (identified by .c extension or -x c flag). It inserts the C++ scope resolution operator '::' at a random location where a token can be placed, such as at the beginning of a line, before a statement, or after a valid token. The operator is inserted as a standalone token without context, mimicking the bug report example. The change is simply adding '::' to the source code, ensuring it is parsed as a token. For example, in a C file containing `int x = 5;`, mutate to `:: int x = 5;` or `int x = 5 :: ;`. This exploits the parser's assumption that C++ constructs are only in C++ files, leading to assertion failures.
