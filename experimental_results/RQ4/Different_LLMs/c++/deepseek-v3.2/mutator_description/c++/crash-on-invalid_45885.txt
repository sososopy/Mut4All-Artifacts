Mutation operator: Replace a macro expansion with an empty token sequence at the end of a file.

This mutation applies when a source file contains a macro invocation that expands to nothing (i.e., an empty expansion) and this macro invocation is placed as the very last token in the file, immediately before the end-of-file. The operator targets macro definitions that yield empty expansions, either via an empty replacement list or through conditional directives that result in no tokens.

The mutation modifies the seed program by:
1. Identifying any macro definition in the program that currently expands to a non-empty sequence of tokens. This macro must be used (invoked) somewhere in the code.
2. Changing that macro's definition so that its replacement list becomes empty. For example, if the original macro is defined as `#define MACRO(x) some expression`, it is mutated to `#define MACRO(x)` (with no tokens after the identifier).
3. Ensuring that one invocation of this mutated macro is placed at the absolute end of the source file. This means inserting or moving a line containing only this macro invocation (and any required arguments) such that it is the final line before the EOF, with no subsequent characters or tokens. If the seed file already ends with a macro invocation, that invocation is changed to use the now-empty macro.

For example, consider a seed snippet ending normally. The mutation would alter a macro `#define FOO 123` to `#define FOO`, and then add a line `FOO` right at the file's end. The final file content ends with that line, followed directly by EOF.

Preference is to use existing macros and their invocation sites. If no suitable macro exists, a new macro must be introduced: declare a simple macro at the top of the file with an empty replacement list, e.g., `#define EMPTY`, and then insert a lone invocation `EMPTY` as the last line of the file. This ensures the compiler parses a macro expanding to nothing at the EOF boundary.
