mutation operator: Replace explicit specialization of inherited constructor with explicit specialization of a derived class constructor that directly matches the base class constructor signature.

This mutation applies when a class explicitly specializes an inherited constructor from a base class using a using-declaration combined with an explicit specialization syntax. The mutation changes this to define an explicit specialization of a constructor within the derived class that has the same parameter list as the base class constructor being specialized.

For a seed program containing:
struct Base {
    template<typename T> Base(T);
};
struct Derived : Base {
    using Base::Base;
};
template<> Derived::Derived(int) { }

Mutate to:
struct Base {
    template<typename T> Base(T);
};
struct Derived : Base {
    using Base::Base;
    template<> Derived(int);
};
template<> Derived::Derived(int) { }

The change is to move the explicit specialization declaration inside the derived class body, removing the dependency on the using-declaration for the specialization. Ensure the parameter types in the specialization match an existing base class constructor template instantiation. Use only types and parameter lists already present in the seed program. If the base class constructor is a template, the specialized type must be one that the template can be instantiated with. Do not introduce new types or default arguments not already in the seed.
