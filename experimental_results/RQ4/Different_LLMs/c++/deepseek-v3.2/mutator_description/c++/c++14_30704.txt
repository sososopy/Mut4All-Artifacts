mutation operator: In a generic lambda within a class derived from a lambda type, replace the trailing return type decltype expression that calls the base lambda operator with a direct call to the base lambda operator inside the function body and change the return type to auto, ensuring the base class is accessible via this or explicit scope. Apply when a class template inherits from a lambda type and has a member function template with a trailing return type that invokes the base lambda's operator() within decltype. Change the function signature from having a trailing return type using decltype to using auto return type and move the base lambda call from the decltype into the function body as a statement, preserving the call's arguments. For example, given: template<typename... Args> auto operator()(Args... args) -> decltype(Func::operator()(args...), void()) { Func::operator()(args...); } mutate to: template<typename... Args> auto operator()(Args... args) { Func::operator()(args...); } This removes the decltype-based trailing return type computation that may trigger compiler ICEs involving inheritance and lambda expressions. The mutation applies only if the original function uses decltype with a call to Func::operator() and returns void or a comma operator result; it simplifies the return type deduction to auto, relying on the compiler to deduce the return type from the function body. Ensure the mutated function body includes the same call as in decltype, using existing parameters. If the original has additional statements, retain them. Do not introduce new variables or types; use only existing elements from the seed program.
