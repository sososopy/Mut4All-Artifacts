Mutation operator: Insert invalid token sequence into existing annotation declarations.

Targets annotation declarations such as __attribute__, __declspec, or [[attributes]] in C++ code. Applies when the seed program contains at least one annotation on a function, variable, or type declaration.

The mutation replaces a valid annotation with an invalid token sequence by inserting an unexpected token inside the annotation syntax. For example, if the seed has `__attribute__((visibility("default")))`, mutate to `__attribute__((visibility("default"))) unexpected_token`. The inserted token is chosen from existing identifiers or keywords in the seed program, such as a function name or a type name already declared, to avoid introducing undeclared elements. If no suitable token exists, insert a basic punctuation like `;` or `}` that breaks annotation parsing.

Changes: Locate an annotation in the seed. After the closing parenthesis or bracket of the annotation, insert a token that is present in the seed program's code, such as an existing variable name or a keyword like `int`. Ensure the insertion does not create a syntactically correct annotation extension but rather a malformed sequence that should be invalid. For example, given seed code `void func() __attribute__((deprecated));`, mutate to `void func() __attribute__((deprecated)) func;` using the existing function name `func`. This disrupts the annotation parsing flow while using only existing elements from the seed.
