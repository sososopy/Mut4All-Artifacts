Mutation operator: Replace member access through a pointer with member access through a non-pointer base, while preserving the same member name. This mutation applies when the code contains an expression of the form `pointer->member`, where `pointer` is a variable or expression of pointer type. The operator changes the expression to `base.member`, where `base` is a non-pointer variable or expression of the same underlying type as the pointer's pointee type. The base must be an existing variable or expression in the seed program that is not a pointer. If no suitable non-pointer base exists, introduce a local variable of the appropriate type, initialized with a default constructor or zero-initialization, and use it as the base. For example, if the seed contains `ptr->field`, change it to `obj.field` where `obj` is a non-pointer variable of the same struct/class type as `ptr`'s pointee. This can trigger crashes when the compiler expects a pointer or array type in certain contexts, such as during type deduction or overload resolution.
