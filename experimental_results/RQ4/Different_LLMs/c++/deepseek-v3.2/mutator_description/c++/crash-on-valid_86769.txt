Mutation Operator: Introduce a dependent-type friend declaration within a templated class that uses a concept.

This operator applies when a seed program contains a class template that is constrained by a concept (C++20 feature). The mutation involves adding a friend declaration inside this class template. The friend should be declared as a template class with the same concept constraint, but using a different template parameter name. This creates a scenario where the compiler must handle friend injection and concept satisfaction checking in a potentially circular or dependent context.

Steps for the mutation:
1. Locate a class template declaration in the seed program that is constrained by a concept. For example, find a template of the form: template <ConceptName TypeParam> class ClassName { ... };
2. Inside the body of this class template, before the closing brace, insert a friend declaration. The friend declaration should be: template <ConceptName OtherParam> friend class ClassName;
3. Ensure that the concept name used in the friend declaration is the same as the one constraining the outer class template. The template parameter name (OtherParam) must be different from any existing template parameter names in the scope to avoid shadowing conflicts. If the seed program already uses a specific concept, reuse that exact identifier.
4. This mutation does not introduce new types, variables, or functions beyond the friend declaration. It relies solely on existing elements: the class template name and the concept name.

Original seed code snippet:

concept MyConcept = true;

template <MyConcept U>

    // existing methods...
