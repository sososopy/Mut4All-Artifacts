Mutation Operator: Insert missing comma in template parameter list before ellipsis where template parameter pack is followed by another template parameter without separating comma.

Applicable Context: This mutation targets template declarations where a template parameter pack (e.g., `class... T` or `auto... Vs`) is immediately followed by another template parameter (e.g., `T... Args` or `Vs3`) without a separating comma in the template-parameter-list.

Mutation Description: In a template declaration, if a template parameter pack is followed by another template parameter (which could be another pack or a non-pack parameter) and there is no comma between them, insert a comma after the pack's ellipsis. This mutation applies only when the two parameters are consecutive in the list without any comma token.

Implementation Steps:
1. Identify a template declaration (class, function, or alias template).
2. Parse its template-parameter-list.
3. Find a sequence where a template parameter ends with an ellipsis (`...`) and the next template parameter begins immediately after (no comma token in between).
4. Insert a comma token after the ellipsis of the first parameter.

Example Seed Code:
template <typename... Ts int N>
struct S;

After Mutation:
template <typename... Ts, int N>
struct S;

Note: This mutation uses existing elements from the seed (template parameter names and types). It does not introduce new variables, types, or functions. The change is purely syntactic: adding a missing comma token.
