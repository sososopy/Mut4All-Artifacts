Mutation operator: Incomplete concept definition substitution.

This mutation operator targets C++20 concept definitions. It applies when a concept is declared in the seed program, specifically within its constraint expression. The operator replaces the constraint expression of a concept with an incomplete or malformed expression that is syntactically valid but semantically problematic for normalization. The goal is to produce situations where the compiler's internal normalization routines might receive a null or unexpected expression pointer.

The mutation is performed as follows: locate any concept declaration in the seed program. The concept declaration must have a constraint expression (the part after the '='). Replace that constraint expression with a literal integer '0'. This mimics the bug report's structure where the concept 'g' is defined as '0'. If the seed program does not contain a concept, this operator does not apply. The replacement should preserve the concept's name and template parameters if present. The operator uses existing names from the seed; no new identifiers are introduced.

Example: In the seed, if there is a concept declared as 'template<typename T> concept C = some_constraint;', mutate it to 'template<typename T> concept C = 0;'. This changes the constraint from a potentially valid expression to a literal zero, which is a valid C++ expression but is not a meaningful constraint and may lead to internal assertion failures during constraint normalization.
