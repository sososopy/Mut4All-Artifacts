Mutation operator: Replace a variable declaration with a type alias for an array initialized using parentheses aggregate initialization syntax. This mutation applies to variable declarations where the variable type is an array type or a type alias for an array type. The mutation operator changes the variable declaration to use parentheses instead of braces for initialization if the original initialization uses braces, or introduces a type alias for an array and then declares a variable using parentheses initialization. Specifically, for a variable declaration like 'int arr[2] = {1, 2};', mutate to 'using T = int[2]; T arr(1, 2);'. If the seed program already contains a type alias for an array, use that alias directly. If not, introduce a new type alias before the variable declaration. Ensure the array size matches the number of initializers. For incomplete array types, use 'int[]' with appropriate initializers. Example: Original code 'int x[3] = {10, 20, 30};' mutated to 'using A = int[3]; A x(10, 20, 30);'. This targets C++20's paren-init of aggregates, specifically arrays, which can trigger compiler assertion failures like the one reported.
