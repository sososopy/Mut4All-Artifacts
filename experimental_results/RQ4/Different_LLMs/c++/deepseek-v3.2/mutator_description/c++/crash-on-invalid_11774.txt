Mutation Operator: Malformed namespace nesting with semicolon insertion. This operator applies when the seed program contains at least one namespace declaration. It targets the structure of nested namespace definitions by inserting an erroneous semicolon between the namespace keyword and its identifier, or within a chain of nested namespace identifiers, creating a parsing ambiguity that may trigger a compiler crash during invalid input handling. The mutation modifies an existing namespace declaration in the seed program. For each namespace declaration, select one occurrence. If the namespace is declared as 'namespace A { ... }', change it to 'namespace ; A { ... }'. If it is a nested namespace declaration like 'namespace A::B::C { ... }', change it to 'namespace A::; B::C { ... }' or similar, inserting the semicolon after one of the scope identifiers but before the subsequent identifier or braces, ensuring the semicolon is placed where a namespace name would be expected. The inserted semicolon uses existing syntax elements from the seed; no new identifiers are introduced. Example: Original seed code has 'namespace outer { namespace inner::detail { } }'. Mutated code becomes 'namespace outer { namespace inner::; detail { } }'. This mutation specifically aims to exploit parser state inconsistencies when encountering unexpected tokens in namespace parsing contexts.
