Mutation Operator: Replace Decimal Literal with Braced Initializer in Return Statements

This mutation operator targets return statements that contain floating-point decimal literals. It applies specifically when a function returns a floating-point type (float, double, long double) and the return expression is a decimal literal (e.g., 1.0, 3.14). The operator changes the literal to a braced initializer list containing that literal.

The change is made by taking a return statement of the form `return <decimal_literal>;` and mutating it to `return {<decimal_literal>};`. This introduces list initialization, which can trigger different compiler behavior in C++14 compared to earlier standards, particularly in contexts involving template argument deduction, auto type deduction, or narrowing conversion checks.

For example, given a seed program containing:
    double func() {
        return 2.5;
    }
The mutated version would be:
    double func() {
        return {2.5};
    }
This mutation should use the existing variable names and types from the seed program. No new elements are introduced; only the syntax of the return statement is altered. The operator should only apply when the return expression is solely a decimal literal, not a variable or complex expression. This targets potential compiler crashes (ICE) related to list initialization and literal parsing in C++14 mode.
