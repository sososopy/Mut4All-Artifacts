mutation operator

Target code construct: Lambda expressions within template functions, especially those that capture variables by reference or by value, when the lambda is used inside a template instantiation that involves nested templates or constraints. This applies when a lambda is defined inside a template function or method, and the lambda captures local variables or parameters of that template function.

Mutation operator: Modify the capture list of a lambda expression inside a template function to include an additional capture of a variable that is already in scope but not currently captured, or change the capture mode (e.g., from by value to by reference or vice versa). Specifically, for a lambda that currently captures no variables or captures some variables, add a capture of a variable that is declared in the enclosing template function's body before the lambda. If the seed program has a lambda with an empty capture list [], mutate it to capture a local variable by reference, e.g., change [] to [&var] where var is a variable declared earlier in the same scope. If the lambda already captures variables, add another capture of a different variable from the same scope, preserving existing capture modes. If no suitable variable exists in the scope, introduce a new local variable of a simple type (like int) with a default initializer (like 0) immediately before the lambda, and then capture it by reference in the lambda's capture list. The new variable should be declared as: auto var = 0; or int var = 0; depending on the context. The mutation must ensure the captured variable is used within the lambda body to potentially trigger capture-related compiler logic; therefore, also add a dummy use of the captured variable inside the lambda body, such as a statement that reads its value (e.g., if (var) {} or auto unused = var;). This dummy use should not alter the original semantics significantly, but should be syntactically correct.

Example: In a template function, if there is a lambda defined as [] (auto x) { return x; }, and there is a local variable int y = 5; before the lambda, mutate to [&y] (auto x) { auto dummy = y; return x; }. If no local variable exists, insert int z = 0; before the lambda and mutate to [&z] (auto x) { auto dummy = z; return x; }.
