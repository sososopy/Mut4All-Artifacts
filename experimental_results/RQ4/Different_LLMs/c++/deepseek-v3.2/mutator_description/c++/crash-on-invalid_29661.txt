mutation operator: replace template instantiation with malformed template argument list

This mutation operator targets template instantiation syntax in C++ code. It applies when a seed program contains template class or function instantiation using explicit template arguments (e.g., MyClass<int> or func<float>(x)).

The operator modifies the template argument list by inserting an invalid token sequence immediately after the opening angle bracket. Specifically, it changes a valid template instantiation like "TemplateName<ValidArg>" into "TemplateName< <InvalidToken> ValidArg>" where <InvalidToken> is an additional angle bracket inserted before the first template argument. This creates a nested angle bracket without proper separation, which violates C++ syntax rules for template argument lists.

For example, if the seed code contains:
std::vector<int> v;
The mutation would produce:
std::vector<< int> v;

If the seed code contains:
auto result = func<double>(arg);
The mutation would produce:
auto result = func<< double>(arg);

The operator uses only elements already present in the seed program (the template name and existing template arguments). No new variables, types, or functions are introduced. The change is purely syntactic: inserting an extra '<' token immediately after the initial '<' that starts the template argument list. This creates a malformed template argument sequence that should trigger parsing errors but may expose compiler crashes in template handling code.
