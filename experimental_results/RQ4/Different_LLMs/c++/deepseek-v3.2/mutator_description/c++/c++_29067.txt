Mutation Operator: Member Pointer Assignment Mutation

Target: This mutation operator applies to assignments involving pointers to members in C++ code. It specifically targets statements where a pointer to a member is being assigned a value, including cases where the assignment might be invalid due to type mismatches or improper context.

Application: When a seed program contains an assignment statement that assigns a value to a pointer to a data member or a pointer to a member function, this operator will mutate the right-hand side (RHS) of the assignment. The mutation changes the RHS to an expression that attempts to take the address of a non-static member without using the correct class scope or using an incorrect syntax, which can trigger compiler assertions related to placeholder types or member pointer handling.

Changes: For an assignment of the form `LHS = RHS;` where LHS is a pointer to a member (e.g., of type `int Class::*` for data members or `void (Class::*)()` for member functions), replace RHS with `&MEMBER_NAME`. Here, MEMBER_NAME must be a non-static member (data or function) that exists in the seed program, but it is selected from a different class than the one LHS expects, or it is used without the proper class qualification. If no such member exists in the seed program, introduce a new member in a random class by adding a declaration (e.g., add `int new_member;` to a class definition) and use it in the mutation. The mutation should avoid using ambiguous or undefined identifiers.

Example: In a seed program with classes A and B, where A has a member pointer `int A::* ptr` and B has a member `int b_data`, mutate an assignment like `ptr = &A::a_data;` to `ptr = &b_data;` (which is invalid because b_data is not a member of A). This can expose bugs in compiler frontends when processing invalid member pointer assignments, potentially triggering assertions like the one in the bug report.
