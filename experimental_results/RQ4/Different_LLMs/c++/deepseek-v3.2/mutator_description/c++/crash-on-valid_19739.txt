Mutation Operator: Explicit Specialization of Inherited Constructor in Derived Class Template

Applies to: Explicit specialization of a derived class template that inherits a constructor from a base class using a using-declaration.

Description: This mutation operator modifies a class template that inherits a constructor from its base class via `using Base::Base;`. It introduces an explicit specialization of the derived class template for a specific type. The specialization must redeclare the inherited constructor explicitly, as the using-declaration from the primary template is not carried over into the specialization. This can trigger compiler assertions related to canonical declarations of overridden methods or constructors, particularly in contexts involving template instantiation and constructor inheritance.

Changes: For a given class template `Derived` that inherits a constructor from its base class `Base` with a using-declaration, create an explicit specialization of `Derived` for a specific template argument. In the specialization, explicitly declare a constructor that matches the inherited constructor's signature, typically using a forwarding call to the base class constructor. Ensure the specialization is placed after the primary template definition and any necessary forward declarations.

Example: Given a seed program with structures like:
template<typename T> class Base { public: Base(T); };
template<typename T> class Derived : public Base<T> { public: using Base<T>::Base; };
The mutation adds:
template<> class Derived<int> : public Base<int> { public: Derived(int x) : Base<int>(x) {} };
This introduces an explicit specialization for `int` where the constructor is explicitly defined, rather than inherited via using-declaration, which may expose bugs in compiler handling of constructor inheritance across template specializations.
