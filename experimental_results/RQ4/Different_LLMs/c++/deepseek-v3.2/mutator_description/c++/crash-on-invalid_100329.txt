mutation operator
target construct: defaulted member function definitions with explicit object parameters (C++23 deducing this) where the explicit object parameter's type mismatches the class type or is otherwise unusual.
applies to: any defaulted member function (special member functions like constructors/destructors/assignment, or comparison operators) that uses an explicit object parameter (this Type&, this auto&, etc.) in its declaration within a class/struct, and then is defined as defaulted outside the class body.
mutation description: locate a member function declaration inside a class that uses an explicit object parameter (syntax: return-type func-name (this explicit-object-parameter-type, other-parameters...)). then, outside the class, provide a definition that is explicitly defaulted (i.e., = default;). ensure the explicit object parameter type in the out-of-class definition does not exactly match the class type; instead, mutate it to a different type that is present in the seed program. if the seed program contains other user-defined types (structs, classes, enums, typedefs, etc.), select one of those types as the explicit object parameter type. if no other user-defined type exists, introduce a new type: add a dummy struct declaration before the class (e.g., struct Dummy {};) and use Dummy as the explicit object parameter type. do not use built-in types like int unless they are already used in the original declaration. the goal is to create a mismatch or unusual combination that the compiler must handle when generating the defaulted definition.
example in pseudo-code: suppose the seed program contains:
struct X { int a; };
struct Y { 
    bool operator==(this const Y&, const Y&); 
};
the mutation could change it to:
struct X { int a; };
struct Y { 
    bool operator==(this const X&, const Y&); 
};
bool Y::operator==(this const X&, const Y&) = default;
note that the explicit object parameter type changed from const Y& to const X&, using an existing type X from the seed. the definition is defaulted outside the class with this mismatched type.
