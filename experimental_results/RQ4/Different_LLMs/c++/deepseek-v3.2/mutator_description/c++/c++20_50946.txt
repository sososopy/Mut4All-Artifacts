Mutation operator: Mutate a lambda-expression appearing as a template argument within a concept requirement to a lambda-expression with a dependent constraint.

This mutation applies when a requires-expression contains a compound requirement (i.e., { expression } -> constraint) where the constraint is a concept specialization that itself uses a lambda-expression as a template argument. Specifically, it targets the lambda-expression inside the constraint's template argument list. The mutation changes the lambda's body to include a dependent constraint check, such as invoking a concept that depends on the enclosing template parameters.

For a seed program containing a template with a concept C defined via a requires-expression, locate any compound requirement where the constraint is a concept M that takes a lambda as a template argument. Replace the lambda body, originally possibly empty or simple, with a body that uses a concept check dependent on the template parameters of the surrounding context. For example, if the original lambda is []<A>(){} where A is a concept, mutate it to []<A>(){ requires A<T>; } where T is a template parameter from the enclosing template (must exist in the seed). The new lambda body becomes a requires-clause inside the lambda, making the lambda's constraint dependent on T.

If the seed program does not have a suitable template parameter T, introduce a new template parameter to the enclosing template: add a dummy parameter, e.g., template<class T, class U = int> if only one parameter exists, and use U as the dependent type in the requires-clause. The mutation must ensure all referenced concepts (like A) are already defined in the seed.

Example in pseudo-code: Original code snippet: template<class T> concept C = requires(T t) { { t.x } -> M<[]<A>(){}>; }. Mutated code: template<class T> concept C = requires(T t) { { t.x } -> M<[]<A>(){ requires A<T>; }>; }. This introduces a dependency in the lambda's constraint on T, potentially triggering the ICE in HandleDependentAccessCheck during template instantiation.
