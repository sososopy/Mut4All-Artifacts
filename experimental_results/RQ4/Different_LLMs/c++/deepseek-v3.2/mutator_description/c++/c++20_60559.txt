Mutation operator: Modify constrained parameter packs in lambda templates by swapping the order of constrained and unconstrained parameter packs within a lambda declaration. This mutation targets lambdas inside templates that use C++20 constrained template parameters (concepts) applied to parameter packs. It applies when a lambda within a template function or class template has a parameter list containing a constrained parameter pack followed by unconstrained parameters. Specifically, the mutation swaps the positions: if the lambda originally has a parameter list like (concept auto..., auto, auto...), change it to (auto, auto..., concept auto...). This reordering may expose bugs in the compiler's handling of constrained parameter pack ordering during template instantiation and constraint checking. Use existing concept names and parameter pack syntax from the seed program. For example, if the seed program contains a lambda like [&](any<Idxs> auto..., auto, auto...) { }, mutate it to [&](auto, auto..., any<Idxs> auto...) { }. Ensure the lambda's body remains unchanged, and the swap is performed only on the parameter list. This mutation should be applied to lambdas that are defined inside template functions or classes where the constrained parameter pack depends on template parameters from an outer scope.
