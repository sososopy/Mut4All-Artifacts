mutation operator
Target: Initialization of a union that contains a struct with a flexible array member (FAM). This applies when a union type is defined, and at least one of its members is a struct that ends with a flexible array member (i.e., an array of unspecified size as the last member). The mutation operator modifies the initializer of a variable of such a union type.

Transformation: For a variable declaration of a union type (including anonymous unions) where the union contains a struct with a flexible array member, replace its initializer with an empty initializer list `{}`. If the variable already has an initializer, replace it; if it has no initializer, add one. This mutation should only be applied if the union type is not a member of another aggregate (to avoid nested complexities). Use the existing variable name and type from the seed program.

Example Original Code:
union NamedUnion {
    int a;
    struct { int x; char data[]; } s;
} var = { .a = 1 };

Example Mutated Code:
union NamedUnion {
    int a;
    struct { int x; char data[]; } s;
} var = {};

Example Original Code (Anonymous Union):
struct Container {
    int tag;
    union {
        int num;
        struct { char *name; int list[]; } obj;
    } data;
} inst = { 0, { .num = 5 } };

Example Mutated Code:
struct Container {
    int tag;
    union {
        int num;
        struct { char *name; int list[]; } obj;
    } data;
} inst = { 0, {} };

Note: The mutation introduces an empty initializer for the union variable. It assumes the union and its member struct with FAM are already defined in the seed program. No new types or variables are introduced; only the initializer expression is changed. The change may expose compiler bugs in handling zero-initialization of unions containing structs with flexible array members, particularly during code generation or constant expression evaluation.
