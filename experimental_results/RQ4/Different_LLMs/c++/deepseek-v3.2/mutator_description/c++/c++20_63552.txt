Mutation operator: Replace constrained auto syntax in function parameters with explicit template parameter and requires clause.

Target: This mutation applies when a function uses constrained auto syntax in its parameter list, specifically where a concept name followed by auto appears as a parameter type. It targets C++20 concepts usage.

Description: Identify a function parameter declared with a concept name followed by auto, e.g., ConceptName auto param. Replace this parameter declaration with an explicit template parameter and a requires clause. The function must be transformed into a template function. Introduce a template parameter list before the function, using a placeholder type name T. Change the function parameter type to T. Add a requires clause after the template parameter list or after the function declaration to enforce the original concept constraint on T. Use the same concept name and any template arguments that were part of the original constrained auto syntax.

Example: Original code: void func(ConceptName auto x) { ... }
Mutated code: template <typename T> requires ConceptName<T> void func(T x) { ... }

If the original constrained auto syntax includes template arguments for the concept, e.g., ConceptName<Arg> auto x, then the requires clause must replicate those arguments: template <typename T> requires ConceptName<T, Arg> void func(T x) { ... }.

Ensure the template parameter name T is not already used in the seed program for a conflicting purpose; if T is already declared, choose a different unused identifier like U. Do not introduce new types or variables beyond the template parameter. The mutation only changes the function declaration structure, not the body.
