Mutation operator: Module Interface Unit Conversion

This mutation operator targets C++20 module declarations in source code. It applies when the seed program contains any module-related constructs, specifically when there are module declarations or imports.

The operator transforms a non-module source file into a module interface unit by adding a module declaration at the beginning of the file. If the file already contains a module declaration, this operator does not apply.

Changes to be made:
1. Insert "export module MODULE_NAME;" as the first line of the source file, before any other content.
2. The MODULE_NAME should be generated using existing identifiers from the seed program. The operator should extract the first user-defined type name, function name, or variable name from the seed program and use it as the module name. If no such identifiers exist, use a default name "mutated_module".
3. If the seed program contains any function or variable declarations that could be exported, add the 'export' specifier before them. Select the first function declaration (if any) and prepend 'export' to it.

Example transformation:
Original seed code:
int global_var;
void foo() {}
class MyClass {};

Mutated code:
export module MyClass;
export int global_var;
export void foo() {}
class MyClass {}

The operator should avoid creating ambiguous or invalid module names. The mutation focuses on triggering module-related code paths in the compiler frontend, particularly around the interaction between module declaration and code generation phases.
