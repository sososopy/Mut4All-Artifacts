Mutation operator: Replace built-in function call argument with an undeclared identifier.

This mutation operator targets calls to built-in functions, such as __builtin_fpclassify, __builtin_trap, __builtin_shuffle, and similar compiler-specific intrinsics. It applies when a seed program contains a call to a built-in function that expects a specific number and type of arguments. The mutation changes one of the arguments in the call expression to an identifier that is not declared in the current scope, meaning it is not a variable, function, or type name that has been defined prior to this point. The goal is to test the compiler's internal handling of semantic checking for built-in functions when faced with an unresolved name, potentially exposing crashes in the Sema layer during argument validation.

To apply the mutation, first locate any call expression in the seed program that invokes a built-in function. Select one argument from that call, preferably an argument that is not a literal constant (like 0, 1, or 2) to increase the chance of triggering a crash, but any argument can be chosen. Replace the selected argument with a new identifier name that does not match any existing declaration in the program. For instance, if the seed has a call like __builtin_fpclassify(0, 1, 4, 3, 2, inf), change it to __builtin_fpclassify(0, 1, 4, 3, 2, undefined_name) where 'undefined_name' is a placeholder identifier not defined elsewhere. No new declarations should be added for this identifier; it should remain undeclared. The mutation should preserve the overall structure of the call, only altering one argument.

Example: Given a seed program snippet: int main() { double x = 1.0; __builtin_isinf(x); } The mutation could produce: int main() { double x = 1.0; __builtin_isinf(undefined_name); } Here, 'undefined_name' is introduced without a corresponding declaration. This tests the compiler's reaction to an unresolved argument in a built-in function call, potentially leading to a crash during semantic analysis similar to the reported bug.
