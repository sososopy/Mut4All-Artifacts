mutation operator
This mutation operator targets explicit instantiation declarations that refer to class template member functions with constrained overloads. It applies when a seed program contains a class template with at least two member functions of the same name where at least one has a requires-clause (a constraint). The operator modifies an existing explicit instantiation declaration (or creates one if none exists) to refer to a specific constrained member function from the class template. Specifically, it transforms a simple explicit instantiation of a member function into one that explicitly selects a constrained overload by providing the complete function signature including its requires-clause. The operator should only be applied when the template arguments satisfy the constraint of the chosen overload to keep the code valid. In the seed program, identify a class template with multiple member function overloads where at least one is constrained. If an explicit instantiation declaration for the class template's member function exists (e.g., template void ClassName<TemplateArgs>::functionName();), replace it with an explicit instantiation that includes the requires-clause from the constrained overload. If no such explicit instantiation exists, create one for a constrained overload that is satisfied by the template arguments. Use the existing template name, member function name, and constraint from the seed program. The new explicit instantiation must be syntactically correct and refer to a function that exists in the template. For example, given a seed with: template<typename T> struct S { void f() { } void f() requires SomeConcept<T> { } }; and an explicit instantiation like template void S<int>::f();, and if SomeConcept<int> is true, mutate it to: template void S<int>::f() requires SomeConcept<int>;. If the seed lacks an explicit instantiation, add one for a valid constrained overload, e.g., template void S<int>::f() requires SomeConcept<int>;. Ensure the template arguments used satisfy the constraint; if not, choose other existing template arguments from the seed that do, or do not apply the mutation.
