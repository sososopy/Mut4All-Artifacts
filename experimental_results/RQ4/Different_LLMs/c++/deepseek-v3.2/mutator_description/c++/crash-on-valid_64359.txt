Mutation Operator: Insert Recursive Template Instantiation via Nested Lambda in Member Function Template

This mutation operator targets member function templates within class templates. It inserts a lambda expression inside the member function that captures *this and recursively instantiates the same member function template with modified template arguments, creating a deep instantiation chain that stresses the template substitution and deduction machinery.

Applicability: Applies to any member function template within a class template in the seed program. The class must have at least one template parameter, and the member function must be a template.

Procedure: 
1. Identify a member function template within a class template. Let the class template be named ClassTemplate with template parameters TParams. Let the member function template be named memberFunc with template parameters UParams.
2. Inside the body of memberFunc, before any return statement, insert a lambda expression that captures *this by reference.
3. The lambda should have an auto return type and take a single parameter of type const auto& (or a similar generic parameter).
4. Inside the lambda body, include a recursive call to this->memberFunc with template arguments that depend on the lambda's parameter and the class template parameters, such as using decltype on a combination of these to form a new type.
5. Ensure the lambda is invoked with a trivial argument (e.g., 0 or nullptr) to potentially trigger instantiation, but wrap the invocation in a conditional that always evaluates to false (e.g., if constexpr (false)) to avoid infinite recursion at runtime while still requiring the compiler to consider the template instantiation during parsing and semantic analysis.
