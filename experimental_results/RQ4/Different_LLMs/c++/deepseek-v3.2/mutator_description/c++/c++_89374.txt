mutation operator: Introduce a partial specialization of a class template that does not use any of its template parameters in the specialization argument list but uses them incorrectly in a base class dependency.

Target: This mutation applies when a class template is defined with at least one template parameter. It modifies a primary class template declaration into a partial specialization that is ill-formed according to the C++ standard but might trigger compiler internal errors.

Changes: For a given class template declaration in the seed program, replace it with a partial specialization that does not use its template parameters directly in the specialization type. Specifically, change a primary template like 'template<typename T> struct S;' into 'template<typename U> struct S<int> : Base<S<U>> {};' where 'Base' is an existing template from the seed program that takes a template argument, and the base class uses the template parameter 'U' in a nested context. Ensure the base class template exists in the seed program; if not, introduce a simple template like 'template<typename> struct Base;' before the specialization. The partial specialization must use a fixed type (like 'int') as the specialization argument, while the template parameter remains unused in that argument but appears in the base class's template argument.

Example: Suppose the seed program contains a template 'template<typename> struct MatrixBase;'. The mutation would change any primary class template, say 'template<typename T> struct Solve;', into 'template<typename U> struct Solve<int> : MatrixBase<Solve<U>> {};'. This creates a scenario where the partial specialization 'Solve<int>' does not use 'U' in its argument list, violating C++ rules, and the base class depends on 'U', potentially causing internal assertion failures during template deduction.

This mutation is designed to expose bugs in compiler handling of ill-formed partial specializations, particularly during template argument deduction for base classes or member functions, as seen in the bug report where an assertion about record types fails.
