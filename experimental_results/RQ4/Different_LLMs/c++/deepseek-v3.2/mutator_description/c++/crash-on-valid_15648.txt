Mutation Operator: Expand Parameter Pack With Additional Template Arguments in Alias Template Instantiation

This mutation operator targets explicit specializations or instantiations of alias templates where a template parameter pack is expanded and followed by one or more additional template arguments. It applies when a class template or alias template is declared with a template parameter pack, and there exists an explicit instantiation or specialization of that template where the template arguments include a pack expansion followed by at least one additional argument.

The mutation modifies such instantiations or specializations by altering the order or composition of the template arguments after the pack expansion. Specifically, it takes the existing sequence of template arguments that includes a pack expansion followed by additional arguments and creates a mutated version by either duplicating one of the additional arguments, inserting a previously used type from the pack (if identifiable), or swapping the positions of two arguments immediately following the pack expansion. The goal is to produce a potentially malformed or edge-case template argument list that may stress the compiler's handling of pack expansions in alias templates.

The changes must use only types, templates, or variables that are already present in the seed program. If the pack expansion is based on a template parameter pack from an enclosing template, the mutation can reuse a type from that pack if it is explicitly referenced elsewhere in the code. For example, if the pack is 'Ts...' and the code contains 'typename T' where T is one of Ts, that T can be used. No new declarations are introduced; only existing identifiers are rearranged or duplicated.

Example in pseudo-code:
Original code has an alias template: template<typename... Ps> using Alias = Template<Ps...>;
And an instantiation: Alias<Args..., Extra1, Extra2> obj;
Mutated version could be: Alias<Args..., Extra2, Extra1> obj; (swapping additional arguments)
Or: Alias<Args..., Extra1, Extra1> obj; (duplicating an additional argument)
Or if a type 'First' is known from Args, mutate to: Alias<Args..., First, Extra2> obj; (inserting a pack type)

The mutation is applied only if the seed contains at least one instantiation or specialization where a template parameter pack is expanded and followed by at least one other template argument, and all identifiers used in the mutation are already in scope.
