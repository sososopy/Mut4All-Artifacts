Mutation Operator: Variadic Template Default Argument Expansion Order Mutation

This mutation operator targets default arguments in variadic template function declarations where fold expressions are used. It applies when a function template has a variadic parameter pack and its default argument contains a fold expression over that pack. The operator modifies the evaluation order of the fold expression by altering the placement of the parameter pack relative to the operator within the default argument.

Specifically, for a default argument of the form `(std::integral<T> ||...)`, which is a unary right fold, the operator mutates it to the corresponding left fold `(... || std::integral<T>)`. This changes the order of expansion, which may expose compiler bugs related to the instantiation or evaluation sequence of variadic template arguments in default contexts.

The mutation must use only types, variables, and concepts already present in the seed program. No new declarations are introduced. The change is applied directly to the default argument expression within the function parameter list.

Example based on the bug report context:

Original code snippet:
template <typename... T>
void f1(bool B = (std::integral<T> ||...)) {
}

Mutated code snippet:
template <typename... T>
void f1(bool B = (... || std::integral<T>)) {
}

The operator strictly modifies fold expressions in default arguments by switching between unary right fold and unary left fold patterns, ensuring the semantic intent of the expression (e.g., logical OR over the pack) is preserved while altering the syntactic expansion order.
