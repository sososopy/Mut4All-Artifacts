mutation operator: Replace templated lambda explicit operator() call with direct call using template arguments in angle brackets.

This mutation targets C++17 code constructs where a templated lambda is invoked using the explicit operator() syntax with template arguments. It applies when a lambda with a template parameter list is defined and later called using the form lambda.operator()<template_args>(function_args). The mutation changes these explicit calls to a direct call syntax using angle brackets for template arguments, which is a valid alternative invocation method for templated lambdas.

The mutation modifies the call expression by removing the ".operator()" part and placing the template arguments directly after the lambda variable name in angle brackets, followed by the function arguments in parentheses. This transformation should be applied to all instances of such explicit operator() calls on templated lambdas within the seed program. No new elements are introduced; only the existing lambda variable and its arguments are reused in a different syntactic arrangement.

Example: Original code snippet: test_lambda_impl1.operator()<0>(y); Mutated code snippet: test_lambda_impl1<0>(y); This change preserves the same template argument 0 and function argument y but uses the direct call syntax. Similarly, for calls inside the lambda like test_lambda_impl2.operator()<f, 0>(); it would become test_lambda_impl2<f, 0>(); using the existing template parameter f and constant 0. The mutation assumes the lambda variables test_lambda_impl1 and test_lambda_impl2 are already declared as templated lambdas in the seed program.
