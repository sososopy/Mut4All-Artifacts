Mutation Operator: ReplaceFunctionPointerAssignment
This mutation operator targets the assignment of function pointers in the source code, specifically focusing on the use of decltype(auto) in conjunction with function templates that have unknown return types. The goal is to test the compiler's handling of such constructs, potentially exposing bugs similar to the one reported.

To apply this mutation operator:
1. Identify all occurrences of decltype(auto) used in assignments within the seed program.
2. For each identified occurrence, check if the assigned value is a function pointer, particularly one that involves a function template.
3. Modify the code by changing the type of the variable being assigned to decltype(auto) to a specific type that matches the return type of the function template, if known. If the return type is unknown, attempt to specify a type that could plausibly match the intended use of the function pointer.
4. If a specific type cannot be determined or if the function template's return type remains unknown, introduce a new variable with a type that is commonly used in the program (e.g., int, void*, etc.) and assign the result of the function pointer to this new variable, ensuring the new variable is used in a context that makes sense within the program.

Example:
Original Code:
decltype(auto) g = &f<int>;
Mutated Code:
auto g = &f<int>; // If return type is known to be compatible with auto
or
int* g = (int*)(&f<int>); // Specifying a plausible return type, assuming f<int> returns an integer

By applying this mutation operator, the compiler's ability to handle decltype(auto) with function templates of unknown return types is tested, potentially triggering bugs related to crash-on-invalid scenarios in C++14 code, especially those involving clang's frontend.
