Mutation Operator: InvalidUnionMemberAccess
This mutation operator targets the access of union members and is designed to expose bugs related to invalid casting in C++ compilers, particularly those labeled as crash-on-invalid. It applies to code constructs involving unions with nested structs or other members.

Given a union declaration, this operator will modify the access of its members by introducing an invalid or unexpected type cast. The goal is to simulate scenarios where the compiler might fail to handle type inconsistencies or misinterpret the structure of the union, leading to crashes or incorrect compilation.

For example, in a union that contains a struct or another union, the mutation operator might change the type of a variable used to access a member of the nested struct, or it might introduce a cast that does not match the declared type of the union member. The mutation aims to cover various program structures by applying to different types of unions and their members.

To apply this mutation, first identify a union in the seed program. Then, find an access to a member of this union. Modify the access by introducing an invalid cast, preferably using types that are already declared within the program to avoid introducing ambiguity. If necessary, declare a new type that can be used for the cast, ensuring it is clearly defined and does not introduce complexity that could mask the bug being targeted.

For instance, given a union like "union U { struct { int x; } s; };", an access to "u.s.x" might be mutated to "(char)u.s.x" or another type already present in the program, aiming to provoke an invalid cast error similar to the one described in the bug report. This approach focuses on utilizing existing program elements to create a mutation that is likely to expose crash-on-invalid bugs related to union member access and type casting.
