Mutation operator: ReplaceLambdaWithFunctionPointer
This mutation operator targets code constructs that involve passing lambda functions to other functions. It replaces the lambda function with a function pointer, which may trigger bugs related to the handling of lambda functions in the C++ compiler. The operator applies to code that uses lambda functions as arguments to other functions. 

To apply this mutation, first identify a lambda function that is being passed to another function. Then, replace the lambda function with a function pointer that points to a separate function with the same signature as the lambda function. The separate function should contain the same code as the lambda function. 

For example, consider the following pseudo-code:
if some condition then 
  call function f with lambda function g
else 
  do something else

The mutation operator would replace the lambda function g with a function pointer that points to a separate function, let's call it h, which contains the same code as the lambda function g. The resulting mutated code would look like this:
declare function h 
  same code as lambda function g
if some condition then 
  call function f with function pointer to h

  do something else

This mutation operator is designed to test the compiler's ability to handle lambda functions and function pointers correctly, and may help expose bugs related to these features in the C++ compiler.
