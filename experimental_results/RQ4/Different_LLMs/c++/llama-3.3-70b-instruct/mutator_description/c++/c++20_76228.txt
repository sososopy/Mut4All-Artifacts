Mutation Operator: ReplaceMemberVariableWithFunctionCall
Targeting code constructs: class and struct definitions with member variables
Applies to: C++20 mode, specifically to classes and structs that contain member variables and have constructors or other special member functions
Description: Replace a member variable in a class or struct definition with a function call that returns the same type as the member variable
Example: given a class definition 
class a {
  type var;
  a() {
    // initialization
  }
}
the mutation operator would replace var with a function call, for example 
class a {
  type func();
  a() {
    // initialization
  }
}
where func is an existing function in the program that returns type, or a new function is declared with the correct return type and a dummy implementation
Changes to make:
1. Identify a class or struct definition with a member variable
2. Check if the member variable has a corresponding function in the program that returns the same type
3. If such a function exists, replace the member variable with a call to this function
4. If no such function exists, declare a new function with the correct return type and a dummy implementation, and replace the member variable with a call to this new function.
