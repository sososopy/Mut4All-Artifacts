Mutation Operator: ReplaceDeletedFunction
This operator targets the use of deleted functions, specifically in the context of constexpr. It applies to any function declaration where the delete keyword is used, such as in the example provided where the assignment operator is deleted for the Test class.

The mutation involves replacing the deleted function with a user-declared function that has an empty body or a minimal implementation that does not alter the state of the object, to observe how the compiler handles the change from a deleted function to a defined one.

For example, given a class declaration like class TYPE { constexpr TYPE &operator=(const TYPE &) = delete; }; 
the mutation would result in class TYPE { constexpr TYPE &operator=(const TYPE &) {} }; 
This change allows for testing whether the compiler correctly handles the transition from a deleted function to one that is defined, potentially exposing bugs related to how deleted functions are processed in constexpr contexts.
