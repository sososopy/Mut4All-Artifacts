Mutation operator: ReplaceStaticMemberFunctionWithNonStaticMemberFunction
This mutation operator targets C++ code that contains static member functions within a class or struct. It replaces a static member function with a non-static member function to test how the compiler handles the change in function type. 

The replacement is done by removing the static keyword from the function declaration. If the function is used in a context where a static function is expected, the compiler should report an error. 

For example, given a class with a static member function:
class MyClass {
public:
  static void myStaticFunction();
};

The mutation operator would replace it with:
class MyClass {
public:
  void myStaticFunction();
};

This change can help expose bugs in the compiler related to handling static and non-static member functions, such as incorrect error reporting or crashes when processing the modified code. 

The operator applies to all static member functions within classes and structs, and it does not introduce new variables, types, or functions that are not already present in the seed program. 

To use this operator, existing functions are modified in-place, without adding new function declarations or definitions. The goal is to test the compiler's behavior when encountering the modified function in different contexts, such as when called using the class name or an instance of the class.
