Mutation operator: Recursive Function Template Instantiation Modifier
This mutation operator targets recursive function templates and modifies the recursion depth by introducing a new template parameter that controls the recursion limit. It applies to code constructs involving recursive function templates with a high recursion depth.

The operator works by adding a new template parameter to the function template, which represents the maximum recursion depth allowed. The original recursive call is then wrapped in a conditional statement that checks if the current recursion depth is within the allowed limit. If the limit is exceeded, the function returns or throws an exception.

For example, given a recursive function template like this:
function f(n) = if n > 0 then f(n-1) else result
The mutation operator would transform it into:
function f(n, depth = 0, max_depth = ORDER) = 
  if depth >= max_depth then error or return 
  else if n > 0 then f(n-1, depth+1, max_depth) 
  else result
This operator is designed to expose bugs related to deep recursion in function templates, such as the segmentation fault reported in the bug trace. By introducing a controllable recursion limit, it allows testers to systematically test the compiler's handling of recursive function templates with varying recursion depths.
