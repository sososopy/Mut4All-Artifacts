Mutation Operator: CompoundLiteralEmbedModifier
This operator targets compound literals that contain the #embed directive. It applies to code constructs where a compound literal is used to initialize a variable, and the compound literal contains an #embed directive. 
The operator works by replacing the #embed directive with a different file path, or by changing the variable being initialized to a different type. 
For example, given the code char *p = (char[]){
#embed "/usr/bin/true"
}; the operator could mutate it to char *p = (char[]){
#embed "/usr/bin/false"
}; or to int *p = (int[]){
#embed "/usr/bin/true"
}; 
This mutation can help expose bugs related to the #embed directive in compound literals, such as the crash-on-valid bug reported. 
The mutation operator prefers to use existing file paths and types in the seed program, but if new elements are introduced, they should be declared explicitly, for example by adding a new string literal or a new type definition. 
The goal is to achieve high coverage across different program structures and features, and to test the compiler's handling of compound literals with #embed directives in various contexts.
