Mutation Operator: Replace Lambda with Functor
The Replace Lambda with Functor mutation operator targets code constructs that utilize lambda expressions, specifically those with captures and parameter packs. This operator applies to lambda expressions used as function objects, such as those passed to higher-order functions or used in initialization lists.

To apply this mutation, identify lambda expressions in the code and replace them with functors (function objects defined as classes with an operator()). The replacement functor should have the same capture list and parameter list as the original lambda expression. If the lambda expression has a parameter pack, the functor should also have a variadic template parameter list.

For example, given a lambda expression like ([&](auto... args) { /* lambda body */ }), the Replace Lambda with Functor operator would transform it into a functor class like struct Functor { template <typename... Args> void operator()(Args... args) { /* functor body */ } };, where the functor body is the same as the lambda body.
