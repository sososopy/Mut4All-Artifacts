Mutation operator: NullPointerIntroduction
This mutation operator targets function calls and introduces a null pointer as an argument to the function call. The goal is to check the handling of null pointer arguments by the compiler, especially in cases where the function does not expect a null pointer. 
It applies to any function call in the code.
The mutation operator will be widely adapted to seed programs by using variables, types, or functions that already exist in the seed program. 
If new elements are introduced, they should be declared with the same type as the original argument to avoid type mismatches. 
For example, if a function call foo(a, b) is mutated to foo(a, nullptr), the type of nullptr should match the type of b. 
To achieve high coverage across different program structures and features, the mutation operator can be applied to various types of function calls, including template instantiations and overloaded functions. 
The mutated content can be illustrated using pseudo-code, such as replacing a function call foo(a, b) with foo(a, nullptr), where nullptr is a null pointer constant.
