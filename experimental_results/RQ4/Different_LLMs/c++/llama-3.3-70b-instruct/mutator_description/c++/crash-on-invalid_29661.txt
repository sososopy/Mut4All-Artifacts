Mutation Operator: TemplateInstantiation
This mutation operator targets C++ template instantiations, specifically focusing on the interaction between template parameters and the instantiated code. It applies to template definitions and their corresponding instantiations.

The goal is to introduce variations that can trigger bugs similar to the reported crash-on-invalid issue, which occurred when the compiler encountered invalid C++ code, specifically an issue related to template handling.

To apply this mutation operator, follow these steps:

1. Identify all template definitions in the source code.
2. For each template definition, select a template parameter.
3. Replace the selected template parameter with a different type that already exists in the program. If no suitable type exists, introduce a new basic type (e.g., int, char, bool) and use it as the replacement.
4. Ensure the new type is declared and accessible within the scope of the template definition.
5. Compile the mutated code with the same compiler flags used in the original bug report, specifically including "-std=c++11".
6. Observe if the mutation triggers a crash or an error related to template instantiation, indicating a potential bug in the compiler's handling of template parameters.

Example: Consider a template function `template <typename T> void foo(T x);`. The mutation could replace `T` with `int`, resulting in `void foo(int x);`, if `int` is a type already used elsewhere in the program. This change tests how the compiler handles template instantiation with a concrete type, potentially exposing issues similar to the crash-on-invalid bug.
