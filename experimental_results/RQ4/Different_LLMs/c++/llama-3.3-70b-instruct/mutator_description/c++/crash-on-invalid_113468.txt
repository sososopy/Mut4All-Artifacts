Mutation operator: ConditionalStatementReplacement
This operator targets conditional statements in the code, specifically if-else statements, and replaces the condition with a new one. 
The new condition can be a simple expression, a function call, or another conditional statement. 
This mutation is applied to the code by replacing the existing condition in the if statement with a new condition. 
For example, in the given code, the condition (int f; f = 0; if (f) break) can be replaced with a new condition, such as (x > 0), where x is a variable that exists in the code. 
This mutation can help expose bugs related to conditional statements, such as those that occur when the compiler incorrectly handles the condition or when the condition is not properly evaluated. 
The goal of this mutation is to test the compiler's ability to correctly handle different conditional statements and to identify any bugs that may occur when the condition is changed. 
This mutation can be applied to any if statement in the code, and the new condition can be chosen based on the existing variables and functions in the code.
