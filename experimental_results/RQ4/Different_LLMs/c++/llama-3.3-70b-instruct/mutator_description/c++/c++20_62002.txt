Mutation operator: ReplaceConstevalWithConstinit
This mutation operator targets the consteval keyword in C++20 code and replaces it with constinit. 
It applies to code constructs where the consteval keyword is used to specify that a function is a constant evaluation function.
The purpose of this mutation operator is to test the compiler's handling of constant initialization and evaluation, and to check if the replacement of consteval with constinit triggers any bugs or crashes in the compiler.
For example, given the code 
"consteval void func() { }"
the mutation operator would replace it with 
"constinit void func() { }"
This change would require the compiler to handle the function as a constant initialization function instead of a constant evaluation function, which could potentially expose bugs in the compiler's handling of these constructs.
