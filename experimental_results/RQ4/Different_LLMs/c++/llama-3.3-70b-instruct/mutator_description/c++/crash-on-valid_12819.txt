Mutation operator: replace conditional statement with equivalent loop 
Target: Conditional statements in the source code, such as if-else statements, switch statements, and ternary operators.
Description: Replace a conditional statement with an equivalent loop that achieves the same functionality. For example, replace if (condition) { code } with a while loop that checks the condition and executes the code if true, then breaks out of the loop. 
Apply to: All conditional statements in the source code, including those nested within other control structures.
Example: Replace if (x > 0) { y = 1; } with while (x > 0) { y = 1; break; }.
Changes: Replace the conditional statement with a while loop, and add a break statement after the code to be executed.
Note: This mutation operator targets the code generation and optimization phases of the compiler, where the crash-on-valid bug is likely to occur. By replacing conditional statements with equivalent loops, we can test the compiler's ability to optimize and generate correct code for different control structures.
