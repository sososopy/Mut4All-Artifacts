Mutation operator: ModifyIntegerLiteral 
this operator targets the code structure of integer literals in the source code. 
It applies to all occurrences of integer literals in the seed program. 
To apply this operator, first identify all integer literals in the code, 
then for each integer literal, modify its value to a different integer value, 
for example by changing its sign, or appending or prepending digits to it, 
or replacing some of its digits with new ones, and check if the compiler crashes. 
Note that the new integer value should be syntactically valid. 
For example if we have the code a = 123, 
the operator could change it to a = -123, or a = 1234, or a = 12, 
to test how the compiler handles different integer values. 
The goal of this operator is to achieve high coverage across different program structures 
and features by systematically modifying the integer literals in the code 
to expose potential compiler bugs, especially those related to crash-on-invalid issues.
