Mutation operator: ReplaceEnumWithClass
This operator targets enum declarations in the source code and replaces them with class declarations to test the compiler's handling of invalid code, specifically in the context of C++ binary operator overloading.

The operator applies to any enum declaration in the source code. It replaces the enum declaration with a class declaration, keeping the same name and scope as the original enum. For example, given an enum declaration such as "enum a { ... }", the operator would replace it with "class a { ... }".

To achieve high coverage, this operator should be applied to various enum declarations throughout the seed program, including those with different numbers of enumeration constants, different types of enumeration constants, and different access specifiers.

The changes made by this operator are limited to replacing the enum keyword with the class keyword, without introducing any new elements or modifying existing ones. This allows the compiler to handle the resulting invalid code and potentially expose bugs related to C++ binary operator overloading.
