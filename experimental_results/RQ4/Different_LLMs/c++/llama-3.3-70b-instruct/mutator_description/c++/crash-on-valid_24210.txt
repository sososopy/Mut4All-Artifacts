Mutation operator: ArrayToPointer 
This operator replaces an array declaration with a pointer declaration in a given C++ code, applying to array declarations of any type, including built-in and custom types, and aims to test how compilers handle the differences between array and pointer semantics. 
For an existing array declaration, for example, "array_type array_name[array_size];", this mutation operator will change it into "array_type* pointer_name;", and for code using the array, such as "array_name[index]", it will change to "pointer_name[index]" if the array is not reassigned, otherwise, the code should be adjusted according to the new pointer semantics, such as dynamically allocating memory with new and using pointer_name to access the memory. 
To apply this mutation operator, first, identify array declarations in the given C++ code, then replace each array declaration with a pointer declaration of the same type and adjust any subsequent uses of the array to conform to pointer semantics, taking into account any necessary memory management. 
This mutation operator targets array declarations and their uses, aiming to stress compiler handling of array-to-pointer conversions and related memory management.
