Mutation operator: ReplaceLambdaWithGenericLambda 

This mutation operator targets the use of lambda functions in C++ code and replaces a non-generic lambda with a generic lambda. It applies to code that uses lambda functions, especially in the context of template metaprogramming or when working with generic code.

The motivation behind this mutation is to expose potential issues in the compiler's handling of lambda functions, particularly when they are used in complex generic contexts. By replacing a non-generic lambda with a generic lambda, we can test the compiler's ability to handle the changes in type deduction and instantiation.

To apply this mutation, the following steps can be taken:

1. Identify a lambda function in the code that is not generic.
2. Replace the lambda function with a generic lambda by adding a template parameter list to the lambda introducer.
3. Update the lambda function's parameter list and body as necessary to work with the new template parameters.

For example, consider the following pseudo-code:
```
auto lambda = [](int x) { return x * 2; };
```
This lambda function can be replaced with a generic lambda as follows:
```
auto lambda = [](auto x) { return x * 2; };
```
Note that the `auto` keyword is used to deduce the type of the lambda function's parameter, making it a generic lambda. This change can help expose issues in the compiler's handling of generic lambdas, such as incorrect type deduction or instantiation errors.
