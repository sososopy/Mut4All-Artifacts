Mutation Operator: ReplaceLambdaWithFunctionPointer
This mutation operator targets code constructs involving lambda expressions, particularly those used in type declarations or as function parameters. It replaces a lambda expression with a function pointer of a compatible type, aiming to expose bugs related to the handling of unevaluated lambda types, as seen in the provided bug report.

To apply this mutation, identify lambda expressions within the code and replace them with function pointers that match the lambda's signature. For example, given a lambda expression like "auto func = []{};", the mutation could introduce a function pointer "void (*func_ptr)() = nullptr;" and use "func_ptr" in place of the lambda, considering the necessary adjustments for the context in which the lambda is used.

This approach should help expose issues similar to the one described, where the compiler crashes due to incorrect handling of lambda types during deserialization, by forcing the compiler to handle function pointers in contexts where lambdas are expected, thus testing its ability to handle type declarations and function calls involving these constructs correctly.
