Mutation Operator: Attribute Corruption
This mutation operator targets the attribute syntax in C++ and applies to any code that uses attributes, such as [[attribute]].
It works by randomly corrupting attributes in the code, for example, by changing [[attribute]] to [[attribute2]] or [[ attribute ]].
The goal is to test the compiler's ability to handle malformed attributes, which can help expose bugs like the one described in the report.
The operator will only modify existing attributes and will not introduce new attributes or change the syntax of other code constructs.
To apply this operator, the following steps should be taken:
1. Identify all attribute uses in the code.
2. Randomly select an attribute to corrupt.
3. Modify the selected attribute by changing its name, adding or removing whitespace, or changing its syntax.
For example, the code [[nodiscard]] void foo() { ... } might be mutated to [[ nodiscard2 ]] void foo() { ... } or [[nodiscard ]] void foo() { ... }.
This operator is designed to achieve high coverage across different program structures and features by targeting a specific code construct and modifying it in a way that is likely to expose bugs in the compiler's attribute handling.
