Mutation Operator: Insert Unicode Escape Sequence
This mutation operator targets the insertion of Unicode escape sequences in string literals, comments, or character constants, which can potentially trigger crashes or incorrect behavior in the C++ compiler, particularly in the lexer component. 

It applies to all instances of string literals, comments, and character constants within the source code. 

To apply this mutation, the following steps are taken:
- Identify all string literals, comments, and character constants in the source code.
- Insert a Unicode escape sequence, such as \U or \u, followed by a hexadecimal number, in a random position within these identified elements.
- Ensure the inserted sequence is syntactically correct but semantically invalid or unexpected, aiming to stress the compiler's handling of Unicode characters.

For example, in a string literal "hello", the mutation could result in "hel\u1234lo" or "hel\U12345678lo", using existing variables or types from the seed program to construct the mutated content. 

This operator is designed to achieve high coverage across different program structures and features by targeting fundamental elements of C++ source code, such as string literals and comments, which are ubiquitous in programming. By introducing Unicode escape sequences in these areas, it tests the compiler's ability to handle potentially problematic input gracefully, without crashing, especially in areas labeled as crash-on-invalid.
