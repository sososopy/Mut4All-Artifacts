Mutation Operator: TemplateInstantiationSwapper
This mutation operator targets template instantiations in C++ code, which are likely to trigger bugs related to template metaprogramming and type deduction. The operator swaps the template arguments of two consecutive template instantiations in a given scope. 

The motivation behind this operator is that template metaprogramming can be complex and error-prone, and small changes to the template arguments can cause the compiler to produce incorrect results or crash. 

To apply this operator, first, identify all template instantiations in the given scope. Then, select two consecutive template instantiations and swap their template arguments. For example, if we have two template instantiations: 
std::vector<int> vec1; 
std::vector<float> vec2;

std::vector<int> vec2;

Note that the TemplateInstantiationSwapper operator should be applied judiciously, as it can produce invalid or uncompilable code if the swapped template arguments are not compatible with the template definition. Therefore, the operator should be used in conjunction with other testing strategies to ensure that the produced code is valid and compilable. 

The TemplateInstantiationSwapper operator can be used to test the C++ compiler's ability to handle complex template metaprogramming scenarios, such as template argument deduction, template specialization, and template instantiation.
