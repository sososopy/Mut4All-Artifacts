Mutation Operator: ReplaceConstraintRequiresClause
This mutation operator targets the requires clause in a concept definition, specifically in the context of C++20 concepts. It applies to code constructs where a requires clause is used to constrain template parameters with a set of requirements.

Given a requires clause in the form:
requires (parameter-list) { requirement ; }
Replace the requirement with a different requirement that is similar but has a different constraint, for example, change a equality comparison to a less-than comparison, or replace a convertible_to requirement with a same_as requirement.

For example, given the following code:
template <typename IteratorL, typename IteratorR>
  requires requires(IteratorL __lhs, IteratorR __rhs) {
    { __lhs == __rhs } -> convertible_to<bool>;
  }
The mutated code would be:
template <typename IteratorL, typename IteratorR>
  requires requires(IteratorL __lhs, IteratorR __rhs) {
    { __lhs < __rhs } -> convertible_to<bool>;
  }
Or, replacing convertible_to with same_as:
template <typename IteratorL, typename IteratorR>
  requires requires(IteratorL __lhs, IteratorR __rhs) {
    { __lhs == __rhs } -> same_as<bool>;
  }
This mutation operator is designed to expose bugs in the compiler's handling of concepts, such as the crash-on-invalid bug reported. By changing the requirements in the requires clause, we can test the compiler's ability to diagnose and handle different constraint expressions, which can help identify bugs in the compiler's implementation of C++20 concepts.
