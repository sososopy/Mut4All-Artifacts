Mutation Operator: ModifyArrayIndexing
This mutation operator targets array indexing in C++ code, which is a common construct that can trigger compiler bugs, especially those labeled as crash-on-invalid. The operator applies to code that accesses array elements using square bracket notation.

To apply this operator, locate an array or a pointer to an array in the seed program, and modify the index used to access its elements. For example, if the original code is "a[i]", the mutated code could be "a[i + 1]" or "a[i - 1]". If the index is a constant, replace it with a variable that is already defined in the program, or introduce a new variable with a simple declaration, such as "int newIndex = 0;".

The goal is to test how the compiler handles different indexing scenarios, including out-of-bounds access, negative indices, or indices that are variables. This operator can help expose bugs in the compiler's parsing and semantic analysis phases, particularly when dealing with invalid or edge cases.

By applying this mutation operator, we can increase the chances of triggering compiler bugs related to array indexing, which is a fundamental construct in C++ programming. The mutation operator is designed to be widely applicable to various seed programs, without relying on customized data names, types, or variable names.
