Mutation operator: ReplaceLoopCondition
This mutation operator targets the condition of a for loop and replaces it with a constant value, either true or false, to test how the compiler handles infinite loops or loops that never execute. 
It applies to for loops with a condition that can be evaluated to a boolean value. 
For example, given a seed program with a for loop, such as for (int i = 0; i < 10; i++) { ... }, this mutation operator would replace the condition i < 10 with either true or false, resulting in for (int i = 0; true; i++) { ... } or for (int i = 0; false; i++) { ... }. 
This change can help expose bugs in the compiler's handling of loop constructs, such as the one described in the bug report where the compiler crashes when encountering an infinite loop with a struct definition inside the loop initialization. 
To apply this mutation operator, first identify the condition of the for loop in the seed program, then replace it with either true or false, ensuring that the resulting loop is either infinite or never executes, to test the compiler's behavior in these scenarios.
