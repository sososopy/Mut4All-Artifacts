Mutation Operator: ReplaceMemberAccessOperator
This mutation operator targets the member access operator in C++ code, specifically in the context of struct, union, or class definitions. It applies to code constructs where a member access operator (e.g., ".", "->", or "::") is used to access a member of a struct, union, or class.

The operator replaces the member access operator with a different one, for example, replacing "." with "->" or vice versa. This change can help expose bugs in the compiler's handling of member access, such as incorrect parsing or lookup of member names.

To apply this mutation operator, the following steps can be taken:
1. Identify a struct, union, or class definition in the seed program.
2. Locate a member access operator (e.g., ".", "->", or "::") within the definition.
3. Replace the member access operator with a different one, ensuring that the replacement is syntactically valid.
4. If the replacement operator requires a different type of operand (e.g., replacing "." with "->" requires a pointer operand), modify the operand accordingly.
