Mutation Operator: ExplicitObjectParameterInsertion
This operator targets user-defined types with member functions, specifically those that can be defined with an explicit object parameter using the 'this' keyword in C++23. It applies to structs and classes that have member functions.

The mutation involves inserting an explicit object parameter into a member function of a user-defined type. To perform this mutation, first identify a member function within a struct or class that does not currently use an explicit object parameter. Then, modify the function to include an explicit object parameter using the 'this' keyword. 

For example, given a struct like:
struct Example {
    void memberFunction() {}
};

The mutation could result in:
struct Example {
    void memberFunction(this Example& self) {}
};

This mutation operator is designed to expose bugs related to the handling of explicit object parameters in member functions, such as the crash-on-valid issue reported for the Clang frontend. By systematically applying this mutation across different member functions in user-defined types within a program, it increases the likelihood of triggering similar bugs if they exist, thereby aiding in the testing and validation of C++ compilers.
