Mutation Operator: GlobalVariableToModuleVariable
This mutation operator targets global variables in C++ code and transforms them into module variables by adding the 'module' keyword to their declaration. It applies to global variables declared at the top level of a translation unit.
The operator works by identifying global variable declarations and modifying them to include the 'module' keyword. For example, given a global variable declaration like 'int x;', the mutated code would be 'module int x;'. This change is made to existing global variables in the seed program, without introducing new variables or types. The goal is to test how the compiler handles module variables, especially in the context of C++20 modules, which is relevant to the provided bug report labeled with c++20 and clang:modules. This mutation can help expose bugs related to the compiler's handling of module variables, such as the one described in the bug report.
