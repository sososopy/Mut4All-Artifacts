This mutation operator targets C++ code that uses templates and unqualified lookup into dependent bases. It applies to code constructs where a template class has a dependent base class and the derived class uses an unqualified lookup to access a member of the base class.
The operator works by selecting a template class in the seed program and modifying its definition to introduce an unqualified lookup into a dependent base class.
