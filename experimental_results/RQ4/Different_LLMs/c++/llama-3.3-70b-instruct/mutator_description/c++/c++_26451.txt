Mutation operator: TemplateParameterRemoval
This mutation operator targets class template specializations and removes the use of template parameters in the specialization. This can be applied to any class template specialization where the template parameters are not used in the specialization. 
The operator works by identifying a class template specialization and then removing any references to the template parameters within the specialization. 
For example, given a class template specialization like "template<> class MyClass<int> { int x; };", the mutation operator would transform it into "template<> class MyClass<int> { };", effectively removing the use of the template parameter.
This operator is designed to test the compiler's handling of template specializations and how it responds when template parameters are not used, which is relevant to the bug report provided, where the issue arises from a partial specialization of a class without using any of its template parameters.
