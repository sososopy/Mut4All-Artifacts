Mutation operator: ReplaceTemplateArgumentsWithConstraint
This mutation operator targets template instantiations and replaces the template arguments with constrained template parameters, which are introduced in C++20. The goal is to test the compiler's handling of constrained template arguments and their interaction with template instantiation.

The operator applies to code constructs that involve template instantiation, such as function calls or object creations, where the template arguments are explicitly specified.

To apply this mutation, the following steps are taken:
1. Identify template instantiations in the code, where the template arguments are explicitly provided.
2. Replace the template arguments with constrained template parameters, using the "requires" keyword to specify the constraints.
3. Ensure that the constraints are valid and make sense in the context of the template instantiation.

For example, given a template function:
```c
template <typename T>
void foo(T t) {
    // function body
}
```
The mutation operator might replace the template argument with a constrained template parameter, like this:
```c
template <typename T> requires std::integral<T>
void foo(T t) {
    // function body
}
```
This mutation tests the compiler's ability to handle constrained template arguments and ensures that the template instantiation is correctly performed. By applying this mutation, we can increase the chances of exposing bugs related to constrained template arguments and template instantiation in the C++20 compiler.
