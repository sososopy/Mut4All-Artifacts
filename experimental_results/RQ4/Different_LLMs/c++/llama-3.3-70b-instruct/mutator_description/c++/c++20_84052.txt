Mutation Operator: RemoveTemplateConstraint
This mutation operator targets the template constraints in a given C++ code and removes them. The goal is to check how the compiler handles the absence of constraints, potentially exposing bugs related to constraint evaluation, such as the crash reported when evaluating constraints on a Non-Type Template Parameter (NTTP) with a default template argument.

The operator applies to any template declaration that includes a constraint, such as those defined using the `requires` keyword or through the use of concepts. The mutation involves removing the constraint from the template declaration, which could be a concept constraint or a `requires` clause.

For example, given a template declaration like this:
```c
template <class T> requires Invokable<T> struct S { };
```
The mutation would result in:
```c
template <class T> struct S { };
```
This change removes the constraint that `T` must satisfy the `Invokable` concept, which could lead to compiler errors or crashes if the compiler does not properly handle the lack of constraints, similar to the bug report provided.

To apply this mutation, one would:
1. Identify all template declarations in the code.
2. For each template declaration, check if it includes any constraints.
3. Remove the constraints from the template declaration.

This mutation operator can help test the compiler's robustness in handling template constraints and potentially expose bugs related to constraint evaluation, such as the one described in the bug report.
