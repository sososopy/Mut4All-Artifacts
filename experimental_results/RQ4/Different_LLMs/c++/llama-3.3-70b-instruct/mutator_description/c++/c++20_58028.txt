Mutation Operator: Replace Inheritance 
This mutation operator targets class inheritance in C++ code. It applies to any class definition that uses inheritance. The goal is to replace the inheritance relationship between two classes with a different type of inheritance, such as replacing public inheritance with private or protected inheritance, or removing inheritance altogether.

To apply this mutation, follow these steps:
1. Identify a class definition that uses inheritance.
2. Determine the type of inheritance used (public, private, protected, or none).
3. Replace the inheritance specifier with a different type (e.g., replace "public" with "private" or remove the specifier altogether).
4. If removing inheritance, ensure that any base class members accessed in the derived class are modified to be accessed through composition instead (e.g., by adding a member variable of the base class type).

Example:
Original code:
```c
class V2 : public V1 {
    int& a;
};
```
Mutated code:
```c
class V2 : private V1 {
    int& a;
};
```
Or, if removing inheritance:
```c
class V2 {
    V1 v1;
    int& a;
};
```
This mutation operator can help expose bugs related to the handling of inheritance in the C++ compiler, such as issues with access specifiers, constructor initialization, or member function overriding. By changing the inheritance relationship, we can test how the compiler handles different scenarios and identify potential errors or inconsistencies in its behavior.
