Mutation Operator: ReplaceArraySize
This operator targets array declarations and replaces the size of the array with an empty expression, similar to the bug report where __array_extent is used with an empty second argument. It applies to all array declarations in the code. 

For example, given an array declaration like "int arr[10]", this operator would mutate it into "int arr[]". If the array declaration already has an empty size, like "int arr[]", it would not be mutated further.

In pseudo-code, this can be represented as:
If array declaration is of the form "type name[size]",
Then replace "size" with an empty expression to get "type name[]".

This operator is designed to expose bugs related to improper handling of array sizes, similar to the crash-on-invalid bug reported with __array_extent. It achieves high coverage by being applicable to all array declarations and does not introduce new variables, types, or functions, thus adhering to the guidelines.
