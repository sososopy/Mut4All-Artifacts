Mutation operator: ReplaceReturnWithUnusedVariable
This mutation operator targets functions that contain a return statement and replaces it with an unused variable. The unused variable should be of the same type as the return type of the function. This operator applies to all functions with a return type. 
For example, consider a function like this: 
function foo() {
  int x = 5;
  return x;
}
After applying the mutation operator, the function would look like this: 
function foo() {
  int x = 5;
  int y;
}
In this example, the return statement is replaced with an unused variable y of type int, which is the same as the return type of the function. 
This operator is designed to test the compiler's handling of unused variables and return statements, which is relevant to the given bug report that involves an assertion failure related to unaccounted cleanups in a function. 
The purpose of this operator is to introduce a situation where the compiler needs to handle an unused variable in the context of a function return, which may trigger bugs related to the compiler's handling of such situations.
