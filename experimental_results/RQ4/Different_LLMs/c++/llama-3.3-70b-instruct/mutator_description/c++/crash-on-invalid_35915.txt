Mutation Operator: ReplaceTypeWithIncompleteType 
This mutation operator targets compound types such as classes, structs, or unions and replaces them with incomplete types. 
For example, given the declaration of a class, replace the class with a forward declaration of the class, thus making it an incomplete type at the point of usage.
