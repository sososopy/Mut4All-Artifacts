Mutation operator: ReplaceLambdaWithFunctor
This mutation operator targets lambda expressions in C++ code and replaces them with functor objects. It applies to any lambda expression in the code. The goal is to test how the compiler handles the conversion of lambda expressions to functor objects, which can help expose bugs related to lambda handling, such as the one described in the bug report.

To apply this mutation, the following steps can be taken:
- Identify all lambda expressions in the given code.
- For each lambda expression, create a corresponding functor object with the same behavior.
- Replace the lambda expression with an instance of the functor object.

For example, given a lambda expression like `[&](auto... p2s) { ([&] { p1s; p2s; }, ...); }`, the mutation operator would replace it with a functor object, such as a struct with an operator() that captures the necessary variables and performs the same actions as the lambda.
