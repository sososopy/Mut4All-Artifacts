Mutation Operator: Replace Delete Operator Parameter Type 
This operator targets the first parameter of a member operator delete in a class and replaces its type with a different existing type in the seed program. 
It applies to member operator delete functions where the first parameter has a class type. 
For example, given a seed program with a struct S and a struct T containing a member operator delete with S as the first parameter's type, the mutation operator would replace S with another existing type, such as struct U if it exists in the program. 
If no other class types exist, it would introduce a new type, for instance, struct NewType, which should be declared as an empty struct. 
The goal is to check if the compiler correctly handles different types as the first parameter of a member operator delete. 
This operator aims to achieve high coverage across various program structures and features, particularly focusing on the C++20 standard and the clang frontend, by exploiting the bug where the compiler crashes if the first parameter of a member operator delete is in class type.
