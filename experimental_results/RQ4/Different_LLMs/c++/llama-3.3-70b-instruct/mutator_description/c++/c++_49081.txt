Mutation operator: ReplaceAutoWithTemplateParameter
This mutation operator targets generic lambdas and replaces the 'auto' keyword with a template parameter in the lambda's parameter list. The goal is to trigger bugs related to template instantiation and type deduction.

For example, given a lambda function:
lambda = [](auto arg) { return arg; };

The mutation operator would replace 'auto' with a template parameter 'T', resulting in:
template <typename T>
lambda = [](T arg) { return arg; };

This mutation can help expose bugs in the compiler's ability to handle template instantiation and type deduction, particularly in the context of generic lambdas. By replacing 'auto' with a template parameter, we can test the compiler's ability to correctly deduce the type of the template parameter and instantiate the template accordingly. 

The mutation operator applies to lambda functions that use the 'auto' keyword in their parameter list. The changes made by this mutation operator are limited to replacing 'auto' with a template parameter, without modifying any other part of the code. 

To declare the new template parameter 'T', it should be added to the lambda's template parameter list, like this:
template <typename T>
lambda = [](T arg) { return arg; };

This mutation operator can be used to test the compiler's ability to handle complex template instantiation scenarios and can help identify bugs related to type deduction and template instantiation.
