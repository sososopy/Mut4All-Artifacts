Mutation operator: replace_constexpr_with_non_constexpr
This mutation operator targets the constexpr keyword in C++ code and replaces it with a non-constexpr evaluation. 
It applies to any constexpr function, variable, or expression that is being evaluated at compile-time. 
The goal is to force the compiler to evaluate the expression at runtime instead, which may trigger a crash or incorrect behavior if the compiler has a bug related to constexpr evaluation.
To apply this mutation, find all occurrences of the constexpr keyword in the seed program and replace them with a runtime evaluation, for example by removing the constexpr keyword or replacing it with a runtime function call.
For instance, if the seed program contains a line like constexpr int x = 5, the mutated code would be int x = 5, or int x = evaluate_at_runtime(5), where evaluate_at_runtime is a function that evaluates its argument at runtime.
This mutation operator achieves high coverage across different program structures and features, especially those related to constexpr evaluation, and is likely to expose bugs in the C++ compiler related to crash-on-valid code, such as the one reported in the bug title.
