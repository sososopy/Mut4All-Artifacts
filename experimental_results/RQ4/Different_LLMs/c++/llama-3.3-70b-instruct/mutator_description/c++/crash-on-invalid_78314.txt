Mutation Operator: DeletePrefixIncrement
This mutation operator targets classes with overloaded prefix increment operators and applies when a postfix increment operator is also defined in the same class.
It works by deleting the prefix increment operator in the class and checking if the compiler correctly handles the deletion and selects the correct overload for the postfix increment operator.
The mutation involves removing the declaration of the prefix increment operator, such as void operator++() = delete, from the class definition.
For example, given a class with both prefix and postfix increment operators, the mutation would change 
class b {
  void operator++() = delete;
  template <class> void operator++(int) {
    b bb;
    ++bb;
  }
};
to 
class b {
  template <class> void operator++(int) {
    b bb;
    ++bb;
  }
};
This mutation tests the compiler's ability to handle deleted functions and operator overloading, specifically in the context of prefix and postfix increment operators.
