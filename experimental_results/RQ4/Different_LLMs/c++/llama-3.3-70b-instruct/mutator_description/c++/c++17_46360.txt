Mutation Operator: Lambda Capture Type Modifier
This operator targets lambda expressions and modifies the type of variables captured by the lambda. It applies to code constructs where a lambda expression captures variables by value, reference, or move. 

The mutation operator works by changing the capture type of a variable in a lambda expression from one type to another. For example, if a lambda captures a variable by value, the operator could change it to capture by reference or by move, and vice versa.

To apply this mutation operator, first identify lambda expressions in the seed program that capture variables. Then, for each captured variable, modify its capture type. If the variable is captured by value, change it to capture by reference or by move, using the appropriate syntax (e.g., "=" for capture by value, "&" for capture by reference, and "= std::move" for capture by move).

For instance, given a lambda expression like "auto lambda = [x = std::move(y)](auto&&... args) { ... }", the mutation operator could modify it to "auto lambda = [x = y](auto&&... args) { ... }" or "auto lambda = [x = &y](auto&&... args) { ... }", thus changing the capture type of the variable x from move to value or reference, respectively.

This mutation operator is designed to expose bugs related to how the compiler handles different capture types in lambda expressions, which could lead to issues like the internal compiler error reported in the bug title when using declval + decltype on captured lambda. By modifying the capture type, the operator increases the likelihood of triggering such bugs, providing valuable test cases for compiler testing.
