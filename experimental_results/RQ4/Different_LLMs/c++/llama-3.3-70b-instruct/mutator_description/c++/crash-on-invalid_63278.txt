Mutation Operator: ReplaceNonStaticMemberInitializer

It replaces the initializer of a non-static data member with an auto keyword, which could potentially trigger crashes or errors in compilers that do not handle such initializations correctly, similar to the bug reported.

The operator applies to structs or classes that have non-static data members with initializers. For a given struct or class member declaration of the form "type member_name = initializer;", the mutation operator changes it to "auto member_name = initializer;".
