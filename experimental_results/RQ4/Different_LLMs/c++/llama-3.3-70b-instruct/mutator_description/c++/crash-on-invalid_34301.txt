Mutation Operator: Template Parameter Modification
This operator targets template metaprogramming constructs, specifically partial specializations with template template parameters. It applies to code that involves template classes with nested template parameters, aiming to expose compiler crashes on invalid input.

To apply this mutation, identify a template class with a nested template parameter, such as a template template parameter. Modify the template parameter list by either adding, removing, or rearranging the parameters. For instance, if a template class is defined as template <typename T, template <typename...> class Container>, the mutation could result in template <typename T, typename U, template <typename...> class Container> or template <template <typename...> class Container, typename T>.

Example: Given a seed program with a template class like the provided is_specified_instantiation_of, the mutation could change the template parameter list from template <typename... param_types> to template <typename first_param, typename... param_types>, requiring adjustments to how the template parameters are used within the class. This change can help expose how the compiler handles modifications to the template parameters, especially in the context of partial specializations and template metaprogramming.

The goal is to achieve high coverage across different program structures and features, particularly focusing on the stability and correctness of the compiler when dealing with complex template constructs. This mutation operator is designed to be widely adaptable to various seed programs, using existing variables, types, or functions within those programs to minimize the introduction of new, potentially ambiguous elements.
