Mutation Operator: ConditionalExpressionMutator
The ConditionalExpressionMutator targets conditional expressions with a ternary operator (?:) and modifies the condition or the operands to potentially expose bugs related to unresolved construct expressions and source locations. 
It applies to conditional expressions of the form "condition ? expr1 : expr2" where condition is a boolean expression and expr1 and expr2 are expressions of the same type.
The mutation operator replaces the condition with a different boolean expression, such as a literal, a variable, or a function call that returns a boolean value, or swaps expr1 and expr2 to test the compiler's handling of different code paths.
For example, given a conditional expression "0 ? T<C>{} : T<C>{}", the mutation operator could replace the condition with a variable "x" or swap the operands to get "0 ? T<C>{1} : T<C>{2}".
To apply this mutation operator, first identify all conditional expressions in the seed program, then replace the condition or swap the operands as described above, and finally recompile the mutated program to test the compiler's behavior.
This mutation operator achieves high coverage across different program structures and features by targeting a common construct, the conditional expression, which is widely used in C++ programs.
It uses existing variables, types, and functions in the seed program, and if new elements are introduced, they are clearly declared to avoid ambiguity.
For instance, if a new variable "x" is introduced, it should be declared as a boolean variable, such as "bool x = true;" or "bool x = false;", to ensure the mutated expression is well-formed and testable.
