Mutation Operator: ModifyLambdaReturnType
This mutation operator targets lambda functions and modifies their explicit return types. It applies to code structures that involve lambda functions with explicit return types, such as the one shown in the bug report. The purpose of this operator is to test the compiler's handling of lambda functions with different return types, especially in the context of C++20 features.

To apply this mutation operator, follow these steps:
1. Identify lambda functions in the code with explicit return types.
2. Change the return type of the lambda function to a different type. For example, if the original return type is 'void', change it to 'int' or another type that is compatible with the function's body.
3. Ensure the new return type is consistent with the lambda function's usage in the surrounding code. If necessary, modify the function body or the calling code to match the new return type.
