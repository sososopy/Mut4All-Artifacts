Mutation Operator: Replace Static Variable with Non-Static Variable
This mutation operator targets the use of static variables as template arguments in C++ code. It replaces a static variable with a non-static variable to check if the compiler can handle this change correctly. The operator applies to any C++ code that uses static variables as template arguments.

To apply this mutation operator, first identify all occurrences of static variables used as template arguments in the given C++ code. Then, replace each static variable with a non-static variable. For example, given the following code:

template <const unsigned& Strs>
static auto join_v = 0;

template<typename T>
void foo()
{
    static unsigned scoped_static = 123;
    auto bar = join_v<scoped_static>;
}

Replace the static variable "scoped_static" with a non-static variable, for example:

template <const unsigned& Strs>
static auto join_v = 0;

template<typename T>
void foo()
{
    unsigned scoped_non_static = 123;
    auto bar = join_v<scoped_non_static>;
}

This change should be made in the seed program without introducing any new variables or types. If the compiler crashes or produces an incorrect output after this mutation, it may indicate a bug in the compiler's handling of static variables as template arguments. 

The goal is to achieve high coverage across different program structures and features, and this mutation operator can be used in conjunction with other mutation operators to test the compiler's robustness. The output of this mutation operator is a modified version of the input C++ code, which can be compiled and executed to test the compiler's behavior.
