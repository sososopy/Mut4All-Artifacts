Mutation operator: ReplaceTemplateSpecializationWithPrimaryTemplate
This mutation operator targets code constructs involving class template partial specializations. It applies to seed programs that use template metaprogramming and specialization.
The operator replaces a class template partial specialization with its corresponding primary template, aiming to expose bugs related to template instantiation and parsing.
For example, given a class template partial specialization like "template<> class MyClass<int>", this operator would replace it with the primary template "template<class T> class MyClass".
This change requires the introduction of a new template parameter, which should be declared as a type parameter, for instance, "class T" or "typename T", to avoid ambiguity.
By applying this mutation operator, we can test the compiler's ability to handle template specializations and primary templates, potentially revealing issues like the one reported in the bug, where the compiler crashes on invalid template specializations.
