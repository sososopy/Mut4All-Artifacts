Mutation Operator: TemplateInstantiationOperator
This mutation operator targets the instantiation of templated classes, methods, or functions in C++ code. It applies to code constructs that involve template metaprogramming and generic programming, which are commonly used in various applications, including but not limited to, data structures, algorithms, and utility libraries.

The operator works by identifying templated entities (classes, methods, functions) and then modifying their instantiation parameters. This can involve changing the type parameters passed to a templated class or function, adding or removing template arguments, or swapping the order of template parameters.

For example, given a templated class template <typename T> class MyClass {}; and its instantiation MyClass<int> myObject;, the mutation operator could transform this into MyClass<float> myObject; or MyClass<std::vector<int>> myObject;, depending on the types available in the scope and the goals of the mutation.

To apply this mutation operator, follow these steps:

1. Identify all templated classes, methods, and functions in the source code.
2. For each templated entity found, identify its template parameters.
3. Modify the instantiation of the templated entity by changing its template parameters. This could involve:
   - Changing the type (e.g., from int to float).
   - Adding a new type parameter if the template allows for it.
   - Removing a type parameter if the template allows for variable numbers of parameters.
   - Swapping the order of type parameters if the template allows for multiple parameters.
4. Ensure that the modified template parameters are valid and declared within the scope of the template instantiation.
5. Verify that the mutated code compiles and runs without syntax errors, focusing on whether the compiler correctly handles the modified template instantiations.

This mutation operator can help improve the robustness and reliability of C++ compilers, especially in complex scenarios involving template metaprogramming.
