Mutation Operator: Replace Conditional Expressions with Ternary Operators
This mutation operator targets conditional expressions in the given code, aiming to replace if-else statements with their equivalent ternary operator expressions. The goal is to see if the crash-on-valid bug in the Clang++ compiler is triggered when the code structure is altered in this specific way.

For example, given a piece of code like:
if (condition) {
  result = value1;
} else {
  result = value2;
}
This mutation operator would transform it into:
result = condition ? value1 : value2;

This change maintains the functionality of the original code but presents it in a different syntactic form. By applying this mutation, we can test whether the C++ compiler handles both forms correctly, potentially exposing bugs related to the parsing or processing of conditional expressions and ternary operators. 

To apply this mutation, one would need to identify all if-else statements within the provided source code and systematically replace them with their ternary operator equivalents, taking care to preserve the original logic and functionality of the program. This approach allows for a controlled test of the compiler's ability to handle different yet semantically equivalent code structures, which can be particularly useful in the context of the reported crash-on-valid bug.
