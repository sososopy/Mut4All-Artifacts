Mutation Operator: ReplaceLambdaWithFunctionPointer
This mutation operator targets lambda expressions used as template arguments in C++20 code and replaces them with function pointers to test how the compiler handles this substitution.
It applies to code constructs where a lambda expression is passed as a template argument to a concept or a template function.
For example, given the original code:
template<class T, auto L> concept M = requires {
    L.template operator()<T()>();
};
template<class T> concept C = requires(T t) {
    { t.x } -> M<[]<A>(){}>;
};
The mutation operator would replace the lambda expression []<A>(){} with a function pointer, resulting in:

    L.template operator()<T()>();
};
template<class T> concept C = requires(T t) {
    { t.x } -> M< decltype(&some_function)<A> >;
};
Here, some_function is a function that exists in the seed program, and its declaration should be added if it does not already exist.
The changes involve replacing the lambda expression with a function pointer in the template argument list and ensuring that the function pointer is properly declared and defined in the program.
This mutation operator tests the compiler's ability to handle function pointers as template arguments and diagnose any potential errors that may arise from this substitution.
