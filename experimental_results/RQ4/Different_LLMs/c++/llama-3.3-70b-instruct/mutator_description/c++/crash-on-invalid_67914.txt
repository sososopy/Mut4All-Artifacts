Mutation Operator: ChangeConstructorCall
This mutation operator targets the constructors of classes and structures in C++ code, aiming to expose bugs related to object initialization and constructor calls. It applies to code constructs where constructors are defined and called.

The ChangeConstructorCall operator will modify the constructor calls in the given code by altering the number or types of arguments passed to the constructor. 

For example, if a constructor is defined as follows:
class MyClass {
public:
  MyClass(int x, int y);
};

And an object of this class is created like this:
MyClass obj(10, 20);

The ChangeConstructorCall operator might modify this line to:
MyClass obj(10); 

Or:
MyClass obj(10, 20, 30);

This modification can help reveal bugs that occur when the compiler handles constructor calls with incorrect or missing arguments, which seems relevant given the nature of the crash-on-invalid bug report provided, especially considering the errors related to the Mask constructor and the implicit copy constructor. 

This operator should be applied to all constructor calls found in the code, using existing variables and types to minimize the introduction of new elements and ensure the mutated code remains as close as possible to the original, thus adhering to the guidelines for designing mutation operators.
