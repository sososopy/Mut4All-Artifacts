Mutation Operator: ReplaceConstexprWithNonConstexpr
This mutation operator targets function definitions and replaces a constexpr function with a non-constexpr function, or vice versa. It applies to code constructs where a function is defined with the constexpr keyword. The goal is to test the compiler's handling of constant expressions and non-constant expressions.

The operator works by identifying constexpr functions in the code and replacing the constexpr keyword with nothing, effectively making the function non-constexpr. Conversely, it can also add the constexpr keyword to a non-constexpr function.
