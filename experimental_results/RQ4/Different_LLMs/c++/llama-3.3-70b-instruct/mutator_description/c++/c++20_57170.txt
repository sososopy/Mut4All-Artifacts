Mutation operator: ChangeLambdaExpressionToRegularFunction
This mutation operator targets lambda expressions in the given code and replaces them with regular function definitions. The goal is to test how the compiler handles the differences between lambda expressions and regular functions, particularly in the context of template instantiation and type deduction.

For example, given a code snippet like this:
```c
auto lambdaFunc = [](int x) { return x * 2; };
```
The mutation operator would transform it into:
```c
int regularFunc(int x) { return x * 2; }
int (*funcPtr)(int) = regularFunc;
```
This change can help expose issues related to the handling of lambda expressions, such as incorrect type deduction, incorrect instantiation of template functions, or differences in how lambda expressions and regular functions are treated in the compiler.

The bug report provided suggests that the compiler is crashing when trying to instantiate a template function with a lambda expression as an argument. By replacing the lambda expression with a regular function, we can test whether the issue is specific to lambda expressions or if it is a more general problem with template instantiation.
