Mutation operator: ReplaceTemplateParameter
This mutation operator targets template instantiations and replaces a template parameter with another type that is already defined in the program. 
It applies to any template instantiation where the template parameter is a type. 
For example, given a template function foo that takes a type T as a template parameter and is instantiated with int, 
this mutation operator would replace int with another type, such as double, if double is already defined in the program.
