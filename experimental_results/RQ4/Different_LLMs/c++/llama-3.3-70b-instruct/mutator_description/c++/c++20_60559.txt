Mutation Operator: Template Parameter Pack Expansion Swap
This mutation operator targets the expansion of template parameter packs in C++20 code, particularly in the context of concepts and template metaprogramming. It is designed to test the compiler's handling of complex template instantiations and expansions, which can sometimes lead to compiler crashes or incorrect code generation.

The mutation operator works as follows:
- Identify template parameter packs in the code, such as `template<typename... Ts>` or `template<size_t... Is>`.
- For each identified template parameter pack, swap the order of the first two parameters in the pack expansion. For example, if a template function is defined as `template<typename T, typename U> void f(T t, U u)`, and it is instantiated with `f<int, float>`, the mutation would result in `f<float, int>`.
- If the pack expansion involves more than two parameters, the mutation can also swap the last two parameters or any two parameters that are next to each other in the pack expansion, to increase the diversity of test cases.

Example:
Original code:
```c
template<size_t... Is>
void invoke(Is... args) {
    // Function body
}
```
Mutated code:
```c
template<size_t... Is>
void invoke(Is... args) {
    // Swap the first two arguments in the pack expansion
    invoke<(Is == 0 ? 1 : Is == 1 ? 0 : Is)...>(args...);
}
```
