Mutation Operator: TemplateScopeSwap
This mutation operator swaps the scope of two template declarations in a given program. 

It targets template declarations and their associated scope, typically namespaces or classes. 

The operator applies to C++ code that contains multiple template declarations with different scopes.

For example, given a code snippet with two template declarations:
namespace A {
template <class T> struct X;
}
namespace B {
template <class T> struct Y;
}

The mutation operator would swap the scope of the two template declarations, resulting in:
namespace A {
template <class T> struct Y;
}
namespace B {
template <class T> struct X;
}

This mutation is designed to test the compiler's handling of template scope and deduction guides. 

By swapping the scope of template declarations, the operator can help expose bugs related to incorrect scope resolution or deduction guide declarations, such as the one described in the provided bug report. 

The changes made by this operator include modifying the namespace or scope of existing template declarations, without introducing new variables, types, or functions. 

The operator achieves high coverage across different program structures by targeting template declarations, which are widely used in C++ programs. 

The use of existing variables, types, and functions in the seed program ensures that the mutated code remains valid and compilable, allowing the compiler to test its handling of template scope and deduction guides.
