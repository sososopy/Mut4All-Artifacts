Mutation Operator: Replace Direct Initialization with Direct-List Initialization
This mutation operator targets direct initialization with parentheses and replaces it with direct-list initialization using curly brackets. It applies to all variable declarations and function parameters. 

For a given declaration of the form "type varname(expression);", the mutated code would be "type varname{expression};". This change aims to expose bugs related to the handling of initializer lists in the compiler, such as the one described in the bug report.
