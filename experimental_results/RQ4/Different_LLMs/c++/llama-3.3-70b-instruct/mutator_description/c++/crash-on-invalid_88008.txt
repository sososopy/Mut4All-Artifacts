Mutation Operator: InvalidMemberAccessInsertion
This mutation operator targets struct or class types and applies to member access expressions, such as accessing a member variable or function of a struct or class instance. It inserts an invalid member access by replacing an existing valid member access with a non-existent member name. 

For example, given a struct type with valid member variables, the mutation operator would replace a valid member access, such as accessing a valid member variable, with an invalid member access. The operator ensures the new member name does not exist in the struct or class definition. 

To achieve this, the operator first identifies existing struct or class types and their member access expressions within the given code. Then, it selects a member access expression and replaces the valid member name with a new, non-existent member name. 

The new member name should be a valid identifier in the language but not a member of the struct or class. If necessary, the operator declares the new member name as a variable or function with a type already existing in the seed program to avoid introducing new, undeclared types. 

The goal is to simulate the conditions that led to the crash-on-invalid bug, where the compiler failed to handle an invalid expression, in this case, an invalid member access. By inserting such invalid accesses, the mutation operator helps test the compiler's robustness in handling erroneous code. 

To apply this mutation operator, the following steps are taken:
1. Identify struct or class definitions and their member access expressions within the given code.
2. Select a member access expression and replace the valid member name with a new, invalid member name.
3. Ensure the new member name is a valid identifier but does not exist as a member of the struct or class.
4. If necessary, declare the new member name with a type already existing in the seed program to maintain consistency and avoid introducing undeclared types.
