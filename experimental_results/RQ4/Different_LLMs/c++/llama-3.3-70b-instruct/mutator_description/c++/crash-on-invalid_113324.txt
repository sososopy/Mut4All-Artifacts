Mutation operator: ModifyFunctionParameterList
This mutation operator targets function declarations and applies to the parameter list of a function. It modifies the parameter list by either adding, removing, or modifying the parameters. This operator is designed to test the compiler's handling of function parameter lists, which is relevant to the bug report provided, where the crash occurs in the FunctionDecl::getNumParams() function.

To apply this mutation operator, follow these steps:
1. Identify a function declaration in the source code.
2. Modify the parameter list of the function by either:
   - Adding a new parameter with a random type and name.
   - Removing an existing parameter.
   - Modifying an existing parameter by changing its type or name.
3. Ensure that the modified parameter list is syntactically correct and does not introduce any new variables or types that are not already defined in the seed program.

For example, consider a function declaration like this:
void test(int x, int y) {
  // function body
}

The mutation operator could modify this function declaration to:
void test(int x, int y, float z) {
  // function body
}
or
void test(int x) {
  // function body
}
or
void test(float x, int y) {
  // function body
}

This mutation operator is designed to test the compiler's handling of function parameter lists and can help expose bugs like the one reported, where the compiler crashes when trying to access the number of parameters of a function.
