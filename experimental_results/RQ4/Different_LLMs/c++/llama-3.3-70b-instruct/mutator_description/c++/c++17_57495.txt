Mutation Operator: Replace Scope Resolution Operator
The Replace Scope Resolution Operator mutation operator targets the scope resolution operator in C++ code, specifically in function calls and variable declarations. This operator applies to code constructs where the scope resolution operator is used to access global namespace or class members.

To apply this mutation operator, follow these steps:
1. Identify all instances of the scope resolution operator (::) in the code.
2. Replace each instance of the scope resolution operator with a dot operator (.) or remove it if it is not necessary.

For example, consider the following code:
```c
int x = std::vector::size();
```
This code can be mutated to:
```c
int x = vector.size();
```
or
```c
int x = std.vector::size();
```
This mutation operator can help expose bugs in the compiler related to parsing and resolving scope resolution operators. By replacing or removing these operators, the mutated code may trigger errors or crashes in the compiler, revealing issues with its handling of scope resolution.
