Mutation operator: ReplaceFunctionTemplateDefinition
This operator is designed to target function template definitions and replace them with alternative definitions to test the compiler's ability to handle different instantiations.
The operator applies to function template definitions, specifically those with template parameters and a function body.
To apply this operator, the following steps can be taken:
1. Identify a function template definition in the code.
2. Create an alternative definition for the function template, modifying the template parameters, function body, or both.
3. Replace the original function template definition with the alternative definition.
For example, given a function template definition like:
template <typename T> void foo(T x) { ... }
The mutation operator could replace it with:
template <typename T, typename U> void foo(T x, U y) { ... }
Or:
template <typename T> void foo(T x) { alternative implementation }
This operator is designed to test the compiler's ability to handle different instantiations of function templates, which is relevant to the bug report provided, where the compiler crashes while instantiating a function definition. By replacing function template definitions, this operator can help expose bugs related to template instantiation and function overload resolution.
