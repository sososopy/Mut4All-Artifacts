Mutation Operator: ReplaceConstevalWithConstexpr
This mutation operator targets C++20 code that utilizes the consteval keyword for immediate functions. The operator replaces consteval with constexpr in user-defined conversion functions to test how the compiler handles this change, potentially exposing bugs related to the evaluation of constant expressions. 

The operator applies to code structures involving consteval functions, specifically those used within user-defined conversions. It replaces the consteval keyword with constexpr, which has similar but distinct implications for compile-time evaluation. This change can help reveal issues in the compiler's handling of constant expressions and immediate functions.

For example, given a code snippet like this:
struct A {
  consteval operator int() { return 1; }
};

It would be mutated into:
struct A {
  constexpr operator int() { return 1; }
};

This mutation can help test the compiler's ability to correctly handle the differences between consteval and constexpr, potentially uncovering bugs in the process. The focus is on user-defined conversion functions, aiming to achieve high coverage across different program structures and features related to constant expressions and immediate functions in C++20.
