Mutation Operator: TemplateInstantiationWithNonTypeParameter
This mutation operator targets template instantiations in C++ code, specifically focusing on non-type template parameters. It applies to any template definition or instantiation where a non-type parameter is used.

To perform this mutation, follow these steps:
1. Identify a template definition or instantiation in the code that uses a non-type parameter, such as an integer or an enumeration value.
2. Replace the non-type parameter with a different type that is not currently used in the template, such as replacing an integer with a floating-point number or a pointer type.
3. Ensure the new type is compatible with the operations performed within the template, or modify the template code as necessary to accommodate the new type.

Example:
Original code:
```c
template <int I> class C {
public:
  void f() { /* code */ }
};

template class C<0>;
```
Mutated code:
```c
template <float F> class C {
public:
  void f() { /* code */ }
};

template class C<0.0f>;
```
In this example, the non-type parameter `I` of type `int` is replaced with `F` of type `float`, and the instantiation parameter is changed from `0` to `0.0f` to match the new type.

This mutation operator is designed to test the compiler's handling of template instantiations with different types of non-type parameters, which can help expose bugs like the one reported, where the compiler crashes on valid code due to an unexpected placeholder builtin type.
