Mutation Operator: 
Replace Template Instantiation

This mutation operator targets template instantiations in C++ code. It applies to any template instantiation, regardless of the template type or the instantiated type. 

The operator works by replacing the instantiated type with another type that exists in the program. If no other types exist, a new type can be introduced, preferably a basic type such as int, float, or a pointer to an existing type. 

To apply this mutation, the following steps can be taken:

1. Identify a template instantiation in the code.
2. Determine the type being instantiated.
3. Find another type in the program that can replace the instantiated type.
4. Replace the instantiated type with the new type.

For example, given the following code:

```cpp
template <class T>
struct A {
    T val;
};

struct D {
    int x;
};

int main() {
    A<D> a;
    return 0;
}
```

The mutation operator can replace the template instantiation A<D> with A<int>, resulting in:

```cpp
template <class T>
struct A {
    T val;
};

struct D {
    int x;
};

int main() {
    A<int> a;
    return 0;
}
```

This mutation operator can help expose bugs related to template instantiation, such as incorrect type handling or missing type checks. It can also help test the compiler's ability to handle different types and template instantiations. 

This operator achieves high coverage across different program structures and features by targeting template instantiations, which are a fundamental feature of C++ programming. It also uses existing types and variables in the program, making it widely adaptable to seed programs. 

Note that this mutation operator should be applied carefully, as it can change the behavior of the program. It's essential to ensure that the mutated code is still valid and compilable.
