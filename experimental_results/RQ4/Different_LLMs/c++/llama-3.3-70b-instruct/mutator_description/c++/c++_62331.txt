Mutation Operator: Template Parameter Mutation
This mutation operator targets template parameters in C++ code. It applies to any function or class that uses template parameters. The goal is to modify the template parameters to test the compiler's handling of different template parameter combinations.

The mutation operator works by replacing the template parameter type with another type that exists in the seed program. For example, if a function has a template parameter of type 'int', the mutation operator could replace it with another type, such as 'double' or a user-defined type, if available in the seed program.

To apply this mutation operator, follow these steps:
1. Identify a function or class with template parameters in the seed program.
2. Select a template parameter to mutate.
3. Replace the template parameter type with another type that exists in the seed program.
4. Ensure the new type is compatible with the function or class's implementation to avoid compilation errors.

For instance, given the code:
template <typename T>
void foo(T x) { ... }

The mutation operator could replace 'T' with 'int' or 'double' if these types are used elsewhere in the seed program, resulting in:
void foo(int x) { ... } or void foo(double x) { ... }

This mutation operator can help expose bugs related to template parameter handling, such as crashes or incorrect code generation, by testing the compiler's ability to handle different template parameter combinations.
