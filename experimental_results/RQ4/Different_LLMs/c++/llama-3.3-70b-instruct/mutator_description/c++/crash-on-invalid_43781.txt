Mutation Operator: TemplateInstantiationWithDependentBases

This mutation operator targets C++ code that utilizes templates and unqualified lookup into dependent bases, similar to the bug report provided. It applies to code constructs involving template classes with base classes that depend on template parameters.

The operator works by introducing a new template class with a dependent base class and modifying an existing function to use unqualified lookup to access a member of the dependent base class. The goal is to trigger potential bugs related to template instantiation and unqualified lookup, which can cause compiler crashes or incorrect behavior.

To apply this mutation operator:

1. Identify a template class in the seed program.
2. Create a new template class that inherits from a dependent base class (i.e., a base class that depends on a template parameter).
3. Modify an existing function in the seed program to use unqualified lookup to access a member of the dependent base class.
4. Ensure that the modified function is called with a specific template instantiation that exercises the unqualified lookup.

```

    // ...
};

// Mutated code

    // ...
```
