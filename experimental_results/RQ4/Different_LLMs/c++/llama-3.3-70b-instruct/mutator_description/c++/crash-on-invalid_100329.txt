Mutation operator: ModifyParameterType
This mutation operator targets function parameters and modifies their types to trigger potential bugs in the compiler's handling of function overloading, type checking, and default argument promotion. 
It applies to all function definitions and declarations in the code.
To achieve this, for each function parameter, randomly select a different type that already exists in the seed program, and replace the original type with the selected type.
For example, given a function void foo(int x, double y), the mutation operator may change it to void foo(float x, double y) if float is a type already used in the seed program.
The goal is to test the compiler's ability to handle type mismatches, implicit conversions, and potential crashes when dealing with invalid or unexpected parameter types. 
This operator can be applied to various program structures, including function definitions, function declarations, and function calls, to test different aspects of the compiler's behavior.
