Mutation Operator: Lambda Capture Mutation
This mutation operator targets lambda expressions in C++ code. It applies to any lambda expression that captures variables from its surrounding scope. The purpose of this mutation is to test the compiler's ability to handle lambda captures correctly, especially in complex scenarios.

The mutation involves modifying the capture list of a lambda expression. For each lambda expression found in the code, the mutation operator will randomly select one of the following actions:

- Add a new capture to the lambda expression, which can be a variable from the surrounding scope or a new variable introduced by the mutation operator.
- Remove an existing capture from the lambda expression.
- Modify an existing capture to capture a different variable from the surrounding scope.

The mutation operator will ensure that the modified lambda expression remains syntactically valid and that the new or modified captures are valid variables in the surrounding scope.

For example, given a lambda expression like this:

```cpp
auto lambda = [x, y](int z) { return x + y + z; };
```

The mutation operator might modify it to:

```cpp
auto lambda = [x, y, z](int w) { return x + y + w; };
```

Or:

```cpp
auto lambda = [x](int z) { return x + z; };
```

This mutation operator is designed to be widely applicable to various C++ programs and can help achieve high coverage of different program structures and features.
