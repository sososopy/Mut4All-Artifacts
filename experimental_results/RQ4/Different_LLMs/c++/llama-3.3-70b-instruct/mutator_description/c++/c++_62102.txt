Mutation Operator: ReplaceEqualityOperatorWithInequalityOperator
Target Code Construct: Equality operator (==) in binary expressions

Description: This mutation operator replaces the equality operator (==) with the inequality operator (!=) in binary expressions. 
For example, given the code "if (a == b)", the mutation operator would change it to "if (a != b)". 
This change can help expose bugs related to incorrect handling of equality and inequality in the code. 
It is particularly relevant to the given bug report, which involves the instantiation of a function template with an equality operator. 
The goal of this mutation is to test how the compiler handles the replacement of equality with inequality in various contexts, including template instantiations and function calls. 
The mutation operator should be applied to all binary expressions containing the equality operator, regardless of the types of the operands.
