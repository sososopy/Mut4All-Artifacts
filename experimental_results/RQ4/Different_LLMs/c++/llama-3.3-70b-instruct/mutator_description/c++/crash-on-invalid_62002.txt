Mutation Operator: ReplaceConstevalWithConstexpr
This mutation operator targets the consteval keyword in C++20 constant expression evaluation and replaces it with the constexpr keyword. 
It applies to any function declaration where consteval is used.
For example, given the code 
consteval void func() { /* function body */ };
the mutation operator will replace it with 
constexpr void func() { /* function body */ };
This change is designed to test the compiler's handling of the difference between consteval and constexpr, which are both used for constant evaluation but have distinct semantics in C++20.
The idea is to trigger potential bugs in the compiler's ability to distinguish between these two keywords, especially in the context of constant expression evaluation and the experimental constant expression interpreter.
This mutation operator can be applied to any C++20 code that uses consteval to test the compiler's behavior and potentially expose bugs related to constant expression evaluation.
