Mutation operator: modify format attribute index
Target a function declaration with a format attribute, and change the index value of the format attribute to a number that exceeds the number of parameters in the function, or change it to a negative number, or zero if the function has no parameters. This will test the compiler's handling of invalid format attribute indices, especially in the context of varargs functions. For example, given a function declaration like __attribute__((__format_arg__(x))) void test(int i, ...), modify x to a value that will cause an invalid parameter index error.
