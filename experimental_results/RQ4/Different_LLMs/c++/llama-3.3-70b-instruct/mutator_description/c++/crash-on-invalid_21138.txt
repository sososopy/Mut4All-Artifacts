Mutation operator: TemplateMethodCallToNonTemplateMethod
This mutation operator targets C++ code that uses template methods and attempts to replace a call to a template method with a call to a non-template method. The goal is to expose bugs in the compiler's handling of template instantiation and overload resolution.

The operator applies to code constructs where a template method is called with a specific type argument, and a non-template method with the same name exists in the same scope. The mutation involves replacing the template method call with a call to the non-template method, while keeping the same arguments.

For example, given a class template with a template method and a non-template method:
class X {
  template <typename T> void foo(T);
  void foo(int);
};

The mutation operator would replace a call to the template method, such as foo(0), with a call to the non-template method, resulting in foo(0) being replaced with foo(int(0)).

To achieve high coverage, this mutation operator should be applied to various program structures, including template classes, template functions, and template member functions, as well as different types of method calls, such as constructor calls, function calls, and operator calls.

The changes made by this mutation operator are limited to replacing a single method call, and do not introduce any new variables, types, or functions. The operator prefers to use existing variables, types, and functions in the seed program, avoiding the introduction of ambiguous or undefined elements. 

The above approach ensures that the mutation operator is widely applicable and effective in exposing bugs related to template instantiation and overload resolution, which are relevant to the crash-on-invalid bug label.
