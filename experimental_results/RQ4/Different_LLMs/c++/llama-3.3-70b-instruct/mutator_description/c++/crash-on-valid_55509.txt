Mutation Operator: TemplateInstantiationWithDefaultArgumentMutation
This mutation operator targets template instantiations with default arguments in the seed program. It applies to template function and class definitions where default arguments are provided for one or more template parameters.

The mutation involves replacing an existing default argument with a new expression that is valid but different from the original. The goal is to trigger compiler bugs related to template instantiation, particularly when default arguments are involved, which can lead to crashes or incorrect compilation results.

To apply this mutation:
1. Identify template functions or classes with default arguments in the seed program.
2. Select a default argument that can be replaced with a different but valid expression.
3. Replace the default argument with a new expression, ensuring it is syntactically correct and semantically plausible within the context of the template.
4. The new expression should utilize existing types, variables, or functions from the seed program to maximize relevance and minimize the introduction of unnecessary complexity.

For example, given a template function like template <class T, int N = 10> void foo(T t);, this mutation could replace the default argument 10 with another constant or an expression that evaluates to a constant, such as sizeof(int) or a constexpr function call that returns an integer.

This mutation aims to test the compiler's ability to handle template instantiations with varying default arguments, which can expose bugs related to template argument deduction, substitution, and the overall handling of default template arguments, especially in the context of C++23 features and constraints, as indicated by the labels in the bug report.
