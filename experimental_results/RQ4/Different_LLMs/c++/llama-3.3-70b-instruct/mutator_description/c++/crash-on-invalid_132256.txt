Mutation Operator: ChangeTemplateDefaultArgument
This mutation operator targets the template default arguments in a given C++ program. It applies to any template function or class that has default arguments specified. The goal is to test how the compiler handles changes to these default arguments, potentially exposing bugs related to template argument deduction and substitution.

To apply this mutation, follow these steps:
1. Identify all template functions or classes in the program.
2. For each template function or class, locate any default arguments provided for its template parameters.
3. Change the default argument of a selected template parameter to a different type or value that is still valid within the context of the program. If the default argument is a simple type (like int or bool), change it to another simple type. If it's a complex type or an expression, ensure the new default argument is similarly complex or expressive.
4. If a template parameter does not have a default argument, consider adding one, ensuring it does not conflict with existing function overloads or template specializations.
5. Compile the mutated program and observe if the compiler crashes or produces an unexpected error message, indicating a potential bug in handling template default arguments.

Example:
Original code:
```c
template <typename T = int>
void func(T t) {
    // function body
}
```
Mutated code:
```c
template <typename T = double>
void func(T t) {
    // function body
}
```
In this example, the default type of the template parameter `T` is changed from `int` to `double`, testing the compiler's ability to handle this change without crashing or producing incorrect error messages. This mutation operator is designed to be widely applicable across different C++ programs, targeting a specific aspect of template metaprogramming that could potentially reveal compiler bugs labeled as "crash-on-invalid."
