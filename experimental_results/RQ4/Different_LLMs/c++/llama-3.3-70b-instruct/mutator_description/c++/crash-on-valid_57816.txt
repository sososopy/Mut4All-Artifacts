Mutation Operator: Replace Function Call with Overloaded Function Call
This mutation operator targets function calls in the source code and replaces them with calls to overloaded functions with the same name but different parameters. This operator applies to code constructs where function overloading is used, and the goal is to trigger bugs related to function resolution and inlining, such as the one described in the provided bug report.

The mutation operator works as follows: for a given function call, if there exists an overloaded version of the function with a different parameter list, replace the original function call with a call to the overloaded function. For example, given the code:
void foo(int);
void foo(double);

void bar() {
  foo(1); // original call
}

The mutation operator could replace the call to foo(1) with foo(1.0), which calls the overloaded version of foo that takes a double parameter.

To apply this mutation operator, the following steps are taken:
1. Identify function calls in the source code.
2. For each function call, check if there exists an overloaded version of the function with a different parameter list.
3. If an overloaded version exists, replace the original function call with a call to the overloaded function, ensuring that the new call is valid and compilable.

This mutation operator is designed to test the compiler's ability to resolve function overloads correctly, especially in the presence of inlining directives like [[clang::always_inline]]. By replacing function calls with calls to overloaded functions, this operator increases the likelihood of exposing bugs related to function resolution and inlining, such as the crash-on-valid bug reported for the clang compiler.
