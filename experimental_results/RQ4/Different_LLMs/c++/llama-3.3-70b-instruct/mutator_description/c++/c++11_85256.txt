Mutation Operator: ConstructorCallSwapper
The ConstructorCallSwapper mutation operator targets constructor calls in C++ code, specifically focusing on the initializer lists of constructors. This operator swaps the order of two randomly selected constructor arguments in an initializer list, which applies to any class or struct that has a constructor with multiple arguments.

To apply this mutation, first identify all constructor calls with initializer lists that have more than one argument. Then, select two arguments at random from the initializer list and swap their positions. 

For example, given a constructor like the following:
```c
class MyClass {
public:
    MyClass(int x, int y) : member1(x), member2(y) {}
private:
    int member1;
    int member2;
};
```
The mutation could result in:
```c
class MyClass {
public:
    MyClass(int x, int y) : member1(y), member2(x) {}
private:
    int member1;
    int member2;
};
```
This mutation is designed to test the handling of constructor initialization lists by the compiler, potentially revealing issues with argument ordering or handling of constructor calls, which seems relevant given the nature of the provided bug report involving an assertion failure related to the order of base class initializers in the HandleConstructorCall function.
