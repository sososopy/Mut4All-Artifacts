Mutation operator: ChangeFunctionParameterType
This mutation operator targets function calls and changes the type of one of its parameters to a different type that is already defined in the program.
For example, given the code:
void foo(int x) { }
void bar() { foo(10); }
The mutation operator could change the type of the parameter in the function call to a different type, such as:
void bar() { foo('a'); }
This mutation operator applies to function calls in the program and can help expose bugs in the compiler's handling of function calls with different parameter types.
It achieves high coverage across different program structures and features by applying to all function calls in the program, regardless of the function's definition or the types of its parameters.
The mutation operator uses existing types and variables in the program, avoiding the introduction of new or ambiguous types.
The change made by this mutation operator is to replace the original parameter type with a different type that is already defined in the program, which can help expose bugs in the compiler's handling of function calls with different parameter types.
