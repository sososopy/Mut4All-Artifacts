Mutation operator: NestedStructExportMutator
This mutation operator targets the export of nested structs in C++ code. It applies to code constructs where a struct is defined inside another struct and the inner struct is exported. 
The mutation operator works by introducing a new nested struct inside an existing struct and then exporting the new nested struct. 
For example, given a struct S with a member variable x, the mutation operator would add a new struct T inside S and export T. 
The mutated code would look like this: 
struct S { int x; struct T; }; 
export struct S::T {}; 
This mutation operator achieves high coverage across different program structures and features by targeting the export of nested structs, which is a specific code construct that is likely to trigger bugs labeled as crash-on-invalid. 
The mutation operator uses existing variables and types in the seed program, and if new elements are introduced, they are declared clearly, avoiding ambiguous terms. 
The changes made by this mutation operator include adding a new nested struct and exporting it, which requires modifying the existing struct definition and adding a new export statement.
