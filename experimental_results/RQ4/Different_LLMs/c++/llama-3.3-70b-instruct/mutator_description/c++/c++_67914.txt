Mutation Operator: ChangeConstructorInitialization
This mutation operator targets constructor initialization in C++ code and modifies the initialization of objects by changing the order or parameters of constructor calls. 
It applies to constructor definitions where the initialization list is modified to have a different order or different parameters, which could lead to issues if the compiler does not properly handle such changes.
For example, given a constructor like the following:
struct Example {
  int a;
  int b;
  Example(int x, int y) : a(x), b(y) {}
};
The mutation operator might change it to:
struct Example {
  int a;
  int b;
  Example(int x, int y) : b(y), a(x) {}
};
Or:
struct Example {
  int a;
  int b;
  Example(int x, int y) : a(x+y), b(x-y) {}
};
This could help expose bugs in the compiler related to handling of constructor initialization, especially in cases where the order of initialization or the parameters passed to the constructor are critical. 
The goal is to ensure the compiler correctly handles different initialization scenarios without crashing or producing incorrect results.
