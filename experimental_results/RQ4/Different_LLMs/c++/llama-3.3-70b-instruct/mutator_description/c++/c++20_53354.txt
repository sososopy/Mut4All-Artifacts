Mutation Operator: TemplateSpecializationOrderMutator
This mutation operator targets the order of template specializations in C++ code. It rearranges the order of template specializations to test the compiler's ability to handle different specialization orders.

The TemplateSpecializationOrderMutator operator works as follows:
- Identify all template specializations in the code.
- For each set of specializations, generate new code variants by rearranging the order of the specializations.
- Replace the original specializations with the rearranged ones in the new variant.

For example, given the following code:
```c
template <class T>
struct A {
    // primary template
};

template <>
struct A<int> {
    // specialization for int
};

template <>
struct A<double> {
    // specialization for double
}
```
The TemplateSpecializationOrderMutator operator would generate a new variant with the specializations in a different order:
```c
template <class T>
struct A {
    // primary template
};

template <>
struct A<double> {
    // specialization for double
};

template <>
struct A<int> {
    // specialization for int
}
```
This mutation operator is designed to test the compiler's handling of template specializations, particularly in cases where the order of specializations may affect the behavior of the program.
