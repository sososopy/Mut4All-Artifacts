Mutation operator: replace static const template class member with non-static member
This operator targets static const template class members in C++ programs and replaces them with non-static members to potentially expose bugs related to template instantiation and member variable handling. It applies to template classes that contain static const members. The operator works by identifying such members and replacing the 'static' keyword with nothing, thus making the member non-static. For example, given a template class with a static const member 'x', the operator would change 'static const x' to 'const x', thus making 'x' a non-static member. This change can help reveal issues in the compiler's handling of template classes and their members, particularly in cases where the compiler crashes or produces incorrect results due to the presence of static const template class members. The change is made at the declaration site of the member variable, and no new elements are introduced, thus ensuring the mutated program remains valid and compilable.
