Mutation Operator: ArrayElementModification
This operator targets array initialization and modification, which is relevant to the given bug report where an assertion fails due to an array being zero-initialized but having initialized elements. The operator applies to global or local array variables of any type that contain at least one element.

To apply this mutation, follow these steps:
1. Identify an array in the source code.
2. If the array is initialized, select an element that is explicitly initialized with a value.
3. Replace the initializer of the selected array element with a default or zero initializer, or remove the initializer if it exists, effectively setting the element to its default or zero value.
4. If the array is not initialized or partially initialized, select an uninitialized element and initialize it with a value, preferably using an existing variable or a simple expression from the surrounding code.
5. Ensure that the modification does not introduce any syntax errors or undefined behavior.

Example: Given the array declaration "int arr[] = {1, 2, 3};", the mutation could result in "int arr[] = {1, 0, 3};" or "int arr[] = {1, 2};" depending on the chosen action. This operator aims to expose bugs related to array initialization and access, similar to the one described in the bug report, by altering the state of array elements in a way that might trigger assertions or crashes in compilers that do not handle such cases correctly.
