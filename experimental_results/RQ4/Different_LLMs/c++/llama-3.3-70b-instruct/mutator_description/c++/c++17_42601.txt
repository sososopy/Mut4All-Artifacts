Mutation Operator: ReplaceStringViewWithConstCharPointer
This mutation operator targets the use of std::string_view in function parameters and replaces it with a const char* to test the compiler's handling of string literals and pointer conversions. It applies to function declarations and function calls where std::string_view is used as a parameter type.

The operator works by identifying all function parameters of type std::string_view and replacing the type with const char*. If a function call is made with a std::string_view argument, the argument is replaced with a string literal. For example, if the original code contains a function declaration like void test(std::string_view str), the mutated code would contain void test(const char* str). Similarly, a function call like test(std::string_view("hello")) would be mutated to test("hello").

This mutation operator is designed to expose bugs related to the interaction between std::string_view and other string types, such as const char*, and to test the compiler's ability to handle implicit conversions between these types. The use of const char* instead of std::string_view can reveal issues with null pointer checking, string literal handling, and the compiler's implementation of std::string_view. The operator achieves high coverage by targeting a common use case for std::string_view and by making a minimal change to the original code, which makes it more likely to trigger compiler bugs.
