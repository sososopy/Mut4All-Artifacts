Mutation Operator: Replace Constexpr Function with Consteval Function
This mutation operator targets C++20 code that uses constexpr functions and replaces them with consteval functions to check for potential issues with constant evaluation.
The operator applies to any constexpr function in the code and replaces its keyword with consteval.
For example, given a function like this:
constexpr auto add(int a, int b) { return a + b; }
The mutation operator would replace it with:
consteval auto add(int a, int b) { return a + b; }
This change requires no new variables, types, or functions to be introduced, and it only uses existing elements from the seed program.
The goal is to test the compiler's handling of consteval functions, which are a new feature in C++20, and to identify potential bugs or edge cases that may arise from the use of these functions.
