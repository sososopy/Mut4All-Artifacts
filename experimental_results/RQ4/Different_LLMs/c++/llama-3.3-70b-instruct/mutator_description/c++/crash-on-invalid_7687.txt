Mutation Operator: Conditional_Statement_Swap
This operator targets conditional statements in the code, specifically if-else statements, and swaps the conditions of the if and else branches. 
It applies to all conditional statements where both the if and else branches contain statements. 
For example, given an if-else statement of the form: if (condition) then statement1 else statement2, 
the mutated code would be: if (not condition) then statement2 else statement1. 
This is done to check how the compiler handles the swapped conditions and whether it correctly evaluates the statements. 
The mutation operator uses existing variables and conditions in the seed program, 
thus avoiding the introduction of new elements and ensuring the mutated code is valid and compilable. 
The goal is to achieve high coverage of different program structures and features, 
specifically targeting the compiler's ability to handle conditional statements and their evaluations. 
This mutation operator is designed to expose bugs related to the crash-on-invalid label, 
where the compiler crashes when encountering invalid code, in this case, incorrectly evaluated conditional statements.
