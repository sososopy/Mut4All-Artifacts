Mutation Operator: Replace Deleted Function with Non-Deleted Function
This mutation operator targets classes with deleted functions, specifically focusing on constexpr deleted functions as seen in the bug report. The goal is to replace a deleted function with a non-deleted version to see how the compiler handles the change, potentially exposing bugs related to the handling of constexpr and the deletion of special member functions.

The operator applies to any class that has a deleted function, such as constructors, assignment operators, or destructors, that are marked as constexpr. The process involves identifying such functions and then transforming them into non-deleted versions. For example, given a class with a deleted assignment operator like the one in the bug report:

The operator would replace the deleted assignment operator with a defined one, potentially like this:

By making this change, the mutation operator tests the compiler's ability to handle changes in function definition status and its impact on constexpr evaluation, aiming to expose potential bugs in the compiler's frontend related to these features.
