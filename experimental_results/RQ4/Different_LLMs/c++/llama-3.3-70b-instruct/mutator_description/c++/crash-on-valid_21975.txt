Mutation Operator: Replace Conditional Statement with Nested Conditional Statement
This operator targets if-else statements in the code and replaces them with nested if-else statements to potentially expose bugs related to control flow and conditional execution. It applies to code constructs containing conditional statements.

To apply this mutation operator, identify an if-else statement in the seed program, and replace the condition in the if statement with a nested if statement that checks the same condition. For example, if the original code has an if statement like "if (x > 0)", the mutated code would have "if (if (x > 0) then true else false)". 

This operator is designed to achieve high coverage across different program structures by targeting conditional statements, which are fundamental control structures in C++ programming. By introducing nested conditional statements, this operator can help expose bugs that may arise from the compiler's handling of complex control flows.

The operator prefers to use existing variables and types in the seed program to minimize the introduction of new elements. If new elements are necessary, they should be declared with specific and unambiguous types, such as "int" or "bool", to avoid any confusion. The changes made by this operator are clearly outlined, replacing existing conditional statements with nested versions to test the compiler's ability to handle such constructs without crashing or producing incorrect results.
