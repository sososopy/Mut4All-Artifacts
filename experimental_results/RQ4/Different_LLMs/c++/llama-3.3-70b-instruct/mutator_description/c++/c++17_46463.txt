Mutation operator: Replace Static Member Access with Non-Static Member Access
This mutation operator targets C++ code constructs that access static members of a class or struct using the scope resolution operator ::. The operator replaces the static member access with a non-static member access, which may trigger bugs related to the handling of non-static members, such as the one described in the bug report.

The operator applies to code that uses the scope resolution operator :: to access a static member of a class or struct. For example, if the original code is 
if (std::is_invocable_v<decltype(lambda), S::Func>) 
it will be mutated to 
if (std::is_invocable_v<decltype(lambda), S::Func>) 
becomes 
if (std::is_invocable_v<decltype(lambda), S().Func>) 
or 
if (std::is_invocable_v<decltype(lambda), obj.Func>) 
where obj is an instance of S.

To achieve high coverage, this operator should be applied to all occurrences of static member access in the seed program. The operator should prefer using existing variables, types, and functions in the seed program. If new elements need to be introduced, they should be declared clearly, avoiding ambiguous terms. For example, if a new object needs to be created to access a non-static member, it should be declared as an instance of the existing class or struct, such as S obj. 

This mutation operator is designed to expose bugs like the one described in the bug report, where the compiler crashes when accessing a non-static member using the scope resolution operator ::. By replacing static member access with non-static member access, this operator increases the likelihood of triggering such bugs and testing the compiler's handling of non-static members.
