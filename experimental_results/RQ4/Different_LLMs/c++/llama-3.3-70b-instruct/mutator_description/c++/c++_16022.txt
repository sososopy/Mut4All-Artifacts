Mutation Operator: Reference Initialization Change
This operator targets the initialization of references in the source code. It applies to any line where a reference is being initialized, such as the line "Vector3f& normal = loc.second.normalized();". The mutation involves changing the type of the variable being assigned to, to a non-reference type, to see if the compiler correctly handles the change in type. For example, it would change the line to "Vector3f normal = loc.second.normalized();", as seen in the provided bug report. This mutation operator aims to expose bugs similar to the segfault issue reported, where the compiler fails to correctly handle assignments to references, by altering the initialization of references to use non-reference types and observing if the compiler behaves correctly under these changed circumstances.
