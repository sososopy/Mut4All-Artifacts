Mutation operator: ModifyAggregateInitializer
This operator targets aggregate types such as structures and unions, and modifies their initializers. It applies to code constructs containing aggregate initializers. 
The mutation involves replacing the initializer of an aggregate type with an empty initializer list, or removing the initializer altogether if it already exists. 
For example, given a structure like struct S { int x; int y; }; and its instance S s = {1, 2};, the mutation could result in S s = {}; or simply S s;. 
This operator aims to expose bugs related to the handling of aggregate initializers, such as the one described in the bug report where the compiler crashes when encountering an empty initializer list for a union. 
The operator should prefer using existing variables, types, and functions in the seed program, and clearly specify any new declarations needed, avoiding ambiguous terms.
