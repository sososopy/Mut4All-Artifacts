Mutation operator: TemplateInstantiationWithMissingBaseClass
This mutation operator targets template instantiations and applies to code structures involving template classes with inheritance, similar to the bug report provided. It aims to simulate the scenario where a class is missing its definition, which can trigger crashes in compilers when handling invalid input. 

Here's how it works:
- Identify template instantiations in the seed program.
- For each template instantiation found, locate the base classes that the template class inherits from.
- Select one of the base classes and remove its definition from the program, or if the base class is defined within the template, remove its declaration.
- If the base class is used elsewhere in the program, ensure that those uses are adjusted to avoid compilation errors unrelated to the mutation.
- The goal is to create a situation where the compiler is forced to handle a template class that attempts to inherit from a non-existent or undefined class, similar to the scenario described in the bug report.

For example, given a pseudo-code like:
template <T> class MyClass : public BaseClass { ... };
You would mutate it by removing the definition of BaseClass or replacing it with a non-existent class name, resulting in something like:
template <T> class MyClass : public NonExistentClass { ... };

This mutation operator is designed to expose bugs related to how compilers handle missing or undefined base classes in template instantiations, which is relevant to the crash-on-invalid bug label in the provided bug report.
