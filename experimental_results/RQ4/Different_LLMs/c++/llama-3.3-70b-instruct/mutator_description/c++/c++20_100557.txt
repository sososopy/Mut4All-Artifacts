ChangeFunctionCallArguments: 
This mutation operator targets function calls in a given seed program and modifies the arguments passed to the functions. 
It applies to all function calls in the program, regardless of the function type or the number of arguments. 
The operator selects a function call at random and changes one or more of its arguments to a different type or value, 
while ensuring that the new arguments are valid and exist within the program. 
For example, if a function call is "f(a, b)", the operator may change it to "f(a, c)" where c is a variable of the same type as b. 
This mutation operator can help expose bugs related to function overloading, argument type checking, and argument passing mechanisms.
