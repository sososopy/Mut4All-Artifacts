Mutation Operator: Template Argument Modification
This mutation operator targets the template arguments in template instantiations and modifies them to introduce invalid or ill-formed code, which can trigger crashes or errors in the C++ compiler, particularly those labeled as crash-on-invalid.

The operator applies to template instantiations where the template argument is a type, such as class templates or alias templates. It involves replacing the original template argument with either a non-type argument where a type is expected, a type argument where a non-type is expected, or modifying an existing type argument to reference a non-existent or incorrectly specified nested type, similar to the bug report's example where Bar<int>::type is referenced without Bar being defined with such a nested type.

To apply this mutation, follow these steps:
1. Identify template instantiations in the code.
2. Determine the type of template argument expected by the template (type, non-type, template template parameter, etc.).
3. Modify the template argument to either change its kind (e.g., from type to non-type) or to reference a non-existent or incorrectly specified nested type.
4. Ensure that the mutation does not introduce new, undeclared variables or types but rather manipulates existing ones or references to types in a way that could provoke a compiler error or crash, especially for compilers with issues like those described in the crash-on-invalid bug label.

For example, given a template struct like template<class T> struct Foo {}; and its instantiation Foo<int>, the mutation could involve changing the template argument to a non-type, such as an integer literal (Foo<5>), or to a type that does not match the expected kind, or referencing a nested type that does not exist (e.g., Foo<UnknownType::NonExistentNestedType>), aiming to trigger a crash or error similar to the one reported. This approach targets compiler robustness and error handling for ill-formed template code.
