Mutation operator: InvalidUnaryOpInsertion

The goal is to test the compiler's ability to handle invalid or unexpected input and ensure it produces the correct error messages or behavior.
To achieve high coverage, this operator should be applied to various unary expressions throughout the source code, including those involving different data types and operators.
