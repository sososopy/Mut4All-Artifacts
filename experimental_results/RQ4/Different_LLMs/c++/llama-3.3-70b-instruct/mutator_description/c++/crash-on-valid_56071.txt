Mutation operator: replace lambda with a regular function 
This mutation operator replaces a lambda function with a regular function in the source code to test if the compiler can handle the difference between lambda functions and regular functions. 
The replacement can be done by rewriting the lambda function as a regular function with the same name and parameters. 
For example, if we have a lambda function like this: 
auto x = [](auto) -> void { f3<int>(); };
We can replace it with a regular function like this:
void lambda_function(auto) { f3<int>(); }
auto x = lambda_function; 
This mutation operator targets the code construct of lambda functions and regular functions, and it applies to any lambda function in the source code. 
It is designed to test the compiler's ability to handle the differences between lambda functions and regular functions, and it achieves high coverage across different program structures and features by replacing all lambda functions with regular functions. 
Note that this mutation operator does not introduce any new variables, types, or functions that are not already present in the seed program, and it clearly outlines the changes that need to be made to the source code.
