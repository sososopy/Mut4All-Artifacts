Mutation operator: InsertLambdaAnnotation 
This operator targets lambda expressions within the code and inserts an annotation attribute similar to [[clang::annotate_type("annotation")]] to the lambda expression.
It applies to all lambda expressions, regardless of their position or context within the program.
To implement this operator, first identify all lambda expressions in the seed program.
For each lambda expression found, insert the annotation attribute [[clang::annotate_type("annotation")]] immediately after the parameter list of the lambda.
If the lambda expression already contains attributes, the new annotation attribute should be appended to the existing list of attributes.
The inserted annotation should use existing types or constants in the seed program as the argument to annotate_type, if possible.
If new elements need to be introduced, they should be declared with a clear and specific type, avoiding any ambiguity.
For example, given a lambda expression (void) [] (T) { }, the mutation operator would transform it into (void) [] (T) [[clang::annotate_type("annotation")]] { }, where "annotation" is an existing type or constant in the seed program, or a newly declared one with a specific type.
