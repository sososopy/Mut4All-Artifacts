Mutation operator: InsertInvalidSyntax
This mutation operator targets class and struct definitions in C++ code. It inserts a syntax error, such as a random keyword or symbol, at a random location within the class or struct body. The goal is to test the compiler's ability to handle invalid syntax and crash recovery.

For example, given a class definition like this:
class B {
  private:
    static void foo() {}
    C<int, decltype(foo)> c;
};

The mutation operator might insert a syntax error, resulting in:
class B {
  p   // syntax error
  private:
    static void foo() {}
    C<int, decltype(foo)> c;
};

This mutation operator applies to any class or struct definition in the code. It uses existing variables, types, and functions in the seed program, and does not introduce new elements. The syntax error is inserted at a random location within the class or struct body, which helps to test the compiler's crash recovery mechanisms.
