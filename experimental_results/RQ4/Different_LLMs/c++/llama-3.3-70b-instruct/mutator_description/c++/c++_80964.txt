Mutation operator: Conditional Statement Negation
This mutation operator targets conditional statements in the code and negates their conditions. 
It applies to if statements and conditional expressions, and can be used to test how the program behaves when the condition is false instead of true, or vice versa. 
The operator works by inserting a logical NOT operator before the condition, effectively reversing its truth value. 
For example, if the original statement is "if (x > 5)", the mutated statement would be "if (!(x > 5))". 
This can help expose bugs that occur when the program does not handle conditional statements correctly. 
To apply this operator, identify conditional statements in the code and insert a logical NOT operator before the condition, taking care to balance parentheses and ensure the resulting statement is syntactically correct. 
The operator should be applied to existing conditional statements in the seed program, without introducing new variables or types. 
By applying this operator, you can test the robustness of the program's conditional logic and identify potential bugs that may not be immediately apparent.
