Mutation Operator: ReplaceUnionWithClass
This mutation operator targets code constructs involving unions in C++11, specifically focusing on the instantiation of class templates that contain unions of non-trivial classes. It applies to union declarations within class templates.

To apply this mutation, identify a union declaration within a class template, and replace the union with a class declaration that contains the same member variables as the original union. For instance, if the original code contains a union like "union U { int x; double y; };", the mutated code would replace this union with a class like "class U { int x; double y; };". 

This mutation is designed to test the compiler's handling of non-trivial classes within class templates, potentially exposing bugs related to the crash-on-invalid issue reported, especially in the context of C++11 features and the clang frontend. The operator aims to achieve high coverage by targeting specific structures (unions within class templates) that are likely to trigger such compiler bugs. 

By replacing the union with a class, the mutation tests the compiler's ability to handle the differences in memory layout and access rules between unions and classes, which can be particularly challenging in the context of template instantiation and non-trivial classes. This approach does not introduce customized data names, types, or variable names, making it adaptable to various seed programs. The focus is on utilizing existing variables, types, or functions within the seed program to ensure the mutation is widely applicable and effective in exposing potential compiler bugs.
