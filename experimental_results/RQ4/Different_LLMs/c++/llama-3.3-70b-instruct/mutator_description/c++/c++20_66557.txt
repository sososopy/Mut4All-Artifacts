Mutation operator: ReplaceParenListInitExprWithBraceInitExpr
This mutation operator targets C++ initialization expressions and replaces all occurrences of parenthesized list initialization (e.g., `Type var(type1, type2);`) with brace initialization (e.g., `Type var{type1, type2};`).
The structures that C++ compiler bugs are more likely to trigger include template instantiations, especially those involving complex template argument deduction and instantiation of function templates. This operator is designed to test the compiler's handling of initialization expressions in the context of template instantiation.
This operator applies to all initialization expressions in the code.
The replacement is done by changing the syntax of the initialization expression from parentheses to braces, without modifying the types or variables involved.
For example, given the code `std::pair<int, int> p(1, 2);`, the mutation operator would replace it with `std::pair<int, int> p{1, 2};`.
No new elements are introduced, and the existing types and variables are preserved.
This operator achieves high coverage across different program structures and features by targeting a common C++ syntax element and modifying it in a way that exercises the compiler's handling of template instantiation and initialization expressions.
