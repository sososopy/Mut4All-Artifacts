Mutation Operator: ReplaceNonTypeTemplateParameterPackExpansion
This operator targets the expansion of non-type template parameter packs in template arguments, specifically in the context of concept-constrained non-type template parameters.
It applies to template parameter lists where a non-type template parameter pack is expected to be expanded, such as in the given bug report.
The mutation involves replacing the expansion of a non-type template parameter pack with a single non-type template parameter or vice versa.
For example, given a template like template <typename... Ts, InitFunc<Ts>... auto init> struct LazyLitMatrix;, the mutation might replace Ts with a single type T, resulting in template <typename T, InitFunc<T> auto init> struct LazyLitMatrix;.
Alternatively, if the original template is template <typename T, InitFunc<T> auto init> struct LazyLitMatrix;, the mutation could introduce a pack expansion, changing it to template <typename... Ts, InitFunc<Ts>... auto init> struct LazyLitMatrix;.
This mutation is designed to test the compiler's handling of pack expansions in concept-constrained non-type template parameters, aiming to expose bugs similar to the one reported, where the compiler crashes due to an unexpanded pack in a concept-constrained non-type template parameter.
