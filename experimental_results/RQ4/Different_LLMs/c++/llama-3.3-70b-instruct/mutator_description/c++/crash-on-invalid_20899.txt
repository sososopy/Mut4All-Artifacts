Mutation Operator: Null Pointer Introduction
This mutation operator targets pointer dereferences in the code, aiming to introduce null pointer dereferences similar to the one described in the bug report. It applies to any code construct that involves pointer dereferences.

The operator works by identifying all pointer variables in the code and replacing their assignments or initializations with a null pointer (nullptr) with a certain probability. For example, if the code contains a line like "pointer = new type;", the mutation operator might change it to "pointer = nullptr;".

To achieve high coverage and adaptability to seed programs, the operator will prefer using existing pointer variables and types within the program. If a pointer variable does not exist in the scope where the mutation is applied, the operator will introduce a new pointer variable with the same type as an existing variable in the program, ensuring it is properly declared before use.

For instance, given a pseudo-code like "var = malloc(size);", the operator could mutate it into "var = nullptr;", directly introducing a null pointer. This simple yet effective approach can help expose bugs related to null pointer dereferences, including crashes on invalid operations like the dyn_cast of a nullptr, as mentioned in the bug report.
