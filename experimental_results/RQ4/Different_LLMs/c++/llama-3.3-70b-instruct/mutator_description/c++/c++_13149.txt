Mutation Operator: Modify Template Specialization
This mutation operator targets template specializations in C++ code, specifically where a template class is specialized for a particular type. The goal is to modify the template specialization to trigger potential bugs in the compiler's handling of template metaprogramming.

This operator applies to code constructs where a template class is defined with a primary template and one or more specializations. For example, consider a template class "Container" with a primary template and a specialization for type "int":
template <typename T> class Container { ... };
template <> class Container<int> { ... };

To apply this mutation operator, follow these steps:
1. Identify a template class with a specialization.
2. Modify the specialization by changing the type parameter to a different type that already exists in the seed program. If no such type exists, introduce a new type that is similar to the original type, ensuring it is properly declared and defined within the scope of the template.
3. Replace all occurrences of the original type in the specialization with the new type, ensuring that all references to the original type are updated correctly.

For instance, given the example above, the mutation could result in:

template <> class Container<float> { ... };
