Mutation Operator: ChangeTemplateArgument
The ChangeTemplateArgument mutation operator targets template instantiations in C++ code. It applies to any template instantiation where a type or non-type argument is provided. The goal is to modify the template arguments to potentially expose bugs related to template metaprogramming, type deduction, or instantiation.

To apply this mutation operator, follow these steps:
1. Identify a template instantiation in the code, such as `std::vector<int>` or `MyTemplate<class T>`.
2. Select one of the template arguments, such as `int` in `std::vector<int>`.
3. Replace the selected argument with another type or value that is valid in the context but different from the original. For example, change `std::vector<int>` to `std::vector<float>` or `MyTemplate<class T>` to `MyTemplate<class U>`, assuming `U` is another type that could logically fit in that context.
4. Ensure the replacement type or value is declared and accessible within the scope of the template instantiation to avoid introducing compilation errors not related to the mutation.

This operator can help uncover issues in the compiler's handling of template instantiations, such as incorrect type deductions, mismatches in template argument types, or errors in the instantiation process itself.
