Mutation Operator: IncludeNonExistentHeader 
This mutation operator targets C++ programs that include standard library headers. 
It applies to lines of code where an include directive is present. 
The operator works by replacing an existing include directive with a directive that includes a non-existent header file. 
For example, given the line #include <vector>, the mutation operator might replace it with #include <nonexistentheader>. 
This change is designed to test the compiler's ability to handle invalid input, specifically the case where a header file does not exist. 
The operator achieves high coverage by being applicable to a wide range of include directives throughout a program, regardless of the types, variables, or functions used. 
The use of a non-existent header file is a clear and specific change that avoids introducing customized data names or types, making it adaptable to seed programs without requiring additional declarations. 
By introducing such a mutation, the compiler's error handling and reporting mechanisms can be tested, especially in the context of the crash-on-invalid bug label, where the compiler should gracefully handle and report errors for invalid input rather than crashing.
