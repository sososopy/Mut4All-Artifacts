Mutation Operator: Replace Lambda Default Argument Type
This mutation operator targets generic lambda expressions with default arguments in C++14 code. It applies to code constructs where a lambda expression is defined with a generic parameter and a default argument is provided for that parameter. The goal is to replace the type of the default argument with a different type that already exists in the seed program to potentially trigger crashes or deadlocks similar to the reported segfault/deadlock issue with default lambda arguments to generic lambdas.

To apply this mutation, first identify all generic lambda expressions in the code. For each lambda, check if it has a default argument. If a default argument is found, replace its type with another type that is already used in the program. This could involve changing the type of a variable, function return type, or any other type that is compatible with the context of the lambda expression.

For example, if the original code contains a lambda like this: 
auto lambda = [](auto x = 0.0) { return x; };

The mutation could change the default argument type to an integer type if such a type is used elsewhere in the program:
