It applies to code constructs where a templated lambda function is called with different template parameters within a switch statement.

The mutation involves substituting the template parameters of a templated lambda function with different types or values to observe how the compiler handles various instantiations. The goal is to achieve high coverage across different program structures and features by systematically modifying the template parameters in the existing code.

For example, consider a templated lambda function that takes an integer template parameter and is invoked within a switch statement. The mutation operator would replace the integer template parameter with other types, such as a character or a floating-point number, to test the compiler's handling of different template instantiations.
