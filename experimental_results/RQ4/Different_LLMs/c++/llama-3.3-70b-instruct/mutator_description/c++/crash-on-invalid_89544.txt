Mutation operator: modify_destructor_declaration 
This mutation operator targets class or struct definitions and modifies the declaration of the destructor to make it malformed. 
It applies to any class or struct definition in the code, and its purpose is to test how the compiler handles classes with malformed destructors, 
similar to the bug report where the destructor of the class Foo is declared as ~Foo() = {}, which is not a valid declaration. 
To apply this mutation operator, first identify all class or struct definitions in the code. 
Then, for each class or struct definition found, modify the destructor declaration to introduce a syntax error, 
such as adding an initializer on the function that does not look like a pure-specifier, similar to the bug report. 
For example, if the original code has a class definition like class Foo { ~Foo(); }, 
the mutated code could be class Foo { ~Foo() = {}; }, which is a malformed declaration. 
This mutation operator tests the compiler's ability to handle and report errors in class definitions, 
specifically focusing on the declaration of the destructor, and can help expose bugs like the one reported.
