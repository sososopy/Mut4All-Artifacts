Mutation operator: ReplaceArrayPointerType
This operator targets array and pointer type declarations in the source code. It applies to code constructs where an array or pointer type is used as a base type for another type declaration, such as in the case of a pointer to an array or an array of pointers.
To apply this operator, replace an existing pointer or array type with its corresponding array or pointer type, respectively. For example, if the original code has a declaration of the form "type *base", replace it with "type base[]" or vice versa. If the base type is not already a pointer or array type, introduce a new pointer or array type by adding a pointer or array specifier to the base type.
The goal is to test the compiler's ability to handle type checking and validation for pointer and array types. By replacing these types, the operator can help expose bugs related to type checking and validation, such as the one reported in the bug trace.
To illustrate this, consider a code snippet where a function takes a pointer to an array as an argument. The mutation operator would replace the pointer to an array with an array of pointers, and vice versa, to test the compiler's handling of these types. The operator prefers to use existing types and variables in the seed program, but if new elements are introduced, they should be declared with specific and unambiguous types to avoid ambiguity.
