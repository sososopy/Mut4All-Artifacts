Mutation Operator: Replace Lambda Capture
This mutation operator targets lambda expressions and replaces the capture list with a new capture list that includes all variables from the surrounding scope. 
It applies to lambda expressions that have a capture list and are defined inside a function or block scope.
For a given lambda expression, the mutation operator will replace the existing capture list with a new capture list that includes all variables from the surrounding scope, 
using the default capture syntax, which captures variables by value if they are not explicitly captured by reference.
For example, given a lambda expression such as [x, y] {}, the mutation operator may replace it with [=] {} or [&] {} depending on the context, 
ensuring that all variables from the surrounding scope are captured.
This mutation operator is likely to expose bugs related to variable capture in lambda expressions, such as incorrect capture of variables or incorrect handling of captured variables.
The changed content will include the lambda expression capture list, which will be replaced with a new capture list.
The new capture list will include all variables from the surrounding scope, and variables will be captured by value if they are not explicitly captured by reference.
For instance, in a block scope with variables a, b, and c, the lambda expression [a] {} may be mutated to [=] {} to capture all variables by value, or [&] {} to capture all variables by reference.
This mutation operator achieves high coverage across different program structures and features by targeting lambda expressions, which are a key feature of C++11 and later standards, 
and by replacing the capture list with a new capture list that includes all variables from the surrounding scope, thus exercising the compiler's handling of variable capture.
This ensures that the mutation operator can be widely adapted to seed programs, without requiring customized data names, types, or variable names.
