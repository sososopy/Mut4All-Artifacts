Mutation Operator: LambdaToFunctionPointer
This mutation operator targets code constructs involving lambda functions, specifically those that are used as function arguments or return types. It applies to lambda expressions that capture variables from their surrounding scope.

The mutation involves replacing a lambda function with a function pointer that points to a newly declared function. The newly declared function will have the same signature as the lambda function and will contain the same logic as the lambda function's body.

For example, given the following code:
```c
auto lambdaFunc = [](int x) { return x * 2; };
```
The mutation operator would replace it with:
```c
int lambdaFunc(int x) { return x * 2; }
auto funcPtr = lambdaFunc;
```
In this example, `lambdaFunc` is replaced with a function pointer `funcPtr` that points to the newly declared `lambdaFunc` function. The `lambdaFunc` function has the same signature and logic as the original lambda function.

This mutation operator is designed to expose bugs related to the handling of lambda functions, such as issues with capture lists, return types, or function signatures. By replacing a lambda function with a function pointer, this operator can help identify problems in the compiler's ability to handle these complex constructs.

To achieve high coverage across different program structures and features, this mutation operator can be applied to various lambda functions throughout the code, including those used as function arguments, return types, or assigned to variables. The operator can also be combined with other mutation operators to test more complex scenarios. 

The changes made by this mutation operator are limited to replacing lambda functions with function pointers, without introducing new variables, types, or functions that are not already present in the seed program. If new elements are introduced, they are declared in a way that avoids ambiguity, ensuring the mutated code remains valid and comparable to the original code.
