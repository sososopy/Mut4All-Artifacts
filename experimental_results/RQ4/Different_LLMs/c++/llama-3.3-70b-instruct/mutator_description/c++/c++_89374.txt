Mutation Operator: Template Specialization Swap
This operator targets template specialization in C++ code, specifically focusing on the partial specialization of templates. It applies to code structures that involve template metaprogramming, where the specialization of templates is crucial for the correct functionality of the program.

The goal of this operator is to swap the template parameters of two different partial specializations of the same template, potentially revealing issues in the compiler's handling of template metaprogramming, especially in scenarios where the compiler might fail to correctly deduce template arguments or handle template specialization.

To apply this mutation operator:

1. Identify all partial specializations of a template within the given code.
2. Select two distinct partial specializations of the same template.
3. Swap the template parameters of these two specializations.

For example, given the following original code snippet:
```c
template <typename T>
struct MyTemplate { /* ... */ };

template <>
struct MyTemplate<int> { /* specialization for int */ };

template <>
struct MyTemplate<float> { /* specialization for float */ };
```
Applying the Template Specialization Swap mutation operator would result in:
```c
template <typename T>
struct MyTemplate { /* ... */ };

template <>
struct MyTemplate<int> { /* specialization for float */ };

template <>
struct MyTemplate<float> { /* specialization for int */ };
```
This mutation can expose bugs in the compiler by forcing it to handle unexpected or incorrectly specialized templates, which might lead to failures in template argument deduction, instantiation, or other aspects of template metaprogramming. The swapping of specializations can trigger compiler crashes, incorrect code generation, or other forms of misbehavior if the compiler does not correctly handle the swapped template parameters.
