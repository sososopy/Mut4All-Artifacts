Mutation Operator: Replace Lambda Expression with Alternative Expression
This mutation operator targets lambda expressions within requires expressions, replacing them with alternative expressions. The goal is to test the compiler's handling of different expression types within the requires clause.

Applicable to: Lambda expressions within requires expressions in C++20 code.

Description: Replace a lambda expression with an alternative expression, such as a simple expression or a function call. For example, given the code:
S(auto value) requires (requires () { [&] -> decltype(value) {}; })
Replace the lambda expression [&] -> decltype(value) {} with a simple expression, such as value or a function call, like foo(value).

Changes:
- Identify lambda expressions within requires expressions.
- Replace the lambda expression with an alternative expression.
- Ensure the alternative expression is valid in the context of the requires clause.

Example:
Original code:
struct S {
    S(auto value) requires (requires () { [&] -> decltype(value) {}; })
    {}
};

Mutated code:
struct S {
    S(auto value) requires (requires () { value; })
    {}
};

This mutation operator tests the compiler's ability to handle different expression types within the requires clause, which is relevant to the reported bug. By replacing lambda expressions with alternative expressions, we can expose potential issues in the compiler's parsing and analysis of requires expressions.
