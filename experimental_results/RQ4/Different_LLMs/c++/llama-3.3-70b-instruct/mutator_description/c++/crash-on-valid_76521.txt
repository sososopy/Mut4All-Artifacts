Mutation Operator: Add Attribute to Lambda Expression
This mutation operator targets lambda expressions in C++ code and adds an attribute to the lambda expression. The attribute added will be a pcs attribute with a random calling convention. This operator applies to any lambda expression in the code.

To implement this operator, the following steps can be taken:
1. Identify all lambda expressions in the code.
2. For each lambda expression, add an attribute of the form __attribute__((pcs("calling_convention"))) where calling_convention is a random calling convention such as aapcs, aapcs-vfp, or intel.
3. Ensure that the added attribute does not conflict with any existing attributes on the lambda expression.

For example, given the following code:
auto l = []() {};

The mutation operator could transform it into:
auto l = []() __attribute__((pcs("aapcs-vfp"))) {};

This mutation operator is designed to test the compiler's ability to handle attributed lambda expressions, which is relevant to the given bug report. By adding random attributes to lambda expressions, this operator can help expose bugs in the compiler's attribute handling code.
