Mutation operator: ReplaceTemplateParameterWithDefaultConstructibleType
This mutation operator targets template instantiations in C++ code, particularly focusing on the template parameters that are used within the template definition. The goal is to replace a template parameter with a default-constructible type (like int, double, etc.) to test how the compiler handles various types in template instantiation, especially when those types have default constructors that might influence the behavior of the template.

The mutation applies to code structures involving template definitions and their instantiations. Given a template definition, this operator identifies template parameters and attempts to replace them with a default-constructible type that is already defined within the scope of the template or in the standard library, ensuring that the replacement type is compatible with the context in which the template is used.

For example, given a template struct like the one in the bug report:
template<typename T>
struct B {
  [[clang::annotate("test", (9, (void)T{}))]] void t() {}
};
B<int> b;

This mutation operator might replace T with another type, such as double, if double is deemed compatible and default-constructible in the context of the template B. The resulting mutation could look like:
template<typename T>
struct B {
  [[clang::annotate("test", (9, (void)T{}))]] void t() {}
};
B<double> b;

This mutation is designed to test the compiler's ability to handle different types within templates, especially focusing on types that have default constructors, which could potentially interact with the annotation attribute in the template definition. By systematically replacing template parameters with various default-constructible types, this operator aims to uncover bugs related to template instantiation and type handling within the compiler, similar to the one described in the crash-on-valid bug report.
