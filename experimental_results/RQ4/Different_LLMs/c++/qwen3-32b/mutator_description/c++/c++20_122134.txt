Mutation Operator: CTAD_Constrained_Default_TypeAlias
Target: Class templates with constructors and type alias templates with default arguments.
Application: Replace an existing unconstrained constructor in a class template with a constrained template constructor using an existing concept. Modify a type alias template to include a default argument for a template parameter. Ensure the type alias template is used in CTAD without explicit template arguments.
Example:
Original code:
template <class T> struct S { S(T) {} };
template <class T = int> using A = S<T>;

Mutated code:
template <class, class> concept C = true;
template <class T> struct S {
  S(C<T> auto) {}
};
template <class T = int> using A = S<T>;

int main() {
  A{0}; // CTAD without explicit arguments
}

Notes: Requires an existing class template with a constructor and a type alias template. The concept must be defined in scope. The mutation introduces constrained template parameters and relies on CTAD to trigger template argument deduction.
