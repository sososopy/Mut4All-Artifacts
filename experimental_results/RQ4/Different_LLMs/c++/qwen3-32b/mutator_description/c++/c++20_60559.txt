Mutation Operator: Swap constrained and unconstrained parameter packs in lambdas with concepts.  
Applies to: Lambdas with multiple parameter packs, at least one constrained by a concept.  
Description: In a lambda parameter list containing both constrained and unconstrained parameter packs (e.g., `any<P> auto... args1, auto... args2`), swap their positions to `auto... args2, any<P> auto... args1`. This disrupts the original constraint application order during template instantiation.  

Example:  
Original:  
```cpp  
[&]<size_t... Idxs>(std::index_sequence<Idxs...>) {  
    return [&](any<Idxs> auto..., auto, auto...) {  

    }(args...);  
}  
```  
Mutated:  
```cpp  
[&]<size_t... Idxs>(std::index_sequence<Idxs...>) {  
    return [&](auto, auto..., any<Idxs> auto...) {  

    }(args...);  
}  
```  

This exposes bugs in constrained parameter pack handling by forcing the compiler to process unconstrained packs first, potentially misvalidating concept constraints during instantiation.
