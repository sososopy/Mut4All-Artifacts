Mutation Operator: TemplateParamKindMismatchInSpecialization
Applies to class template partial specializations where the primary template uses a type parameter but the specialization declares a non-type parameter. Target existing templates with type parameters in the seed program. Modify the partial specialization by replacing one or more type parameters with non-type parameters (e.g., integers) in the template argument list, ensuring the substitution creates an invalid type-parameter mismatch. Example: For a primary template `template<typename T> class PrimaryTemplate`, mutate a partial specialization to `template<int N> class PrimaryTemplate<int>`. This forces the compiler to handle inconsistent template parameter kinds between primary and specialization, likely triggering assertion errors during template instantiation.
