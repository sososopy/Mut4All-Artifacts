Mutation operator: Insert a redundant template parameter in a variadic template class declaration by duplicating an existing type from the parameter list. Apply to any variadic template class with multiple type parameters. For example, in template<typename T0, T1...> class X, replace with template<typename T0, T0, T1...> class X. The duplicated type must already exist in the original parameter list. This forces the compiler to process overlapping template argument lists, potentially triggering assertion failures in diagnostic systems during template instantiation.
