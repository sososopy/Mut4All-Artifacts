Mutation Operator 1: Replace the return type of a lambda within a function template from `decltype(parameter)` to a type derived from the same parameter using pointer, reference, or unary operator transformations. Apply this to lambdas in function templates where the return type relies on `decltype` of a parameter. Example: change `-> decltype(value)` to `-> decltype(&value)` or `-> decltype(++value)`. This forces template instantiation to process modified type deduction paths, exposing bugs in handling derived types during substitution. Use the same parameter name as in the original code, ensuring existing variables are referenced.
