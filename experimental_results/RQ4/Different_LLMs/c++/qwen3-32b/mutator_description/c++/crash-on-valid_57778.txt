Mutation operator: Add a module interface declaration to the top of a translation unit, converting it into a module interface unit. This targets code compiled with a module name flag, where the compiler may mishandle module code generation. Apply to translation units without existing module declarations. Example: Insert "module;" or "export module name;" at the beginning of the global scope. If the source is a .cpp file, this creates a hybrid module interface unit that may trigger assertion failures during codegen. The original code must be compilable with a module name flag but lack module declarations. Changes required: Add a module declaration statement at the top level.
