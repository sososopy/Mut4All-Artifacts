Mutation operator: Replace a valid operation in a constexpr function with an invalid constant expression operation (e.g., division by zero) to force the compiler to evaluate it during compile time, potentially causing a crash if the evaluator isn't handling errors correctly. Applies to any constexpr function or variable requiring constant evaluation.

Example:  
Original:  
constexpr int compute(int a) { return a * 2; }  

Mutated:  
constexpr int compute(int a) { return a / 0; }  

This mutation generates a constexpr function with a division by zero. The compiler must detect the invalid constant expression during evaluation. If the evaluator crashes or fails to report the error properly, the bug is exposed. Uses existing variables and constructs from the seed program.
