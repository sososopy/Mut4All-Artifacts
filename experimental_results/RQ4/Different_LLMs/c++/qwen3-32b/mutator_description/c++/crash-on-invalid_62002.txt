Mutation Operator: Replace a user-defined constructor of a class with a consteval constructor that calls a constexpr void function. If no such function exists in the translation unit, declare an extern constexpr void function in the global scope. Ensure the class has a constinit static or global variable to trigger constant evaluation.  

Example:  
Original code:  
class C {  
public:  
    C() { }  
};  
void f() { }  

Mutated code:  
class C {  
public:  
    consteval C() { extern_func(); }  
};  

extern constexpr void extern_func();  

constinit C obj;  

This mutation forces a consteval constructor (which must evaluate at compile-time) to invoke a constexpr void function (which is invalid in a constant expression). The extern declaration ensures linkage, and the constinit variable triggers compile-time initialization, reproducing the context where the experimental constant interpreter crashes.
