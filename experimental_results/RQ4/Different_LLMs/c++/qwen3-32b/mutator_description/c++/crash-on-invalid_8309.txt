Mutation Operator: Replace a constructor's static type cast with a nested template type parameter from an outer template scope.

Applies to: Template specializations containing constructor initializers with type casts to fixed types.

Implementation: In a template class/struct specialization, modify a constructor's initialization list to use a template type parameter from an outer template level instead of a fixed type. For example:
Original: new(this) WeirdClass(static_cast<char*>(str), 0)
Mutated: new(this) WeirdClass(static_cast<T1*>(str), 0) 
Where T1 is a template parameter declared in a surrounding template scope.

Effect: Creates a template depth >0 in nested template type parameters, exposing assertions expecting depth=0. This leverages existing template parameters from the enclosing context rather than introducing new types.
