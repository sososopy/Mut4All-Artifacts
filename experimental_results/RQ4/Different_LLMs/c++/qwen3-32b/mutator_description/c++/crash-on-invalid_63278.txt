Mutation Operator: Replace a non-static data member's type with `auto` and add a default initializer expression. Apply to any struct/class member with a known type and default initialization.  
Example: Change  
`T x;`  
to  
`auto x = initializer;`  
where `initializer` is a valid expression compatible with `T` (e.g., `0`, `""`, `{}`), using existing program logic if available. Use only literals or trivial expressions to avoid undeclared dependencies.
