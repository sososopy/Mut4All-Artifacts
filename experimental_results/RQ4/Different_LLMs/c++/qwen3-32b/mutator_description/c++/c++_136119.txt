mutation operator: NestedTemplateAccessQualification
Target code constructs: Nested template member access using dependent types in template functions.
Applies to: Any template function that uses a qualified name to access a nested template member, where the qualifier depends on a template parameter.
Modifies: Replaces a direct nested template member access with an altered qualification path that introduces an additional level of indirection using the same template parameters.
Example: In a function using 't.U::template B<V>::MEM' where U is a template parameter, change it to 't.U::template C<V>::template B<W>::MEM' (assuming C is a nested template in U with a template parameter W defined in the same scope).
Changes required: Ensure the qualifying path includes at least two levels of nested templates with dependent type parameters, using the same template parameters as the outer function. The 'template' keyword must be explicitly used for all template accesses.
