Mutation operator: LambdaReturnTypeWithOuterScopeDecltype
Applies to: Lambdas within variadic template functions or templates that capture local variables from outer scopes.

Modifies a lambda's return type to use decltype(x) where x is a local variable from a different function in the same translation unit. Requires:
1. Selecting a lambda that is a parameter or local within a variadic template
2. Identifying a local variable x from another function in the same TU
3. Changing the lambda's return type to -> decltype(x)

Pseudo-code transformation:
Original:
void foo() {
  int x;
  auto l = []() { return 0; };
}

Transformed:
void bar() {
  int y;
  auto l = [y]() -> decltype(y) { return y; };
}

void foo() {
  int x;
  auto l2 = []() -> decltype(x) { return 0; };
  f2<decltype(l2)>(l2);
}

template <typename F, typename... Ts>
void f2(F f) {
  ((Ts{}, f()), ...);
}
