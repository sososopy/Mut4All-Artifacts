mutation operator: TemplateSpecializationWithOuterParam
Applies to template struct definitions with at least one template parameter. For a selected template struct, create a partial specialization for a specific type (e.g., int), and in the specialization's base class or member, use a template parameter from the outer scope instead of the current specialization's parameters. Example: Transform 
template<typename T> struct Foo {};
into 
template<typename T> struct Foo {};
template<> struct Foo<int> : Bar<T> {}; 
where T is the original template parameter from the outer Foo template. This introduces a partial specialization that references an outer template parameter instead of using its own, creating an invalid construct that may expose template deduction bugs.
