mutation operator: Introduce requires clause in lambda within concept  
Target construct: Concepts with template parameters (T)  
Apply to: Existing concept definitions with parameter(s)  
Transformation:  
1. Replace concept condition with a lambda that captures template parameter  
2. Lambda body must contain requires clause using parameter from concept  
3. Requires clause must check basic expression (like parameter itself)  
4. Use existing types/parameters from concept definition only  

Example mutation:  
Before:  
template<typename T> concept OldConcept = true;  

After:  
template<typename T> concept OldConcept =  
    []{  
        return requires(T t) {  
            { t } -> satisfies_something;  
        };  
    }();  

Where "t" is the original concept parameter and "satisfies_something" is an existing concept in the same program  

Note: This specifically targets requires expressions in lambdas inside concepts to expose handling of nested constraints in C++20 compilers
