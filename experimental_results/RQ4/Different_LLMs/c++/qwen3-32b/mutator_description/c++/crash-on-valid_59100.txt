Mutation Operator: Replace default constructor call (T()) with list initialization (T{}) in expressions involving reference types or class templates. Apply to temporary object creation where T is a reference or a template instantiation. Example: Replace `std::vector<int>()` with `std::vector<int>{}` in contexts like `decltype(expr){}` or when initializing a reference type. This creates a mismatch between list initialization expectations and actual expressions, exposing assertion checks in semantic analysis.
