Mutation operator: NestedTemplateConstraintMutator
Applies to concepts that use a requires clause with a simple type check. Replaces a type check in the requires clause with a check for a nested template type.

Original pattern:
template<class T>
concept C = requires {
  typename void_t<T::member>;
};

Mutated pattern:
template<class T>
concept C = requires {
  typename void_t<T::template nested_template<>>;
};

Changes required:
1. In any requires clause within a concept, replace a simple member detection with a nested template type detection.
2. Add the 'template' keyword after 'T::' to indicate a nested template.
3. Add empty template parameter list '<>' if not already present.

Example application to seed code:
template<class T>
concept D = requires {
  typename void_t<T::some_member>;
};

Becomes:
template<class T>
concept D = requires {
  typename void_t<T::template deeply_nested<>>();
};

This mutation forces the compiler to process complex template type dependencies within requires clauses, triggering similar stack trace patterns to the original bug when handling partial specializations constrained by these concepts.
