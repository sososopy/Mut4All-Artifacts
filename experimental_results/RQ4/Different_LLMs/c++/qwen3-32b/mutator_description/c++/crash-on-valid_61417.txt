Mutation Operator 1: Zero-Sized Bit Field After Existing Bit Field in Class with Defaulted Operator. Apply to classes containing at least one named bit field and a defaulted `operator==`. Insert an unnamed zero-sized bit field of the same type as an existing bit field immediately after all named bit fields, then ensure the `operator==` remains defaulted.  

Example:  
Original class:  
class C {  
private:  
    unsigned a: 1;  
public:  
    bool operator==(const C&) const noexcept = default;  
};  

Mutated class:  
class C {  
private:  
    unsigned a: 1;  
    unsigned   : 0;  // inserted zero-sized bit field  
public:  
    bool operator==(const C&) const noexcept = default;  
};  

This targets the interaction between defaulted comparison operators and zero-sized bit fields, exposing crashes in compiler code generation for class layout analysis.
