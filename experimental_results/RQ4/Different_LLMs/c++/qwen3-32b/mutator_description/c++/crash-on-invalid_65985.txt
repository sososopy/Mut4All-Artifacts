Mutation operator: InvalidDoxygenSelfInNonClassContext  
Applies to Doxygen-style comment blocks (///) in function, namespace, or variable declarations (outside class/struct/union definitions). Mutation replaces a normal comment with a variant containing @doc.self in the comment text.  

Example:  
Original code:  
```cpp  
/// Function to add two numbers  
int add(int a, int b);  
```  

Mutated code:  
```cpp  
/// Adds two @doc.self values using bitwise operations  
int add(int a, int b);  
```  

This forces the compiler to process @doc.self in a non-class scope, creating a malformed API comment error. The mutation leverages existing Doxygen comments in the seed program and replaces their content with an invalid @doc.self usage. The change does not require new variables or types and works with any existing comment in a non-class context.
