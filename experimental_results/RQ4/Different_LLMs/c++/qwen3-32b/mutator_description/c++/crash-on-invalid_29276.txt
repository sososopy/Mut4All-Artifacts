Mutation Operator 1: Replace a simple noexcept specifier with a template-dependent expression that evaluates to a non-constant expression.  
Applicability: Function declarations with noexcept specifiers in templates.  
Change: For a function `F` with `noexcept(true)` or `noexcept(false)`, replace the boolean with a nested template-dependent expression using an existing template parameter.  
Example:  
Original:  
```cpp  
template <typename T>  
void f() noexcept(true);  
```  
Mutated:  
```cpp  
template <typename T>  
void f() noexcept(T::value);  
```  
This mutation forces the compiler to evaluate a template-dependent expression in a noexcept context where it is not a constant expression, exposing bugs in how exception specifications are resolved during template instantiation. The template parameter `T` must already exist in the seed program.
