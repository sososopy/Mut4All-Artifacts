Mutation operator: Change structured binding reference type in lambda capture context. Apply to any structured binding declaration with an auto& pattern. Replace the reference specifier with non-reference (auto) or vice versa. For example, modify `auto& [v1,v2] = expr;` to `auto [v1,v2] = expr;` or `auto&& [v1,v2] = expr;`. This forces the compiler to handle different value categories of decomposed variables when captured in lambdas. The original bug involved capturing lvalues from a reference-bound structured binding; this mutation tests how the compiler manages different binding semantics (lvalue/rvalue) during decomposition and subsequent lambda captures.
