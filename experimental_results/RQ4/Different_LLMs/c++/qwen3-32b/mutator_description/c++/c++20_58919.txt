Mutation operator: Replace a variadic constrained template parameter in a function with a requires clause using a variadic fold expression to evaluate the same condition. Apply this to any function template with a variadic constrained parameter pack that is always true. This forces the compiler to process the constraint differently, potentially exposing bugs in concept expansion logic. Example: Change `template <always_true<T>... U> auto func(U&&... values)` to `template <U...> requires (always_true<T, U> && ...) auto func(U&&... values)`. This alters the constraint evaluation path while maintaining the same logical condition.
