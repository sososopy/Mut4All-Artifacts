Mutation Operator: NonTrivialUnionMemberInTemplateClass  
Applies to a class template containing a union with at least one trivial member (e.g., scalar types like int). The mutation replaces one trivial member in the union with a non-trivial class type (e.g., a class with a user-defined constructor/destructor). If the seed program does not already contain a non-trivial class, declare a minimal class with a constructor in the same scope as the union.  

Example Mutation:  
Original code snippet:  
```cpp  
template<typename T>  
struct S {  
    union {  
        int a;  
        float b;  
    };  
};  
```  
Mutated code snippet:  
```cpp  
struct NonTrivial {  
    NonTrivial() {}  
};  

template<typename T>  
struct S {  
    union {  
        int a;  
        NonTrivial b;  // Replaced float with non-trivial class  
    };  
};  
```  

This mutation increases the likelihood of exposing parser or instantiation bugs in compilers that mishandle non-trivial types in unions within templates. The introduced class `NonTrivial` is minimal and self-contained, ensuring compatibility with any seed program.
