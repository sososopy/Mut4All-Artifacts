Mutation operator: Replace a template type parameter `T` with `const T` in a function template's parameter list where `T` is a non-const type in the original code. Apply this to any function template that accepts a template type parameter as a value or reference, potentially causing the compiler to mishandle type qualifiers during template instantiation.

Example:  
Original code:  
template<class T>  
void foo(T x) { /* ... */ }  

Mutated code:  
template<class T>  
void foo(const T x) { /* ... */ }  

This mutation forces the compiler to process `const`-qualified template types in contexts where it might not expect them, such as in template-based inheritance or SFINAE scenarios. By modifying existing valid code to use `const T` in template parameters, the mutation may trigger assertion failures or crashes if the compiler fails to validate or process the qualifier correctly, similar to the `B<const T>` case in the bug report. No new types or variables are introduced; existing template structures are altered to test compiler resilience to type qualifiers in template instantiation paths.
