Mutation Operator: Replace unconstrained variable template with constrained variable template using a concept.  
Applies to: Any variable template declaration `template<typename T> constexpr T X = ...;` where a concept can be applied. Uses existing concepts or introduces a trivial concept (e.g., `template<typename T> concept C = true;`).  

Example:  
Original:  
template<typename T>  
constexpr T x_v = 5;  

Mutated:  
template<typename T>  
concept C = true;  

template<C T>  
constexpr T x_v = 5;  

Changes required:  
1. Add a concept (if none exists) before the variable template.  
2. Replace `template<typename T>` with `template<TestConcept T>` where TestConcept is the concept name.  
3. Ensure the mutated template appears in a context where it is instantiated (e.g., used in a constexpr variable).  

This forces the compiler to evaluate constraints on variable templates, triggering potential parsing/semantic analysis bugs in constraint handling.
