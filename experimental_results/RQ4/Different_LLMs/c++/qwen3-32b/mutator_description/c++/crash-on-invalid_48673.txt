Mutation operator: Remove 'template' keyword in nested template references within dependent types. Applies to code using a template nested inside a dependent class template instantiation. Example: Change `C<T1>::template Type<2>` to `C<T1>::Type<2>`. This forces the compiler to misinterpret a class template as a function template during resolution, triggering invalid casts in the AST. Only modifies existing code elements; no new declarations required.
