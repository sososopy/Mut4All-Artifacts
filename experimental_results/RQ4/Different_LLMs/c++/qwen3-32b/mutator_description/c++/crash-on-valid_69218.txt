Mutation operator: ComplexRealAddressComparison
Apply to expressions where a complex type's real part is accessed via __real__ and compared to an integer or pointer type. Target binary operations in function calls or conditional statements by replacing any simple comparison (e.g., x < y) with a comparison between an integer literal (0) and the address of a __real__ complex variable. This forces the compiler to evaluate complex type operations in contexts expecting scalar or pointer types, exposing assertion failures in type handling.

Example:
Original:
int x = 42;
if (x < 50) { ... }

Mutated:
int x = 42;
_Complex float c;
if (0 < &__real__ c) { ... }

Note: If no complex variable exists in the program, add a global or local _Complex declaration using an existing scalar type (float/double). The mutation preserves all function signatures and variable names while altering the comparison logic to stress the compiler's complex type handling in unexpected contexts.
