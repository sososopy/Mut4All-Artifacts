Mutation operator: Replace a valid parameter pack expansion in an unevaluated context with a direct parameter pack reference. Apply to function templates with variadic parameters used in expressions like sizeof, noexcept, or decltype. Example: Original code has `sizeof(Ts...)` in a template; mutated code becomes `sizeof(Ts)` (removing pack expansion ellipsis). This forces the compiler to process unevaluated parameter packs without proper expansion handling, exposing assertion failures in type resolution logic.
