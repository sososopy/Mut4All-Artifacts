Mutation Operator 1: Replace a non-pack argument in a function call with an unexpanded parameter pack in a context expecting a single value.  
Applies to any function call where a parameter pack is substituted for a non-pack parameter.  
Example:  
Original code:  
func(a);  
Mutated code:  
func(Pack);  
Where 'Pack' is a parameter pack declared in an enclosing template, and 'func' expects a single non-pack argument. This forces the compiler to process an unexpanded parameter pack in a context where expansion is required, triggering assertion failures during template instantiation.  

Mutation Operator 2: Insert a parameter pack into a lambda capture list without pack expansion, violating the requirement for explicit ellipsis in variadic lambdas.  
Applies to lambda expressions with capture lists.  
Example:  
Original code:  
[=] { return x; }  
Mutated code:  
[Pack] { return x; }  
Where 'Pack' is a parameter pack declared in the enclosing scope. This creates a lambda that captures a parameter pack as a single entity, causing the compiler to misinterpret the pack during instantiation and leading to uncaught unexpanded pack errors.  

Mutation Operator 3: Replace a scalar type with a pack-qualified type in a template argument list where pack expansion is not syntactically valid.  
Applies to template instantiations with pack-qualified types.  
Example:  
Original code:  
MyClass<int>;  
Mutated code:  
MyClass<int...>;  
Where 'MyClass' expects a single type parameter, but the pack expansion 'int...' is invalid in this context. This forces the compiler to handle a pack expansion where it is not permitted, potentially exposing assertion failures in template argument processing.  

Mutation Operator 4: Substitute a non-pack variable in a conditional expression with an unexpanded parameter pack in a template condition.  
Applies to conditions in if-statements or other conditional contexts within templates.  
Example:  
Original code:  
if (x) { ... }  
Mutated code:  
if (Pack) { ... }  
Where 'Pack' is a parameter pack declared in the template's parameter list. The compiler must evaluate the pack in a scalar condition context, leading to unexpanded pack detection failure during template instantiation.  

Mutation Operator 5: Modify a fold expression to reference a parameter pack without proper placement of the fold operator.  
Applies to fold expressions in variadic templates.  
Example:  
Original code:  
(... + args);  
Mutated code:  
args + ...;  
Where the pack 'args' is used in a context where the fold operator is missing or misplaced, creating an invalid pack expansion. This forces the compiler to process a malformed fold expression, potentially triggering assertion failures during semantic analysis.
