Mutation Operator: Replace enum name in 'using enum' with 'class' or 'struct' to trigger invalid syntax  
Applies to: 'using enum' declarations that qualify an enum class/struct  
Action: In an existing 'using enum' directive, remove the actual enum name and substitute it with the keyword 'class' or 'struct' (e.g., change `using enum MyEnum;` to `using enum class;`)  
Example:  
Original:  
enum class MyEnum { A };  
void foo() {  
    using enum MyEnum;  
}  

Mutated:  
enum class MyEnum { A };  
void foo() {  
    using enum class;  // Replaces MyEnum with 'class' keyword  
}  

This creates invalid syntax expecting an identifier after 'enum' while preserving existing enum declarations. The mutation exploits the restricted grammar for 'using enum' directives where 'class' is a reserved keyword in enum declarations.
