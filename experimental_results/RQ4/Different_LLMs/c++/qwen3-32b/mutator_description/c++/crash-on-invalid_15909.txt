Mutation Operator 1: Atomic Type Mismatch in Comparison  
Applies to binary expressions where both operands are of atomic types or comparable base types.  
Modify one operand of the comparison to use a conflicting atomic/non-atomic type.  
Example: Change  
if (a == b) { ... }  
to  
if ((atomic<unsigned> a_val = a) == b) { ... }  
when a is atomic<unsigned> and b is int, triggering type mismatch during semantic analysis.  

Mutation Operator 2: Mixed Atomic Integral Promotion  
Applies to expressions involving atomic integral types and standard integrals.  
Replace one operand with a cast to a different atomic integral type than the other operand.  
Example: Change  
if (atomic<int>(42) < 42) { ... }  
to  
if (atomic<unsigned>(42) < 42) { ... }  
causing a signed/unsigned atomic comparison during overload resolution.  

Mutation Operator 3: Atomic-Nonatomic Assignment Context  
Applies to assignment expressions where both sides are atomic-qualified types.  
Modify one side to remove the atomic qualifier while keeping the other atomic.  
Example: Change  
atomic<int> x = atomic<int>(0);  
to  
int x = atomic<int>(0);  
creating a transfer between atomic and non-atomic types during value assignment.
