Mutation operator: Replace a type in the template argument list of a `std::variant` alias template with a pack expansion of an existing template parameter, creating an invalid pack expansion where it's not allowed.  
Applies to: `template <typename T> using Alias = std::variant<...>;` where `Alias` is a type alias template for a variant with multiple types.  
Example:  
Original:  
```cpp  
template <typename T>  
using MyVariant = std::variant<TypeA, TypeB, TypeC>;  
```  
Mutated:  
```cpp  
template <typename T>  
using MyVariant = std::variant<TypeA, T..., TypeC>;  
```  
This introduces a pack expansion (`T...`) in a context where it is invalid, forcing the compiler to handle the template substitution with malformed pack expansions. The mutation reuses existing template parameter `T` and types from the variant without introducing new declarations.
