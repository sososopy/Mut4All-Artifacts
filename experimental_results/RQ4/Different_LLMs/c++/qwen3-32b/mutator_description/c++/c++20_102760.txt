Mutation operator: AddTemplateParameterToLambdaRequiresClause
Target construct: Function templates inside lambda expressions with requires clauses that rely on parameter pack indexing.
Applies to: Lambdas with templated call operators using requires clauses that involve parameter packs.
Mutated content: Insert an unused template parameter before the first parameter in the lambda's requires clause.
Example:
Before: []<class T>(auto) requires requires { T{}; }
After: []<class U, class T>(auto) requires requires { T{}; }

Mutation operator: SwapTemplateParametersInNestedLambda
Target construct: Nested template lambdas with interdependent parameter packs.
Applies to: Outer lambdas whose return types contain inner lambdas with template parameters.
Mutated content: Exchange the positions of two template parameters in the inner lambda while preserving their usage in requires clauses and parameter lists.
Example:
Before: []<class A, class B>(...) { return []<class X>(X) -> void {}; }
After: []<class A, class B>(...) { return []<class B, class A>(X) -> void {}; }

Mutation operator: IntroduceDummyTemplateArgumentInLambda
Target construct: Lambda return types with template argument deduction.
Applies to: Lambdas with templated call operators and decltype-based return type definitions.
Mutated content: Add a dummy template argument (e.g., an integer) to the outer lambda's argument list while keeping all existing template parameter usage unchanged.
Example:
Before: []<class T>(T) { return []<class U>(U) -> void {}; }
After: []<class T>(T, int) { return []<class U>(U) -> void {}; }

Mutation operator: ReverseParameterPackUsageInRequires
Target construct: Requires clauses using parameter packs in template lambdas.
Applies to: Lambda call operators with requires constraints based on parameter packs.
Mutated content: Reverse the iteration order of parameter packs within the requires clause without modifying the actual parameter list order.
Example:
Before: []<class T>(auto) requires requires { sizeof...(T); }
After: []<class T>(auto) requires requires { sizeof...(reverse<T>); }
