Mutation operator: Forward declare a struct and append an invalid destructor declaration in the same scope.  
Applies to: Any struct definition where the struct body is replaced with a forward declaration, and the destructor is defined in the same scope (function/block or global) without a corresponding struct body.  
Example:  
Original struct definition:  
struct A { ~A() {} };  

Mutated code:  
struct A;  
A::~A;  // Invalid destructor declaration without body.  

Or in a function:  
void fn() {  
  struct B;  
  B::~B;  
}  

Changes:  
1. Replace the struct's body (e.g., `struct A { ... };`) with a forward declaration (`struct A;`).  
2. In the same scope (function/block or global), add a destructor declaration (`A::~A;` or `A::~A()` without a body).  
3. Avoid introducing new types; use existing struct names from the seed program.  
Note: The mutation creates an incomplete type with an invalid destructor, exploiting compiler handling of incomplete declaration contexts.
