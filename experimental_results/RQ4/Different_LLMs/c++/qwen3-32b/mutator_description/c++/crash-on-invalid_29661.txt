Mutation operator: Unbalanced template parameter list in function templates  
Target construct: Function templates with explicit template parameter lists  
Applies to: Any function template declaration containing at least one template parameter  
Description: Replace the closing '>' of the template parameter list with '<', creating a nested angle bracket structure that forces the parser to process an unterminated template parameter list. This exploits template parsing edge cases in semantic analyzers that expect a balanced bracket structure.  
Example:  
Original:  
template<typename T> void foo(T x) { ... }  
Mutated:  
template<typename <T< void foo(T x) { ... }  
Coverage: Targets template parsing and semantic analysis phases, particularly pathways handling nested template declarations and type resolution. Applies to both class and function templates.  
Note: The mutation preserves existing function signature and parameter names, only modifying the template parameter list structure.
