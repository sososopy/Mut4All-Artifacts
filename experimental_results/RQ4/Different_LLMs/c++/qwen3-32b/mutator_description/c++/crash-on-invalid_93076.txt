Mutation Operator 1: Template Argument and Parameter Count Mismatch Mutation  
Applies to function calls to template functions where the number of explicit template arguments and the number of function arguments are equal.  
Insert one or more additional function arguments that reference an existing function/variable in the seed program, creating a parameter count mismatch. The template argument count remains unchanged to force overload candidate diagnosis during argument conversion.  

Example:  
Original:  
template<class A, class B> int foo(A a, B b);  
int bar() { return foo<int, int>(1, bar); }  

Mutated:  
template<class A, class B> int foo(A a, B b);  
int bar() { return foo<int, int>(1, bar, bar); }  

This forces the compiler to handle 3 arguments for a function expecting 2, triggering invalid overload resolution paths during type checking. The existing function 'bar()' is reused to avoid introducing new identifiers, and the template argument list remains unchanged to maintain invalid overload candidate evaluation.
