Mutation operator: requires clause in variadic base class template with index sequence  
Applies to: base class templates with variadic parameters and index sequence indices  
Action: Insert a requires clause in a variadic base class template that references the index sequence parameter during constraint evaluation. For a base class template like `template <typename... Ts> struct Base`, modify it to `template <unsigned I, typename... Ts> struct Base requires (requires { I < sizeof...(Ts); })`. This forces constraint evaluation involving index sequence indices during template instantiation, which can expose OOB accesses in array-like containers when combined with variadic template inheritance. The mutation leverages existing index sequences and variadic types already present in the seed program.
