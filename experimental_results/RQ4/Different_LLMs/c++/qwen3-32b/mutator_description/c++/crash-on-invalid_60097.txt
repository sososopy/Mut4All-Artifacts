Mutation operator: Replace a valid concept applied to a parameter pack in a lambda's template parameter list with a concept that references the pack in an invalid non-type template parameter context, triggering a pack expansion ICE.  
Applicable to lambdas with template parameter packs and dependent concepts.  
Example:  
Original:  
[&]<class T, std::size_t... Is> requires (ValidConcept<Is>()) (args) { ... }  

Mutated:  
[&]<class T, std::size_t... Is> requires (InvalidConcept<T::value..., Is>()) (args) { ... }  

Note: Mutated code introduces a pack expansion in a context expecting a type but uses pack element values instead. Requires existing concepts, types, and pack parameters in the seed program.
