Mutation operator: Replace direct string literal initialization of a std::string_view in a function body with a call to an existing function that returns a string type. Apply to all std::string_view declarations where the initializer is a string literal and the seed program contains a function with a string-comparable return type. The mutation checks for existing functions matching the string type before applying. 

Example: 
Original code:
std::string_view sv = "literal";

Mutated code:
std::string_view sv = get_string();

Requires the seed program to have a declared function `std::string get_string()` visible in the scope. This stresses compiler parsing of function call expressions in std::string_view contexts, potentially exposing AST construction or code generation errors in C++17 mode.
