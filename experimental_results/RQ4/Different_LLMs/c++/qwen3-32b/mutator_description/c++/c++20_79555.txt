Mutation operator: LambdaPackInDecltype
Target: Function or template declarations where a decltype is applied to an expression. 
Applies to: Any function body or template definition where a type deduction context exists.

Insert after every function call or template parameter list:
decltype([](auto... pack) { return 0; }()) 
This creates an immediately invoked lambda with a parameter pack inside a decltype context. 
The lambda takes a variadic parameter pack and returns 0, then is immediately invoked with no arguments. 
The decltype attempts to deduce the return type of the lambda invocation.

Example of mutation in function body:
Original code:
void foo() {
    bar();
}

Mutated code:
void foo() {
    bar();
    decltype([](auto... pack) { return 0; }()) x;
}

This constructs a lambda with a parameter pack in a decltype expression, which exercises the same template argument deduction path that caused the Clang crash in the bug report.
