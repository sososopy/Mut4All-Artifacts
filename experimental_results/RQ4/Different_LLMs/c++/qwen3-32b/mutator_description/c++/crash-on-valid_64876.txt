Mutation operator: Replace an integer literal with a value exceeding the 64-bit signed integer range. Apply to all integer literals in expressions. Example: Change 1LL to 0x8000000000000000LL (2^63) or -0x8000000000000000LL-1 (-(2^63+1)). This forces APSInt handling to check representability, exposing assertion failures if the compiler's APSInt logic mishandles out-of-range values. Use existing integer literals in the program; replace their values with explicitly large values that cannot fit in int64_t. No new variables or types are introduced.
