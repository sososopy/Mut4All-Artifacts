Mutation Operator: Requires Lambda Return Type Syntax Corruption  
Target: Requires expressions containing a lambda with an explicitly specified return type. Applies to lambdas within requires clauses of constraints, template parameters, or lambda return types.  

Action: Replace the lambda's return type with a malformed expression by inserting an additional '->' operator between the lambda's parameter list and return type, creating invalid syntax. For example, transform:  

requires (requires () { [&] -> decltype(x) {}; })  

into:  

requires (requires () { [&] -> -> decltype(x) {}; })  

This mutation introduces a second consecutive '->' in the lambda's return type specification, which is syntactically invalid but structurally similar to valid code. The compiler's parser may enter an error state when processing this malformed lambda within a requires expression, potentially exposing parsing bugs.  

The mutation uses existing variables (x) already in scope and modifies only the lambda's return type syntax. It avoids introducing new variables or types, relying on the seed program's existing declarations. This operator achieves high coverage by targeting nested lambdas in requires expressions, a C++20 construct with complex parsing rules.
