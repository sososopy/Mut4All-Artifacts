Mutation operator: Insert a `using enum` directive for an enum nested within a class/struct, followed by a compound expression using the enum constants in a bitwise operation. Apply where an existing class/struct contains an enum, and no `using enum` exists for its nested enum.  
Example:  
Original code:  
class Foo { enum E { X, Y }; };  
...  
Foo f;  
int x = 0;  

Mutated code:  
class Foo { enum E { X, Y }; };  
using enum Foo::E;  
...  
Foo f;  
int x = (X | Y);  

This targets interactions between `using enum` and compound expressions, leveraging existing enums/structs to avoid introducing new types. The bitwise operator and parentheses structure the expression to stress name resolution in nested scopes.
