Mutation operator: LambdaWithConceptConstraintVariableTemplate
Target code construct: Function template or variable declaration in a program that can be transformed into a variable template containing a constrained lambda. Specifically, applies to any function/variable declaration that is used as a template argument or with explicit template parameters in the seed program.
Mutation strategy: Replace a selected function or variable declaration with a variable template declaration that holds a lambda expression constrained by a concept. The mutation will:
1. Replace function return type with 'auto'
2. Convert the declaration into a variable template with template parameter(s)
3. Add a requires clause with a concept from the seed program (or introduce a minimal concept if none exist) 
4. Add a call to the variable template with explicit template arguments where the original declaration was used
Example for an existing function void f() { ... } used as g(f()):
Replace with:
template<typename T>
concept MyConcept = true;
auto f = []() requires MyConcept<T> { ... };
// At usage site
g(f<int>());
If no concept exists in the seed program, insert a minimal concept template<typename T> concept C = true; before the mutation.
Coverage justification: Addresses a compiler crash trigger in concept resolution for constrained lambda variable templates, a complex combination of multiple modern C++ features (concepts, variable templates, lambdas) that compilers may not test exhaustively in all permutations. The mutation leverages existing code structure (template usage patterns) rather than introducing new program structures.
