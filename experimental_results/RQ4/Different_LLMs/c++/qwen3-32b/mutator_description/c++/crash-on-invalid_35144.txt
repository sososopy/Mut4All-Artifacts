Mutation Operator: Replace a lambda in a recursive template with one that triggers infinite template instantiation by reusing the template parameter and passing itself to the same template, exploiting the compiler's type handling during recursive template resolution.

Applies to: Any template function or class that recursively calls itself with a lambda argument as part of its instantiation.

Example mutation:
Original code in seed program:
template<typename T>
void process(T val) {
   auto func = []{};
   process(func);
}

Mutated code:
template<typename T>
void process(T val) {
   auto func = [val]() { 
      process(func); // Recursively passes lambda to same template
   };
   process(func);
}

The mutation introduces a lambda that captures the template parameter and is passed to the same template function during its own execution, creating a recursive template instantiation loop. The lambda's capture of the template parameter forces the compiler to process the recursive template with a closure type that depends on the template's own instantiation state. This exploits potential flaws in the compiler's handling of recursive template type resolution when involving lambda capture chains and type-dependent closure types.
