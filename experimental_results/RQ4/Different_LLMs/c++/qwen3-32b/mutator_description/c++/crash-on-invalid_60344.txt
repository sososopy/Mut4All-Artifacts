Mutation operator: Unbounded Template Recursion in Conditional Context  
Applies to: Template specializations or condition expressions (e.g., if constexpr, requires clauses)  
Action: Replace a valid condition with a recursive template instantiation that causes infinite expansion. Use existing template parameters and types from the seed program.  

Example transformation:  
Original:
