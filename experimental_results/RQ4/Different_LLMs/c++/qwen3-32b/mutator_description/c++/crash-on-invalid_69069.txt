Mutation Operator: Add const qualifier to a variable involved in an OpenMP atomic capture block. Apply to any variable in an OpenMP atomic capture context that is declared without const. This creates an invalid assignment to a const-qualified variable during atomic operations, exposing assertion errors in OpenMP AST processing. Pseudo-code example:  
Original:  
#pragma omp atomic capture  
{ v = x; x = 1; }  

Mutated:  
#pragma omp atomic capture  
{ v = x; x = 1; }  
with x declared as const int instead of int.  

Applies to OpenMP atomic directives using capture clauses. Modifies existing variable declarations to add const qualifiers in contexts requiring variable modification. Uses already-declared variables in the seed program.
