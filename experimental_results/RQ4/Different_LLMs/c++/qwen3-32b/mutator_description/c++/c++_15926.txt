Mutation Operator: NestedPointerToMemberSpecifier  
Applies to any nested-name-specifier within a type expression where the inner name is a class or struct. Replaces the inner qualifier with a pointer-to-member operator.  
Example:  
Original: typename A::B::value_type  
Mutated: typename A::B::* value_type  
Effectively creates a pointer-to-member type from a nested name, forcing the compiler to handle context transitions between namespaces/classes and member pointers. This stresses the 'EnteringContext' mechanism during template instantiation or type resolution.  

Mutation Operator: TemplateNestedMemberPointer  
Applies to any template-qualified nested-name-specifier that forms a type. Adds a pointer-to-member asterisk after the closing angle bracket of the template parameters.  
Example:  
Original: typename std::vector<A>::iterator_traits::difference_type  
Mutated: typename std::vector<A>::* iterator_traits::difference_type  
Requires the original code to have a valid nested type structure that can form a member pointer context. This exposes compiler bugs in handling template-dependent nested names with member pointer syntax.
