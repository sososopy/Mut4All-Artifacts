Mutation Operator: Replace template parameter usage in partial specializations with a fixed type.  
Target: Partial template specializations where the body uses the template parameters.  
Application: Modify all occurrences of a template parameter within the specialization's body to a fixed type (e.g., int, void, or another type from the primary template).  
Example:  
Original:  
template<typename T>  
struct MyContainer<T*> {  
    T value;  
};  

Mutated:  
template<typename T>  
struct MyContainer<T*> {  
    int value;  
};  

Notes:  
- This mutation applies to any partial specialization that uses its template parameters in member declarations or definitions.  
- The replacement type must already exist in the program's context (e.g., a built-in type or a type defined in the primary template's scope).  
- Avoid introducing new parameters or undefined types; use existing types from the program.  
- This mutation exploits the compiler's handling of unused template parameters in partial specializations, which may trigger internal logic errors or crashes in template instantiation pathways.
