Mutation Operator: Replace template type parameters with non-type parameters in template alias definitions
Applies to: Template alias declarations using type parameters
Change: Modify a template alias accepting type parameters to use non-type parameters (e.g., lambdas or integers) instead

Example before:
template<class T> using MyAlias = typename T::value_type;

Example after:
template<auto V> using MyAlias = decltype(V);

This mutation forces template instantiation to attempt substituting non-type template arguments where type arguments are expected, creating type-template-argument mismatches. The compiler must handle the assertion in TransformTemplateTypeParmType when the template argument kind doesn't match the parameter kind. Uses existing alias template syntax and replaces type parameters with auto parameters that can accept lambdas or other non-type template arguments.
