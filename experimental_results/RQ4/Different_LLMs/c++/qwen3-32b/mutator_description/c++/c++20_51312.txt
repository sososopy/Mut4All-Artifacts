Mutation operator: Introduce nested conditional control flow with default arguments in template parameters  
Applies to: Function templates with parameters that have default arguments, especially when nested in compound statements  

Transform:  
For a function template parameter with an existing default argument, replace the default value with a conditional expression (e.g., if statement or ternary operator) that:  
1. Uses existing variables from the seed program's scope  
2. Contains a nested control structure (like another if or try statement)  
3. Returns the original default value when conditions are met  
4. Is placed directly in the function parameter list  

Example transformation:  
Original:  
template<class T> void func(T x = 0);  

Mutated:  
template<class T> void func(T x = (if (true) { return existingVar; } else { return 0; }));  

If no existing variables exist, declare a new variable of the parameter type in the surrounding scope and use it in the conditional structure. The nested control flow forces template instantiation to evaluate the default argument in a complex context, increasing likelihood of triggering the isDefaultArgument() crash in template transformation logic.
