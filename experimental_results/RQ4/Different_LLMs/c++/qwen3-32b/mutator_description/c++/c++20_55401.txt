mutation operator RemoveCommaInRequiresClause
Applies to requires clauses containing multiple comma-separated requirements (e.g., in concept definitions, requires expressions, or requires blocks)
Modifies: removes a single comma between adjacent requirements in a requires clause
Example before mutation:
requires { expr1; expr2; expr3; }
Example after mutation:
requires { expr1 expr2; expr3; }
Target mechanism: Triggers compiler's error handling for malformed requires clauses by creating adjacent requirements without separation
Precondition: The requires clause must already contain at least two requirements
Restriction: Only applies to requires clauses with explicit requirement lists (not constraint expressions)
Implementation note: Select a randomly positioned comma between requirements and remove it, preserving all other syntax elements
Effect: Creates invalid syntax that may expose error recovery bugs like the one in the original report
