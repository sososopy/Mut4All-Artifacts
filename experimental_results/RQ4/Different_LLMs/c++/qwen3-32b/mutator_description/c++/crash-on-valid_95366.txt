Mutation operator: Label arithmetic with function pointer comparison  
Applies to functions containing at least two labeled statements.  
Modify a function's compound statement by:  
1. Selecting two existing labels (L1 and L2) within the same function  
2. Adding an expression comparing the difference of their addresses to an existing function pointer  
3. The expression must use GNU label operands (&&L1 - &&L2 < FUNCTION_NAME)  

Example transformation:  
Original function with labels:  
void example() {  
L1: int a = 1;  
L2: int b = 2;  
}  

Transformed function:  
void example() {  
L1: int a = 1;  
L2: int b = 2;  
if (&&L1 - &&L2 < example) {}  // Using function's own address  
}  

This creates a comparison between GNU label addresses (treated as pointers) and a function pointer, forcing the compiler to evaluate label arithmetic in a context that violates standard C rules. The crash occurs when the constant evaluator mishandles the resulting non-LValue expressions during overflow/constant checking.
