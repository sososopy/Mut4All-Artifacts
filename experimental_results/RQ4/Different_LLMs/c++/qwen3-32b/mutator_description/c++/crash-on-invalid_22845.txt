mutation operator: Introduce a nested class/struct with a constexpr member function that references a non-static variable from the enclosing function scope. Apply to any function containing an rvalue reference or similar temporary-bound variable.  
Example:  
Original code:  
void f() {  
    int&& x = 42;  
    // ...  
}  

Mutated code:  
void f() {  
    int&& x = 42;  
    struct Temp {  
        constexpr int get() { return x; }  
    };  
    // ...  
}  

This exploits compilers' handling of constexpr contexts accessing non-static outer scope variables. The mutation ensures the constexpr function directly references the rvalue reference from the parent scope, triggering potential invalid semantics that may cause crashes instead of proper error reporting.
