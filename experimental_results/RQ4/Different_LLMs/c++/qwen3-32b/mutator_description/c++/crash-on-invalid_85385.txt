Mutation Operator: Replace a valid function call with an invalid template application where a template requiring a template template parameter is used as a function without angle brackets.

Applies to: Function calls in contexts where a template instantiation with a nested template template parameter is possible.

Example:
Original code:
void func() {
   process(data);
}

Mutated code:
template <template <typename> class T> class Wrapper;
template <typename C, template<typename> class TTP>
using Alias = Wrapper<TTP>;

void func() {
   Alias(42); // Invalid use of template alias as function
}

Explanation: Replaces a function call 'process(data)' with an invalid instantiation of 'Alias' as a function, using existing template parameters. The template 'Alias' requires a template template parameter but is used without angle brackets, triggering internal compiler errors. Only uses templates 'Wrapper' and 'Alias' assumed to exist in the seed program.
