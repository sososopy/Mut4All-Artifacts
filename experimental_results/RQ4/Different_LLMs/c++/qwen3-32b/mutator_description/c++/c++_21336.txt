Mutation operator: Invalid nested function call in default argument for function templates  
Applies to: Function templates with default arguments that are simple expressions  
Transforms a valid default argument (e.g., literal or simple variable) into an invalid nested function call pattern that the compiler is expected to reject but may crash on.  

Example transformation:  
Original:  
template<typename T> struct S { void f(int k = 42); };  

Mutated:  
template<typename T> struct S { void f(int k = h(k)()); };  
Where `h` is any existing function in the seed program that does not return a function type.  

If `h` does not exist in the seed program, insert:  
void h(int); // Declaration only, no definition  

The mutation creates a syntactically invalid default argument by attempting to call the result of `h(k)` as a function, which is invalid unless `h` returns a function pointer or callable object. This forces the compiler to handle the invalid syntax, potentially exposing crashes during template instantiation or default argument processing. The existing `h` ensures no undeclared names, and the invalid syntax mimics the crashing pattern from the bug report.
