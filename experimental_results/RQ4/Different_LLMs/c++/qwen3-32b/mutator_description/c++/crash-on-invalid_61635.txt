Mutation operator: Increment an attribute parameter index beyond the valid range in a varargs function.  
Applies to: Functions with varargs (e.g., `...`) and attributes specifying a parameter index (like `__format_arg__`).  
Method: For any attribute argument that references a fixed parameter index (e.g., `__attribute__((attr(N)))` where N is valid), change N to a value exceeding the number of fixed parameters (excluding `...`).  
Example:  
Original:  
`__attribute__((attr(1))) void f(int a, ...) {}`  
Mutated:  
`__attribute__((attr(2))) void f(int a, ...) {}`  

The mutation forces an invalid index by targeting the first fixed parameter (1) and increasing it to 2, which exceeds the fixed parameter count (1) in the varargs function. This triggers the assertion in `getParamType`.  
High coverage is achieved by applying this to any function using index-based attributes combined with varargs, leveraging existing attributes and parameters. New elements are not introduced; only existing attribute indices are modified.
