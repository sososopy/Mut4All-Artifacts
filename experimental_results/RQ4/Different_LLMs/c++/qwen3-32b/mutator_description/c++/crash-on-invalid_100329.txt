Mutation Operator: Replace 'this' parameter type in defaulted operator== with an existing non-pointer, non-reference type from the seed program. Apply to any class with a defaulted operator== declaration containing a 'this' parameter. The mutation preserves the operator== syntax and parameter count but invalidates the 'this' parameter type by substituting it with an existing type in the program (e.g., a fundamental type or another class type). The existing explicit object parameter (second parameter) must match the original class type.

Example transformation:
Original:
struct X {
    bool operator==(this const X*, const X&) = default;
};

Mutated:
struct X {
    bool operator==(this int, const X&) = default;
};

The mutation leverages the compiler's requirement to validate 'this' parameter types during defaulted comparison synthesis (per C++23 [over.equality.default]/3). By using an existing type (int in this case) that lacks pointer/reference qualifiers, the operator becomes invalid, forcing error recovery logic that may trigger ICE if not properly handled.
