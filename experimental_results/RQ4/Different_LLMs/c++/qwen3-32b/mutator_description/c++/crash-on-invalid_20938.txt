Mutation operator: Add a static member function to a struct that is declared but not defined, followed by an immediate call to this undefined function within the struct's scope. This applies to any struct that contains at least one member function. The mutation replaces an existing non-static member function's definition with a static declaration and removes its body, then invokes the now-undefined static function. Example: Transform `struct S { void f() { ... } };` into `struct S { static void f(); S() { f(); } };` with f's body removed. This forces the compiler to process an undefined static function during semantic analysis, exposing bugs related to improper AST node handling.
