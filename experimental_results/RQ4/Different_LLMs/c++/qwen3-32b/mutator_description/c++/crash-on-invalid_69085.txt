mutation operator: Insert invalid array size and OpenMP depend clause  
Target construct: Array declarations in global or function scope, and function bodies with OpenMP directives  
Action: For an existing array declaration (e.g., `T name[N];`), replace N with a negative integer or non-integer expression (e.g., `T name[0.5];`). In a function where `name` is in scope, insert an `#pragma omp task depend(...)` clause referencing the array with a slice (e.g., `depend(inout: name[1.5:3])`).  

Example mutation:  
Original:  
```cpp  
int arr[10];  
void foo() { }  
```  
Mutated:  
```cpp  
int arr[-42];  
void foo() {  
  #pragma omp task depend(inout: arr[0.75:2])  
}  
```  
Applies by modifying existing variables/types. No new declarations required. Triggers type validation errors in OpenMP clause handling.
