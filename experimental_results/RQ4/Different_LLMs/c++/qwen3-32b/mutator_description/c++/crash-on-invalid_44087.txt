Mutation operator: Replace a non-pointer/array variable with a function pointer type and use it in a pointer/array context to trigger type-checking failure.  
Applies to: Variable declarations of scalar or class types that are later used in pointer/array operations (e.g., dereference, subscript).  
Example: Change `T var` → `void (*var)()` and replace all uses of `var` in a pointer/array context (e.g., `*var` or `var[i]`).  
Existing program elements: Use the original variable's type and name. No new declarations required unless the function pointer type is not already present in the code; in such cases, declare a dummy function `void dummy_func()` to satisfy the function pointer.  
Coverage: Targets mismatches between expected pointer/array types and invalid usage patterns in expressions involving pointer/array operations.
