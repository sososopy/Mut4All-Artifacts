Mutation operator: Replace a valid attribute with a malformed, unrecognized attribute in function, variable, or type declarations. Apply to existing attributes in the seed program by substituting their names with arbitrary strings not corresponding to any standard or user-defined attributes.  
Example:  
Original: [[nodiscard]] int func();  
Mutated: [[invalid_attr]] int func();  

Mutation operator: Insert an attribute with a malformed syntax (e.g., missing square brackets or incorrect nesting) into a declaration. Target functions, variables, or types already annotated with attributes.  
Example:  
Original: [[no_unique_address]] struct S;  
Mutated: [ [no_unique_address]] struct S;  

Mutation operator: Apply an attribute to a declaration where it is semantically invalid (e.g., a function attribute applied to a type). Use existing attributes from the seed program but shift their target declarations.  
Example:  
Original: [[nodiscard]] int x;  
Mutated: [[nodiscard]] class C { };  

Mutation operator: Replace an attribute's argument list with invalid syntax while preserving the attribute name. Target attributes with parameters in the seed program by corrupting their argument structure.  
Example:  
Original: [[gnu::format(printf, 1, 2)]] void log(const char* fmt);  
Mutated: [[gnu::format(printf,, 2)]] void log(const char* fmt);  

Mutation operator: Duplicate an attribute in a declaration where multiple identical attributes are not allowed. Apply to single-occurrence attributes in the seed program by repeating them.  
Example:  
Original: [[deprecated]] void deprecated_func();  
Mutated: [[deprecated]] [[deprecated]] void deprecated_func();
