Mutation operator: Add nested template class with lambda in operator()  
Target code construct: Class methods that accept type parameters and perform template instantiation.  
Applies to: Any class method that could be extended with nested template processing logic.  

Mutation steps:  
1. Within an existing class method (preferably with template parameters or type variables):  
   - Add a nested class definition with a templated operator()  
2. The nested class should:  
   - Contain a lambda that captures by value from the outer scope  
   - Call a method on its template parameter  
   - Use the lambda in a return statement  
3. Apply to existing parameters: Use any existing parameter type as the template argument  
4. Keep existing variable names: Reuse parameters from the original method  

Example mutation:  
// Original code  
void Process(T value) {  
  value.Use();  
}  

// Mutated code  
void Process(T value) {  
  struct TemplateWrapper {  
    template<typename U> auto operator()(U param) {  
      auto lambda = [value](auto x) { return x.param.Method(); };  
      return lambda(param);  
    }  
  };  
  TemplateWrapper{}(value);  
  value.Use();  
}  

Notes:  
- Uses existing 'value' parameter from outer scope  
- Creates nested template processing layer  
- Forces multiple levels of template instantiation  
- Creates complex type dependency chain  
- Preserves original method functionality while adding stress points  
- Compatible with any existing class with template parameters
