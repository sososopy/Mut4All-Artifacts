Mutation Operator: Replace a friend operator function with a vararg (ellipsis) version in a class/struct context.  
Applies to: Friend operator functions with fixed parameters in class/struct definitions.  
Modify an existing friend operator declaration by replacing its parameter list with an ellipsis. This creates an invalid operator overload with varargs, testing compiler error handling.  

Example:  
Original code:  
class C {  
  friend void operator+(C, int);  
};  

Mutated code:  
class C {  
  friend void operator+(C, ...);  
};  

The mutation reuses the existing operator symbol and class type, introducing a vararg parameter to force the compiler to process an ill-formed overload. This exploits the same pattern as the reported bug, where the presence of an ellipsis in a friend operator triggers a crash instead of a diagnostic.
