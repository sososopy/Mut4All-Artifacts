Mutation operator: InlineNamespaceTemplateSpecialization  
Target code construct: Function templates outside inline namespaces and their explicit specializations.  
Applies to: Any function template declaration or explicit specialization not contained within an inline namespace.  
Mutation action:  
1. Move the outermost function template declaration into an inline namespace block.  
2. For any explicit specialization in the same translation unit, retain its original form but ensure it remains outside the inline namespace.  
Example:  
Original:  
template<typename T> void func(T);  
template<> void func<>(int);  

Mutated:  
inline namespace { template<typename T> void func(T); }  
template<> void func<>(int);  

Coverage rationale: This targets the interaction between inline namespaces and explicit template specializations, which was the root cause in the reported crash. The mutation preserves existing declarations but restructures their scope hierarchy, creating potential for invalid linkage resolution scenarios. No new types/variables are introduced; only relocation of existing declarations.
