mutation operator: Remove 'typename' in dependent template alias access  
Applies to: Dependent template alias references in template parameters or expressions  
Modifies: Replace 'typename T::D<>' with 'T::D<>' where T is a dependent type and D is an alias template  
Example:  
Original code:  
template <typename T> void f(typename T::X<>) {}  
Mutated code:  
template <typename T> void f(T::X<>) {}  
Requirements: The seed program must already define T's member X as an alias template (e.g., struct T { template <int> using X = void; };)  
Effect: Forces compiler to resolve dependent alias template without 'typename' keyword, exposing crashes in template instantiation logic
