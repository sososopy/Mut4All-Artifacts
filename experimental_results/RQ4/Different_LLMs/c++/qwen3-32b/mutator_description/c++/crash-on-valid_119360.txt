Mutation operator: Replace a valid va_arg type with a variable-length array using an existing scoped variable as the size, then cast the result to a pointer type. Applies to functions with va_list usage and an integer variable in scope to define the array size. Example: For existing `T* p = va_arg(args, T*)`, mutate to `(T*)va_arg(args, T[size_var])` where `size_var` is an integer variable already declared in the same scope. This targets compiler handling of VLAs in variable arguments during codegen.
