Mutation Operator: Unused Template Function Parameter Call  
Target: Template functions with a universal reference (T&&) parameter that is not used in the body.  
Action: Insert a call to the function in another function or global scope, passing a temporary or prvalue as the argument. This forces the compiler to process the function body with an unused parameter under warnings-as-errors, potentially triggering internal errors related to unaccounted cleanups.  

Example:  
Original code:  
template<typename T>  
void func(T &&x) {  
}  

void caller() {  
    int i = 0;  
}  

Mutated code:  
template<typename T>  
void func(T &&x) {  
}  

void caller() {  
    int i = 0;  
    func(0);  // Added call with temporary argument  
}  

This mutation applies to any template function with a universal reference parameter that is not used. The added call ensures the parameter is not used in the context of the function’s instantiation, exposing compiler bugs related to diagnostic handling and cleanup tracking.
