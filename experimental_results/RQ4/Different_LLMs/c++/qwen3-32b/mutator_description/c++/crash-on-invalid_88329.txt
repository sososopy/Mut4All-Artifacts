Mutation operator: Replace a non-type template parameter of type auto with an indirection operation (e.g. *T) in a type context where the resulting type is ill-formed, but syntactically valid. Apply to any function or class template parameter declared with auto that appears in a type specification that can be modified by pointer operations.

Applies to: Non-type template parameters declared with auto in function templates or class templates where the parameter is used in a type context requiring lvalue classification.

Example transformation:
Original:
template <auto T> struct A {};
template <auto T> A<T> operator *() { return {}; }

Mutated:
template <auto T> struct A {};
template <auto T> A<*T> operator *() { return {}; }

The mutation preserves syntactic validity but creates an ill-formed type (pointer to T) that triggers type classification during auto deduction, reproducing the assertion failure in the compiler's Expr::ClassifyImpl function.
