Mutation Operator: ReplacePointerArgWithInteger  
Applies to: Function calls to built-in functions expecting a pointer argument (e.g., `__builtin_assume_aligned`).  

Action: Replace the first argument of such a built-in function call with an integer variable from the same scope, creating an invalid type conversion.  

Example (pseudo-code):  
Original code:  
```c  
void foo(T* ptr) {  
    T* aligned = __builtin_assume_aligned(ptr, 16);  
}  
```  
Mutated code:  
```c  
void foo(T* ptr) {  
    int localVar = 42;  
    T* aligned = __builtin_assume_aligned(localVar, 16);  
}  
```  

This mutation introduces a type mismatch between the expected pointer and actual integer, triggering a diagnostic. If the compiler crashes instead of issuing an error, the bug is exposed. Preferences: Use existing integer variables in the same scope (e.g., loop counters, parameters). If none exist, declare a minimal local integer variable (e.g., `int temp = 0;`).
