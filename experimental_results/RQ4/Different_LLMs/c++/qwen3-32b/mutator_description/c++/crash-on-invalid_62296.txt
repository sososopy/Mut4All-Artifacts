Mutation operator: Corrupt scope resolution in using declaration  
Applies to: class/struct member using declarations that inherit a member from a base class  

Transformation: Replace a valid `using Base::member;` with `using Base::;` by removing the member identifier after the scope resolution operator  

Example:  
Original:  
struct Derived : Base {  
    using Base::value;  // Valid using declaration  
};  

Mutated:  
struct Derived : Base {  
    using Base::;  // Malformed using declaration with missing identifier  
};  

This mutation targets the error recovery path of the compiler's parser when handling invalid using declarations. It leverages existing class hierarchies and using declarations in the seed program without introducing new symbols. The transformation corrupts a syntactically valid using declaration into a form that triggers the same compiler crash mechanism observed in the report, by leaving the scope resolution operator unclosed.
