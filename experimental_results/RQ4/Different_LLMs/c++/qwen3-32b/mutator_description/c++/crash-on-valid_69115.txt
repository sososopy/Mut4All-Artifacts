Mutation Operator: NestedArrayStructuredBinding
Applies to: Functions containing a constexpr array of structs initialized with an initializer list and a structured binding declaration that unpacks the array.
Transformation: Replace a 1D array with an N-dimensional array (e.g., arr[N] → arr[N1][N2]...[Nk]) and adjust the structured binding to unpack the array into multiple variables, ensuring the total number of elements matches the original array size. This targets nested ArrayInitLoopExpr combined with structured bindings during constexpr evaluation.

Example:
Original code:
struct S { int x; };
constexpr S arr[] = { {1}, {2}, {3}, {4} };
auto [a] = arr;

Mutated code:
struct S { int x; };
constexpr S arr[2][2] = { {1}, {2}, {3}, {4} };
auto [a, b] = arr;

Rationale: The nested array introduces ArrayInitLoopExpr for multidimensional bounds and requires the interpreter to handle structured binding decomposition of compound types. This mirrors the crash scenario by creating a chain of nested array initializations and structured binding unpacking that may trigger interpreter logic bugs during record destruction or initialization sequences.
