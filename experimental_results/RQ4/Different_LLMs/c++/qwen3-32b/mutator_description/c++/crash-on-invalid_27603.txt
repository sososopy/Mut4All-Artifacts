Mutation operator: In template type arguments, replace a valid type with an undefined identifier. Apply to any template parameter list containing a type that can be substituted with a non-declared identifier. For example, mutate `One<int>` to `One<UnknownType>` where `UnknownType` is not declared in the program scope. This targets error recovery in template instantiation and can expose assertion failures during semantic analysis. The mutation applies to nested template arguments, function parameters, and local variable types. Example: transform `Two<int, One<int>>` to `Two<int, One<InvalidType>>`.
