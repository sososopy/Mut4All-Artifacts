Mutation Operator: Insert Nested Lambda with Parameter Pack Fold Expression in Template  
**Target:** Any non-static function definition within a templated entity (function template, class template, or class with template parameters).  
**Action:** Within the function body, replace an existing statement (e.g., a compound statement or a single expression) with a generic lambda that captures a parameter pack. Inside the lambda, use a fold expression that processes the pack elements. The lambda is immediately invoked with a set of concrete arguments (e.g., integers or types, as appropriate to the pack's usage).  

**Example:**  
Given a function `template <class T> void g()` with a statement like `T x;`, mutate it to:  
```cpp  
[]<class... Us>() {  
    (static_cast<void>(Us{}), ...);  
}.template operator()<T, int, float>();  
```  
Here, the lambda's parameter pack `Us` is expanded via a fold expression. The invocation uses existing template parameter `T` and common types `int`/`float`.  

**Existing Elements Utilization:**  
- Reuse the function's template parameters (e.g., `T`) in the lambda's invocation.  
- If the seed program uses basic types (e.g., `int`, `float`), they can be added as example arguments to the lambda's `.template operator()<...>()` call.  

**Avoid New Elements:**  
- Do not introduce new types or variables beyond those already present in the template or seed program. Use existing types (e.g., template parameters, standard types) for the lambda's invocation.  

This mutation exposes ICEs or errors in handling fold expressions over parameter packs in nested lambdas during template instantiation.
