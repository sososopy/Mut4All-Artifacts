mutation operator: insert_semicolon_in_namespace_decl  
Applies to any multi-line namespace declaration (with opening brace on a subsequent line). Insert a semicolon immediately after the namespace identifier but before the opening brace, creating invalid syntax. This targets parser handling of unexpected tokens in namespace syntax.  

Example:  
Original:  
namespace X  
{  
...  
}  

Mutated:  
namespace X;  
{  
...  
}  

This forces the parser to process a semicolon where it should expect an opening brace, potentially exposing crash conditions in error recovery paths. The mutation uses only existing namespace identifiers and maintains surrounding structure, ensuring compatibility with any seed program already using multi-line namespace declarations.
