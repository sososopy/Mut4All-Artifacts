Mutation operator: DefaultParamConstExpr
Target a function or constructor with a parameter that lacks a default value and no constexpr attribute. Add a default parameter (e.g., 0) to the first parameter and mark the function/constructor as constexpr if it's not mangled with volatile or non-literal types. Modify an existing call site or array initialization to use the new default, swapping explicit arguments {} with empty braces when default values are enabled. For functions, replace a single call in a return statement with an expression that evaluates the function twice using logical operators (e.g., return foo() && foo();) to test repeated evaluation in constant contexts.

Example:
Original:
void bar(int x);
void test() { bar(0); }

Mutated:
constexpr void bar(int x = 0);
void test() { return bar() && bar(); }

(If original bar was non-constexpr, this requires the compiler to evaluate default parameters as constants, potentially exposing assertion failures in the evaluator when handling multiple evaluations.)
