Mutation Operator: Add Requires Clause to Lambda Parameters in Templates  
Applies to: Lambdas within template functions or classes that have auto parameters.  
Modify the lambda's parameter list to include a requires clause checking if an existing type from the seed program can be constructed from the auto parameter.  

Example:  
Original lambda:  
for_each_callback([&](auto x) { process(x); });  

Mutated lambda:  
for_each_callback([&](auto x) requires (requires { T(x); }) { process(x); });  
Where T is a type already declared in the seed program.  

This forces constraint evaluation during template instantiation, stressing the compiler's constraint satisfaction logic and potentially exposing out-of-bounds access in Sema::tryCaptureVariable.
