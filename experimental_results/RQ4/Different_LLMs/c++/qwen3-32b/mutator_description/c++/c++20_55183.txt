Mutation Operator: Replace constexpr with consteval in function or constructor declarations to trigger invalid compile-time evaluation  
Applies to: Any function or constructor currently marked as constexpr  
Example:  
Original:  
constexpr int foo(int x) { return x + 1; }  

Mutated:  
consteval int foo(int x) { return x + 1; }  

Must use existing functions/constructors already marked constexpr in seed programs. Changes only the evaluation context to force consteval handling. This stresses compiler's consteval parsing and constant expression evaluation paths, which were directly involved in the crash.
