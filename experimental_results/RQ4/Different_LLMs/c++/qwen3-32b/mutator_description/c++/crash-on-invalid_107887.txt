Mutation operator 1: Move deduction guide to outer scope. Apply to any class template that has a deduction guide declared within the same namespace scope as the template. For a template declared inside a namespace, mutate by repositioning the deduction guide declaration so it appears in an outer/enclosing namespace scope. For a template in global scope, mutate by placing the deduction guide inside a newly declared inner namespace. This creates a mismatch between the template's scope and its deduction guide's scope. Example: Original has namespace A::template X and deduction guide in A. Mutated version moves the deduction guide outside A namespace while keeping template X within A, creating a scope mismatch that could trigger the deduction guide validation logic in the compiler.
