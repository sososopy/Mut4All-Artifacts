Mutation Operator: Insert an invalid semicolon token into a struct/union/class body between two valid member declarations.  
Applies to: Any user-defined struct/union/class containing multiple member declarations.  
Example:  
Original code:  
struct A { int x; double y; };  
Mutated code:  
struct A { int x; ; double y; };  
(Note: The inserted semicolon is invalid unless part of a valid bit-field or template parameter context.)  
Coverage: Targets class/struct parsing logic, especially error recovery paths for invalid member syntax.  
No new variables/types are introduced. Applies to any existing struct/union/class with two or more members.
