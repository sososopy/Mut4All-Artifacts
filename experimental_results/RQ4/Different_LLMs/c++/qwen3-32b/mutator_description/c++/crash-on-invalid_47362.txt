Mutation operator: TemplateExceptionSpecDependency  
Target construct: Function templates with non-dependent exception specifications (noexcept or throw) that can be made dependent on template parameters.  
Application: Apply to function templates where the exception specification can be rewritten to depend on a template parameter's member or type that may not exist in some instantiations.  

Example mutation (pseudo-code):  
Original:  
template <typename T>  
void foo() noexcept(true) { ... }  

Mutated:  
template <typename T>  
void foo() noexcept(T::invalid_member) { ... }  

Requirements:  
- The seed program must have a template parameter T declared as a class type.  
- The mutation introduces a dependent noexcept specifier using T's member (existing or non-existing in some instantiations).  
- No new types or variables are declared; it leverages existing template parameters.  

This forces the compiler to substitute exception specs during template instantiation, potentially exposing bugs in handling uninstantiated or invalid exception specifications.
