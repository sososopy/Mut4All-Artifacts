Mutation operator: Replace an inline use of an initializer_list with an r-value reference to the initializer_list followed by a call to begin(). Apply to expressions where the initializer_list is used directly as a function argument or within a range-based operation. 

Example: 
Original code: 
f(begin({1, 2, 3}));

Mutated code: 
auto&& temp = {1, 2, 3};
f(begin(temp));

This tests if the compiler mishandles the temporary lifetime or iterator access when the initializer_list is aliased via an r-value reference. If the seed program already has a named function f that takes an iterator, this mutation can be applied without introducing new variables. Otherwise, declare a dummy function void f(auto*) {} in the same scope before the mutation.
