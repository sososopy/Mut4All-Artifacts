Mutation operator: Introduce a recursive concept parameter in a requires clause for a concept definition that already uses requires with parameters. Replace a parameter type in the requires clause of a concept with the concept name followed by `auto`, creating a direct dependency loop (e.g., change `requires (T x)` to `requires (ConceptName auto x)` where `ConceptName` is the concept being defined). Apply to concepts with at least one requires clause parameter. This exploits circular constraint evaluation logic in the compiler, triggering assertion failures when the concept is instantiated. For example, in a program with a concept defined as `template<...> concept C = requires(T x) { ... };`, mutate the requires clause's parameter type to `C auto x` to force dependent type evaluation.
