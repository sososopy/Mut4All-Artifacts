Mutation operator: NestedBlockLambdaCapture - Target lambda functions that capture parameters and nest Objective-C blocks, checking for crashes in capture handling during template instantiation.
Applies to: Function parameters in lambda capture lists followed by nested block constructs.
Example:
// Original
void example(T a) {
    use(a);
}

// Mutated
void example(T a) {
    [a](auto b) {
        ^{
            (void)a;
        };
    }(0);
}

Requires -fblocks flag and existing lambda usage. Modifies existing lambda expressions by adding nested blocks that reference captured variables, ensuring the block references already-captured variables from the outer lambda.
