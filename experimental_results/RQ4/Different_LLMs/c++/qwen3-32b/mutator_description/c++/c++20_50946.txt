Mutation operator: Lambda in meta-concept template argument  
Applies to: Requires expressions with nested concepts that accept lambda-quoted constraints as template arguments.  
Changes: Replace a simple concept check in a `requires` clause with a nested concept that accepts a lambda as a template argument, using an existing member or function in the seed program.  

Example:  
Original code:  
```cpp  
template<class T> concept C = requires(T t) { { t.x }; };  
```  
Mutated code:  
```cpp  
template<class T> concept C = requires(T t) {  
    { t.x } -> M<[]<A>(){}>;  // M is an existing concept, A is an existing constraint  
};  
```  
Requires:  
1. An existing member or function (e.g., `x`) in `T` to form the expression.  
2. An existing concept `M` that accepts a lambda as a template argument.  
3. An existing constraint `A` that can be parameterized by the lambda.  

High coverage is achieved by targeting template argument substitution during concept evaluation, a core C++20 feature with complex instantiation logic.
