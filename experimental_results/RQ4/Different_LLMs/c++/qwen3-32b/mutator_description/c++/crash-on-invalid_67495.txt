Mutation Operator: Replace a reference to a struct returned by a function with a structured binding of its members, then capture those members in a lambda expression. Applies to code where a function returning a struct is referenced and stored, and the struct's members are accessed directly.

Example:  
Original code  
auto& p = get_point();  
int value = p.x + p.y;  

Mutated code  
auto& [x, y] = get_point();  
int value = [x, y] { return x + y; }();  

This transformation introduces a structured binding [x, y] in place of p and replaces direct member access with a lambda that captures x and y. Since the original struct (e.g., Point) and function (e.g., get_point) already exist in the seed program, no new types or declarations are added. The mutation exploits the compiler’s handling of lambda captures of structured binding variables, which may expose a crash-on-invalid bug in structured binding resolution.
