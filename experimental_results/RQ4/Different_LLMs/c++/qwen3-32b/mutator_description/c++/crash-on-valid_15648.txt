Mutation Operator: Replace a variadic template alias instantiation that appends a new parameter after a pack expansion with one that prepends the new parameter before the pack expansion in the alias template arguments. Applies to alias templates that expand a parameter pack followed by a non-pack template argument. For example, mutate `Bar<Ts..., U>` → `Bar<U, Ts...>` where `Ts...` is a pack and `U` is a template parameter. This stresses template argument parsing and pack expansion handling during alias instantiation.
