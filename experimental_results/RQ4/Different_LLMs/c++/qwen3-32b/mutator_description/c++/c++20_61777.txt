Mutation operator: Replace a non-dependent constraint on a nested class template's non-type template parameter with a dependent constraint using the outer class template's parameters.  
Applies to: Nested class templates with constrained non-type template parameters inside another class template.  
Example:  
Original:  
template<class T> struct Outer {  
  template<class U, C auto V> struct Inner { /* ... */ };  
};  

Mutate to:  
template<class T> struct Outer {  
  template<class U, requires_same_as<T, U> auto V> struct Inner { /* ... */ };  
};  
(Requires that "requires_same_as" is a prior concept checking type equality between T and U)  

This creates a dependent constraint by referencing the outer template parameter T, increasing likelihood of triggering dependent expression evaluation issues in constraint checking logic. Existing type parameters of the outer class are reused, and the concept must be defined elsewhere in the seed program.
