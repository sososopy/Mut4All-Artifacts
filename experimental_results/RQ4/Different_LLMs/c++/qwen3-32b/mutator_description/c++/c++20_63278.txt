mutation operator: Replace a struct/class member variable's explicit type with `auto` and add an initializer.  
Applies to: Non-static member variables in structs/classes with explicit type declarations.  
Example:  
Original  
struct S {  
  T m;  
};  

Mutated  
struct S {  
  auto m = value;  
};  
Changes required: Replace `T` with `auto` and append `= value` to the declaration.  
Uses existing variables and ensures invalid code to trigger compiler diagnostic handling.
