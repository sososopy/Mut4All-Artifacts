Mutation operator: Insert inline namespace with forward-declared class
Applies to: Any namespace declaration in the seed program
Change: Within an existing namespace, add an inline namespace that contains a forward declaration of a class (preferably one already defined in the outer namespace or elsewhere in the program)
Example:
Original:
namespace X {
// ... existing code ...
}

Mutated:
namespace X {
inline namespace Y {
class Z;
}
// ... existing code ...
}

Mutation operator: Add nested inline namespace with type reference
Applies to: Class/struct declarations with nested namespaces
Change: Wrap the class declaration inside an inline namespace that shares the same name as the class, creating a three-level nesting (outer namespace -> inline namespace -> class)
Example:
Original:
namespace Outer {
class MyClass {};
}

Mutated:
namespace Outer {
inline namespace MyClass {
class MyClass {};
}
}
