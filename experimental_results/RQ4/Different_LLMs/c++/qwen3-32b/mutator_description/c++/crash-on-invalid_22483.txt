Mutation operator 1: Replace a lambda type used as a template argument with an ill-formed lambda that contains an invalid capture or unsupported feature for the current standard. Apply this to any template function parameter where the function includes a sizeof operation on the parameter. For example, in a function template T f(T x) { int y = sizeof(x); }, mutate a valid lambda parameter like [a] { return a; } to a generalized capture form like [x = 0] { return x; } in C++11 mode, creating an ill-formed closure type that triggers incorrect layout computation when sizeof is invoked. Ensure the lambda is passed as the template argument to f() and the mutation does not modify existing variable declarations.
