Mutation Operator: Replace a non-type template argument that is a constant expression with a non-constant variable reference. Apply this to any template parameter expecting a constant expression by substituting the constant with a variable declared in the same scope but lacking constexpr or const qualifiers. Example: Change template<int N> Foo<3> to Foo<x> where x is an integer variable initialized with runtime data. This forces invalid template argument substitution and may trigger assertion failures in template type-checking logic.
