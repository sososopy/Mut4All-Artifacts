Mutation operator: Add constrained NTTP to nested class template
Applies to: Nested class templates within outer class templates
Modifies: Nested class template parameter list
Change: For a nested class template inside an outer class template, insert a constrained non-type template parameter using an existing concept from the program. If no concept exists, introduce a simple concept like "template <class> concept C = true;" at the namespace scope. The constrained NTTP should follow any existing parameters in the nested template's parameter list. Example: Transform
template <class> struct Outer {
  template <class> struct Inner {};
};
into
template <class> concept C = true;
template <class> struct Outer {
  template <class, C auto> struct Inner {};
};
This mutation targets the interaction between nested templates and constrained NTTPs, which is the core structure triggering the reported crash. The change preserves existing template parameters while adding the new constrained parameter.
