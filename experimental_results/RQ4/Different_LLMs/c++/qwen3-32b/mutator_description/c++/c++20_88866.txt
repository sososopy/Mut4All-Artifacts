Mutation operator: UnexpandedPackInConceptConstraint  
Applies to: Class template partial specializations with a concept constraint that uses an unexpanded parameter pack in its template argument list. Targets the scenario where a variadic template's partial specialization involves an unexpanded pack in a concept-constrained non-type template parameter.  

Example mutation:  
Original code:  
template <typename T, typename... Args>  
concept C = ...;  

template <typename... Ts, C<Ts...> auto Param>  
struct X;  

Mutated code:  
template <typename T, typename... Args>  
concept C = ...;  

template <typename... Ts, C<Ts> auto Param>  
struct X;  

The mutator replaces the expanded pack (Ts...) in the concept constraint with an unexpanded reference (Ts), mimicking the unexpanded pack scenario in the bug report. This modification typically triggers parsing/evaluation errors in C++20 concepts involving non-type template parameters with variadic constraints.  

This mutation leverages existing variadic templates and concepts in the seed program without introducing new types or variables. It requires that the template has a variadic parameter pack and a concept reference in its constraints.
