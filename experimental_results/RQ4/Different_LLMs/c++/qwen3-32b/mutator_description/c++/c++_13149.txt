Mutation operator: Forward-declare class type without definition and access member in template method.  
Target code construct: Member variable with forward-declared class type in a class template.  
Steps:  
1. Replace the type of a member variable in a class with a forward-declared class (e.g., `class X;` in the header).  
2. In a template method of the same class, perform an operation on the member variable that requires the class's definition (e.g., assignment, constructor call).  
3. Ensure the forward-declared class has no full definition in the translation unit.  

Example:  
Original code:  
class Y;  
struct S {  
   Y y_member; // Forward-declared type used as member  
};  
template<typename T>  
void S::foo() {  
   y_member = Y(); // Requires Y's definition  
}  

Mutated code (compiler likely to crash):  
class Y; // No definition  
struct S {  
   Y y_member;  
};  
template<typename T>  
void S::foo() {  
   y_member = Y(); // Triggers assertion due to undefined Y  
}  

This exploits incomplete types in templates, a common error scenario for compiler crash bugs.
