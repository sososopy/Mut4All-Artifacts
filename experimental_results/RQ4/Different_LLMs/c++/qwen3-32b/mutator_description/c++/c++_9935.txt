Mutation operator: Replace a valid call to a member template function with a reference to the function template without the function call syntax. Apply this to any program with a member function template that is invoked using angle brackets and parentheses. For example, mutate `obj.func<T>(args)` to `obj.func<T>`, creating an invalid expression that references a template function without the required syntax for function application. This targets programs where the member function is already present and called correctly. The mutation operator does not introduce new variables or types; it only transforms existing references to member template functions.
