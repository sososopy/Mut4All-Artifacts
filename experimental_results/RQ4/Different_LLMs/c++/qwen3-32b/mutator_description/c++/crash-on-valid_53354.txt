Mutation operator: Convert a concept's requires clause checking for a member type into one that checks for a nested template type using the 'template' keyword. Apply to any concept that currently checks for a member type (e.g., `requires has_member<T>`), replacing it with a nested template check (e.g., `requires typename T::template nested_template<>`). This targets constraint evaluation paths during template argument substitution and partial specialization checks. Example transformation: a concept `concept HasX = requires { typename T::X; };` becomes `concept HasY = requires { typename T::template Y<int>; };`. The seed program must already contain a type `T` with a nested template `Y` to be valid. If no such member exists, declare a placeholder nested template in a test class (e.g., `template<class> struct Y {};` inside a test class).
