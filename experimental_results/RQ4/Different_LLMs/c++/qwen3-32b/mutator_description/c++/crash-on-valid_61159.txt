Mutation operator: Replace a non-type template parameter used in a standard container's return type (e.g., `std::array<T, N>`) with a nested type from the enclosing class template that depends on the same parameter. Apply this to template functions within nested class templates where a nested type exists. Example: Change `auto f() -> std::array<int, N>` to `auto f() -> typename Outer::Nested<Outer::Tag, N>::type`. This creates multi-layer template instantiation requiring cross-class parameter propagation, stressing template name resolution and argument substitution. Existing nested types and tags must already be declared in the seed program.
