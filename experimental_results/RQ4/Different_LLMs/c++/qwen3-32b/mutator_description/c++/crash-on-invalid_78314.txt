Mutation Operator: Replace a valid prefix increment operator with a deleted version in a class and modify an existing postfix increment operator to be a templated function taking an unused type parameter. Inside this templated function, invoke the prefix increment on a local instance of the class.

Applies to: Classes with both prefix and postfix increment operators.

Example:
Original code:
class C {
  void operator++();
  void operator++(int);
};

Mutated:
class C {
  void operator++() = delete;
  template<class T> void operator++(int) {
    C c;
    ++c; // Triggers deleted prefix increment
  }
};

This exposes bugs in overload resolution when a deleted function is involved in candidate selection, especially when templates are present. The mutation uses existing class members (C type and operator structure) without introducing new external declarations.
