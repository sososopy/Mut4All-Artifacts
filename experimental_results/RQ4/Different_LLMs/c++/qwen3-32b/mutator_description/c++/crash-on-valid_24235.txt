Mutation operator: Add constexpr qualifier to a non-constexpr variable declaration with a constant expression initializer. Apply to any variable declaration not already marked constexpr, ensuring the initializer is a valid constant expression. This forces the compiler to evaluate the initializer at compile-time, exercising the constexpr evaluation path. Example: Change `int x = 5 + compute();` to `constexpr int x = 5 + compute();` where `compute()` is a constexpr function or expression. This triggers the crash if the evaluation logic (VD->evaluateValue()) encounters an unhandled edge case in the modified context.
