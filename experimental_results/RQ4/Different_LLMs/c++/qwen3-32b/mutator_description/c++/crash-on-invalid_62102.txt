Mutation operator: Template parameter type mismatch in comparison operator overload for defaulted operator. Apply to classes defining a defaulted comparison operator that depend on a template operator with mismatched type parameters relative to member variables. Replace a type parameter in the template operator's second parameter type to differ from the corresponding member's type in the containing class. For example, in the template operator `operator==(S<T>, S<U>)`, change the second parameter to `S<AlternateType>` where `AlternateType` is a type present in the surrounding class but differs from the actual member type. This forces template instantiation to encounter incompatible types during defaulted operator synthesis. Example: if struct E has S<int> s, modify the operator to `operator==(S<T>, S<float> x)` to trigger type conversion challenges during overload resolution.
