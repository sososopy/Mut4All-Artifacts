Mutation Operator: IncompleteMemberInitList
Target code constructs: Structures with incomplete member types and malformed constructor initializer lists.
Application: For a class/struct containing a member of a forward-declared but incomplete type, insert a constructor with an incomplete initializer list that attempts to initialize the incomplete member with a syntax error in the initializer expression.
Example mutation:
Original:
class A;
struct B {
  A a;
};
Mutated:
struct B {
  A a;
  B() : a{ ( { // Malformed nested initializer
};
};
Rationale: Triggers special member lookup during constructor processing for a class with incomplete members, reproducing assertion conditions in SemaLookup.cpp. Requires existing forward-declared type 'A' in the seed program.
