Mutation operator: Replace deduction guide's non-type parameter inference with a complex expression that requires multiple template parameter deductions. Apply to class templates with a deduction guide that uses a template parameter for a constructor and derives a non-type template parameter from another type property. Example: Change `C(T) -> C<Ptr<T>, sizeof(T)>;` to `C(T) -> C<Ptr<T>, alignof(T) + 1>;` where `alignof(T)` is a standard trait evaluating to a compile-time constant. The mutation replaces the `sizeof(T)` expression with `alignof(T) + 1` for the non-type parameter, maintaining the deduction guide structure but introducing a more complex expression that combines type traits and arithmetic. This stresses the compiler's ability to handle nested template evaluations in deduction guides.
