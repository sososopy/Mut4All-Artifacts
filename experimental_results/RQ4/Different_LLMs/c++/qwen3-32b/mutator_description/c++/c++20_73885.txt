Mutation Operator: VariableTemplateConceptParameterMutation  
Applies to variable templates declared with a requires clause that checks a concept. Replace the requires clause with a constrained template parameter using the same concept. For example, transform:  

template <typename T>  
  requires C<T>  
constexpr T var = value;  

into:  

template <C T>  
constexpr T var = value;  

This mutation leverages existing concepts defined in the seed program. It ensures constraint syntax variation, which can expose errors in compiler handling of constrained variable templates. The example uses a variable template with a generic type parameter and a concept constraint. The mutation targets the constraint application method, shifting from a trailing requires clause to a direct template parameter constraint.
