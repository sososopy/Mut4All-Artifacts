Mutation operator: Add explicit template arguments to non-template constexpr function calls.  
Applies to: Non-template constexpr functions called without template arguments in a context where template arguments are invalid.  
Changes: Select a constexpr function call that is not a template, add arbitrary explicit template arguments (e.g., `<1>`) to the call.  
Example:  
Original:  
`static constexpr int value = foo();`  
Mutated:  
`static constexpr int value = foo<1>();`  
Rationale: Triggers compiler logic for template argument resolution in non-template contexts, exposing assertions or crashes during overload resolution or constexpr evaluation.  
Avoids introducing new elements; uses existing functions and syntax.
