Mutation operator: DependentTemplateAccess
Applies to decltype/decltype(auto) expressions accessing nested templates through a dependent type. Modify an expression like 't.U::template B<V>::MEM' to use a nested template accessed via a type that is a template parameter dependent on other template arguments. For example, change:
decltype(t.U::template B<V>::MEM)
to:
decltype( typename U::template Nested<T>::template B<V>::MEM )
where T is an existing template parameter in the current scope. This increases the depth of template nesting in a dependent context, stressing the compiler's mangling of complex nested names where the qualifier is itself a dependent type. The nested 'Nested<T>' must already exist as a type in U's template parameters, or if not, introduce a new member type 'Nested' in U's definition that depends on T, ensuring it's a valid template alias or class template.
