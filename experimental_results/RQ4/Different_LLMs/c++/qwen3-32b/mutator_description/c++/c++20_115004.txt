Mutation operator: InvalidConceptConstraintRemoval  
Applies to C++20 concept declarations where the constraint expression is explicitly defined.  

Modifies a valid concept constraint declaration by removing the constraint expression, leaving only the concept name. Example:  
Original: `concept C = expr;` → Mutated: `concept C;`  

This creates a concept with no associated constraint expression. When such a concept is used in template declarations (e.g., `template<C T> struct X;`), the compiler must handle the missing constraint expression during template parsing and constraint normalization, potentially exposing assertion failures in constraint processing logic.  

The mutation is applicable to any seed program containing:  
1. A concept declaration with a valid constraint expression  
2. At least one template that uses the concept as a constraint  

The resulting invalid constraint forces the compiler to process a null constraint expression during semantic analysis, reproducing conditions that trigger assertion failures in constraint normalization code paths.
