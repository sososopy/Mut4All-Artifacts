Mutation Operator: Replace valid type trait template argument with invalid nested type 
Applies to: Any standard type trait (e.g., add_rvalue_reference, is_same) applied to a class/template type

When a standard type trait is used with an existing class or template type, replace the type trait with a similarly named non-standard variant that lacks the required nested type. For example, change:
std::SomeTrait<T>::type 
to 
std::__SomeTrait<T>::invalid_type

This forces the compiler to process an invalid type trait that either doesn't exist or doesn't contain the expected nested type member. The mutation preserves the template syntax structure while creating an invalid code path that may trigger compiler crashes during template instantiation. The replacement must use:
1. Existing template name (SomeTrait) with added/modified underscore prefix
2. An existing type (T) from the seed program
3. A non-existent nested member name (invalid_type) instead of valid ones like 'type'

The compiler is expected to crash when attempting to instantiate or evaluate this malformed type trait, rather than reporting a proper error. This exploits the fact that many type traits depend on nested type members which, when missing, can expose unhandled code paths in template evaluation.
