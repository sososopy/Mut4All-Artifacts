Mutation operator: Add a constrained inner class template with nested constraints referencing outer template parameters.  
Applies to: Class templates with existing template parameters.  

Action: Insert an inner class template inside the target class template. The inner class must:  
1. Use at least one template parameter constrained by a concept (e.g., a placeholder concept name).  
2. Reference outer class template parameters in constraint expressions (e.g., `requires outer_template_param::value`).  
3. Avoid introducing new types or functions if possible; use existing template parameters from the outer class.  

Example (pseudo-code):  
Original code:  
```cpp  
template <typename T>  
struct Outer {  
  // ...  
};  
```  

Mutated code:  
```cpp  
template <typename T>  
struct Outer {  
  template <typename U>  
  requires (requires { T::value; } && U::value)  
  struct Inner {  
    // ...  
  };  
};  
```  

High coverage is achieved by transforming class templates with nested constraints that require cross-level parameter resolution.
