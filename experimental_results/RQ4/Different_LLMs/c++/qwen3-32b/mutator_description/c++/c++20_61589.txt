Mutation Operator: Replace a generic lambda's parameter type (e.g., auto) with a specific type from the seed program in a template function, making the lambda non-generic. Apply to lambdas used in concept constraints or template instantiations. Example: Change a lambda's parameter from auto&&... args to T&&... args where T is an existing type in the seed program. This alters concept evaluation and template instantiation paths, potentially exposing compiler bugs in handling non-generic lambdas within concepts. The seed program must already declare T. No new variables or types are introduced.
