Mutation operator: PartialSpecializationBaseParameterMismatch  
Target a partial template specialization and modify its base class template arguments to use a different template parameter than the one in the specialization's own template parameter list. Apply to any class template partial specialization that directly inherits from a templatized base class. For example, given a specialization:  
template <typename T>  
struct Outer<T, int> : Base<T> { ... };  

Change the base to use a different parameter:  
template <typename T>  
struct Outer<T, int> : Base<U> { ... };  
where U is a type parameter from the same template or an unrelated type. This forces incorrect template argument deduction during base class instantiation, mimicking the error in the bug report where a partial specialization's base class used Rhs while the specialization's template parameter was int. Ensure the mutation uses existing template parameters in the seed program and preserves valid syntax through valid placeholder types.
