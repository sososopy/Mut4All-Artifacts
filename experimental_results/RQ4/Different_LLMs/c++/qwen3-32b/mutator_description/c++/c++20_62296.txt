Mutation operator: MalformedUsingDeclarationInDerivedClass  
Applies to: 'using Base::member;' within a derived class that inherits from Base.  
Targets code where a derived class uses a 'using' declaration to inherit constructors or members from a base class.  
Example: Replace 'using Base::member;' with 'using Base::;' (omitting required identifier after '::').  
Changes required: Existing base class (Base) and derived class must exist. Locate a valid 'using Base::member;' line and remove 'member' and following characters before the semicolon.  
Effect: Triggers syntax error handling in the 'using' declaration parsing logic, exposing compiler bugs in error recovery paths for incomplete token sequences after '::'.  

Mutation operator: IncompleteAccessSpecifierInUsingDeclaration  
Applies to: 'using Base::member;' within a class definition that derives from Base.  
Targets code where access specifiers are used in inheritance or 'using' declarations.  
Example: Modify 'using Base::member;' to 'using Base::;' (remove identifier after ::).  
Changes required: Existing base/derived class relationship must exist. Find a 'using' declaration in the derived class and truncate the token sequence after ::.  
Effect: Forces compiler to handle invalid token sequence in 'using' declaration, exposing improper error recovery in semantic analysis phases.
