Mutation operator: Replace a non-deduced class template type parameter with a nested template template parameter in an alias template, forcing CTAD to attempt deduction of the inner template. This targets alias templates that compose nested template parameters with CTAD constraints in C++20. Apply to alias templates that already use template template parameters or nested type references. Example: Change `template<T> using Alias = Class<T>` to `template<template<U> class UTP> using Alias = Class<Inner<UTP>>` where `Inner` is an existing template that requires template template parameters. This forces the compiler to chain template template parameter deduction through multiple layers, mimicking the nested K<TTP> structure in the original error case.
