Mutation Operator: Replace __builtin_va_arg's first argument with a non-va_list variable from the same scope, targeting variadic function argument handling.  
Example:  
Original code:  
va_list list;  
__builtin_va_arg(list, int);  

Mutated code:  
va_list list;  
int x;  
__builtin_va_arg(x, int);  

Applies to any __builtin_va_arg call with a non-va_list variable already declared in scope. Replaces the expected va_list argument with an existing variable of a different type (e.g., int, pointer, struct), creating an invalid use of the built-in function. This triggers compiler error handling paths for invalid va_arg usage, increasing likelihood of exposing crashes in type validation mechanisms.
