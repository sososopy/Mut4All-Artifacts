Mutation Operator: Replace a default member initializer in a class template with a lambda that returns the same value.  
Target Construct: Class templates with default member initializers.  
Conditions:  
- The class template must have at least one member with a default initializer (literal, simple expression, or existing function call).  
- The lambda must capture nothing, return a value of the same type as the original initializer, and be placed in the default initializer.  
Example:  
Original:  
class Template<T> {  
    int x = 42;  
};  

Mutated:  
class Template<T> {  
    int x = []{ return 42; }();  
};  

Changes:  
1. Replace the default initializer of `x` with a lambda that returns the same value.  
2. Ensure the lambda uses existing types (e.g., `int`) from the seed program.  
3. No new variables or functions are introduced.  

Coverage:  
Applies to class templates with default member initializers, testing lambda handling in AST generation and template instantiation.
