Mutation Operator: Add constexpr to a deleted member function declaration in a class where the function is not constructible or destructible by default.  
Applies to: Any class member function (constructor, destructor, or operator) declared with `= delete`.  
Example:  
Original code:  
class C {  
public:  
    C(const C&) = delete;  
};  

Mutated code:  
class C {  
public:  
    constexpr C(const C&) = delete;  
};  

Changes required: Identify a deleted member function in the seed program, insert `constexpr` before the `= delete` specifier. No new variables or types are added; only modify the existing function's qualifiers.  

This mutation targets invalid code combinations in C++11 where `constexpr` functions cannot be deleted, exposing compiler crashes during semantic analysis.
