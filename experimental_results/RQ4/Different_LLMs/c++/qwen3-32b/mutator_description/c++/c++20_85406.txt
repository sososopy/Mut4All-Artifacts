Mutation operator: Nested alias template with extraneous template parameters
Applies to class templates with at least one type parameter
Insert an alias template declaration inside the class template body that:
- Uses the same name as the outer class template
- Has a new template parameter list
- Refers to the outer class template using the new parameter

Example mutation:
Original:
template <typename T>
class Container { };

Mutated:
template <typename T>
class Container {
  template <typename K>
  using Container = Container<K>; // erroneous nested alias
};

This creates a similar invalid alias template structure as the bug report where:
1. The alias template is incorrectly nested inside another template
2. The new template parameter list causes a mismatch in template depth
3. The alias refers to the outer class template using the new parameter type

The mutation uses only existing elements from the seed program by:
- Using the class template's existing name (Container)
- Reusing the outer template parameter (T) as a base
- Creating a new template parameter (K) for the alias
- Referencing the outer class template directly
