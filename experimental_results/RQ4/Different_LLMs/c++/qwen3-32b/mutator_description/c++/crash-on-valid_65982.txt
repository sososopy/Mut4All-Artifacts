Mutation operator: In a class template inheriting from a parameter pack with virtual inheritance, add a using declaration with a fold expression for a member from all base classes. Example: Change a class `template<typename...Ts> struct C : virtual Ts... { };` to add `using Ts::member...;` where `member` is a common member in all Ts. Avoids new types by reusing the existing parameter pack and base class member. Targets the interaction between C++20's variadic name lookup and virtual inheritance, as seen in the bug trace.
