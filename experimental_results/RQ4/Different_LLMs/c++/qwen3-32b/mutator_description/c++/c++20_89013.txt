Mutation operator: Replace a concept constraint that checks a type's derivation from a non-dependent base with one that requires derivation from a template-dependent base, where the base's template parameters include the derived type itself.

Example mutation: In a template class with a concept constraint checking derivation from a simple base type (e.g. 'std::derived_from<D, Base>'), replace the base type with 'Base<T, D>' where T is a template parameter of the class. This creates a curiously recurring template pattern dependency chain that forces the compiler to evaluate type relationships during constant evaluation. Apply this to both concept constraints and CTAD guides that use raw pointer parameters.

The operator targets CRTP-based templates with concept constraints and CTAD guides by increasing the dependency complexity of type relationships. It works with existing types in the program by modifying existing template parameters and inheritance structures instead of introducing new elements. This change creates scenarios where the compiler may incorrectly attempt to evaluate value-dependent expressions as constant expressions, exposing assertion failures like the one in the original report.
