Mutation Operator: Replace a default constructor of a class with a constructor that initializes a new reference member to an array of a type and size derived from an existing array member. The reference is initialized by dereferencing a dynamically allocated array of one higher dimension than the referenced array. For example, given an existing array member T[N], add a reference member T(&)[N] and initialize it in the constructor as data(*new T[1][N]). This applies to classes with existing array members and a default constructor. The mutation reuses the array type and size from the existing member, ensuring the new reference and dynamic allocation are compatible. This pattern forces the compiler to handle materialization of temporaries in constructor member initializers, exposing bugs in such evaluations.
