Mutation Operator: Replace a simple member initialization with a parenthesized initializer involving a nested template and type trait.  
Target construct: Class member with direct initialization (e.g., T member;).  
Action: Modify the member initialization to use a CXXParenListInitExpr with a nested template dependent on a type trait. For example:  
Original:  
struct S {  
    T member;  
};  

Mutated:  
struct S {  
    T member{ typename std::conditional<std::is_integral<T>::value, A, B>::type() };  
};  
Use existing types A, B, and T from the seed program. If not present, declare minimal type aliases (e.g., typedef int A; typedef int B;) in the global scope. This forces the compiler to process nested templates and paren list initializers, stressing type trait evaluation and initialization logic.
