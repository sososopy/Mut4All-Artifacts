Mutation Operator: Remove type from a function parameter declaration in a function definition or declaration, leaving the parameter name intact but omitting its type.  
Applies to: Function parameters with explicit type declarations in C/C++ function signatures.  
Example: Transform `void example(int a)` into `void example(a)`.  
Rationale: Triggers compiler error recovery for invalid parameter lists by creating a parameter without a type. This mimics the bug report’s `main` function with an invalid parameter (e.g., `int main(b)`). Existing parameters are targeted to ensure compatibility with seed programs. No new variables or types are introduced; only the type is removed from an existing valid declaration.
