mutation operator: RequiresFoldExpansion
Target code: A requires clause that uses a fold expression over a parameter pack within a template constraint.
Applicable when: A requires expression contains a parameter pack expansion via a fold operator (e.g., `(... && expr)` or `(expr && ...)`).
Mutation method: Replace the fold expression with a nested requires expression that replicates the same logical constraint but requires separate instantiation of each pack element.
Example: 
Original code:
requires requires (...) { (expr && ...) ? ... : ... };
Mutated code:
requires requires (...) { (expr <0> ? expr <1> ? ... ? expr <N-1> ? ...) ? ... : ... };
This forces sequential evaluation of each pack element in a requires clause, increasing template instantiation depth and potentially exposing bugs in parameter pack expansion during constraint checking.
