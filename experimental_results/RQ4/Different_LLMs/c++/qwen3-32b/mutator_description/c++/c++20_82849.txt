Mutation operator: TriggerConceptLambdaInDependentContext  
Applies to template functions that could evaluate a concept in their body.  
Modifies an existing concept (if none exists, introduces one with a requires clause containing a lambda) and evaluates it within a template function's dependent context (e.g., as a standalone statement in the function body rather than as a constraint).  

Example transformation:  
Original code (simplified):  
```cpp  
template <typename T>  
void foo() {  
  // existing code  
}  
```  

Mutated code:  
```cpp  
template <typename>  
concept C = requires {  
  [] {};  
};  

template <typename T>  
void foo() {  
  // existing code  
  C<T>;  // evaluated in a dependent context  
}  
```  

Change steps:  
1. If no concept exists in the translation unit, declare a new concept with a requires clause containing a lambda.  
2. In an existing template function, add a statement that evaluates the concept with the template parameter in a non-constant-evaluation context (e.g., `C<T>;`).  
3. Ensure the concept's requires clause includes a lambda (as in the bug report's minimal case) to trigger the assertion.  

Avoids introducing new variables or types beyond the concept declaration. Reuses the template parameter from the target function.
