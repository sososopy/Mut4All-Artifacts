Mutation operator: Invert SFINAE condition in template parameter. Apply to template parameters using std::enable_if or similar SFINAE-based conditions. For example, change `std::enable_if_t<Cond>` to `std::enable_if_t<!Cond>` in a template argument list. This forces substitution failure during template instantiation, which may trigger assertion failures in the compiler's access control or template deduction logic. Use existing boolean-type expressions from the seed program (e.g., replace `Cond` with `!Cond` without introducing new variables). Example:  
Original: `template<typename T, typename = std::enable_if<sizeof(T) < 4>>`  
Mutated: `template<typename T, typename = std::enable_if<!sizeof(T) < 4>>`
