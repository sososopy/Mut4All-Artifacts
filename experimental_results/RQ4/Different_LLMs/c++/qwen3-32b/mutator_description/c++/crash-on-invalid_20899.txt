Mutation operator: Replace a valid dependent type condition in `enable_if` with an invalid dependent type that is not defined in the template parameter. Apply to any template method or function where the return type or parameter uses `enable_if` with a condition that depends on a nested type or member of a template argument. Use existing types and variables in the seed program to construct the invalid condition. 

Example:  
Original code:  
`static typename enable_if<Foo<T>::bar, void>::Type method()`  

Mutated code:  
`static typename enable_if<Foo<T>::undefined_member, void>::Type method()`  

This introduces an invalid nested type (`undefined_member`) in the condition, which the compiler must evaluate during template instantiation. The crash occurs if the compiler attempts to process this as a valid type during error recovery.

If no such class exists, declare a new empty class `Foo` in the global scope and apply the mutation. This ensures the compiler handles undefined dependent types in template conditions, exposing bugs during type checking.
