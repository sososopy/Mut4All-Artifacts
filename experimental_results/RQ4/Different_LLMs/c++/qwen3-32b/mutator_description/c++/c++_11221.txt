Mutation operator: Modify a class template partial specialization by altering the kind of a template parameter (e.g., from type to non-type or vice versa) in the specialization's parameter list. Apply this to any existing class template with at least one partial specialization.  

Example: Given a class template declared as `template <typename T, int N> class X;` with a partial specialization `template <int N> class X<int, N>;`, change the partial specialization's first parameter to a type parameter:  
`template <typename U, int N> class X<U, N>;` (only valid if the original template uses `int` as a parameter). This creates an invalid or conflicting partial specialization pattern that may trigger parser/semantic analysis code paths vulnerable to assertion failures like the one described.  

This mutation leverages existing template structures and modifies parameter kinds to expose handling of template argument deduction and specialization validation in the compiler.
