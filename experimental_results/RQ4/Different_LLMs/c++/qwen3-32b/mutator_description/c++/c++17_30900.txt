Mutation operator: Change an existing enum declaration to a forward-declared enum with underlying type bool and add a static_assert that applies a type trait for non-enum types (e.g., std::is_function) to the enum.

Example:
Original code:
enum E { A, B };
...

Mutated code:
enum E : bool;
static_assert(!std::is_function<E>::value, "");
...

Applies to: Any enum declaration in the seed program. The mutation replaces the enum definition with a forward declaration (no enumerators) and adds a type trait check expecting a different type category. The static_assert is inserted in the same scope as the enum declaration.

Changes needed: Rewrite enum declaration as forward-declared with underlying type bool. Introduce a static_assert in the nearest enclosing namespace or global scope, using existing or standard type traits.
