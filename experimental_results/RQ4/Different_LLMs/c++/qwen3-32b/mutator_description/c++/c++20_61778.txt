Mutation Operator: ConstrainedOverloadWithExplicitInstantiation
Targets code with a class template member function by adding a constrained overload and an explicit instantiation that may conflict with the overload.
Example: For a class template class T { void m(); }, insert void m() requires C<T>(); and template void T<int>::m(); where C is a concept present in the seed program.
Changes: Add a constrained member function overload using an existing concept, then add explicit instantiation for a type that does not satisfy the concept. This creates an overload resolution scenario during explicit instantiation that may trigger compiler bugs in handling constrained functions.
