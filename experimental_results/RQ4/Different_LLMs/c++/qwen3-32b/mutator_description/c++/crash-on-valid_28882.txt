Mutation Operator: ShadowTagInControlFlow  
Applies to: control structures (e.g., for/while loops) where a variable is declared using a typedef name.  
Description: Replace the declaration of a loop variable with a struct/union tag declaration using the same name as an existing typedef, creating a shadowed tag. This forces the compiler to resolve conflicting name scopes during control flow parsing.  

Example:  
Original code:  
```c  
typedef int MyType;  
void foo() {  
  for (MyType x = 0; x < 10; x++) {}  
}  
```  

Mutated code:  
```c  
typedef int MyType;  
void foo() {  
  for (struct MyType { float f; } x; x < 10; x++) {}  
}  
```  

Requirements:  
1. The typedef must exist in the same scope.  
2. The control structure must have a variable declaration using the typedef.  
3. The struct/union declaration must use the same name as the typedef.  
4. No new functions/types are introduced—only reuse existing typedef names.  

Effect: Triggers name resolution conflicts between tags and typedefs during control flow parsing, exposing assertion failures in tag completeness checks.
