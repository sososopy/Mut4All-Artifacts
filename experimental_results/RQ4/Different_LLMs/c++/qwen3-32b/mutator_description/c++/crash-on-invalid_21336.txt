mutation operator: Replace a valid default argument expression in a templated function/method with a nested function call that involves an undefined function and a parameter reference from the outer scope. Apply within templates to test error handling of invalid default arguments.  
Example: If original code has `void f(int k = 5);`, mutate to `void f(int k = unknown(k)());` where `unknown` is not declared. This forces the compiler to evaluate a recursive or undefined expression in the default argument context of a template.  

mutation operator: Substitute a simple default argument in a templated class member function with a function call that returns a function object, followed by an immediate invocation. Apply to template member functions to stress-check syntactic parsing of complex default expressions.  
Example: If original code has `void m(T x = 0);`, mutate to `void m(T x = helper(x)());` where `helper` is not declared. This creates a chain of dependent invalid expressions within a template's default argument.
