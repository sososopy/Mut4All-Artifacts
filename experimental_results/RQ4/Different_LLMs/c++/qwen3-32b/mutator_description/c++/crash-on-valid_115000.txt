Mutation operator: Add a `__attribute__((target_version("X")))` to function declarations, where X is a target-specific feature flag not supported by the current architecture.  
Applies to: Any function declaration without an existing `target` or `target_version` attribute.  

Example:  
Original:  
`void foo() { }`  

Mutated:  
`__attribute__((target_version("aes"))) void foo() { }`  

Rationale: This exploits the compiler's internal validation of multiversion attributes. When applied to a target (e.g., AArch64) that does not support the specified feature (e.g., "aes" for x86), it may trigger assertions or invalid state checks during semantic analysis (as seen in the bug report). The mutation uses existing functions and introduces a known target-specific feature flag, forcing the compiler to evaluate cross-architecture compatibility checks.  

Changes required:  
1. Select a function declaration from the seed program.  
2. Add `__attribute__((target_version("X")))` before its return type.  
3. Replace X with a feature flag (e.g., "avx2", "neon", "sve") incompatible with the current compilation target.  

This mutation targets the compiler's handling of multiversion function attributes and ensures coverage of target-specific validation logic, likely exposing bugs in cross-target compatibility checks.
