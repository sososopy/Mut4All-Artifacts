Mutation operator for constrained template CTAD with lambda concept checks:  
Applies to class templates using CTAD with constrained template parameters that involve a requires clause using a lambda or function object. Replace a direct CTAD instantiation with a constrained version that includes a concept requiring substitution into a lambda that accesses template parameters. Example:  

Original (CTAD without constraint):  
MyClass inst(Arg{});  

Mutated (CTAD with concept involving lambda):  
template<typename T>  
concept MyConcept = requires(T t) {  
    []{ T::member; }();  
};  
MyClass<MyConcept<Arg>> inst(Arg{});  

This stresses constraint substitution during CTAD by forcing the compiler to evaluate a lambda in the concept that depends on deduced template parameters, similar to the std::format crash path.
