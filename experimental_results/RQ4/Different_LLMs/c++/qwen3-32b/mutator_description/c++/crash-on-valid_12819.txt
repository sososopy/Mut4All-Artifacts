Mutation Operator: Inline Function Expansion in Template Instantiation
Target: Template instantiated functions with inline candidate attributes
Applies to: Function definitions within template classes or functions where the compiler applies inlining heuristics
Mechanism: 
- For each template-instantiated function marked as inline or having a 'always_inline' attribute
- Insert a nested function call to itself with modified parameters in the current function body
- Maintain the same return type and parameter signature
- Example transformation: 
Original:
void foo(int x) { process(x); }
Mutated:
void foo(int x) { 
    int y = x + 1;
    foo(y); 
    process(x);
}
- Ensures the function becomes a recursive call chain that the X86 instruction selector must process
- Creates complex call graphs that stress the DAG optimization passes
- Preserves original function signature and return type
- Avoids introducing new variables beyond existing ones in the function scope
