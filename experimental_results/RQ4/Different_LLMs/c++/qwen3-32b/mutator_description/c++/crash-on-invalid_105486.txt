Mutation operator: Invalid dereference in constant expression evaluation  
Apply to any constant expression context where a valid value is directly used (e.g. primitive literals, simple variable references, or arithmetic expressions). Replace the expression with a dereference of a non-pointer type (e.g. *42 or *0) while preserving the outer const/constexpr declaration. This forces the compiler to evaluate an invalid expression during constant folding.  

Example:  
Original:  
const int x = 100;  
Mutated:  
const int x = *0;  

Another example:  
Original:  
constexpr long y = a + b;  
Mutated:  
constexpr long y = *1;  

This mutation leverages existing variables (a, b) or literals while introducing a non-pointer dereference. The compiler's constant evaluator may crash when attempting to convert a value-dependent or non-pointer expression to an integer.
