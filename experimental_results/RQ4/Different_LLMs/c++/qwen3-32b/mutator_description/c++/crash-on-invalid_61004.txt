Mutation operator: Replace non-constexpr copy assignment operators with a constexpr deleted copy assignment operator. Apply to any class-type that already has a user-defined or defaulted copy assignment operator.  

Example:  
Original structure:  
class A { A& operator=(const A&); };  

Mutated structure:  
class A { constexpr A& operator=(const A&) = delete; };  

Changes:  
1. Add `constexpr` to copy assignment operator  
2. Add `= delete` to the operator declaration  
3. Preserve the parameter type (const class reference) and return type (reference to class) from the original declaration  

The mutation leverages existing class assignment operators while introducing the conflicting constexpr=delete combination that can trigger compiler crashes. The operator signature elements (parameter/return types) are derived from the original class members to ensure syntactic validity. This targets the same frontend parsing path as the original bug while varying the context across different program structures.
