Mutation Operator: Insert a requires clause in a nested lambda with pack expansion using parameters from the outer lambda. Apply to lambdas that return another lambda and have at least one parameter. Add a requires clause in the inner lambda that references the outer lambda's parameters as a pack in a requires expression. For example, transform a lambda returning a lambda with `[](auto y) { return [](...) { ... }; };` into `[](auto y) { return [](auto... params) requires requires { y.size(params...); } { return false; }; };`. Use existing parameters like `y` from the outer lambda as the basis for the pack expansion in the inner requires clause.
