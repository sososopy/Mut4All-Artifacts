Mutation operator: InvalidAnonymousNamespaceInFunction  
Applies to any function body in a C++ class or standalone function.  
Insert an anonymous namespace declaration directly inside the function body (within its curly braces), violating C++ rules that restrict anonymous namespaces to file scope.  

Example:  
// Original  
void func() {  
   int x = 42;  
}  

// Mutated  
void func() {  
   namespace {  
      int y = 0;  
   }  
   int x = 42;  
}  

This mutation creates an invalid program structure by using an anonymous namespace in a context where it is not allowed. The compiler must correctly handle this error without crashing during semantic analysis of the function body. The operator avoids introducing new types/variables beyond the namespace itself, relying on existing program structure.
