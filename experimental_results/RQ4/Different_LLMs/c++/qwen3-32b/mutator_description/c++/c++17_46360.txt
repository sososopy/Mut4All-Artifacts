Mutation Operator: Replace move capture with value capture in lambda expressions  
Description: Targets lambdas with move captures (e.g., [l = std::move(x)]) and replaces them with value captures ([l = x]). This alters the type of the captured variable (e.g., from a forwarding reference to a direct copy), potentially exposing compiler bugs related to decltype/declval interactions when the captured type differs from the source. Applies to any lambda that captures a variable via std::move.  

Example:  
Original code:  
auto lambda = [x = std::move(var)]() { return x; };  

Mutated code:  
auto lambda = [x = var]() { return x; };  

This mutation preserves existing variable names and types but changes the capture strategy, potentially triggering different code paths during template instantiation or type deduction, especially in nested contexts involving decltype and declval.
