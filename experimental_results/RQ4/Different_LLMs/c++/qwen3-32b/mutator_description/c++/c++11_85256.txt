Mutation operator: Alter the order of base class initializers in a constructor's initializer list.  
Applies to: Class constructors with multiple base class initializers in the constructor's initializer list.  
Example:  
Original code:  
```cpp  
struct Derived : BaseA, BaseB {  
    Derived() : BaseA(), BaseB() {}  
};  
```  
Mutated code:  
```cpp  
struct Derived : BaseA, BaseB {  
    Derived() : BaseB(), BaseA() {}  
};  
```  
This mutation breaks the expected order of base class initialization checks in the compiler's constant evaluation, exposing assertion failures during constructor analysis.
