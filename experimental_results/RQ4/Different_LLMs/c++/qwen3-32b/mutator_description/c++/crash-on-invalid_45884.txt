Mutation Operator: Duplicate nested class/enum in inline namespace  
Applies to any existing inline namespace or outer scope containing a class/enum declaration.  
Inserts a nested class with the same name as an outer declaration inside an anonymous struct or inline namespace.  
Example:  
Original code:  
struct Outer { };  
inline namespace N { enum E {}; }  

Mutated code:  
struct Outer { struct Outer {}; };  
inline namespace N { struct N {}; }  

Mutation Operator: Conflicting anonymous struct inheritance  
Applies to any struct/union/class with an ancestor declaration.  
Replace the inheritance clause with an anonymous struct containing a duplicate name conflict.  
Example:  
Original code:  
struct Base { };  
struct Derived : Base { };  

Mutated code:  
struct Base { };  
struct Derived : struct { struct Base { }; } { };  

Mutation Operator: Inline namespace with duplicate typedef  
Applies to any inline namespace containing a class/enum.  
Add a typedef with the same name as an existing class/enum inside the inline namespace.  
Example:  
Original code:  
inline namespace M { class X {}; }  

Mutated code:  
inline namespace M { class X {}; typedef X X; }  

Mutation Operator: Nested enum-class in same scope  
Applies to any existing enum declaration.  
Create an outer enum with the same name as an inner enum when the outer is in a different scope.  
Example:  
Original code:  
enum E { A };  
namespace N { enum class E { B }; }  

Mutated code:  
enum E { A };  
namespace N { enum class E { B }; enum E { C }; }  

Mutation Operator: Ambiguous template parameter  
Applies to any template class/struct declaration.  
Add a template parameter with the same name as an enclosing class/namespace.  
Example:  
Original code:  
struct S { template<typename T> class A {}; };  

Mutated code:  
struct S { template<typename S> class A {}; };
