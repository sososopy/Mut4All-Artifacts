mutation operator: Replace bitwise OR of 'using enum' values assigned to an int with a cast to the enum type.  
Applies to: Expressions where the result of a bitwise OR on 'using enum' values is assigned to an int variable.  
Example transformation:  
Original: int i = (A | B);  
Mutated:  Things i = (A | B);  
Or, if the enum requires explicit casting:  
Mutated:  Wrap::Things i = (Wrap::Things)(A | B);  
This forces the compiler to handle the enum type context, potentially exposing bugs in type resolution during operator overloading after 'using enum'.
