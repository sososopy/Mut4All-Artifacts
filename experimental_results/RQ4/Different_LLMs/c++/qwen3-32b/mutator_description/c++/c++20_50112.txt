Mutation Operator: Replace Non-Constant Template Argument with Variable  
Target: Function templates with non-type template parameters expecting a constant expression  
Action: For any template argument in a function template instantiation that is a valid constant expression, replace it with a non-constexpr variable name from the same scope. This forces substitution failure during template argument substitution (SFINAE) and may trigger compiler bugs in error recovery paths.  

Example:  
Original:  
template<int N>  
void process() { /* ... */ }  
int main() {  
    process<42>();  
}  

Mutated:  
int x;  
template<int N>  
void process() { /* ... */ }  
int main() {  
    process<x>();  
}  

This mutation leverages existing variable 'x' (non-constexpr) to create an invalid template argument. If the compiler crashes during substitution instead of producing a well-formed diagnostic, it indicates a bug similar to the reported issue.
