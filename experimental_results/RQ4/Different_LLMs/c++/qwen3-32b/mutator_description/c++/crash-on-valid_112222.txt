Mutation operator: Add trailing requires clause with template parameter condition to out-of-class member function in templated class. Apply to any member function defined outside class body in a templated class that lacks a requires clause. Modify both declaration and definition. Use existing template parameters in requires condition.

Example pseudo-code transformation:
Original:
template<typename T>
class MyClass {
public:
    void myFunc();
};

template<typename T>
void MyClass<T>::myFunc() {
    // ...
}

Mutated:
template<typename T>
class MyClass {
public:
    void myFunc() requires (sizeof(T) > 0);
};

template<typename T>
void MyClass<T>::myFunc() requires (sizeof(T) > 0) {
    // ...
}
