Mutation operator: NOEXCEPT_MACRO_EXPANSION
Target: function templates using noexcept specifications with macro expansions
Description: Replace a simple noexcept condition with a macro that expands to a complex expression involving std::declval() on an existing type parameter. This tests compiler handling of unevaluated expressions in exception specifications, potentially exposing bugs in template substitution and constant expression validation logic.
Example: 
Original code:
template<typename T>
void func(T t) noexcept(std::is_same<T, int>::value) {}

Modified code:
template<typename T>
void func(T t) noexcept(NOEXCEPT_MACRO(std::declval<T>().nonconstexpr_method())) {}

Where NOEXCEPT_MACRO is defined as:
#define NOEXCEPT_MACRO(x) x
