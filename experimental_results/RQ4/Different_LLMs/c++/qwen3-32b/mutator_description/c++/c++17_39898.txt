Mutation operator: DeductionGuideAsMemberMutation  
Target code construct: Class template deduction guides defined as member functions within another class template or struct.  

Apply to: Any class template (e.g., `Person`) with an associated deduction guide (`Person(...) -> Person<Type>`) that can be relocated into a nested scope.  

Modification steps:  
1. Locate a deduction guide for a class template (e.g., `Person(const Type& object) -> Person`) declared in the same scope as the primary template.  
2. Move this deduction guide into the definition of another class (e.g., `CPerson`) as a member function.  
3. Ensure the moved deduction guide retains its signature but is now nested within a different class scope.  

Example pseudo-code:  
Original:  
```cpp  
template <typename T> struct A {};  
A(T&) -> A<U>;  // Deduction guide in same scope as A  
struct B { /* ... */ };  
```  
Mutated:  
```cpp  
template <typename T> struct A {};  
struct B {  
    A(T&) -> A<U>;  // Deduction guide as nested member  
};  
```  

Rationale: The compiler must validate that deduction guides are only declared in the same scope as their primary template. This mutation exposes bugs where the compiler fails to reject or incorrectly accepts deduction guides in invalid contexts (e.g., nested classes).  

Applicability: Seed programs with at least two class templates or a class template and a non-template class. New elements not required.
