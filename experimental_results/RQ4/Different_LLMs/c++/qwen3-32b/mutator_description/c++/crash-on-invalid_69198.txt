Mutation operator: OpenMP-ArraySection-Negative
Apply to: Array declarations with OpenMP directives referencing the array in depend clauses
Action: Replace a valid array size with a negative literal in the array declaration. In an existing OpenMP directive using this array, modify the depend clause to use multiple colons in the array section notation.
Example:
Original:
int arr[10];
#pragma omp task depend(inout: arr)

Mutated:
int arr[-1];
#pragma omp task depend(inout: arr[:][:])

Requires: Array and OpenMP directive already exist in seed program. No new declarations needed.
