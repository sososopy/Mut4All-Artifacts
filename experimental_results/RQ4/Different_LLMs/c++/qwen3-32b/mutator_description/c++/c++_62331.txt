Mutation Operator: TemplateMemberFunctionDefaultArgMismatch
Target construct: Member function templates in class templates with default arguments and their specializations
Applies to: Class templates with member function templates having default arguments and explicit specializations

Modifies: Presence of default arguments in primary template vs specializations

Example transformation:
Original:
template <typename T>
class C {
    void f(T = T());
};
template<>
void C<int>::f(int) {}

Transformed:
template <typename T>
class C {
    void f(T); // Removed default argument from primary template
};
template<>
void C<int>::f(int = int()) {} // Added default argument to specialization

This creates a discrepancy between the primary template and specialization regarding default arguments for the same function. The compiler must correctly handle which default arguments are applied during template instantiation and function resolution. This mismatch exposes bugs in how compilers manage template argument deduction and default parameter handling across template specializations.
