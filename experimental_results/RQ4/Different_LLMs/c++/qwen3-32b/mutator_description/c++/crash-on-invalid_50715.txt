Mutation Operator: Replace a struct/union/array initializer's compatible type with an incompatible type, targeting static or global declarations. Apply to existing array or struct initializers where the original type is scalar (e.g., int, float, pointer) or fixed-size array. Replace one or more elements with values of a different scalar category (e.g., integer → floating-point, floating-point → pointer, array → non-array). For example, change "int x[] = {5};" to "int x[] = {3.14};" or "int y[2] = {1, 2};" to "int y[2] = {0, &x};". This forces type-checking logic to handle invalid conversions, exposing crash paths in error handling.
