Mutation operator: Replace a type alias template usage with a static member access that is a value instead of a type in template contexts. Apply this to any template type alias (using/typedef) that references a struct/class with a static const member. For example:  
Original: `template <typename T> using A = typename X<T>::Y;`  
Mutated: `template <typename T> using A = X<T>::v;`  
Where X<T> is a class template with `static const T v = 0;` and Y is a type alias. This forces the compiler to treat a value as a type during template instantiation, exposing type resolution bugs. The mutation applies to type alias templates, static member accesses, and template argument substitutions. Example in natural language: Replace each occurrence of `typename ClassName::TypeAlias` with `ClassName::v` where `v` is a static const member of the same class.
