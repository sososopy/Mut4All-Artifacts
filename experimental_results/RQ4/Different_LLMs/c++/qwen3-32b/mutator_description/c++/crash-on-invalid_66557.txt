Mutation operator: Replace simple constructor calls with nested template instantiations involving paren list expressions.  
Applies to: Any function call, constructor, or brace-initialized expression using a base type.  
Example:  
Original code:  
A a = A(42);  

Mutated code:  
template<typename T, typename U> struct X { X(T(), U()) = delete; };  
A a = X<int, B>(42, B{});  

Effect: Forces template instantiation with paren list expressions in contexts where type deduction may fail, increasing path length through template instantiation chains and stressing the dependence analyzer. The mutation uses existing types A and B from the seed program.  

Mutation operator: Introduce variadic template parameters in function templates with paren list parameters.  
Applies to: Non-variadic function templates with at least one non-type parameter.  
Example:  
Original code:  
template<typename T> void f(T x) { }  

Mutated code:  
template<typename T, typename... U> void f(T x, U... args) { }  

Effect: Creates complex type lattices during instantiation that may trigger ICEs in template argument substitution. Uses existing template T from the seed program.  

Mutation operator: Convert single-type alias templates to nested alias templates with paren list dependencies.  
Applies to: Type alias templates using simple type mappings.  
Example:  
Original code:  
template<typename T> using A = T*;  

Mutated code:  
template<typename T> using A = decltype(T(0));  
template<typename T> using B = A<decltype(T())>;  

Effect: Creates recursive type dependency chains requiring paren list analysis, increasing template instantiation depth. Uses existing type T from the seed program.
