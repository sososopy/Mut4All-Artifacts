Mutation operator: Replace non-empty initializer list with empty initializer list for nested container types.  
Applies to variable declarations where the declared type is a container (e.g., std::array, std::vector, std::map) containing another container type. Mutation replaces any initializer list (e.g., {1,2,3}) with empty braces { }, even if the original code provided element values.  

Example:  
Original:  
std::vector<std::unordered_map<int, int>> v = { { {1,2} }, { {3,4} } };  

Mutated:  
std::vector<std::unordered_map<int, int>> v = {};  

The mutation ensures the outer container is initialized with an empty list while retaining the existing nested container type structure. Targets compiler handling of empty initialization sequences for complex type hierarchies.
