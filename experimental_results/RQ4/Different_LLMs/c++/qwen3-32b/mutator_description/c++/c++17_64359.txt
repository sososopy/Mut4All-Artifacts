Mutation Operator: TemplateLambdaNestedReturn  
Target: Function templates with simple return types that can be replaced with nested templates involving lambdas.  
Applies to: Function templates where the return type is a base type or simple template.  
Changes: Replace the return type of a function template with a lambda that returns a nested template instantiation using the original template parameters.  
Example:  
Original:  
template<typename T>  
T func(T x) { return x; }  

Mutated:  
template<typename T>  
auto func(T x) {  
  return [x](T y) -> typename std::vector<typename std::map<T, T>::value_type>::size_type {  
    return y.size();  
  }(x);  
}  
This introduces a lambda with a nested template return type (vector<map<T,T>::value_type>::size_type) using the same template parameter T, creating complex substitution chains.
