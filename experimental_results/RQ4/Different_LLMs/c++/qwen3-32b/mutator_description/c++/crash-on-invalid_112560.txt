Mutation operator: Add incomplete in-class initializer to union member  
Target code construct: Unions with non-static data members  
Applies to any union declaration containing at least one field that lacks an in-class initializer  

Transformation steps:  
1. Select an existing union declaration  
2. Choose a non-static data member (preferably of scalar or simple type)  
3. Modify the field declaration by appending " = ;" to create an incomplete initializer  
4. Ensure the modified union remains syntactically valid except for the malformed initializer  

Example transformation:  
Original code:  
union U {  
  int f;  
};  
void foo() {  
  U g{};  
}

union U {  
  int f = ;  // Incomplete initializer  
};  
void foo() {  
  U g{};  
}
