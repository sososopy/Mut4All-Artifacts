Mutation operator: Variant with inherited struct and reference member  
Target code construct: std::variant containing a base struct and a derived struct with a reference member  
Applies to: Code with existing structs and variant usage  

For any pair of existing structs S and T where T is a base class of S:  
- Add a non-static data member of reference type to S (e.g., int& x)  
- Create a variant that contains both S and T  
- Initialize the variant with a temporary of type T using brace initialization  

Example mutation:  
Original code with existing structs A and B (B inherits from A):  
std::variant<A,B> v = A{};  

Mutated code:  
struct A {};  
struct B : A {  
    int& x;  
};  
std::variant<A,B> v = A{};  

This exploits the interaction between non-static reference members in derived classes and variant construction by default initialization, which is known to trigger the compiler's internal error in template instantiation. The mutation can be applied to any existing struct hierarchy with variant usage, using the seed program's existing types where possible.
