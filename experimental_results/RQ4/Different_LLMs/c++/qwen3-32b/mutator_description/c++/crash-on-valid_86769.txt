Mutation Operator 1: Add concept-constrained friend declarations in template classes  
Target construct: Class templates with friend declarations in their bodies.  
Applies to: Existing class templates that already contain friend declarations (class or function) and co-located concepts (e.g., `concept X = ...`).  
Changes required: Modify a friend declaration inside a class template to add a concept constraint on its template parameter.  
Example:  
Original code:  
```cpp  
template <typename T>  
class MyClass {  
    friend class MyFriend;  
};  
```  
Mutated code:  
```cpp  
template <typename T>  
class MyClass {  
    template <MyConcept U>  
    friend class MyFriend;  
};  
```  
Note: `MyConcept` must be an existing concept defined in the seed program. If no concept is present, this mutation is inapplicable. The change introduces a constrained template parameter in the friend declaration, forcing constraint evaluation during template instantiation and potentially exposing bugs in dependent expression handling.
