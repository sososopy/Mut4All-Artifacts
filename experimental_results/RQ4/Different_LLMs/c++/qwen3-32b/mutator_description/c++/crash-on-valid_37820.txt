Mutation operator: Replace switch condition with a variable of a type having a non-const conversion operator to an enum, and use enum members directly in case labels without explicit cast.  
Applies to switch statements where the condition is a user-defined type with a conversion to an enum, and case labels reference enum values without explicit casts.  
Example: Change  
switch (static_cast<Enum>(m_enumMember))  
to  
switch (m_enumMember)  
and keep case SomeValue: ...  
This forces evaluation of the conversion operator in a context requiring a constant expression, exposing cases where the compiler improperly handles the conversion.
