Mutation Operator: TemplateInheritanceWithConstraint
Applies to a non-templated struct/class with a default constructor
Transforms:
Original struct:
struct X { X(); };

Mutated struct:
template<typename T>
struct X {
  X() requires (IsSame<T, int>);
};

template<>
struct X<void> : public X<int> {
  using X<int>::X;
};

Requirements:
1. Must exist in same scope as existing IsSame trait
2. Must not conflict with existing template specializations
3. For existing types, T must be a type parameter present in the original declaration

Example application:
Given:
struct A { A(); };

Replace with:
template<typename T>
struct A {
  A() requires (IsSame<T, int>);
};

template<>
struct A<void> : public A<int> {
  using A<int>::A;
};
