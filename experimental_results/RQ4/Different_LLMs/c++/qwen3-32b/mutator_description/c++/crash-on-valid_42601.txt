Mutation Operator: ReturnStdStringViewSubstr
Applies to functions that return std::string values and have a valid local std::string variable in scope.
Transforms return statements for string values into returning a std::string_view of a substring.
Example: Change return s; to return std::string_view(s.substr(0,3)); in functions that originally return std::string.
Requires existing std::string variable in function scope and includes necessary #include <string_view> directive.
Targeted at C++17 code using libstdc++ where string_view parsing triggers crashes during function return value handling.
