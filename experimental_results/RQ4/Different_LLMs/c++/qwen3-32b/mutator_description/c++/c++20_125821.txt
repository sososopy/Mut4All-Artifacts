Mutation operator: CTAD_alias_template_chain.  
Target: Template structs with constructors and alias templates in the seed program.  

Action:  
When a seed program contains a template struct `S<T>` with a constructor that accepts a `T` argument, and an alias template `Proxy<T> = T` exists, introduce a new alias template `C<T> = Proxy<S<T>>`. Then, in a function (e.g., `main`), declare a variable of type `C` using CTAD by passing a constructor argument (e.g., `C obj{ arg };`).  

Example (pseudo-code transformation):  
```cpp  
// Original struct in seed program  
template<typename T>  
struct S {  
    S(T);  
};  

// Existing alias in seed program  
template<typename T>  
using Proxy = T;  

// Mutation adds this alias  
template<typename T>  
using C = Proxy<S<T>>;  

// Mutation adds this code in a function  
C obj{ some_value };  
```  

This mutation triggers complex CTAD logic involving nested alias templates, which is likely to expose bugs in compilers handling template argument deduction for alias chains.
