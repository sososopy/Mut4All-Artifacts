Mutation Operator: Change the first parameter of a member operator delete from a non-class type to a user-defined class type existing in the same translation unit.  
Applies to: Member operator delete declarations where the first parameter has a built-in type or a class type different from the enclosing class.  
Example:  
Original code:  
struct A { void operator delete(size_t); };  
Mutated code:  
struct A { void operator delete(B); }; // assuming struct B is already declared in the same program.  
Change involves replacing the size_t parameter with a user-defined class type B from the existing seed program.  
Requires: A declared class type B exists in the same scope. No new types are introduced. The mutation uses existing type names from the program.  
Effect: Triggers compiler code paths handling member operator delete parameters, potentially exposing parsing or semantic analysis bugs related to class-type parameters.
