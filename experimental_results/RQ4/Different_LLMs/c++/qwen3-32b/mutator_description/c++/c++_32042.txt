Mutation Operator: Add a static const member to a class template using an existing type from the class  
Applies to class templates lacking a static const member declaration  

Mutation Steps:  
1. Locate a class template in the seed program that does not already contain a static const member  
2. Insert a static const member declaration inside the template class body using an existing type from the class (e.g., a member variable's type)  
3. Do not provide an initializer for the static const member in the class declaration  

Example:  
Original code:  
```cpp  
template<typename T>  
class Container {  
    T data[16];  
};  
```  

Mutated code:  
```cpp  
template<typename T>  
class Container {  
    T data[16];  
    static const int capacity;  
};  
```  

Key characteristics:  
- Targets template class scope  
- Uses existing type from class (int in example, derived from array size)  
- Triggers compiler's template instantiation logic for static members  
- Avoids introducing new types/variables beyond program's existing structure
