Mutation operator: RequiresClauseNesting 
Target code construct: Lambda or function declarations with requires clauses that evaluate constraints based on existing parameters or expressions. 
Applies to any lambda or function with a requires clause that can be modified by adding nested requires conditions. 
Example: 
Original: 
[](auto... args) requires requires { expr; } { ... }

Mutated: 
[](auto... args) requires (requires { inner_expr; } && requires { expr; }) { ... }

Where inner_expr uses existing parameters from the lambda/function and expr is an existing constraint. This increases nesting depth and complexity of constraint evaluation, stressing the compiler's constraint satisfaction logic during template instantiation.
