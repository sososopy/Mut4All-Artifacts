Mutation Operator: Introduce a new template parameter in a template alias and set the default argument of an existing parameter to a type that depends on the new parameter. Apply to template aliases with non-dependent default arguments. Replace the default type with a dependent type using the new parameter, e.g., change `template <typename T2 = T> using A = ...;` to `template <typename U, typename T2 = typename U::type> using A = ...;` where U is a new template parameter. This forces substitution of a dependent default type during instantiation, exposing bugs in template argument substitution logic for partial specializations.
