Mutation operator: Add a templated call operator to an existing callable type, forcing template argument deduction during constructor invocation. Apply this to any class, struct, or lambda with a non-templated call operator used as a constructor argument in new-expression syntax. Replace `operator()(ArgType args)` with `template<typename T> operator()(T args)`. Example: Change a class's `operator()(int x)` to `template<typename T> operator()(T x)` to simulate a callable requiring template parameter deduction when passed to a constructor. This mutation targets class template argument deduction (CTAD) in constructor calls involving templated callables, directly exposing compiler crashes in template instantiation chains.
