Mutation Operator: GenericLambdaCaptureMisuse
Apply to template functions that use a lambda as an argument parameter. Replace a non-generic lambda with a generic lambda (auto parameters) or vice versa, while maintaining the same capture scope and template instantiation structure. This exploits compiler logic for tracking capture-ready lambdas in template contexts.

Example:
Original code pattern:
template<typename T>
void visit(T value) {
    void(*Func1)(int) = [](int x) { /* code */ };
    void(*Func2)(int) = [](int x) { /* code */ };
    some_method(Func1, Func2);
}

Mutated content:
template<typename T>
void visit(T value) {
    void(*Func1)(auto x) = [](auto x) { /* code */ }; // Generic lambda
    void(*Func2)(auto x) = [](auto x) { /* code */ }; 
    some_method(Func1, Func2);
}

This mutation preserves the template structure and variable names while altering the lambda's genericity, directly targeting the assertion in SemaLambda.cpp. When the compiler processes the template instantiation, it must correctly identify whether lambdas with auto parameters are generic and adjust capture scope tracking accordingly.
