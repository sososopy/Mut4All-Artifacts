Mutation operator: Template reference mismatch in function call
Applies to function calls that use variadic templates with rvalue references. For any such function call in the program, modify the arguments to pass lvalue expressions where rvalue references are expected.

Example:
Original code:
template <typename... Ts> void foo(Ts&&... args);
void bar(int i) { foo(0, i); }

Mutated code:
void bar(int i) { foo<int, int>(0, i); }

Change involves:
1. Explicitly specifying template arguments matching the number of parameters
2. Forcing rvalue reference parameters to bind to lvalue arguments
3. Triggering overload resolution for template functions

This mutation creates invalid template instantiations that expose parser/semantic analysis bugs during overload resolution. It works with existing variables in the seed program without introducing new declarations, and can be applied to any function call with variadic template parameters.
