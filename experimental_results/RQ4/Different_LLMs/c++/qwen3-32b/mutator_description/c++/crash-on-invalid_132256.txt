MutationOperator: MisplacedCxxAttributeOnDefaultTemplateArg
Applies to function templates with a default template argument. Insert an attribute (e.g. [[deprecated]] or [[nodiscard]]) immediately preceding or appended to the default argument in the template parameter list, creating an invalid syntax position. This triggers parser confusion during template argument parsing when combined with default arguments. Example: Change 
template <typename T = int> void func() { ... }
to 
template <typename [[deprecated]] T = int> void func() { ... } 
or 
template <typename T = [[deprecated]] int> void func() { ... }

MutationOperator: MalformedForRangeWithTemplateDefault
Applies to for-range loops where the range expression uses a type defined via template parameter with default argument. Replace the range expression with a malformed type derived from the template's default argument. Example: In 
for (auto x : createRange<T>()) { ... }
modify to 
for (auto x : createRange<typename T::InvalidMember>()) { ... } 
where T is a template parameter with a default type (T = SomeType), creating invalid nested name access in the for-range expression. Ensure used identifiers match existing declarations in seed program.
