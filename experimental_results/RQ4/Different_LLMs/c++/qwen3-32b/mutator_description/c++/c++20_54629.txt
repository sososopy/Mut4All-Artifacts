Mutation Operator: Replace a constraint in a constrained template specialization's 'requires' clause with an altered relational condition. Apply to any specialization with 'requires' that uses a comparison involving a type-checked expression (e.g., sizeof). Example: Change 'requires sizeof(t) > 4' to 'requires sizeof(t) < 4' in the 'requires' clause of a partial template specialization, using existing expressions from the seed program. This forces the compiler to re-evaluate constraint satisfaction logic, potentially exposing bugs in template instantiation with concepts.
