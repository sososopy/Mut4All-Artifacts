Mutation Operator: Introduce Dependent Default Argument in Template Alias  
Applies to: Template aliases with non-dependent default arguments in their parameter lists.  
Action: Replace a non-dependent default argument with a new parameter that depends on an existing template parameter. The new parameter must be marked with a default value referencing an existing template parameter.  

Example:  
Original seed code:  
template <typename T>  
using Foo = Bar<T, int>;  

Mutated code:  
template <typename T, typename U = T>  
using Foo = Bar<T, U>;  

Coverage Notes:  
- Targets template alias substitution logic in compilers.  
- Requires existing template parameters (e.g., T) for dependency.  
- Valid for any seed program with template aliases that have at least one non-dependent default argument and two template parameters.  

Implementation Details:  
1. Select a template alias with a default argument (e.g., `Bar<T, int>`).  
2. Identify an existing template parameter (e.g., `T`).  
3. Add a new parameter (e.g., `U`) with a default value derived from `T`.  
4. Replace the non-dependent default argument (e.g., `int`) with the new parameter.  
5. Ensure the mutated code remains syntactically valid by retaining existing types and parameters.  

This mutation forces substitution of dependent default arguments in template aliases, mimicking the bug-triggering scenario in the report.
