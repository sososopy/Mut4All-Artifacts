mutation operator: Convert namespace definitions to invalid namespace-alias declarations by replacing their body with a semicolon  
Applies to: Any namespace declaration that contains a non-empty body (e.g., `namespace X { ... }` or `namespace Y::Z { ... }`)  
Implementation:  
1. Identify a namespace declaration with a body  
2. Remove all content between the opening `{` and closing `}`  
3. Replace the `}` with a semicolon  
Example:  
Original:  
namespace MyLib {  
    class Helper { ... };  
}  

Mutated:  
namespace MyLib;  

Rationale: This exploits compilers' incorrect handling of invalid namespace syntax (malformed alias declarations), which may trigger assertion failures or crashes during parsing. The mutation leverages existing namespace structures without introducing new variables or types.
