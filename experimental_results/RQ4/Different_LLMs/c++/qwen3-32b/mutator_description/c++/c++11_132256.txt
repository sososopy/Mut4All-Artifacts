Mutation Operator: DefaultTemplateArgInForRangeLoop  
Applies to functions with a parameter using a default template argument and a compound statement body. Replace a simple statement in the function body with a range-based for loop that iterates over a collection of the parameter's type. The loop should initialize a variable of the same type as the parameter and process it in the loop body. This stresses handling of template argument propagation within control structures.

Example:  
Original code:  
void foo(T x = T{}) {  
   x.doSomething();  
}  

Mutated code:  
void foo(T x = T{}) {  
   for (const T& elem : x.getCollection()) {  
      elem.process();  
   }  
}  

Note: Requires that 'T' has a method 'getCollection' returning an iterable type, and 'elem' has a valid 'process()' method. If 'T' lacks these, the mutation introduces a new method declaration in the original type's scope, e.g., adding 'auto getCollection() const { return collection; }' to 'T' and 'void process()' to the element type.
