Mutation operator: Replace a direct-initialization argument in a new expression for an aggregate type with an aggregate initializer containing equivalent values. Apply to any new expression where the type is an aggregate (has no user-provided constructors) and the current initializer uses positional arguments. 

Example: 
Original code: 
new SomeAggregate(x, y)

Mutated code:
new SomeAggregate({x}, y)

This tests how the compiler handles mixed direct and aggregate initialization in new expressions, particularly when transitioning between different initialization syntax forms for aggregate types.
