Mutation Operator: Insert an attribute on a lambda expression within a template function's body, targeting the interaction between template instantiation and lambda attributes.

Example:
Original:
template <typename T>
void foo() {
  auto l = []() {};
}

Mutated:
template <typename T>
void foo() {
  auto l = []() __attribute__((pcs("target"))) {};
}

This mutation applies to any lambda in a template function by adding a valid function-style attribute that influences code generation (e.g., `pcs`). It leverages existing program structure (template + lambda) without introducing new variables or types, testing how template instantiation handles decorated lambdas.
