Mutation Operator: Replace Default Template Parameter with Lambda-Constructed Type
Applies to: Templates with type parameters and default arguments

Example transformation:
Original:
template <typename T, int Value = 42>
void func() {}

Mutated:
template <typename T, decltype([]{ return T(); }) Default = decltype([]{ return T(); })>
void func() {}

Change: 
1. Locate template parameters with default values
2. Replace integer/constant default with a lambda returning the template type
3. Use decltype of the lambda as the parameter type
4. Assign same lambda as default value

This targets template parameter syntax involving nested decltype expressions and lambdas, exposing bugs in template instantiation and type printing logic. The mutation leverages existing template parameters and constructs valid lambdas using the parameter type itself.
