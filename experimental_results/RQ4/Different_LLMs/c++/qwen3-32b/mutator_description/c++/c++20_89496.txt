mutation operator: Add concept constraint to lambda parameters in function templates using standard iterator concepts. Applies to lambdas in function templates that accept iterators as parameters. Changes 'auto' parameter types to 'std::input_iterator auto' or equivalent standard iterator concept to force constraint satisfaction checks. Example: Transform 'lambda = [&](auto from, auto to) { ... }' to 'lambda = [&](std::input_iterator auto from, std::input_iterator auto to) { ... }'. Targets C++20 concept instantiation in template lambdas with reverse iterators.
