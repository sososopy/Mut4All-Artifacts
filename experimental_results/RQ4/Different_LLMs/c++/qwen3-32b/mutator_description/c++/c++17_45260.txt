MutationOperator: InvalidDeductionGuideFunctionDeclaration
Applies to class template definitions with explicit deduction guides (C++17 feature). Targets malformed deduction guides that contradict function declaration syntax but appear as if they could be valid in a template context.
Modifies a valid deduction guide of the form T(U) -> T<V> to appear as T(U) T, which resembles a function declaration but lacks necessary components for a valid deduction guide and template argument deduction.
Example: Change template<typename T> class C; C(int) -> C<double> into template<typename T> class C; C(int) C (which is parsed as a constructor declaration but not a valid deduction guide).
This exploits the compiler's parsing logic for deduction guides by creating ambiguous syntax that adheres to neither valid function declarations nor valid deduction guides, potentially exposing crash conditions in error recovery paths.
