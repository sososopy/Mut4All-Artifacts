Mutation Operator: VariadicFriendOpWithConstraint
Applies to template structs exported as modules containing a friend operator== with variadic template parameters and cross-pack constraints. Targets the interaction between variadic templates, friend declarations, and module instantiation.

Example Mutation:
Original seed struct:
export module M;
template<typename... Ts>
struct S {};

Mutated version:
export module M;
template<typename... Ts>
struct S {
    template<typename... Us> requires (... and C(Ts, Us))
    friend bool operator==(S, S<Us...>) { return true; }
};
template struct S<>();

Where C is a generic constraint involving Ts and Us. This creates a scenario where pack expansions with mismatched lengths may trigger assertion failures in template instantiation during module usage. The operator requires both parameter packs to be present in the constraint to reproduce the same cross-pack comparison issue as the original bug.
