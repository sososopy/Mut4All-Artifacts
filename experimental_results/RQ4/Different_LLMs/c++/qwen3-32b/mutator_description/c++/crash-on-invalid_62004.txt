Mutation operator: Replace a static variable in a consteval function with a thread_local variable to expose incorrect handling of storage durations during constant evaluation.  
Applies to: Any consteval function with a static variable.  
Example:  
Original code:  
consteval int f() { static int x = 0; return x++; }  
Mutated code:  
consteval int f() { thread_local int x = 0; return x++; }  
This introduces thread_local in a consteval context, which may trigger assertion failures if the compiler improperly manages stack frames for non-static storage durations in constant expressions.
