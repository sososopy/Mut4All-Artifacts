Mutation operator: IncompleteTypeInConstexprMutation  
Applies to: constexpr variable declarations using a user-defined type (struct/class) that is fully defined at the declaration site.  
Action: Replace the complete type definition with a forward declaration, making it an incomplete type before the constexpr declaration.  

Example (before mutation):  
struct S { int x; };  
constexpr S s = { 0 };  

Example (after mutation):  
struct S;  // Incomplete type  
constexpr S s = { 0 };  

Coverage: Targets constexpr correctness checks, type completeness validation, and semantic analysis pathways for literal types. Requires the seed program to have a user-defined type used in a constexpr context. If no such type exists, a new minimal struct/class must be forward-declared and used in a constexpr declaration.
