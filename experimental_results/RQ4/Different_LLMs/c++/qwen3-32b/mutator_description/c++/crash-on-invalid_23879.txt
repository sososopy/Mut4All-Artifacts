Mutation Operator: BitfieldWidthOverflow
Target: Anonymous bitfield declarations in struct/class with computed width expressions that exceed type bit limits.
Apply to: Any struct/class anonymous bitfield with a width expression that can be modified to evaluate to a value exceeding the bitfield type's maximum size (e.g., int, unsigned, __int128).
Change: Replace the bitfield width with an expression that combines existing constants/variables with arithmetic operations to produce an overflowed bit count. For example, replace N with (TypeName)MaxValue + K where MaxValue is the type's maximum and K is a small integer.
Example: Before: struct X { int : 32; }; After: struct X { int : (uint64_t)-1 + 1; };
Constraints: Use existing types and constants (like -1, 0, or 1) already present in the seed program. Avoid creating new variables or types. Ensure the expression is valid C++ but evaluates to a bit count exceeding 64 bits for types expecting 64-bit or smaller values.
