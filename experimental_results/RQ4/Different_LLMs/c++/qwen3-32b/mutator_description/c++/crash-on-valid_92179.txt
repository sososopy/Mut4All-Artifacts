Mutation operator: Insert a nested compound statement within the function body of an existing function, creating additional scope layers without altering original logic.  
Example: Given a function body `T f() { A; B; }`, mutate it to `T f() { { A; }; B; }`. The inner block introduces a new scope without changing the program's semantics, increasing the parser's complexity in tracking nested blocks. Apply to any non-empty function body using existing variables/statements. No new declarations required.
