mutation operator: Remove semicolon after struct declaration and introduce typo in base class name within nested template struct inheritance.  
Applies to: Template structs with nested structs that inherit from template parameters or related types.  
Example: Given a nested struct `B` inside template struct `A` that inherits from `T`, mutate to:  
struct A {  
  struct B // Missing semicolon here  
  struct C : Btypo, T { }; // Misspelled base class name 'Btypo' instead of 'B'  
};  
Triggers parser/semantic analysis confusion by omitting critical syntax and corrupting base class references.
