MutationOperator: Replace lambda's noexcept with a nested requires clause checking a dependent type from the outer template. Apply to any lambda inside a function template with at least one type parameter. Modify the lambda to add a template parameter list, then replace its noexcept with requires{ requires requires{ typename T::X; }; }, where T is the outer function's template parameter. Example:  
Original:  
template<typename T>  
void f() {  
  [](...) noexcept(...) { ... };  
}  

Modified:  
template<typename T>  
void f() {  
  []<typename U>(U) noexcept(  
      requires { requires requires { typename T::X; }; }) { ... }(0);  
}
