Mutation operator: Insert a line continuation within the argument of a preprocessor macro invocation that expects a string or identifier. Apply this to any preprocessor directive where a macro argument is a single token, splitting it into multiple lines. For example, transform `#if MACRO("arg")` into `#if MACRO("arg\ continuation")` or `#if MACRO(identifier)` into `#if MACRO(identifier\ _suffix)`. This targets tokenization during preprocessing, particularly in handling macro arguments with line breaks.
