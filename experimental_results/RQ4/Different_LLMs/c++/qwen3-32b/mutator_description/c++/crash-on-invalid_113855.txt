Mutation Operator: UnionMultiInitMutation  
Applies to: Union-type object constructions using list-initializers.  
Description: Modify a union-type object's initialization to contain multiple initializers (designated or non-designated) that target different union members. This forces the compiler to validate whether the union is being initialized with more than one active member.  

Example:  
Before mutation:  
new U{0}  

After mutation:  
new U{0, .y=1}  

Application Requirements:  
1. The target union must have at least two distinct members.  
2. The first initializer must be positional (e.g. 0) for the first member.  
3. The second initializer must be a designated initializer (e.g. .y=1) for a subsequent member in the union.  
4. Existing union members and their names must be used to avoid introducing new types or undeclared identifiers.  

Effect on Compiler:  
Triggers logic for checking union initialization constraints, exposing assertions or crashes when the compiler fails to enforce the "single active initializer" rule for unions.
