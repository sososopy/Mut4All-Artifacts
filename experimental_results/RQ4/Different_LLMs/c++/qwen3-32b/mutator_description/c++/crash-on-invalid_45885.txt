Mutation Operator: IncompleteTemplateParameterListAtEOF  
Applies to: Template declarations with parameter lists (e.g., template<typename T>).  
Action: Remove the closing '>' of the template parameter list, leaving it unbalanced.  
Example (pseudo-code):  
Original: template<typename T> class Example { /*...*/ };  
Mutated: template<typename T class Example { /*...*/ };  
Effect: The parser reaches EOF while expecting '>' to close the template parameter list. This forces diagnostic rendering at EOF, potentially exposing assertion failures in diagnostic systems when handling unterminated templates.  
Coverage: Targets template syntax, a common source of frontend crashes when invalid.
