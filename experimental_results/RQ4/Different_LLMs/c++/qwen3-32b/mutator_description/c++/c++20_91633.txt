Mutation Operator: Modify Lambda Capture List in Template Context  
Applies to: Lambdas within templated functions or class templates where the lambda captures variables from the enclosing scope.  
Change: Add an explicit capture of a variable (by value or reference) already in scope but not used in the lambda body. This forces the compiler to resolve capture semantics during template instantiation.  
Example:  
Original code:  
```cpp  
template<typename T>  
void foo() {  
  int x = 42;  
  auto lambda = []() { /* no capture */ };  
  (void)lambda;  
}  
```  
Mutated code:  
```cpp  
template<typename T>  
void foo() {  
  int x = 42;  
  auto lambda = [x]() { /* x not used in body */ };  
  (void)lambda;  
}  
```  
This mutation introduces an explicit capture of `x` in the lambda, which may trigger template instantiation logic in `clang::Sema::tryCaptureVariable` if the captured variable's type or constraints depend on template parameters.
