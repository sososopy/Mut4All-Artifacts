Mutation Operator 1: Add explicit specialization of a member function template with a non-type template parameter.  
Target code construct: A class template containing a non-type template parameter in a member function template.  
Apply to a class template with a member function template declared with a non-type template parameter. Insert an explicit specialization for a specific non-type value. For example, if the class has:

   template<int N> auto func();  
};

Then explicitly instantiate the class template for a different type (e.g., template struct X<int>;) to trigger compiler processing of the specialization.
