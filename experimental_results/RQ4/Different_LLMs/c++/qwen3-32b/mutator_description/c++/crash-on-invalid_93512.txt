Mutation Operator: ForwardDeclaredLambdaDefaultArg
Targets a function parameter of a forward-declared type. Modifies the function to include a default argument that is a lambda returning the parameter variable without explicit capture. This structure forces the compiler to process the lambda while attempting to compute the layout of the incomplete type during parsing, which can trigger assertion failures in layout validation phases.

Applies to:
1. Functions with a parameter of a forward-declared class/struct type
2. Where the type is only forward-declared without a full definition in scope

Example Pseudo-Code:
Original:
struct T; // forward declaration
void foo(T arg);

Modified:
struct T; // forward declaration
void foo(T arg = [] { return arg; });

The lambda implicitly references the parameter 'arg' without capture, and the compiler's attempt to resolve this inside a forward-declared type context causes it to trigger the assertion in getASTRecordLayout(). The modified code uses existing function parameters and forward-declared types from the seed program.
