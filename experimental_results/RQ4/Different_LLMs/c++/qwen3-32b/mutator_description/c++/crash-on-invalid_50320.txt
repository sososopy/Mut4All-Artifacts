Mutation Operator: InvalidConstantInitializer  
Target: Static variable or constant declarations with explicit initializers that are not syntactically valid constant expressions.  
Applies to: Any static storage duration variable or constexpr declaration where the initializer is a compile-time constant in the original program.  

Transformation:  
1. Replace a valid compile-time constant initializer in a static declaration with a non-const lvalue reference/identifier that is not a constant expression.  
2. Ensure the substituted identifier is a non-const variable declared in the same or outer scope with a non-constant value.  

Example:  
Original code:  
static int x = 10;  

Mutated code:  
int y = 5;  
static int x = y;  

Key mechanism: Triggers assertion failures in Sema::CheckForConstantInitializer by forcing the compiler to process non-constant initializers for static/constexpr entities. The compiler must detect this invalid pattern and issue a diagnostic instead of crashing.  

Mutation rules:  
- Select any variable with static storage duration (static in function scope or namespace scope)  
- Substitute its constant scalar initializer with a non-const variable from the same scope  
- Preserve all type relationships and scope hierarchy from the seed program  
- No new variables or types are introduced—only identifier substitution within existing declarations
