Mutation Operator: Insert C++-specific scope resolution operator in C context  
Applies to: C source files (files with .c extension)  
Description: Replace a valid C statement or expression with a C++ scope resolution operator (::) token, which is invalid in C syntax but may trigger C++ parsing logic.  
Example before mutation:  
int main() {  
    return 0;  
}  

Example after mutation:  
int main() {  
    ::;  
    return 0;  
}  

Note: This introduces a C++-only syntax element into C source code without requiring existing identifiers. The operator may also be inserted as a standalone token, e.g., replacing a semicolon or entire line. This targets compiler validation of language mode guards in parsing routines.
