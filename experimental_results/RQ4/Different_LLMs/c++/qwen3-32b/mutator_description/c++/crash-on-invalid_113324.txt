Mutation operator: AddDefaultArgToTemplateFriendFunction  
Target code construct: A friend function declared inside a template class/struct without a default argument for one of its parameters.  
Description: Modify the friend function in the template to add a default argument to one of its parameters. Then, in a separate function (e.g., test()), call the friend function without providing the parameter with the newly added default argument. This forces the compiler to handle template instantiation and default argument resolution for the friend function, potentially exposing bugs in parameter counting or instantiation logic.  

Example mutation:  
Original code:  
template<typename T>  
struct S {  
  friend void f(T t, int x) { }  
};  
void test() {  
  f(S<int>{}, 42);  
}  

Mutated code:  
template<typename T>  
struct S {  
  friend void f(T t, int x = 0) { }  
};  
void test() {  
  f(S<int>{});  // Omit 'x' parameter, relying on default  
}  

Key changes:  
1. Add a default argument to the second parameter of the friend function `f`.  
2. Adjust the function call in `test()` to omit the parameter with the default argument.  
3. The friend function remains part of the template, and the mutation uses existing types/function names in the seed program.  

This mutation targets template instantiation and default argument handling at the intersection of friend functions and templates, aligning with the crash-on-invalid pattern in the bug report.
