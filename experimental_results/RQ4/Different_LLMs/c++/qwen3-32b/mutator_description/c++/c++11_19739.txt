Mutation Operator: Add an explicit specialization of a constructor in a derived class that inherits a constructor from its base class.  
Applies to classes deriving from a base with inherited constructors (e.g., via `using Base::Base`).  
Example: Insert a constructor in the derived class with the same signature as the inherited one but with explicit specialization (e.g., `Derived(ArgType) : Base(ArgType) {}`), potentially triggering mishandled method overriding or canonicalDecl assertion checks.  
Code Structure Targeted: Derived classes with inherited constructors and explicit constructor specializations.  
Avoids Custom Types/Variables: Uses existing base class constructors and types in the derived class definition.  
Coverage: High, as it involves inheritance, constructor delegation, and template-like specialization patterns.
