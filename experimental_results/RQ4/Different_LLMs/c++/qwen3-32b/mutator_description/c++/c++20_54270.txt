Mutation_operator: Insert_Global_Module_Fragment_Construct  
Applies_to: C++20 module declarations that do not include a global module fragment.  
Description: Adds a global module fragment (introduced in C++20 modules) before the module declaration to force a mismatch in module state tracking.  
Example:  
Original code:  
export module <identifier>;  
export int foo() { return 0; }  

Mutated code:  
global module fragment;  
export module <identifier>;  
export int foo() { return 0; }  

This creates a scenario where the compiler must reconcile the global module fragment with the exported module declaration. The mutation leverages existing module syntax and triggers compiler logic responsible for tracking the global module state, directly exposing assertions related to module state mismatches.
