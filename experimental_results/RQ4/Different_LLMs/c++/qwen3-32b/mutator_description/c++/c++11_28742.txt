Mutation operator: Replace fixed-length template parameters with variadic template parameters in class templates, then instantiate the class with multiple types, potentially triggering diagnostic line-number mismatches. Apply to class templates with explicit template parameter lists (e.g., template <typename T>). Modify the template declaration to use parameter packs (template <typename... Ts>), then modify any method to unpack the pack (e.g., add a function call that consumes Ts...). Example: Change template <typename T> class X { void f() {} }; to template <typename... Ts> class X { void f() { g(Ts{}...); } }; Assume g() exists in the seed program. This forces template instantiation with multiple arguments and may expose assertion failures in diagnostic systems during error highlighting.
