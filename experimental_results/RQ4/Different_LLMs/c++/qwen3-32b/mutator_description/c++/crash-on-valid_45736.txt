Mutation operator: RequiresClauseConceptModification
Applies to function templates or constructor templates with a requires clause that evaluates a concept constraint.
Change an existing requires clause constraint expression by replacing the concept check with a different constraint formed from existing functions or types in the seed program. For example, if the original constraint is "requires C<T>", replace it with "requires C<T> && D<T>" where D is another existing concept or function that evaluates to a boolean. This forces the compiler to evaluate more complex constraint combinations during template instantiation, stressing the constraint evaluator's ability to handle multiple interdependent constraints in nested template contexts.

Example pseudo-code:
Before:
template<typename T>
requires MyConcept<T>
void func(T t) { ... }

After:
template<typename T>
requires MyConcept<T> && (sizeof(T) > 0)
void func(T t) { ... }

Or with existing functions:
template<typename T>
requires (CheckConstraint(T{}) && !HasInvalidType<T>())
void func(T t) { ... }
