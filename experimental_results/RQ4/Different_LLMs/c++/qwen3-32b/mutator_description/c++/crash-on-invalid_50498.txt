Mutation Operator: InvalidMemberAccessViaCommaOperator  
Applies to member access expressions (expr.member) where 'expr' is a struct/union. Insert a comma operator with a non-struct type, e.g., transform (expr).member into ((expr, invalid_expr)).member where 'invalid_expr' evaluates to a non-struct type. Target existing struct variables and use already-declared non-struct variables for the comma operator's right operand.  
Example:  
Original: x = s.data;  
Mutated: x = ((s, y).data); // y is an int  

Mutation Operator: StructAssignmentViaCommaOperator  
Applies to assignment operations where the left-hand side is a struct variable. Insert a comma operator with an incompatible type, e.g., transform (s = value) into ((s = invalid_value)).member where 'invalid_value' is a non-struct type. Use existing variables of non-struct types for the assignment.  
Example:  
Original: s = getStruct();  
Mutated: ((s = y).data); // y is an int, followed by member access
