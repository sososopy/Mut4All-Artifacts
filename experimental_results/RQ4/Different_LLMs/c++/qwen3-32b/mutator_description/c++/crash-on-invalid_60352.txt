Mutation operator: Replace a simple requires expression with a lambda template that checks an existing type's member.  
Applies to: Requires clauses in templated functions/methods that use existing types with members.  
Example:  
Original requires clause:  
requires requires(T t) { t.f(); }  
Mutated:  
requires requires(T t) { []<typename Y>(ExistingType<Y>& e){ e.f(); }(t); }  

Key elements:  
1. Nested lambda with template parameter inside requires clause  
2. Uses existing type (ExistingType) from seed program  
3. Depends on outer template parameter (T)  
4. Checks member access pattern from original code  

This targets the same template instantiation path as the crash report by adding complex nested templates within requires clauses that need proper type substitution during constraint checking.
