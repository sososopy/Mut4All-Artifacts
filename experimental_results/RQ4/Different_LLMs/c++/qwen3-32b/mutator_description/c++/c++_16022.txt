Mutation operator: Replace a const reference to a temporary with a non-const reference. Apply to assignments where the right-hand side is a method call or rvalue expression that returns a temporary object. This tests whether the compiler correctly rejects non-const reference bindings to temporaries, which is required by C++ standards. Example: 
Original code: 
const T& x = obj.get_temp(); 
Mutated code: 
T& x = obj.get_temp(); 
If the compiler fails to diagnose this error, the resulting undefined behavior may manifest as a crash when accessing x. The mutation applies to any method returning a temporary, using types and variables already present in the seed program.
