Mutation operator: InvalidClassFunctionMerge  
Target construct: A class declaration followed by a function declaration  
Application rule: Replace the closing brace of a class with an immediately following function body, merging the two declarations without proper syntax  

Example mutation (before):  
class MyClass { };  
void myFunction() { ... }  

Example mutation (after):  
class MyClass { void myFunction() { ... }  

Rationale: This creates an invalid declaration where the parser is forced to interpret a function body as part of the class definition, mimicking the malformed code in the crash-on-invalid bug. The operator uses existing class and function from the seed program, modifying only the structural relationship between them.  

Mutation condition: Must apply when a class and a function exist in the seed program, with the function not being a member of the class. The mutation replaces the class closing brace with the function's body, causing a parsing ambiguity.  

Coverage justification: This mutation targets the boundary between class and function parsing, a high-risk area for compiler crashes when invalid. It works with any existing class and function, ensuring broad applicability across different program structures.
