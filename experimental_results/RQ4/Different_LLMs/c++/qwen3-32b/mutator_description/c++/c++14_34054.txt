Mutation Operator: Convert a non-generic lambda with explicit parameters to a generic lambda with a default argument for one parameter. Apply to lambdas with at least one parameter. Replace the first parameter with a template parameter (e.g., auto) and add a default argument using a variable from the surrounding scope. If no such variable exists, use a literal as the default.  
Example:  
Before: [x](int a) { return a + x; }  
After: [x](auto a = y) { return a + x; } (assuming y is accessible in the outer scope).
