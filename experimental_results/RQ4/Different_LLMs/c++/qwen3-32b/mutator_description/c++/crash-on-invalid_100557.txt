Mutation Operator: ReplaceTemplateArgWithMismatchedType
Applies to function calls with explicit template arguments where the template parameters are used to deduce or match argument types. Specifically targets calls to functions like std::make_tuple, std::variant, or any other templated function where template parameters and argument types are explicitly specified.

Example:
Before: std::make_tuple<int, double>(0, "test")
After: std::make_tuple<int, int>(0, "test")

This mutation forces a type mismatch between template parameters and actual arguments. The first template argument remains compatible (int with 0), but the second template argument (int) is now incompatible with the string literal argument ("test" is const char*). This creates an invalid overload resolution scenario that exposes compiler crashes in type-checking paths.

The mutation uses existing elements from the seed program:
1. The function std::make_tuple is already present
2. The string literal argument "test" is already present
3. The type 'int' is already used in variant definitions

No new variables or types are introduced. The mutation only modifies template parameter specifiers to create intentional mismatches with existing argument types in the program.
