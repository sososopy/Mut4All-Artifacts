Mutation operator: In a derived class that inherits a constructor from a base class via a `using` declaration, replace the `using` declaration with an explicit constructor specialization that delegates to the base class's constructor. Apply only to classes already containing a base class with a constructor and a derived class with an inheriting constructor declaration.

Example:
Original:
class B {
public:
 B(int);
};
class D : public B {
public:
 using B::B;
};

Mutated:
class B {
public:
 B(int);
};
class D : public B {
public:
 D(int) : B::B(int) {}
};
