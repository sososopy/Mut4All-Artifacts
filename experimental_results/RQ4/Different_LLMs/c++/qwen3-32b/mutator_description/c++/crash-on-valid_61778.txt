Mutation Operator: AddConstrainedMemberFunctionOverloadWithExplicitInstantiation
Applies to class templates with at least one member function.
For any class template with a member function, add a constrained overload of that function using a concept that checks if the template parameter is a class type. Then add an explicit instantiation of the member function for a non-class type.

Example:
Original code:
template<typename T>
struct S {
    void f() { }
};

Modified code:
template<typename T>
concept C = __is_class(T);

template<typename T>
struct S {
    void f() { }
    void f() requires C<T> { }
};

template void S<int>::f();

This creates a scenario where the compiler must resolve constrained overloads during explicit instantiation, exposing assertion failures in template instantiation logic. The mutation uses existing class templates and functions, adds minimal new elements (a concept check), and triggers the same diagnostic path as the reported crash by combining explicit instantiation with constrained overloads.
