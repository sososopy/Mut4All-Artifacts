Mutation Operator: Apply type-based concept constraints to non-type template parameters, creating invalid concept usages.  
Applies to: Function templates with non-type template parameters constrained by concepts.  
Action: Replace the concept constraint on a non-type template parameter with a type-based concept (e.g., change `C auto` to `TConcept auto`).  
Example:  
```cpp  
// Original  
template <TConcept C> auto Func(TConcept auto X);  

// Mutated  
template <TConcept C> auto Func(C auto X);  
```  
This introduces a constraint where a type-based concept is applied to a non-type parameter, creating a scenario where the compiler must validate or reject the constraint. If the compiler mishandles concept validation during AST processing, it may trigger assertion failures or crashes similar to the bug report. The mutation reuses existing types/concepts in the program and avoids introducing new declarations.
