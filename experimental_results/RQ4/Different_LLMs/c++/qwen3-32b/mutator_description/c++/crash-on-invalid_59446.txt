Mutation Operator: Add 'virtual' to a member function definition outside the class body  
Applies to: Member functions defined outside their class definition  
Description: Insert 'virtual' before the return type in a member function definition that is declared outside the class body. This creates an invalid use of 'virtual' that must be diagnosed by the compiler.  
Example:  
Original code:  
struct C {  
    void f();  
};  
void C::f() { }  

Mutated code:  
struct C {  
    void f();  
};  
virtual void C::f() { }  

This transformation introduces an invalid 'virtual' keyword in a member function definition, which may cause the compiler to crash if error recovery is inadequate when combined with other errors.
