Mutation operator: Insert an `export` keyword before a template declaration that is not enclosed in a module interface unit. This applies to any template declaration (class, function, or specialization) in global scope or non-module contexts.  

Example:  
Original code:  
```cpp  
template <class T>  
class X {  
};  
```  
Mutated code:  
```cpp  
export template <class T>  
class X {  
};  
```  

This mutation tests invalid use of `export` outside module boundaries, a C++20 feature restricted to module interface units. It leverages existing template declarations in the seed program and does not introduce new variables or types. The error should trigger if the compiler properly diagnoses the misuse of `export`, but may cause a crash if the parser/semantics handling is incomplete.
