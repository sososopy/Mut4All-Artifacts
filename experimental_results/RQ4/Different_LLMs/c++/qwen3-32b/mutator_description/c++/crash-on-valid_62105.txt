Mutation Operator: Replace ternary operator condition with a boolean expression derived from template type properties in conditional constructor expressions. Apply to conditional expressions (?:) where both branches instantiate a template constructor with the same type, especially when the condition is a constant. This targets compiler mishandling of unresolved constructor expressions in coverage instrumentation. 

Example:
Original:
0 ? T<C>{} : T<C>{}

Mutated:
sizeof(T) > 0 ? T<C>{} : T<C>{}

This forces the compiler to resolve both constructor expressions even when the condition is a constant. The mutation leverages existing template types and uses sizeof() which is valid within templates. The conditional logic remains computationally equivalent but exposes compiler bugs in source location tracking for unresolved expressions during coverage mapping.
