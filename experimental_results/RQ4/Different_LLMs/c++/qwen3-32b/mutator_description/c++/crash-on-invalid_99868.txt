Mutation Operator: ForwardTemplateInheritance
Applies to class declarations without base classes. Modifies the class to inherit from a forward-declared template class with an integer parameter. Declares a new template class with an integer template parameter and instantiates it with a constant value (e.g. 1). Triggers implicit template instantiation during inheritance and may expose crashes when the compiler queries properties of the undefined template.
Original:
class TargetClass {};
Mutated:
template <int> class T;
class TargetClass : T<1> {};

Mutation Operator: NestedTemplateMember
Applies to struct/class definitions within template classes. Adds a nested struct inside the template class that contains a data member of a forward-declared template class. Declares a new template class with an integer parameter and references it in the nested struct's member declaration.
Original:
template <int> class D {};
Mutated:
template <int> class B;
template <int> class D {
  struct {
    B<1> field;
  } member;
};
