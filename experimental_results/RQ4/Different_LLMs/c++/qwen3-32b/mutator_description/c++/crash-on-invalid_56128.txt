Mutation operator: Replace a valid Unicode escape sequence in a string or character literal with an invalid variant that introduces non-hexadecimal digits or malformed braces. Apply to any existing string/char literals in the program. Example: change "abc\u{1234}" to "abc\u{123g}" or "abc\U{d{4}" by inserting non-hex characters or mismatched braces. Does not require new declarations. Covers string literals, character literals, and any context where Unicode escapes are present.
