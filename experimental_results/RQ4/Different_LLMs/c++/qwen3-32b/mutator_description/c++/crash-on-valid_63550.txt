Mutation operator: Atomic pointer var init with int and shift in function.
Applies to global _Atomic variables and functions with bit shift.
Replace _Atomic(type) of global variable with _Atomic(pointer type) and initialize with integer 0. Retain existing function with bit shift on another _Atomic variable.
Example: 
Original: _Atomic(int) a; void f(int x) { a << x; }
Mutated: _Atomic(int*) a = 0; void f(int x) { a << x; }
Ensances size mismatch between pointer type and int init. Requires existing _Atomic var and function with bit shift.
