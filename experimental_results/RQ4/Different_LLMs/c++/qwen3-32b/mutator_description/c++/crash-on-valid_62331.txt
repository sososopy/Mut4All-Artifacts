Mutation Operator: InsertTemplatedMethodWithDefaultTemplateArg  
Applies to: Class templates with at least one template template parameter  
Action: For a class template C that accepts a template template parameter TTemp, insert a new method template M in C with a parameter list containing a default argument of type TTemp<TArg>. The method should (1) use the template template parameter in its parameter type, (2) include a default argument of the same type, and (3) be called in a context where the argument is omitted. The method body may be empty or trivial.  

Example:  
Original code:  
template <template <typename> class TTemp>  
class A {  
    // existing members  
};  

Mutated code:  
template <template <typename> class TTemp>  
class A {  
    template <typename TArg>  
    void M(TTemp<TArg> = TTemp<TArg>()) { }  // inserted method  
};  

void test() {  
    A<SomeTemplate> instance;  
    instance.M<ArgType>();  // calls method without explicit argument  
}  

This structure forces the compiler to resolve the default argument using the template template parameter, exposing bugs in template instantiation logic when the argument is implicitly generated.
