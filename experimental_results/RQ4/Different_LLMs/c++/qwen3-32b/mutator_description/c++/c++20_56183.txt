Mutation Operator: Lambda in Immediate Function Argument
Target construct: Use of a lambda as an argument to a consteval function or immediate function.
Apply to: Function calls where the target function is declared with consteval or is an immediate function.
Action: Replace a simple literal or variable reference argument in a consteval function call with a lambda that captures a variable from the current scope and returns it. 
Example: Change f(42) to f([&x]{ return x; }) where x is a variable in scope at the call site. The lambda must capture by reference and return the captured variable.
Applies to any consteval function call with a scalar argument. The lambda must use existing variables in the function's scope. No new variables are introduced. The lambda body consists of a return statement returning the captured variable.
