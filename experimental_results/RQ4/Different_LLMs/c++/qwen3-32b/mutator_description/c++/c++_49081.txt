Mutation operator: Lambda return type with template-dependent alias
Target construct: Generic lambdas using template parameters in return type via template alias
Applies to: Functions containing generic lambdas that return a template alias using a compile-time constant from outer scope

Change: Replace a simple lambda return type (e.g., void) with a template alias that depends on a constexpr variable in the outer scope

Example transformation:
Original:
auto lambda = [](auto) -> void { };

Mutated:
constexpr int T = 0;
auto lambda = [](auto) -> type<T> { };

This creates a scenario where the compiler must substitute the template alias during instantiation, potentially triggering the same assertion in template argument substitution. Uses existing template alias 'type' and constexpr variable in scope.
