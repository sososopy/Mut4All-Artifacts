Mutation operator: Introduce a class template that declares a union containing a non-trivial class member (e.g., a class with user-defined constructor/destructor). Apply to class declarations that can be transformed into class templates by adding a template parameter and nested union definition. The non-trivial class must already exist in the seed program as a type with user-defined constructors/destructors. Example:  
Original code:  
class A { public: A() { } };  

Mutated code:  
template<typename T>  
class A {  
    union {  
        A<T> a; // Non-trivial class member in union  
    };  
};
