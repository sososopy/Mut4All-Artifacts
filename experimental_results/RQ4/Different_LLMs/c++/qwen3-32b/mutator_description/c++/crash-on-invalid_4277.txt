Mutation operator: Replace a valid function call or assignment statement with an inline assembly statement that uses an existing variable as an operand with an invalid constraint (e.g., "q" for non-integer types) in a context requiring operand validation. For example, transform `x = y + z;` to `asm("" : "=q"(x) : "r"(y), "r"(z));` where `q` is an invalid constraint for `x`'s type. This exploits compiler IR generation paths for inline assembly, increasing crash likelihood during operand validation.
