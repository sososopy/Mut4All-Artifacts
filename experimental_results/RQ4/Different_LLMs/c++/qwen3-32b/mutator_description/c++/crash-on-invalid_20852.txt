Mutation operator: NestedTemplateAngleBracketsMutation  
Applies to: Template instantiations with nested templates in return types or variable declarations.  
Operation: Add an extra '>' to the closing angle brackets of an outer template, creating invalid template syntax. Example: Change `Foo<Bar<int>::type>` into `Foo<Bar<int>::type>>` in a function return type or variable declaration. This forces the compiler to parse the malformed nested template, exposing crashes during template instantiation.  

Example:  
Original:  
`T Foo<Bar<int>::type::value> x;`  
Mutated:  
`T Foo<Bar<int>::type::value>> x;`  

This mutation targets the angle bracket ambiguity, which is a common source of compiler crashes when invalid template syntax is encountered. It requires existing templates or types in the seed program and does not introduce new declarations.
