Mutation Operator 1: FunctionParameterListExpansion
Applies to functions declared within at least two levels of nested namespaces. Adds an additional parameter of a reference or pointer type to an existing type in the function's parameter list. The new parameter must use a type already present in the function's context.

Example: 
Original:
namespace A::B {
void foo(int a, double b) { ... }
}

Mutated:
namespace A::B {
void foo(int a, double b, const std::string& c) { ... }
}

The mutation introduces a new parameter using a type (std::string) that already exists in the program context. This increases parsing complexity in nested namespace function declarations, which was demonstrated as a crash point in the bug report.
