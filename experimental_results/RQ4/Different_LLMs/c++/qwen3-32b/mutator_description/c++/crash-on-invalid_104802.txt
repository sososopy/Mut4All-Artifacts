Mutation Operator: Replace a pointer/reference member of a class with a direct instance of the same class type within its own declaration, creating an incomplete type usage. Apply to any class with an existing pointer or reference member.  

Example (before):  
class A {  
    A* ptr;  
    virtual int func();  
};  

Example (after):  
class A {  
    A direct;  // Invalid: uses own type before completion  
    virtual int func();  
};  

This exploits the compiler's incomplete-type handling logic when resolving destructors for partially-defined classes. The mutation forces a recursive type dependency during semantic analysis, similar to the reported crash pattern.
