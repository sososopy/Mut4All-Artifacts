Mutation operator: Swap the order of template parameter pack expansion and an additional argument in an alias template instantiation. Apply to alias template uses where the parameter pack is followed by one or more explicit arguments within the template argument list. Example: Change `Bar<Ts..., U>` to `Bar<U, Ts...>` using existing Ts (template parameter pack) and U (template parameter) from the context. This targets incorrect handling of mixed template argument expansion orders in alias templates.
