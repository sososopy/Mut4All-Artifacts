Mutation operator: Replace a struct's inline static constant member with a variable template and add a partial specialization using a template template parameter. Apply to any struct template with at least one type parameter. The variable template's primary case returns false, and the partial specialization matches containers using template template parameters. The mutation adds:  
- A variable template inside the struct template with primary definition `static constexpr bool value = false;`  
- A partial specialization for `container<params...>` where `container` is a template template parameter.  

Example:  
For struct template `MyStruct<T>`, mutate to:  
```cpp  
template <typename T>  
struct MyStruct {  
  template <typename U>  
  static constexpr bool value = false;  
};  

template <template <typename...> class Container, typename... Params>  
constexpr bool MyStruct<Container<Params...>>::value<Container> = true;  
```  

This forces the compiler to process a variable template with template template parameter-based partial specialization, exposing crashes in template deduction systems.
