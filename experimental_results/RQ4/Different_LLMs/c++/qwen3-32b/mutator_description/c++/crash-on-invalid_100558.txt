Mutation operator: Lambda return type as function type with existing parameter
Applies to: Lambda expressions with a trailing return type and at least one parameter
Action: Replace the trailing return type of the lambda with a function type using the first parameter's name and type from the lambda's parameter list. For example, transform [](T x) -> U { ... } into [](T x) -> U(T x) { ... }

Example transformation:
Original lambda:
[] (int x) -> int {
    return x;
}

Mutated lambda:
[] (int x) -> int (int x) {
    return x;
}

This creates an invalid return type (function type) that references an existing parameter name, exposing compiler errors in handling nested function types as return types. The mutation preserves all existing variable references and does not introduce new declarations.
