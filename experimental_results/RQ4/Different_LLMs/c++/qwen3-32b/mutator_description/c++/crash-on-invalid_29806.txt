Mutation Operator: InsertStructMemberSemicolon  
Applies to struct definitions with at least one member. Replaces the first struct member declaration with the same type and name followed by an explicit semicolon. For example:  
Original: struct A { int a; float b; };  
Mutated: struct A { int a; ; float b; };  
This forces the parser to handle a semicolon immediately after a member declaration, triggering error-handling paths that may involve Microsoft extension checks. The mutation uses existing member names and types from the seed program. If the struct has fewer than two members, this operator is not applied.
