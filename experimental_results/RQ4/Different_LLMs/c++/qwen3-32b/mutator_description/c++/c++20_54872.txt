Mutation operator: In consteval functions with nested lambdas using index_sequence, replace a reference capture of an array with a by-value capture. This alters the evaluation context, potentially triggering stack overflow during template instantiation. Example: Change `[&arr, func]` to `[arr, func]` in the lambda that returns the transformed array, forcing the compiler to evaluate the array's value capture during consteval, which could expose bugs in stack management. Apply this to any existing array variable captured in such lambdas.
