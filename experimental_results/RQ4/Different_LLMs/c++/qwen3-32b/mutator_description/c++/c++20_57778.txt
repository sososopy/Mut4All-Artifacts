Mutation operator 1: Add a module interface declaration at the top of a source file that lacks a module declaration, and declare a global variable within that module. 

Example: 
Original file contains a global variable like `int x;`. 
Mutated file becomes: 
```
module;
int x;
```

This triggers the compiler's module code generation logic by associating the global variable with a module interface, potentially exposing assertion failures in module-related parsing or codegen handling when compiled with `-fmodule-name`.
