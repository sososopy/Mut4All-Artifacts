Mutation Operator: Template Base Class Injection  
Target: Base class declarations in a class (e.g., `class Derived : public Base`).  
Action: Replace the base class with a template parameter, introducing a template to the class. For example, transform `class Derived : public Base` into `template <typename T> class Derived : public T`. This creates a scenario where, during template parsing, the type of `T` is not yet known, potentially leading to a NULL pointer dereference if the compiler does not handle unresolved types during base class processing. The seed program remains valid as the template is not instantiated, and the mutation uses existing class names.  

Example:  
Original Code:  
```cpp  
class Base {};  
class Derived : public Base {};  
```  

Mutated Code:  
```cpp  
template <typename T>  
class Derived : public T {};  
```  

This mutation is widely applicable to classes with base classes, leveraging existing class names while introducing a template to stress compiler handling of unresolved types in inheritance contexts.
