Mutation Operator: Replace a template type parameter in a complex constructor (e.g., std::tuple, std::variant) with an incompatible type that does not match any overload. Apply to any function call creating such a complex type that is passed to an overloaded function expecting the original type. Example: Given `f(std::tuple<T1, T2>())` where `T2` matches an overload, change to `f(std::tuple<T1, T3>())` using `T3` not in any overload. Ensure `T3` already exists in the program but is not part of the overload's expected types. This stresses overload resolution on mismatched nested templates.
