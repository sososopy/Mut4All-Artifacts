Mutation Operator: Insert a lambda that accepts a const reference to an instance of a class and attempts to call a non-static member function on the instance. Wrap the lambda in a `std::is_invocable_v` check with the class type as the argument. The lambda's return type is deduced via `decltype` of the member function call. This forces the compiler to evaluate the invocability of the non-static member function through the lambda, triggering potential ICEs if the compiler is affected.

Example:
Original code with a non-static member function:
struct S {
    void Func() {}
};

Mutated code:
struct S {
    void Func() {}
};

int main() {
    auto lambda = [](const auto& cls) -> decltype(cls.Func()) {};
    auto isInv = std::is_invocable_v<decltype(lambda), S>;
    return 0;
}
