Mutation Operator: Lambda with Function Type Parameter  
Target: Lambda expressions within template functions or any function body that capture by reference or value.  
Action: Modify a lambda to include a parameter of a function type (e.g., void(), int(*)(), etc.), which is invalid in a lambda’s parameter list.  
Example:  
Original code:  
template <class T>  
void bar() {  
  [&] (int x) { /* body */ };  
}  

Mutated code:  
template <class T>  
void bar() {  
  [&] (void (func)()) { /* body */ };  
}  

Effect: The lambda now has an invalid parameter (a function type), which may expose compiler crashes during template instantiation or lambda parsing. Uses existing template structure and captures by reference.
