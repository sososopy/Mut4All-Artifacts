Mutation operator: Replace a valid default argument in a constexpr constructor or function parameter with an empty parentheses list, creating an unterminated value-dependent expression. This targets the constexpr evaluation of malformed default arguments in array or initializer contexts.

Example:
Original: `constexpr S(const int &a = 0) {}`
Mutated: `constexpr S(const int &a = ()) {}`

Applies to any constructor or function parameter with an existing default argument. The mutation introduces an invalid but syntactically valid-looking CXXParenListOrInitListExpr that may trigger value-dependent assertion failures during constant evaluation. Uses only existing parameters and types from the seed program.
