Mutation Operator: ChangePackParamToCastInTemplateArg  
Applies to a template argument in a pack expansion where the pack parameter is of an integral type and the template expects a different integral type. Replace the pack parameter with an explicit cast to the expected type. For example, in a lambda using an index_sequence, if a pack parameter (e.g., std::size_t) is used in a template argument expecting int, change  
`Templated<T>` to  
`Templated<static_cast<int>(pack_param)>`,  
where `Templated` is an existing alias or template in the seed program and `pack_param` is a parameter from the index_sequence. This targets nested template lambdas and pack expansions, stressing type conversion during template instantiation.
