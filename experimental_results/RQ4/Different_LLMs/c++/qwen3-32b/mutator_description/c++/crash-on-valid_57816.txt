Mutation Operator: Inline Attribute Overload Conflict  
Applies to function templates that call a non-template function with the same name but different parameter types. Insert an inline attribute before the function call, forcing the compiler to resolve an overload with varying parameter types during template instantiation. This targets compiler bugs in attribute handling during overload resolution in templates.  

Example:  
Given a function template `T f(T t)` calling a non-template function `void f(int*)`, mutate the template's function body to:  
`[[attr]] f(reinterpret_cast<int*>(t));`  
(Replace `attr` with a valid inline attribute for the compiler.)  

Changes:  
1. Add a valid inline attribute (e.g., `[[clang::always_inline]]` or `__attribute__((always_inline))`) before the function call in the template.  
2. Replace the parameter in the function call with a type-cast expression that matches the non-template function's argument type.  

Rationale: Forces the compiler to reconcile inline attribute semantics with overload resolution in template instantiation, exposing bugs in attribute propagation or name resolution logic.
