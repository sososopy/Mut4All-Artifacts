Mutation operator: Replace a valid member access with a non-existent member in a struct/class.  
Applies to: Struct/class member access expressions (e.g., `obj.member` or `ptr->member`).  
Example:  
Original:  
struct S { int x; };  
void f(S s) { s.x; }  

Mutated:  
struct S { int x; };  
void f(S s) { s.y; } // 'y' is not a member of S, triggering invalid member resolution  

This mutation forces the compiler to process an undefined member access. If the compiler does not properly validate the member name against the struct/class definition, it may crash during semantic analysis or static checking. The operator is widely applicable to any struct/class with member accesses, using existing variables/structs without introducing new elements.
