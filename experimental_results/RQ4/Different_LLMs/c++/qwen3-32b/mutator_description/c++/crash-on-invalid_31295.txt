Mutation operator: Replace a union or struct member with a nested struct containing a bitfield of an invalid type (e.g., pointer, function type, or non-scalar type). Apply to any existing union or struct member, using existing types in the program. Example: change `int x;` in a union to a nested struct with a bitfield like `void* : 4;` or `SomeClass : 8;` where `SomeClass` is a user-defined type. This corrupts the type system by forcing invalid bitfield types during semantic analysis, exposing crashes in CXXRecordDecl handling. Avoid creating new types; use existing types in the seed program for the bitfield type.
