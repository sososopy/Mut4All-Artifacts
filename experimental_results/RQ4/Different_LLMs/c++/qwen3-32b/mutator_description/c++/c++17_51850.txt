Mutation Operator: Templated Lambda Switch Nesting
Applies to: Lambdas with a non-type template parameter. 
Insert within the lambda body a switch statement over an existing parameter. In each case, invoke an existing lambda's operator() with the current template parameter and an additional non-type parameter. Requires an existing lambda in scope for the nested call. 

Example:
Original lambda: 
auto L = [][<int N>() { return N; }];

Modified lambda:
auto L = [][<int N>() {
    switch (x) {
        case 0: M.operator()<N, 0>();
        case 1: M.operator()<N, 1>();
        ...
    }
}]; 

Where x is an existing parameter and M is an existing lambda with appropriate operator() template parameters. Each case adds a new non-type template argument while reusing the original template parameter N.
