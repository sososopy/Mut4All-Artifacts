Mutation Operator: IncompleteTypeBuiltinApplication  
Description: Forward-declare an existing user-defined type, declare a pointer variable of that type, and apply __builtin_dump_struct with a valid callback function in a function body. The type must remain incomplete.  
Applicability: Seed programs containing at least one user-defined type (e.g., struct/class) and one function with a compatible signature (e.g., matching __builtin_dump_struct's expected callback format).  
Changes:  
1. Insert a forward declaration (e.g., `struct T;`) for an existing user-defined type T if not already declared.  
2. In a function (e.g., main), declare a pointer variable of type `T*` and initialize it to `nullptr`.  
3. Call `__builtin_dump_struct` with the pointer and a valid callback function (e.g., a function already present in the seed program).  
4. Ensure the forward-declared type T is not defined (i.e., no full struct/class definition is present).  
Example Pseudo-code:  
Original (contains `struct MyType` and function `void callback(int)`):  
struct MyType { int x; };  
void callback(int);  

Mutated:  
struct MyType;  
void callback(int);  

int main() {  
    MyType* ptr = nullptr;  
    __builtin_dump_struct(ptr, callback);  
    return 0;  
}
