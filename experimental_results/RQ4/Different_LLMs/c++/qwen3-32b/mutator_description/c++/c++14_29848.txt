Mutation operator: Insert Apostrophe in Exponent of Floating-Point Literal  
Applies to: Floating-point literals with explicit exponents in variable initializations or assignments.  
Change: Replace a valid exponent (e.g., 1.23e45) with a malformed form by inserting an apostrophe in the exponent part (e.g., 1.23'e45). This creates an invalid token sequence that may confuse the C++14 parser but retain enough syntactic structure to avoid immediate errors in C++11.  
Example:  
Original code: "double x = 0.123e5;"  
Mutated code: "double x = 0.123'e5;"  
Coverage: Targets exponent notation in floats/doubles, common in scientific computing. Avoids new variables/types by modifying existing literals.
