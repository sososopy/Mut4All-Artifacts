Mutation operator: Replace a valid template class partial specialization with an invalid one using a boolean value in type parameter position where a type is expected, targeting templates with multiple type parameters.

Applies to: Any template class declaration with two or more type parameters in the source program.

Mutation process:
1. Locate a template class declaration with the form `template <typename T1, typename T2> class NAME;`
2. Add a partial specialization with the form `template <typename T1> class NAME<T1, true>;`
3. Leave the specialization body empty or use the existing class definition if available

Example mutation:
Original code:
template <typename T, typename U>
class MyTemplate;

Mutated code:
template <typename T>
class MyTemplate<T, true>;

This creates an invalid partial specialization by using a boolean value (`true`) in a type parameter position, similar to the crash-on-invalid trigger in the reported bug. The mutation leverages the existing template class structure without introducing new types or functions that weren't already present in the seed program.
