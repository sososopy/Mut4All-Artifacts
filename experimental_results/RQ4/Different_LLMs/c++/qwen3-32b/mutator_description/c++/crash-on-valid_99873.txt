Mutation Operator: Recursive Template Instantiation with Nested Type Deduction  
Applies to templates with specializations that recursively call template functions using nested type traits (e.g., decltype(member)).  

Example:  
Original code:  
```cpp  
template <typename T> T* factory() { return new T; }  
```  
Mutated code:  
```cpp  
template <typename T> T* factory() {  
  return new T(factory<decltype(T::NestedType)>());  
}  
```  
Where `T::NestedType` is a public type alias in `T` (e.g., `using NestedType = int`).  

This forces template instantiation chains where the compiler must resolve nested type placeholders, potentially hitting code paths that mishandle type deduction in complex template contexts. The mutation leverages existing types and their member types to trigger type system edge cases.  

Note: Requires that `T` has a public type alias. If `T` lacks this, insert `using NestedType = int;` into `T`'s definition before applying the mutation.
