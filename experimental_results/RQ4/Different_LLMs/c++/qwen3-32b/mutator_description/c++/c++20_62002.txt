Mutation operator: Introduce a consteval constructor in a struct that calls a constexpr function, prioritizing void-returning or externally declared functions.  
- **Target**: Structs with non-consteval constructors.  
- **Modification**: Replace the constructor's qualifiers (e.g., `constexpr`, `default`) with `consteval`.  
- **Add**: In the constructor body, insert a call to an existing `constexpr` function (e.g., `func()`). If no such function exists, declare `extern constexpr void func();` before the struct and call it.  
- **Example**:  
  Original code:  
  ```cpp  
  struct S {  
    S() { /* ... */ }  
  };  
  ```  
  Mutated code:  
  ```cpp  
  extern constexpr void func();  

  struct S {  
    consteval S() { func(); }  
  };  
  ```  
- **Purpose**: Forces constant evaluation of the constructor, stressing the experimental interpreter when resolving external or void-returning `constexpr` calls.
