Mutation Operator: AddReferenceToDecayedTypeInTemplateConstraint
Target construct: Class template constructors with requires clause using std::is_constructible_v<std::decay_t<T>, T>
Transformation: Modify the constraint in the requires clause to check constructibility from the decayed type with a reference added. Replace std::is_constructible_v<std::decay_t<T>, T> with std::is_constructible_v<std::decay_t<T>&, T>
Example:
Original code:
template<typename F>
requires std::is_constructible_v<std::decay_t<F>, F>
Derived(F&& f);

Mutated code:
template<typename F>
requires std::is_constructible_v<std::decay_t<F>&, F>
Derived(F&& f);

This creates a circular dependency in constraint evaluation where the decayed type's reference qualification affects the is_constructible check. The compiler may attempt infinite recursion when resolving whether a reference-to-decayed-type can be constructed from the original type, exposing bugs in constraint dependency tracking and template substitution.
