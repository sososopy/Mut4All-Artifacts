Mutation operator: Replace a valid non-type template parameter with a concept name that lacks a type and variable for constraint checking. Target templates with constraints as non-type parameters.  
Example:  
Original: `template <Concept T> struct X;`  
Mutated: `template <Concept> struct X;`  

Mutation operator: Convert a constraint-based substitution into a malformed non-type template parameter by omitting the type. Target template declarations using concepts as non-type parameters.  
Example:  
Original: `template <Constraint<int> D> struct Y;`  
Mutated: `template <Constraint D> struct Y;`  

Mutation operator: Substitute a valid constraint expression in a template specialization with an unconstrained non-type parameter. Target partial template specializations.  
Example:  
Original: `template <Constraint Z> struct Z {}; template <Constraint<int> D> struct Z<D> {};`  
Mutated: `template <Constraint> struct Z {}; template <Constraint D> struct Z<D> {};`  

Mutation operator: Replace a valid constraint condition with a bare concept name in a template parameter list. Target templates with concept-based parameters.  
Example:  
Original: `template <Concept<T> T> struct W;`  
Mutated: `template <Concept<T>> struct W;`  

Mutation operator: Introduce a non-type template parameter using a concept without specifying its associated type. Target template declarations with concepts.  
Example:  
Original: `template <Concept<T> V> struct V {};`  
Mutated: `template <Concept<T>> struct V {};`
