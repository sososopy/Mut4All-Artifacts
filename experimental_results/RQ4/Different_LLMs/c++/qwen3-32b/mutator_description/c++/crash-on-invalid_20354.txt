Mutation operator: Insert an extern declaration in a function body that shares the same name as a parameter or local variable. Apply to any function with at least one parameter or local variable. Replace a local declaration or parameter with an extern of the same type and name. Example: For function `void g(float x)` with body `{ ... }`, mutate to `void g(float x) { extern float x; ... }`. Do not introduce new variables, only use existing names and types from the function's parameters or local scope. Insert the extern before any uses of the variable to maximize shadowing.
