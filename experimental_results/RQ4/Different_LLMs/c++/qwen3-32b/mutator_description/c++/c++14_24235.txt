Mutation Operator: Replace a runtime assignment of a value with a static assertion that forces its evaluation during compilation.  
Applies to: Expressions where a value is assigned to a variable after being returned by a function or computed in a non-constexpr context.  
Example (pseudo-code):  
Original:  
int x = compute_value();  

Mutated:  
static_assert(compute_value() > 0, "");  

This mutation forces the compiler to evaluate `compute_value()` at compile time, exposing potential frontend crashes in constexpr evaluation logic. Existing functions and variables are reused without introducing new declarations.
