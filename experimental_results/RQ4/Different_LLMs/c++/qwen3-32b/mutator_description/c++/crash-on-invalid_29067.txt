Mutation Operator: Replace explicit member function pointer type in cast with a placeholder type (e.g., auto) to create invalid code that triggers type resolution failure in the compiler

Applies to: Any static_cast or similar cast expressions that use a fully specified member function pointer type (e.g., T (Class::*)())

Change: Identify a valid cast from concrete member function pointer type to another type. Modify the source type in the cast to a placeholder type (auto, decltype(auto)) while maintaining the destination type. For example:

Original:
auto ptr = static_cast<int (A::*)()>(Fun);

Mutated:
auto ptr = static_cast<auto (A::*)()>(Fun);

This creates an invalid cast where the cast source has a placeholder type where a complete type is required, forcing the compiler to perform incomplete type resolution that may bypass normal error checks.

Example: If original code has a valid cast between member function pointers, replace the source type in the cast with 'auto' to create invalid code that should be rejected but instead triggers a compiler crash. The mutation preserves all existing variable references (Fun) and class references (A) that already exist in the seed program.
