Mutation operator: Change the size of a constexpr array used in a ternary operator's second or third operand to create an incompatible array type while preserving the element type (e.g., transform a 10-element array into a 1-element array where both operands use different array sizes but same element type in the conditional expression). Apply only to existing constexpr arrays already declared in the seed program. 

Example:  
Original code:  
```cpp  
constexpr const unsigned char arr1[10] = {0};  
constexpr const unsigned char arr2[10] = {0};  
auto x = (condition ? arr1 : arr2);  
```  

Mutated code:  
```cpp  
constexpr const unsigned char arr1[10] = {0};  
constexpr const unsigned char arr2[5] = {0};  // Changed array size from 10 to 5  
auto x = (condition ? arr1 : arr2);  
```  

This creates a valid program with incompatible array types in the ternary operator, exposing assert-based type unification failures in the ASTContext.
