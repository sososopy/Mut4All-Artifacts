Mutation Operator: Add a struct with a flexible array member to a union and use empty aggregate initialization to trigger potential out-of-bounds initializer access in the compiler. Apply to any struct with scalar members and an existing union, or create a minimal struct and union if necessary.  
Example:  
Original code with struct and union:  
struct S { int a; };  
union U { int x; struct S y; };  

Modified code:  
struct S { int a; char b[]; };  
union U { int x; struct S y; } u = {};  
Changes:  
1. Add flexible array member 'b' to struct S.  
2. Initialize union 'u' with empty initializer list.  

Mutation Operator: Replace a scalar member of a struct with a flexible array and insert the struct into a union, then initialize the union with an empty initializer list to stress compiler handling of aggregate initialization. Apply to any struct with at least one scalar member and an existing union.  
Example:  
Original code with struct and union:  
struct S { int x; };  
union U { int i; struct S s; };  

Modified code:  
struct S { int x; char arr[]; };  
union U { int i; struct S s; } u = {};  
Changes:  
1. Replace 'int x' in struct S with 'char arr[]'.  
2. Initialize union 'u' with empty initializer list.
