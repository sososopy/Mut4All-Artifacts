Mutation operator: AddConstexprCTADClass  
Applies to: Struct templates with a consteval constructor and a constexpr instance using CTAD.  
Description: For each struct template with a consteval constructor and a constexpr instance using CTAD, introduce an additional struct template with an identical consteval constructor and a constexpr instance using CTAD. This increases the number of such classes in the code, triggering scenarios where the compiler's handling of multiple consteval CTAD structures may fail.  

Example:  
Original code:  
template<class T>  
struct A {  
    consteval A(T) {}  
};  
constexpr A a = []() { return 0; };  

Mutated code:  
template<class T>  
struct A {  
    consteval A(T) {}  
};  
constexpr A a = []() { return 0; };  
template<class T>  
struct B {  
    consteval B(T) {}  
};  
constexpr B b = []() { return 0; };  

Note: The new struct (e.g., B) mirrors the structure of the existing one and uses an already-declared lambda or function (if present in the seed program) to initialize the constexpr instance. If no such elements exist, a new lambda or function must be declared explicitly, following the same logic as the original.
