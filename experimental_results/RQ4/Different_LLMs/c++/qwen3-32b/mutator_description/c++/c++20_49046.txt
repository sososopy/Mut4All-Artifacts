Mutation operator: Replace a constrained template template parameter with an equivalent requires expression that evaluates the same constraint. Apply this to all template template parameters constrained by a concept, particularly those involving non-type template parameters with constraints.

Example:
Original code:
template<template<C auto...> typename Templ> struct S {};

Mutated code:
template<template<auto...> typename Templ> struct S requires C<decltype(Args)...) {};

Note: This mutation preserves existing parameters (Args) from enclosing contexts and replaces the concept-based constraint with a requires clause. The compiler may crash when processing the requires expression during template instantiation, exposing the same internal error related to constrained NTTPs in template template arguments. This applies to any template template parameter using a concept to constrain its NTTPs.
