Mutation Operator: Replace a prvalue initialization of a struct with a deleted copy constructor and consteval members with an assignment between two prvalues of the same type in a consteval context. Apply to code that declares a struct/class with a deleted copy constructor and at least one consteval constructor or method, and uses a prvalue initialization (e.g., X{x}) within a consteval evaluation context. The mutation modifies an existing expression that creates a prvalue using consteval semantics by replacing it with an assignment between two prvalues (e.g., (X{} = X{})). This forces the compiler to evaluate the deleted copy constructor during consteval processing, exposing potential ICEs. Example: Change `A{A{}}.f();` to `(A{} = A{}).f();` in programs where `A` has a deleted copy constructor and consteval members.
