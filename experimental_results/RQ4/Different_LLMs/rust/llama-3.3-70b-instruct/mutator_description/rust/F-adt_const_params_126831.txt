Mutation Operator: ReplaceConstValue
This mutation operator targets constant values in the code and replaces them with different values. The purpose of this operator is to test the compiler's ability to handle different constant values, especially in the context of ADT const params, which is relevant to the F-adt_const_params bug label.

This operator applies to constant declarations, such as const N_ISLANDS: usize = 4;, and replaces the value 4 with a different constant value. The new value can be chosen randomly from a set of possible values, such as 0, 1, 2, 8, 16, etc.

For example, given the code:
const N_ISLANDS: usize = 4;
The mutation operator ReplaceConstValue could replace the value 4 with 8, resulting in:
const N_ISLANDS: usize = 8;

This mutation operator is designed to achieve high coverage across different program structures and features, including constant declarations, type definitions, and function implementations. By replacing constant values with different values, this operator can help expose bugs related to constant handling, such as the one described in the F-adt_const_params bug label.
