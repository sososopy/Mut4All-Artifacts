Mutation Operator: ReplaceConstantWithFunctionPointer
This mutation operator targets constant declarations that hold function pointers and replaces them with a new function pointer that is defined in the same scope. The goal is to expose bugs related to constant evaluation and function pointer comparisons, which are relevant to the A-const-eval label.

The operator applies to code constructs where a constant is assigned a function pointer, such as `const TEST: Fn = my_fn;`. The mutation involves replacing the constant with a new function pointer that is defined in the same scope. For example, if the seed program contains a function `fn new_fn() -> u8 { 0 }`, the mutation could replace `const TEST: Fn = my_fn;` with `const TEST: Fn = new_fn;`.

To achieve high coverage, this operator should be applied to all constant declarations that hold function pointers in the seed program. The new function pointer should be chosen from existing functions in the program that have the same signature as the original function pointer.

To illustrate this mutation, consider the following pseudo-code:
```
const ORIGINAL: Fn = original_function;
```
The mutation operator would replace this with:
```
const ORIGINAL: Fn = new_function;
```
where `new_function` is a function that exists in the seed program and has the same signature as `original_function`.

This mutation operator is designed to expose bugs related to constant evaluation and function pointer comparisons, which are relevant to the A-const-eval label. By replacing a constant function pointer with a new one, the operator can trigger bugs that occur when the compiler evaluates constants or compares function pointers.
