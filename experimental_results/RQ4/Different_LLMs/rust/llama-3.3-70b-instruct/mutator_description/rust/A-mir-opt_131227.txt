Mutation Operator: Replace Scalar Type with Pointer Type
Target: Expressions containing scalar types, such as integers or booleans, in functions or global variables.
Description: This mutation operator replaces scalar types with pointer types to trigger bugs related to type mismatches, similar to the bug reported in the issue. 
For example, given the code: 
let var: i32 = 0; 
This mutation operator would change it to: 
let var: *mut i32 = &mut 0;

pub static mut G: i32 = 0; 
This mutation operator would change it to: 
pub static mut G: *mut i32 = &mut 0; 
This change can help expose bugs where the compiler incorrectly handles type conversions or expects a scalar value but receives a pointer instead, as seen in the provided bug report.
