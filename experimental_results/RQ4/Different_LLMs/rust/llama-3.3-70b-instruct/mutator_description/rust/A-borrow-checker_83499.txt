Mutation operator: replace_async_fn_with_non_async_fn
This mutation operator targets async functions in the given code and replaces them with non-async functions. The operator applies to any function marked with the async keyword. 

To apply this mutation operator, first identify all async functions in the given code. Then for each identified async function, remove the async keyword from the function definition. 

For example, given the function definition: 
async fn multiple_named_lifetimes<'a, 'b>(_: u8, ...) {}

The mutation operator would replace it with: 
fn multiple_named_lifetimes<'a, 'b>(_: u8, ...) {}

This mutation operator can help expose bugs related to the borrow checker, as the replaced function may now have different borrowing behavior. The operator achieves high coverage across different program structures and features, as async functions can appear in various contexts. 

Note that this mutation operator prefers to use existing variables, types, and functions in the seed program, and it does not introduce any new elements that are not already declared in the program.
