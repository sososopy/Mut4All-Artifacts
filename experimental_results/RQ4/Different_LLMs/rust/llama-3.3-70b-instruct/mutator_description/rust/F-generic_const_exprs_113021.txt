Mutation Operator: Replace Array Length with Constant Expression

This mutation operator targets array declarations in the code and replaces the length of the array with a constant expression. The goal is to introduce a situation where the compiler is forced to evaluate a constant expression to determine the length of an array, which can trigger bugs related to constant evaluation, such as the one described in the provided bug report.

The operator applies to any array declaration in the code, regardless of its type or location. It replaces the length of the array with a constant expression, which can be a simple constant, an arithmetic expression, or a call to a constant function.

For example, given the following code:
```
let arr: [i32; 10] = [0; 10];
```
The mutation operator might replace the length of the array with a constant expression, resulting in:
```
let arr: [i32; 10 + 5] = [0; 10 + 5];
```
Or, using a constant function:
```
const fn len() -> usize { 10 }
let arr: [i32; len()] = [0; len()];
```
This mutation operator can help expose bugs in the compiler's constant evaluation mechanism, particularly when dealing with generic const expressions, as indicated by the F-generic_const_exprs label in the bug report. By introducing constant expressions in array lengths, the operator increases the likelihood of triggering such bugs, allowing developers to identify and fix issues related to constant evaluation in the compiler.
