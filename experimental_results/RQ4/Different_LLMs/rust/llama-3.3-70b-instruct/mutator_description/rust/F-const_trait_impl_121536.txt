Mutation Operator: Modify Const Function Signature
Target: Constant functions within trait implementations that have effects.
Description: This mutation operator modifies the signature of constant functions within trait implementations by adding or removing the `const` keyword, and adding or modifying the `effects` parameter to the `ConstContext` of the function.
Example: For a given constant function `const fn foo(self) -> ReturnType`, the mutation operator may change it to `const fn foo(self, effects: Effects) -> ReturnType` or remove the `const` keyword to make it a non-const function.
Application: This mutation operator applies to trait implementations that have constant functions, especially those that involve effects, such as the `Add` trait implementation for the `Vec3` struct in the provided Rust code.
Changes: The mutation operator may add or remove the `const` keyword, add or modify the `effects` parameter, or change the `ConstContext` to `Maybe` or other variants, to test the compiler's handling of constant functions with effects.
