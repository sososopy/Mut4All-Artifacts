Mutation operator: ReplaceEnumWithStruct
This mutation operator targets enum declarations in the code and replaces them with struct declarations. 
It applies to any enum declaration, regardless of its location or context within the program. 
The replacement involves changing the keyword 'enum' to 'struct' and adjusting the syntax accordingly, 
for example by replacing enum variants with struct fields. 
The goal is to test how the compiler handles the differences between enums and structs, 
especially in terms of layout and ABI, which is relevant to the bug report provided. 
The mutation operator prefers to use existing types and variables in the seed program, 
and if new elements need to be introduced, they should be declared with specific and unambiguous types. 
For instance, if a new field is added to the replaced struct, its type should be an existing type in the program, 
such as an integer or a floating-point type, rather than a complex or user-defined type. 
The mutation should ensure that the modified code is syntactically correct and compilable, 
even if it may trigger errors or warnings due to semantic issues. 
By applying this mutation operator, we can test the compiler's handling of enum and struct layouts, 
which is directly related to the bug report's focus on layout and ABI issues.
