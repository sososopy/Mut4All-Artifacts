Mutation Operator: ReplaceAsyncAwait
This mutation operator targets async/await code constructs and applies to any function or block that contains an async or await expression. 
It replaces an existing async block with an equivalent non-async block, or vice versa, to test how the compiler handles the conversion between asynchronous and synchronous code. 
The operator achieves high coverage by applying to a wide range of program structures and features, including functions, closures, and loops. 
For example, given a function with an async block, the operator might replace it with a non-async block, or add an await expression to a non-async function. 
To illustrate, consider a function like async |check, a, b| { temp.abs_diff(12); }, the operator might mutate it to |check, a, b| { temp.abs_diff(12); } or async |check, a, b| { await temp.abs_diff(12); }. 
This helps to ensure that the compiler correctly handles the differences between async and non-async code, and exposes bugs related to async/await functionality. 
Note that the operator uses existing variables, types, and functions in the seed program, avoiding the introduction of new elements unless necessary, and clearly outlines the changes made to the code.
