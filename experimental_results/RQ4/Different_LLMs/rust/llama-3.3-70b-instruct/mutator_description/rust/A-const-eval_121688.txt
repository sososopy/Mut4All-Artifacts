Mutation operator: replace_function_pointer_comparison
This mutation operator targets the comparison of function pointers in constant evaluation contexts. It applies to code that uses function pointers as arguments to const functions, similar to the provided example. 
The operator replaces the comparison of function pointers using the equality operator with a call to a new function that takes the two function pointers as arguments and returns a boolean value indicating whether they are equal. 
This new function can be defined in terms of the original comparison, but with additional logic to handle the comparison of function pointers with different types or lifetime parameters, which may trigger bugs in the const evaluation pipeline. 
For example, given the original code: 
const fn cmp(x: fn(), y: for<'a> fn()) -> bool { unsafe { x == y } }
The mutation operator would replace it with: 
const fn cmp(x: fn(), y: for<'a> fn()) -> bool { equal_functions(x, y) }
Where equal_functions is a new function that takes two function pointers and returns a boolean value. 
This mutation operator can help expose bugs in the const evaluation pipeline related to the comparison of function pointers with different types or lifetime parameters.
