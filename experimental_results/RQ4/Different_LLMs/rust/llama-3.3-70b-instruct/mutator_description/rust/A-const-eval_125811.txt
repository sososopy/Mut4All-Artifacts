Mutation operator: change_enum_variant_order 
This mutation operator targets the code construct of enums and modifies the order of the variants. 
The change_enum_variant_order operator applies to all enum definitions in the given Rust code.
It reorders the variants of each enum in a different way, such as reversing the order or shuffling the variants.
For example, given an enum like enum Color { Red, Green, Blue }, the operator might change it to enum Color { Blue, Red, Green }.
The goal of this operator is to test the robustness of the compiler when dealing with different enum layouts.
By changing the order of the variants, it can help expose bugs related to enum handling, such as those related to transmutability and discriminant values. 
The operator should be applied to all enums in the code, including those that are used as fields in structs or as types in functions.
Note that this operator does not introduce any new elements, such as types or functions, and only modifies the existing enum definitions. 
The changes made by this operator are limited to the enum definitions and do not affect other parts of the code.
