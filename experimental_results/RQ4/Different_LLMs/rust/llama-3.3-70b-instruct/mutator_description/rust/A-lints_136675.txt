Mutation operator: ReplaceMatchArmWithCatchAll
This mutation operator targets match statements and replaces one of the match arms with a catch-all arm (_). 
It applies to any match statement in the code, regardless of the type of the value being matched or the number of match arms.
The operator uses existing variables and types in the seed program, and does not introduce any new variables or types.
To apply this mutation operator, identify a match statement in the code and select one of the match arms. 
Replace the selected arm with a catch-all arm (_), effectively removing the original arm and allowing any value to match this new arm.
For example, given the match statement:
match x {
    1 => println("one"),
    2 => println("two"),
    _ => println("something else"),
}
This mutation operator might replace the second arm with a catch-all arm, resulting in:
match x {
    1 => println("one"),
    _ => println("something else"),
}
