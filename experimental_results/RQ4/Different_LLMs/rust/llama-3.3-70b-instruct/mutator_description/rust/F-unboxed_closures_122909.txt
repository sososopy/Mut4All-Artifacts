Mutation operator: ReplaceExternalFunctionABI
Target: Functions with external ABI
Description: Replace the ABI of a function with an external ABI, for example, replace "extern rust-call" with "extern c" or vice versa.
Application: This mutation operator applies to all functions with an external ABI.
Example: Replace "extern rust-call" with "extern c" in a function declaration.
Change: Replace the ABI of a function, for example, change "extern rust-call fn try_get(&self) -> Option<Arc<T>> {}" to "extern c fn try_get(&self) -> Option<Arc<T>> {}".
Note: This mutation operator is designed to test the compiler's handling of different external ABIs, which may trigger bugs like the one reported in the issue.
