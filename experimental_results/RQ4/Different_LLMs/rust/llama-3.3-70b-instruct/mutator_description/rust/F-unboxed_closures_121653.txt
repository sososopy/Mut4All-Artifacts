Mutation Operator: Change Trait Bound
Target: Trait definitions with higher-ranked trait bounds
Description: This mutation operator targets trait definitions that use higher-ranked trait bounds, which are trait bounds that involve lifetimes or other type parameters. The mutation operator will change the trait bound to a different bound, such as changing a bound from `Fn(&'a ())` to `Fn(&'static ())` or to a different trait bound like `FnMut(&'a ())`. This mutation is likely to expose bugs related to the handling of higher-ranked trait bounds, such as the one reported in the bug title.
Example: Given a trait definition like `trait Dispatch { fn dispatch(self); } impl<T: for<'a> Fn<(&'a (),)>> Dispatch for T { ... }`, the mutation operator might change the bound to `impl<T: for<'a> FnMut<(&'a (),)>> Dispatch for T { ... }`. This change could potentially trigger bugs in the compiler's handling of trait bounds and higher-ranked lifetimes.
