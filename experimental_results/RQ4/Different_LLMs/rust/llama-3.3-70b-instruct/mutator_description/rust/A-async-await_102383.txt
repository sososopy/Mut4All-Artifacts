Mutation operator: swap_await_expressions 
This mutation operator targets async expressions within the same function scope. It applies to programs containing multiple await expressions, specifically where the awaited values are used in assignment operations. 

The operator identifies two await expressions within the same scope and swaps their positions, effectively interchanging the order in which the asynchronous operations are executed. 

For instance, given a function with two await expressions like this: 
let result1 = async { expression1 }.await; 
let result2 = async { expression2 }.await; 
The mutation operator would transform it into: 
let result1 = async { expression2 }.await; 
let result2 = async { expression1 }.await; 

This swap can reveal issues related to the handling of asynchronous operations, such as the bug described in the report where an ICE occurs due to improper drop tracking involving await in the left-hand side of an assignment. 

By applying this mutation, test cases can be generated that target the interaction between multiple await expressions and their impact on program state, potentially exposing bugs similar to the one reported, where the order of asynchronous operations affects the correctness of the program.
