Mutation Operator: AsyncClosureArgumentSwap
This mutation operator targets async move closures and swaps the order of arguments within the closure.
It applies to async move closures with multiple arguments.
The operator works by identifying the arguments within the closure and swapping their order.
For example, given the following code:
let wrapped_task = task.then(async move |mut arg1: Type1, mut arg2: Type2| {
    // closure body
})
The mutation operator would transform it into:
let wrapped_task = task.then(async move |mut arg2: Type2, mut arg1: Type1| {
    // closure body
})
This operator is designed to test the compiler's ability to handle argument ordering within async move closures, which is relevant to the bug report provided.
The bug report indicates an issue with async move closures and borrow checking, and this operator can help expose similar issues by modifying the argument order and observing the compiler's behavior.
