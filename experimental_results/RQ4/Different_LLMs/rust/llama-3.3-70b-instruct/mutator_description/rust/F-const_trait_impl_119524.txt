Mutation operator: Replace Trait Bound
This mutation operator targets the bounds of a trait in a function signature and replaces them with a different trait bound, such as replacing a lifetime with a const bound, to test how the compiler handles different trait bounds and their interactions.
For example, given a function signature like `fn foo(x: ~const From<_>)`, this mutation operator could replace `~const` with `dyn` or another trait bound, resulting in `fn foo(x: dyn From<_>)`.
This operator applies to any function signature that includes a trait bound, and can be used to test the compiler's handling of different trait bounds and their interactions, which is relevant to the bug report F-const_trait_impl.
