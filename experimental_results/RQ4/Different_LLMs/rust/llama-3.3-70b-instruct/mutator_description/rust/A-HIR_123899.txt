Mutation operator: Change Lifetime Parameters
This mutation operator targets Rust code constructs that involve lifetime parameters. It applies to functions, structs, and traits that have lifetime parameters specified. 
The operator works by modifying the lifetime parameters in the following ways: 
- changing the name of a lifetime parameter, 
- adding a new lifetime parameter, 
- removing an existing lifetime parameter, 
- swapping the order of lifetime parameters. 
For example, given a function like `pub fn g(val: T<'a>) -> _ {}`, the mutation operator could change it to `pub fn g<'b>(val: T<'b>) -> _ {}` by renaming the lifetime parameter from `'a` to `'b`. 
This operator requires that the seed program already contains lifetime parameters, and it will modify these parameters to create new versions of the code. 
The goal is to test how the Rust compiler handles different lifetime parameters and to expose any bugs related to lifetime inference and variance computation.
