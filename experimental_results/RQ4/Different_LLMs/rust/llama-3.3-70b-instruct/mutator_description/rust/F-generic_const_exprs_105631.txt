mutation operator: swap_default_and_non_default_generic_params 
this mutation operator targets generic structures where some parameters have default values and others do not. 
it swaps the order of a default and a non-default generic parameter in a generic definition. 
for example, given a generic struct definition like struct A<const B: str = 1, C>, this operator would mutate it into struct A<const C, B: str = 1>. 
the goal is to test the compiler's handling of default and non-default generic parameters, especially when they are mixed together, as seen in the provided bug report. 
this operator applies to any generic definition, including structs, enums, traits, and functions, that have a mix of default and non-default generic parameters. 
by swapping these parameters, we can test how the compiler handles the changed order and whether it correctly enforces the rule that generic parameters with defaults must be trailing.
