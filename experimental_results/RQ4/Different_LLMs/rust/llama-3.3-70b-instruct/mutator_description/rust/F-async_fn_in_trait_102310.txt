Mutation operator: ReplaceAsyncFnWithMethodCall
Replace an async function definition in a trait with a method call to the same function, introducing a new method with the same name and signature, and then call this new method from the original function definition. This operator targets async functions in traits, especially those with generic parameters, and applies to code constructs where async functions are defined inside traits. For example, given a trait with an async function like async fn transaction, replace it with a call to a new method, say, transaction_helper, which has the same signature and is defined in the same trait, thus: 
replace async fn transaction with async fn transaction { self.transaction_helper() } and add a new method async fn transaction_helper. 
This operator can help expose bugs similar to the one reported, where the presence of generic parameters in async functions within traits causes the compiler to ICE, by increasing the complexity of the trait and its methods, thus increasing the likelihood of triggering such bugs.
