Mutation operator: Change Array Index Access to Out of Bounds Access
This mutation operator targets array and vector indexing operations in the provided Rust code. It applies to any instance where an array or vector is accessed using an index. 
The goal is to replace valid index accesses with out-of-bounds accesses to simulate the conditions that may trigger the index out of bounds bug. 
For example, given a vector V with a valid indexing operation V[i], this operator would change it to V[i + V.len()] or V[-1] to introduce an out-of-bounds access. 
This change can help expose bugs related to indexing and bounds checking in the Rust compiler. 
The operator should be applied to all array and vector indexing operations in the provided code, including those within library functions and user-defined functions. 
The changes should be made by replacing the existing index value with an out-of-bounds index value, while keeping the rest of the code unchanged. 
By applying this mutation operator, we can increase the likelihood of triggering the index out of bounds bug and test the Rust compiler's handling of such errors.
