Mutation operator: ChangeConstToNonConst 
This mutation operator targets the const keyword in function declarations and changes it to non-const by removing the const keyword. It applies to functions that have the const keyword before the fn keyword, indicating that the function can be evaluated at compile-time. 

For example, given a function declaration like this: 
const fn foo() { ... } 
The mutation operator would change it to: 
fn foo() { ... } 

This change can help expose bugs related to the const_trait_impl feature, as it may cause the compiler to attempt to evaluate a function at runtime instead of compile-time, potentially revealing issues with the implementation of const traits. The operator is widely adaptable to seed programs and can be applied to various functions, including those that implement const traits. 

To apply this mutation operator, simply remove the const keyword from function declarations in the seed program. If a function does not have the const keyword, this operator does not apply. The goal is to achieve high coverage across different program structures and features, so it is recommended to apply this operator to multiple functions in the seed program. 

Note that this operator only changes the const keyword in function declarations and does not introduce any new variables, types, or functions. It uses existing elements in the seed program, making it a targeted and controlled mutation operator.
