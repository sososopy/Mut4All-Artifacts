Mutation operator: SwapTypeParameters
This mutation operator targets struct or function definitions with generic type parameters and swaps the order of two type parameters in the definition. 
It applies to any struct or function that has at least two generic type parameters.
For example, given a struct definition like "struct A<const B: str = 1, C>;", this mutation operator could swap the order of B and C to get "struct A<C, const B: str = 1>;".
If the original code has "struct A<T, U>;", after applying this mutation operator, it could become "struct A<U, T>;".
This operator achieves high coverage across different program structures and features by modifying the generic type parameters of various definitions.
It uses existing variables and types in the seed program, so no new elements need to be declared.
To apply this mutation operator, identify a struct or function definition with at least two generic type parameters, and then swap the order of two type parameters in the definition.
