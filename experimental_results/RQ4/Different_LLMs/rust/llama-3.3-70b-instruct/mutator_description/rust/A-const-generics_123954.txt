Mutation operator: swap_const_generics_and_type_generics 
This mutation operator targets Rust code that uses const generics and type generics. It swaps the order of const generic parameters and type generic parameters in a generic struct or enum definition. For example, given the code 
struct A<const N: usize = {2 + 1}, B = u8> {
    _i: [B; N]
}
the mutation operator would transform it into 
struct A<B = u8, const N: usize = {2 + 1}> {
    _i: [B; N]
}
This operator is likely to expose bugs related to the interaction between const generics and type generics, as seen in the provided bug report. By swapping the order of these parameters, the operator can trigger issues with how the Rust compiler handles the scoping and evaluation of const expressions in the context of generic definitions. The goal is to test the compiler's ability to correctly handle these complex generic constructs and identify potential errors or inconsistencies in its behavior.
