Mutation operator: swap associated type bounds
This mutation operator targets a specific code construct, namely associated types with bounds in trait definitions. It applies to all trait definitions in the given code.
The mutation operator works by swapping the bounds of two associated types in a trait definition. For example, given a trait definition like this:
trait Trait {
    type A: Bound1;
    type B: Bound2;
}
The mutation operator would swap the bounds of A and B, resulting in:
trait Trait {
    type A: Bound2;
    type B: Bound1;
}
This mutation operator achieves high coverage across different program structures and features by targeting associated types, which are a fundamental feature of Rust's type system. The swap operation is simple and widely applicable, making it a good candidate for exposing bugs in the Rust compiler.
The mutation operator uses existing variables, types, and functions in the seed program, making it easy to apply and avoiding the introduction of new, potentially ambiguous elements. The changes made by the mutation operator are clear and well-defined, making it easy to understand and apply.
