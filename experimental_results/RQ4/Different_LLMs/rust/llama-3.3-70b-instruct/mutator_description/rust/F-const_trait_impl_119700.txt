Mutation operator: replace_const_trait_impl_with_default_impl
This mutation operator targets trait implementations with the const_trait feature and replaces them with default implementations without the const_trait feature. It applies to code constructs that use the const_trait feature to define trait implementations. The goal is to test how the Rust compiler handles the removal of const_trait and whether it correctly reports errors or behaves unexpectedly.

To apply this mutation, first identify a const trait implementation in the seed program. Then, remove the const_trait feature from the trait definition and replace the implementation with a default implementation that does not use const_trait. For example, given a trait implementation like this:
trait Bar {
    fn bar() -> u8;
}
#[const_trait]
trait Foo {
    fn foo() -> u8
    where
        Self: ~const Bar,
    {
        <Self as Bar>::bar() * 6
    }
}
The mutated code would be:

    fn bar() -> u8;
}
trait Foo {
    fn foo() -> u8
    where
        Self: Bar,
    {
        <Self as Bar>::bar() * 6
    }
}
This mutation operator tests the compiler's ability to handle changes in trait implementations and ensures that the removal of const_trait does not cause internal compiler errors or unexpected behavior. By applying this mutation, we can increase the chances of exposing bugs related to the const_trait_impl feature.
