Mutation Operator: AttributeSwapper
This mutation operator targets the use of attributes in Rust code, specifically swapping the positions of inner and outer attributes. 
It applies to any code construct that uses attributes, such as functions, structs, and modules. 
The operator will swap the positions of inner and outer attributes, for example, #![allow(missing_docs)] and #[derive(serde::Serialize)], to test the compiler's handling of attribute ordering. 
This can help expose bugs like the one reported, where the compiler incorrectly handles inner and outer attributes in a proc macro. 
To apply this mutation, the operator will identify all attribute pairs in the code, and then swap their positions, ensuring that the resulting code is syntactically valid. 
No new variables, types, or functions will be introduced, and existing ones will be reused to avoid ambiguity. 
The goal is to achieve high coverage across different program structures and features, focusing on attribute usage. 
For example, given a struct with an inner attribute #![deny(missing_docs)] and an outer attribute #[derive(serde::Serialize)], the operator will swap them to produce #![derive(serde::Serialize)] and #[deny(missing_docs)], testing the compiler's ability to handle this change.
