This operator applies to Rust code constructs involving generic types, particularly those with complex type parameter definitions and instantiations. 
It replaces a type parameter in a generic type definition with another existing type parameter in the same definition.

this operator could replace `CellIdx` with `MAX_LENGTH` to create a new definition `struct RobinHashTable<const MAX_LENGTH: usize, MAX_LENGTH = <Cond<{}, usize, u32> as Ret>::R> {}`.
