Mutation operator: ChangeGenericConstExprToNonGenericConstExpr

This mutation operator targets constant expressions that use generic types and replaces them with non-generic constant expressions. 

For example, given a generic struct with a constant expression, 
the mutation operator would replace the generic type with a non-generic type.

1. Identify all constant expressions in the code that use generic types.
2. For each constant expression, replace the generic type with a non-generic type.
3. If the non-generic type does not exist in the code, 
   declare a new non-generic type with the same structure as the generic type,

regardless of where they appear in the code.
