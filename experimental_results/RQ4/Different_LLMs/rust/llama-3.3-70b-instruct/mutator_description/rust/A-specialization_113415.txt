Mutation Operator: SwapAssociatedTypeDefinition
This mutation operator targets the associated type definition of a trait and swaps it with another associated type definition from the same trait or a different trait. 
Applicable to: Rust code with trait definitions that have associated types.
The mutation operator can be applied by finding all associated type definitions, selecting two of them, and swapping their positions. 
For example, given the following Rust code:
trait Assoc {
    type Output;
    type AnotherOutput;
}
 
default impl<T> Assoc for T {
    type Output = bool;
    type AnotherOutput = u8;
}
 
impl Assoc for u8 {
    type Output = i8;
    type AnotherOutput = u16;
}
The SwapAssociatedTypeDefinition mutation operator can swap the definitions of Output and AnotherOutput, resulting in:
trait Assoc {
    type Output;
    type AnotherOutput;
}
 
default impl<T> Assoc for T {
    type Output = u8;
    type AnotherOutput = bool;
}
 
impl Assoc for u8 {
    type Output = u16;
    type AnotherOutput = i8;
}
This mutation can help expose bugs related to associated type handling in the Rust compiler, such as incorrect type checking or code generation. The A-specialization label in the bug report indicates that the bug is related to specialization, and swapping associated type definitions can trigger such bugs.
