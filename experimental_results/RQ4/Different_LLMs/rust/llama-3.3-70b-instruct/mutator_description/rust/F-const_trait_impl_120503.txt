Mutation operator: ReplaceConstWithAsync 
this operator targets functions declared with the const keyword and replaces it with async, this can help trigger bugs related to const and async functions, especially when they are used in trait implementations. 
it applies to functions in trait implementations, 
for example, given a function declared as const fn, replace it with async fn and see if the compiler correctly handles the change, 
the operator achieves high coverage across different program structures and features by applying to all const functions, 
for instance, const fn foo() { code } becomes async fn foo() { code }, 
note that the operator only replaces the const keyword with async and does not modify any other part of the function, 
also note that if a function is already declared as async, this operator will not modify it, 
the goal is to test how the compiler handles the interaction between const and async functions in different contexts.
