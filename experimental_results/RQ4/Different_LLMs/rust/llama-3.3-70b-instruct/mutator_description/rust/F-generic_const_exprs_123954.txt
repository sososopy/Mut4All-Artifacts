Mutation operator: SwapGenericParameterOrder
This mutation operator targets generic structs with const generic parameters and default const expressions. It swaps the order of the generic parameters to test how the Rust compiler handles the changed order. The operator applies to struct definitions with generic parameters, where at least one parameter has a default const expression. 

To perform the mutation, identify a struct definition with generic parameters, such as the given code: 
struct A<const N: usize = {2 + 1}, B = u8> {
    _i: [B; N]
}

Then, swap the order of the generic parameters, resulting in:
struct A<B = u8, const N: usize = {2 + 1}> {
    _i: [B; N]
}

This mutation operator tests the Rust compiler's handling of generic parameter order and default const expressions, which is relevant to the F-generic_const_exprs bug label in the given bug report. By swapping the order of the generic parameters, the operator helps to identify potential issues with the compiler's handling of const generics and default expressions.
