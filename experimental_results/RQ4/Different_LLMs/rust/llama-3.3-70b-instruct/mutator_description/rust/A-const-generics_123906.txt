Mutation operator: ReplaceConstGenericWithNonConstVariable
This mutation operator targets functions that use constant generics, specifically those with a const parameter of type usize, and replaces the const parameter with a non-const variable of the same type. 
It applies to functions with a const generics parameter, such as fn as_chunks<const N: usize>() -> [u8; N], where N is a const parameter of type usize. 
To apply this mutation, first, identify the const parameter, then replace it with a non-const variable of the same type, for example, replacing const N: usize with let N: usize = some_value, where some_value is a value that already exists in the seed program or a new value declared as a constant or a variable with a specific value. 
For instance, if a seed program has a function fn as_chunks<const N: usize>() -> [u8; N], this mutation operator would replace it with fn as_chunks() -> [u8; N], where N is a non-const variable, such as a function parameter or a local variable, like let N: usize = 10, to test how the Rust compiler handles the change from a const generic to a non-const variable. 
This operator aims to expose bugs related to constant generics by changing the const nature of the generic parameter, which can help achieve high coverage across different program structures and features, especially those related to constant generics and their handling by the Rust compiler.
