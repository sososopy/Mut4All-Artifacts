Mutation Operator: DuplicateFieldInNestedStruct
This mutation operator targets nested structs and unions in Rust code, aiming to expose bugs related to field uniqueness checks in the compiler. It applies to any struct or union that contains at least one nested struct or union.

To apply this mutation, the operator will:

1. Identify a struct or union in the code.
2. Check if it contains any nested structs or unions.
3. If it does, the operator will duplicate an existing field within the nested struct or union.
4. The duplicated field will have the same name as an existing field in the same scope.

For example, given a struct like this:
struct Outer {
    nested: struct {
        a: u8,
    },
}

The mutation operator might transform it into:
struct Outer {
    nested: struct {
        a: u8,
        a: u8, // Duplicated field
    },
}

This mutation is designed to trigger bugs related to field uniqueness checks, such as the one described in the provided bug report. By duplicating fields in nested structs and unions, this operator increases the likelihood of exposing issues in the compiler's handling of such constructs.
