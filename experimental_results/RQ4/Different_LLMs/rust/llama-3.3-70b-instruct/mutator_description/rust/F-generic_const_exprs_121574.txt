Mutation operator: ChangeGenericConstraintOperator
This operator targets the where clause of a generic function or type definition, specifically the trait bounds on type parameters. The goal is to modify or add trait bounds to see how the compiler handles different constraint combinations. 
It will apply to any generic function or type definition with a where clause. 
To apply this operator, first locate a generic definition with a where clause. Then, choose a type parameter and modify its trait bounds by either adding a new bound, removing an existing one, or replacing one bound with another. 
For example, given a function like fn foo<T: Iterator>(t: T), this operator might produce fn foo<T: Iterator + Clone>(t: T) or fn foo<T: Send>(t: T), introducing new constraints to test the compiler's handling of these changes. 
This can help expose bugs related to generic constraints, such as issues with trait resolution, coherence, or constraint solving, which are relevant to the F-generic_const_exprs feature.
