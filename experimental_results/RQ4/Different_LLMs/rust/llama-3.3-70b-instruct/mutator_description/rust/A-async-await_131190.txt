Mutation Operator: ChangeAsyncFunctionToSync
This mutation operator targets the async functions in the given code and changes them to sync functions. 
It applies to functions that are defined with the async keyword and is used to test how the compiler handles changes in function type. 
The mutation involves replacing the async keyword with nothing, effectively changing the function to a synchronous function. 
For example, given the pseudo-code 
async function foo() { 
  // function body 
}, 
the mutation operator would change it to 
function foo() { 
  // function body 
}. 
This change can help identify bugs in the compiler related to async and await, as well as code coverage and instrumentation. 
The change is made by replacing the async keyword and adjusting the function call accordingly. 
Note that this mutation operator may introduce compilation errors if the function is using await or other async-specific features.
