Mutation Operator: ReplaceAwaitExpression
This mutation operator targets async functions and replaces await expressions with a blocking call to the awaited future, effectively removing the asynchronous behavior. 

For example, given the following code:
```

    let future = async { 1 + 1 };
    let result = future.await;
    println!("{}", result);
}
```
The mutation operator would replace the await expression with a blocking call:
