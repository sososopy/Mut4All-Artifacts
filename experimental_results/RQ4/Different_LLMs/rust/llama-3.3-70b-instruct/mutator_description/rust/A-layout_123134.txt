Mutation operator: SwapFieldOrder
This mutation operator targets struct definitions in the code and swaps the order of two fields. 
It applies to structs with at least two fields. 
The operator randomly selects two fields in the struct and exchanges their positions. 
For example, given a struct with fields a and b, the operator might transform it into a struct with fields b and a. 
No new variables, types, or functions are introduced by this operator, and it only rearranges existing fields. 
The changes are limited to the struct definition and do not affect other parts of the code. 
This operator achieves high coverage across different program structures and features by being applicable to any struct definition, regardless of the types of its fields or the context in which it is used. 
The operator is designed to test the compiler's handling of struct layouts and field ordering, which is relevant to the bug report's focus on layout and field issues.
