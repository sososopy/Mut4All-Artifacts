This mutation operator targets the type parameter in a struct or trait definition and replaces it with a trait that extends the Sized trait. The goal is to check if the compiler can correctly handle the replacement and still maintain the correctness of the code. 
For example, given the code 
struct Foo<T: ?Sized>();

struct Foo<T: Sized + MyTrait>();
where MyTrait is a trait that extends Sized.
