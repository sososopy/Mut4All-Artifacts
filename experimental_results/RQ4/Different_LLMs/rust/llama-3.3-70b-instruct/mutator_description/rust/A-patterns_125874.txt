Mutation operator: ReplaceStructFieldWithWildcardPattern
Target: Struct patterns in match statements.
This operator replaces a specific field in a struct pattern with a wildcard pattern '..' to potentially expose bugs related to A-patterns, such as incorrect handling of associated types in constructor sets.
For example, given the code 'match strct { Bar { foo: 1, .. } => {} }', the operator would replace 'foo: 1' with '..', resulting in 'match strct { Bar { .. } => {} }'.
The goal is to achieve high coverage across different program structures and features, and to test the compiler's ability to handle various pattern matching scenarios, including those involving A-patterns.
The operator would be applied to existing struct fields in the seed program, without introducing new variables, types, or functions.
To apply this operator, the following steps would be taken: 
1. Identify struct patterns in match statements.
2. Select a specific field in the struct pattern.
3. Replace the selected field with a wildcard pattern '..'.
The result would be a mutated version of the original code, which can be used to test the compiler's behavior and potentially expose bugs related to A-patterns.
