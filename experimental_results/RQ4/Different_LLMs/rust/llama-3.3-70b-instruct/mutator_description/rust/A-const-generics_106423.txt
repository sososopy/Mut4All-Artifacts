Mutation Operator: ReplaceConstantGenericsWithConstants
This mutation operator targets generic constants in constant generic definitions and replaces them with regular constants to check the behavior of the Rust compiler when dealing with constant generics.
It applies to any code that uses constant generics, particularly in the context of generic functions or structs.
The operator replaces a generic constant, for example, a value of type const T where T is a type parameter, with a concrete constant value, such as an integer or a floating-point number.
For example, given a function like fn foo<const N: usize>() { ... }, the mutation operator would change it to fn foo() { let N = 10; ... }, replacing the generic constant N with a concrete value.
The goal is to test how the compiler handles the transition from generic constants to regular constants and to identify potential bugs in the compiler's handling of constant generics, such as the one reported in the given bug report.
