Mutation operator: ReplaceTraitBounds
Replace the bounds of a trait with a different set of bounds, including changing the type of the bound, adding or removing bounds, or reordering the existing bounds.
This operator targets trait definitions and applies to the where clause of a trait definition.
For example, given a trait definition like `trait Document { fn cursor(&self) -> Lexer::Cursor<'_>; }`, this operator could change it to `trait Document: Sized { fn cursor(&self) -> Lexer::Cursor<'static>; }`, or to `trait Document: Send { fn cursor(&self) -> Lexer::Cursor<'_>; }`.
The goal of this operator is to test the compiler's ability to handle different types of trait bounds and to ensure that it correctly enforces these bounds when checking the validity of a program.
This operator is likely to expose bugs related to F-inherent_associated_types, as it directly manipulates the bounds of a trait, which can affect the compiler's ability to infer the types of associated types.
