Mutation operator: Replace_Yield_With_Return
This mutation operator targets functions that use the yield keyword, typically found in generator functions or coroutines. It replaces the yield statement with a return statement, potentially altering the control flow and return type of the function. 

The operator applies to any function that contains a yield statement. 

To perform this mutation, first, identify all yield statements within the function body. Then, replace each yield statement with a return statement, ensuring the syntax is correct and the return type matches the function's return type, if applicable. 

For example, given a function like:
function foo() -> impl Iterator {
  yield value;
}

The mutated version would be:
function foo() -> impl Iterator {
  return value;
}

This mutation can help expose bugs related to the borrow checker, coroutines, and trait implementations, as seen in the provided bug report. By changing the yield statement to a return statement, the mutation operator can reveal issues with the function's return type, borrow checking, and overall control flow. 

Note that this mutation operator requires attention to the function's return type and the type of the value being returned or yielded, to ensure the mutation is valid and meaningful.
