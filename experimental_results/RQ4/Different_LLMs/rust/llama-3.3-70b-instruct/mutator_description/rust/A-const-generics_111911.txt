Mutation operator: ReplaceLifetimeParameterWithStaticLifetime
This mutation operator targets the code construct of const generic types with lifetime parameters. It applies to any function or type that has a const generic parameter with a lifetime bound. 
The operator replaces a lifetime parameter with the static lifetime, similar to the bug report where the const generic type has a lifetime parameter that causes an ICE.
For example, given a function like pub async fn foo<const X: 'a>(&'a str) {}, the mutation operator would replace 'a with 'static, resulting in pub async fn foo<const X: 'static>(&'static str) {}.
The goal is to test the compiler's handling of const generic types with different lifetime parameters, which could expose bugs related to lifetime inference, substitution, and checking. 
This operator achieves high coverage across different program structures and features by targeting a specific but common code pattern, and it uses existing variables and types in the seed program to minimize the introduction of new elements.
