Mutation operator: ChangeConstType
This mutation operator targets constant type declarations in Rust code, specifically where a constant is declared with a specific type. It applies to code structures where constants are used in generic types or const expressions.

The ChangeConstType operator works by identifying constant type declarations and changing the type of the constant to a different type that is compatible with the expression or generic type constraints. For example, if a constant A is declared as a usize, this operator might change it to an i64, or vice versa, if the expression or generic type constraints allow it.

To apply this operator, first, identify constant type declarations in the code. Then, determine the type constraints of the surrounding expression or generic type. Next, select a compatible type that is different from the original type and replace the original type with the new type.

For instance, given a code snippet like:
```rust
struct Outer<const A: i64, const B: usize>();
```
The ChangeConstType operator could change the type of A from i64 to usize, resulting in:
```rust
struct Outer<const A: usize, const B: usize>();
```
This mutation can help expose bugs related to constant evaluation, generic types, and type checking, which are relevant to the F-generic_const_exprs feature and the ICE (Internal Compiler Error) reported in the bug trace. The goal is to test the compiler's ability to handle different types in constant expressions and generic types, potentially revealing errors in type checking or const evaluation.
