Mutation Operator: ReplaceGenericArgsWithConstants
Target a specific code construct: generic arguments in trait definitions and function signatures.
This mutation operator replaces generic arguments in trait definitions and function signatures with constants, which can help trigger bugs related to generic const expressions.
For example, given a trait definition like `trait B { type U<T: A>; }`, this operator could replace `T` with a constant type, such as `i32`, resulting in `trait B { type U<i32: A>; }`.
Similarly, for a function signature like `fn f<T: B<U<1i32> = ()>>() {}`, this operator could replace `T` with a constant type, such as `i32`, resulting in `fn f<i32: B<U<1i32> = ()>>() {}`.
By applying this mutation operator, we can test the compiler's ability to handle generic const expressions and identify potential bugs in this area.
