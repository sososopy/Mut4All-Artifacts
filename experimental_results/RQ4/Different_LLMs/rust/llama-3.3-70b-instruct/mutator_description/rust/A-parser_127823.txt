Mutation operator: ReplaceAssignmentOperator
This mutation operator targets the assignment operator in variable declarations and replaces it with a similar-looking Unicode character, such as replacing '=' with '⩵', to test the compiler's ability to handle Unicode characters and distinguish between them. 
It applies to all variable declarations in the code, including constants and let bindings. 
The goal is to check if the compiler correctly identifies and handles the replacement character, providing accurate error messages or suggestions for correction. 
For example, given the code 'const A: usize = 2;', the mutation operator would replace the '=' with '⩵', resulting in 'const A: usize ⩵ 2;'. 
This tests the compiler's awareness of Unicode characters and its ability to provide helpful diagnostics when encountering unfamiliar or invalid characters in the code. 
The operator modifies existing code by introducing a Unicode character that resembles a standard assignment operator, aiming to trigger compiler bugs related to Unicode handling and parsing. 
It achieves high coverage by applying to all variable declarations, using existing variables and types in the seed program, and introducing a specific, well-defined change that tests a particular aspect of the compiler's behavior.
