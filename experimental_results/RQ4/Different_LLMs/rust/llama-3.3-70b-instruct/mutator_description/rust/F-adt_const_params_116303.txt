Mutation operator: ReplaceConstParamWithUnsupportedType 
This mutation operator targets constant parameters in functions, specifically those that are marked as const parameters using the `const` keyword. 
It applies when a constant parameter is of a type that implements the `ConstParamTy` trait but the compiler does not support it due to internal limitations.
The operator works by replacing the type of the constant parameter with an unsupported type, such as a string or a custom struct, 
to check how the compiler handles such a scenario.
For example, if we have a function `fn function_with_my_str<const S: &'static MyStr>() -> &'static MyStr`, 
the mutation operator would replace `MyStr` with a string type, resulting in `fn function_with_my_str<const S: &'static str>() -> &'static str`.
This would help to expose bugs like the one reported, where the compiler panics when trying to compute the symbol for a constant parameter of an unsupported type.
