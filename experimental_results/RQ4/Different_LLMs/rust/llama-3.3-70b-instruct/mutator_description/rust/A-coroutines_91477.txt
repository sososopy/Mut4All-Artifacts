Mutation operator: ReplaceYieldWithReturn
This mutation operator targets functions that use the yield keyword, specifically those that implement iterators. It replaces the yield statement with a return statement, effectively changing the behavior of the function from producing a series of values to producing a single value. 

The operator applies to functions that contain at least one yield statement. 

For example, given a function like this:
function get_values() -> impl Iterator {
    // some code
    yield value1;
    // some code
    yield value2;
}

The mutation operator would replace the yield statements with return statements, resulting in:
function get_values() -> impl Iterator {
    // some code
    return value1;
    // some code
    return value2;
}

Note that this mutation operator may introduce compilation errors if the return type of the function does not match the type of the value being returned. 

To apply this mutation operator, existing variables, types, and functions in the seed program should be used. If new elements need to be introduced, they should be declared explicitly, avoiding ambiguity. 

This mutation operator is designed to test the compiler's handling of coroutines and iterators, specifically the yield keyword, which is related to the bug report labeled as A-coroutines. By replacing yield with return, the operator tests the compiler's ability to handle changes in the function's behavior and identify potential errors.
