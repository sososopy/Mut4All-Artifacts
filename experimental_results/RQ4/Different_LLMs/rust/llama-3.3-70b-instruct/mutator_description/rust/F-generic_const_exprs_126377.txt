Mutation operator: ReplaceConstValue
This operator targets constant values in generic const expressions and replaces them with values of different types to trigger potential type mismatch errors. 
It applies to constant values used in generic const expressions, such as boolean, integer, or other constant values.
For example, given a generic const expression like `assert::is_transmutable::<Src, Dst, {0u8}, false, false, false>()`, this operator can replace the constant value `0u8` with a boolean value `true` or `false`, or replace the boolean value `false` with an integer value `0u8` to test the robustness of the generic const expression.
The replacement values should be chosen from existing variables or constants in the seed program to avoid introducing new undefined elements.
If new elements need to be introduced, they should be declared with specific types, such as `let new_bool: bool = true;` or `let new_int: u8 = 1;`.
This operator can help achieve high coverage across different program structures and features, especially those related to generic const expressions and constant values.
