Mutation operator: DuplicateConstParam 
This mutation operator targets generic parameters in trait definitions, and it works by duplicating a const parameter name. 
It applies to trait definitions that include const parameters, such as trait Foo<const M: u8, const N: u8>. 
The operator will modify the trait definition to have duplicate const parameter names, for example, trait Foo<const M: u8, const M: u8>. 
This is likely to expose bugs related to const generics, as seen in the provided bug report, where the compiler unexpectedly panics due to a duplicated const param name in a trait. 
To achieve high coverage, this operator should be applied to various trait definitions with different types and numbers of const parameters. 
For example, if a seed program contains a trait definition like trait Bar<const X: i32, const Y: bool>, the operator will modify it to trait Bar<const X: i32, const X: bool> or trait Bar<const Y: bool, const Y: bool>. 
The changes made by this operator are limited to the trait definition and do not introduce new elements, types, or variables, thus avoiding ambiguity and ensuring the mutated code is still valid Rust code.
