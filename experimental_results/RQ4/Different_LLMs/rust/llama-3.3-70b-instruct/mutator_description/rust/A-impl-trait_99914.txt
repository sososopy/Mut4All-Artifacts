Mutation operator: Replace async function calls with equivalent sync function calls by removing the async keyword and the await expression.

This mutation operator targets asynchronous function calls and replaces them with synchronous function calls. The async keyword and the await expression are removed to achieve this. The goal is to test how the compiler handles the change from asynchronous to synchronous code, which can help expose bugs related to concurrency and async/await functionality.

For example, given the following code:
```
async fn foo() {
    let initial_exchange: Result<usize, Error> = todo!();
    initial_exchange.and_then(|_|
        serve_udp_tunnel()
    ).await;
}
```
The mutated code would be:
```
fn foo() {
    let initial_exchange: Result<usize, Error> = todo!();
    initial_exchange.and_then(|_|
        serve_udp_tunnel()
    );
}
```
This mutation operator applies to any code that uses async/await syntax and can help test the compiler's handling of asynchronous code. By replacing async function calls with sync function calls, we can test how the compiler handles the differences in concurrency and control flow between async and sync code.
