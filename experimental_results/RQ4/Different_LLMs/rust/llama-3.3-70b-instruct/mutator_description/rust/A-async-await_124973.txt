Mutation operator: swap named lifetime parameters in a function signature
This mutation operator targets functions with multiple named lifetime parameters and swaps the positions of two randomly chosen lifetime parameters in the function signature. 
For example, given a function signature like `async fn multiple_named_lifetimes<'a, 'b>(_: u8) {}`, this operator could transform it into `async fn multiple_named_lifetimes<'b, 'a>(_: u8) {}`. 
This change is likely to expose bugs in the Rust compiler's handling of named lifetimes, particularly in the context of async/await, as indicated by the A-async-await label in the bug report. 
By swapping the lifetime parameters, we are testing the compiler's ability to correctly infer and check the lifetimes of variables in the presence of complex lifetime relationships. 
This operator applies to any function with multiple named lifetime parameters, regardless of the function's return type or the types of its parameters. 
The goal is to achieve high coverage across different program structures and features, and to test the compiler's robustness in handling a wide range of input programs.
