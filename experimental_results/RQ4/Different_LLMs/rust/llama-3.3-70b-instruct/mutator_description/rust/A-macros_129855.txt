mutation operator: async_to_sync 
this operator targets async closures and applies to code constructs that use async closures as arguments to macro invocations. 
it replaces the async closure with a synchronous closure, effectively changing the code to use a synchronous closure instead of an asynchronous one. 
for example, given the code foo(async |who| println!()) it would be mutated to foo(|who| println!()) by removing the async keyword from the closure. 
this change can potentially trigger bugs related to the interaction between async closures and macros, such as the one described in the bug report. 
the goal of this operator is to test how the compiler handles the change from asynchronous to synchronous code and whether it correctly resolves the macros in the new context. 
preference is given to using existing variables, types, or functions in the seed program, and if new elements are introduced, they should be declared in a way that avoids ambiguity. 
in this case, no new elements are introduced, and the existing closure is simply modified to be synchronous. 
this operator achieves high coverage across different program structures and features by targeting a specific code construct and applying to a wide range of macros and async closures.
