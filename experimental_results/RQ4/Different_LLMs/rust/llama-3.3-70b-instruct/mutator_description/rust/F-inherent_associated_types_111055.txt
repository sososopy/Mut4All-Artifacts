Mutation Operator: ReplaceConstWithVariable
This mutation operator targets constant values used in generic type parameters and replaces them with variables. It applies to code constructs where a constant value is used as a type parameter in a generic type, such as in the provided bug report where `const DEFAULT_CHUNK_SIZE: usize = 65536;` is used as a default value for the type parameter `C` in the `Writer` struct.

The mutation operator works by identifying constant values used in generic type parameters and replacing them with variables that are already declared in the scope. If no suitable variable is found, a new variable with a similar type is introduced. The goal is to test how the compiler handles the substitution of constants with variables in generic types, which could expose bugs related to type checking and substitution.

```

    data: [u8; C],

```

It is widely applicable to seed programs that use generic types with constant or variable type parameters.
