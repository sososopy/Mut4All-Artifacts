Mutation operator: ReplaceConstWithStatic 
This mutation operator targets constant values in the code and replaces them with static variables. 
It applies to any constant declaration in the code. 
To perform this mutation, first identify all constant declarations in the code. 
Then, for each constant declaration, replace the const keyword with the static keyword. 
For example, if the code contains the line "const x: i32 = 5;", the mutated code would be "static x: i32 = 5;". 
This mutation operator is designed to test the compiler's handling of constant evaluation and static variables. 
By replacing constants with static variables, we can test whether the compiler correctly handles the differences between these two concepts. 
The expected output of this mutation operator is that the code should still compile and run correctly, but the behavior may change due to the differences between constants and static variables. 
This mutation operator achieves high coverage across different program structures and features, as it can be applied to any constant declaration in the code, regardless of the surrounding code structure. 
The mutation operator uses existing variables and types in the seed program, and does not introduce any new elements that are not already declared in the code. 
The changes made by this mutation operator are clearly defined and easy to understand, making it a useful tool for testing the compiler's behavior.
