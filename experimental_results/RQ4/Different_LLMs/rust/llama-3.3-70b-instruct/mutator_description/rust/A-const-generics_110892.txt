mutation operator: 
replace generic constant arguments with their negation in const generic functions, 
specifically targeting const generic functions that use the generic const exprs feature, 
replacing bool const arguments with their opposite, 
using variables and types that already exist in the seed program, 
and avoiding introducing new elements unless necessary for the mutation, 
in which case they should be declared with specific and unambiguous terms. 

This mutation operator is designed to target specific code constructs, 
such as const generic functions, and apply changes to the generic constant arguments, 
which in this case are the bool values used in the from_options function. 
By replacing these arguments with their negation, the mutation operator can help expose bugs 
related to const generics and generic const exprs, such as the one described in the bug report. 
The goal is to achieve high coverage across different program structures and features, 
while using variables, types, and functions that already exist in the seed program, 
and clearly outlining the changes that need to be made.
