Mutation Operator: Insert Yield Statement
This mutation operator targets functions and inserts a yield statement at a random location within the function body, potentially triggering borrow checker errors, especially in the context of coroutines and impl trait. The yield statement can be inserted at any point where a statement is allowed, including within control flow statements, loops, and blocks. The goal is to test the compiler's ability to handle yield statements in various contexts and ensure that it correctly checks borrowing and lifetime rules. 

This operator applies to functions that do not already contain a yield statement, and it does not modify existing yield statements. The yield statement is inserted with the syntax "yield;" which is a placeholder and does not return any value, thus preserving the original function's return type if any. 

This mutation is relevant because the bug report provided involves an issue with yield syntax and its interaction with the borrow checker, making this a targeted approach to test similar scenarios that might expose related bugs in the Rust compiler. 

Example: Given a function like "fn test() { let x = 5; }", the mutation could result in "fn test() { let x = 5; yield; }" to test how the compiler handles the introduction of a yield statement in a simple function context. 

This mutation operator is designed to achieve high coverage across different program structures by applying to a wide range of functions and to test the compiler's handling of yield statements in various contexts, including those that might involve borrowing and lifetime issues.
