Mutation Operator: Replace Trait Bounds with Supertraits

Target: Code constructs that use trait bounds, especially those involving supertraits.

Description: This mutation operator targets code that uses trait bounds, and replaces them with their supertraits. For example, in a trait definition like `trait MyTrait: std::iter::Iterator`, the mutation operator would replace `std::iter::Iterator` with one of its supertraits, such as `std::iter::ExactSizeIterator`. This can help expose bugs in the trait system, especially those related to trait bounds and supertraits.

Example: 
Original code: 
```
trait MyTrait: std::iter::Iterator {
    // ...
}
```
Mutated code: 
```
trait MyTrait: std::iter::ExactSizeIterator {
    // ...
}
```
This mutation operator applies to any code that uses trait bounds, including trait definitions, impl blocks, and function signatures. By replacing trait bounds with their supertraits, this operator can help test the robustness of the trait system and expose bugs related to trait inheritance and bounds.
