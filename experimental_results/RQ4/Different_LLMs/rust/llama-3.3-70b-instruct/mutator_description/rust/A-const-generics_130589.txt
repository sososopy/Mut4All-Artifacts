Mutation operator: ReplaceConstGenericWithMacroExpansion
This mutation operator targets code constructs that use const generics in conjunction with macros. It applies to any Rust code that uses const generics with macros. 
The operator works by replacing const generic values with their macro-expanded equivalents. 
For example, given a struct S with a const generic V, and a macro wrap that expands to its argument, the mutation operator would replace Const<{ wrap!(V) }> with Const<{ V }>.
