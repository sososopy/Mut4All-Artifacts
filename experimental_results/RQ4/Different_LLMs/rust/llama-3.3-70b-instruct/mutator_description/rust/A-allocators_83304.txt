Mutation Operator: ReplaceAllocator
This operator targets the code construct of using allocator APIs via references. It applies to any code that uses the allocator API, such as Box::new_in, to allocate memory on the heap. 
The mutation involves replacing the existing allocator with a different one, for example, replacing std::alloc::Global with std::alloc::System. 
This can be achieved by replacing the allocator reference in the code with a different allocator type that already exists in the seed program. 
If no alternative allocator type exists, a new one can be introduced by declaring a new instance of the std::alloc::Allocator trait, which requires implementing the allocate, deallocate, and usable_size methods. 
For example, the mutated code for the given bug report would be: 
pub fn foo() -> u8 {
    *Box::new_in(0, &std::alloc::System)
}
This mutation operator is designed to expose bugs related to allocator APIs and memory layout, which are relevant to the given bug report labeled with A-allocators and A-layout.
