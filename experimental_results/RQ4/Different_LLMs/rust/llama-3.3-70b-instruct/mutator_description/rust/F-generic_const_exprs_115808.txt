Mutation operator: ChangeGenericConstraint
This mutation operator targets generic constraints on traits and changes them to different traits or removes them altogether. The goal is to test the robustness of the Rust compiler in handling complex generic constraints, which is relevant to the given bug report labeled with F-generic_const_exprs.
The change involves selecting a generic constraint on a trait, such as where I: Concat<J>, and modifying it to use a different trait, like where I: Mul<J>, or removing the constraint altogether. The mutation should apply to existing traits and types within the seed program, without introducing new, customized data names, types, or variable names.
For example, given the code:
```rust
impl<I: Indices<N>, J: Indices<N>, const N: usize> Mul<Tensor<J, N>> for Tensor<I, N>
where
    I: Concat<J>,
    <I as Concat<J>>::Output: Indices<N>,
{
    // implementation
}
```
The mutation could result in:
```rust
impl<I: Indices<N>, J: Indices<N>, const N: usize> Mul<Tensor<J, N>> for Tensor<I, N>
where
    I: Mul<J>,
    <I as Mul<J>>::Output: Indices<N>,
{
    // implementation
}
```
Or:
```rust
impl<I: Indices<N>, J: Indices<N>, const N: usize> Mul<Tensor<J, N>> for Tensor<I, N>
{
    // implementation
}
```
This mutation targets the specific code construct of generic constraints and aims to cover a wide range of program structures and features by applying to various traits and types within the seed program, without introducing new elements unless specified and avoiding ambiguous terms. The goal is to expose bugs related to generic constraints and const expressions, which are relevant to the given bug report.
