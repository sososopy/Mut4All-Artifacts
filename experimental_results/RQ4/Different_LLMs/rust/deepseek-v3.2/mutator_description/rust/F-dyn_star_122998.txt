mutation operator: Insert a cast to dyn* with a trait object that is then coerced to a regular dyn trait object. This applies to any expression of a type that implements at least one trait, where the expression can be cast to a dyn* type and then further coerced or cast to a regular dyn trait type. Specifically, locate an expression E of type T where T implements trait Trait. Insert a new variable declaration: let temp_var: dyn* Trait = E; then replace uses of E with temp_var as Box<dyn Trait> or &temp_var as &dyn Trait, depending on context. If the original context expects a Box<dyn Trait>, mutate to Box::new(temp_var) as Box<dyn Trait>. If the original context expects a &dyn Trait, mutate to &temp_var as &dyn Trait. Ensure the dyn_star feature is enabled in the crate root with #![feature(dyn_star)] if not already present. Use a fresh variable name that does not conflict with existing names in scope, such as inserting a numeric suffix to an existing variable name. For example, given a seed program with a trait Send and an expression &(), mutate to: let x_dynstar: dyn* Send = &(); Box::new(x_dynstar) as Box<dyn Send>;. This mutation should be applied to expressions that are of a type that implements a trait and are used in a context that expects a dyn trait object, or can be adapted to such a context by adding a cast.
