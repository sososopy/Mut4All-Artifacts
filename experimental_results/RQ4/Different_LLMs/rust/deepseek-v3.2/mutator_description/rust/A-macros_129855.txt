mutation operator
Target the combination of async closures and macro invocations, specifically when a macro is invoked inside an async closure body. This mutation applies to any async closure defined with the async keyword followed by a closure parameter list and body. The mutation changes the async closure by inserting a macro invocation into its body. If the closure body is already a block, the macro invocation is added as a statement at the beginning of that block. If the closure body is an expression, it is wrapped in a block, and the macro invocation is added as a statement before the expression. The macro used should be an existing macro from the seed program, such as println! or vec!, or if no macro exists, a simple macro like println!("") can be introduced. To introduce a macro, add a use statement for the macro if needed, e.g., use std::println; for println!. The mutation ensures the macro call is syntactically correct and uses existing or newly introduced identifiers appropriately. For example, given an async closure async |x| { existing_code }, mutate to async |x| { some_macro!(); existing_code }. If the closure is async |x| expression, mutate to async |x| { some_macro!(); expression }.
