Mutation operator: Insert an empty union as an unnamed field in a struct or enum variant. This operator targets struct and enum definitions. For any struct or enum variant in the seed program, add a new field that is an unnamed union with an empty body. The new field should be inserted among existing fields, or if the struct/enum is empty, as the sole field. The union must be declared without any fields inside. Specifically, locate a struct definition or an enum variant with a struct-like body (i.e., a variant that uses curly braces and fields). Within that body, add a field with the pattern: `_: union { }`. If the seed program has no such struct or enum, but has a union definition elsewhere, adapt by creating a new struct containing this field. Ensure the mutation uses existing identifiers from the seed where possible; do not introduce new names for the field (it is unnamed). If the seed has no union type defined, the mutation still applies because `union` is a built-in keyword. The mutated code should be syntactically valid Rust (though possibly triggering feature-gate errors or ICEs). Example: Original struct `struct S { x: i32 }` becomes `struct S { x: i32, _: union { } }`. Original enum `enum E { V { a: bool } }` becomes `enum E { V { a: bool, _: union { } } }`. This operator exploits the compiler's handling of unnamed fields and empty unions, which may lead to missing data in the AST and cause ICEs during pretty-printing or other phases.
