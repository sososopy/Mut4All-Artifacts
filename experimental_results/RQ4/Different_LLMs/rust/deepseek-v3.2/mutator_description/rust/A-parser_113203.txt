Mutation operator: Insert an await keyword as a prefix to a block expression that is used as a function call argument or directly as a call receiver. This operator targets expressions where a block `{...}` is followed by parentheses `(...)` indicating a call, and inserts `.await` before the block. Specifically, when the seed program contains an expression of the form `{...}()` (a block immediately called as a function), mutate it to `await {...}()`. If the block is used as an argument, for instance `foo({...})`, mutate to `foo(await {...})`. This replicates the pattern in the bug report where `await{}()` triggers an internal compiler error due to incorrect span handling in error reporting. The mutation should only apply when the edition is 2018 or later, as `await` is a keyword in those editions. Use existing variable names and types from the seed program; do not introduce new identifiers. This mutation can expose parser and diagnostics bugs related to the interaction of `.await` syntax with invalid or unexpected expression contexts.
