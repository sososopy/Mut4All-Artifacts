mutation operator: Insert a slice creation with out-of-bounds length and subsequent indexing operation within a const context. This mutation targets code that performs pointer arithmetic and slice creation in const blocks or const functions. The operator first identifies any existing array or slice variable in the seed program. It then creates a pointer to an element one past the end of the array using the as_ptr method and add. This pointer is used to create a slice via std::ptr::slice_from_raw_parts with an extremely large length, specifically usize::MAX. Finally, it adds a statement that attempts to index this slice at a high index, such as usize::MAX - 1, to trigger potential overflow during CTFE. The new code is inserted within the same const context where the original array or slice is defined, ensuring all used types and functions are already in scope. If the seed program does not contain a suitable array or slice, the operator does not apply. Example transformation: Given a seed containing 'const { let arr = [1, 2]; }', mutate to 'const { let arr = [1, 2]; unsafe { let ptr = arr.as_ptr().add(arr.len()); let fat = std::ptr::slice_from_raw_parts(ptr, usize::MAX); let _ = (*fat)[usize::MAX - 1]; } }'. This uses only existing names and types from the seed.
