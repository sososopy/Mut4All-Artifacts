mutation operator: replace array indexing in constant expression with out-of-bounds index using a trait-associated constant

this mutation applies when a constant expression contains an array indexing operation where the index is a compile-time constant integer literal. the mutation replaces the integer literal index with a trait-associated constant that evaluates to a value that is out of bounds for the array length.

steps: first, identify any constant expression of the form [e0, e1, ..., en][index] where index is an integer literal. then, check if there exists a trait with an associated constant of type usize in scope; if not, introduce a new trait with an associated constant. define an impl for a concrete type that sets the associated constant to a value greater than or equal to the array length. replace the original index with trait_name::associated_const_name. ensure the trait is implemented for the relevant type used in the context.

example: given seed code with an array [5, 6, 7] indexed by 2, the mutation changes the index to a trait-associated constant that yields 42, producing [5, 6, 7][trait_name::constant_name]. the trait and impl are added if they do not exist, using existing types from the seed program for the impl.
