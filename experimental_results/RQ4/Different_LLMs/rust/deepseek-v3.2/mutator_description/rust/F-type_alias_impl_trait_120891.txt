Mutation operator: Replace a type alias with impl Trait with a trait implementation that uses the same type alias.

This mutation operator targets type alias impl Trait (TAIT) definitions that are used in trait implementations. It applies when a seed program contains a type alias defined as `type Name = impl Trait;` (or with generic parameters `type Name<T: Bound> = impl Trait;`) and there is an existing trait `TraitName`. The operator adds an impl block that implements `TraitName` for the type alias `Name` (or `Name<ConcreteType>` if generic), where `ConcreteType` is a type that satisfies the bound and is already present in the seed program. If no such type exists, the mutation does not apply.

Steps: 1. Identify a type alias `Alias` defined as `impl SomeTrait` (with or without generic parameters). 2. Identify a trait `TraitName` already defined in the seed program (not `SomeTrait` from the alias definition). 3. If `Alias` is generic with a bound `Bound`, find a concrete type `Concrete` in the seed program that implements or satisfies `Bound`. 4. Add an impl block: `impl TraitName for Alias` (or `impl TraitName for Alias<Concrete>` if generic). Ensure the crate already has `#![feature(type_alias_impl_trait)]` if the seed uses TAIT; otherwise add it.

Example: Seed contains `type MyAlias = impl Display;` and trait `MyTrait`. Mutation adds `impl MyTrait for MyAlias {}`. If seed contains `type MyAlias<T: Iterator> = impl Display;` and type `Vec<u32>` (which does not satisfy Iterator), mutation does not apply. If seed contains `type MyAlias<T: Iterator> = impl Display;` and type `std::ops::Range<u32>` (which implements Iterator), mutation adds `impl MyTrait for MyAlias<std::ops::Range<u32>> {}`.
