mutation operator: Replace a const generic argument that is a function pointer with a function pointer cast to a different function pointer type, preserving the same function value but introducing a type mismatch in the const generic parameter. This operator targets const generic parameters in struct, enum, or type alias definitions where the const parameter's type is a function pointer (e.g., const F: fn() -> u32). The mutation changes the argument provided when instantiating the generic type by casting the function pointer to a different function pointer type (e.g., casting fn() -> u32 to fn() -> i32). The new function pointer type must differ from the expected const generic parameter type, but the function itself must be defined in the seed program. This mutation should be applied to the usage site of the generic type, not its definition. For example, if the seed program contains a struct definition like struct Wrapper<const F: fn() -> u32>; and an instantiation Wrapper::<function> where function is a fn() -> u32, mutate it to Wrapper::<function as fn() -> i32>. This introduces a type mismatch because the const parameter expects fn() -> u32 but receives fn() -> i32, which may trigger internal compiler errors during const evaluation or type checking, especially with the generic_const_exprs feature. Ensure the function used in the cast exists in the seed program; do not introduce new functions. If no suitable function exists, the mutation does not apply. The mutation should only be applied when the generic_const_exprs feature is enabled in the seed program.
