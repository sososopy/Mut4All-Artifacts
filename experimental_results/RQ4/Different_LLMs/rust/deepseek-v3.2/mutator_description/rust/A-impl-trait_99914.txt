mutation operator: Replace a closure that returns an async block with a closure that directly calls an async function using .await, and apply .await to the result of a method chain that includes this closure. This mutation applies to any closure within a method chain where the closure's body is a call to an async function without .await. The mutation changes the closure to include .await on the async function call and then adds .await to the entire method chain if not already present. Use the existing async function name from the seed program. If the seed program does not contain an async function, introduce a simple async function that returns unit, defined as async fn dummy_async() {}. The mutation must ensure that the closure's parameter list remains unchanged and that the method chain is terminated with .await. Example transformation: If the seed contains let x = some_result.and_then(|p| async_fn(p));, mutate to let x = some_result.and_then(|p| async_fn(p).await).await;. If the seed contains let x = some_result.and_then(|p| async_fn(p)).some_other_method();, mutate to let x = some_result.and_then(|p| async_fn(p).await).some_other_method().await;.
