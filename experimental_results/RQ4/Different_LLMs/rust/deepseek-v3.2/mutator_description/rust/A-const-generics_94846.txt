This mutation applies when a struct, enum, or function has a generic const parameter with a default value. It targets the default value expression. The operator changes the default value from its original expression to a const expression that uses the same generic const parameter's identifier. For example, if a struct is defined as `struct S<const N: usize = 5>`, the mutation would alter it to `struct S<const N: usize = N>`.
