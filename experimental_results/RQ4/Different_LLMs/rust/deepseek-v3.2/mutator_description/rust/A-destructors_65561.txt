mutation operator: Replace impl Trait return type in infinite recursion with a concrete unit return to bypass recursion-checking assumptions.

Applies to functions declared with `-> impl Trait` return type where the function body consists solely of a recursive call to itself (direct tail recursion). The operator modifies the function to return the unit type `()` instead, while preserving the recursive call. This targets compiler assumptions about infinite recursion in impl Trait contexts.

Steps:
1. Identify a function definition with return type `impl Trait` (where Trait is any trait).
2. Check if the function body contains exactly one statement: a recursive call to the same function, optionally wrapped in a block expression.
3. Change the return type from `impl Trait` to `()`.
4. Ensure the function still compiles by adding a unit return if needed, but keep the recursive call as the last expression.

Example transformation:
Original:
fn function_name() -> impl TraitName {
    function_name()
}
Mutated:
fn function_name() -> () {
    function_name()
}

Note: The trait `TraitName` must exist in scope. The mutation may cause type errors if the function is called in a context expecting the trait, but this operator aims to trigger internal compiler errors related to destructors or impl Trait handling, not to produce valid code.
