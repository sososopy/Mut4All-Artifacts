mutation operator: replace const generic parameter's lifetime with a different lifetime from the same function's context. apply to const generic parameters in function definitions that have an explicit lifetime annotation. the mutation substitutes the original lifetime with another lifetime parameter already declared in the same function signature, or if none exists, with 'static. if the const parameter's type is a reference with a lifetime, change that lifetime. do not introduce new lifetime parameters. for example, given a seed function `fn bar<'a, 'b, const C: &'a u8>()`, mutate to `fn bar<'a, 'b, const C: &'b u8>()`. if the seed is `async fn foo<const X: &'static str>()` and no other lifetimes are present, no change occurs because 'static is the only option. but if the seed is `async fn foo<'a, const X: &'a str>()`, mutate to `async fn foo<'a, const X: &'static str>()` because 'static is always available. ensure the mutated const parameter type remains syntactically valid.
