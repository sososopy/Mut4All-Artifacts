mutation operator
This mutation operator targets macro invocations within function bodies, specifically when the macro expands to a statement that includes a cfg attribute placed on a non-tail expression. The operator modifies the macro invocation to insert a cfg attribute directly on an argument that is an expression statement, which after macro expansion may become an attribute on a non-tail expression. This applies to any macro invocation within a function body where at least one argument is a simple expression statement like `();`. The mutation changes the macro invocation by adding `#[cfg()]` in front of one of the expression statement arguments inside the macro call. For example, if the seed program contains a macro call like `the_macro!( (); (); );`, the mutation would change it to `the_macro!( #[cfg()] (); (); );`. The cfg attribute is empty, mirroring the bug report. The attribute must be placed immediately before the argument token tree that is an expression statement. This mutation leverages existing macro definitions and function contexts, introducing only the cfg attribute which is a built-in Rust construct, thus avoiding new declarations. The change is precise: locate a macro invocation in a function, identify an argument that is a simple expression statement (e.g., `();`), and prefix it with `#[cfg()]`.
