mutation operator: swap the positions of generic parameters with defaults and those without defaults in a generic parameter list. This operator applies to generic parameter lists in struct, enum, union, trait, impl, and function definitions where there is at least one generic parameter with a default value and at least one generic parameter without a default value. The operator selects a generic parameter with a default value that is not in the last position among generic parameters without defaults and swaps it with the immediately following generic parameter that does not have a default value. If there are multiple such pairs, one is selected arbitrarily. The operator does not introduce new names, types, or values; it only reorders existing generic parameters. For example, if a seed program contains 'struct S<T = u8, U>', after mutation it becomes 'struct S<U, T = u8>'. Similarly, for a function 'fn f<const N: usize = 1, T>() {}', after mutation it becomes 'fn f<T, const N: usize = 1>() {}'. This operator aims to trigger bugs related to the constraint that generic parameters with defaults must be trailing, especially in contexts involving const generics and default values.
