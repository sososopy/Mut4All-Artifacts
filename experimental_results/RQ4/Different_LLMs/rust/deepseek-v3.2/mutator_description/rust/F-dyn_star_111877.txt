Mutation operator: Introduce a dyn* cast in a function that returns an impl Trait with lifetime parameters.
This mutation applies to functions that have a generic lifetime parameter and return an impl Trait, where the impl Trait includes at least one trait bound. The operator modifies the function body to include a cast of an expression to a dyn* type that matches the return type's trait bounds, ensuring the cast expression is valid within the context.
First, identify a function in the seed program that meets these criteria: it must have a lifetime parameter (e.g., fn func<'a>(...) -> impl Trait + 'a) and return an impl Trait with one or more trait bounds (e.g., impl Debug + 'a). If no such function exists, this operator does not apply. For the mutation, within the function body, locate an expression that implements the traits specified in the return type. If such an expression exists, replace it with a cast to dyn* using the syntax expression as dyn* Trait. For example, if the original function is fn example<'a>(x: impl Debug + 'a) -> impl Debug + 'a { x }, change it to fn example<'a>(x: impl Debug + 'a) -> impl Debug + 'a { x as dyn* Debug }. This introduces a dyn* trait object cast, which may trigger compiler bugs related to dyn* handling, especially with lifetimes and incremental compilation. Ensure the cast uses dyn* followed by the trait name from the return bounds; if multiple traits are present, use the first trait bound listed. The mutation does not introduce new variables or types; it reuses existing ones from the function body.
