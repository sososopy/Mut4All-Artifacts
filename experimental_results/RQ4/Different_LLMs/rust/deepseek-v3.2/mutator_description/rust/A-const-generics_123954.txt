mutation operator
This operator targets struct, enum, union, trait, and impl definitions that have generic parameters. It reorders the generic parameters such that any const generic parameter with a default value is placed before any subsequent type or lifetime parameter that lacks a default. Specifically, for a generic parameter list, if a const parameter with a default exists and is followed by a type parameter without a default, the positions of these two parameters are swapped. This applies only when the const parameter's default is a const expression (e.g., a literal, constant, or arithmetic expression). If the seed program already has a const parameter with a default before a type parameter, no change is made. The operator must preserve all bounds and constraints on the parameters. For example, given a struct definition like 'struct S<T, const N: usize = 5>;', it would be mutated to 'struct S<const N: usize = 5, T>;'. Conversely, if the seed is 'struct S<const N: usize = 5, T>;', no change occurs. The operator should avoid introducing new names or types; it only reorders existing parameters. The change is applied to the first eligible pair of consecutive generic parameters where the first is a type or lifetime without a default and the second is a const with a default, swapping them to place the const with default first. This aims to expose ordering bugs in the compiler's handling of defaulted const generics.
