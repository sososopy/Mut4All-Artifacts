mutation operator: Replace lifetime parameters in async function signatures with a single anonymous lifetime '_ where possible. This operator targets async function declarations with explicitly named lifetime parameters. It applies when an async function has two or more named lifetime parameters in its generic parameter list. The mutation changes the function signature by removing all named lifetime parameters and replacing them with a single anonymous lifetime '_ if the function's parameters and return type permit such a substitution without introducing new named lifetimes. Specifically, for each lifetime parameter in the generic list, if it appears in the function's parameter types or return type, those occurrences are replaced with '_'. The generic parameter list itself is modified to contain only a single '_ lifetime if any lifetimes remain needed, or is removed entirely if no lifetimes are required. For example, an async function like 'async fn foo<'a, 'b>(x: &'a i32, y: &'b i32) -> &'a i32' would be mutated to 'async fn foo<'_>(x: &'_ i32, y: &'_ i32) -> &'_ i32'. Note that if the function's body references any of the removed lifetimes, those references must also be changed to '_' or removed, but the operator only applies to function signatures; the body is left unchanged, which may cause compilation errors but is intended to trigger region-related ICEs. The operator uses existing elements from the seed program; no new variables, types, or functions are introduced.
