mutation operator: Replace a yield expression within a generator with a block that yields a reference to a local variable that is later mutated in a match expression. This operator targets generators (coroutines) that are declared with the static keyword or other storage classes. It applies when a seed program contains a generator with a yield expression. The mutation modifies the yield expression by wrapping it in a block that yields a reference to a mutable local variable declared before the yield. After the yield, the mutation adds a match expression that uses the dereferenced value of that variable in its scrutinee. Specifically, for a yield expression `yield;` in a generator, change it to `{ let x = &mut 0; yield; *x += match { *"" }.len() { _ => 0, }; }` where `x` is a fresh mutable variable name not conflicting with existing names in the scope. The type of `x` is `&mut i32` initialized with `0`. If the seed program already contains a mutable binding of a compatible type in the same scope, reuse that binding's name instead of introducing a new one. The mutation ensures the generator's state includes a reference to a sized type that may become unsized due to layout computation, potentially triggering the assertion failure in the compiler's layout calculation for generator fields.
