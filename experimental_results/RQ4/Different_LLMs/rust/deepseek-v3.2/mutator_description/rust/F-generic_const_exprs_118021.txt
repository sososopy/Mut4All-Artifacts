mutation operator: Introduce an invalid lifetime specifier in a generic parameter list where a lifetime is expected, specifically by replacing a declared lifetime parameter with the reserved keyword 'static without proper lifetime syntax, while also referencing that lifetime elsewhere in the item where it becomes undeclared. This mutation applies to struct, enum, union, trait, or impl definitions that have generic lifetime parameters. For each such item, select one of its lifetime parameters (e.g., 'a) and change it to 'static. If the item uses that lifetime in its body (e.g., in field types, method signatures, or where clauses), keep those references unchanged, creating a mismatch where the lifetime 'static is used as a parameter name (which is invalid) and the original lifetime name becomes undeclared. If the item does not already have lifetime parameters, first introduce a lifetime parameter (e.g., add <'a> after the item name) and then apply the mutation. Ensure the feature generic_const_exprs is enabled in the crate attributes if the seed uses it, otherwise add #![feature(generic_const_exprs)] at the top. For example, given a struct definition: struct MyStruct<'a> { field: &'a i32 }, mutate to: struct MyStruct<'static> { field: &'a i32 }. This introduces the error 'static is a reserved lifetime name and the error use of undeclared lifetime name 'a, which may trigger internal compiler errors in the borrow checker or region handling when combined with generic const expressions.
