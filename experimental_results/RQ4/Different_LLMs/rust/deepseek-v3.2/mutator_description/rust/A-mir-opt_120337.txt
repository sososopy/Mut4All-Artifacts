mutation operator
Introduce nested question mark operator chains on Result types, especially when the inner type is also a Result, and embed them within a block expression that is directly used as the operand for the question mark operator. The mutation applies to any function returning a Result type. Find an expression of type Result<T, E> within the function body. Replace it with a block expression containing a nested Result where the Ok variant holds another Result<T, E> (using the same T and E types from the context), and then apply the question mark operator to the entire block. If the function already returns Result<(), ()>, use that; otherwise, adapt the inner types to match the function's return type. For example, if a function returns Result<U, V>, and there exists an expression like Ok(value), mutate it to { Ok(Ok(value)) }??. Ensure the outer block contains only this nested Result expression. This mutation should be applied to at least one expression in the function, preferably where a simple Ok or Err is returned or where a question mark is already used.
