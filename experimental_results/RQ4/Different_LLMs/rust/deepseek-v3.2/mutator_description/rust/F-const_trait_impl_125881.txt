Mutation operator: Replace const closure with non-const closure in const fn returning impl const Trait.

This operator targets const functions that return an opaque `impl const Trait` type, where the return value is a closure. It applies when the seed program contains a `const fn` with a return type of the form `impl ~const Trait` and the returned expression is a closure, which may be explicitly marked `const`. The mutation changes the closure to be non-const by removing any `const` modifier from the closure expression. If the closure is a move closure, the `move` keyword is preserved, but the `const` keyword is omitted. The surrounding function signature and trait bounds remain unchanged. This creates a mismatch where a const function promises to return a type that implements a const trait, but the actual returned closure may not be eligible for const evaluation, potentially exposing type inference or trait satisfaction bugs in the compiler's const checking logic.

Example: In a const function `const fn example() -> impl ~const Default`, if the return statement is `const || 0`, it is mutated to `|| 0`. If the return statement is `const move || {}`, it is mutated to `move || {}`. The operator only applies when the returned expression is a closure literal. All variable names, types, and function names are taken from the seed program. No new elements are introduced; only the `const` keyword is removed from the closure expression.
