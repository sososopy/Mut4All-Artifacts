mutation operator: Introduce a trait method in a const trait impl that is not declared in the trait definition, and annotate a generic bound on that method with a const trait bound using the ~const syntax. This applies to any const trait implementation block where the trait itself does not have the #[const_trait] attribute.

The mutation modifies the const trait implementation block. For a given const impl block for a trait T for a type Ty, where the trait T is not marked #[const_trait], the mutation adds a new method definition inside that impl block. This method must not be declared in the trait T. The method should have a generic type parameter with a trait bound. This trait bound should be prefixed with ~const. The method's return type should be a type that is not in scope, causing a resolution error. The method body should be a single expression that is a value of that unresolved type.

Specifically, locate a const impl block of the form: impl const TraitName for TypeName { ... }. If the trait TraitName is not preceded by #[const_trait] in its declaration, then within the impl block's braces, insert a new method. The method should have a unique name not used elsewhere in the current scope to avoid collisions. For example, insert a method named method_unused. It should take a generic parameter, e.g., <A>. Apply a bound to this parameter using a trait that is in scope and is intended to be a const trait (like Clone, Add, etc., but note the mutation does not require the trait to actually be #[const_trait]). Prefix this bound with ~const. The method should take self as a parameter. The return type should be a type name that is not defined, such as UndefinedType. The method body should be a single expression that is a value of that undefined type, e.g., UndefinedType. This ensures the type is not found.

Example transformation: If the seed contains: trait MyTrait {} impl const MyTrait for () {}. The mutated code becomes: trait MyTrait {} impl const MyTrait for () { fn method_unused<A: ~const Clone>(self) -> UndefinedType { UndefinedType } }. Here, Clone is assumed to be an in-scope trait name; if Clone is not in scope, use another trait name present in the program. The UndefinedType is a new identifier not declared. This creates a mismatch between the trait definition and its impl, and introduces a ~const bound on a trait in a const impl for a non-const_trait, potentially triggering internal compiler errors related to const trait checking and predicate gathering.
