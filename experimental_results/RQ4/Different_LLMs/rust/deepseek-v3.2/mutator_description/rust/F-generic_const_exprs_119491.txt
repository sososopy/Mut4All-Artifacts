mutation operator: Replace an async block or async closure inside a constant expression context with a non-async block or closure of the same body, or vice versa. This mutation applies when the seed program contains an async block or async closure used within a constant expression, such as within an array length expression, const generic argument, or associated const value. The mutation changes the async keyword to remove it, making the block a regular block, or adds the async keyword if the original block is non-async. For example, if the seed has `let x = async { 1 };` inside a const context, mutate to `let x = { 1 };`. Conversely, if the seed has `let x = { 1 };` inside a const context, mutate to `let x = async { 1 };`. This operator targets the interaction between async constructs and constant evaluation, which can expose internal compiler errors like the one in the bug report where the compiler expected a coroutine type in a const context.
