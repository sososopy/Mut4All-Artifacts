mutation operator: Replace const generic parameter in async function with type alias impl trait bound

This mutation operator targets async functions with const generic parameters. It applies when an async function has a const generic parameter of a concrete type. The mutation changes the const generic parameter's type to a type alias impl trait (TAIT) that is defined elsewhere in the program. Specifically, if the seed program contains a type alias defined as `type Alias = impl Trait;`, and there is an async function with a const generic parameter like `async fn func<const N: ConcreteType>() {}`, the operator will replace `ConcreteType` with `crate::Alias` (or `Alias` if appropriate) in the const generic parameter's type annotation. This mutation requires that the TAIT is already defined in the module hierarchy. The change is made directly in the async function's signature, leaving all other code unchanged. For example, if the seed has `type MyTAIT = impl Display;` and `async fn foo<const N: i32>() {}`, the mutated code becomes `async fn foo<const N: crate::MyTAIT>() {}`. This mutation is designed to expose bugs related to the interaction between const generics, async functions, and TAITs, as seen in the bug report where such a combination triggered an internal compiler error. The operator does not introduce new elements; it uses existing TAIT definitions from the seed program.
