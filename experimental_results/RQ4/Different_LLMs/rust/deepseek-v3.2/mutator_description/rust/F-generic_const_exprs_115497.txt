mutation operator
This mutation operator targets where clauses in functions or trait definitions that involve complex nested combinations of forall binders and associated type bounds, particularly when generic const expressions are also present. It applies when a seed program contains a where clause with a forall binder that introduces lifetime or const parameters, and that binder is used in a trait bound which itself has associated type bounds. The mutation modifies the structure by inserting an additional forall binder inside the associated type bound, nesting it deeper. Specifically, if the seed has a pattern like `for<'a> T: TraitA<'a, AsA: TraitB<'a>>`, it transforms it to `for<'a> T: TraitA<'a, AsA: for<'b> TraitB<'a, 'b>>`. If the seed already has a forall inside, it adds another one, creating deeper nesting. The operator only uses lifetimes or const parameters that are already in scope or introduces new lifetime parameters with fresh names like 'z1, 'z2, etc., ensuring they are distinct from any existing lifetimes. It does not introduce new types or traits; it reuses those from the seed. For const parameters, it uses a fresh const parameter name like N1 with a default value of 0 if needed. The change is applied to the entire where clause item, replacing the old bound with the mutated one. Example transformation: given `fn foo<T>() where for<'a> T: TraitA<'a, AsA: TraitB<'a>> {}`, mutate to `fn foo<T>() where for<'a> T: TraitA<'a, AsA: for<'z1> TraitB<'a, 'z1>> {}`.
