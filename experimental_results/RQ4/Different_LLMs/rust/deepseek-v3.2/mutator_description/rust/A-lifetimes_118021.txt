Mutation Operator: Reserved Lifetime Name Substitution in Generic Parameters

This mutation operator targets generic lifetime parameters in struct, enum, trait, and impl definitions. It replaces a declared lifetime parameter with the reserved lifetime name 'static. This mimics the bug-triggering condition where a reserved name is incorrectly used as a generic parameter, potentially causing inconsistencies in lifetime resolution and region error reporting.

The operator applies when a generic lifetime parameter is declared within angle brackets. For example, in a struct definition like struct Example<'lifetime>, the operator would mutate 'lifetime to 'static. The change is made only at the declaration site, not at usage sites of the lifetime within the type body. This ensures the mutation creates a direct conflict with Rust's lifetime naming rules.

Example mutation:
Original code: struct Container<'param> { field: &'param Type }
Mutated code: struct Container<'static> { field: &'param Type }

In this mutated code, 'static replaces 'param in the generic parameter list. The usage &'param remains unchanged, which may lead to an undeclared lifetime error similar to the bug report. The operator should only apply if 'param is a user-defined lifetime name, not if it is already 'static or another reserved name. This mutation is designed to expose compiler crashes in lifetime checking, especially when combined with features like generic const expressions that may complicate constant evaluation and region analysis.
