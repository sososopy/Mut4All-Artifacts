mutation operator
Target: struct definitions with const generic parameters that have default values using inline const blocks.
Where it applies: In a struct definition where a const generic parameter has a default value expressed as an inline const block (e.g., const { ... }). The mutation operator changes the const generic parameter's default value from an inline const block to a simple constant expression without an inline const block, or vice versa, while attempting to keep the value semantically equivalent if possible. Specifically, if the default is an inline const block containing a single constant expression, replace the entire default with that inner expression. If the default is a simple constant expression, wrap it in an inline const block. This operator applies only when the generic_const_exprs feature is enabled in the seed program.
Mutation steps: Locate a struct definition with a const generic parameter that has a default value. If the default value is an inline const block (e.g., = const { 3 }), extract the inner expression (e.g., 3) and replace the default with that expression (e.g., = 3). If the default value is a simple constant expression (e.g., = 3), wrap it in an inline const block (e.g., = const { 3 }). Ensure that any extracted expression is valid as a const generic argument; if not, abort the mutation. Prefer to use existing constant expressions from the seed program to maintain validity. Do not introduce new names or types; only transform the existing default value.
Example: For the seed code: pub struct S<const N: usize = const { 3 }>; mutate to: pub struct S<const N: usize = 3>; Conversely, for seed: pub struct S<const N: usize = 3>; mutate to: pub struct S<const N: usize = const { 3 }>; This mutation should be applied once per struct definition per const generic parameter with a default.
