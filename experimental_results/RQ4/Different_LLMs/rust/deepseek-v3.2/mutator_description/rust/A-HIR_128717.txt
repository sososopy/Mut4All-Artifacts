mutation operator: Replace ASCII parentheses with their fullwidth Unicode look-alikes in function call arguments.

This operator targets function call expressions. It applies to any call expression where the function name is followed by an opening parenthesis '(' and the argument list ends with a closing parenthesis ')'. The operator changes these ASCII parentheses to their fullwidth Unicode counterparts: '(' becomes '（' (U+FF08 FULLWIDTH LEFT PARENTHESIS) and ')' becomes '）' (U+FF09 FULLWIDTH RIGHT PARENTHESIS). The change is made only to the parentheses tokens themselves, not to any content inside the parentheses. For example, a call like `function_name(arg1, arg2)` becomes `function_name（arg1, arg2）`. The operator should be applied only when the parentheses are directly adjacent to the function name or the last token of the argument list, without introducing whitespace. If the seed program contains no function call expressions, this operator does nothing. The goal is to create a mismatch between the byte positions calculated for these Unicode tokens and the compiler's internal span accounting, potentially triggering assertion failures in the source map or diagnostic subsystems.
