mutation operator
This mutation operator targets generic const expressions in where-clauses. It applies when a where-clause contains a constant expression that uses generic const parameters. The operator replaces a binary arithmetic operator (+, -, *, /, %) within such an expression with a different binary arithmetic operator. The replacement must be among the set of arithmetic operators. For example, if the seed contains `[(); A + B]:`, it could be mutated to `[(); A - B]:` or `[(); A * B]:`. If the seed contains `[(); A * B]:`, it could be mutated to `[(); A + B]:`. The operator is applied only to expressions that are directly used in a where-clause bound like `[(); expr]:`. The types of the operands must remain unchanged; only the operator is swapped. The operator should be chosen from the available arithmetic operators that are valid in constant expressions, avoiding division by zero or overflow in a way that could cause immediate compilation errors unrelated to the bug class. The goal is to trigger internal compiler errors during constant evaluation with mismatched or unexpected operand types across the new operator.
