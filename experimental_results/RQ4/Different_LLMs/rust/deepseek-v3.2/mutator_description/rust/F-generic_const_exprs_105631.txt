mutation operator: Swap the order of a generic parameter with a default value and a subsequent generic parameter without a default value in a struct, enum, union, trait, or function definition. This mutation applies when the seed code contains a generic item (struct, enum, union, trait, or function) with at least two generic parameters where the first parameter has a default value and the second parameter does not. The mutation swaps the positions of these two parameters, placing the parameter without a default before the parameter with a default. The mutation must preserve the original names, types, bounds, and default values of the parameters, only altering their order. If the seed program uses the generic_const_exprs feature, ensure it remains enabled. For example, if the seed contains 'struct S<const N: usize = 1, T>', mutate to 'struct S<T, const N: usize = 1>'. If the seed contains 'fn f<const M: u8 = 0, U>()', mutate to 'fn f<U, const M: u8 = 0>()'. This targets potential ICEs related to substitution index miscalculations when defaulted parameters are not trailing.
