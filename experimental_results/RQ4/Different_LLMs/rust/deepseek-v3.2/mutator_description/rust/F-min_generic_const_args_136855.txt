mutation operator: Replace a constant expression in a generic argument with a function item that is in scope and has the same type as the constant expression.

This mutation applies to generic arguments in type contexts, specifically within array size expressions, const generic parameters, or where constant values are expected in generic arguments. The operator targets a constant expression C that appears as a generic argument, such as in [T; C] or Struct<C>. It replaces C with a function item F that is visible in the current scope and whose return type matches the expected const parameter type (e.g., usize for an array size). The function F must be a free function or an associated function, not a closure or method with a self parameter. If multiple suitable functions exist, one is selected arbitrarily. The mutation introduces a function item where a constant value is required, which can expose bugs in const generic handling, particularly around the evaluation and validation of const arguments during type lowering and monomorphization.

Example: In a seed program with a constant `const N: usize = 5;` and a function `fn f() -> usize { 10 }`, and a type `[i32; N]`, the mutation can change it to `[i32; f]`. The function `f` must be declared in the seed program; no new declarations are introduced. If no suitable function exists, the mutation is not applied.
