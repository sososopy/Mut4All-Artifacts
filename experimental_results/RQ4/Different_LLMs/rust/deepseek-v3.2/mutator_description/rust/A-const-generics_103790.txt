mutation operator: Introduce a duplicate generic parameter name within the same generic parameter list, specifically targeting a const generic parameter that shadows the name of the containing item or another generic parameter. This applies to struct, enum, union, function, trait, and impl definitions that have generic parameters. When mutating, select a const generic parameter within the list. Change its identifier to match the identifier of the containing item or to match another generic parameter already present in the same list, whichever is syntactically possible without introducing new identifiers. For example, if the seed contains 'struct X<const N: usize>', mutate to 'struct X<const X: usize>'. If the seed contains 'fn f<T, const C: u8>()', mutate to 'fn f<T, const T: u8>()' or 'fn f<T, const C: u8, const C: u32>()' by duplicating an existing parameter name. Ensure the mutation does not create undeclared types or values; only rename existing generic parameters. This operator can produce cycles and out-of-range substitutions similar to the bug report.
