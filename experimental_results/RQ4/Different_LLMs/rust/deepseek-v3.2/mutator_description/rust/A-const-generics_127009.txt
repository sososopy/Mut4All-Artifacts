mutation operator: replace a const generic parameter bound in a `for<const ...>` binder with a concrete constant expression that is valid in the current scope. this applies where a `for<const C: T>` binder is used in a where-clause to introduce a const generic parameter, specifically when this parameter appears as a value in a type, such as `[(); C]: Trait`. the mutation changes the late-bound const parameter to an early-bound constant by substituting `C` with a concrete integer literal or a named constant that is in scope, altering the binding from universal quantification to a fixed instance. for example, given a seed program containing `for<const N: usize> [(); N]: Copy`, mutate it to `[(); 0]: Copy` if `0` is a valid array length, or to `[(); CONST]: Copy` if a constant `const CONST: usize = 5;` is already defined in the program. do not introduce new constants if none exist; use a literal like `0`. the change must be made directly in the where-clause, removing the `for<const ...>` binder entirely and updating the trait bound accordingly. this operator targets the compiler's handling of late-bound versus early-bound const parameters in generic bounds, which is a known source of bugs in const generics features.
