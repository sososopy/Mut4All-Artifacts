mutation operator: modify attribute application on statements or expressions by inserting an additional attribute that uses proc_macro_hygiene and stmt_expr_attributes features. This mutation applies when the seed program contains any statement or expression that can have an attribute attached, and the program already uses or could use the stmt_expr_attributes and proc_macro_hygiene features. The mutation will add a dummy proc macro attribute to an existing statement or expression in the seed program. Specifically, locate a statement (like an item declaration, let statement, or expression statement) or an expression (like a block, if expression, or match expression). Before that statement or expression, insert a new attribute of the form #[breaks_rust] where breaks_rust is a proc macro attribute defined in the same crate. If the seed program does not already define such a proc macro, add a minimal definition: include use proc_macro::TokenStream; and define #[proc_macro_attribute] pub fn breaks_rust(_: TokenStream, input: TokenStream) -> TokenStream { input } in the root module. Also ensure the features are enabled by adding #![feature(stmt_expr_attributes, proc_macro_hygiene)] at the crate root if not already present. The mutation changes the seed program by adding the attribute to an existing code structure, potentially triggering internal compiler errors related to token handling for nonterminals. For example, if the seed contains let x = 5;, mutate to #[breaks_rust] let x = 5;. If the seed contains fn main() { println!("hello"); }, mutate to fn main() { #[breaks_rust] println!("hello"); } by placing the attribute on the expression statement inside the block. Prefer attaching to statements or expressions that are not already attributed. The mutation should be applied once per seed program, selecting a suitable target.
