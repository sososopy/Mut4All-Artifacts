mutation operator

Target code construct: This mutation operator targets where clauses that involve const generics with generic const expressions, specifically focusing on the interaction between higher-ranked trait bounds (HRTBs) and const expressions that contain inner items with lifetime parameters. It applies to function signatures that have a where clause containing a const generic type (like an array) whose length is a const expression block that declares a local variable with a lifetime bound that is introduced by a for<'b> quantifier in the where clause itself.

The operator modifies the where clause by introducing a new const generic parameter that references a lifetime from the HRTB inside a const expression block. If the seed program already has a where clause with a const generic type, the operator will replace the const expression with a block that contains a local variable declaration that uses a lifetime bound from the HRTB. If the seed program does not have such a where clause, the operator will add one to an existing function. Specifically, for a given function, if it already has a where clause, append a new predicate of the form: for<'b> [(); { let x: &'b (); 0 }]: . If the function has no where clause, add a where clause with this predicate. The array type must be an existing type from the seed program, such as [(); N] where N is a const expression. If no suitable array type exists, use [(); 0] as a default. The lifetime 'b must be a fresh lifetime name not used elsewhere in the function to avoid conflicts.

Example transformation: For a function fn foo() where T: Trait, change to fn foo() where T: Trait, for<'b> [(); { let x: &'b (); 0 }]: . For a function fn bar() { }, change to fn bar() where for<'b> [(); { let x: &'b (); 0 }]: { }. Ensure the feature flag #![feature(generic_const_exprs)] is present at the crate root if not already present. Do not introduce new types or variables beyond the local x and lifetime 'b. The const expression block must return an integer literal (like 0) to serve as the array length.
