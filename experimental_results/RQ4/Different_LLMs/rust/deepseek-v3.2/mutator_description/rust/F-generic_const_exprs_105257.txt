mutation operator: replace a trait's generic const parameter default value with a reference to a function that returns a constant expression but has a mismatched type or is not a const fn. This operator targets trait definitions that include generic const parameters with default values. It applies when a trait definition contains a const generic parameter that has a default value. The mutation changes the default value to a call to a function that exists in the current scope or is introduced. If a suitable function is not present, introduce a new function with a signature that returns a value of a type that does not match the expected const parameter type, or that is not a const fn, or that is a const fn but returns a value that depends on generic parameters in a way that is not allowed in that context. For example, if the seed program contains a trait definition like trait Trait<const N: usize = 42>, mutate it to trait Trait<const N: usize = some_function()>. Then, declare some_function appropriately: if a function returning usize exists, use it; otherwise, add a new function like fn some_function() -> usize { 42 } or, to induce more complex interactions, fn some_function<T>() -> usize { 42 } to introduce a generic dependency. The key is that the function call should be syntactically valid but may cause internal compiler errors during const evaluation or generic handling.
