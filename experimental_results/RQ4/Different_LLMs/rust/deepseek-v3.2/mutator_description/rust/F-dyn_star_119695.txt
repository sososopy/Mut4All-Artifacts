mutation operator: Replace dyn-star trait object with union type that implements the trait.

This mutation operator targets code that uses the dyn-star feature (dyn* Trait) and has at least one union type that implements the trait. It applies when a function or method has a parameter of type dyn* Trait, and there exists a union type in the current scope that implements that Trait. The mutation changes the argument passed to that function from its original value to a value of that union type, using a constructor that matches the union's fields.

Steps for mutation:
1. Identify a function call where an argument is being passed to a parameter of type dyn* Trait.
2. Check if there is a union type in scope that implements that Trait.
3. If such a union exists, replace the argument expression with a new expression that constructs an instance of that union. Use the union's constructor with appropriate field values. For example, if the union has a field of type T, use a default value for T (like 0 for integer types, false for bool, etc.) or if the original argument has a field of compatible type, use that value.
4. Ensure the union type is brought into scope if needed.

Example in pseudo-code:
Original code snippet:
trait Trait {}
union MyUnion { f: i32 }
impl Trait for MyUnion {}
fn foo(x: dyn* Trait) {}
fn main() {
    let val = some_expression;
    foo(val);
}

Mutated code snippet:
trait Trait {}
union MyUnion { f: i32 }
impl Trait for MyUnion {}
fn foo(x: dyn* Trait) {}
fn main() {
    let val = some_expression;
    foo(MyUnion { f: 0 });
}

Note: The mutation uses the existing union type MyUnion and its field f. The value 0 is used as a placeholder for the integer field; in practice, if the seed program has a variable of type i32 in scope, it could be used instead. The key is to create a valid instance of the union that implements the trait, to replicate the scenario that triggered the ICE.
