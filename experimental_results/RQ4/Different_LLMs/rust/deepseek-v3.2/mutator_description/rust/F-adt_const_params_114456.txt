mutation operator: Substitute a type alias for its underlying type in const generic argument positions. This operator targets const generic arguments that are of a type alias type. It applies when a type alias is defined and then used as a const generic argument in a struct or enum definition, or in an impl block for a specific const generic parameter. The mutation replaces the const generic argument with an expression of the underlying type of the alias that is semantically equivalent. Specifically, if the const generic argument is an identifier that names a constant of a type alias, and that constant's value is a simple literal or array expression, replace the identifier with that literal or array expression directly. The underlying type of the alias must be used for the replacement expression. For seed programs, if the constant's value is a literal like a numeric literal or array, use that literal. If the constant's value is a more complex expression, the operator may not apply unless the expression can be directly substituted without introducing new names. The goal is to create a mismatch or reveal an inconsistency in how the compiler handles type aliases versus their underlying types in const generic contexts. For example, in a seed program containing 'type Alias = u8; const C: Alias = 5; struct S<const X: Alias>; impl S<C> {}', mutate the impl to 'impl S<5> {}'. This changes the const generic argument from a constant of type Alias to a literal of type u8, potentially triggering type relation bugs. Another example: if the seed has 'type Matrix = [usize; 1]; const EMPTY_MATRIX: Matrix = [0; 1]; struct Walk<const R: Matrix>; impl Walk<EMPTY_MATRIX> {}', mutate the impl to 'impl Walk<[0; 1]> {}'. This replaces the constant of type Matrix with an array expression of type [usize; 1], which is the underlying type. The mutation should only be applied if the constant's initializer is a compile-time evaluable expression that does not depend on other constants or generics not in scope. The operator aims to expose bugs where the compiler fails to properly equate or relate a type alias with its underlying type during const generic instantiation or inference.
