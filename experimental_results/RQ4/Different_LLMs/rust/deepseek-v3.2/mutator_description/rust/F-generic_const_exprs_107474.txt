Mutation Operator: Replace Explicit Type Argument with Inferred Call in Generic Const Context


Based on the bug report and the F-generic_const_exprs label, the bug involves an internal compiler error (ICE) when evaluating an associated constant from an inferred generic type parameter within a const generic expression. The bug is triggered when a function uses a generic type parameter in a where clause that constrains an array size using an associated constant from a trait, and the function attempts to call a constructor without explicitly specifying the type argument, relying on inference. The compiler fails to properly handle the const evaluation during trait fulfillment when the type is inferred.

This mutation operator targets function calls within generic functions that have where clauses involving const expressions dependent on associated constants. It applies when a function call explicitly provides generic type arguments (turbofish syntax) and the function's return type or the surrounding context involves a const generic expression that depends on an associated constant of a trait bound. The operator changes the call to rely on type inference by removing the explicit type arguments. Specifically, it replaces a call of the form `function_name::<TypeArgs>(args)` with `function_name(args)`, provided that the function's signature includes a where clause that uses a const expression (like `[(); T::CONST]: Sized`) where `T` is a generic type parameter and `CONST` is an associated constant from a trait bound. This mutation is designed to expose bugs where the compiler's const evaluation during inference may fail, particularly with the generic_const_exprs feature. For example, if the seed program contains a call like `Conster::<COT>::new()`, change it to `Conster::new()`. This should be applied only when the function `new` is defined with a generic parameter that has a trait bound with an associated constant used in a const expression in its where clause, as seen in the bug report. The mutation does not introduce new variables, types, or functions; it simply removes the explicit type arguments from the call site.
