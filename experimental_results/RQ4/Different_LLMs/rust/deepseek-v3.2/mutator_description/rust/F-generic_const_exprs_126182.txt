mutation operator: Replace a generic const parameter in a struct default type with an erroneous const expression that results in a const error during evaluation. This operator targets struct definitions that have a generic const parameter and use a default type for another generic parameter that depends on that const parameter via a trait projection or other complex type expression. It applies when the seed program contains a struct definition with at least one generic const parameter and at least one associated type projection involving that const parameter. The mutation changes the const argument used in the associated type projection to a syntactically valid but type-mismatched const expression, such as replacing a boolean const argument with a unit type `()` literal. Specifically, locate a struct definition of the form `struct StructName<const C: Type, T = <SomeType<C> as Trait>::Assoc> { ... }`. Change the const argument `C` within the default type expression to a mismatched constant, for example, if `C` is of type `bool`, replace `C` with `{}` (an empty block expression yielding `()`). This must be done within the default type expression only, not in other uses of `C`. If the seed program does not contain such a struct definition, the operator does not apply. For instance, given a seed struct `struct S<const N: usize, T = <Wrapper<{N}> as Trait>::Output> {}`, change it to `struct S<const N: usize, T = <Wrapper<{}> as Trait>::Output> {}`, introducing a type mismatch between `usize` and `()`. This creates a const error that may lead to an ICE during well-formedness checking when the compiler attempts to instantiate generic parameters with erroneous const arguments.
