mutation operator Swap Trait Method Name with Trait Name in Implementation
This mutation operator targets trait implementations where a method name matches the trait name. It applies when a trait is implemented for a type and at least one method in the implementation has the same name as the trait itself. The mutation swaps the name of one such method with the trait name in the implementation block, while keeping the trait name unchanged in the trait definition and the method signature unchanged. This creates a mismatch between the implemented method name and the expected trait method name. For a seed program containing a trait named TraitName with methods, and an impl TraitName for SomeType block, if there exists a method definition like `fn TraitName(&self) -> ReturnType { ... }` inside the impl block, mutate it to `fn some_other_method(&self) -> ReturnType { ... }` where some_other_method is another method name defined in the same trait. If no other method exists in the trait, introduce a new method name by appending a suffix like `_mutated` to the trait name, declaring it within the trait definition first. Specifically, before mutating the impl block, modify the trait to add a new method with the mutated name and a default implementation if possible, or a required signature. For example, given a seed with trait MyTrait { async fn foo(&self) -> i32; async fn bar(&self) -> i32; } and impl MyTrait for i32 { async fn MyTrait(&self) -> i32 { *self } async fn bar(&self) -> i32 { self.foo().await } }, the method named MyTrait in the impl is incorrectly named. The mutation would change that line to `async fn bar(&self) -> i32 { *self }` and the original bar method to a different name, e.g., `async fn bar_mutated(&self) -> i32 { self.foo().await }`, but also requires adding `async fn bar_mutated(&self) -> i32;` to the trait MyTrait. This directly mimics the bug trigger where a method name coincides with the trait name, which can lead to internal compiler confusion about defaultness and associated items. The change must ensure trait coherence is updated accordingly.
