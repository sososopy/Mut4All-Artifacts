mutation operator: Replace a const generic parameter type in an impl header with an unsupported type, while ensuring the impl block uses that parameter in a const expression that triggers a cast operation. This operator targets impl blocks for traits on structs with const generic parameters, specifically when the generic_const_exprs feature is enabled. It applies to impl headers where a const generic parameter is declared with a supported type (like usize, u8, etc.) and is used in a const expression within the impl header, such as in the struct's generic arguments. The mutation changes the const parameter's type to an unsupported type for const generics, such as f32, f64, or a non-integer type, while preserving the usage of that parameter in a const expression that involves a cast or arithmetic operation. For example, if the seed program contains an impl block like impl<const N: usize> Trait for Struct<N, { N + 1 }> {}, mutate it to impl<const N: f64> Trait for Struct<N, { N as usize }> {}. The struct definition must have const generic parameters of integer types; the mutation introduces a type mismatch because the struct expects an integer type but receives a float. The const expression using the mutated parameter should be a cast operation (e.g., as usize) or another operation that requires evaluation, to potentially trigger internal compiler errors during const evaluation. Ensure the mutated impl block is referenced in the code, such as through a function call that instantiates the struct with concrete values. Do not introduce new variables or types; use existing struct names, trait names, and const parameter names from the seed program. The change should be made directly in the impl header, keeping the rest of the code unchanged.
