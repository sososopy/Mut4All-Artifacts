mutation operator pattern mutability inversion
This operator targets pattern matching expressions that involve nested patterns with mutable references. It applies when there is a pattern that destructures a reference to an enum or struct, and within that pattern, there are inner patterns involving mutable references or mutability qualifiers. The operator inverts the mutability qualifier on the innermost mutable reference within the pattern. Specifically, it changes a mutable reference pattern `&mut` to a shared reference pattern `&` when it appears inside a destructuring pattern that is itself matched against a reference. This inversion can violate the compiler's internal assumptions about mutability caps in pattern analysis, potentially triggering internal compiler errors related to pattern mutability violations. The change is made directly within the pattern syntax of the let statement, match arm, or if let expression. Only existing patterns are modified; no new variables, types, or functions are introduced. The operator modifies the source code by locating a pattern of the form `... &mut ...` nested inside another pattern that is matched against a reference, and replacing that `&mut` with `&`. For example, given a seed code snippet with `if let &Some(Some(x)) = &Some(&mut Some(0)) {}`, the operator would mutate the expression on the right-hand side of the `=` to invert the inner mutable reference, producing `if let &Some(Some(x)) = &Some(&Some(0)) {}`. This changes the mutability of the inner reference without altering the overall structure or introducing new elements, focusing on the specific interaction between nested pattern matching and reference mutability that is known to cause compiler crashes under debug assertions.
