mutation operator
Target a function returning `impl Trait` with explicit lifetime parameters that are not used in the return type but are used in the bounds. The operator applies when a function signature includes at least one explicit lifetime parameter and returns `impl Trait` with a lifetime bound referencing that parameter, but the returned expression's type does not actually depend on that lifetime. Specifically, mutate by introducing a recursive call to the same function within the body, assigning the result to a variable, and then returning a value of a concrete type that does not involve the lifetime. This should be done only if the function body does not already contain a recursive call to itself. The operator first checks for an existing function `fn ident<'lifetimes...>() -> impl Trait + 'lifetime_bound` where `'lifetime_bound` is one of the declared lifetimes. If the body contains no call to `ident`, then modify the body by inserting a let-binding: `let var_name: concrete_type = ident();` where `concrete_type` is a type present in the program (e.g., `i32`, `bool`, `String`) that implements the `Trait`. Then change the return expression to be a value of that concrete type, which could be a literal or a default value. For example, given a seed function `fn foo<'a>() -> impl Sized + 'a { 5 }`, mutate to `fn foo<'a>() -> impl Sized + 'a { let _x: i32 = foo(); 5 }`. If no suitable concrete type is found, the operator does nothing. The goal is to create a mismatch between the lifetime bound on the opaque type and the actual returned type, combined with recursion, which may trigger region inference issues.
