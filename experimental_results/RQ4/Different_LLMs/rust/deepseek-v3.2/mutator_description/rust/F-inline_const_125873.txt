Rust compiler bugs involving F-inline_const often occur when inline const blocks are placed inside contexts with complex lifetime interactions, especially those that involve higher-ranked trait bounds (HRTB) or closure lifetime binders. The bug report shows an ICE when an inline const block references a lifetime parameter bound by a for<'a> closure binder inside the const block's body. This suggests that the compiler's region handling for inline consts within late-bound parameter scopes is fragile. Specifically, the combination of inline consts within closures with explicit lifetime binders can trigger region conversion errors during borrow checking.
