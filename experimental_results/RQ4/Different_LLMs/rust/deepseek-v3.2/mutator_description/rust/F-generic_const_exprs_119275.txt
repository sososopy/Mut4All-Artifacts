mutation operator Introduce a generic const parameter in a where-clause bound using a for<const ...> binder where the const parameter is used in a const expression that references a path that may be unresolved. This operator targets function definitions and inherent impl blocks that have a generic const parameter. It applies when the seed program contains at least one generic const parameter. The operator adds a where-clause of the form `for<const N: usize = VALUE> [(); PATH::CONST]:,` where VALUE is a literal integer already present in the seed program or 0 if none exists, and PATH is an identifier chosen from existing type names or trait names in scope, or a new simple identifier like `Unresolved` if none are suitable. The operator should be applied to the function or impl that contains the generic const parameter. For example, if the seed contains `fn foo<const N: usize>() {}`, mutate it to `fn foo<const N: usize>() where for<const M: usize = N> [(); SomeType::SIZE]:, {}`. If no suitable PATH exists, introduce a new type alias `type Unresolved = ();` at the crate root before the mutation and use `Unresolved::CONST` in the bound. The new const parameter in the for binder must have a distinct name from existing generic parameters. The bound must be a const expression that is likely to be evaluated during trait solving.
