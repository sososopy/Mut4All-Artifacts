mutation operator
target: generic const expressions in trait bounds and where clauses, specifically those involving const parameters and associated constants.
applicability: when a trait bound or where clause contains a const expression involving generic parameters, such as a const equality bound like `T: Trait<CONST = { expr }>` or a where clause involving const generic parameters like `where [(); T::N + 1]:`.
change: modify the const expression within the bound or where clause by either replacing it with a different const expression of the same type, or by introducing a new const generic parameter and using it in the expression. for the replacement, use an existing const item from the seed program if possible; otherwise, introduce a new const parameter to the item (e.g., add a const parameter to the function or struct) and use it. the new const expression should be syntactically valid and type-check, but may alter the semantics.
example: if a trait bound is `T: Trait<CONST = { 5 }>`, change it to `T: Trait<CONST = { 6 }>` if there is an existing const `SIX` equal to 6, or add a new const parameter `const M: usize` to the enclosing function and change the bound to `T: Trait<CONST = { M }>`. for a where clause like `where [(); N + 1]:`, change it to `where [(); N + 2]:` or introduce a new const parameter `const OFFSET: usize` and use `where [(); N + OFFSET]:`.
