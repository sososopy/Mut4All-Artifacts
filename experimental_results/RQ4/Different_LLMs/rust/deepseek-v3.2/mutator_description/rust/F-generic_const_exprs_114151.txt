Mutation operator:

Target: Where-clause predicates and array size expressions that involve generic constant parameters.

Applicability: This mutation applies to any where-clause predicate of the form `[(); <expr>]:` or array type `[T; <expr>]` where `<expr>` is a constant expression containing generic parameters (like `N`, `L`). The mutation also applies to similar constant expressions in other contexts like trait bounds or value positions if they involve generic parameters.

Operation: For each constant expression `<expr>` that contains a generic parameter, create a mutated version by introducing an extra addition or subtraction of the same generic parameter. Specifically, locate sub-expressions where a generic parameter appears. Then, modify the expression by adding or subtracting the same generic parameter in a way that creates a redundant arithmetic operation.

1. Identify all constant expressions in where-clauses, array sizes, and similar positions.
2. For each expression, check if it contains any generic constant parameters (identifiers that are declared as const parameters in the surrounding generic parameter list).
3. For each occurrence of a generic parameter in the expression, create a mutation by replacing that occurrence with `(parameter + parameter)` or `(parameter - parameter)`.
