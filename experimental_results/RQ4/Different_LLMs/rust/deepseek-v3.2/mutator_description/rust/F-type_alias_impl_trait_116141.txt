mutation operator: Replace a type alias impl trait definition with an equivalent explicit opaque type using `impl Trait` in return position of a function, while preserving the same constraints and usage patterns. This mutation applies to any occurrence of `type Name<...> = impl Trait;` within a function body, where the alias is used to define a value and later accessed. The mutation changes the alias definition into a helper function that returns the `impl Trait` and adjusts the assignment to call that function. Specifically, for each `type Alias<Params> = impl Trait;` followed by `let var: Alias<Args> = expr;`, replace with `fn helper<Params>(...) -> impl Trait { expr }` where `expr` is adapted to match the parameters, and change the let binding to `let var = helper<Args>(...);` ensuring all dependencies are correctly passed. If the original `expr` uses variables bound outside, they must be passed as arguments to `helper`. Example: seed contains `type O<T> = impl Sized; let x: O<T> = (y,);` becomes `fn helper<T>(t: T) -> impl Sized { (t,) }` and `let x = helper(y);`. This mutation targets the interplay between type alias impl trait and function-level opaque types, which can trigger elaboration drop errors due to differing handling of generics.
