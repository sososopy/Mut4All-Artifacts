Mutation operator: This operator targets drop elaboration in static initializer blocks. It applies when a static item is initialized with a block containing local variable declarations that may require drop glue. The mutation modifies the static initializer by wrapping the existing block in an immediately-invoked closure that returns unit type, changing the drop scope boundaries. Specifically, replace 'static NAME: TYPE = { ... };' with 'static NAME: TYPE = (|| { ... })();'. This must only be applied if the original static initializer is a block expression. Use the existing static name and type. Ensure the closure returns the unit type to match the static's type if needed. This mutation alters drop ordering and may expose bugs in the compiler's handling of destructors in static contexts.
