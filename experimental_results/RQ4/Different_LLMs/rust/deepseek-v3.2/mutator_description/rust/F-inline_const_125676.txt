mutation operator: replace a const block expression with a const block containing a generic type parameter inside a conditional branch.

This mutation operator targets const blocks in generic contexts, specifically when a const block contains a conditional expression where at least one branch references a generic type parameter. The operator applies when the seed program contains a generic function or method with a const block. It modifies the const block by replacing its body with a new const block that includes a conditional expression where one arm uses a generic type parameter via a size_of or align_of operation, and the other arm uses a constant value. If the original const block already contains a conditional expression, the operator replaces it entirely. If the original const block does not contain a conditional expression, the operator introduces a new conditional expression. The generic type parameter used must be one already declared in the enclosing generic item. If the generic context has multiple type parameters, choose the first one. The conditional expression should compare two parameters of the function or two constant values already present in the seed program. If no suitable parameters or constants exist, use a comparison between two integer literals, such as 0 and 1. The mutation ensures that the generic type parameter appears only in one branch of the conditional, not both, to mimic the structure that triggered the bug. For example, given a generic function with parameters a and b of type usize, and a type parameter T, the original const block might be replaced with: const { if a < b { std::mem::size_of::<T>() } else { usize::MAX } }. The operator does not introduce new generic parameters or new variable names beyond those already present. It only reuses existing names and types from the seed program. The goal is to create a const block where the evaluation path depends on generic parameters, which may expose missing entries in the compiler's internal maps during MIR construction.
