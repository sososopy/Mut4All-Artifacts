mutation operator: Replace Sized Type Parameter with Unsized Trait Object in Generic Const Expression Where Clause

This mutation targets generic const expressions in where clauses that depend on the size of a generic type. Specifically, it applies when a struct or function has a generic parameter T used within a const expression inside a where clause, and that const expression involves a call to `core::mem::size_of::<T>()` or similar size-dependent operations. The mutation changes the concrete type used to instantiate T from a sized type to an unsized trait object (like `dyn Trait`), where Trait is a trait that T is already bound to or a commonly used trait like Debug. The goal is to trigger compiler errors or internal compiler errors when the const evaluator attempts to compute the size of an unsized type.

To apply this mutation, first locate a struct or function definition with a generic parameter T and a where clause that includes a const expression using `size_of::<T>()` or similar. Ensure that the context where T is used already involves a trait bound (e.g., `T: Debug`) or introduce a new trait bound if needed. Then, in the instantiation of that struct or function (e.g., in a function call or variable declaration), change the type argument from a concrete sized type to a trait object of that trait. For example, if the seed program uses `Inline::<u32>::new(0)`, mutate it to `Inline::<dyn Debug>::new(0)`. If the trait bound is not present, add a bound like `T: Debug` to the generic parameter and use `dyn Debug` as the type argument. This mutation should only be applied when the const expression in the where clause would become invalid for unsized types, aiming to expose bugs in const evaluation or type checking for generic const expressions.
