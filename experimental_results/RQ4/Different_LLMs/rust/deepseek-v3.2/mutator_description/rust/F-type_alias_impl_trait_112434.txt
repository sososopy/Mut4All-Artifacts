mutation operator: Replace a branch in an if expression with an empty block when the function return type is an impl Trait type alias.

This mutation applies to functions that have a return type defined as a type alias for impl Trait (type Alias = impl Trait;). For each if expression within such a function that has both a then branch and an else branch, mutate by replacing the contents of either branch with an empty block {}. The mutation should choose one branch (then or else) to empty. If the branch is already an empty block, this mutation does not apply. The mutation must preserve the overall structure of the if expression, only changing the block body.

For example, given a seed program containing:
type Alias = impl Trait;
fn f(condition: bool) -> Alias {
    if condition {
        value1
    } else {
        value2
    }
}
One possible mutation is:
type Alias = impl Trait;
fn f(condition: bool) -> Alias {
    if condition {
        value1
    } else {
    }
}
Another is:
type Alias = impl Trait;
fn f(condition: bool) -> Alias {
    if condition {
    } else {
        value2
    }
}
The mutation uses existing types and variables from the seed. No new elements are introduced. This mutation targets the interaction between type inference for impl Trait and control flow, which can trigger compiler bugs in suggestion diagnostics.
