mutation operator: replace a lifetime in a const generic parameter with a different lifetime from the same scope
target code construct: const generic parameters of type &'lt T (or other reference types with explicit lifetimes) within function signatures, struct definitions, or enum definitions where multiple lifetimes are available in the same scope.
detailed description: this operator applies when a const generic parameter explicitly specifies a lifetime, such as &'a str. it modifies the lifetime by substituting it with another lifetime that is already declared and in scope within the same item (e.g., another lifetime parameter of the function or a lifetime defined in an outer scope if applicable). the operator only changes the lifetime identifier; the rest of the type remains unchanged. this mutation aims to test the compiler's handling of lifetime interactions in const generic contexts, particularly when lifetimes are mismatched or substituted.
example: given a seed function fn bar<'a, 'b, const C: &'a u32>() {}, the operator could mutate it to fn bar<'a, 'b, const C: &'b u32>() {}. note that both 'a and 'b are existing lifetime parameters in the same function signature. the mutation does not introduce new lifetimes; it swaps to an existing one. if only one lifetime is in scope, this operator does not apply.
