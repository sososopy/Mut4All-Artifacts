Mutation operator: Duplicate a const generic parameter name in a trait or inherent impl definition, and introduce a default value that references a const parameter (potentially the first occurrence). This operator applies to trait definitions or inherent impl blocks that already have at least one const generic parameter. The mutation modifies the generic parameter list by adding a new const parameter with the same name as an existing const parameter in the same list, and optionally provides a default value that references a const parameter (which could be the duplicated name or another). The new parameter must have the same type as the existing one. If the seed program lacks a const parameter to duplicate, this operator does not apply. The change is made directly to the generic parameter list in the source code.

Example: For a trait definition like `trait Trait<const N: usize> {}`, mutate to `trait Trait<const N: usize, const N: usize = N> {}`. Ensure the duplicated name matches exactly an existing const parameter name, and the default value uses an identifier that is a const parameter (here, referencing the first N). If the seed program has multiple const parameters, choose one to duplicate; for instance, `trait Trait<const A: u8, const B: u16>` could become `trait Trait<const A: u8, const B: u16, const A: u8 = A>`. The operator only adds one duplicated parameter per application.
