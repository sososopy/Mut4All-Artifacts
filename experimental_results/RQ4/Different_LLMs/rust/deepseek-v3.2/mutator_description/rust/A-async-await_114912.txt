mutation operator: Replace array size constant with maximum usize value in an async context.

This mutation operator targets array expressions within async functions or blocks that are being awaited. The operator modifies the size constant of an array literal to the maximum value of usize (i.e., usize::MAX). It applies when an array expression (e.g., [T; N]) appears as the left-hand side of an await expression. The change is to replace the size N with usize::MAX. The mutation must preserve the element type and the await suffix.

For example, given a seed program containing an async function with an awaited array expression like:
async fn f() {
    [0u8; 10].await;
}
The mutation would produce:
async fn f() {
    [0u8; usize::MAX].await;
}
If the seed program does not already have an array expression being awaited, the operator does not apply. The mutation should only be applied if the array expression is directly awaited; nested contexts (e.g., inside a tuple) are also considered. The operator introduces the constant usize::MAX which is a standard library constant and does not require additional declarations beyond the prelude. This mutation aims to trigger arithmetic overflow during size computations in the compiler's generator interior analysis, similar to the bug report.
