mutation operator: Insert a generic const expression bound that references a generic associated type const in a where clause for a GAT definition or its impl. This applies when a trait defines a generic associated type (GAT) with a generic parameter that implements a trait containing an associated const, and the GAT's where clause may include a generic const expression using that associated const. Specifically, locate a trait definition with a GAT that has a trait bound on its generic parameter, and ensure the bounded trait includes an associated const. Then, in the GAT's where clause, add a bound of the form `[(); T::CONST]:` where T is the GAT's generic parameter and CONST is the associated const from the trait bound. This also applies to the corresponding GAT implementation: in the impl block for the trait, within the GAT's impl definition, add the same generic const expression bound to its where clause. The mutation should reuse existing trait names, associated const names, and generic parameters from the seed program. If the necessary associated const does not exist, this mutation does not apply. Example: given a seed with trait Foo { const N: usize; } and trait Owner { type Gat<T: Foo>; }, mutate the GAT definition to: type Gat<T: Foo> where [(); T::N]:; and similarly in the impl for Owner, mutate to: type Gat<T: Foo> = ... where [(); T::N]:;. The change must be syntactically correct and use only elements present in the seed.
