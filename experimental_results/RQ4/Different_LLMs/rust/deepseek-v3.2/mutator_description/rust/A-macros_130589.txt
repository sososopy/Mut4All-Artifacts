mutation operator: Wrap const generic argument in a macro invocation. This operator targets const generic arguments in struct definitions, enum definitions, or function signatures. It applies when a const generic parameter is used as an argument to another const generic type. The mutation replaces the direct use of the const parameter with a macro invocation that expands to that parameter. The macro must be defined in the seed program; if not present, a simple pass-through macro is introduced. To introduce the macro, add a macro_rules definition at the appropriate scope (e.g., at the crate root or within the module) with a name not conflicting with existing identifiers, such as wrap_const. The macro should have a single rule: ($v:expr) => { $v }. Then, locate a const generic argument that is a simple identifier (the const parameter name) and replace it with the macro invocation. For example, if the seed contains 'struct S<const N: usize>;' and a usage like 'Struct<{ N }>', change it to 'Struct<{ wrap_const!(N) }>'. Ensure the macro is defined before its use. The mutation should not be applied if the const argument is already a complex expression (e.g., arithmetic or another macro call), to avoid nested complexities. The goal is to create a scenario where the compiler must resolve a const generic argument through macro expansion, potentially triggering internal compiler errors in constant evaluation or HIR mapping.
