Mutation operator: Replace ADT (struct/enum) constant parameter types with unsized types like str or slices in generic functions and impls.

This mutation targets code constructs that use ADT (Algebraic Data Type) constant parameters, specifically structs or enums that are marked with ConstParamTy and are used as const generic parameters. It applies when a generic function or trait implementation has a const generic parameter of a type that implements ConstParamTy, and the mutation changes that type to an unsized type such as str or [T] (slice). The mutation should be applied to the type definition of the constant parameter in the generic context. For example, if the seed program contains a generic function like `fn foo<const S: MyStruct>()`, where MyStruct implements ConstParamTy, mutate it to `fn foo<const S: str>()` or `fn foo<const S: [u8]>()`. The unsized type must be introduced as a const parameter directly, not wrapped in another ADT. If the seed program uses a wrapper ADT like struct MyStr(str), mutate to use the raw unsized type. This mutation may require adding a new const parameter declaration; ensure that the unsized type is used directly as the const parameter type. Note that unsized types as const parameters are a known edge case and can trigger ICEs in symbol mangling or coverage instrumentation, as seen in the bug report.
