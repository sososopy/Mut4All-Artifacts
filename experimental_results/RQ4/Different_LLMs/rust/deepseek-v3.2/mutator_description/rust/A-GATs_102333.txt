mutation operator: Modify trait bounds involving associated types with const generics to include explicit const parameter assignments in the bound.

This mutation operator applies to trait bounds where an associated type from one trait is used as a type argument to another trait that has const-generic parameters. Specifically, it targets bounds of the form `Type: Trait<AssocType>` where `AssocType` is an associated type from another trait, and `Trait` has a const-generic associated type or parameter. The mutation changes the bound to include an explicit assignment of a const parameter to the associated type, using a const expression available in the context.

For example, if the seed program contains a trait `B` with an associated type `U<const C: i32>`, and a trait `A` with an associated type `T` bound by `B`, the original bound `type T: B` is mutated to `type T: B<U<CONST_EXPR> = TYPE>`. Here, `CONST_EXPR` must be a constant expression that is valid in the current scope, such as a literal constant or a const parameter from the enclosing context. `TYPE` must be a type that exists in the seed program, such as a unit type `()` or a named type already declared.

The operator first identifies all trait definitions with associated types that have const-generic parameters. Then, it locates trait bounds that use these associated types without specifying const arguments. It modifies such bounds by inserting an explicit const argument and an associated type assignment. If multiple const parameters exist, it chooses one to assign. The const expression used should be derived from existing constants in the program; if none exist, a simple literal like `0` or `1` is introduced, but only if the const parameter's type supports it (e.g., `i32`). The type assigned to the associated type must be an existing type in the program, such as `()`, `bool`, or a user-defined type.
