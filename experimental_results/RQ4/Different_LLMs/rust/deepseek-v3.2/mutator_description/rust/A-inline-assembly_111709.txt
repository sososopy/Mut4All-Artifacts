Mutation Operator: Inline Assembly Sym Operand Type Argument Mutation

This mutation operator targets sym operands in inline assembly blocks that reference generic functions. It applies when an asm! block contains a sym operand that refers to a generic function with explicit type arguments. The mutation changes the type arguments passed to the generic function, particularly focusing on substituting reference types with their referenced types or changing reference mutability.

Specifically, for any sym operand in an asm! block that references a generic function with type arguments, if any of those type arguments is a reference type &T or &mut T, mutate it to either the referenced type T or change the mutability. For example, if the original is sym some_func::<&mut SomeType>, mutate to sym some_func::<SomeType> or sym some_func::<&SomeType>. This mutation should only be applied when the referenced function exists in the seed program and the type T is also defined or accessible.

The mutation should be applied as follows: First, identify all asm! blocks in the seed program. For each sym operand within those blocks, check if it references a generic function with explicit type arguments. If it does, parse the type arguments. For each reference type in the arguments, create a mutated version where the reference is removed or its mutability is changed. Generate a new asm! block with this mutated sym operand, replacing the original. Ensure the rest of the asm! block remains unchanged, including the assembly template string and other operands.

Example: If the seed program contains asm!("template", sym crate::func::<&mut Type>, ... ), mutate to asm!("template", sym crate::func::<Type>, ... ) or asm!("template", sym crate::func::<&Type>, ... ). The mutation must not introduce new variables or types; it only modifies existing type arguments. The mutated program should compile, but may expose edge cases in the compiler's handling of sym operands with non-reference types in inline assembly.

This mutation targets the specific code construct that triggered the ICE—sym operands with generic type arguments in inline assembly—and is widely applicable to any seed program containing inline assembly with sym operands to generic functions.
