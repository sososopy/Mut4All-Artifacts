mutation operator: Insert a const generic parameter default expression into a trait implementation block that specializes a generic struct with defaulted const generic parameters. This mutation targets trait implementations for generic structs that have const generic parameters with default values, especially when the generic_const_exprs feature is enabled. The operator applies when a struct definition includes a const generic parameter with a default value and there exists a trait implementation for that struct without explicit const generic arguments. The mutation modifies the trait implementation block by inserting an explicit const generic argument that matches the default value from the struct definition. If the struct has multiple const generic parameters with defaults, choose the first one. The insertion should be placed after the struct name in the impl block. For example, given a seed program with a struct definition like 'struct S<const N: usize = 1>;' and an implementation 'impl Trait for S {}', mutate it to 'impl Trait for S<1> {}'. Ensure the inserted constant expression is syntactically valid and matches the const parameter's type. Use only constants or literals that are already present in the seed program or introduce a simple literal like 0, 1, or true/false appropriate to the type. Do not introduce new names or complex expressions.
