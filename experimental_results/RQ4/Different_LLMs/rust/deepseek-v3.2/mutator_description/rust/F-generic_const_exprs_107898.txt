mutation operator: Replace a const generic parameter with a type parameter in a where clause that uses a const expression involving size_of or other const functions. This operator applies when there is a where clause in an impl block that uses a constant expression dependent on a generic parameter, specifically where the constant expression involves a function like size_of::<T>() and is used to bound an array of unknown size. The mutation changes the const parameter in the array size expression to a type parameter, altering the const expression's dependency. For example, given an impl block with a where clause like `where [(); size_of::<T>()]: Sized`, if there is a const generic parameter `N` of type `usize` defined in the struct or trait, the operator modifies the where clause to use `N` instead of `size_of::<T>()`, resulting in `where [(); N]: Sized`. This change targets scenarios where const expressions rely on type parameters, potentially exposing bugs in const evaluation or type relation logic. The operator ensures that `N` is an existing const parameter in scope, avoiding introduction of new elements. Only one mutation per operator application, focusing on the where clause in impl definitions.
