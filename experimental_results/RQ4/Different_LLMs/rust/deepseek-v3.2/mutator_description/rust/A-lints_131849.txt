mutation operator
This mutation operator targets unary negation operations applied to numeric literals, specifically integer literals. It applies to any unary minus operator `-` directly preceding a numeric literal (decimal, hexadecimal, binary, octal). The operator modifies the literal by appending a zero digit to its representation, effectively scaling its value by the base. For decimal literals, append a `0`. For hexadecimal literals (starting with `0x`), append a `0` after the existing hex digits. For binary literals (starting with `0b`), append a `0` after the existing binary digits. For octal literals (starting with `0o`), append a `0` after the existing octal digits. This change can create literals that exceed the default inferred integer type (e.g., `i32`/`i64`) range, potentially triggering overflow checks during constant evaluation or linting phases. The mutation should be applied to the literal token after the unary minus sign. Example: Given `let x = -123;` mutate to `let x = -1230;`. Given `let y = -0xFF;` mutate to `let y = -0xFF0;`. Given `let z = -0b101;` mutate to `let z = -0b1010;`. The operator does not introduce new variables or types; it only modifies the literal's textual representation.
