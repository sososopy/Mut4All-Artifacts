mutation operator

This mutation operator targets the default values of const generic parameters in trait definitions. It applies when a trait has a const generic parameter with a default value. The operator modifies the default value to be a reference to the parameter's own identifier, creating a self-referential default that may not be properly handled during well-formedness checking.

Specifically, for any trait definition of the form:
trait TraitName<const PARAM: Type = DefaultExpr> { ... }

The operator changes the default expression to the identifier of the parameter itself:
trait TraitName<const PARAM: Type = PARAM> { ... }

If the trait has multiple const generic parameters, the operator applies to each parameter independently, creating multiple mutation opportunities.

The mutation uses only elements already present in the seed program - the parameter name and type are reused. No new declarations are introduced. The operator preserves all other aspects of the trait definition including other parameters, bounds, and associated items.

Example transformation:
Original: trait Example<const N: usize = 5, const M: bool = true> { fn method(); }
Mutated: trait Example<const N: usize = N, const M: bool = M> { fn method(); }

This mutation creates self-referential defaults that may expose bugs in the compiler's handling of const generic parameter defaults during HIR well-formedness checking, particularly around anonymous constants and their resolution.
