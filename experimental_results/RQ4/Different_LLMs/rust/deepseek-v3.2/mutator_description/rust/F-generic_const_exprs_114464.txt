mutation operator: Insert a let binding with an explicit lifetime annotation into a const generic argument block expression. This operator applies when a const generic argument is a block expression, which is permitted in Rust with the generic_const_exprs feature. The mutation targets a const generic argument that is a block expression. It modifies the block by inserting a let statement that declares a variable with an explicit lifetime annotation, where the lifetime is a generic lifetime parameter from the enclosing function. Specifically, if the enclosing function has at least one generic lifetime parameter, choose one of those lifetimes. If the function has no generic lifetime parameters, introduce a new lifetime parameter 'a to the function signature and use it in the inserted let statement. The inserted statement should be placed at the beginning of the block expression. The variable should be of a reference type using that lifetime, such as a reference to the unit type. The expression part of the block (the final expression) remains unchanged. For example, given a function like fn test<const N: usize>() {} and a call site test::<{ some_expr }>(); within a function fn wow<'a>() {}, mutate the const argument block to test::<{ let _: &'a (); some_expr }>();. If the function wow had no lifetime parameters, change its signature to fn wow<'a>() {} and then apply the mutation. This mutation aims to trigger bugs in the borrow checker when processing lifetimes within const generic block expressions, especially in the universal regions computation, as seen in the bug report.
