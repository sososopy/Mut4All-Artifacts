mutation operator
target construct: generic const parameter usage in impl trait bounds where the const parameter type is mismatched or incorrectly substituted, particularly involving associated const expressions or structs with const generic parameters. applies to impl blocks, trait bounds, and function signatures where const generic parameters are used.

description: replace a const generic parameter in an impl block's trait bound with a different const expression that has a mismatched type or is an unconstrained inference variable. if the seed program contains a struct with a const generic parameter, and an impl block that uses a const generic parameter in its trait bound, mutate the trait bound by substituting the const parameter with a const expression of a different type (e.g., replacing a const parameter of type Dimension with a const parameter of type bool or an integer, or replacing it with a const expression that references a different const parameter or a literal). if no such mismatch exists, introduce a new const generic parameter in the impl block with a different type and use it incorrectly in the trait bound.

steps: locate an impl block that uses a const generic parameter in a trait bound (e.g., impl<const D: Dimension> Add<...> for Quantity<..., D>). identify the const parameter's type (e.g., Dimension). if there exists another const parameter in scope with a different type (e.g., a const parameter of type bool or usize), replace the usage of the original const parameter in the trait bound with that other const parameter. if no such other const parameter exists, add a new const generic parameter to the impl block with a different type (e.g., const X: bool) and replace the original const parameter in the trait bound with this new parameter. ensure the new const parameter is declared in the impl block's generic parameters. do not introduce new items outside the impl block.

example: given seed code with struct Quantity<S, const D: Dimension>(S); and impl<const D: Dimension> Add for Quantity<f32, D>, mutate to impl<const D: Dimension, const X: bool> Add for Quantity<f32, X>. this creates a type mismatch because X is bool but expected Dimension. alternatively, if the seed has a const parameter of type usize elsewhere, use it instead.

note: this mutation aims to trigger internal compiler errors during const combination, as seen in the bug report where const inference variables of different types (bool and Dimension) were incorrectly combined.
