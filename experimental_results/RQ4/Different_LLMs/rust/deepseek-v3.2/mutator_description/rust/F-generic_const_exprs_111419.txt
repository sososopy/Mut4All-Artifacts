mutation operator

Target code construct: generic const parameter declarations with default values in trait definitions.

Where it applies: In any Rust program where a trait is declared with one or more generic const parameters, and at least one of those const parameters has a default value expressed as a constant expression.

Operator description: For a trait definition that includes a generic const parameter with a default value, modify the default value expression. Specifically, replace the default expression with a different constant expression that is well-typed (i.e., of the same const parameter type) and uses only constants, literals, and generic parameters already in scope within the trait definition. The new expression must be distinct from the original. If the original default is a simple binary operation (like addition), change the operation (e.g., change addition to subtraction, or swap operands). If it is a single parameter, wrap it in an identity operation (e.g., change `X` to `{ X }`). If it is a literal, adjust the literal value (e.g., change `0` to `1`). The goal is to alter the structure of the default value without introducing new, undeclared names or types.

Example: Given a seed program with trait definition:
`trait Trait<const N: usize, const M: usize = { N + 5 }> {}`
Mutate it to:
`trait Trait<const N: usize, const M: usize = { N - 5 }> {}`
Or, if subtraction is not valid (e.g., might underflow), use:
`trait Trait<const N: usize, const M: usize = { 5 + N }> {}`
Or, if the default is a single parameter:
`trait Trait<const N: usize, const M: usize = N> {}`
could become:
`trait Trait<const N: usize, const M: usize = { N }> {}`
Or, if the default is a literal:
`trait Trait<const N: usize, const M: usize = 10> {}`
could become:
`trait Trait<const N: usize, const M: usize = 11> {}`

Changes: Only the constant expression defining the default value of the const generic parameter within the trait declaration is altered. No other parts of the program are changed. The new expression must be syntactically valid and type-check as a constant expression of the correct type, using only elements present in the original trait's generic parameter list and any outer scope constants/literals of appropriate type that are already accessible. Do not introduce new `const` items, variables, functions, or types.
