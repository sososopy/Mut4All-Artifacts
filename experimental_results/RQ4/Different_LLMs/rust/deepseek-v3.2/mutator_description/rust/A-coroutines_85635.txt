mutation operator: Replace yield expression in a generator with a box expression containing the yield, targeting generator closures where yield is used as an expression. Apply this mutation to any generator closure that contains a yield expression. The mutation changes the yield expression to `box yield`, ensuring that the box keyword is placed immediately before the yield. This requires the seed program to already have the box_syntax feature enabled or be in a context where box syntax is allowed. If the seed program does not have box_syntax enabled, enable it by adding the feature attribute #![feature(box_syntax)] at the crate root. The mutation should only be applied once per generator closure, targeting the first yield expression encountered. For example, if the seed code contains `|| { let x = yield; }`, mutate it to `|| { let x = box yield; }`. If the seed code already uses box yield, do not apply the mutation. This mutation aims to trigger MIR validation errors related to type mismatches in generator state handling.
