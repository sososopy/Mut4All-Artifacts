mutation operator: Insert const block in array length position for generic types. This mutation targets array type definitions where the array length is a constant expression, specifically in contexts involving generic type parameters. It applies when an array type `[T; N]` is declared, and `N` is a simple constant expression like a numeric literal or a call to `size_of`. The mutation replaces `N` with `const { N }` to introduce an inline const block. This is designed to trigger edge cases in const evaluation, particularly with generic parameters, as seen in the bug where `[u8; const { mem::size_of::<T>() }]` caused an ICE. The mutation should only be applied if the array length expression `N` does not already contain a const block. For example, given a seed program with `struct S<T> { arr: [u8; std::mem::size_of::<T>()] }`, mutate to `struct S<T> { arr: [u8; const { std::mem::size_of::<T>() }] }`. Ensure the const block uses existing items from the seed; no new declarations are introduced. This mutation aims to expose bugs in const evaluation with generics and inline consts, covering structures like unions, structs, and function signatures where arrays appear.
