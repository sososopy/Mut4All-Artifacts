mutation operator: Replace inner attribute with outer attribute in proc-macro expanded code. This operator applies to any inner attribute (`#![...]`) found in the token stream generated by a proc-macro invocation. The mutation changes the inner attribute's style from inner to outer by removing the exclamation mark (`!`), turning it into `#[...]`. This targets the compiler's attribute parsing logic during macro expansion, particularly when inner attributes are placed in contexts where only outer attributes are expected, which can trigger internal compiler errors like the one reported. The change should be applied directly to the token stream representation before it is further processed by the compiler. For example, if the proc-macro output contains `#![deny(missing_docs)]`, mutate it to `#[deny(missing_docs)]`. The operator should only modify attributes that are syntactically inner attributes; it does not introduce new attributes or modify their arguments. Use the existing attribute path and arguments from the seed program. This mutation is designed to expose bugs in the compiler's handling of attribute ordering and validation after macro expansion.
