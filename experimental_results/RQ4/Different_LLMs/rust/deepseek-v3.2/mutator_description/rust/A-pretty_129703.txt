mutation operator: replace a closure expression with an async closure expression. this mutation applies to any closure expression in the seed program that is not already an async closure. the mutation adds the async keyword before the closure's parameter list or move keyword, if present. if the closure is a non-async closure like || { body } or |args| { body } or move || { body }, it becomes async || { body }, async |args| { body }, or async move || { body } respectively. the body of the closure remains unchanged. for example, given a closure expression let f = || {}; it is mutated to let f = async || {};. given let g = move |x| { x + 1 }; it is mutated to let g = async move |x| { x + 1 };. this mutation may trigger compiler internal errors related to async closure handling, particularly in MIR dumping or coroutine transformation passes, as seen in the bug report.
