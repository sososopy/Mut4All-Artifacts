Mutation Operator: Specialization-Associated Type Substitution Swap

Target: This operator applies to any trait that uses the specialization feature and defines an associated type with a default implementation that references the implementing type itself. Specifically, it targets trait definitions where the associated type's default value is a generic type constructor applied to Self.

Changes: For each trait with specialization that contains a default associated type definition of the form `default type Assoc = Generic<Self, ...>;`, the operator will swap the position of `Self` with another type parameter of the trait, if one exists. If the trait has no additional type parameters, the operator will wrap `Self` in an additional, existing generic container available in the current scope (e.g., `Option<Self>`), ensuring the new type is valid and declared.

Example: Given a seed program with a trait:
trait SpecTrait {
    type Assoc;
}
impl<C> SpecTrait for C {
    default type Assoc = Vec<Self>;
}
The operator modifies the default associated type to use a different parameter. If the trait has another type parameter, e.g., `impl<C, D> SpecTrait<D> for C`, it might change to `default type Assoc = Vec<D>;`. If no extra parameter exists, and `Option` is in scope, it could change to `default type Assoc = Vec<Option<Self>>;`. The operator ensures the substituted type or container is already declared in the program.
