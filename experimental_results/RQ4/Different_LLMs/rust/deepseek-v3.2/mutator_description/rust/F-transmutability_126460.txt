mutation operator
Target the transmutability check by swapping source and destination types in calls to functions that assess transmutability. This operator applies wherever a function call explicitly specifies type arguments for a function that performs a transmutability check, such as those using the BikeshedIntrinsicFrom trait. The mutation changes the order of the type arguments in the call. For example, if the original code calls assert::is_maybe_transmutable::<TypeA, TypeB>(), mutate it to assert::is_maybe_transmutable::<TypeB, TypeA>(). This should be done for all such function calls where both type arguments are provided and the function is expected to evaluate transmutability. Use only types that are already present in the surrounding scope or module to avoid introducing new declarations. The change is limited to the type argument list within the angle brackets of the function call.
