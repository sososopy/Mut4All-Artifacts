mutation operator: Replace a generic lifetime parameter name in a struct or impl definition with the reserved lifetime name 'static, but only if the generic_const_exprs feature is enabled in the seed program. This operator targets struct definitions or impl blocks that have generic lifetime parameters. The mutation changes the lifetime parameter name to 'static, which is a reserved keyword and cannot be used as a generic parameter name. For example, if the seed program contains a struct definition like struct MyStruct<'a> { ... } and the generic_const_exprs feature is enabled, mutate it to struct MyStruct<'static> { ... }. Similarly, if there is an impl block like impl<'b> MyStruct<'b> { ... }, mutate it to impl<'static> MyStruct<'static> { ... }. Ensure that the mutation is applied only to the first generic lifetime parameter found in the definition if there are multiple, and only if the feature flag #![feature(generic_const_exprs)] is present in the crate root. Do not apply this mutation to lifetime parameters that are already 'static. The goal is to trigger lifetime resolution errors that may lead to internal compiler errors in the const generics or borrow-checking phases, especially when associated constants or generic const expressions are involved.
