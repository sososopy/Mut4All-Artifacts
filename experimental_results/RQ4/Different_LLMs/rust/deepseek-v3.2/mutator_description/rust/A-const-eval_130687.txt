mutation operator
target: array length expressions in constant contexts.
description: replace the length expression in an array type or array constructor with a large constant arithmetic expression that may overflow or exceed reasonable memory allocation limits. specifically, take any array length expression `N` that appears in a const context (e.g., in a const item, static item, or const generic argument) and mutate it to `usize::MAX >> K` where K is a small integer (like 0, 1, 2, 4, 8, or 16). if the original length expression is already a simple integer literal, replace it entirely. if it is a more complex expression, replace the entire expression. this targets potential issues in const evaluation where large array sizes cause internal compiler errors due to memory allocation failures or improper handling of unevaluated constants.
example: given `[u8; 100]` mutate to `[u8; usize::MAX >> 8]`. given `let _ = [0; 100];` mutate to `let _ = [0; usize::MAX >> 4];`. note: only apply where the array length is evaluable at compile time; avoid contexts where the length is a generic parameter. use existing constant `usize::MAX` from the standard library; no new declarations are needed.
