mutation operator: Replace an impl Trait type alias with a concrete generator type that captures the same closure expression. This mutation targets type alias impl Trait (TAIT) definitions that are used as associated types in traits and are constrained to implement the Generator trait. Specifically, it applies when a trait defines an associated type as `impl Generator<...>` and provides an implementation that returns a closure expression (including generator closures using `yield`). The mutation changes the associated type definition from `type Gen = impl Generator<...>` to `type Gen = [generator@path::to::function]` where the generator type is explicitly named by using the concrete generator type synthesized for the closure in the implementing function. To apply, identify a trait with an associated type defined as `impl Generator<...>`. In the implementation of that trait, locate the function that returns a generator closure (using `move || { ... yield ... }`). Then, in the trait impl block, replace the `impl Generator<...>` in the associated type definition with the explicit generator type that the compiler would infer. Since this concrete type is internal and not directly nameable, introduce a new type alias at the module scope that captures the closure's generator type by using `impl Generator<...>` in a non-associated type position, then use that alias in the associated type definition. For example, if the original code has `impl GeneratorProviderAlt for () { type Gen = impl Generator<(), Return=(), Yield=()>; fn start(ctx: Context<Self>) -> Self::Gen { move || { yield (); } } }`, first add `type ConcreteGen = impl Generator<(), Return=(), Yield=()>;` outside the trait impl. Then, change the associated type to `type Gen = ConcreteGen;` and adjust the function signature to return `ConcreteGen`. Ensure the closure remains unchanged.
