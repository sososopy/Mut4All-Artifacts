mutation operator: replace associated type bounds with invalid trait bounds in trait object or impl Trait positions where the bound references a const instead of a type. apply when an associated type bound syntax (Trait<Assoc: Bound>) is used but the associated item is a constant (const) rather than a type. change the bound to a type bound that does not exist, for example, replace `impl Trait<K: literal>` where `K` is a const with `impl Trait<K: SomeType>` introducing a reference to a non-existent type `SomeType`. in the seed program, if there is no existing type named `SomeType`, introduce a dummy type declaration such as `struct SomeType;` at an appropriate scope (e.g., module level) to avoid undefined names. the mutation modifies the bound in the function signature or trait object to use a type bound for a const, creating a mismatch. example: original `pub fn accept(_: impl Trait<K: literal>) {}` mutated to `pub fn accept(_: impl Trait<K: SomeType>) {}` with `struct SomeType;` added if not present. this targets the incorrect handling of consts in associated type bounds.
