mutation operator
This operator targets nested anonymous structs and unions within named structs or unions, specifically when using the unnamed_fields feature. It applies when a seed program contains a named struct or union that has at least one field which is an anonymous struct or union (i.e., a struct or union type defined inline without a separate type name). The operator modifies the nesting structure by swapping the order of an anonymous struct and an anonymous union within a field, or by introducing an additional level of nesting that mixes these anonymous types. The change must be made within an existing field declaration; no new fields are added. The goal is to create complex nested anonymous ADT (Aggregate Data Type) patterns that may stress the compiler's field uniqueness checking logic. For example, consider a seed struct S with a field `_: struct { _: union { a: u8 } }`. The operator could mutate this to `_: union { _: struct { a: u8 } }`, effectively swapping the inner struct and union. Alternatively, it could add an extra nesting level: `_: struct { _: struct { _: union { a: u8 } } }` by inserting another anonymous struct inside the existing one. The mutation must use only existing types and variables from the seed; if the seed lacks a suitable anonymous union or struct to swap, the operator may insert a new anonymous type, but this new type should be a trivial one (e.g., `union { x: u8 }` or `struct { x: u8 }`) using a primitive type like u8 that is already present in the program. The operator should avoid creating duplicate field names unless such duplication already exists in the seed.
