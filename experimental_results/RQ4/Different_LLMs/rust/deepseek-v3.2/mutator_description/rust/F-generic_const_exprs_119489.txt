mutation operator
This mutation operator targets the interaction between generic const expressions and non-lifetime binders in where-clauses. It applies to a function or impl block that uses a for binder with generic const parameters. The operator modifies the default value expression of a const generic parameter that depends on another const generic parameter bound in the same for binder. Specifically, it changes the arithmetic expression used in the default value to a different operation or introduces a more complex expression that still depends on the earlier parameter. The mutation must use only existing names and types from the seed program; no new identifiers are introduced. If the seed program contains a const generic parameter with a default value that is a simple arithmetic expression like { N + 1usize }, the operator will replace the addition with subtraction, multiplication, or a bitwise operation, ensuring the expression remains valid and depends on N. For example, if the seed has for<T, const N: usize, const NP: usize = { N + 1usize }> T: Copy, mutate it to for<T, const N: usize, const NP: usize = { N - 1usize }> T: Copy, or for<T, const N: usize, const NP: usize = { N * 2usize }> T: Copy. The change is made directly to the expression inside the braces. If no such default exists in the seed, the operator does nothing. This mutation aims to trigger internal compiler errors related to constant evaluation and map lookups in the THIR or MIR construction phases.
