mutation operator: Replace constant expression in array type with a mismatched constant expression that uses existing generic const parameters but alters the arithmetic operation or operand.

This mutation operator targets array type definitions within impl blocks that involve generic constant expressions, specifically those using const generics in array sizes. It applies when an array type in the return position or within a trait bound uses a constant expression involving multiplication, addition, subtraction, or division of generic const parameters. The operator modifies the constant expression by altering the arithmetic operation or one operand while ensuring the expression remains syntactically valid and uses only existing generic const parameters from the context.

For example, if the seed program contains an array type like `[(&'a T, &'a U); N * N]` within an impl signature, the operator could mutate it to `[(&'a T, &'a U); N + N]` or `[(&'a T, &'a U); N * (N - 1)]`, assuming `N` is a declared const generic parameter. The change must be made directly in the array size expression, preserving all other parts of the code. No new variables, types, or functions are introduced; only existing const generic parameters are reused in a modified arithmetic expression. The mutation should be applied to every occurrence of such array type definitions in the program.

Illustration with pseudo-code:
Original: `[SomeType; N * N]`
Mutated: `[SomeType; N + N]`

Original: `[AnotherType; M * K]`
Mutated: `[AnotherType; M * (K + 1)]` (if K is a const generic parameter)

Implementation steps:
1. Identify all array type definitions in impl blocks that include constant expressions using generic const parameters.
2. For each identified array type, parse the constant expression and locate arithmetic operations (like *, +, -, /).
3. Modify one arithmetic operation or operand: change the operator (e.g., * to +) or adjust an operand by a small integer offset (e.g., change N to N-1), ensuring the operand is a generic const parameter.
4. Replace the original constant expression with the mutated version in the code.
5. Ensure no undeclared elements are introduced; only use const generic parameters already present in the scope.

This operator aims to trigger bugs related to const expression evaluation, type checking, or trait resolution mismatches in the compiler, especially under the F-generic_const_exprs feature.
