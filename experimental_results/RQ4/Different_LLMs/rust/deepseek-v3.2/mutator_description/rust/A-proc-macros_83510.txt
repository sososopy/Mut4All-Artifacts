mutation operator: Replace a trait bound in a type alias with a placeholder trait bound that lacks a path segment.

This mutation operator targets type alias definitions that contain trait bounds. Specifically, it applies when a type alias uses the syntax `type Name = ConcreteType + TraitBound;` or similar forms where a trait is used as a bound. The operator changes the trait bound to an incomplete path, such as by removing its final identifier segment or replacing it with a single, undefined identifier.

The operator should first identify a type alias item in the seed program. Within that alias, locate a trait bound that is specified after a `+` (or `?` for negative bounds). The trait bound must be expressed as a path (e.g., `Trait` or `some::module::Trait`). The mutation modifies this path to become syntactically incomplete: if the path has multiple segments (like `std::fmt::Debug`), remove the last segment, resulting in `std::fmt`. If the path is a single identifier (like `Debug`), replace it with a placeholder identifier that is not declared as a trait in the current scope; a suitable placeholder is a single underscore `_`. Ensure the mutated type alias remains syntactically valid Rust code for parsing, though it will be semantically incorrect.

Example: For a seed code snippet `type Alias = Vec<u8> + Clone;`, the trait bound `Clone` is a single identifier. Mutate it to `type Alias = Vec<u8> + _;`. For a seed with a qualified path, such as `type Foo = Box<Bar> + std::fmt::Debug;`, mutate to `type Foo = Box<Bar> + std::fmt;`. The mutation introduces an incomplete trait path, which may trigger resolution errors or internal compiler errors like the one in the bug report, where the compiler expected a fully resolved trait but encountered `None`.

The operator should avoid creating duplicate mutations for the same alias; apply only one mutation per type alias, selecting the first applicable trait bound. Do not introduce new type or trait declarations; use only existing syntax elements or the underscore placeholder. This mutation is designed to test the compiler's diagnostic and resolution logic for malformed trait bounds in type aliases.
