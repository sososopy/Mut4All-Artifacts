mutation operator: replace repr attribute combinations on enums and structs with conflicting or duplicate repr specifiers

this mutation applies to any struct or enum definition that has at least one repr attribute. the operator introduces a second repr attribute with either the same specifier or a conflicting specifier relative to the existing one, placed immediately before or after the existing repr attribute. for enums, if the existing repr is an integer type (like repr(u8)), the duplicate will use the same integer type. for structs, if the existing repr is C, the duplicate will also be C. if the existing repr is transparent, the duplicate will be transparent. the goal is to create a syntactically valid but potentially semantically conflicting layout directive. if the item already has multiple repr attributes, this mutation will add one more duplicate of the first specifier found.

example transformation: given a seed enum definition like #[repr(u8)] enum EnumName { A, B } it becomes #[repr(u8)] #[repr(u8)] enum EnumName { A, B }. given a seed struct definition like #[repr(C)] struct StructName(u8); it becomes #[repr(C)] #[repr(C)] struct StructName(u8);. this mutation should use only specifiers already present in the seed program; if no repr attribute exists on any item, this operator does not apply. the new attribute is inserted directly adjacent to the existing attribute, preserving other attributes if present.
