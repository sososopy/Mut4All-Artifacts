mutation operator: Replace a generic associated constant expression in a where clause bound with an explicit type parameter substitution in a function call expression. This mutation applies when a function call expression within a generic function uses a generic type parameter that appears in a where clause bound involving an associated constant expression, such as [(); T::CONST]: Sized. The mutation replaces the generic function call expression, which relies on type inference to determine the generic argument, with an explicitly specified type argument using the turbofish syntax. For example, if a seed program contains a function call like function_name() within a generic function where the return type or constraints involve T::CONST, mutate it to function_name::<T>(). The mutation should only be applied if the function being called is defined with generic parameters and the call site does not already use explicit turbofish arguments. Ensure the type used in the turbofish is the same generic type parameter that is in scope at the call site. If multiple generic parameters exist, choose the one that appears in the associated constant bound. This mutation aims to alter the inference context and may expose bugs in const evaluation during trait selection. For instance, given a function call like Conster::new() where Conster is generic over OT and has a where clause [(); OT::BYTES]: Sized, mutate to Conster::<OT>::new().
