mutation operator: Wrap a const generic parameter expression in a trivial macro invocation when used as a const argument in a type. This applies when a const generic parameter (e.g., const N: usize) is used directly as a const argument for another type (e.g., in a struct field type like Const<N>). The mutation changes the usage of the parameter to be wrapped by a simple, existing macro that expands to its input. For example, if the seed program contains a macro_rules! macro named identity_macro defined as ($x:expr) => { $x }, and a struct definition like struct S<const N: usize>(Const<N>);, then mutate the const argument N to identity_macro!(N), resulting in struct S<const N: usize>(Const<{ identity_macro!(N) }>);. If no suitable macro exists in the seed, introduce a new macro_rules! macro named wrapper at the appropriate scope (module or crate root) with the definition macro_rules! wrapper { ($e:expr) => { $e }; } before applying the mutation. The change is made only to the usage site of the const parameter within the type argument; the parameter declaration itself remains unchanged. This targets interactions between macro expansion and const generic HIR representation.
