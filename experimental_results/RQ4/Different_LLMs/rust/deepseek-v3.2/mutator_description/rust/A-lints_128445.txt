mutation operator: replace a literal in a macro expansion with an out-of-range literal for its inferred type.

This mutation operator targets literal expressions that appear inside macro expansions, particularly when the macro is defined in a separate file or module where the source may not be directly available during linting. It applies when a seed program contains a macro that expands to a literal (integer, float, character, or string). The operator changes that literal to a value that is outside the permissible range for the type that the literal will be inferred to have in its context. For example, if the macro expands to an integer literal that is used in a context expecting a u8, replace it with a literal like 1000. The mutation should be applied directly to the macro definition's token tree, replacing the literal token. Use an existing literal from the seed program to determine an appropriate type for overflow; if no context is clear, default to using a literal that would overflow common integer types (e.g., 1000000 for a 16-bit context). Do not introduce new variables or types; only modify the literal value in the macro body.

Example: In a seed program with a macro `make_num!` defined as `macro_rules! make_num { () => { 42 }; }`, mutate it to `macro_rules! make_num { () => { 1000 }; }` if 42 is used in a u8 context. If the seed program uses a float literal, mutate to a value like `1e400` to overflow f32. Ensure the mutated literal is a valid Rust literal token.
