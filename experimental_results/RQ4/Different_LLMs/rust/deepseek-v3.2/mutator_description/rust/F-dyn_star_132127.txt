mutation operator
Target a cast expression where the source type is a dyn* trait object with auto trait additions (like Send, Sync) and the target type is a dyn* trait object without those auto traits. The mutation changes the cast to a coercion context by using the source expression in a position that expects the target dyn* type, such as an assignment to a variable of the target type or passing it as an argument to a function expecting that type. Specifically, for a cast expression of the form "source_expr as dyn* Trait" where source_expr has a type like dyn* Trait + Send, replace the cast with an assignment "let new_var: dyn* Trait = source_expr;" where new_var is a fresh variable name not used in the current scope. If the source expression is already a variable, you can reuse it, but you must declare a new variable with the target type to force a coercion check. This mutation applies only when the source type is a dyn* trait object with one or more auto traits and the target type is a dyn* trait object with a subset of those traits (specifically, removing auto traits). The mutation should be applied in a block where such a cast exists, and the new variable declaration should be placed immediately after the original cast statement, or the original cast can be replaced. For illustration, if the seed contains "let x: dyn* Trait + Send = value; x as dyn* Trait;", mutate to "let x: dyn* Trait + Send = value; let _coerce_target: dyn* Trait = x;". Ensure the new variable name does not conflict; use a name like "_coerce_target" or a fresh identifier based on existing names. The mutation introduces a new variable declaration, which is valid Rust syntax, and relies on coercion to handle the type conversion instead of an explicit cast.
