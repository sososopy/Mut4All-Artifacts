mutation operator: Alter the lifetime bound in trait method signature to a tautological bound.

This mutation operator targets trait definitions where a method includes a lifetime parameter with a bound. Specifically, it applies to any trait method signature that contains a lifetime parameter declared with a bound, like `'a: 'b`. The operator changes the bound to a tautological self-reference, i.e., it replaces the bound with the same lifetime name. For example, if a trait method is defined as `fn method<'a: 'b>() -> T`, mutate it to `fn method<'a: 'a>() -> T`. If the original bound is already a self-reference, no mutation occurs. The operator only modifies the bound expression within the lifetime parameter declaration; it does not alter any other part of the signature, such as return types or parameter lists. This mutation should be applied to trait definitions, not to implementations. The goal is to create a scenario where the lifetime bound is trivially satisfied but may expose inconsistencies in the compiler's handling of such bounds, particularly in combination with other complex features like impl Trait or Fn family traits.

For example, consider a seed program with a trait:
trait Trait {
    fn example<'input: 'output>() -> impl Iterator;
}
After mutation, it becomes:
trait Trait {
    fn example<'input: 'input>() -> impl Iterator;
}
This mutation uses only elements present in the seed program: the trait, method, and lifetime parameter names are unchanged; only the bound identifier is replaced with the same name as the lifetime parameter. No new variables, types, or functions are introduced.
