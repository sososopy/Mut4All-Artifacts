mutation operator: Duplicate Field Names In Struct Definition

This operator targets struct definitions that contain multiple fields. It modifies a struct by introducing a duplicate field name, creating a scenario where two fields share the same identifier but may have different types.

The operator applies when a struct has at least one field. It selects a struct definition within the seed program. It then chooses one existing field name from within that same struct. Next, it creates a new field entry using this selected name. The type for this new duplicate field is chosen from one of the following options, in order of preference: 1) the type of another existing field within the same struct; 2) a primitive type like `i32` or `bool` that is already in use elsewhere in the seed program; 3) if no suitable type exists, a default primitive type `u8` is introduced.

The change is made directly to the struct's definition. No other declarations are added. The operator only duplicates the field name; it does not modify any struct instantiation code, which will likely lead to compilation errors or unexpected const-evaluation behavior.

Example transformation:
Original seed code contains: `struct S { a: i32, b: String }`
After mutation, it could become: `struct S { a: i32, a: bool, b: String }`
Here, the field name `a` is duplicated, and the new field is given the type `bool`, which must be a type already present in the program context.
