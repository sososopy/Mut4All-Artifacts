mutation operator Replace const pointer to unsized type with raw pointer to sized type. This mutation applies to constant items with a raw pointer type (*const T or *mut T) where T is an unsized type such as str or [U]. It changes the pointer to point to a sized type, specifically the unit type (), while preserving the const context and the match expression if present. The operator first identifies any constant item declared as const NAME: *const str = "string literal"; or similar for mutable pointers and unsized slice types. It then changes the type to *const () and the initializer to &() as (). For example, given const C: *const str = "abcd";, mutate to const C: *const () = &() as *const ();. If the constant is used in a match expression like match C { C => {}, _ => {} }, the match expression remains unchanged, still matching on the mutated constant. The mutation should only be applied if the constant is used in a pattern matching context such as a match arm, as the bug involves const-evaluating the pointer for pattern matching. If the constant is not used in such a context, the mutation may still be applied but might not trigger the bug. The mutated constant must remain a compile-time constant. The operator does not introduce new names; it reuses the existing constant name and adjusts its type and initializer. This mutation targets the interaction between const-evaluation of raw pointers to unsized types and pattern matching, which caused an internal compiler error in the bug report.
