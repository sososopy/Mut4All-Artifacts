mutation operator: Replace a const generic parameter default value in a struct, enum, or function definition with a different const expression of the same type that is already present in the seed program. This operator targets struct, enum, and function definitions that have const generic parameters with default values. The operator identifies a const generic parameter with a default value, such as `const C: usize = DEFAULT_CHUNK_SIZE`. It then searches the seed program for another const expression of the same type, for example, a different const item like `const OTHER_SIZE: usize = 32768;` or a literal like `1024`. The operator replaces the default value with this other const expression. If no other const expression of the same type exists in the seed, the operator does not apply. The change is made directly in the definition. For example, given a seed with `const A: usize = 100; const B: usize = 200;` and a struct `struct S<const N: usize = A>`, the operator could mutate it to `struct S<const N: usize = B>`.
