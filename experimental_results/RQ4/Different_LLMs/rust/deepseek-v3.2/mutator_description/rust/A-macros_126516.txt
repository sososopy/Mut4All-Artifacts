mutation operator

This mutation operator targets const blocks containing inner attributes, particularly when they are placed within function return types involving impl Trait and const trait bounds. It applies when a seed program contains a const block that is syntactically valid but may be placed in a context where macro expansion interacts with incremental compilation. The operator modifies the const block by replacing its inner attribute with a macro invocation that expands to an attribute. Specifically, it changes an inner attribute of the form `#![attr = "value"]` to `#![path = macro!()]` where `macro` is a macro that currently exists in the seed program's scope and is known to expand to a string literal. If no such macro exists, the operator does not apply. The change should be made directly within the const block's body, ensuring the block remains a valid const block syntactically. For example, if the seed has `const { #![cfg(test)] }` within a return type like `-> impl ~const Trait`, and there exists a macro `foo` that expands to `"test"`, the operator mutates it to `const { #![cfg = foo!()] }`. This mimics the structure in the bug report where an attribute's value is supplied by a macro invocation, which may cause resolution issues during incremental compilation. The operator aims to trigger edge cases in macro expansion within const blocks in complex type contexts.
