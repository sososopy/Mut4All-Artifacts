Mutation operator: Replace array repeat expression length with a function item identifier. This mutation applies to array repeat expressions of the form [expr; length] where length is a constant expression. The operator replaces the length expression with a function item identifier that is in scope, such as the name of a function defined in the current module or a built-in function like main. The mutation should only be applied if the function identifier is accessible and its type is not a const fn returning a suitable integer. Specifically, target array repeat expressions that appear in contexts where the array may be involved in type inference or comparisons, such as being an operand to a binary operator like ==. For example, given a seed program containing a function named foo and an array repeat expression like [value; 42], mutate it to [value; foo]. This mimics the bug-triggering pattern where a function item is used as a const argument in an array repeat length, potentially exposing edge cases in const argument evaluation and type checking. Ensure the mutated program compiles with the min_generic_const_args feature enabled to activate the relevant compiler paths.
