Mutation operator: Replace a generic const parameter's expected type with a mismatched integer literal in a function call that expects boolean const parameters.

This operator targets function calls where generic const parameters are explicitly provided as arguments, and the const parameters are expected to be of boolean type. The mutation changes one of the boolean literal arguments (true or false) to an integer literal (like 0u8 or 1u8), creating a type mismatch.

The operator applies when a function or method call supplies explicit const arguments for generic const parameters, and those parameters are constrained to be of type bool within the function's definition (e.g., via trait bounds or internal assumptions). The seed program must already contain such a call.

The change involves selecting one function call in the seed program that passes boolean literals (true/false) as const generic arguments. One of these boolean literals is replaced with an integer literal, such as 0u8. The integer literal should be a simple, well-typed expression like 0u8, 1u32, etc., ensuring it is a valid constant expression but of the wrong type. No new declarations are needed; the integer literal is introduced directly. The operator should prefer to mutate calls where the const generic parameters are explicitly bound to bool, as inferred from the surrounding code (e.g., the function's const parameters are typed as bool, or a where clause enforces bool).

For example, if the seed contains: `some_function::<T, U, true, false, true>()`, mutate it to: `some_function::<T, U, true, 0u8, true>()`. The mutation changes the second const argument from `false` to `0u8`. Ensure the call remains syntactically correct; only the argument token is replaced.

The goal is to trigger type-checking errors or internal compiler inconsistencies related to const generic parameter mismatches, especially in features like generic_const_exprs where const evaluation and type checking interact. This mimics the bug scenario where a u8 was passed where a bool was expected, leading to an ICE.
