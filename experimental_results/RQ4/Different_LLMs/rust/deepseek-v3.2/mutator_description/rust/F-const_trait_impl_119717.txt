Mutation operator: Const trait impl with missing generic parameter and const trait attribute.

This operator targets trait implementations that are declared with the const keyword but are missing required generic parameters or the const trait attribute. It applies to any impl block that uses the const keyword for a trait that is not marked with #[const_trait]. The operator modifies the impl block by either removing the const keyword or adding a generic parameter placeholder if missing, and optionally adding the const trait attribute import if not present.

Specifically, when encountering an impl const TraitName for Type block, if Type is a generic parameter that is not defined in scope (like a single capital letter without declaration), the operator will change it to impl const TraitName for ConcreteType, where ConcreteType is an existing type from the seed program, such as i32 or String. If no concrete type exists, it will introduce a new type alias like struct Placeholder; and use that. Additionally, if the trait is not marked with #[const_trait] in its definition, the operator will add a dummy trait definition with the attribute in the same scope, but only if the trait is not from the standard library. For standard library traits, it will remove the const keyword from the impl block.

Example: In the seed code, there is impl const FromResidual for T. Since T is not defined, change it to impl const FromResidual for i32, assuming i32 is present or can be introduced. If the trait FromResidual is not marked with #[const_trait], either remove const from impl or add a dummy trait definition with #[const_trait] at the top of the file. The goal is to create a syntactically valid but semantically unusual impl block that may trigger edge cases in const trait handling.

The operator must ensure that all types and traits used are either already in scope or introduced in a valid way, avoiding undefined identifiers. It should not use placeholder names like T without declaration. The mutation should produce code that compiles without immediate errors but may expose internal compiler assertions related to const trait and effects feature interaction.
