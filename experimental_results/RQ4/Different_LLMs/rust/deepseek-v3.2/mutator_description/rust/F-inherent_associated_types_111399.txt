mutation operator: Replace inherent associated type references in associated constants with the concrete type they are bound to. This operator targets code that uses inherent associated types within associated constant definitions inside the same impl block. Specifically, when an associated constant within an impl block uses Self::AssocTy where AssocTy is an inherent associated type defined in the same impl, replace Self::AssocTy with the concrete type that AssocTy is bound to. Apply this mutation only if the inherent associated type is defined as a type alias to a concrete type within the same impl. For example, given a seed program with a struct S, an impl block for S that defines an inherent associated type AssocTy = T (where T is a concrete type like usize) and also defines an associated constant AssocConst: Self::AssocTy = value; mutate the associated constant definition to AssocConst: T = value;. Ensure that T is a valid existing type from the seed program, such as usize in the example. This mutation should be applied to all such occurrences in the seed program where the conditions are met. If the inherent associated type is defined with generic parameters or bounds, do not apply the mutation. The goal is to test the compiler's handling of inherent associated type resolution when the reference is replaced by its concrete definition, potentially exposing bugs in the type checking or bounds collection for associated constants.
