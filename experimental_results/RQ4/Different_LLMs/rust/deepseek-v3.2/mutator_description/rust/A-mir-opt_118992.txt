mutation operator: Replace an index expression with a constant index value that is out of bounds relative to a length derived from the same variable. This operator applies when there is an indexing operation on a variable of an array or slice type where the index is computed using a method call on that same variable, such as `len()`. The operator replaces the computed index with a constant integer that is either less than 0 or greater than or equal to the length of the collection. Specifically, if the index expression is `var.len() - K`, where `K` is a positive integer constant, replace the entire index with `var.len() - 1 - K`, ensuring the resulting index is still out of bounds if the original was valid. If the seed program does not have a suitable constant, use `-1` or `var.len()` as the replacement. Only apply this mutation if the variable being indexed is already declared in the current scope and has a type that supports indexing. For example, given `let x = arr[arr.len() - 2];`, mutate to `let x = arr[arr.len()];` or `let x = arr[-1];`, choosing the first option if `arr.len()` is a valid expression. Introduce a constant like `-1` only if the language permits it in the context; otherwise, use `arr.len()`. The change must directly substitute the index part of the indexing operation.
