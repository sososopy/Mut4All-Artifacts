mutation operator: Replace higher-rank trait bound lifetime quantification with a static lifetime bound in where clauses

This mutation operator targets where clauses that contain higher-rank trait bounds (HRTBs) of the form 'for<'a> ...' specifically when they involve associated types from trait implementations. It applies when a function or method has a where clause with a HRTB that constrains an associated type projection (like <Foo<'a> as Bar>::Type) with a trait bound (e.g., Sized). The operator modifies the bound by removing the universal quantification ('for<'a>') and replacing the lifetime parameter 'a with the static lifetime 'static in the associated type projection.

Specifically, for a seed program containing a where clause like: 'where for<'a> <Foo<'a> as Bar>::Type: TraitBound', the operator changes it to: 'where <Foo<'static> as Bar>::Type: TraitBound'. The operator only applies if the HRTB introduces exactly one lifetime parameter (like 'a) that appears within an associated type projection. The trait bound (e.g., Sized) remains unchanged. The types (Foo, Bar) and the associated type name (Type) are taken directly from the seed program; no new types or variables are introduced.

Example: In the provided bug report code, the function test has 'where for<'a> <Foo<'a> as Bar>::Type: Sized'. The mutation would produce 'where <Foo<'static> as Bar>::Type: Sized'. This changes the meaning from requiring the associated type to be Sized for all lifetimes 'a to requiring it only for the static lifetime, which may expose bugs in compiler handling of associated type projections and lifetime substitution in bound checking.
