mutation operator: Replace async trait method with a non-async method that returns a manually implemented future using `impl Future<Output = ...>` in the trait definition. This operator applies when a trait contains an async method (i.e., a method using the `async fn` syntax). It modifies the trait definition by converting the async method into a regular method that returns an `impl Future` with the same output type, while keeping the method signature otherwise identical. The trait implementation for the method must be updated to return a future, typically by wrapping the original async block in an `async { ... }` block or using an existing future-returning expression. If the `Future` trait is not in scope, add `use core::future::Future;` at the top of the module. Only apply this mutation if the seed program uses the `async_fn_in_trait` feature or contains async trait methods. For example, given a trait `Trait` with an async method `async fn method(&self) -> Output;`, change it to `fn method(&self) -> impl Future<Output = Output>;` and in the impl block, change `async fn method(&self) -> Output { ... }` to `fn method(&self) -> impl Future<Output = Output> { async { ... } }`. Use existing types and variable names from the seed program; do not introduce new types or functions beyond the necessary `Future` import.
