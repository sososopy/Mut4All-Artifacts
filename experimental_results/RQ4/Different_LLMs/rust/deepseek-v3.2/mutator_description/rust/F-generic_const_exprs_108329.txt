mutation operator: Replace a generic constant expression with a different constant expression that uses the same generic parameters but alters the arithmetic or logical structure, focusing on expressions that appear in array lengths, type parameters, or const generic arguments. This mutation applies when a const generic parameter is used in an expression within a struct definition, function signature, or associated constant, particularly when the expression involves arithmetic operations or comparisons. The mutation changes the expression by swapping operators, modifying operands, or introducing parentheses to change evaluation order, while ensuring the expression remains syntactically valid and uses only existing generic parameters and constants from the seed program.

For example, if the seed program contains a struct definition like struct Example<const N: usize> where [(); N + 1]: , mutate the expression N + 1 to N - 1, N * 2, or (N + 1) * 1, provided these operands and operators are valid in the context. Another example: if a function uses a bound like where [(); M * 2]: , mutate M * 2 to M / 2 (if division is valid for integer types) or M + 2. The mutation should not introduce new variables or types; it only rearranges or replaces operators and operands within the existing expression. Prefer mutations that produce constant expressions that are still evaluable at compile time but may alter type system constraints.
