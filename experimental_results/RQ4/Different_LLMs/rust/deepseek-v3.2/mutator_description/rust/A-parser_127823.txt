mutation operator Replace single-byte operator with Unicode look-alike multi-byte character.
This mutation applies to any token in the source code that is a single-byte operator recognized by the Rust lexer. It targets operators such as =, ==, !=, <=, >=, +, -, *, /, %, &, |, ^, !, ~, <, >, ?, ., :, ;, ,, @, #, $, (, ), [, ], {, and }. The operator must be a valid ASCII operator in the seed program. The mutation replaces the single-byte operator token with a Unicode character that visually resembles the operator but is encoded using multiple bytes. The replacement character must be chosen from the Unicode set of characters that are visually similar to the original operator, for example, replacing = with ⩵ (U+2A75) or replacing == with ⩵ (U+2A75). The change is made directly at the token level in the source text, ensuring the surrounding context remains valid Rust syntax except for the mutated token. For instance, if the seed contains `x == y`, mutate to `x ⩵ y`. If the seed contains `let a = 5;`, mutate to `let a ⩵ 5;`. The mutation must only replace operators that exist in the seed; it does not introduce new operators or change operands. The selection of which operator to mutate and which Unicode replacement to use should be randomized among available operators and their look-alike counterparts. This targets parser and diagnostics code that may incorrectly handle multi-byte characters that are not valid tokens, potentially triggering assertion failures in span handling or suggestion logic.
