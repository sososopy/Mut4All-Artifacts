mutation operator
Target a cast expression where the target type is a dyn-star trait object (dyn* Trait). Replace the source expression of the cast with a numeric literal of a floating-point type (f32 or f64) that is not a valid source for a dyn-star cast according to the language semantics, but is syntactically allowed. The mutation applies when the seed program contains a cast expression with a dyn-star target type. Specifically, locate any cast expression of the form "expression as dyn* Trait". Replace the source expression with a floating-point literal, such as "1.0" for f64 or "1.0f32" for f32. Ensure the literal is a valid floating-point literal in Rust. If the seed program does not have a dyn-star cast, this mutation does not apply. Use existing floating-point types from the seed program if available; otherwise, introduce a literal of a standard floating-point type like f64. The change is only to the source expression; the target type remains unchanged. This mutation aims to trigger unexpected type handling in the compiler for dyn-star casts with incompatible source types.

Example: In a seed program with "x as dyn* Debug", mutate to "1.0 as dyn* Debug". In a seed program with "(func()) as dyn* Send", mutate to "3.14f32 as dyn* Send".
