mutation operator: Replace a trait bound in an associated type with a const_trait bound when the trait is marked as const_trait.

This mutation applies to associated type declarations inside trait definitions. Specifically, it targets the bounds on an associated type. When an associated type has a bound specifying a trait (e.g., `: Trait`), and that trait is declared with the `#[const_trait]` attribute, the operator changes the bound to a `const Trait` bound.

The change is made directly in the trait definition. For example, given a seed program containing:
`trait Trait1 { type Assoc: Trait2; }`
and where `Trait2` is declared as `#[const_trait] trait Trait2 {}`,
the mutation would modify the bound in `Trait1` to:
`trait Trait1 { type Assoc: const Trait2; }`.

The operator only applies when the trait being bound to (Trait2 in the example) is explicitly marked with `#[const_trait]`. No new types, variables, or functions are introduced; the change is solely to the bound syntax within an existing associated type declaration. This targets the compiler's handling of const trait bounds in implied bounds calculations, which was the area of the bug report.
