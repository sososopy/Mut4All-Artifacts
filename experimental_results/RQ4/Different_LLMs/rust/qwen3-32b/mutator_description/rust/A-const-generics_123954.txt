mutation operator: struct_const_before_type_with_default
Applies to struct definitions with at least one const parameter and one type parameter
Action: Reorder parameters to place a const parameter with a default expression before the type parameters
Implementation steps:
1. Select a const parameter (must have default expr or add one)
2. Ensure it appears before any type parameters in the struct declaration
3. If no existing default: add default like {0} to const parameter
4. Maintain original parameter names and constraint relationships
Example:
Original:
struct S<T, const N: usize> { ... }
Mutated:
struct S<const N: usize = {0}, T> { ... }

mutation operator: enum_const_before_type_with_default
Applies to enum variants with const/type parameters
Action: Place const variant parameter with default expr before type parameters
Implementation steps:
1. Identify enum variant with both const and type parameters
2. Reorder variant parameters to place const with default before types
3. Add default to const parameter if missing (e.g., {0})
Example:
Original:
enum E<T> { V(i32, const N: usize) }
Mutated:
enum E<T> { V(const N: usize = {0}, i32) }

mutation operator: trait_const_before_type_with_default
Applies to trait definitions with const/type parameters
Action: Position const parameter with default before type parameters
Implementation steps:
1. Select trait with const and type parameters
2. Reorder to place const with default before types
3. Add default to const if necessary
Example:
Original:
trait T<T, const N: usize> { ... }
Mutated:
trait T<const N: usize = {0}, T> { ... }
