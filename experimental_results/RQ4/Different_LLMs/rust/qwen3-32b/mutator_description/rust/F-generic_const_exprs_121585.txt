Mutation operator: Replace generic const parameter type with float in impl block and use in cast expression  
Applies to: impl blocks with generic const parameters used in associated type or const expressions  
Action: Select an existing generic const parameter in an impl block, change its type to f32/f64, and replace any usage of the parameter with a cast to integer type in const context  

Example mutation:  
Before:  
impl<const N: usize> MyTrait for MyStruct<{ N * 2 }> {}  

After:  
impl<const N: f64> MyTrait for MyStruct<{ N as u32 }> {}  

Target mechanism: Forces compiler to handle invalid float-to-integer cast in const generic context where only integer types are permitted. This exploits the same code path as the bug report by introducing a type mismatch in const evaluation logic.
