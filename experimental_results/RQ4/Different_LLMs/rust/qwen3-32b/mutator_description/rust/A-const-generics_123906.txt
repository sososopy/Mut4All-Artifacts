Mutation operator: Replace a fixed-size array return type with a const generic parameterized array. Apply to functions returning arrays with literal sizes (e.g., [T; N] where N is a literal). Change the return type to [T; const N: usize], introducing a const generic parameter N. The function body must instantiate an array of size N using the const parameter. For example:
Original: fn foo() -> [u8; 2] { [0, 1] }
Mutated: fn foo<const N: usize>() -> [u8; N] { [0; N] } 
This targets const generic handling in array type inference, exposing compiler bugs when resolving size parameters in type contexts.
