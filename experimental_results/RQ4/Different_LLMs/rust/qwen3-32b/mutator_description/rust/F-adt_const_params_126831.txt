Mutation Operator: ReplaceConstFnMatrixWithLiteral
Target: Algebraic Data Type (struct) const generic parameters initialized with const function returning an array type (Matrix), when the same array literal is already present in the seed program

Applies to:
- Structs with at least one const generic parameter using a computed array value
- Where the computed value is a multi-dimensional array with const parameters
- When a const function returns the same array literal value

Mutation procedure:
1. Find occurrence where a struct's const generic parameter is initialized with a const function call
2. Replace the function call with the array literal directly
3. Ensure the literal matches the exact same const array structure from the existing const function

Example transformation:
Original: const BRIDGE_MATRIX: [[usize; N_ISLANDS]; N_ISLANDS] = to_matrix();
Mutated: const BRIDGE_MATRIX: [[usize; N_ISLANDS]; N_ISLANDS] = [[0; N_ISLANDS]; N_ISLANDS]

Resulting in:
pub struct Walk<const CURRENT: usize, const REMAINING: Matrix> { _p: () }
impl Walk<0, [[0; N_ISLANDS]; N_ISLANDS]> { pub const fn new() -> Self { Self { _p: () } } }

This mutation stresses the type mapping system by directly embedding the literal value in the struct definition, bypassing the const function indirection while maintaining identical type structure. The compiler's internal consistency check for const parameters is likely triggered when directly comparing the literal form with internally generated type representations.
