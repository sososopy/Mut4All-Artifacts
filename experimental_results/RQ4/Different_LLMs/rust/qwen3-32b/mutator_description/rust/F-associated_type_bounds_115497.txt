Mutation Operator: Nested Associated Type Bounds with Generic Const Expressions  
Applies to functions with `where` clauses containing trait bounds and const parameters. The operator augments existing trait bounds by adding nested associated type constraints using `for` lifetimes and replaces simple const parameters with generic const expressions that compute using associated items from the trait.  

Example transformation (pseudo-code):  
Original:  
```rust  
trait T { type A; }  
fn f<T: T>() { ... }  
```  

Mutated:  
```rust  
trait T { type A; }  
trait U<'a> { type B; }  
trait V<'a, 'b> { }  
fn f<T>() where for<const N: u8 = { T::<0>::A as u8 }> T: T<A: for<'a> U<'a, B: for<'b> V<'a, 'b> >> { ... }  
```  

If the seed program lacks traits like `U` or `V`, they are introduced with appropriate lifetime parameters and associated types. The mutation ensures nested bounds are applied to existing trait bounds, leveraging already-declared traits and associated items.
