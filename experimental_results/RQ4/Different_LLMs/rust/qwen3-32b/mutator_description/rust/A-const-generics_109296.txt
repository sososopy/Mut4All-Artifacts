Mutation operator: ConstGenericAssocTypeMismatch
Target: Trait impls with generic const parameters and associated const usage
Applies to: Any struct/enum implementing a trait with associated const, where the impl uses a different type for the generic parameter than the associated const type

Changes to make:
1. In an existing trait definition with an associated const of type T
2. In an impl block for that trait with a generic const parameter of type U != T
3. Use the associated const in a context expecting a value of type U
   Example pattern:
   trait AssocConst {
     const VAL: T;
   }
   impl<const N: U> AssocConst for SomeType<N> {}
   fn use_assoc() -> [u8; <SomeType<13> as AssocConst>::VAL] {}

This exposes ICE scenarios where the compiler attempts to relate consts of different types (U vs T), particularly during const evaluation and trait resolution. The mutation leverages existing trait/impl structures and uses primitive types already present in the seed program.
