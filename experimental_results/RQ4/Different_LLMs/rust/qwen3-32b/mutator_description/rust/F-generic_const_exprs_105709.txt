Mutation Operator: Replace a struct or enum's const generic parameter's default value with a redundant nested block that contains a const item evaluating to the same value. This adds an unnecessary layer of scoping for the const expression, potentially triggering substitution errors in the compiler's handling of generic const parameters.

Target Code Construct: 
- Structs or enums with const generic parameters that have default values defined using a single const block (e.g., const { 5 }).

Change Description: 
1. Identify existing const generic parameters with default values using a const block.
2. Wrap the inner const block inside another block or a redundant const context.
3. Ensure the new expression maintains the same computed value but introduces syntactic complexity in the AST.

Example Before Mutation:
pub struct S<const N: usize = const { 42 }>;

Example After Mutation:
pub struct S<const N: usize = { const { 42 } }>;

Mutation Steps:
- Locate any struct or enum definition with a const generic parameter that has a default value using the pattern `const { ... }`.
- Replace the default value expression `const { expr }` with `{ const { expr } }`.
- No new variables or types are introduced; only the structure of the existing const expression is modified.
- The existing code must already define the const generic parameter with a default using a const block for this mutation to apply.

This mutation increases the nesting level of const expressions, which may expose bugs in the compiler's substitution logic when processing nested or redundant const contexts.
