Mutation Operator: Replace const generic parameter default value with a type name.  
Target: Const generic parameters in structs, enums, or impl blocks that use default expressions.  
Mechanism: Locate a const generic parameter with a default value (e.g., `const M: u32 = 10`). Replace the default expression with a type name (e.g., `u8`, `i32`, `String`). This exploits the compiler's incorrect handling of type names as const expressions.  

Example:  
Original:  
`struct Uwu<const N: u32 = 1, const M: u32 = 10>;`  

Mutated:  
`struct Uwu<const N: u32 = 1, const M: u32 = i32>;`  

Requirements:  
1. The target program must already use const generics with default parameters.  
2. Use a type name from the current scope (e.g., `u8`, `String`, or a user-defined type already in scope). Avoid introducing new types.  
3. Apply this mutation to any const parameter with an existing default expression (e.g., `const X: T = VALUE`).  

Coverage: High for programs using const generics, particularly with default parameters. This mutation exposes edge cases where the compiler fails to distinguish type names from expressions in const contexts.
