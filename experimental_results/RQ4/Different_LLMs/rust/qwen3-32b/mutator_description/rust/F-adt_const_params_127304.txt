Mutation operator: ADT_REF_CONST_PARAM
Target code with structs implementing `ConstParamTy` that hold string or byte slice references. In any function using const generics, replace the const parameter type with `&'static T` where T is such a struct, and replace the const argument with a T::new("literal") call. For example, change `fn foo<const N: usize>()` to `fn foo<const S: &'static MyStr>()`, and replace `foo!()` with `foo::<{ MyStr::new("test") }>()`. Ensure the struct's new method returns `&'static Self` and wraps a string/str. Apply only when the target struct already implements `ConstParamTy` and has a `new` method accepting a string literal.
