Mutation Operator: Replace array size with a large constant in await expressions within async functions to trigger overflow during generator interior type analysis.  
Applies to: Any array creation (`[T; N]`) used as the operand of `.await` in an `async` function.  
Example:  
Original:  
async fn f() {  
    [value; small_size].await;  
}  

Mutated:  
async fn f() {  
    [value; 0xffff_ffff_ffff_ffff].await;  
}  

Changes needed: Substitute `small_size` with a large `usize` value (e.g., `0xffff_ffff_ffff_ffff`) in the array size expression of the `.await` operand.  
Existing elements: `value` must be a placeholder for any valid expression or literal already present.  
New elements: None required; use existing types and literals in the seed program.
