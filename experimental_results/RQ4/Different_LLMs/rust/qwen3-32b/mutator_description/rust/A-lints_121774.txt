Mutation operator: Add `#[must_use]` attribute to a function and ensure at least one call site does not use its return value  
Applies to: Functions with return type but not marked as `#[must_use]`  
Change: For function `fn X(...) -> _` with no `#[must_use]`, insert `#[must_use]` above the definition. For any call site `X(...);` in the same crate, verify the return value is not assigned or used (e.g., `let _ = X(...);` becomes `X(...);`).  
Example:  
Original:  
```
fn compute() -> Result<i32, ()> { ... }  
fn main() { compute(); }  
```  
Mutated:  
```
#[must_use]  
fn compute() -> Result<i32, ()> { ... }  
fn main() { compute(); }  
```  
Note: Only applies to functions with non-void return types. Requires at least one unused return value in the crate.
