Mutation operator: NestedHigherRankTraitBounds
Applies to functions returning `impl Trait` with existing traits having associated types. Replace `impl Trait` return type with `impl for<T> Trait<Assoc = impl Trait<T>>` using existing trait name and associated type. If trait lacks associated type, declare `trait Trait { type Assoc; }` before use. Example: change `fn f() -> impl MyTrait` to `fn f() -> impl for<T> MyTrait<<Assoc = impl MyTrait<T>>`. This creates overlapping binders that stress bound variable tracking in type inference.
