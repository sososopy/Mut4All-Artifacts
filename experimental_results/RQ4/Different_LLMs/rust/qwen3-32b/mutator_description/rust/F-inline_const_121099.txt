Mutation Operator: InlineAssemblyInvalidConst
Targets inline assembly macros (e.g., `asm!`, `global_asm!`) that take constant expressions as arguments. Replaces a valid constant expression in the inline assembly context with one that contains a compile-time evaluation error (e.g., division by zero, overflow, or invalid type operation). Applies to expressions marked with `const` or implicitly evaluated at compile time in the macro arguments. For example, transforms `global_asm!("...", const X)` into `global_asm!("...", const 1 / 0)` where X was a valid constant. The mutation preserves macro structure and existing variable/function usage, ensuring the invalid expression is syntactically valid but semantically erroneous in the context of constant evaluation. Applies to any seed program containing inline assembly macros with constant arguments.
