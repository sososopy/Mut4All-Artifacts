Mutation Operator: For any function, trait, or struct that is generic over a type parameter T, introduce a new const parameter of type T. Example: Change `fn f<T>(t: T)` to `fn f<T, const C: T>(t: T)`. This mutation applies to all existing generic type parameters in the seed program. The const parameter is not used in expressions but forces the compiler to process const generics with non-primitive types, potentially triggering assertion failures in const generic handling logic.
