Mutation operator 1: Replace standard punctuation with visually similar Unicode characters in function calls.  
Applies to function calls using parentheses. Replace '(' with '（' (Fullwidth Left Parenthesis) and ')' with '）' (Fullwidth Right Parenthesis).  
Example: Change `f(x)` → `f（x）`.  
Applies to any existing function call in the seed program using standard parentheses. No new variables or types are introduced.  

Mutation operator 2: Introduce undefined variable access in expressions.  
Applies to array indexing expressions. Replace a valid array index access `arr[i]` with a reference to a non-existent array or variable in the same scope.  
Example: Change `arr[i]` → `undefined_arr[i]`.  
Applies to any existing array indexing expression in the seed program. No new variables or types are introduced.  

Mutation operator 3: Add extraneous arguments to function calls with mismatched signatures.  
Applies to function calls where the function has no parameters. Append a dummy argument of any type to the call.  
Example: Change `main()` → `main(x)`.  
Applies to any existing function call with zero parameters in the seed program. The argument `x` must already exist in the same scope.
