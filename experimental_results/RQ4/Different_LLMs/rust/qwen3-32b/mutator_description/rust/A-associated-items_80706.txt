Mutation operator: Introduce a higher-ranked lifetime bound on an associated type used in a trait bound. Apply to any function or method's where clause where an existing bound references an associated type from another trait. Modify the existing bound by wrapping the associated type in a `for<'lifetime>` clause requiring it to satisfy a phantom bound (e.g., `Sized`, `Debug`), or if no such bound exists, add a bound requiring the associated type to hold for all lifetimes (e.g., `for<'a> <T as Trait>::AssocType: 'a`). Example: Change `T: Trait` to `T: Trait<AssocType = for<'a> 'a>`. This increases interaction between associated types and higher-ranked bounds.
