mutation operator: Replace const parameter default with non-const variable in traits/methods  
Applies to: Any trait or method definition with const parameters that have default values  

Action: In a trait or method declaration with a const parameter using a valid default expression (e.g., `const N: Type = value`), replace the default expression's value with a non-const variable name declared in the same scope. The variable must already exist in the program and be a non-const binding (e.g., `let x = 42;`).  

Example:  
Original code:  
```rust  
trait Example<const N: u32 = 5> {  
    fn foo<const M: u32 = 10>(&self);  
}  
let bar = 2; // existing non-const variable  
```  

Mutated code:  
```rust  
trait Example<const N: u32 = bar> {  
    fn foo<const M: u32 = bar>(&self);  
}  
```  

Effect: Forces the compiler to process a generic const parameter with an invalid default expression (non-const variable), potentially exposing ICEs in the const expression evaluation path when analyzing trait/method generics.
