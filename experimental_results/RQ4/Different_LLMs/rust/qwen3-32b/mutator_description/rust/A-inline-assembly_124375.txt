Mutation Operator: InlineAssemblyExcessRegisterAccess  
Target: Naked functions with inline assembly that use registers corresponding to more parameters than declared.  
Action: Insert an inline assembly statement that accesses a register corresponding to an undeclared parameter.  
Example: In a function with two parameters (e.g., `a: isize, b: isize`), add an assembly line like `add rax, rdx` where `rdx` refers to a third undeclared parameter. This forces the compiler to reference a non-existent operand during codegen, potentially exposing index out-of-bounds errors in operand resolution.
