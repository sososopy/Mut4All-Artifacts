Mutation Operator:
In a function with a `where` clause that falsely assumes a non-`Sized` type (like references or `str`) satisfies `Sized`, insert a computed array size using a `const` block with a local variable declaration of that unbounded type. This forces the compiler to evaluate a constant requiring uncomputable layout.

Example:
Original: 
fn test() where str: Sized { ... }

Mutated:
fn test() where str: Sized {
    [(); { let _x: &str; std::mem::size_of::<str>() }];
}

This applies to any function with a `where` clause asserting `Sized` on a reference type or `str`. The mutation uses `size_of` on the unbounded type within an array size expression, leveraging existing type (`str` or `&T`) from the seed program's `where` clause.
