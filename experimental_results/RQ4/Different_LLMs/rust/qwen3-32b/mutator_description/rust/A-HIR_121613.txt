Mutation Operator: Replace a struct construction with a qualified path using an associated type from a trait, using existing trait and struct definitions. Apply to any struct initialization where the type is an associated type of a trait in scope. 

Example: 
Original: 
let x = StructStruct { br: 5 };

Mutated: 
let x = <Foo as A>::Assoc { br: 5 }; 

Requires: 
1. `StructStruct` is an associated type of trait `A` implemented for `Foo` 
2. `Foo` and `A` are already defined in scope 
3. No `#![feature(more_qualified_paths)]` attribute present
