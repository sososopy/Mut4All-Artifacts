Mutation operator: Replace valid const expressions in array/struct initialization lengths with function item references.  
Target: Any array initialization [T; N] or struct requiring const generic arguments.  
Change: Substitute N (a valid const) with an existing function name (e.g. main, foo).  
Example:  
Original: [X; 5]  
Mutated: [X; main] (assuming main is a declared function).  
Condition: Program must enable the 'min_generic_const_args' feature gate.  
Effect: Forces compiler to evaluate function items as const arguments, exposing ICEs in const argument validation paths.  

Mutation operator: Inject macro invocations resolving to function items in const argument positions.  
Target: Any array/struct initialization with explicit const parameters.  
Change: Replace literal/const expr in [T; N] with panic!() or log!(), which expand to function items.  
Example:  
Original: [X; 3]  
Mutated: [X; panic!()] (requires existing function-like macro).  
Condition: 'min_generic_const_args' feature is active.  
Effect: Triggers const argument typechecking for function-returning macros, bypassing normal const expr validation.  

Mutation operator: Convert const generics to function references in struct/array definitions.  
Target: All struct/array definitions using const parameters.  
Change: Replace literal const values with function names (existing in program).  
Example:  
Original: struct Buf<const N: usize>;  
Mutated: struct Buf<const N: usize = main>(); (main must be a declared function).  
Condition: Program uses 'min_generic_const_args' and declares at least one function.  
Effect: Probes compiler's handling of non-const expr values in generic const parameters.
