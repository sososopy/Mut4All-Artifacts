mutation operator: Insert an #[expect] or #[allow] attribute with a lint name onto a macro invocation in a context where the macro's expansion does not support attribute propagation. This applies to any macro invocation that appears as an expression or statement. The mutation introduces the attribute directly before the macro invocation, using an existing lint name that appears in the seed program's diagnostic comments. For example, transform `foo!(x);` into `#[expect(some_lint)] foo!(x);` where `some_lint` is a lint referenced in the seed program's `#[warn(...)]` or ` //~ WARN` comments. The mutation ensures the lint name matches a known diagnostic to increase compiler processing likelihood. If no lint name is present, use a placeholder like `unreachable_code`. This forces the compiler to process diagnostic levels during macro expansion, exposing inconsistencies in diagnostic propagation.
