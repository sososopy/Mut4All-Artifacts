mutation operator: insert_union_inline_const_array_with_generic_size  
Applies to unions with generic type parameters. Modify a union definition by adding a field with an array whose size is a `const { ... }` block containing a generic const expression that depends on the union's type parameter. This targets the interaction between `inline_const`, `generic_const_exprs`, and unions.  

Example transformation:  
Original:  
`union U { a: i32 }`  

Mutated:  
`union U<T> { a: i32, as_bytes: [u8; const { std::mem::size_of::<T>() }] }`  

If the union already has a generic parameter (e.g., `U<T>`), the mutation adds the field using its existing parameter. If the union is not generic, add a type parameter (e.g., `T`) to the union and use it in the const expression. The `std::mem::size_of` function must exist in the program's imports; if not present, introduce `use std::mem;` at the file scope.
