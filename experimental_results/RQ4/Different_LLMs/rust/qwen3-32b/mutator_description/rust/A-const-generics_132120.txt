Mutation Operator: Replace a const generic parameter with a const block wrapping a type-inferred variable. Apply to function calls where a const parameter is passed as a literal or variable with omitted type, and the seed program contains at least one const item declaration without explicit type annotation. In the mutated code, wrap the const argument in a `const { ... }` expression using a previously declared const variable (without explicit type) as the inner value. This targets type inference failures in const generics processing. Example: Change `f(x, 42)` to `f(x, const { y })` where `y` is a const var declared as `const y = ...;`.
