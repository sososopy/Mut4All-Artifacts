Mutation operator: Introduce a higher-ranked trait bound on an associated type in a function's where clause. For any function with a where clause referencing an associated type from a trait that has a lifetime parameter, replace the non-HRTB bound with a for<...> quantified bound over the trait's lifetime parameter, applying the bound to the associated type's use. This applies to functions where the trait bound includes an associated type and the trait has a lifetime parameter visible in the associated type's definition.

Example: 
Original code:
fn test<T>() where T: MyTrait<Assoc = U> { ... }

Mutated code:
fn test<T>() where T: for<'a> MyTrait<Assoc = U> { ... }
