Mutation Operator: ReplaceConstParamWithUnresolvedMacro  
Applies to: Const or type parameters involving macro invocations in generic arguments  
Transformation: Replace a concrete value in a const/type parameter with a macro invocation that expands to an undefined identifier  
Example in pseudo-code:  
// Original  
struct S<const N: usize> = ...;  

// Mutated  
macro_rules! m { ($($t:tt)*) => { unresolved_var } };  
struct S<const N: { m!() }> = ...;  

Targets the interaction between macro expansion and HIR lowering for anonymous constants in generic parameters. The mutation forces the compiler to process a macro-generated unresolved identifier in a context where def'n conflicts may arise, stressing the AST-to-HIR conversion logic. The macro must be fully contained within the mutation (no external dependencies) and must generate a simple unresolved identifier like 'unresolved_var' to avoid relying on existing program elements.
