Mutation Operator 1: Introduce Negation of Minimum Signed Integer Literal
Target Code Construct: Signed integer literals of maximum negative value (e.g., -0x8000_0000_0000_0000_0000_0000_0000_0000 for i128)

Description:
This mutation operator targets expressions that assign or compute the negation of the minimum possible value for a signed integer type. Such expressions are known to cause overflow during negation, leading to potential ICEs (Internal Compiler Errors) in the lints or semantic analysis phase.

How to Apply:
1. Identify an existing signed integer literal in the seed program. For example:
   let x = 0;

2. Change the literal to the largest possible negative value for the same bit width signed type (e.g., 0x8000_0000_0000_0000_0000_0000_0000_0000 for i128) and apply negation.
3. Replace the assignment with the mutated expression. Example:
   let x = -0x8000_0000_0000_0000_0000_0000_0000_0000;

4. Ensure the variable name (x in this example) is already present in the program unless a new one needs to be introduced explicitly.

Mutation Effect: 
This mutation is likely to expose bugs in the compiler's handling of negation overflow in lints or semantic analysis, especially when the compiler is in debug mode or with overflow checks enabled.

Example before mutation:
let x = 0;

Example after mutation:
let x = -0x8000_0000_0000_0000_0000_0000_0000_0000;
