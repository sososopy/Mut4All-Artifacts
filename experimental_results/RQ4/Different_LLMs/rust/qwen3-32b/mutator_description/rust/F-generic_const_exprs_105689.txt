Mutation Operator: Replace a fixed-size array in an async function with a generic const expression using a newly introduced const parameter, ensuring the expression is enclosed in braces and placed in a context where the async function may have lifetimes.

Example:
Original:
async fn foo() {
    let _data = [0u8; 5];
}

Mutated:
async fn foo<const N: usize>() {
    let _data = [0u8; { N + 2 }];
}

Explanation:
1. Targets the interaction between `generic_const_exprs` and async functions with lifetimes, as seen in the ICE.
2. Replaces a fixed array size with a generic const parameter `N` in an arithmetic expression.
3. Uses braces `{}` to form a constant expression, mimicking the bug’s context.
4. Leverages an existing `async fn` in the seed program, adding a generic parameter and modifying the array length.
5. High coverage across programs using async functions and basic generics.
