Mutation Operator: Replace array length with a generic constant expression using const block inside a union field.

Applies to: Unions with generic type parameters where one or more fields use array types with a const block to compute their size at compile time.

This mutation operator targets situations where the `const` block is used in a context that depends on a generic type and is part of a union. The compiler may trigger internal errors when evaluating such expressions if the feature is not fully stabilized or has edge cases not yet handled correctly.

Example:

Original code:
```
union AsBytes<T> {
    value: T,
    as_bytes: [u8; 8],
}
```

Mutated code:
```
union AsBytes<T> {
    value: T,
    as_bytes: [u8; const { mem::size_of::<T>() }],
}
```

The mutation replaces a fixed-size array (`[u8; 8]`) with a generic constant expression (`[u8; const { mem::size_of::<T>() }]`). This can expose bugs related to the evaluation of generic const expressions, particularly when used in unions or other complex type contexts.

Note: This only applies when the required nightly features are enabled (`inline_const` and `generic_const_exprs`). It is recommended to apply this mutation to existing unions or struct-like types that already use generic type parameters and are likely to benefit from const-evaluated sizes.
