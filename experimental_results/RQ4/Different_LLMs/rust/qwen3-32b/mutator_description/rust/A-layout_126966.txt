Mutation Operator: ModifyEnumReprForABIAlignmentConflict
Applicable to: Enum types used as fields in a union with varying alignment attributes.
Action: Alter the repr attribute of an existing enum to a conflicting alignment (e.g., packed(2) or align(1)) compared to another enum in the same union, ensuring both enums share a compatible ABI (such as size matching) but differ in alignment requirements.
Example:
Original code:
enum A { V = 0, }
enum B { V = 1, }
union U { a: A, b: B, }

Mutated code:
#[repr(u32)] // Align 4 bytes
enum A { V = 0, }
#[repr(C, packed(2))] // Align 2 bytes
enum B { V = 1, }
union U { a: A, b: B, }

fn main() {
    #[derive]
    use std::mem;
    let _: mem::BikeshedIntrinsicFrom<U, U>;
}
