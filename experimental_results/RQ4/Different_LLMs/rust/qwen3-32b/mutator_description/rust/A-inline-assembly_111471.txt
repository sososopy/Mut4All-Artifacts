MutationOperator: Replace an inline assembly instruction in a `core::arch::asm!` block with a WebAssembly-specific `global.get` or `global.set` instruction using a numeric index, paired with a `local.set` or `local.get` operand and `out(local)` output constraint.

Applies to: Rust code using `core::arch::asm!` with WebAssembly targets (e.g. `wasm32-unknown-unknown`) that contains inline assembly instructions with register operands (e.g. `out(reg)`, `in(reg)`) or generic memory operands.

Example of mutation:
Original code:
```rust
core::arch::asm!("i32.const 42", out(reg) val);
```
Mutated code:
```rust
core::arch::asm!("global.get 0", "local.set {0}", out(local) val);
```

This mutation introduces a WebAssembly global operation that:
1. Uses a numeric index (`0`) for `global.get`
2. Combines with `local.set` for stack manipulation
3. Requires `out(local)` constraint to capture results
4. Targets LLVM code emission pathways for WebAssembly inline assembly
