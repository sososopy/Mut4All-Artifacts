Mutation Operator: UnboxedClosureArgTupleViolation  
Applies to functions declared with `extern "rust-call"` ABI that accept a single non-self tuple argument.  
Modifies the first parameter of such functions by replacing the tuple pattern with individual parameters, removing the outer tuple wrapper.  
Example:  
Original:  
`extern "rust-call" fn foo((a, b): (i32, i32)) -> i32 { a + b }`  

Mutated:  
`extern "rust-call" fn foo(a: i32, b: i32) -> i32 { a + b }`  

This breaks the ABI requirement that all closure arguments must be passed as a single tuple. The compiler should detect the invalid signature but may ICE if the MIR inliner mishandles the argument structure.
