Mutation operator: Change const trait method parameter type mismatch
Target: Trait implementations with const methods using generic const exprs
Applies to: Functions implementing const-trait methods where parameter type differs from trait definition

Example mutation:
Original:
trait MyTrait {
    fn compute<const X: usize>(x: u8) -> usize;
}

impl MyTrait for MyType {
    fn compute<const X: usize>(x: u8) -> usize {
        x as usize
    }
}

Mutated:
impl MyTrait for MyType {
    fn compute<const X: usize>(x: usize) -> usize {
        x
    }
}

Mutation effect: Changes input parameter type from u8 to usize in the implementation while keeping trait definition as u8. This creates a type mismatch that triggers const evaluation ABI layout checks during type-checking. The compiler must reconcile differing scalar layouts (8-bit vs pointer-sized) in the const context, potentially exposing ICEs in generic_const_exprs handling. Requires existing const trait and impl blocks with generic parameters in the seed program.
