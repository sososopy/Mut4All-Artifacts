Mutation operator: Remove explicit type on static with complex initializer. Apply to static variables with explicit type and initializer using existing types in the seed program. Replace `static NAME: TYPE = INIT;` with `static NAME = INIT;`. Example: Change `static S_COUNT: AtomicUsize = AtomicUsize::new(0);` to `static S_COUNT = AtomicUsize::new(0);`. Targets const evaluation of ill-typed statics by omitting type annotation, triggering validation ICE when initializer's type is ambiguous or invalid.
