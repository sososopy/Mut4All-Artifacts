Mutation operator 1: Introduce undeclared lifetime in const generic return type
Target construct: Trait methods returning structs with lifetimes and const generics
Applicable when a trait method defines a return type that uses a lifetime parameter not declared in the trait or method, while also using const generics.

Example mutation on:
trait Foo<T> {
    fn bar<const N: usize>(&self) -> Baz<'a, T, N>;
}

impl<T> Foo<T> for [T] { }

struct Baz<'a, T, const N: usize> { }

Mutated to:
trait Foo<T> {
    fn bar<const N: usize>(&self) -> Baz<'a, T, N>;
}

impl<T> Foo<T> for [T] { }

struct Baz<'a, T, const N: usize> { }

This forces the compiler to process a return type with 'a lifetime not declared anywhere, while also involving const generics. The combination can trigger ICE during type inference when the borrow checker encounters unexpected inference variables during const parameter binding.
