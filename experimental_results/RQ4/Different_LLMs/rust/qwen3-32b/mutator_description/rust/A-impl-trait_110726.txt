Mutation Operator: Add Unused Lifetime to Recursive RPIT Return  
Target: Functions returning `impl Trait` with self-recursive calls in their body.  
Description: Introduce an unused lifetime parameter in the function signature and return type while ensuring the function body contains a recursive call that does not utilize the added lifetime. This exploits potential compiler bugs in handling opaque types with unused lifetimes in recursive contexts.  
Example:  
Original:  
```rust  
fn foo() -> impl Trait {  
    // body that may or may not use existing lifetimes  
}  
```  
Mutated:  
```rust  
fn foo<'a>() -> impl Trait + 'a {  
    let i = foo();  
    i  
}  
```  
Note: The recursive call `foo()` must not reference the new lifetime `'a` in the body, and the function must not use `'a` in any other context (e.g., parameters, field accesses).
