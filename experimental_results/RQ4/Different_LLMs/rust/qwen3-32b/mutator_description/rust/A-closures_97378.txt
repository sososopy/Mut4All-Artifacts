Mutation Operator: Insert async block with enum destructure
Target construct: Functions that use enums, inserting an async move block with enum pattern matching inside the function body.
- Apply to any function that uses an existing enum type, replacing a statement with:
  async move { let EnumVariant { field } = existing_value; }.await;
- Requires an existing enum declaration in the same scope and a variable holding an enum value.
- Example transformation:
Original:
fn process(e: MyEnum) { /* ... */ }

Mutated:
async fn process(e: MyEnum) {
    async move { let MyEnum::Variant { field } = e; }.await;
    /* ... */
}
