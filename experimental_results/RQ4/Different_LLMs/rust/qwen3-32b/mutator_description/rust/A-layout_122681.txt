Mutation operator: Apply a layout_scalar_valid_range attribute to a unit struct and include it as a variant in an enum that derives Default, then invoke Default::default() on the enum.

Applies to: Unit structs with layout attributes used in Default-derived enums.

Example:
Original:
struct MyStruct;
enum MyEnum { Variant }

Mutated:
#[rustc_layout_scalar_valid_range_start(1)]
struct MyStruct;
enum MyEnum {
    #[default]
    Variant(MyStruct)
}

In code: Replace existing unit structs with layout attributes and modify enums to include them as variants with #[default], then add Default::default() calls to enum usage.

Triggers compiler checks for scalar layout validity during enum default construction, exposing ICEs in layout validation logic when invalid ranges conflict with enum variant initialization paths.
