Mutation Operator: Nested Reference Pattern Expansion in Const Matches  
Applies to: Match arms where a constant reference is used in a pattern, and the matched value has nested reference layers.  

Action: For each match arm using a constant like `&PATTERN_CONSTANT`, insert an additional reference layer in the matched expression and adjust the pattern to match the new reference count. For example, if the original code is:  
`match &value { &PATTERN_CONSTANT => ... }`  
Mutate to:  
`match &&value { &&PATTERN_CONSTANT => ... }`  
This increases reference nesting in both the matched expression and the pattern, forcing the compiler to evaluate the constant in a context requiring deeper reference indirection.  

Example:  
Original:  
`match &vec[0] { &CONSTANT => ... }`  
Mutated:  
`match &&vec[0] { &&CONSTANT => ... }`  

This targets const evaluation paths that mishandle reference layers in patterns, particularly when the constant's type involves non-structural equality or requires dynamic evaluation. The mutation leverages existing variables and patterns in the seed program, ensuring compatibility with existing code structures.
