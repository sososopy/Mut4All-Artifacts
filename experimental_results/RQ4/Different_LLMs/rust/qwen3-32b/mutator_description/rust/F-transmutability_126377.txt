Mutation operator: Replace a boolean-typed const generic parameter with a numeric expression (e.g., `0u8`, `1i32`) when invoking a generic function. Apply this to any const parameter declared to require a `bool` type, using existing expressions from the program that evaluate to non-boolean types. For example, transform:

```rust
SomeGenericFunction::<..., { true }, ...>()
```

into:

```rust
SomeGenericFunction::<..., { 0u8 }, ...>()
```

This forces the compiler to validate type consistency in const parameters, potentially exposing ICEs or incorrect error handling when the transmutability logic misinterprets or mishandles mismatched types in generic const expressions. The mutation leverages existing const parameters and replaces their values with expressions from the same program that are numerically valid but semantically incorrect for the expected `bool` type.
