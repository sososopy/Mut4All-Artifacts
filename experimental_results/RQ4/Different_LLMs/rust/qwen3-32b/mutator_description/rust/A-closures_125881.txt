Mutation Operator: Closure Capture Order Alteration  
Target Code Construct: Closures that are returned from const functions and contain captures within a match pattern.  
Applicability: Apply to any closure returned from const functions, particularly when the closure captures variables used in pattern matching or const contexts.  
Mutation Description: Modify the order of variable captures within the closure so that a variable referenced in a match pattern is captured after it is used. This violates the capture type inference sequence and may expose ICEs in closure type checking.  
Example:  
Original code:
```
const fn test() -> impl ~const Fn() {
    let x = 42;
    || {
        match x {
            _ => {},
        }
    }
}
```
Mutated code:
```
const fn test() -> impl ~const Fn() {
    || {
        match x {
            _ => {},
        }
    };
    let x = 42;
}
```
Note: The variable `x` is referenced in the closure before it is declared, which may trigger compiler errors or ICEs during inference of closure capture types.
