Mutation operator: GenericConstArgOutofScopeRef
Target code constructs with const parameters in generic arguments that do not match the current function's parameters. In a function that calls another generic function with const parameters, replace the expression in a generic argument with a reference to a const parameter from a different function in the same module. For example, in a function like:

fn foo<const X: usize>() -> GenericType<{ X + 1 }> { ... }

mutate the generic argument to use a parameter from a different function:

fn bar<const Y: usize>() -> GenericType<{ Y * 2 }> {
    foo::<{ Y + 3 }>()
}

This creates a const expression in a generic argument that references a parameter Y from the bar function where it's not in scope for the foo call. The mutation applies to any function call that uses generic arguments with expressions and has access to const parameters from other functions in the same module.
