Mutation Operator: Replace a pattern matching a generic type with a concrete literal, causing incompatible constructor comparison in pattern analysis.  
Applies to: Enum/struct variants with generic type parameters where a pattern uses a literal of unrelated type.  
Example:  
Original: if let MyEnum<T>::Variant(x) = value { ... }  
Mutated: if let MyEnum<T>::Variant("literal") = value { ... }  
Requirements: Target variants with type parameter T and replace with string/integer literal where T is not a literal type.  
Must use existing types/variables in seed program; no new declarations needed.  
High coverage potential by targeting common generic ADT patterns.
