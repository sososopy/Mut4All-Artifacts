Mutation Operator 1: Replace array size in struct or const with `usize::MAX >> 2` to force oversized array evaluation.  
Applies to: Structs or arrays with fixed-size `[T; N]` where `N` is a constant.  
Example:  
Original struct: `struct Data([u8; 4]);`  
Mutated: `struct Data([u8; usize::MAX >> 2]);`  
Effect: Forces the compiler to evaluate a deeply oversized array size during const checks, potentially triggering const-eval ICEs.  
Use existing `usize::MAX` and apply to any array/struct in the code. No new variables or types are introduced.
