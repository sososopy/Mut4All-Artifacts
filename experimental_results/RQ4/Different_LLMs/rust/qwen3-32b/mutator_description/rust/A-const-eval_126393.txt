Mutation Operator: ExternTypeInStaticInit
Applies to: Struct definitions containing a field of an extern type and static variable initializers.
Modify a struct field type to be an extern type (e.g., `pub struct X(ExternType);`), then create a static variable initialized with an unsafe transmute from a local variable inside an unsafe block (e.g., `pub static NAME: &'static X = unsafe { std::mem::transmute(&{ let x = 42; x }) };`). Ensure the extern type is declared with `extern "C" { pub type ExternType; }` if not already present in the code. This forces const evaluation to process an invalid allocation reference involving extern types.
