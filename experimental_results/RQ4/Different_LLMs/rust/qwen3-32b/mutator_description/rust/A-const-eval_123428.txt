Mutation Operator: Replace field access on an ADT with a field access on a non-ADT by chaining an additional field access to the result of the first access, ensuring the second access targets a primitive type. Apply to any existing field access in the seed program.

Example:
Original:
let x = tuple.0;

Mutated:
let x = tuple.0.0;

This induces a field access (0) on a non-ADT (primitive type) by chaining .0 after accessing a tuple field. The second .0 targets a u8, which is not an ADT, triggering potential compiler errors during field access resolution.
