Mutation operator: Replace a generic const parameter's type with an undefined type in function or item definitions. Apply to any function/const item with a generic const parameter expecting a type (e.g., `usize`), and modify it to use a new undefined type name (e.g., `__NonExistentType`). Example:  
Original: `fn foo<const N: usize>(...)`  
Mutated: `fn foo<const N: __NonExistentType>(...)`  
This creates a type mismatch during predicate collection, potentially triggering ICE in `predicates_of.rs` when resolving const generics. Avoid if the seed program already declares `__NonExistentType`.
