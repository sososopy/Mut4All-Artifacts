Mutation Operator: Reorder struct parameters to place const parameters with default expressions before type parameters  
Applicable to: Structs with both type and const parameters  

Example Mutation:  
Original code:  
struct S<T, const N: usize> {  
    data: [T; N]  
}  

Mutated code:  
struct S<const N: usize = {0 + 1}, T> {  
    data: [T; N]  
}  

This mutation introduces const parameters with default expressions before type parameters in structs. It targets the same code structure as the bug report, which caused the ICE when const parameters with defaults were declared before type parameters. The mutation achieves high coverage by applying to any struct with both parameter kinds and preserves existing variables (T, N, [T; N]) while introducing a default const expression.
