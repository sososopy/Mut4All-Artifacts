Mutation Operator: Replace a type parameter in a struct field or impl with a const parameter from the same struct definition, using it as a type in a context where a type is expected.  

Target Construct: Structs with both generic type and const parameters, and impl blocks referencing those parameters.  

Example:  
Given a struct like `struct S<T, const N: usize> { field: T }`, mutate it to use the const parameter `N` as a type:  
`struct S<T, const N: usize> { field: N }` (invalid, as `N` is a const, not a type).  

Applicability: Seed programs must declare structs with both type and const parameters. If no such struct exists, the mutation operator does not apply.  

Rationale: This misuse of const parameters in type positions exploits compiler logic for substituting generic parameters, potentially exposing ICEs in generic const expression handling, such as the out-of-range type parameter error in the bug report.  

Coverage: Targets interactions between type and const parameters in struct/impl definitions, commonly occurring in generic abstractions with const constraints.
