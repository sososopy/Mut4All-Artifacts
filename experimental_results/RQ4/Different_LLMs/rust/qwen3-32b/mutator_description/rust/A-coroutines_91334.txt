Mutation Operator: Replace a closure's body with a yield expression inside a generator context.  
Target: Closures nested within generator functions (using `yield`).  
Example:  
Before:  
```rust  
fn example() {  
    let _ = || { /* existing valid code */ };  
}  
```  
After:  
```rust  
fn example() {  
    let _ = || { yield (); };  
}  
```  
Notes:  
- Requires the outer function to be a generator (e.g., containing `yield`).  
- Uses existing closure syntax and introduces `yield` without feature gates.  
- Ensures mismatched types or invalid generator nesting to expose ICEs in type-checking.
