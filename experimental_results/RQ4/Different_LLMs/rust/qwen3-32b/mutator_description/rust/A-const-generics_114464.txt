MutationOperator: MO1_GenericConstWithLifetimeRef  
Applies to: const generic function calls where the function has a const parameter of type usize (or similar) and the calling context has a declared lifetime parameter.  
Action: Replace a simple const literal (e.g. N) in a generic function call with a block containing a let-binding of a reference type using an existing lifetime (e.g. let _: &'a ();), followed by a literal of the same type. The block must not include any complex expressions or assignments beyond the reference binding and literal return.  
Example:  
Before:  
fn foo<const X: usize>() {}  
fn bar<'a>() {  
    foo::<42>();  
}  

After:  
fn foo<const X: usize>() {}  
fn bar<'a>() {  
    foo::<{  
        let _: &'a ();  
        42  
    }>();  
}  

Note: The mutation introduces a reference binding inside a const generic argument. This exploits the compiler's handling of lifetime parameters in generic const expressions. If the calling function lacks a lifetime parameter, add one (e.g. fn bar<'a>()) before applying the mutation.
