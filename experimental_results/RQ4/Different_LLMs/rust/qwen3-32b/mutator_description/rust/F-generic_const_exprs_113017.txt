Mutation operator: Replace valid const expressions in generic parameters with invalid closures. This applies to any function, struct, or enum using `const` generic parameters where an expression is expected. For example, mutate a valid expression like `for<const N: usize = 5>` to `for<const N: usize = { || {} }>`. The change introduces a closure in a const context where it is not syntactically or semantically valid, which can trigger ICEs in the compiler's generics processing logic. The mutation leverages existing variables and types by modifying existing const expressions, ensuring no new declarations are required.
