Mutation operator: Add a const generic parameter of unit type with a default value and a where clause referencing the same type with the unit const.  
Applies to structs/enums with at least one const generic parameter.  
Modify:  
Original:  
struct S<const T: Type> { ... }  
Mutated:  
struct S<const T: Type, const C: () = {}> where S<{}>: { ... }  

This targets substitution logic for const generics with unit types and defaults, leveraging the where clause to force compiler evaluation of the substituted const value. The mutation reuses existing struct name and adds minimal new syntax, focusing on the combination of unit const parameters and substitution context that triggered the ICE in the reported bug.
