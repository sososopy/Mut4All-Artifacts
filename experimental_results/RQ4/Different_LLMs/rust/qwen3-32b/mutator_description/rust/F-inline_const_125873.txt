Mutation Operator: Replace a closure inside an inline const block with a closure that includes a `for<'a>` lifetime binder in its signature, ensuring the closure's parameters or return type reference `'a`. If the program does not already enable the `closure_lifetime_binder` feature, prepend `#![feature(closure_lifetime_binder)]` to the crate root. This applies to any existing closure within an inline const context that could be transformed to use a higher-ranked lifetime binder. For example, mutate:  
`const { || ... }`  
to:  
`const { for<'a> |x: &'a T| -> &'a T { ... } }`  
where `T` is a type already in scope. This exposes bugs in region handling during MIR borrow-check due to interactions between inline const, closures, and lifetime binders.
