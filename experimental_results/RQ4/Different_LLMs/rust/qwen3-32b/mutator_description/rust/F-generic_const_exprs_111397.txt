Mutation operator: Replace an associated type's type parameters with const parameters used in const expressions, and apply complex const expressions in their usage.  

Target code construct: Inherent associated types with generic const parameters used in const expressions.  

Example mutation:  
Original code:  
```
impl SomeStruct {
    type Assoc<T> = OtherStruct<{ 2 * 3 }, T>;
}
```
Mutated code:  
```
impl<const C: usize> SomeStruct {
    type Assoc<const I: usize> = OtherStruct<{ C + I }, [(); C + I]>;
}
// Later usage:  
SomeStruct::Assoc::<{ 5 * C }>::new();
```  

This targets substitution logic by combining inherent associated types with nested const expressions that reference both the impl's const parameter and the associated type's const parameter. The mutation ensures const parameters are used in both the impl and associated type definitions, creating potential for substitution errors when const expressions involve multiple parameter levels. Existing types and const expressions are reused in the seed program. New const parameters must be added to the impl and associated type declarations when absent.
