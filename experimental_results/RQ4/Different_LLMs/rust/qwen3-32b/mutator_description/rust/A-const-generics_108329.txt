Mutation Operator: Replace arithmetic operation in const parameter-based index calculations with an operator that could produce an out-of-bounds index.  
Applies to: Assignments where a const generic parameter is used in arithmetic to compute an index or length (e.g., `index = S - 1`).  

Example:  
Original code:  
`self.index = S - 1;`  

Mutated code:  
`self.index = S + 1;`  

This creates an index that exceeds the buffer size (if `S` is the buffer's length), potentially triggering an ICE during const generic evaluation. The mutation uses existing variables (`S`, `self.index`) and introduces no new declarations, relying on seed program structure.
