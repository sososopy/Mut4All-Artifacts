Mutation operator: Replace a type parameter in an associated type's where-clause with a lifetime parameter from the enclosing method's input.
Applies to: Trait or impl methods where an associated type's definition includes a where-clause binding that uses a type parameter instead of a lifetime parameter.

Example mutation:
Original:
type Assoc<T: Clone> = T;
fn method<'a>(&'a self) -> Self::Assoc<T> where T: Default {}

Mutated:
type Assoc<'a: Clone> = T;
fn method<'a>(&'a self) -> Self::Assoc<'a> where 'a: Default {}

This directly targets the invalid use of lifetime parameters in trait bounds for RPITIT collection by forcing the compiler to process a lifetime as a type parameter in an associated type context. The mutation preserves existing type/variable names by using already declared lifetimes in the method signature and replaces type constraint positions with lifetime parameters.
