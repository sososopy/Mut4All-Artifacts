Mutation operator: Insert a `yield` statement in a function that returns an iterator type and introduce a recursive call to the same function within the `yield` chain. This targets the compiler's handling of recursive coroutines with `yield`, which the original bug exploited. Example: transform a non-generator function like  
`fn foo() -> impl Iterator { /* returns iterator without yield */ }`  
into  
`fn foo() -> impl Iterator { yield 42; foo().collect(); }`  
by adding a `yield` and a recursive call that propagates the iterator. This stresses the borrow checker and MIR analysis during type recursion, likely exposing instability in coroutine-related code generation.
