Mutation operator: Undeclared Lifetime in Trait Impl
Target: Any impl block implementing a trait for a type with a lifetime parameter.
Modifications: Replace a declared lifetime parameter in the type's path with an undeclared lifetime. For example, if the original code uses 'a in the type (MyType<'a>), change the impl to use a different lifetime (MyType<'b>) without declaring 'b in the impl's generics.
Example:
Original:
impl MyTrait for MyType<'a> {}

Mutated:
impl MyTrait for MyType<'b> {}

Where 'b is not declared in the impl's generic parameters. This creates a reference to an undeclared lifetime, potentially triggering ICE during coherence checks.
