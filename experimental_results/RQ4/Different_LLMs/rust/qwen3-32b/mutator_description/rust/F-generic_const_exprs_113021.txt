Mutation operator: Replace a structurally simple array or slice pattern in a match or if-let with a nested array pattern involving a generic const expression, leveraging existing const generics in the seed program. For example, in a function parameter of type &[[T; N]; M], mutate match patterns from [] | _ to [[]; _] | _, [[]; K] where K is a const generic from the same scope. This forces the compiler to evaluate nested const expressions in pattern contexts, exposing mismatches between expected/actual const types during MIR construction and borrow checking. Apply this only to functions with const generics already present in their type parameters.
