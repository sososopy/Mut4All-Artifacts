Mutation operator: Replace valid inline assembly instructions with invalid mnemonics in global_asm! blocks. Locate any inline assembly block (e.g., `global_asm!{...}` or `asm!{...}`), select a known valid assembly instruction, and substitute it with a non-existent mnemonic (e.g., change `stp` to `IN_STP`). This triggers unrecognized instruction errors and may expose ICEs during source position tracking if the compiler's error handling for invalid assembly is flawed. Example transformation:  
Original: `asm!("stp x0, x1, [sp, #-16]");`  
Mutated: `asm!("IN_STP x0, x1, [sp, #-16]");`
