Mutation Operator: ReplaceConstGenericDefaultWithIncompatibleType  
Target: Const generic parameters with a default value in a struct, enum, or function declaration where a const item of an unrelated type exists in the same scope.  
Action: Replace the default value of a const generic parameter with a const item of a different type (e.g., using a `u32` const as the default for a `usize` parameter) that is already declared in the same module as the affected type/function.  
Example:  
Original:  
```rust  
struct S<const N: usize = 10> { ... }  
const FOO: u32 = 20;  
```  
Mutated:  
```rust  
struct S<const N: usize = FOO> { ... }  
const FOO: u32 = 20;  
```  
The mutation introduces a type mismatch between the const parameter's declared type (`usize`) and its default value's type (`u32`), potentially triggering substitution errors during trait resolution or well-formed checks. Existing program elements (`FOO`) are reused to avoid introducing new definitions.
