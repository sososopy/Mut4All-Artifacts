Mutation Operator: Introduce lifetime parameter in a const function and use it in a const array context. Apply to const functions with no lifetime parameters. Modify the function to include a lifetime parameter in its signature, add a `where` clause referencing a reference with that lifetime and `Sized`, then use the function as a const parameter in an array declaration within a function that has a corresponding lifetime parameter. Example for a seed function `const fn f() -> usize { ... }` in a function `fn g<'a>() { ... }`:

Original:
const fn f() -> usize { 42 }
fn g() { let _: [u8; f()]; }

Mutated:
const fn f<'a>() -> usize where &'a (): Sized { 42 }
fn g<'a>() {
    let _: [u8; f::<'a>()];
}

This creates a scenario where a const function with a lifetime parameter is used in a const array size, triggering potential ICEs during region inference.
