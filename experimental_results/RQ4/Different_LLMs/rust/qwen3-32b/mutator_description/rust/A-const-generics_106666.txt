Mutation operator: Introduce a struct with a const generic parameter constrained by a trait with a const associated type, implemented with a PhantomData field, and a Clone impl with a where clause enforcing the const-bound array is Sized. Apply to existing structs with at least one type parameter. Example: Take struct T<U> and mutate into struct T<U> { _phantom: PhantomData<U> } that implements Clone where [(); U::N]: Sized.
