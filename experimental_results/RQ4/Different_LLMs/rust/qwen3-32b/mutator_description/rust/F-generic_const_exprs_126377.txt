Mutation operator: Replace a boolean const generic parameter with an integer literal (e.g., 0u8) in a function/trait bound expecting a boolean, using existing integer types from the seed program. Apply to any const parameter where the expected type is bool but an integer literal is syntactically allowed (e.g., {0u8} in the first argument of assert::is_transmutable). This exposes compiler validation issues in generic_const_exprs handling by creating a type mismatch that should trigger an error rather than ICE. The mutation requires that the seed program already contains integer literals or integer-typed variables (e.g., 0u8) available in the same scope, which is common in Rust programs using const expressions.
