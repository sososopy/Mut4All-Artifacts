Mutation operator: Add nested associated type where clauses with shared parameter names to stretch generic argument instantiation.  
Applies to: Functions/trait methods with associated type projections and where clauses.  

Example mutation:  
Original:  
trait Example { type Assoc<T>; }  
fn foo<T, U>(t: T) where T: Example<Assoc<U> = T> { ... }  

Mutated:  
trait Example { type Assoc<T>; }  
fn foo<T, U, V>(t: T) where T: Example<Assoc<U> = T>, T::Assoc<U>: Example<Assoc<V> = T::Assoc<V>> { ... }  

Changes:  
1. Introduces a nested where clause on T::Assoc<U> that itself uses a parameter name (V) already in scope.  
2. Creates a chain of associated type bindings where parameter names from outer scopes are reused in inner scopes.  
3. Maintains all existing function parameters and type parameters from the seed program.  

This forces the compiler to resolve type parameters across multiple layers of projection, increasing the risk of parameter index miscalculations during generic argument folding.
