Mutation operator: Replace a concrete type in an allocator API call with a generic type parameter to trigger type mangling errors during CFI sanitization.  
Applies to: Functions using allocator APIs (e.g., `new_in`) with concrete types as arguments.  
Example: Given a function `f` that allocates a value of type `T` using an allocator, introduce a generic type parameter in the allocation call. For code:  
```rust  
Box::new_in(value, allocator);  
```  
Mutate to:  
```rust  
fn generic<T>(data: &[T], allocator: &A) {  
    Box::new_in(data, allocator);  
}  
```  
This forces the compiler to process `Param(T)` during CFI symbol mangling, exposing ICEs if type parameters are mishandled. Ensure the mutated code reuses existing variables (`value`, `allocator`) and adds a generic function declaration.
