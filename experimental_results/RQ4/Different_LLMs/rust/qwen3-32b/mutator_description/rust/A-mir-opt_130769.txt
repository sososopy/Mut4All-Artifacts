Mutation operator: introduce a cleanup block followed by a non-cleanup edge in match arms  
Applies to: functions with match expressions over Result/Poll variants containing drop statements  
Example:  
Original code:  
match val {  
    Poll::Ready(Ok(Some(_))) => {},  
    ...  
}  

Transform to:  
match val {  
    Poll::Ready(Ok(Some(x))) => {  
        drop(x);  
        return;  
    },  
    ...  
}  

This creates a cleanup block (for the drop) followed by a return (normal edge), mimicking the unwind invariant violation reported in the panic. The mutation reuses existing variables (x) from the match pattern and modifies an existing match arm without introducing new types or functions.
