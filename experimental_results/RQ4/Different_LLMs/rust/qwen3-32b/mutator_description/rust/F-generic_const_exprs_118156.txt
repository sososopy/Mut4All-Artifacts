Mutation Operator: Replace a lifetime parameter in a struct or impl declaration with a reserved lifetime name (e.g., 'static) and enable the generic_const_exprs feature. Apply to struct/impl declarations using custom lifetime parameters.

Example:
Original:
struct Container<'a> { data: &'a [u8; 16] }
impl<'a> Container<'a> { const SIZE: usize = 16; }

Mutated:
struct Container<'static> { data: &'static [u8; 16] }
#![feature(generic_const_exprs)]
impl Container<'a> { const SIZE: usize = 16; }

This creates conflicting lifetime references (reserved name and undeclared 'a) in a context using generic const exprs, triggering ICE in region error handling. Existing struct/impl structure is modified without adding new types/variables.
