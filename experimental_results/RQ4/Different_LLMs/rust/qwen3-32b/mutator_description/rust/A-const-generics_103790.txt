Mutation operator: For a struct definition with at least one generic const parameter, introduce a new generic const parameter with the same identifier as the struct's name. Set its type to the struct's name and provide a default value that references the struct's name or another existing generic parameter. This creates a recursive cycle in type substitution, triggering compiler validation errors or ICE if substitution bounds are improperly handled.

Example pseudo-code for struct S<T> with existing const parameter T:
struct S<const T: usize, const S: S = S::S> { ... } 

This mutation applies to any struct with a const parameter and uses its own name as a type. Default value uses struct name S or references earlier const parameter T, creating a cycle. Existing seed programs with const generics are susceptible to this pattern.
