Mutation Operator: Replace a regular struct initialization with a const block wrapped inline_const expression, targeting struct fields where a static reference or constant evaluation is feasible. Apply to existing struct definitions by modifying their field initializations to use `const { ... }` blocks for at least one field. Example:  
Original code:  
`Field: value`  
Mutated code:  
`Field: const { value }`  

This targets the compiler's handling of inline_const in struct contexts, particularly in scenarios involving type metadata or unsafe transmutes, as seen in the bug report. It stresses the interaction between const evaluation and type layout computation, which are key to triggering the ICE.
