Mutation operator: Add array-length const bound in GAT implementation where clauses.  
Applies to struct type definitions that implement a GAT trait with a const parameter.  
Modify the struct's type implementation by adding a where clause: `where [(); Self::<T as Trait>::N]:` in the GAT type definition, using the const parameter from the trait.  

Example:  
Before:  
`struct MyType<T: Trait> { ... }`  

After:  
`struct MyType<T: Trait> { ... } where [(); <T as Trait>::N]:`  

This stresses the interaction between GATs and generic const expressions by enforcing array-length validation in the type implementation, triggering potential ICEs when the compiler processes these bounds.
