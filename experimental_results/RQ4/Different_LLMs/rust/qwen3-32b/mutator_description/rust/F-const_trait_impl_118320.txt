Mutation operator: Introduce a const closure that calls a method from a trait whose implementation is incomplete (missing the method), within a const context. This applies to code with a trait definition and an impl that omits at least one required method. Modify the impl to remove a method and create a const closure that invokes the missing method on an instance of the impl's type. Example: Given a trait `Trait` with method `fn foo(&self);` and an existing impl `impl Trait for Type`, mutate the impl to `impl Trait for Type {}` (omitting `foo`), then add `const _: () = { const || { Type.foo(); }(); };` to trigger a const closure referencing the missing method. This forces the compiler to process an incomplete trait impl in a const context, exposing ICEs related to missing host effect parameters.
