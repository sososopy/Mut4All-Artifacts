Mutation Operator 1: Inherent Associated Type Reference Without Parameters  
Target: Structs with generic parameters and inherent associated types.  
Action: Replace a valid reference to an inherent associated type (with explicit type arguments) with a reference that omits the required type arguments.  
Example:  
Original: `type A = S<()>::P;`  
Mutated: `type A = S::P;`  
Impact: Forces the compiler to substitute type parameters for an inherent associated type without explicit arguments. This stresses substitution logic when parameterization is missing, potentially exposing ICEs related to out-of-range type parameters.  
Precondition: The struct `S` must be generic (e.g., `S<T>`) and have an inherent associated type `P`. No new variables, types, or functions are introduced.
