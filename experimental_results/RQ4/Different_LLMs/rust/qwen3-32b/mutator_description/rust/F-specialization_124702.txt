Mutation Operator: Trait Impl with Nested Associated Type and From Implementation  
Target: Structs with associated types in trait implementations  
Applies to: Any struct implementing a trait with an associated type, and existing trait implementations for the same or related types  

When a seed program contains a struct and an associated trait, mutate by:  
1. Adding a new trait implementation for the struct with an associated type  
2. Implementing the From trait for a generic type parameterized by the nested associated type  

Example using existing types/structs from seed program:  
Original:  
struct S;  
trait T { type A; }  

Mutated:  
impl T for S { type A = u32; }  
impl<T> From<<S as T>::A> for T {}  

This creates nested type resolution (<<S as T>::A> -> T) that stresses the compiler's specialization/coherence checks. The From implementation uses a generic parameter referencing the associated type, forming a circular dependency pattern that can expose ICEs in type inference. The mutation reuses existing types from the seed program and generates a valid but complex type structure that triggers the same compiler logic as the reported bug.
