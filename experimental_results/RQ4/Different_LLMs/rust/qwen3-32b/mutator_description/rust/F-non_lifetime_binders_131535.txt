Mutation operator: Replace function return type with a trait bound using unbound generic parameter in binder.  
Applies to functions with return type referencing an existing trait or type within the seed program.  
Example:  
Original:  
fn example() -> impl MyTrait { ... }  

Mutated:  
fn example() -> impl MyTrait<UnrelatedGeneric> { ... }  
(where `UnrelatedGeneric` is a type parameter from another definition in the same program, not declared in `example()`'s generics)  

The mutation introduces an unbound generic parameter in a binder position, forcing the compiler to process a poorly scoped binder during well-formedness checking. This exploits the interaction between binder inference and unbound variables in predicate construction, a common source of ICEs in non_lifetime_binders logic.
