Mutation Operator: ReplaceConcreteWithImplTraitInTraitImpl
Applies to: Function parameters in trait implementations where the trait definition does not expect a type parameter for that position.
Change: Replace a concrete type T in a function parameter with `impl Trait`, introducing an implicit type parameter that conflicts with the trait's expected signature.
Example:
Original:
trait Example {
    fn method(a: u32);
}
impl Example for MyStruct {
    fn method(a: u32) {}
}
Mutated:
trait Example {
    fn method(a: u32);
}
impl Example for MyStruct {
    fn method(a: impl Debug) {}
}
Resulting in a type parameter count mismatch during MIR optimization when -Zpolymorphize is enabled.
