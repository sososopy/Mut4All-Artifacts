Mutation operator: Replace a generic const parameter's value with a closure that captures a reference bound by an existing lifetime parameter and evaluates to a const value. Apply to functions or structs with at least one lifetime parameter and one generic const parameter.

Example:
Original:
fn foo<'a, const N: usize>() { ... }

Mutated:
fn foo<'a, const N: usize>() -> [u8; { let _ = |x: &'a u32| x; 4 }]> { ... }

This creates a const array size expression containing a closure capturing a lifetime parameter 'a, triggering binder normalization issues in the compiler. The closure body could be any expression that evaluates to a const value like 4. The u32 type can be any existing scalar type in the seed program.
