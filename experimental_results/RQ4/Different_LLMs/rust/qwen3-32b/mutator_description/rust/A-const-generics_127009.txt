mutation operator: Introduce late-bound const parameter in invalid constant context. Apply to functions with const generics or trait bounds. Add a `for<const C: T>` binder in a `where` clause where the const is used in a constant array size or other fixed-size context that requires a known value at elaboration time. The mutation replaces an existing valid const generic constraint with one that attempts to capture a late-bound const in a position requiring an inlinable constant. This targets the compiler's handling of const parameters in contexts where they cannot be resolved as part of the type-checking process.

example: 
Before mutation:
```
fn foo<const N: usize>()
where
    [(); N]: Default,
{}
```

After mutation:
```
fn foo()
where
    for<const N: usize> [(); N]: Default,
    //~^ ERROR cannot capture late-bound const parameter in constant
{}
```
