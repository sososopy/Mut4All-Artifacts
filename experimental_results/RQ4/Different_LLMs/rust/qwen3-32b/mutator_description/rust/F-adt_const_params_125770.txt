Mutation Operator: ADTConstParamCombination  
Applies to: Structs with const parameters of ADT type and trait implementations using mixed const types.  
Targets code where an Algebraic Data Type (ADT) is used as a const parameter and combined with other const parameter types.  
Example: In a struct like `pub struct Quantity<S, const D: Dimension>(S);` (existing ADT as const parameter), introduce an impl block that mixes this ADT const with another const type (e.g., bool).  
Pseudo-code:  
- For a struct using `const C: Adt` as a const parameter:  
  Add a trait impl such as `impl<const D: Adt, const B: bool, T> Add<T, B> for Quantity<T, D> {}`  
- Ensure the impl block uses multiple const parameters of different types (ADT + integer/bool).  
- Requires existing ADT types. If none exist: declare a new marker struct `pub struct Adt;` as in the example.  
- This creates scenarios where the compiler must unify ADT const parameters with other types, exposing inference errors.  

This operator ensures coverage by leveraging existing ADTs and combining them with standard const types, mirroring the bug’s root cause (mixing `Dimension` with `bool` in the ICE).
