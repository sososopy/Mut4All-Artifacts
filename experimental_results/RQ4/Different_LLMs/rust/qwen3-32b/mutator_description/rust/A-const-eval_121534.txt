Mutation Operator: Replace a binary operation between variables of the same type with an operation between variables of different numeric types (e.g., i32 and u32) by selecting existing variables of differing types in the same scope. This creates an asymmetric binary op that may trigger const-eval ICEs during unsafe arithmetic.

Example:
Original code:
let a = x - y; // x: u32, y: u32
Mutated code:
let a = x - z; // z: i32 (existing variable from same scope)
