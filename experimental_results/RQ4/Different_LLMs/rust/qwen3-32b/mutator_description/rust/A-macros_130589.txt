Mutation operator: Replace a const generic parameter reference in a struct field or generic constraint with a macro invocation that expands to the same parameter, targeting the interaction between macro hygiene andHIR ID generation for const generics.

Applies to: Struct definitions with const generics where a parameter is directly referenced in a field type or generic argument.

Example mutation:
Original:
pub struct S<const V: usize>(Const<{ V }>);

Mutated:
pub struct S<const V: usize>(Const<{ wrap!(V) }>);

Requires existing macro definition:
macro_rules! wrap { ($v:expr) => { $v }; }

Mutation ensures: 
1. Macro is applied to const parameter in a nested generic context
2. Macro expansion produces identical AST to original usage
3. Triggers potential HIR ID resolution issues during const generic processing
4. Maintains valid syntax while testing compiler's handling of macro hygiene in const generic contexts

Does not introduce: New variables, types, or functions beyond existing macro and const parameter
