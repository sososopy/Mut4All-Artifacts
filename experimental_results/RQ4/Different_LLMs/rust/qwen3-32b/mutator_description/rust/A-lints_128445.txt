Mutation Operator: Replace a literal in a context expecting a specific type with a macro that expands to an out-of-range literal, triggering a "literal out of range" diagnostic while ensuring the expanded literal's source is inaccessible to the compiler. This applies to expressions where a type-checked literal (e.g., numeric, char) exists and is subject to linter validations. For example, change a direct literal `100u8` (which is valid) to a macro invocation `out_of_range!()` that expands to `256u8`, causing a range violation. The macro must be defined in such a way that the expanded source location for `256u8` is marked as unavailable (e.g., through macro hygiene or external generation). The mutation does not introduce new types or variables; it reuses the target expression's context (e.g., its type and position in the code). If the seed program already uses macros, the operator can modify the macro's expansion logic to return out-of-range values with invalid source spans.
