Mutation Operator 1: Introduce nested const parameter usage within a generic struct or function. This applies to functions or structs that already have generic const parameters and associated const expressions in their bounds or return types. The mutation adds an additional invocation of a function with a generic const expression that depends on the same or another existing const parameter, creating a layered const expression that references unbound or ambiguous parameters. For example, where a const parameter `M` is used in a function, replace or add a nested call like `substs2::<{ Substs1([0; N + 1]) }>()` that references an undefined or ambiguous const like `N` instead of `M`. This is likely to expose bugs in the handling of const expression scopes and dependencies in the trait solver or type-checking logic.
