Mutation operator: Replace a field in a struct or enum variant with an unsized type (e.g., str, [T;]) in a type that is used in a const context (e.g., passed to size_of/align_of). This creates an unsized type scenario where the compiler's const evaluator might trigger an ICE if it fails to handle the unsized type. Apply by modifying existing struct/enum fields in code that uses size_of/align_of on the type. Example: Change a [u8; 16] field to str in a struct passed to size_of::<T>().
