mutation operator: Replace const parameter in trait bound with arithmetic expression.  
Applies to methods with `where` clauses using const generic parameters from their struct's type parameters.  
Modify the const value in the trait bound to an arithmetic expression of the original const parameter (e.g., `N` → `N + 1`, `N - 1`, or similar).  
Example:  
Original:  
```rust  
fn unsatisfied(self) where T: Bar<N> { ... }  
```  
Mutated:  
```rust  
fn unsatisfied(self) where T: Bar<{N - 1}> { ... }  
```  
This creates a scenario where the trait bound is unsatisfied due to a mismatched const value, potentially exposing ICEs if the compiler fails to report the error correctly.  
Requires existing const parameters in the struct's type. No new variables or types are introduced.
