Mutation operator: Add a `for<const C: usize>` binder in a where clause that references an existing lifetime parameter.  
Applies to functions with at least one lifetime parameter 'a and a type bound T: 'a.  
Replace the where clause with `for<const C: usize> [(); C]: 'a` using existing 'a.  
Example:  
Original:  
fn foo<'a, T: 'a>(_: T) where T: Clone {}  
Mutated:  
fn foo<'a, T: 'a>(_: T) where for<const C: usize> [(); C]: 'a {}
