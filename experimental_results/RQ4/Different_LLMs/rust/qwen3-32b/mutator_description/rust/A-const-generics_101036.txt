Mutation operator: Replace a const generic parameter's default value with an arithmetic expression that references the same enum's variant values, creating a potentially recursive evaluation context. Apply to enums/structs with const generics and explicitly assigned variant values.

Example: Given an enum like `enum E { A = 1, B = 2 }` with a const generic `struct S<const N: u8 = 3>`, mutate to `struct S<const N: u8 = { E::A as u8 + E::B as u8 }>`. This forces evaluation of variant values during const substitution, exposing bugs in recursive/dependency-resolution paths.
