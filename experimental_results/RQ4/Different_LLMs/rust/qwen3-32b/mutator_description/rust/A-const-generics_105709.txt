Mutation Operator: Replace a const parameter's inline const expression with a compound arithmetic operation involving nested inline const expressions, using existing constants or introducing a minimal new const function if necessary.

Applies to: Structs with const parameters that use inline const expressions for default values.

Example:
Original:
pub struct S<const N: usize = { const { 5 } }>;

Mutated:
pub const fn add(a: usize, b: usize) -> usize { a + b }
pub struct S<const N: usize = { const { add(2, 3) } }>;

If no new function is needed:
pub struct S<const N: usize = { const { { const { 2 } } + { const { 3 } } } }>;

Changes required:
1. Add const function declaration if not present (simple arithmetic).
2. Replace simple constant value with arithmetic composition of inline const expressions.
3. Maintain existing type (usize) and struct name.

High coverage across: const generics, inline const blocks, nested expressions, type substitution.
