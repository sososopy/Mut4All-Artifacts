Mutation Operator: ModifyFunctionGenericParamCount  
Target Construct: Function definitions with generic type parameters  
Application Point: Alter the number of generic type parameters in a function's declaration while keeping at least one call site unchanged to retain the original parameter count. This breaks the consistency between the defined and used generic signatures.  

Example Before Mutation:  
```rust  
fn func<T>() {  
    // function body  
}  
fn main() {  
    func::<i32>();  
}  
```  

Example After Mutation:  
```rust  
fn func<T, U>() {  // Added generic parameter 'U'  
    // function body  
}  
fn main() {  
    func::<i32>();  // Still uses one generic argument  
}  
```  

This operator introduces discrepancies where the HIR type-checking phase expects specific parameter counts but encounters mismatches, potentially exposing ICE bugs like the one described. It uses existing functions and their parameters/arguments, fulfilling the "preference to existing elements" requirement.
