mutation operator: Inherent Associated Type with Anon Const Expression in Const Parameter  
Target: References to inherent associated types with const generic parameters where a literal const is used.  
Modifies: Replace a literal const value in the associated type's generic parameter with an anon const expression (e.g., { 10 + 1 }) using existing const values or arithmetic operations.  
Example:  
Original code:  
let a = T::Assoc::<5>::new();  

Mutated code:  
let a = T::Assoc::<{ 5 + 1 - 1 }>::new();  

Ensures the compiler processes anon const expressions in inherent associated type parameters, stressing const evaluation and type resolution paths. Uses existing types (T) and parameters (5) from the seed program.
