Mutation Operator: Add explicit but redundant generic parameters to iterator return types in associated items  
Applies to: Method definitions returning `std::slice::Iter` or `std::slice::IterMut` where the element type is already inferable from the receiver  
Mutation rule: For a method returning `-> std::slice::Iter`, append `<Item = T>` where `T` is the element type of the slice being iterated  
Example: Change `-> std::slice::Iter` to `-> std::slice::Iter<Item = T>` where `T` is the type of elements in the receiver's field array  
Target structure: Redundant explicit generics on iterator return types that force compiler metadata processing  
Coverage scope: Applies to any method returning an iterator over a fixed-size array field or slice that could be type-inferred  
Rationale: Exposes compiler bugs in metadata and associated item handling when explicit generics are added to iterator return types where inference would suffice
