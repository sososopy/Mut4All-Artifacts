Mutation Operator: Replace a const generic subtraction in a where clause with an underflow-inducing form by decrementing the parameter, triggering overflow checks in const evaluation. Apply to any code using generic const expressions with arithmetic in where clauses or similar contexts.

Example: In a where clause using `[(); {N - X}]`, replace `X` with `1` to form `[(); {N - 1}]`. This creates an underflow when `N` evaluates to `0`, causing `0 - 1` in const evaluation. The mutation targets const expressions in where clauses or associated type constraints where the result could overflow.
