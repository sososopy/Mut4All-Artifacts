Mutation operator: Add a const generic in a trait's associated type bound by introducing an associated type with a trait bound that includes a const generic parameter, using an existing trait with a const generic associated type. For example, if a trait `X` has `type Y<const Z: i32>`, mutate a target trait to include `type NewAssoc: X<Y<5i32> = ()>;`. This applies to traits that reference existing const generic associated types in their bounds.
