Mutation Operator: AddAsyncExternVariadicWithLifetimes
Applies to functions with at least one parameter. Replace the function signature with an async function with two named lifetime parameters and a C-variadic parameter, while marking it as unsafe extern "C".

Example:
Original code:
fn f(x: i32) { ... }

Mutated variant:
unsafe extern "C" async fn f<'a, 'b>(x: i32, ...) { ... }
