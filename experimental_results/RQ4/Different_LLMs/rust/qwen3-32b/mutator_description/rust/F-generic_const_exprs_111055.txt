mutation operator: const_generic_param_default_with_const_var
Target a const generic parameter in a struct/enum definition with an explicit default value set to a const variable already declared in the program. Apply to any struct/enum with a const parameter that lacks a default value. Replace the parameter with one that has a default value assigned to a const variable of type usize (must already exist in scope). For example:
Original:
pub struct Writer<'a, W, A, const C: usize>
Mutated:
pub struct Writer<'a, W, A, const C: usize = EXISTING_CONST_USIZE>
Where EXISTING_CONST_USIZE is a const variable of type usize already declared in the same scope. This creates complex substitution scenarios during type checking, exposing ICEs in const parameter resolution.
