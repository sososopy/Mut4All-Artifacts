Mutation Operator: DuplicateConstParamNameInTrait
Applies to trait definitions with at least one const parameter. Replaces the first const parameter with two const parameters of the same name, where the second has a default value referencing the first.

Application points:
1. In trait header with generic parameters
2. Any existing const parameter in a trait declaration

Example transformation:
Original: trait Example<const X: usize> { ... }
Mutated: trait Example<const X: usize, const X: usize = X> { ... }

Applies to:
- Traits with const generics
- Any position of the first const parameter in generic parameter list

Requires no new declarations as it reuses existing parameter name and type from the trait's generic parameter list. The mutation creates a duplicate const parameter with identical name but adds a default value that references the first occurrence.
