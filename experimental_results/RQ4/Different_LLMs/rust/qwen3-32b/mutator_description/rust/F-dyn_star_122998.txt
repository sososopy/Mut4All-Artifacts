Mutation Operator: Replace an existing dyn T with dyn* T in a type annotation (e.g., variable, parameter, or return type) and insert a cast from dyn* T to dyn T in a context like boxed allocation or function argument passing. Applies to programs compiled with -Zsanitizer=cfi -Ccodegen-units=1 -Clto, leveraging existing traits in the seed program. Example: if a variable x is declared as dyn Send, mutate to dyn* Send and cast with Box::new(x) as Box<dyn Send>. This targets trait object unification and codegen phases, exposing ICEs in predicate indexing when dynamic bounds mismatch.
