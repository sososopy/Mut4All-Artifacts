Mutation operator: In macros expanding to code with lifetimes in generic parameters, replace a valid lifetime prefix with an invalid prefix by omitting the colon or using an identifier instead of a lifetime. Apply to macro_rules-generated code where the macro's expansion contains a malformed lifetime prefix in a trait bound. Example: mutate `impl<T'invalid> TraitName<T'invalid> for SomeType` into `impl<T<'a>> TraitName<T<'a>> for SomeType`. This exploits the interaction between macro parsing and edition-specific rules for prefixed lifetimes.
