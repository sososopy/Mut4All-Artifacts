Mutation Operator: Add default const parameter using external const to struct with generic const
Applies to: Struct definitions with const generic parameters and existing const variables in scope
Changes: For a struct with const generic parameter without default, add a default value that references an existing const variable in the same scope (e.g., const N: usize = CONST_NAME), creating complex substitution scenarios

Example:
Before: 
struct MyStruct<T, const N: usize> { ... }

After:
const DEFAULT: usize = 64;
struct MyStruct<T, const N: usize = DEFAULT> { ... }

Requires: 
1. Struct has const generic parameter without default
2. There exists a const variable in the same scope with matching type
3. The struct may have other generic parameters (type/lifetime) that can form complex type relationships
