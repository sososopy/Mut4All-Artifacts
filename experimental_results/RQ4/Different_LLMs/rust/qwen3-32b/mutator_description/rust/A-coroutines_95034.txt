Mutation Operator: AsyncFnReturnGenericAssocFuture  
Target code constructs: Functions with generic parameters constrained by traits having associated types, returning those associated types as futures in async contexts. Applies to trait implementations where the return type is a generic's associated type constrained by a future trait.  

Example mutation:  
Change a function signature from  
`fn handle<T>(f: T) -> impl Future<Output = ()>` to  
`fn handle<T: AsyncTrait>(f: T) -> T::Future` where `AsyncTrait` is a trait defined as  
`trait AsyncTrait { type Future: Future<Output = Self::Output>; fn async_op(&self) -> Self::Future; }`  

The function must be marked async:  
`async fn handle<T: AsyncTrait>(f: T) -> T::Future { f.async_op().await }`  

This introduces nested trait evaluation of associated futures, increasing complexity during Copy/Drop trait evaluation and likely exposing ICEs in type checking logic for async generics with associated types.
