Mutation operator: Swap the order of two consecutive fields in a struct declared with `#[repr(C)]` or equivalent layout attribute, provided the fields have distinct sizes. Apply this to structs that contain enum types with variants of differing sizes. This targets layout validation errors during transmutation checks by altering padding and size assumptions. Example: For struct `A(F1, F2)` where `F1` and `F2` have different sizes, mutate to `A(F2, F1)`.
