Mutation operator: Remove explicit type parameters in function calls, relying on type inference for omitted types when the argument's type is unambiguously constrained by context. This applies to calls with both const and type generic parameters (e.g., `f::<const_value, Type>(arg)` becomes `f::<const_value>(arg)` if `Type` can be inferred from `arg`). 

Example:  
Original: `let _y = blah::<20, Integers >(&_x);`  
Mutated: `let _y = blah::<20>(&_x);` (compiler must infer `T: Debug` from `&Integers`).

Bug exposure rationale: The ICE in #110553 involves missing metadata during type inference. Removing explicit type parameters forces the compiler to compute missing `DefId`/`def_span` information via inference, which could expose flaws in how HIR or type metadata is tracked for inferred generics.
