Mutation Operator: Add a higher-ranked trait bound with a named lifetime in a where clause of a struct or impl.
Applies to structs or impl blocks that use associated types with lifetime parameters.
Replace a simple where clause with "for<'a> T::Assoc<'a>: Bound" where T is an existing type in the program and 'a is a named lifetime used in T's associated type definition. This creates a situation where a universal region must be converted during borrowck, similar to the ICE scenario. The mutation requires that the existing type T has an associated type with a lifetime parameter. Apply mutation to any struct definition that could contain such a constraint using existing types in the program.
