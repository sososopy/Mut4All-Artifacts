Mutation operator: "DynStarCastInsertion"
Applies to functions with parameters of unsized types (e.g., `dyn Trait` or `str`) that have unknown size. In the function body, insert a cast of the parameter to a `dyn* Trait` pointer type. For example, if a function `fn foo(x: dyn Trait)` exists, add `let _: dyn* Trait = x;` after the parameter is introduced. This targets the compiler's handling of conversions between unsized trait objects and raw pointer-like trait objects, exposing ICEs when operand validation fails for pointer values. The mutation reuses existing parameters and trait bounds from the function signature.
