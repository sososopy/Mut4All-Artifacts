Mutation Operator: AddDefaultConstParamWithWhereClause  
Target: Structs or enums with at least one const parameter.  
Description: Introduce a default value for a const parameter using a const item from the same scope, and add a where clause that references the const parameter in a const expression. This exploits incomplete handling of default const parameters during substitution in specialization checks.  

Example:  
Original struct:  
struct S<const N: usize>;  

Mutated struct:  
const DEFAULT: usize = 42;  
struct S<const N: usize = DEFAULT> where [(); {N}]:;  

Application:  
1. Add a const item (e.g., `const DEFAULT: usize = ...`) in the same scope as the struct.  
2. Modify the struct's const parameter to use the default value via `= DEFAULT`.  
3. Add a where clause with a const expression that uses the parameter (e.g., `[(); {N}]` or `[(); N]`).  
4. For existing trait impls for the struct, ensure they use the default parameter (e.g., `impl Tr for S` instead of specifying `N`).  

This mutation targets the interaction between default const parameters, where clauses with const expressions, and trait impls that omit the parameter, creating conditions likely to trigger const param substitution errors in the compiler.
