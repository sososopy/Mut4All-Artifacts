Mutation Operator: InlineAssemblyFunctionReferenceParameter
Target: Functions referenced by inline assembly (e.g., via `sym` in `asm!`) that have a parameter of a concrete type.
Action: Modify one parameter of the referenced function to be a reference to the original type (e.g., change `arg: T` to `arg: &T` or `arg: &mut T`). This creates an indirect call through inline assembly to a function taking a reference, triggering compiler internal types handling.
Example:
Original: `fn f(arg: T)` referenced in `asm!(sym f);`
Mutated: `fn f(arg: &T)` or `fn f(arg: &mut T)` referenced in `asm!(sym f);`
