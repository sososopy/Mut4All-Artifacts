Mutation Operator: Introduce a non_lifetime_binders const binder in a where clause capturing a const generic parameter in a constant context.  
Apply to functions with where clauses that bind lifetimes or types. Replace a lifetime binder with a const binder like `for<const C: usize>` and reference the const parameter in a constant expression (e.g., array bounds). Example:  
Original:  
`fn foo<T>() where for<'a> T: 'a {}`  

Mutated:  
`fn foo<T>() where for<const C: usize> [(); C]: Sized {}`  

This forces the compiler to handle a late-bound const parameter in a constant context under the non_lifetime_binders feature, triggering potential ICEs in THIR body construction.
