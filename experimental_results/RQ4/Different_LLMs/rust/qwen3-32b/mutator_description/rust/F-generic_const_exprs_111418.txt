Mutation Operator: Introduce nested bound lifetime in const generic where clause with local variable of bound type. Apply to functions with generic const parameters that have where clauses. Change a valid const generic where constraint to include for<...> bound that defines a nested lifetime variable, then declare a local variable of a type referencing that nested lifetime within the const expression. Example: Modify a function signature from 'fn example<T>(x: T) where [(); f(): usize] {}' to 'fn example<T>(x: T) where for<'a> [(); { let y: &'a u8; 0 }]: {}'. This creates a situation where a bound lifetime from the where clause is used within the const expression, which may trigger ICEs if the compiler cannot correctly handle escaping bound variables in generic const contexts.
