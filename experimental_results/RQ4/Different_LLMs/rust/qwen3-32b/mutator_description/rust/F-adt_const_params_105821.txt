Mutation operator: Swap the order of two const parameters in an ADT (struct or union) declaration while keeping all references to their names consistent elsewhere in the same scope. Apply this mutation to any ADT with at least two const parameters. Example: Change `struct S<const X: usize, const Y: usize>` to `struct S<const Y: usize, const X: usize>`, but retain all references to `X` and `Y` in field types, where clauses, or other related code in their original order. This stresses the compiler's logic for tracking parameter order in MIR, exposing bugs in ADT const param handling.
