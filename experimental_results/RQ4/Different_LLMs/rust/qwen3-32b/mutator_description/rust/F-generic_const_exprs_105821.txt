Mutation operator: Replace additive expression in array-length-bound generic const parameter with multiplicative expression using same operands.  
Applies to const fns with where clauses using [(); additive_expr] for array length bounds, where additive_expr involves generic const parameters.  
Example: In a const fn with where clause [(); A + B], mutate to [(); A * B]. Targets how compiler evaluates arithmetic operations in generic const bounds.  
Requires existing variables A and B of type usize. Uses no new elements; replaces + with * in bounds. Exposes potential ICE if compiler mishandles multiplicative expressions in const generics.
