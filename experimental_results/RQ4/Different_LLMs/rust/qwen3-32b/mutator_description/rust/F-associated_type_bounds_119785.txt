Mutation operator: Replace a concrete type bound in a const function's generic parameter with an associated type from an unimported trait, using `<Self as Trait>::AssocType` syntax, where `Trait` is not imported and must be declared in the seed program.

Target code construct: Method parameters or return types in const functions that currently use concrete types. Applies when the method is part of a trait or impl block with const trait bounds.

Example mutation:
Change
```rust
fn foo(x: i32) -> i32
```
To
```rust
fn foo(x: <Self as UnknownTrait>::AssocType) -> <Self as UnknownTrait>::AssocType
```
where `UnknownTrait` is a trait already declared in the seed program but not imported into scope.

Coverage benefit: This directly targets the interaction between associated type projection and const trait coherence checks, which is central to the ICE's deadlock in query processing. It requires the presence of const traits and opaque types in the seed program to create overlapping evaluation cycles.
