Mutation operator: generator_yield_return_mismatch
Applies to generator closures (move || { ... }) that return an impl Generator with explicit Yield/Return type parameters. For any yield or return expression in the generator body, replace the expression with a value of a type incompatible with the Generator's declared Yield/Return type. Example: if Generator<Yield = (), Return = ()> uses yield 1; → change to yield 1i32 or return 1; (when Return is ()). Targets type mismatches between generator body and opaque associated type constraints.
