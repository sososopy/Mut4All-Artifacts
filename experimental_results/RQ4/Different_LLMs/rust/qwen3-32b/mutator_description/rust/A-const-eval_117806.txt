Mutation Operator: Introduce a match arm with a constant pattern where the matched value is the same constant. This applies to code with a constant (const or static) used in a match expression evaluating to its own value. The mutation adds an arm where the pattern is the constant's identifier, forcing const evaluation during pattern matching.

Example (pseudo-code):
Original:
const C: T = ...;
fn f() { match C { ... } }

Mutated:
const C: T = ...;
fn f() { match C {
    C => {},
    // existing arms
} }

This leverages existing constants and match expressions. It applies to all constants of any type where the matched value is the constant itself. The ICE occurs when const evaluation of the pattern unexpectedly involves a scalar pair instead of a scalar.
