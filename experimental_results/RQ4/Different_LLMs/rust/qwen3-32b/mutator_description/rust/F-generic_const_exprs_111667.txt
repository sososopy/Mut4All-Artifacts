Mutation Operator: ArraySizeConstExprArithmeticMutation  
Applies to array size expressions using generic const parameters in `const N: usize` contexts. Target any array declaration where size is a binary operation (e.g., `N * N`, `N + 1`). Replace the binary operator with an alternative operator that preserves type validity but changes expression semantics (e.g., replace `*` with `+`, `/` with `%`).  

Example:  
Original: `[(&'a T, &'a U); N * N]`  
Mutated: `[(&'a T, &'a U); N + N]`  

This targets the compiler's handling of const expressions in array size calculations. The mutation ensures the expression remains a valid `usize` but creates a mismatch between expected and actual size logic.  

Mutation Operator: GenericArrayIndexExprMutation  
Applies to array indexing operations within generic-const contexts. Target expressions like `i / N` or `i % N` in `array::from_fn`. Replace the operator or operand in the index calculation (e.g., `i / N` → `i % N`, `i % N` → `i / N`).  

Example:  
Original: `|i| (&self[i / N], &us[i % N])`  
Mutated: `|i| (&self[i % N], &us[i / N])`  

This exposes bugs in how the compiler validates const expressions for array index bounds during generic evaluation.  

Mutation Operator: GenericArrayNestedSizeInferenceMutation  
Applies to nested array declarations with generic const expressions. Replace a nested array's size expression with a syntactically valid but semantically conflicting const expression (e.g., `N` → `N + 1`, `N` → `N * 2`).  

Example:  
Original: `[(&'a T, &'a U); N * N]`  
Mutated: `[(&'a T, &'a U); N]`  

This stresses the compiler's ability to correctly infer and validate nested array sizes in generic contexts.
