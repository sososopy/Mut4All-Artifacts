Mutation Operator: Replace a valid macro statement argument with an invalid statement that mimics a non-existent syntax expecting a non-terminal parse error.  
Applies to: Macro invocations with a parameter defined as NtStmt in the macro rules.  

Example:  
Original code:  
```rust  
macro_rules! m { ($s:stmt) => {} }  
m! { let x = 5; }  
```  

Mutated code:  
```rust  
macro_rules! m { ($s:stmt) => {} }  
m! { var x = 5; }  
```  

Explanation: The mutation introduces an invalid statement syntax "var x = 5;" where a valid Rust statement (like "let x = 5;") was previously used. This forces the parser to handle an unexpected token sequence in the NtStmt context, potentially exposing missing error handling paths that lead to ICEs. The change targets the interaction between macro parsing and the non-terminal grammar rules for statements, leveraging existing macro definitions without introducing new variables or types. When applied, this mutation requires that the seed program already contains a macro invocation with a $:stmt parameter.
