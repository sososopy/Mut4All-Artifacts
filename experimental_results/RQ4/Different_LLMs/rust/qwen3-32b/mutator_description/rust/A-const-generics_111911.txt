Mutation operator: AddAsyncConstGenericRefParam  
Applies to functions that are not already async. Modify the function signature by:  
1. Adding a const generic parameter with a type that is a reference (e.g., `const _: &'static str`).  
2. Prefixing the function with `async`.  
3. Changing the return type to `impl Future<Output = ()>`.  
Example transformation:  
Before: `fn example() {}`  
After: `async fn example<const _: &'static str>() -> impl Future<Output = ()> { ... }`  

Mutation operator: InjectConstGenericLifetimeInImplTrait  
Applies to functions or closures returning `impl Trait` where a const generic is not yet present. Modify the return type by:  
1. Adding a const generic parameter bound to a reference with a declared lifetime (e.g., `const _: &'a str` where `'a` is a named lifetime in the signature).  
2. Ensuring the `impl Trait` return type is bounded by a trait that requires lifetime inference (e.g., `Future` or `Iterator`).  
Example transformation:  
Before: `fn example() -> impl Iterator<Item = u8> { vec![1].into_iter() }`  
After: `fn example<'a, const _: &'a str>() -> impl Iterator<Item = u8> + 'a { vec![1].into_iter() }`  

Mutation operator: ReplaceTypeParamWithConstRefParam  
Applies to generic functions using type parameters that are references (e.g., `T: ?Sized + 'static`). Modify by:  
1. Replacing the type parameter with a const parameter of reference type (e.g., replace `T` with `const _: &'static str`).  
2. Where applicable, annotate the const parameter with a `#[cfg(...)]` condition to avoid runtime usage.  
Example transformation:  
Before: `fn example<T>(_: T) where T: ?Sized { ... }`  
After: `fn example<const _: &'static str>() { ... }`
