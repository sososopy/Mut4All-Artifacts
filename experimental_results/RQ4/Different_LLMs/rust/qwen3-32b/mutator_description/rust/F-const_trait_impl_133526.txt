Mutation Operator: CONST_TRAIT_ASSOC_BOUND_REMOVAL  
Target construct: A `#[const_trait]` trait with an associated type that has a `const` bound.  
Applies to: Traits using `const` in their definition and associated type bounds.  
Change: Remove the `const` keyword from the associated type's trait bound.  
Example:  
Original:  
```
#[const_trait]  
trait Trait {  
    type Assoc: const Trait;  
}  
```  
Mutated:  
```
#[const_trait]  
trait Trait {  
    type Assoc: Trait;  
}  
```  
This exposes potential mismatches in how `const` bounds are treated during implied bounds computation, aligning with the ICE in the bug report.
