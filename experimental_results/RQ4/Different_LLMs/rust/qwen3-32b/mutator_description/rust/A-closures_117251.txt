Mutation Operator: Closure returns mutable reference to collection element, causing borrow conflict  
Applies to: Closures that capture a mutable reference to a collection (e.g. Vec, HashMap)  
Changes: Modify closure body to return a reference to an element within the captured collection  
Example:  
Before:  
|vec| vec.pop()  

After:  
|vec| &vec[0]  

This forces the closure to return a reference to an element of the captured mutable collection, creating a potential borrow conflict. The compiler must track that the returned reference's lifetime originates from the mutable borrow, which can expose bugs in borrowck's handling of closure return types and lifetimes. The mutation uses existing variables/structure from the seed program (the collection parameter and its elements) without introducing new types or variables.
