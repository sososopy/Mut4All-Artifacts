Mutation operator: Replace bounded iterator bounds with infinite loops in nested impl Trait return types. Apply to methods returning nested impl Trait types where the innermost iterator's item contains a const parameter. Replace (0..1) with loop {} in innermost iterators. Example: (0..1).map(move |_| (0..1).map(...)) becomes (loop {}).map(move |_| (loop {}).map(...)) while preserving the const parameter usage in array sizes.
