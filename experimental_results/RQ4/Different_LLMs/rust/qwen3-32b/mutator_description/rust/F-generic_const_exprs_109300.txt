Mutation operator: Replace an associated type's type argument with a const expression in a function or method signature. Target code constructs where an associated type with type parameters is used in a generic context, and mutate by substituting one of the type arguments with a numeric literal (e.g., replace `<T>` with `<42>`) in an existing associated type reference. The seed program must already have a trait with an associated type parameterized by types (e.g., `trait X { type Y<T>; }`), and the mutation applies to any function/bound that uses this associated type with concrete parameters. Example: change `fn f<T: X<Y<i32> = ()>>() {}` to `fn f<T: X<Y<42> = ()>>() {}`. No new elements are introduced—only arguments are modified from types to const expressions.
