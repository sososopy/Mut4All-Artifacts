mutation operator: Replace a struct field or const item of a sized type with an unsized type (e.g., trait object or function pointer) where it would require layout computation during const-eval. Apply to any struct field or const declaration in the code. For example, change `struct X(u8);` to `struct X(Fn)` where `Fn` is a trait type alias like `type Fn = FnOnce();`. This forces const-eval to handle unsized types in contexts requiring sizedness, triggering layout assertion failures.
