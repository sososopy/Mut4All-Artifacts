Mutation operator: Swap the position of a generic parameter with a default and a preceding non-default generic parameter in a struct, enum, or function definition. This applies to any mixed generic parameter list where a default parameter is not last (e.g., `struct S<T, const U: usize = 42>` → `struct S<const U: usize = 42, T>`). The mutation ensures default parameters (const, type, or lifetime) are not trailing, violating the compiler's expectation and exposing ICE during well-formedness checks. No new elements are added; the operator works by reordering existing parameters, ensuring the default parameter is not the last in the list.
