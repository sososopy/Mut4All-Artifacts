Mutation operator: A-patterns-ice
Target construct: Struct definition with tuple fields and pattern matching in assignments
Application: Modify a struct to have a tuple field ((), ()) and add a method with a pattern (Self, var) = (Struct, ());

Example:
Original struct:
struct S;

Mutated struct:
struct S((), ());

impl S {
    fn check() {
        let a;
        (Self, a) = (S, ());
    }
}
