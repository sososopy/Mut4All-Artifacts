Mutation Operator: Add a `const` parameter to an ADT (struct or enum) with a type that is generic over the ADT's existing generic parameters. Apply this to ADTs with at least one lifetime or type parameter, introducing a `PhantomData`-based const parameter that depends on those parameters. Example:  
```rust  
struct Example<'a> { /* ... */ }  
// becomes  
struct Example<'a, const C: std::marker::PhantomData<&'a ()>> { /* ... */ }  
```  
This exploits the compiler's inability to handle const parameters referencing generic lifetimes or types, exposing bugs in type-checking logic.
