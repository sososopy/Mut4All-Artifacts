mutation operator: ReplaceConstWithLiteralInGenericArg
applies to: struct implementing a trait with a const generic parameter where the argument is a const variable
action: replace the const variable with a numeric literal of the same value
example:
before: impl<const N: usize> MyTrait<{ N }> for MyStruct
after: impl MyTrait<{ 42 }> for MyStruct

mutation operator: ReplaceLiteralWithConstInGenericArg
applies to: struct implementing a trait with a const generic parameter where the argument is a numeric literal
action: replace the numeric literal with a const variable having the same value
precondition: const variable with matching value exists in scope
example:
before: impl MyTrait<{ 42 }> for MyStruct
after: impl<const N: usize> MyTrait<{ N }> for MyStruct 
requires: const N: usize = 42; is already declared in program

mutation operator: NormalizeConstExprInTraitImpl
applies to: trait impl with const parameter using either variable or literal
action: if using variable, replace with literal value; if using literal, replace with equivalent const variable
example:
before using N: impl Print<N> for Printer; 
after using 4: impl Print<4> for Printer;
before using 42: impl MyTrait<{ 42 }> for Foo; 
after using N: impl<{ const N: usize = 42 }> MyTrait<{ N }> for Foo;
