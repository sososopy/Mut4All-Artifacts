Mutation Operator: Replace a closure or generator in a generic const expression with an async block, creating a type mismatch. Apply to const expressions where a closure/generator is expected (e.g., array lengths with `&[(); { ... }]`). Use existing variables/types in the seed program's scope to declare the async block. Example:  
Original:  
`&[(); { let f: F = || {}; 1 }]`  
Mutated:  
`&[(); { let f: F = async { 1 }; 1 }]`  

This targets the compiler's type-checking of const expressions with async closures, which are not valid closures/generators, exposing errors in handling their type inference.
