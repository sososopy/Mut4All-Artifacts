mutation operator: IncreaseConstArraySizeWithBitshift
This operator targets existing const declarations that use array types. It modifies the array size expression to a large value using a bitwise right shift operation on a size constant. The change follows the pattern: replace array size expressions with "usize::MAX >> 16" when possible.

Application example:
Original code:
struct Example([T; N]);
const X: Example = Example([value; N]);

Mutated code:
struct Example([T; N]);
const X: Example = Example([value; usize::MAX >> 16]);

The operator applies to:
1. Any const declaration with an array initializer
2. Where the array type already exists in the program
3. When the array size is a simple literal or basic expression

The mutation stresses the compiler's const evaluation system by creating a huge array allocation request during compilation. This pattern was shown in the bug report to trigger the ICE in the const evaluator.
