Mutation operator: Change a non-async trait method to async, introduce a new lifetime parameter in the trait, and define the method's receiver with a distinct lifetime while returning a reference tied to the trait's lifetime.

Example pseudo-code before mutation:
trait T {
    fn f(self);
}

Example after mutation:
trait T<'a> {
    async fn f<'b>(self: &'b Self) -> &'a ();
}

This creates a scenario where the async function's return type is a reference with a trait-bound lifetime, which could expose ICEs in async coroutine type inference. The mutation leverages existing trait and method structures, adding minimal new elements (lifetime parameters) to existing constructs. The receiver uses a separate lifetime parameter to ensure the async function's closure signature contains both lifetimes, increasing the likelihood of triggering unexpected type inference interactions.
