Mutation operator: TuplePatternOnNonTupleAssignment  
Applies to assignments where a non-tuple expression (e.g., scalar value or struct field) is matched against a tuple pattern. Replace an existing assignment (e.g., `let x = value;`) with a tuple pattern destructuring on the same value (e.g., `let (_, y) = value;`).  

Example:  
Original:  
```rust  
let name = user.name;  
```  
Mutated:  
```rust  
let (_, name_part) = user.name;  
```  

This creates a pattern mismatch that may trigger pattern analysis bugs when the compiler expects the target to be a tuple-like type. The mutation uses existing variables (`user`, `name`) and introduces a new pattern variable (`name_part`) bound to the right-hand side of the original assignment.
