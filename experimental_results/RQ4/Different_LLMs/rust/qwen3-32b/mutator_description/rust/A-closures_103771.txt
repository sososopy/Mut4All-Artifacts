Mutation Operator: Nested Closure Lifetime Capture
Applies to: Nested closures where inner closure captures lifetime from outer closure's binder
Action: Replace a closure body with another closure that uses a lifetime parameter from outer scope in its signature

Example:
Original:
|| {
    let _ = &value;
}

Mutated:
|| {
    for<'x> |_: &'x ()| -> () {
    }
}

Changes:
1. Locates an existing closure body that captures references
2. Replaces body with a new closure that:
   - Uses a binder 'x in its signature
   - Takes a reference with captured outer lifetime 'x
   - Must reuse an existing lifetime parameter from outer closure if present
   - If no existing lifetime, introduces 'x as new binder in outer closure

Targets compiler's handling of nested binders and lifetime propagation between closures.
