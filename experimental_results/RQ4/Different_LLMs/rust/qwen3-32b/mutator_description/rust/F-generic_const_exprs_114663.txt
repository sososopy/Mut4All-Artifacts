Mutation Operator: Replace a sized type in a generic const `size_of` expression with an unsized type like `dyn Trait`.  
Target: A generic type parameter used in a const context where `core::mem::size_of::<T>()` is applied.  

Example:  
Original code:  
```rust  
struct S<T> where [u8; core::mem::size_of::<T>() + 1]: {}  
let x = S::<u32>::new();  
```  

Mutated code:  
```rust  
struct S<T> where [u8; core::mem::size_of::<T>() + 1]: {}  
let x = S::<dyn Debug>::new();  
```  

Effect:  
Replaces the generic type argument `u32` (sized) with `dyn Debug` (unsized) in the const expression `size_of::<T>()`. This triggers an ICE if the compiler fails to validate the unsized `T` in the `size_of` context.  

Coverage:  
Applies to generic structs/functions using `size_of` in const array lengths, const parameters, or type bounds, ensuring mutations expose unsized-type handling bugs.
