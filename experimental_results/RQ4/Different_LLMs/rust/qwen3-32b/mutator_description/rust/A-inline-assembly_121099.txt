Mutation Operator: Replace a valid constant expression in a `global_asm!` macro with an invalid operation that causes a compile-time error, such as division by zero or referencing a non-const value. Applies to `global_asm!` with `const` operands.

Example: Change `global_asm!("...", const valid_expr)` to `global_asm!("...", const 1 / 0)` or `global_asm!("...", const undefined_value)`.
