mutation operator: Add nested impl Iterator with generic const array in return type for an impl block  
Applies to: impl blocks without const generics  
Action: Introduce a const generic parameter to the impl block. Modify a method in the impl to return a nested impl Iterator structure containing an array with the const generic parameter. Add lifetime parameters to the method signature that are used in the return type.  

Example transformation:  
Original code:  
```rust  
struct S;  
impl S {  
    fn m() -> Vec<i32> { todo!() }  
}  
```  
Mutated code:  
```rust  
struct S;  
impl<const Z: usize> S {  
    fn m<'a, U: 'a>(&'a self) -> impl Iterator<Item = impl Iterator<Item = [u8; Z]> + '_> { todo!() }  
}  
```  
Note: Requires the generic_const_exprs feature to be enabled. If the seed program lacks a suitable struct, declare a minimal struct. Ensure the const parameter is used in at least one array size expression within the nested opaque types.
