Mutation operator: Add a const generic parameter with a type that is a generic struct or lifetime parameter from the program. Apply to struct/enum definitions with existing type/lifetime parameters.

Example mutation (pseudo-code):
Original:
struct Example<T>;
struct Foo<'a, T> { ... }

Mutated:
struct Example<T, const C: Foo<'static, T>> { ... }

This introduces a const parameter where the type is a generic struct (Foo) already present in the code. The mutation uses existing type/lifetime parameters from the target struct and references another existing generic type from the same program. The compiler must detect that const parameter types cannot be generic, triggering either a proper error or an ICE if the bug is present.
