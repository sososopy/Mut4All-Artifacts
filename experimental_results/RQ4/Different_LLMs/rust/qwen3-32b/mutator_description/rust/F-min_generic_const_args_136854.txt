Mutation Operator: ReplaceConstArgWithFunctionName
Applies to const generic arguments in array sizes, struct instantiations, or type parameters where a valid const expression is used. Targets cases where a function name is substituted as the const value instead of a literal or const variable.
Action: In any const generic parameter (e.g., [(); 5] or Struct<{5}>), replace the existing expression with the name of an existing function (without parentheses) declared in the same program. The function must have a return type that would semantically act as a numeric or array size value if called.
Example: Change [(); 5] into [(); F] where F is a named function present in the program. This forces the compiler to interpret the function as a const value, potentially exposing errors in const evaluation handling.
Requirements: The seed program must already contain at least one function (not a const) that could logically return a numeric or size-compatible value. The mutation uses only existing functions, avoiding new declarations.
