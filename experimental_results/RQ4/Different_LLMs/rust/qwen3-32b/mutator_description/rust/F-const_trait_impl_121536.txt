Mutation operator: Add a const effect parameter to a const trait function. Applies to const functions in trait implementations that do not already use the effects feature. Modify the function signature by adding a const parameter with a host effect marker, even if it is unused in the function body. For example, transform:  
`const fn add(self, b: T) -> Self::Output { ... }`  
into:  
`const fn add(self, b: T, const _: ()) -> Self::Output { ... }`  
This targets the interaction between const functions and the effects system by introducing a parameter that the compiler must validate for host effect parameters in const contexts. Existing structs and traits in the program can be used directly, with the mutation applied to any const function in an impl block.
