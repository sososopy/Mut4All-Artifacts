Mutation operator: EnumConstDefaultArithmeticExpr  
Target code construct: Enum definitions with const generics that have default values.  
Applies to: Enums with at least two variants having explicit discriminant values.  
Mutation: Replace the default value of a const generic parameter with an arithmetic expression combining the discriminant values of two variants.  
Example:  
Original:  
enum T<const N: u8 = 0> { A = 1, B }  

Mutated:  
enum T<const N: u8 = { T::<0>::A as u8 + T::<0>::B as u8 }> { A = 1, B }  

This forces evaluation of const expressions during substitution and may trigger ICEs in generic const expression handling.
