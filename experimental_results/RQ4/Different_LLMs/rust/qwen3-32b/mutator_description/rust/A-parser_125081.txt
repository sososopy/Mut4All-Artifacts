Mutation Operator 1: Generic Argument Count Mismatch + Incompatible Literal
Target: `let` statements with type annotations using generic structs that have fixed parameter counts.
Apply when: The declared type has exactly N generic parameters, and the assigned value is a literal of type T.
Mutation: 
1. Append a dummy generic argument after the last valid one (e.g., `Cell<T>` → `Cell<T, X>`)
2. Replace the assigned literal with a type-incompatible literal (e.g., `&str` literal → `char` literal)
3. Ensure the new generic argument and literal type create conflicting type expectations

Example:
Before: 
`let x: Vec<i32> = vec![1, 2, 3];`
After:
`let x: Vec<i32, u8> = vec!['β'];`

Note: This creates a double generic argument for Vec (which only takes one) and uses a char where a slice of i32 is expected, mimicking the original ICE scenario. The mutation leverages existing type (Vec) and literal forms already present in the program.
