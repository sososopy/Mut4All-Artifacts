Mutation Operator: In a function body, replace a simple variable initialization statement with a const block that evaluates an intrinsic function using the same type as the variable.  
Example: Replace `let x = T;` with `const { core::ptr::read::<T>() };` where T is the original type of x. This creates a shim from an intrinsic in the const context, potentially triggering the ICE. The mutation reuses existing types from the seed program and applies to any function with variable declarations.
