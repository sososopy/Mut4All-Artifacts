Mutation Operator: ReplaceNamedFieldWithUnnamed
Applies to struct definitions with at least one named field. Replace a named field with an underscore `_` while preserving its type. The mutation applies to any field in any struct with named fields, using the existing type from the field's original declaration.

Example:
Original:
struct Foo {
    x: i32,
    y: String
}

Mutated:
struct Foo {
    _: i32,
    y: String
}

Or:
struct Foo {
    x: i32,
    _: String
}

This mutation operator targets the same compiler path as the original ICE by introducing an unnamed field in a struct, which interacts with the pretty-printer's AST handling. The operator requires no new type declarations and operates on existing struct fields.
