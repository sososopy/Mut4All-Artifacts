Mutation Operator: Replace iterator item type with unsized DST in function signature.
Applies to functions using `&mut impl Iterator<Item = &T>` where T is a concrete type.
Change to `&mut impl Iterator<Item = T>` where T is a DST (e.g. str, [u8]).
Example:
Before: fn process(items: &mut impl Iterator<Item = &T>) { ... }
After: fn process(items: &mut impl Iterator<Item = T>) { ... }
Only modifies the generic parameter in the function signature, keeps existing iterator usage patterns.
Preserves variable names and function structure, changes only the trait bound.
Applies to any existing iterator-based functions where the item type is a reference to a concrete type.
