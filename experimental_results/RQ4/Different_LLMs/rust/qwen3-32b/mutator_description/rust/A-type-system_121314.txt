mutation operator: Introduce a second generic type parameter with the same type constraints as an existing parameter, and use both in a type comparison context. Apply to any function with at least one generic type parameter. For example, transform:

fn original<T>() { ... }

into:

fn mutated<T, U>() where U: PartialEq<T> { let a: T = ...; let b: U = ...; a == b; }

This forces the compiler to track type parameters with potentially identical constraints but distinct names, exposing bugs in index/name resolution during type comparison operations.

mutation operator: Add a generic type parameter that shadows another in nested scopes and use both in a type assertion. Apply to functions with generic parameters and nested item declarations. Example:

fn original<T>() { ... }

becomes:

fn mutated<T>() { struct Inner<T, U> where U: PartialEq<T> { x: T, y: U }; assert!(Inner::<T, T> { x: ..., y: ... }); }

This creates two distinct T type parameters in different scopes, requiring the compiler to distinguish their indices during typechecking.
