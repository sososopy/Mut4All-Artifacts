mutation operator: Replace constant value in generic parameter with arithmetic expression involving existing const parameter and inferred type.  
Applies to methods returning a generic type with a const parameter where the const value is computed from a struct's const parameter.  

Example mutation:  
Original line:  
struct S<const N: usize>;  

impl<const N: usize> S<N> {  
    fn new() -> S<5> { S }  
}  

Mutated to:  
struct S<const N: usize>;  

impl<const N: usize> S<N> {  
    fn new() -> S<{ N + 1 }> { S }  
}  

Then in function calls, replace explicit const values with underscore inference:  
Original call: S::<3>.new();  
Mutated call: S::<0>.new::<_>();  

This creates nested const expressions requiring inference that may trigger ICEs in type-checking phases when the compiler fails to propagate const evaluation errors. The mutation leverages existing struct const parameters and adds arithmetic expressions in return type positions, stressing const generic evaluation with inference markers.
