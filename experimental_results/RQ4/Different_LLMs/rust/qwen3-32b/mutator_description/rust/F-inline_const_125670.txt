Mutation operator: Replace a return statement with a `const` block containing a nested block that has an early `return`, specifically modifying the structure to `return const { { return; } }` inside any function body. This targets nested scope interactions within inline constants during MIR construction, increasing the likelihood of index-related failures in scope management. Example: a function `fn foo() -> _ { return const { ... } }` would be mutated to `fn foo() -> _ { return const { { return; } } }` without altering the outer return's visibility or type.
