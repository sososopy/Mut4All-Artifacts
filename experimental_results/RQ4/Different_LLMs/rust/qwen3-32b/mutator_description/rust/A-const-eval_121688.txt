Mutation Operator: Add Higher-Rank Trait Bound (HRTB) to Function Pointer Comparison in Const Function
Applies to const functions that compare function pointers with differing lifetime binders. Targets comparisons between function pointers with and without higher-rank trait bounds (e.g., `fn()` vs `for<'a> fn()`). Replaces one or both function pointer parameters with HRTB versions and forces comparison in const context.

Example:
Original: 
`const fn cmp(x: fn(), y: fn()) -> bool { unsafe { x == y } }`

Mutated:
`const fn cmp(x: fn(), y: for<'a> fn()) -> bool { unsafe { x == y } }`

Changes:
1. Add `for<'a>` binder to second parameter's function pointer type
2. Maintain `const fn` context for const evaluation
3. Retain `unsafe` block to allow pointer comparison
4. Ensure function parameters exist in seed program (use existing function names/types if available)

Note: Focuses on mismatched Binder structures during const evaluation, exposing ICE when comparing function types with different lifetime binders.
