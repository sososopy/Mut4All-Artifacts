Mutation Operator: Replace const parameter type with an associated type from a trait implemented for the parameter type. Apply to functions with const parameters where the type can be expressed via a trait's associated type, specifically targeting ADT const param handling in the compiler's const conversion logic. The mutation replaces X: T with X: <T as Trait>::AssocType where Trait defines type AssocType = T and T is a type parameter or concrete type.

Example mutation:
Original:
pub fn bar<const X: i32>() { ... }

Mutated:
pub fn bar<const X: <<T as Trait>::AssocType as Trait2>::AssocType>() { ... } 
// where T is a type parameter of bar and Trait/Trait2 include AssocType = i32

Precondition: The seed program must contain at least one trait with an associated type that evaluates to the original const parameter type (i32 in the example). The mutation reuses existing traits/types in the program. If no such trait exists, declare a minimal trait with an associated type matching the parameter type: 
trait Helper { type Assoc; } 
impl<T> Helper for T { type Assoc = T; }

This mutation stresses the compiler's const parameter normalization logic by chaining associated types through multiple trait references. The increased indirection raises the likelihood of encountering incomplete ADT const param handling in the compiler's type system.
