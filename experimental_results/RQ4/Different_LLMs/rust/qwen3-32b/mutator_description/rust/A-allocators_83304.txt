Mutation operator: Replace an allocator API function argument that expects an owned allocator with a reference to an existing allocator instance. Apply to any function call where an allocator is passed by value, using the address-of operator to create a reference.

Example (pseudo-code):
Before: Box::new_in(value, allocator)
After:  Box::new_in(value, &allocator)

This targets allocator API usage patterns where references are passed to compiler internals expecting owned values, exposing bugs in type layout and LLVM code generation for allocator arguments. The mutation requires an existing allocator variable in scope but does not introduce new variables or types.
