Mutation Operator: Add a method to a struct with const generics that returns a new struct instance using a modified const expression, then chain method calls with inferred generics.  
Target: Structs or enums with const generic parameters (e.g., `struct S<const N: usize>`).  
Apply when: The struct has a method that returns a new instance with a const expression (e.g., `N + 1`).  
Example:  
Original code:  
`struct S<const N: usize>;`  

Mutated code:  
```rust  
impl<const N: usize> S<N> {  
    fn increment(self) -> S<{ N + 1 }> {  
        S  
    }  
}  

pub fn test() {  
    S::<0>.increment::<_>().increment::<_>();  
}  
```  
Changes:  
1. Add a method `increment` to the struct that returns a new instance with a const expression (`N + 1`).  
2. Modify the usage of the struct to chain two `increment` method calls with inferred generics (`::<_>`).  
This mutation stresses the compiler’s handling of nested const expressions in method chaining, similar to the ICE-triggering pattern in the bug report.
