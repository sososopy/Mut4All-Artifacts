Mutation operator: NestedConstADTInsertion  
Applies to: const parameters in struct/enum instantiations that use ADT expressions  
Modifies: Replaces a simple const expression with a nested ADT value constructed from existing structs in the seed program  
Example:  
Original:  
struct Test<const F: Foo>;  
...  
Test<{ Foo { value: 3, nested: &Bar(4) } }>  

Mutated:  
struct Test<const F: Foo>;  
...  
Test<{ Foo { value: 3, nested: &Bar(Baz { ... }) } }>  
(where Baz is another existing struct with fields that can be instantiated using values from the original Foo)  

Trigger mechanism: Forces compiler to evaluate const parameters containing deeply nested ADTs with associated type markers (e.g., references to generic parameters) that require layout validation. The mutation creates complex type hierarchies in const parameters that stress the interaction between ADT layout computation and const param validation.  

Coverage pattern: Applies to any struct/enum with a const generic parameter that:  
1. Uses an ADT as the parameter value  
2. Contains nested ADTs within the parameter value  
3. References generic parameters or markers (e.g., std::fmt::Debug) in the nested structure
