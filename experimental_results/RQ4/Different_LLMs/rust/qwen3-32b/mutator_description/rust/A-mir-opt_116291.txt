Mutation Operator: InlineClosureRecursion
Target: Functions containing a closure without captures or recursion.
Action: Modify the closure to capture a variable from the outer scope and call itself recursively. Replace the closure's body with a recursive call using the captured variable.
Example:
Original:
fn main() {
    let func = || 123u8;
    func();
}

Mutated:
fn main() {
    let data = 0u8;
    let func = |&mut| {
        if data < 1 {
            func(data)
        } else {
            123u8
        }
    };
    func(&mut data);
}

Note: The closure now captures 'data' by reference and recursively calls itself. This creates a cyclic call graph with captured values, exercising MIR inliner's cycle detection and value handling. The existing variable 'data' is reused to avoid introducing new declarations.
