mutation operator: generic_const_in_trait_bound_with_const_param
Applies to function or impl block where a trait is implemented with a generic type parameter and a const parameter. Replace a const parameter's type from a fixed type (e.g., usize) to a generic type parameter of the trait/impl. Introduce a const expression using the generic type's size or similar in a where-clause. Requires enabling #![feature(generic_const_exprs)].

Example mutation:
Original code:
trait Process {
    const N: usize;
    fn validate(&self);
}
impl<T> Process for Vec<T> {
    const N: usize = 10;
    fn validate(&self) { ... }
}

Mutated code:
trait Process<T> {
    const N: T;
    fn validate(&self);
}
impl<T> Process<T> for Vec<T>
where [(); std::mem::size_of::<T>()]: Sized {
    const N: T = 42;  // Note: Requires valid T type
    fn validate(&self) { ... }
}

Requires existing T type parameter in impl/trait. If no type parameter exists, declare one in trait/impl. Use std::mem::size_of or similar const expressions in where-clauses.
