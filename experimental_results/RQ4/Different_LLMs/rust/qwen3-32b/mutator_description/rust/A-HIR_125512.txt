Mutation operator: MutualTraitMethodCycleInsertion
Applies to: Pairs of traits each containing at least one method
Change: For two existing traits T1 and T2, modify their first methods to create mutual dependencies:
1. In T1's method, replace a parameter and return type with T2
2. In T2's method, replace a parameter and return type with T1
Example:
Original:
trait T1 { fn m1(a: i32) -> bool; }
trait T2 { fn m2(b: char) -> String; }
Mutated:
trait T1 { fn m1(a: T2) -> T2; }
trait T2 { fn m2(b: T1) -> T1; }

Mutation operator: NestedTraitReferencePropagation
Applies to: Traits with methods that return types from other traits
Change: For a method returning trait type X, replace with a method that returns a trait type Y that also references X
Example:
Original:
trait A { fn f() -> B; }
trait B { fn g() -> i32; }
Mutated:
trait A { fn f() -> B; }
trait B { fn g() -> A; }

Mutation operator: ObjectSafeCycleEnforcement
Applies to: Traits with object-safe method signatures
Change: Modify method signatures to become non-object-safe by creating circular references between traits
Example:
Original:
trait T { fn m(x: usize) -> Self; }
Mutated:
trait T { fn m(x: U) -> Self; }
trait U { fn m(x: T) -> Self; }
