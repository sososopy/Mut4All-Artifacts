Mutation Operator: Inferred_Generic_Const_Parameter
Applies to functions that construct a generic type using a const parameter derived from an associated constant of the type parameter. 
When a struct's constructor is called with an explicit type parameter like T::new(), mutate to use inferred type parameters like T::new() without the explicit <COT> syntax. 
This targets situations where the compiler attempts to evaluate const expressions with inferred types during generic parameter resolution.

Example mutation:
Original code:
pub fn create<T>() -> MyStruct<T> 
where
    [(); T::CONST]: 
{ 
    MyStruct { a: [0; T::CONST] } 
}

Mutated code:
pub fn create<T>() -> MyStruct<T>
where
    [(); T::CONST]: 
{ 
    // Remove explicit type parameter from struct construction
    MyStruct::new()
    // Original: MyStruct::<T>::new()
} 

High coverage is achieved by applying to programs using associated constants in const parameters combined with type inference. The mutation preserves all existing type and variable names but relies on the compiler inferring the type parameter during const evaluation.
