Mutation Operator: Replace binary arithmetic operands in generic const expressions with incompatible types. Apply to arithmetic operations in const parameter expressions (e.g., array lengths, struct generics). If the original operands share the same type (e.g., both `usize`), change one operand to a different type (e.g., `i32`, `i64`, `u32`, or another type incompatible with the operation). Example: Change `X + Y` to `X (i64) + Y (usize)` when X and Y were originally both `usize`. This creates asymmetric binary operations that may trigger const evaluation bugs.
