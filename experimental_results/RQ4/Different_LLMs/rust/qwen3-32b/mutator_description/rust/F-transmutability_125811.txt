Mutation operator: Replace an enum variant type with the `!` never type and add the `never_type` feature gate.  
Target: Enum variant fields using a concrete type or unit type.  

Example mutation for a seed program with:  
```rust  
enum E { A(i32), B() }  
```  
Mutated code becomes:  
```rust  
#![feature(never_type)]  

enum E { A(i32), B(!) }  
```  

This triggers assertion failures in discriminant handling when combined with transmutability checks (e.g., `is_transmutable::<_, _>()`). The `!` type lacks a valid discriminant value, exposing bugs in the compiler's constant evaluation logic for enum variants. The feature gate ensures the never type is available as in the bug report. Apply to any variant with a non-`!` field type, prioritizing those in enums with existing transmutability-related traits or `#[repr]` attributes.
