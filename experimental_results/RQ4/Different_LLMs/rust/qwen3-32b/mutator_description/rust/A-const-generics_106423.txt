Mutation Operator: Replace a const generic literal argument with an existing const variable of the same value and type in the same scope.  
Example: Change a function call like `butter_st::<f64, 4, 2>(...)` to `butter_st::<f64, N, M>(...)` where `N` and `M` are const variables in the same scope with values `4` and `2`. If no such variables exist, this operator is not applicable.
