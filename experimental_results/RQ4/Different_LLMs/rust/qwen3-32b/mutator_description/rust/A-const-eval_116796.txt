Mutation operator: Replace const generic parameters with function pointer types using closures as defaults. Apply to structs/enums with existing const parameters.  
Example:  
Original code:  
struct S<const N: usize>;  

Mutated code:  
struct S<const FN: fn() = { || {} }>;  

Mutation operator: Add a const generic of function pointer type to an existing struct/enum, initializing it with a closure. Apply where the struct/enum uses simple const generics (e.g., usize, i32).  
Example:  
Original code:  
enum E { V }  

Mutated code:  
enum E<const FN: fn() = { || {} } { V }  

Mutation operator: Modify an existing const generic type to a function pointer (fn()) and assign a default closure. Target code that uses concrete types like integers or booleans for const generics.  
Example:  
Original code:  
struct T<const B: bool = true;  

Mutated code:  
struct T<const FN: fn() = { || {} }>;
