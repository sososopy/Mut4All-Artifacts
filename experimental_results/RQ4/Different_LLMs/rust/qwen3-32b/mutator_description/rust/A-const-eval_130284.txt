Mutation operator: Modify a slice index access to use a value close to usize::MAX in a const context with unsafe pointer manipulation to trigger overflow during const evaluation.  
Applies to: Code using `slice_from_raw_parts` with a large length and subsequent index access.  
Example: Given `let fat = slice_from_raw_parts(ptr, len); let x = fat[last_index];` mutate to `let fat = slice_from_raw_parts(ptr, usize::MAX); let x = fat[usize::MAX - 1];`. Keep existing `ptr`, `len` as original, but replace `len` with `usize::MAX` and `last_index` with `usize::MAX - 1`.  
Avoids new variables; reuses existing `ptr` and modifies its usage.
