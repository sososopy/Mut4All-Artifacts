Mutation Operator: Replace an associated type's expected lifetime parameter with a const generic expression in a trait object bound, targeting traits with generic associated types that require lifetimes.

Applies to: Functions or items using `dyn Trait` bounds where the trait includes a generic associated type requiring a lifetime parameter.

Example transformation:
Original code with trait:
trait MyTrait {
    type MyAssoc<'a>;
}

Modified code in a function:
fn example(arg: Box<dyn MyTrait<MyAssoc<1> = ()>>)
//              ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
// Replaced required lifetime parameter with const expression

This forces the compiler to process a const argument in a position expecting a lifetime, creating a type/lifetime confusion. The mutation works by taking an existing GAT that requires a lifetime (common in seed programs using GATs) and substituting the correct lifetime with a const generic argument in a bound context. No new types/variables needed - uses existing trait and associated type declarations.
