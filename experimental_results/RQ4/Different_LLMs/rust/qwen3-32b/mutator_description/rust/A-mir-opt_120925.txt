Mutation Operator: Convert a safe static function pointer to an unsafe variant when assigned to a closure. Apply to static items where a function pointer type is safely declared and assigned to a closure. Modify the function pointer type to `unsafe fn(...)` instead of `fn(...)`. This forces an invalid coercion that may expose MIR optimization bugs during cast validation.

Example:
Original:
static FOO: fn() = || { ... };

Mutated:
static FOO: unsafe fn() = || { ... };

This applies to any existing static function pointer declarations with closure assignments in a seed program. Existing closures and function signatures are reused without modification.
