Mutation Operator: Move non-trailing generic parameter with default value
Target Code Construct: Struct, enum, or function with generic parameters having a default value that is not in the trailing position.
Mutation Rule: For a generic parameter with a default value (e.g., `const X: T = expr`), reorder the generic parameters so that the parameter with the default value is not the last in the list. Additionally, replace the default value's type with an invalid const generic type (e.g., `str` instead of `usize`). 
Example: 
Original code: `struct S<const A: usize = 5, const B: usize>;` becomes `struct S<const B: usize, const A: str = 5>;`
Applies to: Any struct/enum/function with generic parameters where a default exists and can be reordered.
Requires: Existing generic parameters with at least one default value. New types/parameters must use existing types in the seed program.
