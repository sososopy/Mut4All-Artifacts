Mutation operator: For a struct containing a field of type `&'static [T]` where `T` includes a field with a mutable static reference, replace the initializer of that field with an array that includes a reference to a static that points to a mutable static via `unsafe`. This creates nested static references that may trigger invalid scalar layout evaluation during const-checking.

Example mutation:
Original struct field: `pub field: &'static [StructA]`
Modified initializer: `field: &[StructA] = &[StructB { ref_to_mut_static: unsafe { &mut GLOBAL_STATIC } } ]`

Applies to any static initializer that includes a `&'static [T]` slice containing a struct with a mutable static reference. The mutation introduces a dependency chain between statics via unsafe references, mimicking the bug's pattern of transitive static dependencies that challenge const evaluation logic.
