Mutation operator: In a GAT's where clause that specifies a lifetime bound between two lifetimes, reverse the bound to create a conflicting or non-standard hierarchy. Applies to any trait or impl block defining a GAT with a where clause involving two distinct lifetimes (e.g., 'outer: 'inner). Example: Change 'outer: 'inner to 'inner: 'outer in the where clause of the GAT's definition. This increases compiler complexity when resolving HRBBs and may expose ICEs in lifetime constraint handling.

Mutation operator: In a trait method with a higher-ranked trait bound (HRBB) on a parameter, add an additional nested HRBB using a new lifetime parameter, creating a compound bound. Applies to any function parameter with a for<'a> bound in its where clause. Example: Change F: for<'a> Fn(A<'a>) to F: for<'a> Fn(A<'a>) + for<'a, 'b> Fn(B<'a, 'b>). This increases compiler complexity when resolving HRBBs and may expose ICEs in nested bound handling.

Mutation operator: In a GAT's associated type definition, introduce an additional nested HRBB by adding a function parameter with a for<'a> bound that references the same or a different lifetime as the GAT's own parameters. Applies to any trait or impl block with a function method that uses a GAT and HRBB. Example: Change F: for<'a> Fn(A<'a>) to F: for<'a> Fn(A<'a>, B<'a>). This increases compiler complexity when resolving HRBBs and may expose ICEs in nested parameter handling.
