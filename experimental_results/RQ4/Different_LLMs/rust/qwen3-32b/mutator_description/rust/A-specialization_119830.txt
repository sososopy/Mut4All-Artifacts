Mutation Operator 1: Introduce a specialization constraint where the base trait is not marked as const.  
Applies to code that defines a trait and a specialization impl on a type bound to a const-trait.  
Mutate by adding a `const` qualifier to the specialization `impl`, but ensure the base trait is not marked with `#[const_trait]`.  
Example:  
Original:  
```
trait Base {}
trait Special: Base {}
impl<T> Base for T {}
impl<T> Special for T where T: Base {}
```
Mutated:  
```
trait Base {}
trait Special: Base {}
impl<T> const Base for T {}
impl<T> const Special for T where T: Base {}
```
This mutation targets the interplay between specialization and const bounds, which is likely to expose internal compiler errors related to constraint resolution and trait coherence.
