Mutation operator: Add an enum variant with a ZST field and an explicit discriminant of a large integer value (e.g., 0x7FFFFFFF). Target enums that already exist in the seed program. Example: Given an enum E { A(), }, and a zero-sized type ZST { }, mutate to E { A(), B(ZST) = 0x7FFFFFFF, }. This forces const evaluation of discriminants with variant-type-dependent layouts, which can trigger discriminant calculation bugs in the compiler.
