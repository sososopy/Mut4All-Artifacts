Mutation Operator: Generator Box Yield Expression  
Target: Generator closures (closures with `yield`) that produce a boxed expression.  
Change: Replace any `yield` expression in a generator closure with a `box yield` expression, wrapping the `yield` directly in a `box`.  
Example:  
Original generator closure:  
`let f = || { yield value; };`  
Mutated generator closure:  
`let f = || { box yield value; };`  
This targets MIR validation logic by creating a type mismatch between boxed and unboxed yields in generator state machines, similar to the ICE in the bug report.
