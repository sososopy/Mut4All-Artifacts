Mutation operator: Replace a match arm pattern with an undeclared variable pattern.  
Applies to: Match expressions with at least two arms, where the original pattern is a compound/range pattern.  
Example: In a match arm like `(1.., ..=-34665) => {}`, replace the pattern with `FOO_REF_REF => {}` where `FOO_REF_REF` is not declared elsewhere in the code.  
Rationale: Forces the compiler's late lint to process an undeclared variable in a pattern, triggering validation of variable presence during lint analysis. This targets issues where the lint infrastructure fails to handle missing variables, potentially causing `Option::unwrap()` on a `None` value (as seen in the ICE trace).  
New elements: The variable `FOO_REF_REF` must not exist in the seed program. The replacement preserves the structure of the match arm but introduces an invalid pattern, relying on the compiler to detect the missing declaration rather than panicking.
