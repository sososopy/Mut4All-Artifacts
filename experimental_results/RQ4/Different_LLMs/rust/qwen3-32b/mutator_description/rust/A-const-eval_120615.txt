Mutation operator: Introduce a field access on a non-ADT value  
Target construct: Variables of type array, slice, or primitive type in any expression context  

For any existing variable `x` of a non-ADT type (e.g., array `[T; N]`, slice `&[T]`, or primitive `i32`/`bool`), replace an existing simple expression `x` with a field access expression `x.field_name`.  

Example:  
Original code:  
```rust  
let s = [(); 10];  
println!(s);  
```  

Mutated code:  
```rust  
let s = [(); 10];  
println!(s.nonexistent_field);  
```  

This creates a field access on an array (non-ADT) which triggers the ICE in the compiler's dead code analysis. The mutation preserves existing symbols and uses the original variable `s` without introducing new types or variables.
