Mutation Operator: Introduce nested const-GAT trait bounds in traits with associated types.  
Target Code Construct: Traits defining associated types that are bounded by another trait's const-Generic Associated Type (GAT) with a constant parameter.  

Example Mutation:  
Given an existing trait `TraitA` with an associated type `TypeA`, and an existing trait `TraitB` with a GAT `TypeB<const C: i32>`, replace the associated type bound of `TypeA` with a nested const-GAT bound. For instance, modify:  
`trait TraitA { type TypeA: TraitB; }`  
to:  
`trait TraitA { type TypeA: TraitB<TypeB<const 1i32> = ()>; }`.  

This applies to any seed program containing at least one trait with a GAT and another trait with an associated type bound. The mutation forces the compiler to resolve nested const parameters during type checking, increasing the likelihood of exposing ICEs in const-GAT resolution logic.
