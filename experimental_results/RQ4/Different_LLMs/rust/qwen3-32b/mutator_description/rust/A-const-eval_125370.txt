Mutation Operator: Replace the type in a const item's declaration with an undefined type and assign its value using an infinite loop expression. Applies to const items with a concrete type and assignment. Example: Change `const C: T = expr;` to `const C: UnknownType = loop {};`. This creates a scenario where typeck processes a non-existent type alongside an invalid const expression, potentially exposing ICEs in const evaluation andHIR resolution.
