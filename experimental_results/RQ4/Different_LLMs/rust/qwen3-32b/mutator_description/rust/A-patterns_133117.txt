Mutation operator: Duplicate a match arm in a match expression where the original has a single arm. Replace the single arm with two identical arms, ensuring the pattern and condition are exact copies. Applies to any match statement with a single arm in the program.

Example:
Original:
match p {
    A if c => e
}

Mutated:
match p {
    A if c => e
    A if c => e
}

This targets the compiler's pattern matching analysis by creating duplicate match arms with identical patterns and conditions, which may trigger ICEs related to MIR construction and pattern overlap checks. The mutation preserves existing types/variables and applies to any match with a single arm.
