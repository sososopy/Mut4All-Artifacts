Mutation Operator: Replace a concrete const generic parameter in a function call with a generic const function that depends on a type parameter, potentially creating an unevaluated const expression during monomorphization.  
Applies to: Function calls using const generics where at least one parameter is a literal value.  
Example:  
Before:  
`fn call<T>() { let _ = MyStruct::<3, 4>::new(); }`  
After:  
`const fn helper<T>() -> usize { std::mem::size_of::<T>() / 2 }; fn call<T>() { let _ = MyStruct::<3, helper::<T>()>::new(); }`  
Change: Introduce a new const function `helper` that references a type parameter and replace a literal const with its result. If no suitable type parameter exists, add a generic type parameter `T` to the function.
