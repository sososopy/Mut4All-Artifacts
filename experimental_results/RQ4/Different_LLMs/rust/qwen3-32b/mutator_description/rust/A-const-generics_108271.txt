Mutation Operator 1: Replace an associated const's value in a trait bound with a generic const expression in a function's generic parameter. Targets code where a trait defines an associated const and a function uses that trait with a const argument. Example: Modify a function `fn foo<T, U: Trait<A = X>>() { ... }` where `X` is a non-generic literal (e.g. `{42}`) to instead use a generic expression like `{T}` or `{T + 1}`. This forces the compiler to treat the const argument as generic, exposing invalid const parameter type handling.
