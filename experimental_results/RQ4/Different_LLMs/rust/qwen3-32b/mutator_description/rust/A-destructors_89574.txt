Mutation Operator: Replace the initializer of a const declaration with an empty array, triggering destructor handling during compilation.

Applies to: Const declarations that do not involve function calls or complex expressions.

Change: Modify the right-hand side of a `const` declaration to an empty array literal (`[]`), regardless of the original value or type. This forces the compiler to process destruction logic for zero-sized arrays in const contexts, potentially exposing errors in destructor handling.

Example:
Before:
```
const X = compute_value();
```
After:
```
const X = [];
```

This mutation applies to any existing `const` declaration in the seed program. It does not require introducing new types or variables, relying instead on the compiler's handling of empty arrays in `const` contexts. The change is minimal and universally applicable to const declarations, making it likely to trigger the same internal error conditions reported in the bug.
