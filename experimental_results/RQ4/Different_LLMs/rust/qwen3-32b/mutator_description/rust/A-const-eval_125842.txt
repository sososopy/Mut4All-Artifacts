Mutation operator: DuplicateStructFieldWithConflictingType  
Applies to structs with at least one field and static variable declarations that reference the struct.  
Changes: For a target struct, duplicate an existing field with the same name but a different type from one of its other fields, creating a duplicate field name with conflicting types. In any static variable declaration using this struct, initialize the duplicated field with a value that matches its new type, even if it creates a type conflict with another field of the same name.  

Example:  
Original struct:  
pub struct Example {  
    value: T,  
    count: U,  
}  

Mutated struct:  
pub struct Example {  
    value: T,  
    count: U,  
    count: V,  
}  

In a static declaration:  
static DATA: Example = Example {  
    value: ...,  
    count: U::default(),  
    count: V::default(),  
};  

This forces const evaluation to encounter a struct with duplicate fields of different types, stressing type checking and evaluation logic.
