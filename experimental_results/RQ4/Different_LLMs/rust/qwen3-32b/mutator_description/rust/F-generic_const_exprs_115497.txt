Mutation operator 1: Increase nested binder depth in trait bounds  
Target: Trait bounds with `for<...>` associated type projections  
Applies to: Any trait bound that uses `for<...>` with associated type bounds  

Mutate trait bounds like `AsA: for<'b> TraitB<...>` to add nested binders and associated type bounds, e.g.:  
Original:  
trait TraitA<'a> { type AsA; }  
fn foo<T>() where T: TraitA<'a, AsA: for<'b> TraitB<'a, 'b>> { ... }  

Mutated:  
trait TraitA<'a> { type AsA; }  
fn foo<T>() where T: TraitA<'a, AsA: for<'b> TraitB<'a, 'b, AsB: for<'c> TraitC<'a, 'b, 'c>>> { ... }  

Changes required:  
1. Add new lifetime parameter ('c in example) to innermost trait  
2. Add nested `for<...>` binder in associated type bound  
3. Chain multiple trait bounds with increasing binder depth  

This stresses the compiler's handling of nested binders and bound var resolution in type-checking.
