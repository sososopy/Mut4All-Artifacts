Mutation Operator: MacroWrapConstGeneric
Target: Const generic parameters that directly reference variables or expressions.
Action: Introduce a macro `wrap!` expanding to its argument, and replace the direct expression in the const generic with `wrap!(expression)`. For example, transform `pub struct S<const V: usize>(Const<{ V }>)` into `pub struct S<const V: usize>(Const<{ wrap!(V) }>);`. If no existing macro is present, declare `wrap!` as a simple identity macro (`macro_rules! wrap { ($v:expr) => { $v }; }`). This creates a macro nesting in a const generic context, testing compiler handling of macro expansion for const parameters.
