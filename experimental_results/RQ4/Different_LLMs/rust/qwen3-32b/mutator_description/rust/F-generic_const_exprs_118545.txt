Mutation Operator: ReplaceConstGenericWithFunctionPointer
Target: Struct or enum definitions with const generic parameters.
Action: Modify an existing const generic parameter's type from an integer or boolean to a function pointer signature (e.g., `fn(usize) -> bool`). If no suitable function exists in the seed program, declare a new function like `fn dummy(val: usize) -> bool { true }` and use it as the const parameter value in struct/enum instantiations. This forces the compiler to evaluate unsupported function pointer usage in const generics, exposing handling of incomplete generic_const_exprs feature. Apply to any struct/enum with const generics, replacing one parameter type and modifying all usages to pass the function name.
