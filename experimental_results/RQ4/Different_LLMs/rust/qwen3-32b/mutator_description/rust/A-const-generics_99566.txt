Mutation Operator: InsertConstGenericInClosureParamList  
Applies to every closure in the seed program. Replace a closure's parameter list with a `for<const _: T>` clause, where `T` is a type from the seed program. If the `closure_lifetime_binder` feature is not already enabled, add `#![feature(closure_lifetime_binder)]` to the crate root.  

Example:  
Original:  
```rust  
let c = || { ... };  
```  
Mutated:  
```rust  
#![feature(closure_lifetime_binder)]  

let c = for<const _: Type> || { ... };  
```  
Where `Type` is a valid type existing in the seed program.
