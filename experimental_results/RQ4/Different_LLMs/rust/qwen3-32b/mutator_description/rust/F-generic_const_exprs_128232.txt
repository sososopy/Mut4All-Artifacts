Mutation operator: Replace const generic parameter with a function pointer type returning the same type as the original parameter, using an existing function from the program. Apply to struct/impl declarations with generic const parameters.

For any struct or impl using a const parameter of type T, mutate to use const parameter of type fn() -> T, referencing an existing function returning T. Example:
Original:
struct S<const N: u32>;
impl S<N> { /* ... */ }

Mutated:
struct S<const F: fn() -> u32>;
impl S<{ existing_func() }> { /* ... */ }

Where existing_func is a function already present in the program that returns u32. This exploits the compiler's handling of function pointers in const parameters, which is explicitly forbidden in the bug report's error[E0741]. The mutation forces ICE conditions by combining generic const expressions with unsupported function pointer parameters, leveraging existing program elements without introducing new declarations.
