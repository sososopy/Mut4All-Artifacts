Mutation operator: NestStaticGenericWithLifetime  
Applies to: static variable declarations with generic types involving 'static lifetime bounds  
Action: Add an additional nested generic layer to the static's type by wrapping it in a struct with a 'static bound, and adjust the initializer to include an extra reference level. For example, change `static X: T = expr;` to `static X: A<B<T>> = A(&B { inner: expr });` where A and B are structs with 'static bounds in their definitions. This increases nesting depth and challenges const evaluation of promoted constants in deeply nested statics.
