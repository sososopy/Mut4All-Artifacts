Mutation operator: Replace a valid const generic parameter with an existing function name in const generic positions.  
Applies to: Array length, struct const fields, or function const parameters where a valid const expression is used.  
Example:  
Original: `[(); 42]`  
Mutated: `[(); my_fn]` (where `my_fn` is an existing function, not a const).  
Effect: Forces the compiler to evaluate a non-const function as a const argument, potentially exposing ICEs in const generic analysis.  
Requirements:  
- Use only functions already declared in the seed program.  
- Apply only to const generic parameters (e.g., `[(); N]`, `Struct<N>`), ensuring the replacement is syntactically valid but semantically invalid.  
- Prioritize functions with non-const signatures to maximize invalidity.
