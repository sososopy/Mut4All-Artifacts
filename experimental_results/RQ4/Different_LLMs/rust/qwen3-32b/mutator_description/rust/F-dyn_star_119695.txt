Mutation operator: Convert a struct to a union, implement a trait for the union, and replace a function parameter with a raw trait pointer expecting the union. Example: Replace `struct S { x: T }` with `union U { x: T }`, add `impl Trait for U`, then change `fn f(_: S)` to `fn f(_: *const dyn Trait)` and pass `U { x: 0 }`. This targets raw pointer trait object handling for unions, common in ICEs with `dyn*`.
