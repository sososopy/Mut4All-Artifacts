Mutation Operator 1: Replace array index with trait's associated constant in generic context.  
Applies to: Array access expressions within a generic impl or function where a trait with associated constant is in scope.  
Modifies: A simple array index expression (e.g. `[...][N]` where `N` is a literal or variable) by replacing `N` with `T::CONST` where `T` is a generic parameter with a trait bound that declares the associated constant.  
Example:  
Original:  
```rust  
const BAR: usize = [5, 6, 7][3];  
```  
Mutated:  
```rust  
const BAR: usize = [5, 6, 7][T::CONST];  
```  
Requires:  
1. `T` is a generic parameter with a trait bound (e.g., `T: MyTrait`).  
2. `MyTrait` must declare an associated const (e.g., `const CONST: usize`).  
3. Existing array and trait must already exist in the seed program.  
Note: This introduces potential out-of-bounds access during MIR optimization (e.g., GVN), which may trigger ICEs in constant evaluation paths. Prioritize replacing indices where array length is small and associated constant value is large (if possible).
