Mutation operator: Replace transmutations from pointers to integers with transmutations to non-integer scalar types (e.g., f64, bool) in unsafe contexts. This alters the scalar type handled by MIR optimizations, potentially triggering assertion failures if the compiler expects integer scalars where others exist.

Example application in pseudo-code:
Original: `let x: usize = unsafe { mem::transmute(ptr) };`
Mutated: `let x: f64 = unsafe { mem::transmute(ptr) };` 

Applies to: Any transmute converting a pointer to an integer type in the seed program. Reuses existing variables/pointers from the code without introducing new types.
