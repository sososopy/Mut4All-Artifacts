Mutation operator: Add a const trait with `#[const_trait]` and a trait object with `~const` bound on a non-auto trait.  
Target: Any struct or trait declaration.  

Example: Given a trait `Trait`, modify it to:  
```rust  
#[const_trait]  
trait Trait {}  
```  
and create a trait object in a function:  
```rust  
fn main() {  
    let _: &dyn ~const Trait;  
}  
```  
This forces the compiler to process a `#[const_trait]` and a `~const` trait object bound, which can trigger ICEs in type-checking or object safety validation.
