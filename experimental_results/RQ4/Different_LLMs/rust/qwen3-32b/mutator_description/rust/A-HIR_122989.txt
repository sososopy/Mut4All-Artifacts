Mutation Operator 1: DuplicateConstParamCycle  
Applies to: Traits with const parameters (e.g., `trait T<const X: U> { ... }`).  
Mutation: Add a duplicate const parameter with the same identifier as an existing one, and set its default value to reference the previously declared const parameter in the same list.  

Example:  
Original:  
```rust  
trait Example<const X: usize = 42> { ... }  
```  
Mutated:  
```rust  
trait Example<const X: Example<10> = 42, const X: usize = X> { ... }  
```  

This creates a cyclic dependency between the two const parameters (one referencing the trait itself and the other referencing the first parameter), leading to conflicts during HIR well-formedness checking. The mutation avoids introducing new variables or types, leveraging existing trait names and identifiers.
