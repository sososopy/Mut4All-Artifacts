Mutation operator: Add a computed generic const parameter in a where clause using an existing const parameter.  
Target: Functions with at least one generic const parameter and a where clause.  
Example:  
Original code:  
```rust  
fn f<T, const N: usize>()  
where  
    T: Copy,  
{  
    // ...  
}  
```  
Mutated code:  
```rust  
fn f<T, const N: usize, const NP: usize = { N + 1 }>()  
where  
    T: Copy,  
{  
    // ...  
}  
```  
Explanation: This introduces a new generic const parameter `NP` derived from an existing `N` via a constant expression (`N + 1`). The mutation applies to existing where clauses and uses variables already declared in the function's generics. It stresses the compiler's handling of computed const expressions in trait bounds, similar to the bug report's ICE scenario.
